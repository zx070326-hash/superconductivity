被订正的对象：`$ARGUMENTS`。分两段写，第二段不许省：

**第一段：旧陈述错在哪。**
- 两个数不一致时先问「同一个证书 / 同一约定下的量吗」，再问谁错。（`√c_GF=1.11712` 是另一份证书的合法下端。）
- 先确认那个符号/截断作用在哪个变量上，不从名字推语义。（`ω_c` 的宗量是松原频率。）

**第二段：新陈述凭什么对。** 逐项：
1. 标级了吗？
2. 方向审了吗？订正一个方向缺陷后，受它影响的每一列重算。
3. 前提核了吗？
4. 用的是对方的证据还是我从零重建的？
5. 「X 与 Y 不相合」：它们是同一模型设定下的同一参数吗？（线性 b vs 二次 b 差 +0.24。）
6. 「X 是实验内容非公式伪影」：配对生成检验跑了吗？
7. 简化恰好把结论推向我期待的方向 ⟹ 那一处必须审。

只完成第一段 = 只完成不承重的那一半。

本条可被覆盖，写明理由即可。
