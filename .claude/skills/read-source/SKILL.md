来源：`$ARGUMENTS`。

1. **两种仪器都跑**：`pdftotext -enc UTF-8`（不加则吞 σ/π 上下标）+ Read 页图（小下标 `N_{JJ′}` vs `N_{J′}` 页图不可靠）。互为对照，不只信一种。
2. **APS 老文**：`harvest.aps.org/.../fulltext` 是 JBIG2 扫描件，只能 Read 页图，WebFetch 必失败。
3. **搜 PDF 用 ASCII 词**：pdftotext 糊 Unicode。
4. **改承重列语义前，先找一个它必须复现的旧数**（`ω̄₂=65 ⟹ 𝔣_Pb=0.4869`）。
5. **表的自由度**：几个印出的数、几个独立量？找生成式（比值对 × 拟合标度）。
6. **数据集来源**：那批 Tc 是实验值还是公式值？（Cerqueira 6912 是 AD 公式值。）
7. **引文核到句**：「optimized…」类转述先在原文找到那句；找不到写「未见」，且该引文不得作承重依据。
8. 转录后记：出处（页/式/表）、我读的是文本层还是页图、有无歧义字符。
