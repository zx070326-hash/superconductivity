---
name: tighten-bound
description: 我自己在纸笔/符号推导里放缩或收紧一个量，产出是不等式。不是派给别人（dispatch-*），不是写区间算术脚本（write-certificate）。
---

对象：`$ARGUMENTS`。落笔前查：

1. **预算**：把这个量退化到最坏（×κ / ∞ / 删掉），下游哪里翻转？∞ ⟹ 不做，它只买余量。这条对我自己与对 agent 同等有效。
2. **方向**：每处代入/截断旁写不等号朝向。上界的下估只支持 PASS。
3. **松早了没有**：链条上哪一步已经是精确的（有限窗口逐位精确）？只放缩尾部，不全程放缩。先查现有链每一步，再造新工具。
4. **还在类里吗**：对核做了加/减/取绝对值之后，结果还在 𝒫 里吗？矩之差不界任何东西。
5. **同一个符号一个意思**：`M2` 是尾系数还是二阶矩？两者只在 𝒫 上重合。
6. **重解下游**：这个界收紧后，凡是「为它解过一次优化」的（格划分等）必须重解，不许把新值代进旧最优解。
7. **标级**：analytic / rational-exact（格数+有理数个数，不得简称 analytic）/ certificate / numerical-evidence，写在结论旁。

本条可被覆盖，写明理由即可。
