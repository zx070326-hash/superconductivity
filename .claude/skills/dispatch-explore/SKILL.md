---
name: dispatch-explore
description: 派活，但预算填不出来（侦察文献、扫可能性、找反例形状）。选它即声明「探索型，预算门不适用」。产出一份 3 格 prompt。
---

用户原话（`$ARGUMENTS`）**原样**作为 prompt 首段，不改写、不翻译、不补全；模型/agent 类型按用户指定，作为 Agent 工具参数传。

prompt 正文 = 3 格：

1. **问题**：写成问句，不写成待证命题（探索型的失效形状是把猜测预写成结论）。
2. **约定钉死**：只钉与问题相关的那几项（单位 / 约定 / 谱），其余明说「自选并写明」。
3. **什么算发现、什么不算**：一句「若找到 ___ 即报告；找不到也报告，写明检索式/扫过的范围」。阴性结果同样交付。

先验检索由 hook 自动追加，不手抄；hook 没附加时手动跑 `sh tools/prior_art.sh "<承重量>"`。
探索型交付回来后仍走 `receive`：探索得出的数字若被任何判决消费，就地升级为承重，要从零复核。

本条可被覆盖，写明理由即可。
