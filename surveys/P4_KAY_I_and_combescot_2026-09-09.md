## §1 算子 𝔊(γ) 的精确定义（检索目标一 · 第 1 项）

### 1.1 总结构（等级 A，PDF p.22–23，eqs. 41–44）

𝔊(γ) 作用在 **ℓ²(ℕ₀)** 上（下标从 **n = 0** 起），定义为

> 𝔊 = −𝔊₁ + 𝔊₂ + 𝔊₃　（p.25 行文逐字："the operator 𝔊 = −𝔊₁ + 𝔊₂ + 𝔊₃ is compact"）

三个分量的**逐分量作用**（原文 eqs. 42–44，A 级逐字转录）：

**(𝔊₁(γ)Ξ)_n** = [ 1/(2n+1) · Σ_{k=1}^{n} 2/k^γ ] ξ_n　　　(42)

**(𝔊₂(γ)Ξ)_n** = Σ_m [ 1/√(2n+1) · (1−δ_{n,m})/|n−m|^γ · 1/√(2m+1) ] ξ_m　(43)

**(𝔊₃(γ)Ξ)_n** = Σ_m [ 1/√(2n+1) · 1/(n+m+1)^γ · 1/√(2m+1) ] ξ_m　(44)

其中 Ξ = (ξ_n)_{n∈ℕ₀} ∈ ℓ²(ℕ₀)，所有求和默认 m ∈ ℕ₀。

### 1.2 等价的矩阵元表述（等级 A/B，从上式直读）

**(𝔊₁)_{n,m}** = [ 1/(2n+1) · Σ_{k=1}^{n} 2/k^γ ] δ_{n,m}　——**对角算子**，**非负**，n=0 时该元素 = 0（求和为空）

**(𝔊₂)_{n,m}** = (1−δ_{n,m}) / ( √(2n+1) · |n−m|^γ · √(2m+1) )　——**实对称**，对角 = 0，非对角 > 0

**(𝔊₃)_{n,m}** = 1 / ( √(2n+1) · (n+m+1)^γ · √(2m+1) )　——**实对称**，**所有元素** > 0（含对角）

**关键特性（原文 p.23 逐字，A 级）**：
- "𝔊₁ is a diagonal operator with non-negative diagonal elements"
- "𝔊₂ is a real symmetric operator with vanishing diagonal elements and positive off-diagonal elements"
- "𝔊₃ is a real symmetric operator with all positive elements"
- 三个 𝔊_j 都是 **Hilbert–Schmidt** 的（Appendix A 证明，pp.42–43），因此紧

### 1.3 归一化约定与下标（A 级）

- **下标从 n = 0 开始**（ℕ₀ = {0,1,2,...}），原文 p.22 eq.(39)–(40) 和多处 "ℓ²(ℕ₀)" 明确。
- 归一化因子是 **1/√(2n+1)**，来自变换 ξ_n = √(2n+1) · θ_n（p.22 eq.39）。
- **没有额外的常数或全局前因子** —— 𝔊₁, 𝔊₂, 𝔊₃ 的定义里除了 γ 以外没有任何待定常数。
- γ **仅通过幂律指数** k^γ, |n−m|^γ, (n+m+1)^γ 进入。

### 1.4 𝔊^(4)(γ) 的显式 4×4 矩阵（A 级，p.13 eq.31）

原文给出完整的 4×4 矩阵。逐字转录（每个元素为 𝔊_{n,m}，n,m ∈ {0,1,2,3}）：

```
𝔊^(4)(γ) =
⎛  1                    1/√3 [1/2^γ + 1]       1/√5 [1/3^γ + 1/2^γ]     1/√7 [1/4^γ + 1/3^γ]  ⎞
⎜  1/√3 [1/2^γ + 1]    1/3 [1/3^γ − 2]         1/√15 [1/4^γ + 1]       1/√21 [1/5^γ + 1/2^γ] ⎟
⎜  1/√5 [1/3^γ + 1/2^γ] 1/√15 [1/4^γ + 1]     1/5 [1/5^γ − 2/2^γ − 2]  1/√35 [1/6^γ + 1] ⎟
⎝  1/√7 [1/4^γ + 1/3^γ] 1/√21 [1/5^γ + 1/2^γ] 1/√35 [1/6^γ + 1]       1/7 [1/7^γ − 2/3^γ − 2/2^γ − 2] ⎠
```

每个元素 = −(𝔊₁)_{n,m} + (𝔊₂)_{n,m} + (𝔊₃)_{n,m}，可逐项核对。

### 1.5 与 KAY II 的关系（连接到 P4-A/B/C 的桥梁）

KAY II 的 𝔎 算子与 KAY I 的 𝔊 不同：**KAY II 的 𝔎(P,T) = ∫₀^∞ ℌ(ϖ) P(dω)**，其中 ℌ(ϖ) 有分量 ⟦n⟧(ϖ) = ϖ²/(n² + ϖ²)。KAY I 的 𝔊(γ) 是 γ 模型的固有算子。物理 γ = 2 对应 Einstein 声子的 λ → ∞ 极限。

关系（survey §1.3 逐字）：C_∞ = (1/2π) √𝔤(2)，其中 𝔤(2) = ρ(𝔊(2)) 是 KAY I 算子在 γ = 2 的谱半径。这是 P4-B 的核心对象。

## §2 Propositions 5 与 6（检索目标一 · 第 2 项）

### 2.1 Proposition 5（A 级，p.35 eq.89）

**确切陈述**：
> **Proposition 5**: Let γ > 0 be given. Then for any ε ∈ (0, min{2γ, 1}),
>
> ρ(𝔊₂(γ)) ≤ ((2^{1+ε} − 1) ζ(1+2γ−ε) ζ(1+ε))^{1/2}.　　(89)

**证明骨架**（pp.35–36，A 级逐字摘要）：

1. **对称性利用**：𝔊₂ 的对角元为零，故 ⟨Ξ, 𝔊₂ Ξ⟩ = 2 Σ_{n≥0} Σ_{m>n} ξ_n [1/√(2n+1) · 1/(m−n)^γ · 1/√(2m+1)] ξ_m　(90)

2. **Cauchy–Schwarz**（eq.91）：将每个 (n,m) 项拆为三因子 ξ_n · [kernel] · ξ_m，用 C-S 分离 ξ 和 kernel。

3. **核心松弛步骤**（eq.92，**这是 P4-C 的攻击点之一**）：
   > 1/√(2m+1) · ξ_m = 1/(2m+1)^{1/2−ε/2} · 1/(2m+1)^{ε/2} · ξ_m

   即把 1/√(2m+1) 拆为两个因子，分别吃进不同的求和。

4. **产生 ζ 函数的步骤**（eqs.95–96）：
   > Σ_{m>n} 1/(m−n)^{2γ} · 1/(2m+1)^{1−ε} ≤ (用 m−n → m > 0 换标) Σ_{m>0} 1/m^{2γ} · 1/(2m+2n+1)^{1−ε}

   然后**关键估计**（eq.96，A 级逐字）：
   > ≤ 1/2^{1−ε} · Σ_{m>0} 1/m^{1+2γ−ε}

   使得求和在 ε < 2γ 时收敛为 **ζ(1+2γ−ε)/2^{1−ε}}**。

5. 另一侧的求和产生 Σ_{n≥0} 1/(2n+1)^{1+ε}，该因子等于 **(1 − 1/2^{1+ε})ζ(1+ε)**。

6. 最终合并并取平方根得 eq.(89)。

**P4-C 视角**：证明里最粗糙的一步是 eq.(96) 的 **2m+2n+1 ≥ 2m** 估计。当 n ≥ 1 时 2n+1 ≥ 3 ≥ 2，该估计浪费了一个因子 ~(1+n/m)^{1−ε}。~~但在 γ = 2, ε = 0.65 处，ζ(1+2γ−ε) = ζ(4.35) ≈ 1.062 已经很接近 1（更紧的估计不能低于 1），所以这一因子的改进空间不大。真正的大损失在 Lemma 8/9 把 ρ(𝔊₂) + ρ(𝔊₃) 当上界（§2.3 的 Lemma 9）。~~ **⚠ 更正（P4-C，commit 0c7353d）：此判断错。只盯 ζ(4.35)≈1.06 忽略了 Prop5 另两个因子 (2^{1.65}−1)≈2.14 与 ζ(1.65)≈2.11——三者合成 Prop5≈2.19，而真值 ρ(𝔊₂)=0.71，即 Props 5&6 的 C-S+ζ 估计整体高估 ~3×，正是缺口的 ~90%（不是 Lemma 9 的次可加性，那只 6.9%）。**


### 2.2 Proposition 6（A 级，p.36 eq.98）

**确切陈述**：
> **Proposition 6**: Let γ > 0 be given. Then for any ε ∈ (0, min{2γ, 1}),
>
> ρ(𝔊₃(γ)) ≤ 1 + ((2^{1+ε} − 1) ζ(1+2γ−ε) ζ(1+ε))^{1/2}.　(98)

**注意结构**：Prop 6 的右端 = **1 + Prop 5 的右端**。这个 "1" 来自 𝔊₃ 的对角元素贡献。

**证明骨架**（pp.36–38，A 级）：

1. 利用 𝔊₃ 的全正性，展开（eq.99）：
   > ⟨Ξ, 𝔊₃ Ξ⟩ = Σ_{n≥0} [1/(2n+1)^{1+γ}] ξ_n² + 2 Σ_{n≥0} Σ_{m>n} ξ_n [1/√(2n+1) · 1/(n+m+1)^γ · 1/√(2m+1)] ξ_m

2. 对角项估计（eq.100）：Σ [1/(2n+1)^{1+γ}] ξ_n² ≤ ‖Ξ‖²　（因为 1/(2n+1)^{1+γ} ≤ 1）

3. 非对角项用与 Prop 5 完全类似的 C-S + ζ 手法处理。核心步骤（eq.103–105）：
   > Σ_{m>n} 1/(n+m+1)^{2γ} · 1/(2m+1)^{1−ε} = Σ_{m>0} 1/(m+2n+1)^{2γ} · 1/(2m+2n+1)^{1−ε}

   然后**关键估计**（eq.104）：
   > ≤ 1/(2^{1−ε}) · Σ_{m>0} 1/m^{1+2γ−ε}

   **注意**：这里用了 **2n+1 > 0**（即 2m+2n+1 > 2m），**但原文 p.38 明确说 "where we used that 2n+1 > 0"**——这就是 survey §1.6 第 4 点提到的 "ϖ²+k² > k² 那类松弛"的原型。

4. 合并得 eq.(98)。
