## 1. 化约（主会话，半页；待 researcher 核 KAY III 是否已写出）

记 ϖ=ω/2πT，𝔎(P,T)=∫ℌ(ϖ)P(dω)（KAY II eq.39 后：三块都是 P-平均，Bochner 积分，P 紧支 ⟹ ℌ 一致有界）。

- **引理 A（Jensen）**：λ₁(·)=sup_{‖u‖=1}⟨u,·u⟩ 是自伴算子上的凸泛函，故 𝔨(P,T)=λ₁(𝔎) ≤ ∫λ₁(ℌ(ϖ))P(dω) = ∫h(ϖ)P(dω)，h(ϖ):=λ₁(ℌ(ϖ))。
- **引理 B（逐点不等式，待证）**：h(ϖ) ≤ 𝔤(2)·ϖ² 对所有 ϖ>0，且 ϖ>0 时严格。
- **推论**：𝔨(P,T) ≤ 𝔤(2)∫ϖ²P = 𝔤(2)⟨ω²⟩/(2πT)²。Tc 由 𝔨(P,T_c)=1/λ（或 sup 定义）给出 ⟹ (2πT_c)² ≤ 𝔤(2)⟨ω²⟩λ ⟹ T_c ≤ T̃_c；严格性由引理 B 的严格不等式 + P≠δ₀ 给出。∎

引理 B 恰是 KAY III 对 Einstein 声子（P=δ_{ω_E}）的 Conjecture 1。**⟹ 一般-P 猜想被 Einstein 特例蕴含**；本文件只需证引理 B。

## 2. 引理 B 的三段证明计划

数值探针（`notes/_scratch_ir/conj2_probe.py`、`conj2_probe2.py`，float64 证据、非证书）：r(ϖ):=h(ϖ)/ϖ² 在 [0.01,3] 上严格单调下降；ϖ→0 时 r→𝔤(2)，r = 𝔤(2) − 1.193·ϖ² + O(ϖ⁴)（二阶系数 = ⟨v₀,𝔊(4)v₀⟩=1.19317，与网格逐位符）；r(0.3)=0.926𝔤(2)、r(0.7)=0.701𝔤(2)、r(1)=0.543𝔤(2)、r(2.4)=0.199𝔤(2)。极值只在 ϖ=0 从上方逼近。

**恒等式（级数）**：⟦k⟧(ϖ)/ϖ² = 1/(k²+ϖ²) = Σ_{j≥0}(−1)^j ϖ^{2j}/k^{2j+2}（|ϖ|<k，即对全部 k≥1 当 ϖ<1），逐元代入 ℌ 的定义（与 𝔊(γ) 定义同型，`H_matrix` vs `G_matrix`）得

  ℌ(ϖ)/ϖ² = Σ_{j≥0} (−ϖ²)^j 𝔊(2j+2)，　ϖ<1，算子范数收敛（‖𝔊(γ)‖ 由 Prop5/6 型 ζ-界一致有界，或由 |𝔊(γ)| ≤ |𝔊(2)| 逐元 dominate 的 Schur 界）。

- **段 I（小 ϖ，解析微扰，ϖ∈(0,ϖ₀]，目标 ϖ₀≈0.5–0.7）**：A(ϖ)=𝔊(2) − ϖ²𝔊(4) + R(ϖ)，‖R‖ ≤ Σ_{j≥2}ϖ^{2j}‖𝔊(2j+2)‖。二阶本征值余项 (*)（`p4_remainder_interchange.py` 行 40）给 λ₁(𝔊(2)−ϖ²𝔊(4)) ≤ 𝔤(2) − ϖ²⟨v₀,𝔊(4)v₀⟩ + ϖ⁴‖𝔊(4)‖²/(g−2ϖ²‖𝔊(4)‖)，g = 𝔤(2)−λ₂(𝔊(2)) 由 P4-C 的 α 证书（λ₂≤2.0e-2）严格；⟨v₀,𝔊(4)v₀⟩ 的严格下界由数值试探向量 + Davis–Kahan 角度（认证谱隙 ≈1.30、残差小）给。要证：−c₂ϖ² + Cϖ⁴ + ‖R‖ < 0 ⟺ ϖ² < c₂/(C+…)，粗算 ϖ₀≈0.7。**全部量须 mpmath、进界的无 float64**。
- **段 II（中 ϖ，区间证书，[ϖ₀, ϖ₁]，ϖ₁≈6）**：逐 cell 上界 h(ϖ) ≤ λ₁(A_head)+‖B‖+‖D‖ + L(b−a)/2（λ₁(A_head)≤c 由 Cholesky cI−A SPD，**不需 deflation**；‖B‖,‖D‖ 分段包络；L 加权第 0 行 `schur_full_seg_w0`），与 𝔤(2)_lo·a²（cell 左端）比较。余量 ≥6%（ϖ₀=0.7）到 80%（2.4），网格可粗，Na=70/140。
