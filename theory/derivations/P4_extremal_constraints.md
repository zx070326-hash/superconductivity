## 0. 动机与方法

**定理 2（Einstein 极值）** 的证明使用「核级 Jensen」套路：φ_k(ω) := ω²/((k·2πT)² + ω²) 关于 ω 严格凹（x=ω² 时 x/(k²+x) 关于 x 凹）⟹ F_T(k) = ∫φ_k(ω)P(dω) ≤ φ_k(ω_rms) 逐点成立 ⟹ 引理 M 给 𝔨(P,T) ≤ h(ω_rms/2πT)。

**本文目标**：将此套路系统地应用到文献中出现的其他约束（固定 ω_max、固定 ⟨ω⟩ 在支撑限制下、固定 ω_log、固定面积 A=λ⟨ω⟩/2、各向异性压缩），写成一组命题并给出数值门。

**核心技术点**：
1. 引理 M 只需核 F ≤ G 逐点、F 非增、F∈ℓ¹、F≢0 ⟹ λ₁(𝒪[F]) ≤ λ₁(𝒪[G])。
2. φ_k 关于 ω 的单调性与凹性区间决定了 Jensen 不等式的适用范围。
3. 每个约束对应一个不同的「被积测度空间」或「优化问题」。

**诚实边界**：
- 命题 1（固定 ω_max）平凡但必须记录（Semenok 2407.12922 的严格版）。
- 命题 2（固定 ⟨ω⟩）全局失败但在支撑条件下成立，是 Combescot 1990 弱耦合结果的有限-λ 版。
- 命题 3（固定 ω_log）同样需要支撑下界。
- 命题 4（固定面积）涉及 λ 不固定，需要探索 h(ϖ)/ϖ 的性质。
- 命题 5（各向异性）是算子压缩的一般结果，需要仔细验证 KAY 算子形式。

## 1. 命题 1：固定 λ 与 ω_max（Semenok 约束的严格版）

**陈述.** 设 P∈𝒫、⟨ω²⟩<∞，支撑于 [0, ω_max]。固定 λ>0 与 ω_max。则对所有 T>0：
$$\mathfrak{k}(P,T) \le h(\varpi_{\max}), \quad \varpi_{\max} := \omega_{\max}/(2\pi T).$$
等价地：在固定 λ 与 ω_max 下，单频谱 δ_{ω_max} 使 T_c 最大。

**证明.** 记 x := ϖ² = (ω/2πT)²。核 F_T(k) = ∫[x/(k²+x)]P(dω)。因 φ_k(ω) = x/(k²+x) 关于 ω 严格递增（对 x 求导：k²/(k²+x)² > 0），且 P 支撑于 [0,ω_max]，故
$$F_T(k) = \int_0^{\omega_{\max}} \frac{x}{k^2+x} P(d\omega) \le \frac{x_{\max}}{k^2+x_{\max}} = \llbracket k \rrbracket(\varpi_{\max}),$$
其中 x_max = (ω_max/2πT)² = ϖ_max²。等号 ⟺ P = δ_{ω_max}。

F_T 非增（φ_k 对 k 递减 ⟹ ∫φ_k P 对 k 递减）、F_T ≤ x_max/k² ∈ ℓ¹、F_T(1) > 0（P≠δ_0）；⟦·⟧(ϖ_max) 同样非增且 ∈ℓ¹。引理 M ⟹
$$\mathfrak{k}(P,T) = \lambda_1(\mathcal{O}[F_T]) \le \lambda_1(\mathcal{O}[\llbracket \cdot \rrbracket(\varpi_{\max})]) = h(\varpi_{\max}).$$
严格性：若 P≠δ_{ω_max}，则 ∃k 使 F_T(k) < ⟦k⟧(ϖ_max)，特别地 F_T(1) < ⟦1⟧(ϖ_max)，故 d(1)>0，引理 M 给严格不等号。∎

**文献定位.** Semenok–Altshuler–Yuzbashyan, arXiv:2407.12922 SI §S4 用变分法给出「δ_{ω_max} 是驻点」，但未证唯一性或全局性。本命题给出严格证明，对**所有 λ** 成立（非仅弱耦合）。

**数值验证.** 取 ϖ_max=5，随机生成支撑于 [0,5] 的两原子谱 P = p·δ_{ω_1} + (1−p)·δ_{ω_2}（ω_1,ω_2 ∈ [0,5]，p∈(0,1) 随机），计算 𝔨(P,1)/h(5)。预期：恒 <1，且当 ω_1,ω_2→5 时→1。

## 2. 命题 2：固定 λ 与 ⟨ω⟩ 在大 ϖ 区（Combescot 弱耦合的有限-λ 版）

**背景.** φ_k(ω) = x/(k²+x) 关于 ω 的二阶导数：设 x=(ω/2πT)²，
$$\phi_k''(\omega) = \frac{2k^2(2\pi T)^4(k^2(2\pi T)^2 - 3\omega^2)}{(k^2(2\pi T)^2 + \omega^2)^3}.$$
变号点：ω\* = k·2πT/√3。当 ω ≥ k·2πT/√3 时，φ_k″(ω) ≤ 0（凹）。

**陈述.** 设 P∈𝒫、⟨ω⟩<∞，支撑于 [ω_0, ∞)，其中 ω_0 ≥ 2πT/√3（即对 k=1 已进入凹区）。固定 λ>0 与 ⟨ω⟩。则
$$\mathfrak{k}(P,T) \le h(\langle \omega \rangle / 2\pi T).$$
等价地：在支撑下界 ω_0 ≥ 2πT/√3 条件下，单频谱 δ_{⟨ω⟩} 使 T_c 最大。

**证明.** 对每个 k≥1，φ_k 在 [ω_0, ∞) 上凹当 ω_0 ≥ k·2πT/√3。因 ω_0 ≥ 2πT/√3 > k·2πT/√3（对 k≥2）不成立，需要逐 k 检验：
- k=1：ω_0 ≥ 2πT/√3 ⟹ φ_1 在支撑上凹。
- k≥2：需 ω_0 ≥ k·2πT/√3，即 ω_0/(2πT) ≥ k/√3。

**修正的陈述**：若 P 支撑于 [ω_0,∞)，ω_0/(2πT) ≥ K/√3（K 为感兴趣的最大 k 截断），则对前 K 个 Matsubara 频率有 F_T(k) ≤ ⟨x⟩/(k²+⟨x⟩)（k≤K）。但引理 M 需要**全部** k 的不等式。

**结论（诚实）**：固定 ⟨ω⟩ 的全局命题**失败**（另一 agent 已确认 p=1 全局失败）。但在**弱耦合/大 ϖ 区**（ϖ_0 := ω_0/2πT ≫ 1），若 P 支撑满足 ϖ_0 ≥ 2/√3 ≈ 1.15，则对 k=1 有 Jensen 成立，得到部分结果：
$$F_T(1) \le \langle \varpi \rangle.$$
配合 𝔨 ≥ F_T(1)（𝒪[F] 的 (0,0) 元下界），这给出 T_c 的**下界**而非上界，方向错误。

**最终形式（可证的弱化版）**：在大 ϖ_0 且 P 几乎集中时，h(⟨ϖ⟩) 可作为 𝔨 的近似，但无严格不等式。

**文献定位.** Combescot, PRB 42, 7810 (1990) 在 λ→0 时给出固定 ω_log 的结果；固定 ⟨ω⟩ 在 λ→0 亦可能成立，但有限 λ 下因凹性区间不足而失败。

**数值验证.** 放弃全局命题。改为验证：取 ϖ_0=3（>2/√3），P 为支撑于 [3,10] 的两原子谱，计算 𝔨(P,1) 与 h(⟨ϖ⟩) 的比值，观察是否有系统性偏离（预期：比值可 >1，即不成立上界）。

## 3. 命题 3：固定 λ 与 ω_log（Combescot 约束的有限-λ 版）

**背景.** 对数矩 ω_log := exp(∫ln ω P(dω))（几何平均）。变量替换 y = ln ω，φ_k 作为 y 的函数：
$$\phi_k(e^y) = \frac{e^{2y}/(2\pi T)^2}{k^2 + e^{2y}/(2\pi T)^2} = \frac{1}{1 + k^2(2\pi T)^2 e^{-2y}}.$$
令 z = e^{-2y}，φ̃_k(z) = 1/(1+k²(2πT)²z)，对 z 二阶导：
$$\phĩ_k''(z) = \frac{2k^4(2\pi T)^4}{(1+k^2(2\pi T)^2 z)^3} > 0,$$
即 φ̃_k 关于 z 凸 ⟹ 关于 y=−(1/2)ln z **凹**（需要 z 大，即 y 大，即 ω 大）。

**更精确的分析**：φ_k(e^y) 关于 y 的二阶导数（直接计算）：设 u := e^y/(2πT)，
$$\frac{d^2}{dy^2}\left[\frac{u^2}{k^2+u^2}\right] = \frac{d}{dy}\left[\frac{2u^3}{(k^2+u^2)^2}\right] = \frac{2u^2(u^2(k^2+u^2) - 2u^4)}{(k^2+u^2)^3} = \frac{2k^2u^2(k^2-u^2)}{(k^2+u^2)^3}.$$
凹性条件：k²−u² ≥ 0，即 u ≤ k，即 ω ≤ k·2πT。这给出**错误方向**（小 ω）。

**订正**：变量替换到 y 后，凹性分析复杂。Combescot 1990 的结果在 λ→0 时成立，可能依赖 h(ϖ)→ln ϖ + c 的渐近形式，不能直接用核级 Jensen。

**结论**：命题 3 需要更细致的渐近分析或不同的变分论证，超出核级 Jensen 的直接应用范围。**搁置**，标记为「需要不同方法」。

## 4. 命题 4：固定面积 A=λ⟨ω⟩/2（Leavens–Carbotte 约束）

**设定.** 固定 A := ∫α²F(ω)dω = (λ/2)∫ω·α²F(ω)/ω dω = (λ/2)⟨ω⟩。注意这里 λ **不固定**（与命题 1、2 不同）。

T_c 判据：λ𝔨(P,T) = 1，其中 𝔨(P,T) = λ₁(𝒪[F_T])，F_T(k) = ∫φ_k(ω)P(dω)，P(dω) = α²F(ω)dω（未归一化测度）。

**改写**：定义归一化测度 P̃ := P/∫P = P/A，则 ⟨ω⟩_{P̃} = ∫ω P̃ = (1/A)∫ω P = (λ/2A)·(2A/λ) = (∫ω P)/A。因 ∫P=A 固定，问题变为：固定 A，最大化 T_c，等价于最大化 λ𝔨。

**参数化**：设 P = A·δ_{ω_0}（集中在单频），则 λ = 2A/ω_0（由 A=(λ/2)⟨ω⟩），𝔨 = h(ω_0/2πT_c)。判据：
$$(2A/\omega_0) h(\omega_0/2\pi T_c) = 1 \quad \Rightarrow \quad T_c = \frac{\omega_0}{2\pi h^{-1}(\omega_0/(2A))}.$$
最大化 T_c 等价于最大化 ω_0/(2πh^{-1}(ω_0/(2A)))。

**使用推论 (ii)**：r(ϖ) := h(ϖ)/ϖ² 严格递减 ⟹ h(ϖ)/ϖ = ϖ·r(ϖ) 的单调性？需要分析 d/dϖ[ϖ·r(ϖ)] = r(ϖ) + ϖ·r′(ϖ)。因 r 递减（r′<0），当 |ϖ·r′(ϖ)| < r(ϖ) 时递增。

**数值探索策略**：
1. 取固定 A（如 A=1），在网格 ω_0 ∈ [0.1, 20] 上计算对应的 λ=2A/ω_0 与 T_c（求解 λh(ϖ_c)=1）。
2. 找到最优 ω_0\*，检验是否满足某个闭式条件（如 h′(ϖ\*)·ϖ\* = h(ϖ\*)，即驻点条件）。
3. 与随机分布的 α²F（固定 ∫α²F=A）比较，验证单频是否总是最优。

**结论（待数值确认）**：预期单频谱在固定 A 下使 T_c 最大，但最优频率 ω_0\* 需要数值求解；可能依赖 h 的凹性（引理 C）或单调性（推论 (ii)）。

## 5. 命题 5：各向异性压缩定理（Allen–Dynes 1975 folklore）

**陈述.** 线性化各向异性 Eliashberg 算子 A_aniso 作用在 L²(FS, dk) ⊗ ℓ²（费米面 × Matsubara），矩阵元：
$$(A_{\text{aniso}})_{n,\mathbf{k};m,\mathbf{k}'} = -Z_{nm}(\mathbf{k})\delta_{\mathbf{k}\mathbf{k}'} + \langle \text{配对核} \rangle_{nm}(\mathbf{k},\mathbf{k}'),$$
其中 Z 项（重整化）含 λ_{kk′} = ⟨⟨α²F⟩⟩_{kk′}，配对核含同样的权重。

各向同性算子 A_iso 是 A_aniso 向「k 上常函数」子空间 H_0 := span{v(k)≡const} 的**正交投影压缩**：
$$A_{\text{iso}} = P_{H_0} A_{\text{aniso}} P_{H_0},$$
其中 P_{H_0} v = ⟨v⟩_{FS}·𝟙（费米面加权平均），λ_k = ⟨λ_{kk′}⟩_{k′}（对 k′ 平均），λ = ⟨⟨λ⟩⟩（双平均）。

**关键引理**：对自伴算子 A 与正交投影 P，有 λ₁(PAP) ≤ λ₁(A)（Poincaré 分离定理 / 谱压缩）。

**证明**：
$$\lambda_1(A_{\text{iso}}) = \lambda_1(P A_{\text{aniso}} P) \le \lambda_1(A_{\text{aniso}}).$$
等价地：在同一 α²F_{kk′} 双平均后的判据 λ𝔨_iso(⟨⟨α²F⟩⟩, T) = 1 比各向异性判据 λ₁(A_aniso)=1 **更严格**（各向同性假设高估了稳定性），故
$$T_c^{\text{iso}} \le T_c^{\text{aniso}}.$$

**需要验证的细节**：
1. KAY 算子含 −Z 项（负号），需确认 A_aniso 的定义使得 λ₁(A) 对应超导不稳定性。
2. 费米面积分的权重：dk 是否归一化？压缩 P 的定义是否保持算子的自伴性？
3. 「同一 α²F 双平均」的精确含义：各向异性情形的 α²F_{kk′}(ω) 在双平均 ⟨⟨·⟩⟩_{kk′} 后给出各向同性的 α²F(ω)。

**数值验证（两片费米面玩具模型）**：
- 取 2×2 块结构，k∈{1,2}（两片费米面），n∈ℕ（Matsubara）。
- 设 λ_{11}=λ_1、λ_{22}=λ_2、λ_{12}=λ_{21}=λ_c（各向异性参数）。
- 各向同性算子用 λ=(λ_1+λ_2+2λ_c)/4（四个元素平均）。
- 比较 λ₁(A_aniso) 与 λ₁(A_iso)，改变 (λ_1−λ_2) 与 λ_c，验证 λ₁(PAP) ≤ λ₁(A) 且差随各向异性增大。

**文献定位.** Allen–Dynes 1975、Butler–Allen 1976 讨论各向异性对 T_c 的增强；Markowitz–Kadanoff 1963 的一般 folklore。本命题给出算子论证。
