## 2. 主命题（P4-A）

**命题 P4-A.** 设 P(dω) 为紧支概率测度，ϖ̄=⟨ω⟩/2πT，v_N(ϖ̄) 为 ℌ^(N)(ϖ̄) 的最大本征向量（Krein–Rutman 在正锥上单一）。则截断本征值有矩展开

  𝔨^(N)(P,T) = 𝔥^(N)(ϖ̄)·[ 1 + ½κ_N(ϖ̄)σ² + c_{3,N}(ϖ̄)γ₃σ³ + O(σ⁴) ]，　　(P4A.1)

其中

  κ_N(ϖ̄) = ϖ̄²·⟨v_N|ℌ^(N)′′(ϖ̄)|v_N⟩ / 𝔥^(N)(ϖ̄)，　　(P4A.2)
  c_{3,N}(ϖ̄) = (1/6)·ϖ̄³·⟨v_N|ℌ^(N)′′′(ϖ̄)|v_N⟩ / 𝔥^(N)(ϖ̄)，　　(P4A.3)

**只依赖 ϖ̄、N，与 P 的谱形族无关**（普适函数，但——与 P3 不同——是 ϖ̄ 的函数而非纯数，见 §3 结构判断）。**可证伪版**：若 κ_N 依赖 P 的四阶及以上矩（而非只 σ、γ₃、ϖ̄、N），命题为假。

**推导骨架**（严格性见 §4 待办）：
1. 矩阵值矩展开（逐元素 Taylor）：M(P):=∫ℌ^(N)(ϖ̄(1+ξ))P(dω) = ℌ^(N)(ϖ̄) + ½ϖ̄²ℌ^(N)′′(ϖ̄)σ² + (1/6)ϖ̄³ℌ^(N)′′′(ϖ̄)γ₃σ³ + O(σ⁴)。一阶项 ∝⟨ξ⟩=0 消失。
2. 最大本征值的一阶微扰（Hellmann–Feynman）：𝔨^(N)=λ_max(M) = 𝔥^(N)(ϖ̄) + ⟨v_N|δM|v_N⟩ + [二阶微扰]。δM 起于 O(σ²) ⟹ 二阶微扰是 O((δM)²)=O(σ⁴)，故 (P4A.1) 到 O(σ³) 由一阶微扰给全。
3. N=1 时 v₁ 平凡（标量），(P4A.2/3) 退化为纯 Taylor 系数——见 §3 锚点。

**KAY 已在用同一工具**：eq.(86) 用一阶微扰算 ∂𝔨^(N)/∂T²。接口现成。

## 3. N=1 锚点（手推完成，v0.1 的承重块）

N=1 核 h(ϖ):=𝔥^(1)(ϖ)=ϖ²/(ϖ²+1)=1−1/(ϖ²+1)。逐次求导：

- h′(ϖ) = 2ϖ/(ϖ²+1)²
- h′′(ϖ) = (2−6ϖ²)/(ϖ²+1)³
- h′′′(ϖ) = 24ϖ(ϖ²−1)/(ϖ²+1)⁴

代入 (P4A.2/3)（N=1，⟨v|·|v⟩→标量值）：

  **κ₁(ϖ̄) = ϖ̄²h′′/h = (2−6ϖ̄²)/(ϖ̄²+1)²**　　(P4A.4)
  **c_{3,1}(ϖ̄) = (1/6)ϖ̄³h′′′/h = 4ϖ̄²(ϖ̄²−1)/(ϖ̄²+1)³**　　(P4A.5)

即 𝔨^(1)(P,T) = [ϖ̄²/(ϖ̄²+1)]·[ 1 + ½·(2−6ϖ̄²)/(ϖ̄²+1)²·σ² + 4ϖ̄²(ϖ̄²−1)/(ϖ̄²+1)³·γ₃σ³ + O(σ⁴) ]。

**结构判断（P3→P4 的本质差别，必须前置声明）**：
- κ₁ 在 **ϖ̄=1/√3** 变号（宽谱在低 ϖ̄ 抬高 𝔨^(1)、高 ϖ̄ 压低）；c_{3,1} 在 ϖ̄=1 变号。**κ_N 是 ϖ̄ 的函数，不是 P3 那样的纯数 5.6035。**
- 原因：P3 的普适纯数来自在 g 核**极大处**展开（g′(x_max)=0，envelope 定理把鞍点位移推到 O(σ⁴)）；KAY 这边 𝔨^(N) 不含对 ϖ 的极大化，一阶项靠 ⟨ξ⟩=0（即 ⟨ω⟩ 的定义）消掉。**两者机制不同，κ_N(ϖ̄) 仍是良定义普适函数，只是形态是函数不是常数。**
- **不承诺「又一个纯数」**——survey §5(iv) 已预警，这里落定。

**与 P3 的对回校验**：N=1 的 P-平均结构与 Semenok 泛函 λ_*[P]=1/max_T∫g(ω/2πT)P(dω) 同型（都是标量核 P-平均）。差别只在：Semenok 在 T 上取极大（→纯数），KAY 的 𝔨^(1) 在固定 T 上直接平均（→ϖ̄ 函数）。若把 KAY 侧也在 T 上取极大（即沿 Tc 条件 𝔨=1/λ 求解），ϖ̄ 被自洽钉住——那一步把 ϖ̄ 函数塌回单值，是 §4 待办 (T3)。
