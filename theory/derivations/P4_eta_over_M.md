## 1. λ⟨ω²⟩ = η/M 在本文框架下的确切地位

这一节全部意义在于把三件事分开：哪一步是**定义**、哪一步是**恒等式**、哪一步是**近似（带误差）**。任务分派书正确地指出这是全篇最容易出错的地方——文献里的 McMillan–Hopfield 关系是 α²F 的二阶矩恒等式，而本文的 ⟨ω²⟩ 是抽象测度 P 的二阶矩，两者**先验地不是同一个东西**。

### 1.A 框架对接：P 是哪个测度（**定义级，非近似**）

本文（KAY II 形态）：P∈𝒫 是 ℝ₊ 上概率测度，F_T(k) = ∫⟦k⟧(ω/2πT)P(dω)，⟦k⟧(ϖ)=ϖ²/(k²+ϖ²)，Tc 判据 λ𝔨(P,T)=1。

物理（各向同性线性化 Eliashberg）：Allen–Dynes 1975 **Eq. (10)**（一手，见 §8）给 Matsubara 核

  λ(n) = 2∫dω α²F(ω)·ω/(ω² + (2πnT)²)。

取 **AD Eq. (5)** 的归一化权重（AD 逐字："the normalized weight function is g(ω) = (2/λω)α²F(ω)"）

  **P(dω) := 2α²F(ω)dω/(λω)**,　λ := 2∫dω α²F(ω)/ω　（**AD Eq. (3)**）,　　(1.1)

则 ∫P = 1（这正是 λ 的定义），且逐 k 精确地

  λ·F_T(k) = λ∫[ω²/(ω²+(2πTk)²)]P(dω) = 2∫dω α²F(ω)ω/(ω²+(2πTk)²) = λ(k)。　(1.2)

即**本文的 λF_T 就是 AD 的 λ(n)，逐项相等，无近似**。于是本文的二阶矩由 **AD Eq. (5)**（⟨ωⁿ⟩ = (2/λ)∫dω α²F(ω)ω^{n−1}）给出

  **⟨ω²⟩_𝒫 := ∫ω²P(dω) = (2/λ)∫dω ω α²F(ω) = ⟨ω²⟩_AD ≡ ω₂²。**　　(1.3)

> **这是本节的枢轴，也是唯一真正的"识别"步骤**：本文定理里的 ⟨ω²⟩ **是 Allen–Dynes 的 ω₂²**，不是声子 DOS 的二阶矩，也不是 ω_log²。三者数值不同（§4 表里 ω₂/ω_log = 1.075–1.194）。用错哪一个，界就不再是界——这是 `P4_tc_sandwich.md` §4 第 4 条已经付过学费的地方。

### 1.B 二阶矩恒等式（**恒等式级**）

由 (1.3) 直接

  **λ⟨ω²⟩ = 2∫₀^∞ dω ω α²F(ω) = 2 × (α²F 的一阶矩)。**　　(1.4)

注意左端是"耦合 × 频率平方"，右端是 α²F 的**一阶**矩——λ 的两个因子里各含一次 α²F 的 1/ω 权重，抵消后只剩一次 ω。这一步是纯算术。

### 1.C 第一矩的微观形式 = McMillan 1968 Eq. (22)（**一手**；在 (A2)(A3) 下为恒等式）

McMillan 1968（一手，p.334，我们已取到原文 PDF 并逐式核对）：

- **Eq. (19)**：α²F(ω) 的定义（FS 平均 + 声子求和 δ(ω−ω_qν)）；
- **Eq. (20)–(21)**：g_pp′ν = (ħ/2MNω_{p−p′ν})^{1/2}·𝒢_ν(p,p′)，其中 𝒢_ν(p,p′) = ∫ψ\*_{p+q}∇_ν𝒱ψ_p dr 是**纯电子的形变势矩阵元**；
- McMillan 原话（Eq. (22) 上方，逐字）："Note that g² is inversely proportional to the phonon energy ω_{p−p′ν}, so that **the first moment of α²F(ω) is independent of the phonon frequencies**"：
- **Eq. (22)**：∫₀^∞ dω ωα²F(ω) = **N(0)ħ⟨𝒢²⟩/(2M)**。

且 **Eq. (23)**（同页）：**λ ≡ 2∫dω′ α²F(ω′)/ω′ = N(0)⟨𝒢²⟩/(M⟨ω²⟩)**，其中 **Eq. (24)** 定义的 ⟨ω²⟩ = [∫dω ωα²F(ω)]/[∫dω α²F(ω)/ω]（≅ ∫F dω / ∫F dω/ω，后者是 McMillan 的 Debye 化近似）正是 (1.3) 的二阶矩——除以 λ 因子后与 AD Eq. (5)（n=2）逐字相同。

定义 **η := N(0)⟨𝒢²⟩ ≡ N(0)⟨I²⟩**（记号按 Hopfield 1969；"A McMillan–Hopfield parameter η (or N(0)⟨I²⟩)" 这一表述在 AD 1975 摘要中**一手出现**，且 AD Table III 的表头逐字是 "λM⟨ω²⟩ ≡ η (eV/Å²)"）。代入 (1.4)：

  **λ⟨ω²⟩ = 2∫ωα²F dω = η/M。**　　(1.5)

**地位认定**：(1.5) 是 α²F 定义 + Eq. (20) 因子化 + 求和的**重排恒等式**——给定 α²F，它与"声子软硬"无关地成立，没有任何被忽略的项。它的**物理解读**（"η 是电子量、可以谈它随不随 M 变"）才需要假设 (A2)(A3)。

### 1.D 假设清单

**(A1) 各向同性（FS 平均）Migdal–Eliashberg 框架。** 配对相互作用由 α²F 编码；(1.1)–(1.3) 的对接与定理 A、B 本身都在这个模型内。顶角修正、能带各向异性、多带效应不计入——界的"物理保真度"受此限（残余假设 U 系列同源，`P4_main_theorems.md` §5 第 4 条）。

**(A3) 谐波（或固定 BO 面上的准谐波）声子。** ω_j(M) = ω_j(M₀)·√(M₀/M)。等价地：g = (ħ/2Mω)^{1/2}I 的因子化在质量变动时仍把 M 全部吸进 1/√(Mω)。**在质量变动（同位素替换）下这是近似**，误差项见 (E1)。

**(A4) 单一有效质量 M。** 单原子种类时 (1.5) 的形式。多组分见 (A5)。

**(A5) 多组分分解。** 按物种分解形变势 I^{(a)}、声子本征矢分量 e_{aj}（质量加权归一 Σ_a|e_{aj}|²=1），对**完整模式集**求和后 Σ_j e_{aj}e_{bj} = δ_{ab} 消去交叉项，得

  **λ⟨ω²⟩ = Σ_a η_a/M_a**，　η_a := N(0)⟨|I^{(a)}|²⟩_{FS}。　　(1.6)

两点诚实标注：(i) **若只对物种纯的子模式集求和**（如只取 H 主导的高频模），交叉项 2√(η_aη_b)/√(M_aM_b) 不消——数值负控制显示单混合模式（|e_H|²=0.6）处漏掉的交叉项为 **+21%**（`p4_eta_over_M.py` Stage 1b）。(ii) 完全集版本的推导在本文档是重排，**未独立于 McMillan Eq. (19)–(24) 的框架重证**；物种分解的 η_a 在 DFT 文献中标准，本文未取得一手出处，**标为二手转引**。

**(A6) μ\* 的处理。** 上界的 μ\*-无关性在框架内是定理（推论 (v)：库仑束 K_c ⪰ 0，定理 1(c)/2 的界逐字成立）；μ\*>0 只把真实 T_c 压到更低。无需假设。

**(A7) SSCHA 有效声子。** 用非谐重整化（SSCHA）的 α²F 替代谐波 α²F 时，(A3) 失效到"η 漂移"的水平：界**仍然成立**（界只需要 ⟨ω²⟩ 的**实际**值），失效的是"η 与 M 无关"和"指数恰 ½"两句话的**解读**。数据上：H3S 的 λ 同位素漂移 1.84→1.87（H→D，+1.6%），PdH 0.40→0.46（+15%）——这就是 (E1) 的大小。

## 2. 两个定理版本

  **T_c(λ, P) < T̃_c = (√𝔤(2)/2π)·√(η/M)**，　√𝔤(2)/2π ∈ [0.182726247746, 0.182726247790]，

## 3. 同位素指数：界的 ½ 与真实 Tc 的 α 是两个对象

**这是本结果最容易被误读的地方。** 下面把两者的定义、各自的值、以及"为什么不矛盾"逐条写清。

### 3.A 界的同位素指数（定理，条件为 (A2)(A3)）

**命题 3.1（全同位素替换）.** 设全部核质量同比例 M_a → sM_a，且 η_a 不变（(A2)+(A3)）。则 η/M → (η/M)/s，故

  **α_bound := −d ln T̃_c/d ln M = ½，精确。**

*证*：T̃_c = C_∞√(η/M) ∝ M^{−1/2}。∎（数值确认：中心差分给 0.500000000070，三个步长；T̃(M)/T̃(2M) = 1.414213562373 = √2 到 1e−12，Stage 3。）

**命题 3.2（部分替换，实验实际做的）.** 只把物种 a 的质量 ×s（如 H→D），其余不变。则

  **α_a^bound = ½ · (η_a/M_a)/(Σ_b η_b/M_b) ∈ [0, ½]。**　　(3.1)

*证*：d ln(Σ_b η_b/M_b)/d ln M_a = −(η_a/M_a)/(Σ_b η_b/M_b)，再乘 ½。∎（数值确认：合成两组分谱上闭式与差分一致到 1e−8，Stage 3。）

即**界的部分同位素指数 = ½ × 该物种在 η/M 中的份额**。氢化物里 H 份额接近 1（M_La/M_H = 138，见 §5.1），故 α_H^bound ≈ ½；但这是**份额假设下的结论**，我们没有 η_a 的第一手位点分解数据，只有上估 η_H ≤ M_H·λ⟨ω²⟩（§4 表末列）。

**(A3) 失效时**：α_bound = ½ − ½·d ln η/d ln M（由 (E1)）。SSCHA PdH 实测 d ln η/d ln M = ln(1.296)/ln 2 = 0.374 ⟹ α_bound = 0.313，**不是 ½**。

### 3.B 真实 Tc 的同位素指数（P1 的对象，不是本文的）

### 3.C 为什么两者不矛盾——以及为什么必须分开说

**结构性原因**：T_c = T̃_c · ρ，ρ := T_c/T̃_c ∈ (0,1) 是"可达度"。取对数微分

  **α_true = α_bound − d ln ρ/d ln M。**　　(3.2)

α_bound 是**天花板的指数**；ρ 的质量依赖来自 μ\*(ω_c(M))、谱形（⟨ω²⟩ 之外的**全部**高阶矩）、以及非谐对 λ 的重整。(3.2) 对 d ln ρ/d ln M 的符号**无任何约束**，所以：

- α_true > ½ 不与本定理矛盾（LaH10 实验 0.57–0.71）：天花板按 M^{−1/2} 落，真实 Tc 落得**更快**（ρ 随 M 降）。
- α_true < 0 不与本定理矛盾（PdH −0.29～−0.38）：真实 Tc **升**而天花板落，ρ 升得比天花板落得快。PdH 处天花板高出真实值 13 倍（67.3 K vs 5.0 K），有充足的"空间"让 ρ 这样动。

**PdH 的实算对照（Stage 3，一手 SSCHA 数据，ω_log 代 ω₂ 已标注）**：

```
ceiling : eta/M = 1008.4 -> 653.4 meV^2,  alpha_bound = +0.313  (天花板下降，H->D)
true Tc : 5.0 K -> 6.5 K,                 alpha_true  = -0.379  (真实 Tc 上升，H->D)
```

**两者反号。** 这是"不可混淆"最锋利的例子：任何把 α_bound = ½ 当作"本理论预测同位素指数为 ½"的读法，都会在 PdH 上被数据直接否证——而本定理在 PdH 上**完全没有被违反**（5.0 与 6.5 K 都远在 67.3 / 54.2 K 的天花板之下）。

**一句可签名的措辞**：本定理约束的是 **T_c 的上界如何随 M 变**，不是 **T_c 如何随 M 变**。前者指数在 (A2)(A3) 下恰为 ½；后者是 P1 的四因子问题，实测跨越 −0.38 到 +0.71。

## 5. 物理讨论：为什么是氢

### 5.1 机制：η 不随 M 变，而 M 可以小到 1

界 = C_∞√(η/M)。两个旋钮：η（电子结构）与 M（核质量）。McMillan Eq. (22) 的那句原话——**α²F 的一阶矩与声子频率无关**——正是"η 与 M 无关"的出处：η 只由 N(0) 与形变势 ⟨I²⟩ 决定，两者在 BO 下与核质量**精确**无关 (A2)。于是在**同样的 η** 下，天花板 ∝ M^{−1/2}：

| 元素 | M/amu | 同 η 下天花板相对 H |
|---|---:|---:|
| H | 1.008 | 1.000 |
| C | 12.011 | 0.290（H 高 3.45×） |
| N | 14.007 | 0.268（H 高 3.73×） |
| O | 15.999 | 0.251（H 高 3.98×） |
| S | 32.06 | 0.177（H 高 5.64×） |
| Y | 88.906 | 0.107（H 高 9.39×） |
| Pd | 106.42 | 0.097（H 高 10.3×） |
| La | 138.905 | 0.085（H 高 11.7×） |

**注意这不是"氢化物必然 Tc 高"**——η 本身逐材料不同，上表是"固定 η"的对照，而 η 恰恰是电子结构量、不同材料差几倍（AD Table IV：1.2–7.9 eV/Å²）。真正稳健的陈述是**多组分版本 (1.6)**：λ⟨ω²⟩ = Σ_a η_a/M_a 里，重原子那一项被 1/M_a **压制**，所以在含 H 的化合物中，即便 η_La ≈ η_H，La 通道的贡献也只有 H 通道的 1/138。氢**几乎必然主导 η/M**——不是因为它的 η 大，而是因为除以的 M 小。这就是"why hydrogen"在本框架内的确切形式，并且它**不依赖任何可调参数**。

**并且这解释了软化悖论为何是假问题**：把晶格软化（ω₂↓）会抬高 λ（λ = η/(M⟨ω²⟩)），但 λ⟨ω²⟩ 不变，天花板**一动不动**。想抬天花板只有两条路：**增大 η**（更强的形变势/更高的 N(0)）或**减小 M**（用氢，已经到底）。"靠软化拿高 Tc"在 ceiling 层面是不可能的。

### 5.2 紧度：界比现实高多少

- LaH10（唯一有真 ω₂ 的体系）：界 A 高出 SSCHA 理论 **1.44–1.78×**，界 B 高出 **1.28–1.41×**。
- PdH（λ=0.40）：界 A 高出 **13×**，界 B 高出 **2.7×**——**弱耦合区界 A 几乎无信息量**，因为 C_∞ 是 λ→∞ 常数（G(0.40)/C_∞ = 0.203）。用界 A 谈弱耦合材料是滥用。
- 差距的来源分三份：(i) μ\*=0（文献 Tc 用 μ\*=0.085–0.16）；(ii) λ 有限（界 A 的 C_∞ vs 界 B 的 G(λ)，在 λ≈2–3 处占 10–20%）；(iii) 谱形（定理 2：非 Einstein 谱只降不升，实际氢化物 r=1.07–1.19 离 Einstein δ 不远，所以这一份小）。

三条可引用的结论：
1. **H3S 在 200 GPa 无法裁决**：ω_log 下估给 15866 meV²，但这只是**界的下估**，不是真界，所以它低于 20016 meV² 这件事**不支持任何排除**（§4.A：带 \* 的行不能产生「否」）。可引用的是等价的 r 判据——H3S 的 300 K 越线门槛等价于 **r ≥ 1.123**，而这落在 LaH10 经验区间 [1.075, 1.194] **之内**，**因此无法裁决**；要有约束力的结论（无论排除还是越线），需要 H3S 的实测 ω₂（见 §4.C）。
2. **LaH10 的 η/M 足够**：它在 λ ≥ **2.19** 时 B 级天花板越过 300 K，而实际 λ=2.67（余量 1.037）。所以 LaH10 距室温的差额（242.8 K vs 300 K）**不在 η/M**，而在可达度 ρ——即 μ\*、谱形与非谐稳定性。这把"如何把 LaH10 推到室温"的问题从"找更大 η/M"改写为"提高 ρ"。
3. **PdH 类（λ<1、无氢主导的高频谱）在经验范围内不是候选**：其 η/M 低 20 倍，A 级 300 K 门槛需要 **r = ω₂/ω_log ≥ 4.456**（B 级需 r ≥ 21.52），对比 LaH10 的经验 r ≈ 1.07–1.19 差了近 4 倍（B 级近 20 倍）。**因此在经验范围内不是候选（r 无先验上界，故此结论仅经验性、不是定理）。**

### 5.4 诚实说明：这是上界

- 上界**不保证可达**。达到 C_∞ 需要 λ→∞ **且** Einstein 谱；达到 G(λ) 需要 Einstein 谱（定理 2 的等号仅在点质量取到）。真实谱有宽度，μ\* > 0。
- 反向不成立：**η/M 大不蕴含 Tc 高**。η/M 只给天花板。
- 唯一严格的**逆命题**方向：**η/M 小 ⟹ Tc 一定低**（框架内 (A1)–(A4) 下严格）。这是本定理最有用的用法：**筛掉**候选材料，而不是预测赢家。**但它要的是真的 η/M**：带 \* 的行只有 η/M 的下估（ω_log 代 ω₂），下估小**不蕴含**真值小，所以这个逆命题**不能施加到 §5.3 结论 1（H3S）上**——那一行只能给出 r 阈值。§5.3 结论 3（PdH）保留，因为它已改用 r 判据陈述（且明示为经验性）。

1. **上界，不是预测，不保证可达。** 达到界 A 需要 λ→∞ **且** Einstein 谱；达到界 B（每个 λ 都被 Einstein 谱精确达到）仍需要点质量谱。真实氢化物（r=1.07–1.19）离 δ 谱不远，但 μ\*>0 与非谐稳定性是真实的压低渠道。界 B/Tc_theory = 1.28–1.41×（LaH10）是"框架内可达性差距"的量化。
