## 2. 核心约化：矩量级数（本文的机器）

**关键代数（精确，非渐近）。** 置 **K := M + I = 𝓡 + (I − 𝒟)**。则 hI − M = (h+1)I − K，故

> **(A1)　F(h) = 2⟨τ,(hI−M)⁻¹τ⟩ = 2⟨τ,((h+1)I − K)⁻¹τ⟩。**

对 y := h+1 > ‖K‖（大 ϖ 时 y ~ L ≫ ‖K‖ ≤ Θ*+1 ≈ 1.63）做 Neumann 展开，记 **矩量 κ_j := ⟨τ,Kʲτ⟩**（κ_0 = B）：

> **(A2)　F(h) = (2/y) Σ_{j≥0} κ_j/yʲ = 1　⟺　y = 2B + 2 Σ_{j≥1} κ_j/yʲ。**

代入 2B = L + C、y = h+1 = (L+c₀+δ)+1 = L + C + δ（这里 δ := h−(2B−1) = y − 2B），两边的 **2B = L+C 精确相消**：

> **(A3)　δ = 2 Σ_{j≥1} κ_j/yʲ,　y = L + C + δ。**

这是全文的引擎。它比定理 W′ 的 F_k 记法干净：**"+1" 的移位把 𝒟 的主对角（≈I）吸收进 K，令唯一发散的矩量只剩 κ_0 = B。**

**矩量的增长结构（决定一切）。** 写 K = 𝓡 + 𝒩、𝒩 := I−𝒟。由 (SR)，

  (Kτ)_n → p_n·[Υ_G(s_n) + d(s_n)G(s_n)]　（标度像，记作 p_n·Φ_K(s)，Φ_K := Υ_G + dG）。

因为 Φ_K(s) 在 s→0 是 O(s²)（Υ_G ~ (11/12)s²、dG ~ s²/3、Φ_K ~ (5/4)s²）、在 s→∞ 是 O(1/s²)，**Kτ 是 ℓ² 的（范数收敛）**。于是对 j ≥ 1，

> **(A4)　κ_j = ⟨τ,Kʲτ⟩ → κ_j^∞（有限，无 γ 的标度周期）；只有 κ_0 = B ~ L/2 发散。**

（证：κ_j = ⟨τ,Kʲτ⟩，对 j≥2 写成 ⟨Kτ,K^{j−2}(Kτ)⟩，Kτ∈ℓ²、K 有界 ⟹ 有限；j=1 时 κ_1 = ⟨τ,Kτ⟩ = ⟨τ,𝓡τ⟩+⟨τ,𝒩τ⟩ → (r₁+a₁)/2 = b₁/2，收敛因被积函数 GΦ_K/s ~ s 在 0 处、~1/s⁵ 在 ∞ 处。κ_j^∞ 是收敛积分，**无格点缺陷 ⟹ 无 γ**，见 §5。）

**κ_j^∞ 的显式标度积分。** 由 (SR)：

  **κ_1^∞ = ½∫₀^∞ G(s)Φ_K(s) ds/s,　κ_2^∞ = ½∫₀^∞ Φ_K(s)² ds/s,**

## 6. 结构引理（订正版）：周期类的加权分级，与 γ 的真实去向

### 6.1 出现的积分类

κ_n^∞ = ⟨G, K_op^n G⟩_{dm}（dm = ds/(2s)）是 (n+1)-重积分，因子取自 {R(s,σ), d(s), G(s)}——都是 **{有理函数}×{arctan(·), ln(1+·²)}** 类。这类在 (0,∞) 上对 ds/s 积出的常数是 **mixed Tate / 多重对数型 period**。

### 6.2 加权分级引理（这是 b₁ 为何在 ℚ[π²]、b₂ 为何不在的真正原因）

> **引理（weight grading）。** 记 wt 为超越权（ds/s 与 arctan、ln 各权 1，有理函数权 0）。则
> **(i)** K_op 把权抬高 1：wt(K_op^n G) = n（G 权 0；每作用一次 K_op = 积分 ⟨R,·⟩dm 或乘 d(s)，权 +1）。
> **(ii)** 故 **κ_n^∞ = ⟨G, K_op^n G⟩_{dm} 是 weight (n+1) 的 period**（外层再积一次 ds/s）。
> **(iii)** ℚ[π²] = span_ℚ{1, π², π⁴, …} 只含**偶权**（π 的偶次幂）。所以：
>   - n=1：κ₁^∞ weight 2 → 可落在 ℚ[π²]（且确实 = b₁/2 ∈ℚ[π²]）；
>   - n=2：κ₂^∞ weight 3（奇权）→ **绝不可能** ∈ ℚ[π²]（除非奇权部分为 0，但 κ₂^∞ = ½‖Kτ‖²_{dm} > 0 且数值证其非平凡）；
>   - n=3：κ₃^∞ weight 4（偶权）→ **可能**含 π⁴，但也含 ζ(3)ln2 等非 π-幂 weight-4 常数，**一般仍不在** ℚ[π²]。

**数值印证 (iii)**：β₃ := 2κ₃^∞ = 0.1414960（weight 4）在 {1,π²,π⁴} 下 PSLQ = **None**（`pi2_tower_lean.py`）。

### 6.3 γ 的真实去向：自然变量是 Λ = 2B，不是 ln ϖ

用 **Λ := 2B = ln ϖ + C** 展开（而非裸 ln ϖ）：由 (A3)，y = Λ + δ、δ = 2Σκ_j/yʲ，逐阶（自洽只在 1/Λ³ 才回插）：

> **δ = 2κ₁/Λ + 2κ₂/Λ² + (2κ₃ − 4κ₁²)/Λ³ + …**,　即 **β_n^Λ = 2κ_n^∞ + (自洽多项式)**。

这些 β_n^Λ **无 γ**（全由 κ_j^∞ 构成）。于是原猜想中"**γ 只经 c₀ 进入**"这句话的**正确版本成立**：全部 ϖ-依赖除 2B 外都走无-γ 的标度周期 κ_j^∞；把 γ 收进 Λ=2B（等价地 c₀）后，展开系数不含 γ。

**物理 T_c 系数（h↔T_c 翻译，与 W″ 交叉核对）**：物理量是 T_c(λ) 的弱耦合展开，其 λ² 系数不是 b₂ 本身。由 h = L + c₀ + b₁/L + b₂/L² + … 与 λ=1/h、1/λ = L + c₀ + b₁/L + … 反演，λ² 项系数 = **b₁c₀ + b₁²/2 + b₂**。代入 c₀ = C−1、b₂ = 2κ₂−b₁C，得 **b₁c₀ + b₁²/2 + b₂ = 2κ₂^∞ − b₁ + b₁²/2**（**γ 与 ln4 精确相消**，数值 = −0.0967183971293895，已验，`pi2_tower_tc.py`，恒等式差 3e-52）。要点：**物理系数天然无 γ/ln4**，其"是否 ∈ ℚ[π²]"**不再依赖** γ∉ℚ[π²] 的开问题——因为 b₁,b₁²/2 ∈ ℚ[π²]，唯一障碍就是 2κ₂^∞ 的 **weight-3** 越界（比 b₂ 的判决更干净：纯 weight 障碍，无 γ 条件性）。此项归 w2 分支 `worktree-agent-ac2ddd8a83db416b2` 的 W″ 记录。

**但 b_n（1/lnϖ 系数）≠ β_n^Λ**：由 1/Λⁿ = 1/(L+C)ⁿ 再展成 1/L，C^k（含 γ）被拉下来污染 b_n（n≥2）。且即便在 Λ 变量里，β_n^Λ 的**加权分级**（§6.2）也把 ℚ[π²] 限死在 n=1。

**主导增长与"平凡重求和"**：b_n 的主导项来自 C^{n−1} 系数，b_n ~ b₁(−C)^{n−1}（因 b₁/(L+C) 展开即给此几何增长）。所以 1/lnϖ 级数系数**几何增长**（比 ~C≈1.46），其"重求和"不过是**换回变量 Λ**——见 §7。

## 7. 共振（resurgence）角度：这条塔是收敛的，不是可复活的

**(a) 微扰级数收敛。** κ_j^∞（j≥1）是有界自伴算子 K 在（可归一化）态 Kτ 上的谱矩量：κ_j^∞ = ∫ρʲ⁻²dμ_{Kτ}(ρ)（j≥2），dμ 支撑于 [−‖K‖,‖K‖]、‖K‖ ≤ Θ*+1 ≈ 1.635。故 κ_j^∞ ≤ ‖Kτ‖²·ρ_eff^{j−2}（ρ_eff := μ_{Kτ} 支撑的上端 ≤ ‖K‖）**几何衰减**。于是 (A3) 的 Λ-级数 δ = Σ2κ_j/Λʲ **收敛**（半径 Λ > ρ_eff），**无阶乘发散、无 Borel 平面奇点**——是"平凡可 Borel 求和"。数值佐证：κ₁:κ₂:κ₃ = 0.1792 : 0.0987 : 0.0707，相邻比 0.551、0.717（单调上升、趋于 ρ_eff，仍 < ‖K‖）。

**(b) 1/lnϖ 级数也收敛**，但系数几何增长（比 ~C≈1.46，§6.3），半径 ~1/C（收敛于 L > O(1)，即 ϖ ≳ e^C ≈ 4.3）。其"奇点"是把 y 拉到谱边缘 ρ* 处的隐函数分支点，位于 L 平面 O(1) 负值——物理区 L≫1 内无害。**唯一需要的"重求和"就是变量替换 lnϖ → Λ = 2B。**

**(c) 真正的非微扰内容 = ϖ^{−2} 跨级数。** 微扰级数的"beyond-all-orders"是有限-ϖ 的**格点↔积分缺陷**：κ_j(ϖ) − κ_j^∞ = O(ϖ^{−2})、2B − (L+C) = O(ϖ^{−2})（引理 B1 的 O(1/ϖ²)、O(lnϖ/ϖ²) 余项）。以 g := 1/L 为微扰参数，这些是 e^{−2L} = ϖ^{−2} 的指数小项——即**作用量 2 的单"瞬子"扇区**。所以完整的 trans-series 结构是

  δ(L) = [收敛 1/L 级数] + ϖ^{−2}·[另一收敛级数] + O(ϖ^{−4})。

**(d) 重构 T_c 的"闭式"** 不是某个初等函数，而是**标度谱条件本身**：

  **λ = 1/h,　2⟨τ,((h+1)I − K)⁻¹τ⟩ = 1**　（ϖ→∞ 标度极限；有限 ϖ 加 ϖ^{−2} 修正）。

等价地 T_c 由 y=h+1 满足 ⟨τ,(yI−K)⁻¹τ⟩ = y/2 决定。这是一个谱/Stieltjes-变换方程，是该塔的"非微扰母函数"。**没有更简的封闭初等重构**：K 的谱是连续的，h 是超越方程的根。

## 8. 主障碍、可行性判决、建议的第一步

**主障碍。** 原猜想（b_n ∈ ℚ[π²]）在 n=2 被**强证据否定**（refuted by strong evidence，**非严格证伪**）：b₂ = −0.327071… 的 60 位 PSLQ 在 {1,π²,π⁴} 落空，机制是 −b₁C 的 γ 与 κ₂^∞ 的 weight-3 双重越界。严格性边界要说清：κ₂^∞ 是显式 period（被积函数只含 arctan/ln/有理，故无 γ），于是 b₂ = 2κ₂^∞ − b₁ln4 + b₁/2 − b₁γ；若 b₂ ∈ ℚ[π²]，则 b₁γ = （γ-free period）∈ ℚ[π²]-可及的量，即会出现一条把 γ 系于 weight≤3 period 的 ℚ[π²]-线性关系——这与"γ ∉ ℚ[π²]"（未证的标准开问题）相悖。故可确证的判决是**条件性的**：**在 γ ∉ ℚ[π²] 成立下 b₂ ∉ ℚ[π²]**，且 60 位数值 + weight 分级给出强独立佐证。实践结论不变："把整条塔证成 ℚ[π²]"的方向被否定，不应再投入。

**能保留、值得做的正确命题（按价值排序）：**

1. **[高价值、可证]** 定理"**γ 只经 2B 进入**"：即 (A3) 的约化 δ = 2Σκ_j/yʲ 中 κ_j^∞（j≥1）严格无 γ。这把原猜想中**对的那一半**变成定理，且顺带把定理 W′ 的 b_n 提升为**任意阶可计算**（b_n 是 {κ_1^∞,…,κ_n^∞, C} 的显式多项式，§4.1）。第一步：把 §2 的 (A1)–(A4) 写成带余项界的引理（κ_j(ϖ)−κ_j^∞ = O(ϖ^{−2}) 的证明照抄引理 B1 的 midpoint-Peano 论证到 Kʲτ 的标度像；难点仅在 K_op^{j} 的核光滑性与远场衰减，已在 §2 验明 j=1,2）。

2. **[高价值、可证]** **收敛性 + trans-series 定理**（§7）：证 δ 的 1/Λ 级数收敛（谱矩量几何界），并给 ϖ^{−2} 跨级数首项。这把"weak-coupling T_c 展开"从"渐近级数"升级为"收敛级数 + 显式非微扰尾"，是干净的可发表结论。第一步：定出 K_op 的谱半径 ρ*（顶谱），给出收敛半径。

3. **[中价值]** κ₂^∞、κ₃^∞ 的闭式（weight-3/4 period）。虽不入 ℚ[π²]，但认出它们（沿 b₁ §3.3 的 Li₂ 路线抬到 Li₃/Li₄ + ln2,ln3）能给 b₂,b₃ 精确闭式，完成"三项 → 五项"渐近。风险：weight-3 常数域大（含 ln3、可能 ζ(3)、Li₃(−2/−3) 型），PSLQ 需 dps≳80 与几十元基；这是**一个独立的多重对数项目**，不建议现在做。

**推荐的第一步（single）**：把 §2 的矩量约化 (A1)–(A4) + §4.1 的 b_n 显式多项式 + §3 的 κ₁=b₁/2 数值，落成 `P4_weak_coupling_series.md` 的一节"定理 W″（矩量塔）"，**明确记录 b₂ ∉ ℚ[π²] 的判决**并订正/收回原 π²-塔猜想。这一步无新硬计算、纯整理，且立刻堵住一个错误方向。

## 9. 诚实边界

1. **b₂ 值的地位**：κ₂^∞ = 0.09873042407… 是 mpmath 一维数值积分（dps=70，被积函数 (E4) 闭式），非区间包围；b₂ = −0.327071… 由此 + 精确 b₁,C 得出。独立的操作子拟合 −0.3276 是 float64 ARPACK + 三参数外推，仅 ~3 位可信——两者一致到外推精度即为交叉验证，**不主张 b₂ 的更多有效位**（若要 15+ 位，需把 κ₂^∞ 的闭式做出来，见 §8.3）。
2. **"κ_j^∞ 无 γ"** 用到"收敛 period 不含 γ"。严格版依赖 γ 非 period（未证的标准信念）。§5 的 60 位 PSLQ（b₂ 不在 {1,π²,π⁴}）是**不依赖该信念的强数值证据**，但 PSLQ 落空只在给定精度/系数范数界内排除关系，属**证据级**、非严格不可判定性证明；因此本文一律用"强证据否定"而非"证伪"。
3. **加权分级引理 §6.2** 的 wt 计数是启发式的超越权论证（对 mixed-Tate period 严格；此处被积函数确在该类内），据此断"奇权 ∉ ℚ[π²]"是可靠的必要条件；κ₂^∞ 奇权部分非零由 ½‖Kτ‖²>0 + 数值 PSLQ 落空共同支撑。
