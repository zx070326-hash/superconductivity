# P4 · 矩阈值定理（p-矩极值与 p<2 反例）

建立：2026-09-13　状态：v0.1（定理 2′ 解析证明 + 命题 2″ 反例构造 + 数值门，零计算机辅助）

## 0. 动机与陈述

定理 2 使用 2-矩（⟨ω²⟩）建立 Einstein 极值。自然的问题：能否换成更一般的 p-矩？

**定理 2′（p-矩阈值，p ≥ 2）.** 设 p ≥ 2。对所有 P∈𝒫（P≠δ₀，⟨ω^p⟩<∞）与 T>0：

  **𝔨(P,T) ≤ h(ϖ_p)**，　ϖ_p := ⟨ω^p⟩^(1/p) / 2πT，

等号 ⟺ P 为点质量。

**命题 2″（p<2 时定理为假）.** 对每个 p∈(0,2)，存在 P 使 𝔨(P,T) > h(ϖ_p)。

**推论.** ϖ_p 随 p 递增（Lyapunov 不等式），故 **p=2 是该界族内最紧的**。

## 1. 证明

### 1.A 定理 2′ 的证明（与定理 2 同构）

记 x := ϖ² = (ω/2πT)²。对固定 k，核函数 φ_k: ω ↦ x/(k²+x) 在 [0,∞) 上严格凹增（φ_k″ = −2k⁴(k²+3x)/(k²+x)⁴ < 0）。

设 p ≥ 2。令变换 t = ω^p（t∈[0,∞)），则 x = t^(2/p)。**关键引理**：t ↦ t^(2/p) 在 p ≥ 2 时于 [0,∞) 上凹（因 2/p ≤ 1）。

由**凹函数的复合律**：凹增 ∘ 凹 = 凹，故
  Φ_k(t) := φ_k(t^(1/p)) = t^(2/p)/(k² + t^(2/p))
关于 t 在 [0,∞) 上凹。应用 Jensen 不等式：

  F_T(k) = ∫ φ_k(ω) P(dω) = ∫ Φ_k(ω^p) P(dω) ≤ Φ_k(⟨ω^p⟩) = ⟨ω^p⟩^(2/p)/(k² + ⟨ω^p⟩^(2/p)) = ⟦k⟧(ϖ_p)。

严格性：Φ_k 严格凹 ⟹ 等号 ⟺ ω^p 为 P-a.s. 常值 ⟺ P 为点质量。

现 F_T 满足**引理 M** 的三个假设（`P4_main_theorems.md` §1）：
  (i) F_T 非增（核 x/(k²+x) 关于 k 递减）、Σ_k F_T(k) < ∞（因 F_T(k) ≤ ⟨x⟩/k²）、F_T ≢ 0（P≠δ₀ ⟹ F_T(1)>0）；
  (ii) G(k) := ⟦k⟧(ϖ_p) ∈ ℓ¹（因 ⟦k⟧ ≤ ϖ_p²/k² 且 Σ 1/k² < ∞）；
  (iii) F_T ≤ G 逐点（上面已证）。

由**引理 M**：𝔨(P,T) = λ₁(𝒪[F_T]) ≤ λ₁(𝒪[G]) = h(ϖ_p)。严格性由 G(1) > F_T(1)（当 P 非点质量时）。∎

### 1.B 命题 2″ 的反例构造

设 p ∈ (0,2)，ε ∈ (0,1)。取两原子谱
  P_ε = (1−ε)δ_{ω₁} + εδ_{ω₂}，　ω₂ → 0⁺。

则
  ϖ_p = [(1−ε)ω₁^p + εω₂^p]^(1/p) / 2πT → [(1−ε)ω₁^p]^(1/p) / 2πT = (1−ε)^(1/p) ϖ₁，
  𝔎(P_ε,T) = (1−ε)ℌ(ϖ₁) + ε·ℌ(ϖ₂)（算子对 P 线性），而 ‖ℌ(ϖ₂)‖ → 0（ϖ₂→0，由 ⟦k⟧(0)=0 与 ‖ℌ(ϖ)‖ ≤ ‖𝒪[ϖ²/k²]‖ = 𝔤(2)ϖ²·(1+o(1))…或直接取 ω₂=0：此时 ⟦k⟧(0)=0，𝔎(P_ε)=(1−ε)ℌ(ϖ₁) **精确**，P_ε≠δ₀ 仍成立），故 𝔨(P_ε,T) → (1−ε)h(ϖ₁)（取 ω₂=0 时精确等于）。**注意 λ₁ 不对算子和线性，上式是算子恒等式加范数极限，不是「λ₁ 的加权和」。**

要证：(1−ε)h(ϖ₁) > h((1−ε)^(1/p)ϖ₁)。令 α := (1−ε)^(1/p)，等价于
  α^p h(ϖ₁) > h(αϖ₁)。

**利用推论 (ii)**（`P4_main_theorems.md` §2）：r(ϖ) := h(ϖ)/ϖ² 于 (0,∞) 严格递减，r(0⁺) = 𝔤(2)。上述不等式等价于
  α^p r(ϖ₁) > α² r(αϖ₁)，
即
  α^(p−2) > r(αϖ₁) / r(ϖ₁)。

当 p < 2 时，p−2 < 0，故 α^(p−2) = (1−ε)^((p−2)/p) > 1（因 (1−ε) < 1 且指数 < 0）。而 r 严格递减、α < 1 ⟹ r(αϖ₁) > r(ϖ₁)，故比值 > 1。

**定量条件**：由推论 (ii)，h(ϖ) ≥ 𝔤(2)ϖ² − 4ζ(4)ϖ⁴（这里 ‖𝒪[1/k²−1/(k²+ϖ²)]‖ ≤ 4ζ(4)ϖ²，由 (S2) 结构恒等式），故
  r(ϖ) ∈ [𝔤(2) − 4ζ(4)ϖ², 𝔤(2))。

要 α^(p−2) > r(αϖ₁)/r(ϖ₁)，当 ϖ₁ 足够小使得 r(αϖ₁) ≈ r(ϖ₁) ≈ 𝔤(2) 时自动成立（因左端 > 1 而右端 → 1）。

**显式条件**：由
  r(αϖ₁) / r(ϖ₁) ≤ 𝔤(2) / [𝔤(2) − 4ζ(4)ϖ₁²] = 1 + 4ζ(4)ϖ₁² / [𝔤(2) − 4ζ(4)ϖ₁²]，

要 α^(p−2) > 1 + 4ζ(4)ϖ₁² / [𝔤(2) − 4ζ(4)ϖ₁²]，整理得

  **ϖ₁² < 𝔤(2) [α^(p−2) − 1] / {4ζ(4) [α^(p−2) + 1]}**，　　　　　　　　　　　　　　(*)

  （主会话核对 2026-09-13：由 α^(p−2) > 1 + a/(𝔤−a)、a:=4ζ(4)ϖ₁² 精确整理得 a < 𝔤[α^(p−2)−1]/α^(p−2)；(*) 的分母写成 α^(p−2)+1 比 α^(p−2) 大，故 (*) 是**更严**的充分条件，soundness 不受影响，只是略保守。）

其中 α = (1−ε)^(1/p)、𝔤(2) 用 CERT-B 严格下界 1.3181093293757127（`P4_main_theorems.md` §4.1）。

当 p ∈ (0,2)、ε ∈ (0,1)、ϖ₁ 满足 (*) 时，P_ε = (1−ε)δ_{ω₁} + εδ_{ω₂}（ω₂→0）严格违反 p-矩界。∎

## 2. 诚实边界（honesty boundary）

1. **定理 2′ 的证明全链解析**，无计算机辅助成分，引用已证明的引理 M（`P4_main_theorems.md` §1，状态 PROVED）与推论 (i)(ii)（§2）。

2. **命题 2″ 的反例构造**依赖推论 (ii) 中 r(ϖ) 严格递减的性质，该性质由引理 M 严格证明（非数值）。显式条件 (*) 使用：
   - 𝔤(2) 的 CERT-B 严格下界 1.3181093293757127（12 个整数 + 有理算术，`P4_main_theorems.md` §4.1）；
   - ζ(4) = π⁴/90 的解析值。

3. **命题 2″ 无需计算机证书**：对每个固定 (p,ε,ϖ₁) 满足 (*) 的三元组，不等式 (1−ε)h(ϖ₁) > h((1−ε)^(1/p)ϖ₁) 可由 mpmath 直接验证（h 的 mpmath 计算已在 `p4_interchange_uniformity.py` 等处标准化）；但不等式本身的**存在性**（即 (*) 的右端 > 0）是解析的。

4. **数值门**（§3）验证：(a) 定理 2′ 的不等式在随机谱与多个 p 值下成立；(b) 命题 2″ 的反例在数值上确实违反；(c) ϖ_p 的单调性。这些是**一致性检查**，非证明的一部分。

5. **p=2 最紧的推论**：由 Lyapunov 不等式 ⟨ω^p⟩^(1/p) 关于 p 递增（凸函数的积分表示），ϖ_p 随 p 递增，故 h(ϖ_p) 随 p 递增（h 严格递增，推论 (i)）。在 p ≥ 2 的可行域内，p=2 给出最小的 ϖ_p，即最紧的界。
