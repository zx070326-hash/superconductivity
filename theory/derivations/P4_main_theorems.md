## 1. 核心引理（全部解析）

**引理 A（矩形部分和正性）.** 对所有 k,L,L′ ≥ 1：⟨e_L,𝒪[δ_k]e_{L′}⟩ ≥ 0，取等 ⟺ L+L′ ≤ k。
*证明形态*：三组逐项非负的闭式和（`P4_uniqueness_strategy.md` §2.A）。**解析、初等。**

**引理 B（Kamke 拟单调 / 阶梯基 Metzler）.** 对所有 K ≥ 0、L≠L′：𝒪[1_{k≤K}] 在阶梯基 {e_L} 下的非对角系数 ≥ 0，取等 ⟺ K=0 或 L ≥ L′+K+1。
*证明形态*：关键恒等式 u_n²−u_{n+1}²=d_n(u_n+u_{n+1}) + u 的严格凸性，四个穷尽情形（同上）。**解析、初等。**
（对非单调核 δ_k 为假——例 k=3,L=2,L′=1 给 −0.447。故阶梯分解是必需的。）

**推论 A′.** 对任意 d ≥ 0（不必单调，只需 𝒪[d] 有界）与任意 v∈C：⟨v,𝒪[d]v⟩ = lim_N Σ_{L,L′≤N} a_La_{L′}Q_{LL′}(d) ≥ a_{L₀}²d(1) ≥ 0，L₀ 为 v 的任一正 Abel 系数下标。**d(1)>0 且 v≠0 时严格。**

**推论 B′（半群保锥）.** F ≥ 0 非增、F(K)→0、𝒪[F] 有界 ⟹ e^{t𝒪[F]}C ⊂ C（Abel 分解 F=Σ_K(F(K)−F(K+1))1_{k≤K} + 引理 B + 有限截断的 Metzler 半群 + 强收敛）。

**引理 M（核单调性）.** 设 F,G: ℕ_{≥1}→[0,∞)，满足 (i) F 非增、Σ_kF(k)<∞、**F≢0**；(ii) G∈ℓ¹；(iii) F ≤ G 逐点。则
  **λ₁(𝒪[F]) ≤ λ₁(𝒪[G])**，且若 G(1)>F(1) 则严格。
*证.* 由 (i)：𝒪[F] 紧自伴（F∈ℓ¹⟹HS），λ₁(𝒪[F]) ≥ 𝒪[F]₀₀ = F(1) > 0 故是本征值；谱投影 P₁ = s-lim_{t→∞}e^{t(𝒪[F]−λ₁)}（不需 λ₁ 孤立），由推论 B′ 保锥，又 C−C ⊃ 有限支撑序列稠密 ⟹ P₁C≠{0}，取 v∈P₁C，‖v‖=1，𝒪[F]v=λ₁(𝒪[F])v。令 d:=G−F ≥ 0，逐元线性 ⟹ 𝒪[G]=𝒪[F]+𝒪[d]。则
  λ₁(𝒪[G]) ≥ ⟨v,𝒪[G]v⟩ = λ₁(𝒪[F]) + ⟨v,𝒪[d]v⟩ ≥ λ₁(𝒪[F]) + a_{L₀}²d(1)。∎
*状态*：**解析。对抗核 PROVED，无 CHALLENGED**（`notes/2026-09-12_lemma_M_review.md`）。它是 `P4_uniqueness_strategy.md` §3.A 步骤 1–3（已审 PROVED）的逐字抽象，不引入新数学。

> **注（λ₁ 的定义）.** KAY 写 𝔤(2)=ρ(𝔊(2))（谱半径）；引理 M 的 Rayleigh 链用的是 max spec。二者对 𝔊(2) 相等（λ_min=−0.9898 > −1.318），且即便不等，ρ ≥ λ₁ 只会让上界更松。论文一律定义 λ₁ := max spec。

**引理 X（存在性）.** 𝔥^{(N)}(∞)=2S_N−1→∞ ⟹ 对每个 λ>0 存在 T 使 λ𝔨 ≥ 1。**解析（一页）。**

## 2. 主定理

**定理 1（KAY II Conjecture 2，完整，μ\*=0）.** 对所有 P∈𝒫（P≠δ₀，⟨ω²⟩<∞）与 λ>0：
(a) **[存在]** 存在 T>0 使 λ𝔨(P,T) ≥ 1。　*证*：引理 X。
(b) **[唯一]** T↦𝔨(P,T) 于 (0,∞) 严格递减、连续、T→∞ 时→0；故临界面与线 ℒ(λ,P) **恰交一次**，T_c(λ,P) 良定义。　*证*：引理 M 取 F=F_{T′}、G=F_T（T′>T），d(1)=∫[⟦1⟧(ω/2πT)−⟦1⟧(ω/2πT′)]P > 0。
(c) **[界]** T_c(λ,P) < T̃_c(λ,P):=(1/2π)√(𝔤(2)⟨ω²⟩λ)；更强地，**对所有 T>0 有 𝔨(P,T) < 𝔤(2)⟨ω²⟩/(2πT)²**。　*证*：引理 M 取 F=F_T、G(k)=⟨ϖ²⟩/k²（因 x/(k²+x) ≤ x/k²，⟨ϖ²⟩=⟨ω²⟩/(2πT)²），d(1)=∫x²/(1+x)P > 0；λ₁(𝒪[G])=⟨ϖ²⟩𝔤(2)。

**状态：(a)(b)(c) 三部分全部解析。** 无计算机辅助成分（𝔤(2) 作为一个**数**的包围除外——见 §4.1）。

**定理 2（Einstein 极值，全 λ）.** 对所有 P∈𝒫、T>0：
  **𝔨(P,T) ≤ h(ϖ_rms)**，ϖ_rms := √⟨ω²⟩/2πT，**等号 ⟺ P 是点质量**。
等价：固定 λ 与 ⟨ω²⟩，Einstein 谱 δ_{√⟨ω²⟩} 是线性化 Eliashberg T_c 的极大者；T_c(λ,P) ≤ T_c^E(λ,√⟨ω²⟩) 对**所有** λ。
*证*（**核级 Jensen**）：记 x:=ϖ²。F_T(k)=∫x/(k²+x)P(dω)，而 x↦x/(k²+x) 于 [0,∞) 严格凹 ⟹ 逐 k 有 F_T(k) ≤ ⟨x⟩/(k²+⟨x⟩) = ⟦k⟧(ϖ_rms) =: G(k)。F_T 非增、≤⟨x⟩/k² ∈ℓ¹、F_T(1)>0；G 是 Einstein 核 ∈ℓ¹。引理 M ⟹ 𝔨(P,T)=λ₁(𝒪[F_T]) ≤ λ₁(𝒪[G])=h(ϖ_rms)；严格性 ⟺ G(1)>F(1) ⟺ x 非 P-a.s. 常值 ⟺ P 非点质量。∎
**状态：解析（三行）。** 定理 1(c) 是它的 λ→∞ / G→⟨ϖ²⟩/k² 推论。文献定位：陈述为 Allen–Dynes 1975 folklore（Moussa–Cohen PRB 74, 094520 转述），**严格证明新**。

**推论.**
