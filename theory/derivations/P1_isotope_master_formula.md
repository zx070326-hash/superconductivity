## 0. 定义与目标

- 全同位素系数 α ≡ −d ln Tc / d ln M（所有原子质量同比例变化）
- 氢化物实测的是**部分**同位素系数 α_H ≡ −Δ ln Tc / Δ ln M_H（只换 H→D，宿主原子不变），Δ ln M_H = ln 2

目标：把 α_H 写成"理想 Migdal–Eliashberg 值 + 四个修正"，每个修正是可独立计算（最好闭式）的对数导数，然后用 `../data/hydrides_experimental.csv` 里的 α_H 反推四因子相对大小。

## 1. 理想 ME 极限：α = ½（量纲论证）

各向同性 Eliashberg 的输入是 α²F(ω)、μ*、N(ε)。在
(i) 谐波：α²F(ω; M) = α²F_0(ω·√(M/M₀))——所有声子频率 ∝ M^{-1/2}，λ = 2∫α²F/ω dω 不变；
(ii) 绝热（Migdal）：Tc 不显含 E_F；
(iii) μ* 与 M 无关；
(iv) N(ε) = N(0)
下，Tc 只能写成 Tc = ω_log · Φ(λ, μ*, 谱形状不变量)，唯一的质量依赖来自 ω_log ∝ M^{-1/2} → α = ½。

## 2. 主公式

放开 (i)–(iv)，Tc 会额外依赖一组无量纲比 r_k = （随质量变的声子标度）/（与质量无关的电子或势能标度）。写 Tc = ω_log · Φ(λ, μ*; {r_k})，且每个 r_k ∝ M^{-1/2}，则由链式法则

  α = ½ [ 1 + Σ_k s_k ]，　s_k ≡ ∂ ln Φ / ∂ ln r_k |_{λ, μ*, 其余 r 固定}　　(2.1)

四个修正对应四类 r_k：

| 修正 | r_k | 物理 |
|---|---|---|
| 库仑 | r_μ = ω_c / E_F | μ* 通过 Tolmachev 对数依赖截止；截止 ∝ 声子标度 |
| 非谐 | r_anh = η ≡ ħΦ₄ / (4M²ω₀³) | 零点位移 × 四阶力常数（见 §3.2） |
| 非绝热 | r_nad = ω_log / E_F | 顶角修正的控制参数 |
| 能量依赖 DOS | r_DOS = ω_log / δ，ω_log / W | δ = vHs 到 E_F 的距离，W = DOS 特征宽度 |

**推论 1（符号）**：α > ½ ⇔ Σ s_k > 0。μ* 项恒负（§3.1）；强耦合下非谐项小、符号由 ½ − ∂lnTc/∂lnλ 决定（§3.2）；顶角项符号 = 顶角修正对 Tc 的符号（§3.3）；DOS 项符号取决于 δ/ω_log（§3.4）。**因此 α_H 明显大于其理想值是"Tc 增强型非绝热修正"或"特定 DOS 位形"的指纹，μ* 与非谐都给不出。**

**推论 2（部分同位素）**：只换 H 时，理想极限不是 ½ 而是 ½·w_H，w_H 是 H 模对 ln Tc 的对数敏感度份额（Rainer–Culetto 1979 的部分同位素系数；谐波和规则 Σ_i w_i = 1）。于是

  α_H = ½ w_H + ½ Σ_k s_k^{(H)}　　(2.2)

w_H 需要 H 投影的 α²F——这是"适当计算"进入的地方（已发表的投影谱或一次 DFPT）。对 H3S/LaH10/YH6 预期 w_H ≈ 0.85–0.95（宿主模贡献 λ 的 5–15%，**待核**）。

诚实说明：(2.1) 本身是量纲分析 + 链式法则，不新。内容在于：(a) 每个 s_k 的闭式或数值；(b) 四项同时对氢化物数据做约束——文献里没有人合并做过（**待 researcher 核实**）。

## 3. 各项

### 3.1 库仑项（闭式，重推已知结果）

μ* = μ / [1 + μ ln(E_F/ω_c)]。令 L = ln(E_F/ω_c) = −ln r_μ，则 ∂μ*/∂L = −μ*²，∂μ*/∂ln r_μ = +μ*²。

  s_μ = μ*² · ∂ ln Φ / ∂ μ*　　(3.1)

McMillan 形式 Φ = exp[−1.04(1+λ)/D]，D ≡ λ − μ*(1+0.62λ)：∂lnΦ/∂μ* = −1.04(1+λ)(1+0.62λ)/D²，于是

  α = ½ [ 1 − 1.04 (1+λ)(1+0.62λ) μ*² / (λ − μ*(1+0.62λ))² ]　　(3.2)

（与 Carbotte RMP 1990 / Garland 1963 的结果一致，出处待 researcher 抄录。）Allen–Dynes 的 f₁f₂ 因子只含 λ 与 ω₂/ω_log，不含 M，不改变 (3.1) 的结构，只改 ∂lnΦ/∂μ* 的数值。

λ = 2 时的数值（§3.1 的 McMillan 版）：

| μ* | 0.10 | 0.13 | 0.20 | 0.25 | 0.30 |
|---|---|---|---|---|---|
| α | 0.488 | 0.480 | 0.442 | 0.395 | 0.322 |

**氢化物特有的问题**：Tolmachev 对数 L 小。ω_c ≈ 10 ω_max ≈ 2–3 eV，E_F ~ 10 eV 量级 → L ≈ 1.5–2（Pb 是 L ≈ 7）。两个后果：(a) μ* 本身大（μ ~ 1 时 μ* ≈ 0.3–0.4），所以 s_μ 大——**YH6 的 α_H = 0.4 若全归因于库仑需要 μ* ≈ 0.25，与 Troyan 2021 摘要"unusually large impact of the Coulomb repulsion"一致**；(b) L ≫ 1 是推导 Tolmachev 形式的前提，L ≈ 2 时 (3.1) 的可信度本身存疑——这就是 D2 报告里"Tolmachev 对数收缩"的问题。**处理**：在求解器里用显式库仑核 μ(ω_c)θ(ω_c−|ω|) 做数值 Eliashberg，直接数值求 s_μ，用 (3.2) 只作弱耦合校验。

### 3.2 非谐项（闭式，单模 SCHA 四阶模型）

Einstein 模式，Born–Oppenheimer 势 V(u) = ½ k u² + (Φ₄/24) u⁴，k、Φ₄ 与质量无关。ω₀² = k/M。
SCHA（高斯变分）：M ω² = ⟨V''⟩ = k + (Φ₄/2)⟨u²⟩，T=0 时 ⟨u²⟩ = ħ/(2Mω)。故

  ω² = ω₀² + ħΦ₄/(4M²ω)　⇔　x² = 1 + η/x，　x ≡ ω/ω₀，　η ≡ ħΦ₄/(4M²ω₀³) ∝ M^{-1/2}　　(3.3)

领头阶 x = 1 + η/2 + O(η²)。

- 声子频率的同位素指数：−d ln ω/d ln M = ½ + η/4 + O(η²)（轻同位素硬化更多）
- 耦合常数：λ = N(0)ħD²/(Mω²) = N(0)ħD²/(k x²) ∝ 1/(1+η)（D 为形变势，与质量无关）→ d ln λ/d ln M = +η/2（重同位素 λ 更大）
- 代入 Tc = ω_log Φ(λ)：

  s_anh = η/2 − η · ∂lnΦ/∂lnλ　⇒　δα_anh = η [ ¼ − ½ · ∂ ln Tc/∂ ln λ ]　　(3.4)

**判据**：sgn(δα_anh) = sgn(½ − ∂lnTc/∂lnλ)。
- 强耦合（λ ≈ 2，McMillan 给 ∂lnTc/∂lnλ ≈ 0.75）：δα_anh ≈ −0.12η。H3S 的 λ 2.64→1.84（Errea 2015）若全归因于单模四阶硬化，1/(1+η) ≈ 0.70 → η ≈ 0.43 → δα_anh ≈ −0.05。**非谐把 λ 压掉 30%，α 只动 0.05**——这是 (3.4) 的一个可检验预言（对 Errea 2015/2016 的 D3S 数值）。
- 弱耦合（λ ≲ 0.5，∂lnTc/∂lnλ ≈ 2–3）：δα_anh ≈ −η 到 −1.3η → 反常同位素效应（PdH，α_exp ≈ −0.25 ~ −0.3；Errea 2013 理论 −0.38）。PdH 的 η 已非微扰，(3.4) 只给定性。

三阶项：Φ₃ 在二阶微扰给 δω² ∝ −Φ₃²⟨u²⟩/(Mω²)（软化），同样 ∝ M^{-1/2}，相当于给 η 加一个 ∝ −Φ₃² 的负贡献。对称键合环境（反演中心在 H 位）Φ₃ 由对称性为零 → 净硬化 → λ 降、Tc 降；非对称环境 Φ₃ 大 → 可净软化 → λ 升。**这给 Belli–Zurek–Errea 2025 的 iCOBI 正负号规则一个解析基础**（待验证：用 H3S 与 PdH 的三阶/四阶力常数比）。

未包含（假设 A6）：SCHA 波函数对电声矩阵元 g 的非微扰重整化（D3 报告指出这正在成为独立子方向）。

### 3.3 非绝热项（数值目标；闭式留给 P2）

s_nad = ∂lnΦ/∂ln(ω_log/E_F)|_{λ,μ*}。Pietronero–Grimaldi：电声耦合由小动量转移 q < q_c ~ ω/v_F 主导时顶角修正增强 Tc → s_nad > 0 → α 上推；大 q 主导时压制 → 下拉。Mishra–Belli–Zurek–Margine 2026 的诊断量 R_V 应能与 s_nad 建立映射（P2 的任务）。
在 P1 里：先用求解器插入模型顶角核数值算 s_nad(m, Q_c)，m = ω_log/E_F。

### 3.4 DOS 项（数值目标 + 极限闭式）

模型 N(ε) = N(0)[1 + a·ln(W/|ε − δ|)]（2D 型 vHs）或台阶型。已知极限：vHs 恰在 E_F 时 BCS 的 α 被压到接近 0（Tsuei et al. PRL 1990，铜氧化物）。反例：Szczęśniak–Durajski 对 H3S 130 GPa 的 α = 2.37 归因于 DOS 重整化——符号相反。说明 s_DOS(δ/ω_log, a) 变号，这与 P4（dTc/dP 符号）是同一函数。在 P1 里作为二维数值函数算出来，用 Sano 2016 给的 H3S DOS 形状定位 H3S 在这张图上的位置。

**第一轮检验（只用 §3.1 + §3.2 闭式）**：能否用同一套 (L, η) 规则同时解释 H3S 0.44、LaH10 0.46、YH6 0.40、YH9 0.50？
- 若 μ* 单参数不能同时拟合四个高压体系，剩余就是 s_nad + s_DOS 的空间，且其符号被数据钉死。
- YH9 ≈ 0.50 而 YH6 ≈ 0.40 是同一元素两个相，λ 与 ω_log 都相近——这对差值是最干净的判别：μ* 相近的话，差值只能来自 w_H、非谐或 DOS。

**第二轮（求解器）**：四个 s_k 全部数值化，含 H/D 压力不匹配的 dTc/dP 修正。

## 5. 假设清单

- A1 各向同性 ME；各向异性对 α 的影响视为二阶
- A2 单模 SCHA 四阶模型代表多模非谐（粗；§3.2 的数值只到 ±50%）
- A3 Tolmachev 形式在 L ≈ 1.5–2 仍可用——**明确存疑**，用显式库仑核数值标定
- A4 H/D 样品压力差用 dTc/dP 线性修正
- A5 T=0 零点主导（Tc/ω_log ~ 0.1–0.2，边缘成立）
- A6 忽略 SCHA 对 g 的重整化
