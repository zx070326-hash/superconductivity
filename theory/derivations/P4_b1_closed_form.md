## 1. 记号、标度极限的因子，与两处上游订正

记 D := 1/ϖ、s_n := (n+½)D、w_n := 1/(2n+1)、p_n := √w_n、G(y) := 1/(1+y²)、⟦k⟧ := G(k/ϖ)、τ_n := p_nG(s_n)、B := ‖τ‖²。(M1)（`P4_einstein_extremal.md` §1.F.2）

  ℌ(ϖ) = 2ττᵀ + 𝓡 − 𝒟，　𝓡_{nm} = p_np_mR(s_n,s_m)，　𝒟 = diag(w_n + ℓ_G(n))，
  R(s,σ) = G(s−σ)+G(s+σ) − 2G(s)G(σ) = 2s²σ²(5+s²+σ²)/[(1+(s−σ)²)(1+(s+σ)²)(1+s²)(1+σ²)]，
  ℓ_G(n) = 2w_nΣ_{k=1}^{n}G(k/ϖ)。

§1.F.1 的三条精确恒等式是全文的引擎：**(i) w_n = D/(2s_n)；(ii) s_n−s_m = (n−m)D、s_n+s_m = (n+m+1)D；(iii) s_n 是 [nD,(n+1)D] 的中点。**由 (i)+(iii)，

  **Σ_{n≥0} w_n u(s_n) = Σ_{n≥0} D·φ(s_n)，φ(s) := u(s)/(2s)**

**恰是** ∫₀^∞φ 在均匀格 {[nD,(n+1)D]} 上的**复合中点求和**，误差由 Peano 核控制（见 §4）。记 I[u] := ½∫₀^∞ u(s)ds/s。

### 1.1 订正一：𝓡 部分的标度因子是 ½，不是 ¼

`P4_weak_coupling_series.md` §3.A(i) 写

  2⟨τ,𝓡τ⟩ → ¼∫₀^∞∫₀^∞ G(s)G(σ)R(s,σ)dsdσ/(sσ)。

**这少了一个因子 2。**正确推导：

  2⟨τ,𝓡τ⟩ = 2Σ_{n,m} w_nw_m G(s_n)R(s_n,s_m)G(s_m) = 2Σ_{n,m} D²·ψ(s_n,s_m)，
  **ψ(s,σ) := G(s)G(σ)R(s,σ)/(4sσ)**（用 w_n = D/(2s_n)、w_m = D/(2s_m)）

是 2∫∫ψ 的二维中点求和，而 2∫∫ψ = ½∫∫G(s)G(σ)R(s,σ)dsdσ/(sσ) =: **I_R**。脚本的二维 `dblquad` 对照给 ½·I₂ = 0.257856227944 = 格点和的极限，¼·I₂ = 0.128928 与格点和差一倍——**因子确为 ½**。（丢失点在 §3.A(i) 的第三行：前两行的 `2Σ_{n,m}w_nw_m…` 是对的，第三行换成 `(1/ϖ)²·Σ[1/(2s_n)][1/(2s_m)]…·ϖ²` 时把开头的 2 落下了。）

### 1.2 订正二：(I−𝒟) 部分没有「格点部分」

`P4_weak_coupling_series.md` §3.A(ii) 把 2⟨τ,(I−𝒟)τ⟩ 拆成「w_n 项 2Σ_n w_n²G²（对 n ≪ ϖ「→ 精确和（zeta 级数）」）」加「ℓ_G 项（「需仔细处理边界层」）」。**这个拆法是错的：w_n 项被 ℓ_G(n) 的主项精确抵消。**由 G = 1 − (1−G)，

  ℓ_G(n) = 2w_nΣ_{k≤n}G(k/ϖ) = 2w_n[n − Σ_{k≤n}(1−G(k/ϖ))] = (1−w_n) − 2w_nΣ_{k≤n}(1−G(k/ϖ))

（用 2nw_n = 2n/(2n+1) = 1−w_n），于是

> **(E1)　1 − 𝒟_{nn} = 1 − w_n − ℓ_G(n) = 2w_n Σ_{k=1}^{n} (1 − G(k/ϖ)) = 2w_n Σ_{k=1}^{n} (k/ϖ)²/(1+(k/ϖ)²)，精确。**

脚本在 ϖ=7、50、137 上逐元核对到 3.3e-15。因此**格点常数 C_lattice = 0**，整个 (I−𝒟) 部分只有一条标度积分。（这也解释了为什么 §3.A(ii) 预期的「n ≪ ϖ 时 1−𝒟_nn ≈ w_n·(1−…)」是对的但不是一个独立的贡献：由 (E1)，n ≪ ϖ 时 1−𝒟_nn ≈ 2w_n·n³/(3ϖ²) = O(n²/ϖ²)，与标度式 d(s_n) ≈ s_n²/3 一致，属同一项。）

## 2. (I−𝒟) 部分：2⟨τ,(I−𝒟)τ⟩ → 3π²/16 − 7/4

### 2.1 从 (E1) 到标度极限

记 f(y) := 1 − G(y) = y²/(1+y²)（f(0)=f′(0)=0，f 偶 ⟹ f‴(0)=0），F(x) := ∫₀^x f = x − arctan x。由 (E1) 与 w_n = D/(2s_n)，

  Δ_n := 1 − 𝒟_{nn} = (D/s_n)·Σ_{k=1}^{n} f(kD)。

**四阶 Euler–Maclaurin**（m=2，余项 ≤ (2ζ(4)/(2π)⁴)D³∫₀^∞|f⁗| < ∞）：

  Σ_{k=1}^{n} f(kD) = (1/D)F(nD) + ½f(nD) + (D/12)f′(nD) − (D³/720)f‴(nD) + O(D³)。

**半移**：nD = s_n − D/2，把上式三项都在 s_n 处 Taylor 展开：

| 项 | (1/D)F | ½f | (D/12)f′ |
|---|---|---|---|
| D⁰ | (1/D)F(s_n) | — | — |
| f(s_n) | −½ | +½ | — |
| D f′(s_n) | +1/8 | −1/4 | +1/12 |
| D²f″(s_n) | −1/48 | +1/16 | −1/24 |

f 项系数和 = 0；**D f′ 项系数和 = 1/8 − 1/4 + 1/12 = −1/24**；**D²f″ 项系数和 = (−1+3−2)/48 = 0**（半移把 D² 项也杀掉了——这是 §1.F.1「半移格点」技巧的又一次兑现）。故

> **(E2)　Δ_n = d(s_n) − (D²/24)·f′(s_n)/s_n + O(D⁴/s_n) = d(s_n) − (D²/12)G(s_n)² + O(D⁴/s_n)，**
> **d(s) := F(s)/s = 1 − arctan(s)/s，f′(y)/y = 2G(y)²。**

脚本在 ϖ=40,160,640 上量 [Δ_n − d(s_n)]·24ϖ²/(2G(s_n)²)，在 n ∈ [ϖ/2, 3ϖ] 上均值 = −1.00000（三个 ϖ 都是），证实系数 −1/24。

代回：

  2⟨τ,(I−𝒟)τ⟩ = 2Σ_n w_nG(s_n)²Δ_n = **2Σ_n w_n·G²d|_{s_n}** − **(D²/6)Σ_n w_nG(s_n)⁴** + O(D³)。

第二项 = O(ln ϖ/ϖ²)（因 0 ≤ Σ_n w_nG(s_n)⁴ ≤ ½(ln ϖ + γ + ln4 + 1)）；第一项是 u := G²d 的中点求和，→ 2I[G²d] = ∫₀^∞G(s)²(1−arctan(s)/s)ds/s =: **J**。

### 2.2 J 的初等闭式

代 s = tanθ（θ∈(0,π/2)），ds/(s(1+s²)²) = cos³θ/sinθ·dθ，arctan(s)/s = θcotθ：

  J = ∫₀^{π/2}[cos³θ/sinθ − θcos⁴θ/sin²θ]dθ　（两项各自在 θ→0 发散 ~1/θ，差收敛）。

用截断 ε：
- ∫_ε^{π/2}cos³θ/sinθ dθ = [ln sinθ − ½sin²θ]_ε^{π/2} = −½ − ln ε + O(ε²)。
- cos⁴θ/sin²θ = 1/sin²θ − 2 + sin²θ，其原函数 V(θ) = −cotθ − (3/2)θ − ¼sin2θ；分部积分
  ∫_ε^{π/2}θcos⁴θ/sin²θ dθ = [θV]_ε^{π/2} − ∫_ε^{π/2}V = (−3π²/8 + 1) − (−3π²/16 − ¼ + ln ε) = −3π²/16 + 5/4 − ln ε。

相减，ln ε 抵消：

> **(E3)　J = (−½ − ln ε) − (−3π²/16 + 5/4 − ln ε) = 3π²/16 − 7/4 = 0.10055082520425474…**

（`scipy.quad` 给 0.10055082520425 —— 与 §3.A(ii) 的探针值 0.1005 一致。）

## 3. 𝓡 部分：2⟨τ,𝓡τ⟩ → 11π²/72 − 5/4

  I_R = ½∫₀^∞∫₀^∞ G(s)G(σ)R(s,σ)dsdσ/(sσ) = ∫₀^∞ (ds/s)·G(s)·Υ_G(s)，
  **Υ_G(s) := ½∫₀^∞ G(σ)R(s,σ)dσ/σ**（即 §1.F.3(b) 里的 Υ_G，那里只用到了它的 L² 范数 N_R）。

### 3.1 内层积分 Υ_G 的闭式

代 z = σ²（R/σ·dσ 里的 σdσ = dz/2 把被积函数**有理化**），并用

  (1+(s−σ)²)(1+(s+σ)²) = (1+s²+σ²)² − 4s²σ² = z² + 2(1−s²)z + (1+s²)² =: Q(z)，
  Q 的根 z = (s±i)²，Q(−1) = s²(4+s²)，Q′(−1) = −2s²

得

  Υ_G(s) = (s²/(2(1+s²)))∫₀^∞ (5+s²+z)dz / [Q(z)(1+z)²]。

部分分式（三个极点：z=−1 二阶、z=(s±i)²）：B = 1/s²、A = 3/(s²(4+s²))、α = −A（保证 1/(1+z) 与 (αz+β)/Q 的对数发散抵消）、β = 5+s² − (A+B)(1+s²)²。用
  ∫₀^∞dz/Q = arctan(s)/s（配 arctan((1−s²)/2s) = π/2 − 2arctan s），
  ∫₀^M[1/(1+z) − z/Q]dz → ln(1+s²) + (1−s²)arctan(s)/s
并注意 s²(A(1−s²)+β) 的分子恰好塌成 2s²−4：

> **(E4)　Υ_G(s) = [3ln(1+s²) + 2(s²−2)·arctan(s)/s + (4+s²)] / [2(1+s²)(4+s²)]。**

脚本在 s = 0.05…20 的八个点上与数值 σ-积分符合到 ≤ 5.6e-17。**同一台机器的对照**：去掉 G(σ) 权重（把 (1+z)² 换成 (1+z)）给 Θ(s) = [ln(1+s²)+2s·arctan s]/(2(1+s²))，即 §1.F.3(c) 的 Schur 界函数，在 s\*=1.5009040 处复现认证值 Θ\* = 0.63492879178809。

### 3.2 外层积分的六块初等积分

  I_R = ∫₀^∞ [3L + 2(s²−2)T + 4 + s²] ds / [2s(1+s²)²(4+s²)]，L := ln(1+s²)，T := arctan(s)/s。

用 u = s² 的部分分式 1/((1+u)²(4+u)) = −1/(9(1+u)) + 1/(3(1+u)²) + 1/(9(4+u)) 与
(u−2)/((1+u)²(4+u)) = (2/3)/(1+u) − 1/(1+u)² − (2/3)/(4+u)，把 I_R 拆成

  **I_R = P₁ + P₂₃**，
  P₁ := (3/2)[−Λ(1)/9 + Λ₂/3 + Λ(2)/9]，　Λ(a) := ∫₀^∞ L ds/(s(s²+a²))、Λ₂ := ∫₀^∞ L ds/(s(1+s²)²)，
  P₂₃ := (2/3)Φ(1) − Ψ − (2/3)Φ(2) + X/2，
  Φ(a) := ∫_ε^∞ arctan(s)ds/(s²(s²+a²))、Ψ := ∫_ε^∞ arctan(s)ds/(s²(1+s²)²)、X := ∫_ε^∞ ds/(s(1+s²)²)。

（P₁ 各项在 s→0 收敛因 L ~ s²；P₂₃ 的三项各自对数发散，ln ε 在总和中系数为 0。）六块：

| 量 | 闭式 | 来源 |
|---|---|---|
| X | −ln ε − ½ | u=s²，1/(u(1+u)²) 部分分式 |
| ∫_ε^∞arctan(s)/s²ds | 1 − ln ε | 分部积分 |
| W(1) := ∫₀^∞arctan s/(1+s²)ds | π²/8 | = ½arctan²s\|₀^∞ |
| V := ∫₀^∞arctan s/(1+s²)²ds | π²/16 − ¼ | s=tanθ ⟹ ∫₀^{π/2}θcos²θdθ |
| Ψ | 5/4 − ln ε − 3π²/16 | 1/(s²(1+s²)²) = 1/s² − 1/(1+s²) − 1/(1+s²)² |
| Λ(1)，Λ₂ | π²/12，π²/12 − ½ | g(c) := ∫₀^∞ln(1+u)[1/u − 1/(u+c)]du，g(1) = π²/6 |

其中 Φ(a) = a^{−2}[(1 − ln ε) − W(a)]，W(a) := ∫₀^∞arctan(s)ds/(s²+a²)。

### 3.3 关键恒等式：W(2) + Λ(2) = π²/8（这一步消掉全部二重对数）

单看 W(2) = π²/16 − ¼ln2·ln3 − ¼Li₂(−2) 与 Λ(2) = (1/8)[π²/6 − Li₂(−3)] 都带 Li₂；但它们**只以和的形式**进入 I_R（系数都是 1/6）。参数微分一行给出：

  Y(b) := ∫₀^∞ arctan(bs)ds/(s²+4) + ∫₀^∞ ln(1+b²s²)ds/(s(s²+4))，Y(0) = 0，
  两项对 b 的导数分别是 A′(b) 与 2bA′(b)，A′(b) = ∫₀^∞ s ds/((1+b²s²)(s²+4)) = −ln(2b)/(1−4b²)，
  ⟹ Y′(b) = (1+2b)A′(b) = ln(2b)/(2b−1)，
  ⟹ **W(2)+Λ(2) = Y(1) = ½∫₀^² ln x/(x−1)dx = ½[π²/6 + π²/12] = π²/8**

（末步只用 ∫₀^1 ln x/(x−1)dx = ζ(2) 与 ∫₀^1 ln(1+y)/y dy = η(2) = π²/12，全初等）。

### 3.4 组装

把 P₁ 写成「(3/2)(−Λ(1)/9 + Λ₂/3)」＋「Λ(2)/6」，把 −(2/3)Φ(2) 写成「−(1/6)(1−ln ε)」＋「W(2)/6」，则 Λ(2)、W(2) 只以 [Λ(2)+W(2)]/6 = π²/48 出现。其余全是上表的初等块：ln ε 系数 −2/3+1−1/2+1/6 = 0；常数 −1/4+2/3−5/4−1/4−1/6 = −5/4；π² 系数 1/36 − 1/12 + 3/16 = 19/144。故

> **(E5)　I_R = 19π²/144 − 5/4 + π²/48 = 22π²/144 − 5/4 = 11π²/72 − 5/4 = 0.25785622794420757…**

mpmath dps=50 的一维数值积分与闭式差 6.7e-52。

## 4. 引理 B1（存在性 + 可证余项阶）

定理 W′ 的唯一 CHALLENGED 点是 **lim_{ϖ→∞}2⟨τ,(I+𝓡−𝒟)τ⟩ 的存在性**。§2、§3 的推导正是它的构造性证明。整理成：

> **引理 B1.** 记 D = 1/ϖ、φ(s) := G(s)²d(s)/(2s)、ψ(s,σ) := G(s)G(σ)R(s,σ)/(4sσ)、
> V₂[φ] := ∫₀^∞|φ″|ds、V₂ˣ[ψ] := ∫₀^∞∫₀^∞|∂²_sψ|dsdσ。两者都有限（下表给出数值）。则对一切 ϖ ≥ 1：
>
> **(a)** 2⟨τ,(I−𝒟)τ⟩ = J − (D²/6)Σ_{n≥0}w_nG(s_n)⁴ + ρ_a(ϖ)，
>   |ρ_a(ϖ)| ≤ (D²/4)·V₂[φ] + C_a·D³，　J = 3π²/16 − 7/4；
>   又 0 ≤ Σ_n w_nG(s_n)⁴ ≤ ½(ln ϖ + γ + ln4 + 1)，故整条余项是 **O(ln ϖ/ϖ²)**，**没有格点常数**（C_lattice = 0，由 (E1)）。
>
> **(b)** 2⟨τ,𝓡τ⟩ = I_R + ρ_b(ϖ)，|ρ_b(ϖ)| ≤ (D²/2)·V₂ˣ[ψ]，I_R = 11π²/72 − 5/4，余项是 **O(1/ϖ²)**。
>
> 因此极限存在且 **b₁ = J + I_R = 49π²/144 − 3**。

**证明用到的三件事，每件都初等：**

1. **(i)+(iii)（半移格点）**把两个和**恰好**写成中点求和：一维 Σ_n w_n u(s_n) = Σ_n D φ(s_n)，二维 Σ_{n,m}w_nw_m(…) = Σ_{n,m}D²ψ(s_n,s_m)，格 {[nD,(n+1)D]}（分别是一维与二维的乘积格）覆盖 [0,∞)（²），s_n 恰为中点。
2. **中点法则的 Peano 核**（此处对被求和的 φ 作用，φ = u/(2s)，与 §3.A 第 98 行的 u := G²d 不同名，勿混）：单格误差 = ∫K·φ″，K ≥ 0，max K = D²/8、∫K = D³/24。**与 ∫|φ″| 配对的可证常数是 D²/8**，D²/24 只对「逐格 sup|φ″|」成立——这正是主稿 §1.G（M2）对 M1 §1.F.3(a) 做过的同一处订正，本文沿用 1/8。二维取乘积中点法则，单和误差 ≤ (D²/8)(∫∫|∂²_sψ| + ∫∫|∂²_σψ|) = (D²/4)V₂ˣ[ψ]（由 ψ 对称）。**注意外层因子 2**：§2.1 的 2⟨τ,(I−𝒟)τ⟩ = 2Σ_n D φ(s_n) − …（第 96 行）与 §3 的 2⟨τ,𝓡τ⟩ = 2Σ_{n,m}D²ψ 都带一个显式的 2，它同样乘到中点误差上，故余项的可证界是 |ρ_a| ≤ 2·(D²/8)V₂[φ] = **(D²/4)V₂[φ]**、|ρ_b| ≤ 2·(D²/4)V₂ˣ[ψ] = **(D²/2)V₂ˣ[ψ]**——这就是引理 B1 (a)(b) 里的系数。（单和的 1/8、1/4 若直接当作余项界会紧一倍：下表实测比 0.21/0.20，而非把外层 2 漏掉时误算的 0.42/0.40。）
3. **两个总变差有限**：φ 在 0 处解析（d(s) = s²/3 − s⁴/5 + … ⟹ φ(s) = s/6 + O(s³)），s→∞ 时 φ ~ 1/(2s⁵)，故 φ″ ∈ L¹(0,∞)；ψ 在 ℝ² 上实解析（R 在 s、σ 上分别是偶函数且含因子 s²σ²，故 R/(sσ) 光滑；两个分母 1 + (s∓σ)² ≥ 1 从不消失），远场 ψ ~ (s²+σ²)/(4sσ·s²σ²(s²−σ²)²)，对角带上 ψ ~ 1/(4s⁶)，故 ∂²_sψ ∈ L¹((0,∞)²)。

**引理 B1 的常数（脚本 A.6 段，`sympy` 求导 + 求积）：**

| 常数 | 值 | 由此给出的界 |

## 6. B 部分：三路交叉验证

三条路线：
1. **求解器**：`theory/solvers/eliashberg_iso.py`，Einstein 谱、μ\*=0、常 DOS，`Solver(...).tc()`（线性化核矩阵最大本征值 = 1 处对 ln T 用 brentq）。
2. **KAY 算子**：解 λ·λ₁(ℌ^{(N)}(ϖ)) = 1（`p4_extremal_asymptotics.top_eig` 的 FFT matvec + ARPACK，N = 40ϖ），T_c/ω_E = 1/(2πϖ)。
3. **渐近公式**：T_c^{asym} = (ω_E/2π)e^{c₀}e^{−1/λ}。

### 6.1 μ\*=0 时求解器与 KAY 算子的**精确**对应（不是巧合）

求解器（`_kernels` / `_max_eigen_linearized`）在 μ\*=0、Einstein 谱下：λ(ν_{n−m}) = λ⟦n−m⟧，

  Z_n = 1 + w_nΣ_m λ(⟦|n−m|⟧ − ⟦n+m+1⟧)，　Z_nΔ_n = λΣ_m(⟦|n−m|⟧+⟦n+m+1⟧)w_mΔ_m。

在 N = ∞ 下 Σ_{m≥0}(⟦|n−m|⟧−⟦n+m+1⟧) = 1 + 2Σ_{k≤n}⟦k⟧，即 **Z_n = 1 + λ𝒟_{nn}**；又置 x_n := p_nΔ_n 并用 𝑀̃_{nm} := p_np_m(⟦|n−m|⟧+⟦n+m+1⟧) = ℌ_{nm} + δ_{nm}𝒟_{nn}，方程化为

  x_n(1 + λ𝒟_{nn}) = λ((ℌ+𝒟)x)_n　⟺　**λℌx = x。**

即**求解器的「最大本征值 = 1」与 λ·λ₁(ℌ(ϖ)) = 1 是同一个条件**（注意只有在本征值 = 1 处两者等价；求解器矩阵 a = (I+λ𝒟)^{−1}λ𝑀̃ 与 λℌ 一般**不**相似——早期一次对照在非 T_c 处比较过，那是无效的比较）。这也顺带说明：**μ\*=0 时 w_cut 完全不进入物理**，θ 斜坡整条被 μ\*=0 乘掉，w_cut 只通过 `_n_for_T` 的自动 N 估计起作用；脚本用两个相差 16 倍的 w_cut、同一 `n_matsubara`，线性化本征值**逐位相同**。

### 6.2 找到的差异：求解器的 Z 求和截断约定

有限 N 下 Σ_{m=0}^{N−1}(⟦|n−m|⟧−⟦n+m+1⟧) = 1 + 2Σ_{k≤n}⟦k⟧ − **Σ_{j=N−n}^{N+n}⟦j⟧**。求解器把 Z 方程的 Matsubara 和与 Δ 方程**同样截断在 N**，KAY II 的对角 𝒟_{nn} 用的是**无穷和**（`H_mat` 的 `cum` 只累到 n，尾巴解析地取尽）。差额是一个非负对角

  **ε_n := w_nΣ_{j=N−n}^{N+n}⟦j⟧**，　求解器实际解的是 **λ(ℌ^{(N)} + diag(ε))x = x**。

因 Σ_{j=N−n}^{N+n}⟦j⟧ ≈ ϖ²·2n/(N²−n²) 而 2nw_n → 1，ε_n ≈ ϖ²/N² 在 n ≪ N 上近似常数，而顶本征向量 τ 的质量集中在 n ≲ ϖ ≪ N，故

> **δh := λ₁(ℌ^{(N)}+diag(ε)) − λ₁(ℌ^{(N)}) = ϖ²/N² + O(ϖ⁴/N⁴)**，
> **T_c^{solver}(N)/T_c^{KAY}(∞) − 1 ≈ ϖ²/N²**（因 dh/dln ϖ ≈ 1）。

脚本在 (ϖ, N/ϖ) = (15.6, 20)、(15.6, 40)、(40, 20)、(40, 40) 上量 δh·N²/ϖ² = 0.99795、0.99949、0.99785、0.99946 —— 系数就是 1。

这就是「求解器与 KAY 差 0.1% 以上」的**全部**原因：N = 20ϖ 时 ϖ²/N² = 2.5e−3（0.25%），N = 40ϖ 时 6.25e−4。两者都收敛到同一 N→∞ 极限，但**KAY 约定收敛快得多**（O(N^{−4}) vs O(N^{−2})）——对任何想用 Matsubara 求解器算弱耦合 T_c 的人，这是一条可直接用的改进：把 Z 方程的和用解析尾巴补到无穷，截断误差从 N^{−2} 掉到 N^{−4}。

**验证方式**（脚本 B.4）：在**同一个 N** 上，把 KAY 侧换成同约定的算子 ℌ^{(N)}+diag(ε)，求解器 T_c 与其根**逐位吻合（相对偏差 ≤ 1e−7，纯属两边求根容差）**——差异被完全解释，没有剩余。再用 1/N² 的 Richardson 外推（N、2N）回到 N→∞，与 KAY 值符合到 ~5e−4（残差就是 O((ϖ/N)⁴)）。
