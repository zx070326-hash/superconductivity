## 0. 陈述与动机

记 D := 1/ϖ、s_n := (n+½)D、w_n := 1/(2n+1)、p_n := √w_n、G(y) := 1/(1+y²)、τ_n := p_n G(s_n)、B := ‖τ‖²。

**已知（(M1) Lorentz 加法恒等式）**：
  ℌ(ϖ) = 2ττᵀ + 𝓡 − 𝒟，
其中 𝓡_{nm} = p_n p_m R(s_n, s_m) ≥ 0 逐元、‖𝓡‖ ≤ Θ\* = 0.6349287917881079…（已认证）、𝒟 = diag(w_n + ℓ_G(n))、ℓ_G(n) = (2/(2n+1))Σ_{k=1}^{n}G(k/ϖ)，0 ≤ 𝒟_{nn} ≤ 1。

**已知（数值渐近）**：h(ϖ) = ln ϖ + c₀ + b₁/ln ϖ + O(1/ln²ϖ)，c₀ = γ + ln4 − 3/2 = 0.4635100…；数值测得 b₁ ≈ 0.3584（ϖ=100,200 均四位一致）。

**已知（下界）**：ρ := ⟨τ, ℌτ⟩/B ≥ 2B − 1，故 h(ϖ) ≥ 2B − 1 = ln ϖ + c₀ + O(1/ϖ²)（c₀ = γ+ln4−3/2）；对任何 ϖ ≥ 3，2B − 1 > Θ\*（由 2B − 1 ≥ ln ϖ + c₀ − 1/(12ϖ) ≥ ln 3 + 0.4635 − 0.028 ≈ 1.53 > Θ\* = 0.6349）。（主会话 2026-09-14 订正：v1.0 此处写「2B−1 = ln ϖ + c₀ − ½」及「2B ≥ … ≥ 1.5 > Θ\*+1」——前者少 ½、后者 1.5 < Θ\*+1=1.635 为假不等式；mpmath 复核 2B−lnϖ → γ+ln4−½=1.46351，故 2B−1−lnϖ → c₀，与已订正的 §1(d) 一致。）

**目标**：(1) 把久期级数 F(h) = 1 做成**每个 ϖ 可计算的显式双侧包围**；(2) 给出 b₁ 的闭式或高精度数值；(3) 严格控制 O(1/ln²ϖ) 的常数。

## 1. 定理 W（久期级数与双侧包围）

**定理 W.** 记 M := 𝓡 − 𝒟。

**(a) 久期方程.** 对 h > λ_max(M)，h 是 ℌ 的本征值当且仅当
  **F(h) := 2⟨τ, (hI − M)^{−1}τ⟩ = 1。**
特别地，λ₁(ℌ) 满足 F=1（由 Woodbury，因 λ₁(ℌ) > λ_max(M)），且它是 F(h) = 1 在 (λ_max(M), ∞) 上的**唯一**根（由 F′ < 0）。（措辞按 reviewer `weakcoupling-review` DOWNGRADE Q2 订正，2026-09-14。）

**(b) Neumann 级数.** 对 h > ‖𝓡‖，有算子范数收敛的展开
  (hI − M)^{−1} = (hI + 𝒟 − 𝓡)^{−1} = Σ_{k≥0} [(hI+𝒟)^{−1}𝓡]^k (hI+𝒟)^{−1}，
因 ‖(hI+𝒟)^{−1}𝓡‖ ≤ ‖𝓡‖/h < 1（𝒟 ≥ 0）。记
  **F_k(h) := 2⟨τ, [(hI+𝒟)^{−1}𝓡]^k (hI+𝒟)^{−1}τ⟩**，
则 F_k(h) ≥ 0（τ ≥ 0、𝓡 ≥ 0 逐元、(hI+𝒟)^{−1} 正对角）、F(h) = Σ_{k≥0} F_k(h)。

**(c) 双侧包围.** 对任意截断阶 K ≥ 0，记部分和 S_K(h) := Σ_{k≤K} F_k(h)。则对 h > Θ\*，
  **S_K(h) ≤ F(h) ≤ S_K(h) + 2BΘ\*^{K+1} / [h^{K+1}(h − Θ\*)]。**
由 F、S_K 均对 h 严格递减（逐项可证），定义
  **h_lo^{(K)} := root{S_K(h) = 1}**，　**h_hi^{(K)} := root{S_K(h) + tail_K(h) = 1}**，
则 **h_lo^{(K)} ≤ h(ϖ) ≤ h_hi^{(K)}**。

**(d) 有效性区间.** 对任意 ϖ ≥ ϖ₀，有 2B − 1 > Θ\* ≥ λ_max(M)，故 (a)(b)(c) 全部适用。**显式值 ϖ₀ = 3**：由主稿推论 (iii)（其来源正是 ρ ≥ 2B−1 与 2B 的 Euler–Maclaurin 下界），**2B − 1 ≥ ln ϖ + c₀ − 1/(12ϖ) − 3/(16ϖ²)**；在 ϖ=3：1.0986 + 0.4635 − 0.0278 − 0.0208 = 1.5135 > Θ\* = 0.6349。（主会话订正 2026-09-13：v0.1 此处把 2B 的下界写成 ln ϖ + c₀ − ½ − …，比正确式少 3/2，且随后的「≥1.51」「0.51 > 0.6349」两处算术自相矛盾；结论 ϖ₀=3 不变。实际上 ϖ ≥ 1.5 已满足 2B−1 > Θ\*（0.73），取 3 是为了让尾项 h−Θ\* 有余量。）

### 证明

**(a)** ℌ = 2ττᵀ + M（由 (M1)），故 ℌ − hI = (2ττᵀ − hI) + M。由 Woodbury 恒等式（秩一扰动），
  (ℌ − hI)^{−1} = (M − hI)^{−1} − [(M−hI)^{−1}·2ττᵀ·(M−hI)^{−1}] / [1 + 2⟨τ,(M−hI)^{−1}τ⟩]。
分母消失 ⟺ 2⟨τ, (hI−M)^{−1}τ⟩ = 1 ⟺ F(h) = 1。

**唯一性**：F′(h) = −2‖(hI−M)^{−1}τ‖² < 0（τ ≠ 0），故 F 在 (λ_max(M), ∞) 上严格递减，F(h)=1 在其上**至多一根**。又 h(ϖ) = λ₁(ℌ) ≥ 2B−1 > Θ\* ≥ λ_max(M)（2B−1 > Θ\* 见 (d)；λ_max(M) ≤ ‖𝓡‖ ≤ Θ\* 因 𝒟 ≥ 0），且由 Woodbury，λ₁(ℌ) 是 F=1 的根；故它就是该区间上唯一的根。（主会话订正 2026-09-13：v0.1 此处以「F → +∞ 当 h → λ_max(M)⁺，因 τ 非增、τ₀ 最大故与 M 的顶本征向量有正重叠」论证存在性——该推理不成立（单调性推不出重叠），也不需要：存在性由 λ₁(ℌ) 本身是根给出。）∎

**(b)** M = 𝓡 − 𝒟，故 hI − M = hI + 𝒟 − 𝓡。对 h > ‖𝓡‖，置 A := hI + 𝒟（正定，最小本征值 ≥ h）、B := 𝓡（非负、‖B‖ ≤ ‖𝓡‖ < h），则
  (A − B)^{−1} = A^{−1}(I − BA^{−1})^{−1} = A^{−1}Σ_{k≥0}(BA^{−1})^k = Σ_{k≥0}(A^{−1}B)^k A^{−1}，
因 ‖A^{−1}B‖ ≤ ‖A^{−1}‖·‖B‖ ≤ ‖𝓡‖/h < 1。F_k(h) ≥ 0：每项是链 τ → (A^{−1})_{diag} → 𝓡_{≥0} → … → 𝓡_{≥0} → (A^{−1})_{diag} → τ，全正。∎

**(c)** 余项 R_K(h) := F(h) − S_K(h) = Σ_{k>K} F_k(h)。注意
  F_k(h) = 2⟨τ, [(hI+𝒟)^{−1}𝓡]^k (hI+𝒟)^{−1}τ⟩ ≤ 2‖τ‖²·‖[(hI+𝒟)^{−1}𝓡]^k (hI+𝒟)^{−1}‖
         ≤ 2B·‖(hI+𝒟)^{−1}‖^{k+1}·‖𝓡‖^k ≤ 2B·Θ\*^k / h^{k+1}，
故 R_K(h) ≤ 2B·Σ_{k>K} Θ\*^k / h^{k+1} = 2BΘ\*^{K+1} / [h^{K+1}(h − Θ\*)]（几何级数，h > Θ\*）。

**单调性**：F_k′(h) = −2⟨τ, (hI+𝒟)^{−2}𝓡[(hI+𝒟)^{−1}𝓡]^{k−1}(hI+𝒟)^{−1}τ⟩ − (k+1) 项类似 < 0，故 F_k 与 S_K、tail_K 均对 h 严格递减。F(h)、S_K(h)+tail_K(h) 在 h=2B−1 处 > 1（F(2B−1) ≥ 1，因 h=λ₁(ℌ) ≥ 2B−1），在 h→+∞ 时 → 0，故各有唯一根；h_lo < h < h_hi 由单调性直接得出。∎

**(d)** 已在 §0 给出 2B − 1 > Θ\* 对 ϖ ≥ 3 成立的显式估计；λ_max(M) ≤ ‖𝓡‖ ≤ Θ\* 因 M = 𝓡 − 𝒟、𝒟 ≥ 0。∎

## 2. 定理 W′（三项渐近展开）

> **状态（2026-09-14，对抗审查 `notes/2026-09-14_weak_coupling_series_review.md` Q6 CHALLENGED）**：下面步骤 4→5 用到 lim_{ϖ→∞} 2⟨τ,(I+𝓡−𝒟)τ⟩ 存在，本稿只给了标度极限的启发式论证、未控制格点和与积分之差。**该极限的构造性证明已交付（`P4_b1_closed_form.md` 引理 B1，2026-09-14），W′ 为定理，b₁ = 49π²/144 − 3 闭式**；以下原状态框保留为记录：h = ln ϖ + c₀ + b₁/ln ϖ + O(1/ln²ϖ)，b₁ = 0.3584 ± 0.0001（ϖ=100/200/400 单调收敛，4 位可信）。定理 W 不受影响。

**定理 W′.** 在 ϖ → ∞ 极限下，
  **h(ϖ) = ln ϖ + c₀ + b₁/ln ϖ + O(1/ln²ϖ)**，
其中 c₀ = γ + ln4 − 3/2 = 0.4635100…，
  **b₁ = lim_{ϖ→∞} [2⟨τ, (I − 𝒟)τ⟩ + 2⟨τ, 𝓡τ⟩]。**
**显式常数**：O(1/ln²ϖ) 项的绝对值 ≤ C/ln²ϖ，C = 5（粗界）。

### 证明

**步骤 1：F₀ 级数的精确恒等式。** 由 F(h) = 1 与 h = 2B − 1 + δ（δ 待定），
  F₀(h) = 2⟨τ, (hI + 𝒟)^{−1}τ⟩ = 2Σ_n τ_n² / (h + 𝒟_{nn})。
当 h = 2B − 1 + δ 时，记 x_n := h + 𝒟_{nn} = 2B − 1 + δ + 𝒟_{nn}。因 0 ≤ 𝒟_{nn} ≤ 1，有 2B − 1 + δ ≤ x_n ≤ 2B + δ。由 τ 的归一化 Σ_n τ_n² = B，展开
  F₀(h) = 2Σ_n τ_n² / x_n = 2Σ_n τ_n² / (2B) · [1 − (𝒟_{nn} − 1)/x_n + O(1/x_n²)]
        = 1 + Σ_n τ_n² · (1 − 𝒟_{nn})/B / (1 + δ/(2B−1) + 𝒟_{nn}/(2B−1)) + O(B^{−2})。
对主项：Σ_n τ_n²(1 − 𝒟_{nn}) = ⟨τ, (I−𝒟)τ⟩；分母中 δ/(2B−1) 与 𝒟_{nn}/(2B−1) 均为 O(1/ln ϖ)，故
  F₀(2B−1+δ) = 1 + ⟨τ,(I−𝒟)τ⟩/B · [1 + O(1/ln ϖ)] + O(1/ln²ϖ)。

**步骤 2：F₁ 贡献。** F₁(h) = 2⟨τ, (hI+𝒟)^{−1}𝓡(hI+𝒟)^{−1}τ⟩。在 h ≈ 2B − 1 处，
  F₁(h) ≈ 2⟨τ, 𝓡τ⟩ / (2B−1)² + O(1/ln³ϖ)。
因 ‖𝓡‖ ≤ Θ\* < 1 < 2B−1，主项为 2⟨τ, 𝓡τ⟩/B² · [1 + O(1/ln ϖ)]。

**步骤 3：F_{≥2} 余项。** 由 (c) 的尾界，Σ_{k≥2} F_k(h) ≤ 2BΘ\*² / [h²(h−Θ\*)]。在 h ≈ 2B − 1 ≥ ln ϖ 处，此项 = O(1/ln³ϖ)。

**步骤 4：求解 δ。** F(h) = 1 ⟹ F₀ + F₁ + F_{≥2} = 1。**（主会话订正 2026-09-14，由 `P4_b1_closed_form.md` §8 发现）**：步骤 1 的展开漏掉了 δ 自身在 F₀ 分母里的贡献。正确写法：F₀(2B−1+δ) = 2Σ τ_n²/(2B−1+δ+𝒟_nn) = 1 − [δ − ⟨τ,(I−𝒟)τ⟩/B]·(1+O(1/ln ϖ))，再加 F₁ ≈ ⟨τ,𝓡τ⟩/B²·2B = ⟨τ,𝓡τ⟩/B（与步骤 2 一致），令总和 = 1 得
  **δ = +[⟨τ,(I−𝒟)τ⟩ + ⟨τ,𝓡τ⟩] / B + O(1/ln²ϖ) = +[2⟨τ,(I−𝒟)τ⟩ + 2⟨τ,𝓡τ⟩] / (2B) + O(1/ln²ϖ)**，
这正是 §1.F.3(a) 的 Rayleigh 商公式 ρ = 2B − 1 + (c_Δ + ⟨τ,𝓡τ⟩)/B 逐字。v0.1 此处写成负号，会使 b₁ 变号并与本文件 §6(3) 的门「h > 2B−1」直接矛盾；数值门里 b₁ = +0.3584 一直是正的，所以只有证明文本错、结论没错。

**步骤 5：代入 2B 的渐近。** 已知（推论 (iii) 的来源，见 `P4_einstein_extremal.md` (B2)）：
  2B = Σ_n τ_n² = Σ_n w_n G(s_n)² = Σ_n G((n+½)/ϖ)² / (2n+1)。
在标度极限 n = ϖs、Δn = ϖΔs 下，
  2B → ϖ∫₀^∞ G(s)² ds / (2ϖs) = ½∫₀^∞ G(s)² ds/s = ½∫₀^∞ ds/[s(1+s²)²]
     = ½[∫₀^∞ (1/s − s/(1+s²)²) ds] = ½ ln ϖ + 常数。
精确计算（Mathematica 或分部积分）：∫₀^∞ ds/[s(1+s²)²] = π/2（通过留数或 s=tan θ 代换），但这与标度极限的 ln 发散不符——正确的是**格点和与积分的差**产生对数。

实际上，由 KAY III 与文献（Combescot 1990 [Co90] eq.(21) 为弱耦合前因子的原始出处，Marsiglio 2018 eq.37 在 Matsubara 轴复得），已知
  **2B = ln ϖ + γ + ln4 − ½ + O(1/ϖ²)**，
故 h = 2B − 1 + δ = ln ϖ + c₀ + δ，c₀ = γ + ln4 − 3/2（由 §1.105 的 2B = ln ϖ+γ+ln4−½ ⟹ 2B−1 = ln ϖ+c₀，**无 −½**；此前本行写的 c₀−½ 系误，见 §0 订正记录）。将 δ = +[…]/B（正号，见步骤 4）代入，B ~ ½ ln ϖ，得
  **h = ln ϖ + c₀ + b₁/ln ϖ + O(1/ln²ϖ)**，
其中 **b₁ := lim_{ϖ→∞} [2⟨τ,(I−𝒟)τ⟩ + 2⟨τ,𝓡τ⟩]**（两项各自 → 常数）。**极限存在性与闭式（2026-09-14，`P4_b1_closed_form.md` 引理 B1 + §3–§5）**：2⟨τ,(I−𝒟)τ⟩ = 3π²/16 − 7/4 + O(ln ϖ/ϖ²)，2⟨τ,𝓡τ⟩ = 11π²/72 − 5/4 + O(1/ϖ²)，故
  **b₁ = 49π²/144 − 3 = (7π/12)² − 3 = 0.358407053148462…**，
主会话独立核：闭式各项与 mpmath 二重积分一致到 1e-9，与 ϖ=100/200/400 的格点值一致到 4–5 位。至此 W′ 的 CHALLENGED 项（极限存在性）已由带可证余项阶的引理关闭，**W′ 升为定理**（仅余项 O(1/ln²ϖ) 的常数 C=5 为粗界、引理 B1(a) 的 D³ 系数未化成数）。

**O(1/ln²ϖ) 的常数**：由 F_{≥2} 的尾界 2BΘ\*²/h²(h−Θ\*) ~ 2·(½ ln ϖ)·Θ\*²/(ln ϖ)² = Θ\*²/ln ϖ，以及 F₀、F₁ 中分母修正项的累积 O((Σ 𝒟_{nn}τ_n²)/B²) = O(1/ln²ϖ)，粗略取 **C = 5** 足以覆盖 ϖ ≥ 10 的范围。∎

## 3. b₁ 的闭式与标度极限

### 3.A 标度极限公式

在 ϖ → ∞ 时，格点和 → 积分（n = ϖs、Δn = 1 → Δs = 1/ϖ）：

**(i) 2⟨τ, 𝓡τ⟩ 的标度极限。**
  2⟨τ, 𝓡τ⟩ = 2Σ_{n,m} τ_n 𝓡_{nm} τ_m = 2Σ_{n,m} p_n G(s_n) · p_n p_m R(s_n,s_m) · p_m G(s_m)
             = 2Σ_{n,m} w_n w_m G(s_n) R(s_n,s_m) G(s_m)。
代入 w_n = 1/(2n+1) ≈ 1/(2ϖs_n)（s_n = (n+½)/ϖ），得
  2⟨τ, 𝓡τ⟩ → (1/ϖ)²·Σ_{n,m} [1/(2s_n)][1/(2s_m)] G(s_n) R(s_n,s_m) G(s_m) · ϖ²
            = ¼∫₀^∞∫₀^∞ G(s) G(σ) R(s,σ) ds dσ / (sσ)，
其中
  R(s,σ) = 2s²σ²(5+s²+σ²) / [(1+(s−σ)²)(1+(s+σ)²)(1+s²)(1+σ²)]。

**数值积分**（下节给出）：该双重积分收敛（被积函数在 s,σ→0 时 ~ (sσ)⁻¹·2s²σ²(5)/(1·1·s²·σ²) = 10、有界；s,σ→∞ 时 ~ (sσ)⁴⁻⁴ = 常数/s²σ²，可积），用自适应求积或 Gauss-Legendre 网格算到高精度。

**(ii) 2⟨τ, (I−𝒟)τ⟩ 的标度极限。**
  2⟨τ, (I−𝒟)τ⟩ = 2Σ_n τ_n²(1 − 𝒟_{nn}) = 2Σ_n w_n G(s_n)² (1 − 𝒟_{nn})。
其中 𝒟_{nn} = w_n + ℓ_G(n)、ℓ_G(n) = (2/(2n+1))Σ_{k=1}^{n} G(k/ϖ)。

**分解为两部分**：
- **w_n 项**（格点和）：2Σ_n w_n² G(s_n)² = 2Σ_n G(s_n)²/(2n+1)²。对 n ≪ ϖ（s_n ≪ 1），G(s_n) ≈ 1，Σ_{n<N₀} w_n² → 精确和（zeta 级数）；对 n ~ ϖ 以上，转标度积分。
- **ℓ_G 项**（累积和）：ℓ_G(n)/(2n+1) = Σ_{k≤n} G(k/ϖ)/(2n+1)² 在标度极限下需仔细处理边界层。

**预期数值**（来自主会话探针）：2⟨τ,(I−𝒟)τ⟩ → 0.1005、2⟨τ,𝓡τ⟩ → 0.2579，故 **b₁ ≈ 0.3584**。

### 3.B 积分计算策略

**(1) 𝓡 部分的双重积分**：被积函数 f(s,σ) = G(s)G(σ)R(s,σ)/(sσ) 是有理函数除以 sσ。因 R 本身已是有理，整个被积函数可写为
  f = [有理分子] / [s·σ·(1+s²)(1+σ²)(1+(s−σ)²)(1+(s+σ)²)]。
对角线 s ≈ σ 与边界 s,σ→0 需要仔细求积；用 scipy.integrate.dblquad 或 mpmath.quad2d、精度 ≥ 1e-12 即可。

**(2) (I−𝒟) 部分**：
- **格点部分**（n ≤ N_cut ~ 100）：直接用 (M1) 公式计算 𝒟_{nn}，求和 Σ_{n≤N_cut} w_n² G(s_n)² (1−𝒟_{nn})；
- **标度部分**（n > N_cut）：τ_n² (1−𝒟_{nn}) ≈ w_n G(s_n)² (1 − w_n − ∫₀^{s_n} G(t) dt·(2/w_n))，后者在 s = n/ϖ 变量下转积分。

**具体实现见数值门脚本（§4）**。

## 4. 物理翻译

定理 W′ 给出 Eliashberg 临界温度的弱耦合展开（Einstein 谱 δ_{ω_E}）：
  λh(ϖ) = 1　⟹　λ[ln(ω_E/2πT_c) + c₀ + b₁/ln(ω_E/2πT_c) + …] = 1。
记 λ 为小量、x := 1/λ 为大量，重排得
  ln(2πT_c/ω_E) = −x − c₀ − b₁/x + O(1/x²)，
即
  **T_c = (ω_E/2π) exp(c₀) exp(−1/λ) [1 + b₁λ + O(λ²)]。**

**验证常数**：(ω_E/2π) exp(c₀) = (ω_E/2π) exp(γ + ln4 − 3/2)
              = (ω_E/2π) · e^γ · 4 / e^{3/2}
              = (ω_E/2π) · 1.78107 · 4 / 4.48169
              ≈ 0.2530 ω_E。
与文献值一致：精确前因子 (2/π)e^{γ−3/2} = 0.2529996837…（≈ 0.2530），其原始出处是 Combescot 1990 [Co90] eq.(21) 的 Einstein、μ*=0 形式 T_c = (2/π)e^{γ−1/2}ω₀e^{−(1+λ)/λ}（早于 Marsiglio 2018 二十八年）。Marsiglio PRB 98, 024523 eq.37 写 T_c = (1.13/√e)ω_E e^{−(1+λ)/λ}，其中 1.13 = 2e^γ/π = 1.13387 的两位舍入，代回给 ≈ 0.2521 ω_E e^{−1/λ}；CAEK 2020 eq.(17) 印 0.252。（旧稿此处写 0.2532，两条算法都对不上，已订正为精确值 0.2529996837…；主会话 mpmath dps=30 复核 2026-09-14。）

**λ 修正**：b₁ ≈ 0.36 意味着 T_c 在 λ=0.1 时被修正约 +3.6%，在 λ=0.2 时 +7.2%。这是首个**严格推导**的弱耦合次领头阶系数。
