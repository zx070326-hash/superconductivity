## §1. 引理 A（任意谱的双侧 Tc 夹逼）

**引理 A.** 设 P∈𝒫，支撑于 [ω_min, ω_max]，其中 0<ω_min≤ω_max<∞。记 ϖ_min:=ω_min/2πT，ϖ_max:=ω_max/2πT，ϖ_rms:=√⟨ω²⟩/2πT，x:=ϖ²。则对所有 T>0：

**(A-上界)** 𝔨(P,T) ≤ h(ϖ_rms)。
  *证*：定理 2。∎

**(A-下界-1，基于 ω_min)** 𝔨(P,T) ≥ h(ϖ_min)。
  *证*：F_T(k) = ∫ x/(k²+x) P(dω)。对固定 k，函数 φ_k(ω):=ω²/(k²·(2πT)²+ω²) 关于 ω 于 [0,∞) 严格递增（因 ∂_ω φ_k = 2ω·k²·(2πT)²/(k²·(2πT)²+ω²)² > 0），故
      F_T(k) = ∫ φ_k(ω) P(dω) ≥ φ_k(ω_min) = ⟦k⟧(ϖ_min)（P 的支撑于 [ω_min,ω_max]）。
  记 G(k):=⟦k⟧(ϖ_min)，则 F_T ≥ G 逐点。两者均非增（x/(k²+x) 关于 k 递减）、∈ℓ¹、F_T≢0。引理 M ⟹ 𝔨(P,T)=λ₁(𝒪[F_T]) ≥ λ₁(𝒪[G])=h(ϖ_min)。∎

**(A-下界-2，基于 ω_max 与 ⟨ω²⟩)** 𝔨(P,T) ≥ (⟨ω²⟩/ω_max²)·h(ϖ_max)。
  *证*：对固定 k≥1，函数 ψ(x):=x/(k²+x) 于 [0,∞) 凹且 ψ(0)=0（二阶导 ψ″(x)=−2k²/(k²+x)³ < 0）。故对 0≤x≤x_max，由凹函数性质（弦在图象上方）：
      ψ(x) ≥ (x/x_max)·ψ(x_max)，即 x/(k²+x) ≥ (x/x_max)·x_max/(k²+x_max)。
  对 P 积分：F_T(k) = ∫ x/(k²+x) P(dω) ≥ (⟨x⟩/x_max)·x_max/(k²+x_max) = (⟨ω²⟩/ω_max²)·⟦k⟧(ϖ_max)。
  记 G(k):=(⟨ω²⟩/ω_max²)·⟦k⟧(ϖ_max)，常数因子提出后 λ₁(𝒪[G])=(⟨ω²⟩/ω_max²)·h(ϖ_max)。引理 M ⟹ 𝔨≥λ₁(𝒪[G])。∎

**存在性前提**（两条下界的 Tc 存在性）：
- 下界-1：要求 λ·h(ϖ_min) ≤ 1 在某 T 成立 ⟺ λ 足够大或 ω_min 足够小（h 递增，ϖ_min→0 时 h→0）。
- 下界-2：要求 λ·(⟨ω²⟩/ω_max²)·h(ϖ_max) ≤ 1 在某 T 成立 ⟺ λ 足够大。

**Tc 界的翻译**（由 𝔨 严格递减，定理 1(b)）：
若 T_c(λ,P) 与 T_c^E(λ,ω) 均存在且良定义，则
  (i) T_c^E(λ, ω_min) ≤ T_c(λ,P) ≤ T_c^E(λ, ω_rms)，
  (ii) T_c(λ,P) ≥ T_c^E(λ·⟨ω²⟩/ω_max², ω_max)。

**注（方向核验）**：引理 M 要求 F≤G 且 F 非增。
- 下界-1：F_T ≥ ⟦·⟧(ϖ_min)，即「较大者 ≥ 较小者」⟹ 用 F=⟦·⟧(ϖ_min)、G=F_T 代入引理 M 时 F≤G ✓；⟦·⟧ 非增 ✓。
- 下界-2：F_T ≥ c·⟦·⟧(ϖ_max)，同样方向 ✓。

## §2. 命题 B（Einstein Tc 的凸性）

**命题 B.** 定义 H(x):=h(√x)，x∈[0,∞)。由引理 C，H 于 [0,∞) 凹、H(0)=0、H 严格递增。Einstein Tc 由 λH(x_c)=1 隐式定义，其中 x_c:=(ω_E/2πT_c^E)²。则：

**(B-i，凸性)** x_c = H^{-1}(1/λ) 关于 1/λ 为凸函数（H 凹增 ⟹ H^{-1} 凸增）。

**(B-ii，切线上界)** 对任意严格算出的 Einstein 点 (1/λ₀, x_c(λ₀)) 与其斜率 dx_c/d(1/λ)|_{λ₀} = 1/H′(x_c(λ₀))（Hellmann–Feynman 定理），切线
      x_c(1/λ) ≥ x_c(λ₀) + (1/λ − 1/λ₀)/H′(x_c(λ₀))
  对所有 λ 成立（凸函数图象在切线上方）。翻译为 T_c^E 的显式上界：
      T_c^E(λ,ω_E) ≤ ω_E/(2π) · [x_c(λ₀) + (1/λ − 1/λ₀)/H′(x_c(λ₀))]^{−1/2}。
  由定理 2，此上界传递给所有谱 P（⟨ω²⟩=ω_E²）的 T_c(λ,P)。

**(B-iii，弱耦合渐近)** H 凹 ⟹ H(x) ≤ H′(0⁺)·x = 𝔤(2)·x（切线在凹函数图象下方），即
      h(ϖ) ≤ 𝔤(2)ϖ²，
  这正是定理 1(c) 的 T̃_c 上界（弱耦合 / λ→∞ 渐近）。**说明定理 1(c) 是切线族在 λ→∞ 端的极限**。

**证明**：
- (B-i)：H 凹增且 H(0)=0 ⟹ H^{-1} 存在、严格递增、凸（凹函数反函数凸，标准结果）。由 λH(x_c)=1 得 x_c=H^{-1}(1/λ)，故 x_c 关于 1/λ 凸。
- (B-ii)：凸函数性质：图象在任意切线上方。对 x_c(1/λ)，在 (1/λ₀, x_c(λ₀)) 处的切线斜率为 dx_c/d(1/λ) = 1/H′(x_c)（隐函数求导：d/d(1/λ)[H(x_c)]=1 ⟹ H′(x_c)·dx_c/d(1/λ)=1）。切线不等式成立。将 x_c=(ω_E/2πT_c^E)² 代入并解出 T_c^E 得所需上界。
- (B-iii)：H 凹且过原点 ⟹ 对所有 x>0 有 H(x) ≤ H′(0⁺)·x（原点切线）。由引理 C 的证明（或推论 (ii)，`P4_main_theorems.md`），H′(0⁺)=𝔤(2)。代入 H(x)=h(√x) 得 h(ϖ)≤𝔤(2)ϖ²。∎

**注（Hellmann–Feynman）**：对 λH(x_c)=1，两边对 λ 求导：H(x_c)+λH′(x_c)·∂x_c/∂λ=0 ⟹ ∂x_c/∂λ=−H(x_c)/(λH′(x_c))=−1/(λ²H′(x_c))。改写为对 1/λ 的导数：dx_c/d(1/λ)=∂x_c/∂λ·∂λ/∂(1/λ)=∂x_c/∂λ·(−λ²)=1/H′(x_c)。

## §3. 数值验证（`p4_tc_sandwich.py`）

脚本结构（三个 Stage，numpy float64，反映 P4 项目的证书风格）：

**Stage A（随机谱夹逼验证，40+ 谱 × 若干 T）**：
- 生成 40 个随机多原子谱（2–5 峰，随机权重归一化，随机频率于 [0.1,5]）。
- 对每个谱与 T∈{0.01,0.05,0.1,0.5,1.0}：
  (1) 计算 𝔨(P,T) = λ₁(Σ p_j H^(N)(ω_j/2πT))（N=400，float64 非严格）；
  (2) 计算 h(ϖ_min)、h(ϖ_rms)、(⟨ω²⟩/ω_max²)·h(ϖ_max)；
  (3) 验证 h(ϖ_min) ≤ 𝔨 ≤ h(ϖ_rms) 与下界-2。
- 打印通过数 / 总数。

**Stage B（Einstein x_c 凸性验证）**：
- λ 网格 [0.3,0.5,1.0,2.0,3.0,5.0,10.0]，ω_E=1.0。
- 对每个 λ，解 λh(ω_E/2πT_c^E)=1 得 x_c=(ω_E/2πT_c^E)²（N=400）。
- 计算 x_c 关于 1/λ 的二阶差分：Δ²x_c[i] = x_c[i+1]−2x_c[i]+x_c[i−1]（中心差分除以 Δ(1/λ)²）。
- 凸性 ⟺ 所有二阶差分 ≥0（在 float64 意义上，允许 −1e-10 容差）。
- 验证切线界：选 λ₀=2.0，计算该点的 H′(x_c) ≈ (h(ϖ+δ)−h(ϖ−δ))/(2δϖ)（数值导数），验证其他 λ 的 x_c 在切线上方。

**Stage C（氢化物 Tc 上界表）**：
- 数据来源：`isotope_curated.md` 的 SSCHA 表，提取 (system, P, λ, ω_log, Tc_theory)。
- 对每个材料：
  (1) 计算 ω_rms = ω_log（假设对数平均近似 rms，或用 ω₂ 若有）；
  (2) 解 λh(ω_rms/2πT_c^E)=1 得 T_c^E(λ,ω_rms)（N=400，标注非严格）；
  (3) 与文献 Tc 并列：T_c^E / Tc_theory，标注上界性质。
- 打印表格（system | P | λ | ω_log | T_c^E(上界) | Tc_theory | 比值）。
- **诚实边界**：N=400 的 h^(N) 是 h 的下估（N 截断单调，定理 1 阶梯性质），故 T_c^E 的 N=400 解是 T_c^E(N→∞) 的下估。作为「上界」用时，需说明只在 N→∞ 极限下严格，或验证 N=400 vs N=800 的差 <0.1%（由脚本验证并标注）。

**反馈项**：
- Stage A/B：报告通过检查数 / 总数、任何失败的 margin。
- Stage C：表格 + 「N=400 vs N=800 相对差 <X%」注记。

## §4. 诚实边界与残余假设

1. **N 截断的方向**：h^(N) ≤ h（N 截断给严格下界，定理 1 阶梯），故 T_c^E 的 N 截断值是 T_c^E(∞) 的下估。用作「一般谱 Tc 的上界」时，只在 N→∞ 极限下严格。实际操作：验证 N=400 与 N=800 的差 <0.1%，或在文中标注「N 足够大时上界收敛」。
2. **float64 非严格**：所有数值为说明性计算，不是严格包围（无区间算术、无舍入垫）。引理 A 与命题 B 的证明是解析的，数值验证只为交叉检验。
3. **氢化物数据来源**：λ 与 ω_log 取自 SSCHA / 第一性原理计算（Errea 2015/2020、Troyan 2021），μ\*=0.10–0.16 约定。本项目的 Tc 计算在 μ\*=0（KAY 框架），故与文献 Tc 的比较是「μ\*=0 上界 vs μ\*>0 理论值」，预期 T_c^E(μ\*=0) > Tc_theory(μ\*>0)。
4. **ω_rms 的近似**：若只有 ω_log，假设 ω_log ≈ ω_rms（对窄谱合理）；若有 ω₂=√⟨ω²⟩ 则直接用。数据缺失时跳过该材料并列出缺什么。
