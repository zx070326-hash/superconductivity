## 1. 结构：库仑项在阶梯基下的精确形态

记 u_n=(2n+1)^{−1/2}，𝒪[f] = −L1[f]+L2[f]+L3[f]，e_L := 1_{[0,L)}，
  W_{L,L′}[M] := (M e_{L′})_{L−1} − (M e_{L′})_L　（Kamke / 拟单调系数，引理 B 的对象）。

**事实 1.1（任务简报的自然猜测是错的）**。𝔎_c ≠ 𝒪[1_{k<N_c}]。差的最大元为 1.0–1.33（N_c=3 时 1.3333，N_c=20 时 1.0476），与 N 无关。故"g(k)=F_T(k)−μ̃·1_{k<N_c} 的一个负 Abel 系数 a_{N_c−1}"这一表述只是**近似**框架。

**事实 1.2（精确恒等式）**。
  **𝔎_c(N_c) = P_{N_c}(𝒪[1] + I)P_{N_c}**，　P_{N_c} = 前 N_c 个坐标的正交投影，
验证到 1.1e−16（用 `P4_einstein_extremal.md` §1.C 的 𝒪[1] = 2uuᵀ − I，两边同为 2P u uᵀ P）。

**事实 1.3（𝔎_c 的 Kamke 闭式）**。记 S(j) := Σ_{i<j} u_i。对 L≠L′，
  **W^c_{L,L′} = 2·S(min(L′,N_c))·( u_{L−1}1_{L−1<N_c} − u_L 1_{L<N_c} )**，

于是 M = A − μ̃𝔎_c 的 Kamke 矩阵是 W^F − μ̃W^c：**被减去的正生成元块就是"一个坏 Abel 系数"的精确形态**，而且它只占 N_c 行。

## 3. 可行路线：秩一预解式约化 + 鲁棒化推论 A′

设 A := 𝔎_ph(ϖ̄) = H(ϖ̄)（`p4_interchange_uniformity.py` 的认证算子），本征值 μ₁>μ₂ ≥ …，正交本征向量 ψ_j，c_j := ⟨u_c,ψ_j⟩，γ := μ₁−μ₂ > 0。记 f(k) := ϖ̄·∂_ϖ̄⟦k⟧(ϖ̄) ≥ 0，𝒪[f] = ϖ̄·H^{(1)}(ϖ̄)，则 −T·∂_T𝔎 = 𝒪[f]。

**引理 1（秩一久期约化）**。M = A − 2μ̃|u_c⟩⟨u_c|。若 c₁ ≠ 0，则
 (i) λ := λ₁(M) 是久期方程 2μ̃·Σ_j c_j²/(μ_j−λ) = 1 在 (μ₂,μ₁) 内的**唯一**根（久期函数在该区间严格递增，从 −∞ 到 +∞），从而 **λ₁(M) 自动单重**；
 (ii) 顶本征向量**精确**为 v = (A−λ)^{−1}u_c；
 (iii) **μ₁ − λ ≤ 2μ̃c₁²**（由久期方程 2μ̃c₁²/(μ₁−λ) = 1 + 2μ̃Σ_{j≥2}c_j²/(λ−μ_j) ≥ 1）。
 c₁ > 0 由 μ\*=0 理论保证：ψ₁ ∈ C（推论 B′ + λ₁(A) 单重），u_c ≥ 0 且 ≠ 0。
 *验证*：(i)(ii) 与 `eigh` 逐点比对，|λ_sec−λ_eigh| ≤ 1e−11、‖v_sec−v_eigh‖ ≤ 1e−7；(iii) 逐格成立。

**引理 2（角度界）**。记 ‖u_⊥‖ := (‖u_c‖²−c₁²)^{1/2}，θ := ∠(v,ψ₁)。若
  **κ := 2μ̃c₁²/γ < 1**，
则
  **tan θ ≤ 2μ̃·c₁·‖u_⊥‖ / (γ − 2μ̃c₁²)**。
 *证*：由引理 1(ii)，v = c₁/(μ₁−λ)·ψ₁ + Σ_{j≥2} c_j/(μ_j−λ)·ψ_j，故
 tan θ = (μ₁−λ)/c₁ · [Σ_{j≥2} c_j²/(λ−μ_j)²]^{1/2} ≤ (μ₁−λ)/c₁ · ‖u_⊥‖/(λ−μ₂)；
 用 (iii) 的 μ₁−λ ≤ 2μ̃c₁² 与 λ−μ₂ ≥ γ−2μ̃c₁² 即得。∎
 *验证*：在 κ<1 的全部格点上 tan θ ≤ 界（例：(1,10,μ̃=0.13) 实际 0.4255 vs 界 0.8121）。

**引理 3（鲁棒化推论 A′）**。记
  q₁ := ⟨ψ₁,𝒪[f]ψ₁⟩ （**> 0**，正是 μ\*=0 的推论 A′，因 ψ₁∈C、f ≥ 0、f(1)>0），
  b := ‖P_⊥𝒪[f]ψ₁‖，　m := max(0, −λ_min(𝒪[f]))。
则对 v̂ = cos θ·ψ₁ + sin θ·φ（φ⊥ψ₁ 单位）
  **⟨v̂,𝒪[f]v̂⟩ ≥ cos²θ·[ q₁ − 2b·tanθ − m·tan²θ ]**，
右端 > 0 当且仅当 **tan θ < 𝔱_max := (−b + √(b²+m q₁))/m**（m=0 时 𝔱_max=∞）。
 *注*：m 必须取数值。探针 7(a) 表明 L2[f]+L3[f] **不是** PSD（λ_min 从 ϖ̄=0.3 的 −0.065 到 ϖ̄=60 的 −0.909），故不存在 "m ≤ max_n diag L1" 这种廉价解析界；可用的解析上界只有 m ≤ max_n (L1[f])_{nn} + |λ_min(L2[f]+L3[f])|。

**引理 4（Hellmann–Feynman）**。窗内（N_c 固定）T·∂_Tλ₁(M(T)) = −⟨v̂,𝒪[f]v̂⟩，由引理 1(i) 的单重性合法。*验证*：中心差分相对误差 ≤ 2e−9。

**定理（窗内严格单调）**。固定 ϖ̄ 与 N_c。若
  **μ̃ < μ̃\_\*(ϖ̄,N_c) := 𝔱_max·γ / ( 2c₁‖u_⊥‖ + 2𝔱_max c₁² )**，
则 κ<1 且 tan θ < 𝔱_max，从而 ⟨v̂,𝒪[f]v̂⟩ > 0，即 T↦λ₁(M(T)) 在该 N_c 窗内严格递减；于是 λ·λ₁(M(T))=1 在窗内至多一根。
 *证*：条件等价于 2μ̃c₁‖u_⊥‖ < 𝔱_max(γ−2μ̃c₁²)，特别推出 γ−2μ̃c₁²>0 即 κ<1；再串联引理 2、3、4。∎

**命题 6.1（两侧 Rayleigh 夹逼，严格）**。设 w、v 分别是 M(N_c)、M(N_c+1) 的顶向量，u := (2N_c+1)^{−1/2}。则
  2μ̃·u·v_{N_c}·(2⟨u_c^{(N_c)},v⟩ + u·v_{N_c}) ≤ λ₁(N_c) − λ₁(N_c+1) ≤ 2μ̃·u·w_{N_c}·(2⟨u_c^{(N_c)},w⟩ + u·w_{N_c})。
 *证*：u_c^{(N_c+1)} = u_c^{(N_c)} + u·e_{N_c}，故 M(N_c+1) = M(N_c) − 2μ̃[u(|u_c⟩⟨e_{N_c}|+h.c.) + u²|e_{N_c}⟩⟨e_{N_c}|]；两端分别用 v 作 M(N_c) 的试探向量、w 作 M(N_c+1) 的试探向量。∎ 30 个采样步全部通过断言（13 上跳、17 下跳）。
 *注*：跳变符号由 sign(v_{N_c}·⟨u_c,v⟩) 控制。**不能**用 "v∈C ⟹ v_{N_c} ≥ 0" 来单侧论证——v_{N_c} 在 r=10 的窗内典型为**负**（见 §2.C 表）。

**命题 6.2（全局唯一性：r=10 成立，r=3 失效）**。沿真实阶梯路径 N_c(ϖ̄)=⌊rϖ̄⌋ 扫 ϖ̄∈[0.34,6]（步长 0.004，N=200）：
- **r=10**，μ̃ ∈ {0.065, 0.10, 0.13, 0.26}：λ₁ 全局非减 ⟹ 对**每个** λ 唯一交点。
- **r=3**：16 段（μ̃=0.26 时 5 段）下跳，给出显式非唯一 λ-区间，例如
  - μ̃=0.10：ϖ̄∈[0.668,0.760] 时 λ₁ 从 0.267997 掉到 0.181642 ⟹ λ ∈ (3.731, 5.505) 非唯一；ϖ̄∈[1.336,1.360] ⟹ λ ∈ (1.476, 1.514) 非唯一；更外侧的段覆盖 λ≈1（与姊妹探针的 λ=1、μ̃=0.10、r=3 双根独立吻合）。
  - μ̃=0.13：ϖ̄∈[0.668,0.796]，λ₁ 0.228753 → 0.117785 ⟹ λ ∈ (4.372, 8.490) 非唯一。

**这不是本定理的缺口**：失效来自 N_c(T) 的**不连续**，不是窗内行为。诚实陈述应为：

> 对每个固定 N_c 窗，μ̃ < μ̃\_\*(ϖ̄,N_c) 时 T↦λ₁(M) 严格单调；T_c 跨窗唯一性还需要对 N_c(ϖ̄) 的正则性/尺度假设（如 r ≥ 5），否则 T_c 按 sup 定义。

## 7. 诚实边界

- **(H1) 常数是 float64。** γ、q₁、b、m、c₁、‖u_⊥‖ 由 `numpy.linalg.eigh` 在 N-截断上算出。**定理本身是解析的**（引理 1–4 的推导不含数值步骤），但要按本仓库的证书标准把它记为 PROVED，还需要这六个量的区间包络（对照 `p4_cii_m3_interval.py` 的 Tier1/Tier2 划分）。S6 显示它们在 N ≥ 200 起稳定到 6 位有效数字（N=100/200/400/800 比较），这是证据不是证明。S7 用 mpmath dps=40 在 N=60 上复核 λ₁（float64 相对误差 ≤ 1e−13）。
- **(H2) 定理是窗内命题。** 跨窗全局唯一性在 r=3 处于物理 μ̃ 上真实失效（§6），已量化并显式列出坏 λ-区间。
- **(H3) 未证带**：μ̃\_\* < μ̃ < μ̃_crit 之间因子 ~1.5–3 的区域数值上仍单调但未证。已知反例（§5）就落在这条带里，说明该带**不能**被平凡地填满——至少在 N_c=4、ϖ̄≈0.74 附近不能。
- **(H4) 上游依赖。** q₁ > 0 依赖 μ\*=0 理论的引理 A + ψ₁ ∈ C（推论 B′）。本文件是 `P4_uniqueness_strategy.md` 的**扩展**而非替代；S0 闸门在 μ̃=0 处逐项复现该文件的结论（𝒪[1]=2uuᵀ−I、引理 B 非负、ψ₁∈C、q₁>0）。
- **(H5) N→∞ 尾部。** 所有量都在 P_N M P_N 上算。μ\*=0 的证书体系（`p4d_coulomb_certify.py` 的 α 侧、Poincaré 分离）给出 λ₂ 的尾部控制，但 q₁、b、m 的 N→∞ 极限尚未证书化。
