 这是一个**恒等式**，不是数值发现；脚本里的 1.1e−16 只是记账（v0.1 把它记成「验证到 1.1e−16」，措辞已订正，reviewer DOWNGRADE 8）。

## 3. 可行路线：秩一预解式约化 + 鲁棒化推论 A′

设 A := 𝔎_ph(ϖ̄) = H(ϖ̄)（`p4_interchange_uniformity.py` 的认证算子），本征值 μ₁>μ₂ ≥ …，正交本征向量 ψ_j，c_j := ⟨u_c,ψ_j⟩，γ := μ₁−μ₂ > 0。记 f(k) := ϖ̄·∂_ϖ̄⟦k⟧(ϖ̄) ≥ 0，𝒪[f] = ϖ̄·H^{(1)}(ϖ̄)，则 −T·∂_T𝔎 = 𝒪[f]。

**引理 0（λ₁(A) 单重且 ψ₁ 不变号）**。设 A = 𝔎_ph(ϖ̄)，即 A_{nm} = u_n u_m[F(|n−m|)+F(n+m+1)]，F = ⟦·⟧(ϖ̄) > 0 处处（Einstein 核 F(k)=ϖ̄²/(k²+ϖ̄²)）。则 A 的**每个**非对角元严格为正，于是对任意顶本征向量 ψ 有 ⟨|ψ|,A|ψ|⟩ ≥ ⟨ψ,Aψ⟩ = λ₁‖ψ‖²，取等迫使 ψ 不变号；两个正交的不变号向量不可能，故 **λ₁(A) 单重、ψ₁ 可取为 ≥ 0**。
 *记账（CHALLENGED 3）*：这**就是** Perron–Frobenius / Krein–Rutman 那套正性论证。上游 `P4_uniqueness_strategy.md` §3 注 (i)、§3.A 推论 (iv) 四处明写它**不需要**顶本征值单重、不需要 Krein–Rutman——它只证 E₁ ∩ C ≠ {0}（顶本征**空间**含锥向量），而**不是**「归一化的 ψ₁ ∈ C」。v0.1 第 94 行把 λ₁(A) 单重当成上游结论引用，是借了上游明确拒绝提供的东西。本版把它**降格为本定理自己的引理 0**，代价是重新引入了上游刻意避开的正性论证（见 (H4)）。若 λ₁(A) 退化，ψ₁ 不唯一、q₁ 无定义，且 λ₁(M) 会等于 μ₁ 且重数 ≥ dim E₁ − 1，引理 1 的单重性与引理 4 的 Hellmann–Feynman **同时失效**——所以这条引理是必需的，不是装饰。

**引理 1（秩一久期约化）**。M = A − 2μ̃|u_c⟩⟨u_c|。**假设 c₁ ≠ 0 且 κ := 2μ̃c₁²/γ < 1**。则
 (i) λ := λ₁(M) 是久期方程 φ(λ) := 2μ̃·Σ_j c_j²/(μ_j−λ) = 1 在 (μ₂,μ₁) 内的**唯一**根，从而 **λ₁(M) 自动单重**；
 (ii) 顶本征向量**精确**为 v = (A−λ)^{−1}u_c；
 (iii) **μ₁ − λ ≤ 2μ̃c₁²**。
 *证*：置 λ₀ := μ₁ − 2μ̃c₁²。κ<1 恰好说 λ₀ > μ₂。φ 在 (μ₂,μ₁) 上严格递增、φ(μ₁⁻)=+∞，而
  φ(λ₀) = 2μ̃c₁²/(μ₁−λ₀) − 2μ̃Σ_{j≥2}c_j²/(λ₀−μ_j) = 1 − 2μ̃Σ_{j≥2}c_j²/(λ₀−μ_j) ≤ 1，

**引理 2（角度界）**。记 ‖u_⊥‖ := (‖u_c‖²−c₁²)^{1/2}，θ := ∠(v,ψ₁)。若
  **κ := 2μ̃c₁²/γ < 1**，
则
  **tan θ ≤ 2μ̃·c₁·‖u_⊥‖ / (γ − 2μ̃c₁²)**。

## 6. 跨窗：N_c 跳变的严格夹逼与全局唯一性的真实失效

**命题 6.1（两侧 Rayleigh 夹逼，严格）**。设 w、v 分别是 M(N_c)、M(N_c+1) 的顶向量，u := (2N_c+1)^{−1/2}。则
  2μ̃·u·v_{N_c}·(2⟨u_c^{(N_c)},v⟩ + u·v_{N_c}) ≤ λ₁(N_c) − λ₁(N_c+1) ≤ 2μ̃·u·w_{N_c}·(2⟨u_c^{(N_c)},w⟩ + u·w_{N_c})。

## 7. 诚实边界

（本节与 `p4d_coulomb_uniqueness.py` docstring 的 H1–H6 **编号一致**；v0.1 里 .md 有 H1–H5、.py 只有 H1–H4 且同一文件两处 (H4) 互相打架，已统一——reviewer DOWNGRADE 8。）

- **(H1) 六常数联合包络的瓶颈分析（2026-09-15 测量订正）**

  **原认识**：γ 区间化需要 2–3× 更紧的包络，是新工作。

  **测量订正**（numerical-evidence，`probe_gamma_feasibility{,4}.py`）：
  - **γ 侧不是瓶颈**：损失 100% 在 α（Cholesky-deflation + Weyl 尾巴）侧，μ 侧一分不丢。用 Na=560（vs 基线 70）可清过所有 binding 锚点（gam_cert/gam=0.9578 vs 要求 0.9269），是 **Na³ 算力问题**，不是结构障碍。Richardson 外推 + 区间算术可进一步收紧（见 P4_commutator_trace_bound 机制 B 修复）。

  - **真瓶颈是 c₁**：弹性 **−1.47…−1.58**（最大杠杆） vs γ 的 +1.00。六常数 (gam, c1, up, q1, b, m) 共享预算，过 γ(Na=560) 后剩余只有 **1.16%**（λ=0.5, ϖ̄=13.5）/ 1.64%（λ=0.4, ϖ̄=51.2）/ 11.79%（λ=0.7, ϖ̄=4.56）统一相对宽度，给其余五常数。而 c₁ = |⟨u_c, ψ₁⟩| 需要顶本征向量 ψ₁=v/u 的**逐分量上界**。

  - **c₁ 瓶颈的根源**（`probe_c1_weight_profile.py`）：95% 的 c₁ 贡献来自 **n < 10–70**（N95，取决于 ϖ̄）的小窗口，而现有 v 上界（V^{CT2}）在 n=0 处松弛 **1.92–2.00×**，小 n 窗口平均 1.81–1.88×。要让 c1_UB/c1_true ≤ 1.05（预算乘数 ~1.07，可闭合），需要在 n<N95 处收紧到 ~1.03×（shrink_ratio 0.51–0.54，几乎腰斩）。

  **具体方向**：
  1. **分段构造**（优先）：n<N95 用 Cauchy–Schwarz 或更强的局部界（已知在小 n 处紧，~1.18× @ϖ=2，`P4_lemmaC_final_status.md` Attempt #4），n≥N95 继续用 V^{CT2}（贡献只有 5%）。
  2. **小 n Rayleigh 试探**：用更接近真实 v 廓形的试探向量（如 `u_n·exp(−α·n)`，α 从 v 的拟合衰减率反推）。
