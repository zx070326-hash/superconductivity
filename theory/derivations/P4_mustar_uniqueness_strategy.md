## 0. 两种"唯一性/极值"：精确陈述（任务第 1 项）

库仑赝势进来后，临界束（`P4D_coulomb_operator.md` §1，逐字核对）为
> **M(ϖ̄,μ̃,N_c) := 𝔎_ph(ϖ̄) − μ̃·𝔎_c(N_c)**，　𝔎_c = 2\|u_c⟩⟨u_c\|，u_c[n]=(2n+1)^{−1/2}·1_{n<N_c}（秩一、半正定），
> μ̃ := μ\*/λ，　N_c = ⌊ω_c/2πT⌋ = ⌊r·ϖ̄⌋，　r := ω_c/⟨ω⟩（**r=3 为物理库仑截断**），
> T_c 边界：λ·λ₁(M) = 1。

"μ\*>0 的唯一性/极值"实际是**两个不同的命题**，文献与本仓库都把它们并称为"Conjecture 2 / 定理 2 的库仑推广"，必须分清：

**（I）T_c 唯一性（固定谱 P，Conjecture 2 的推广）。**
*猜想 U-C.* 对固定 λ,μ\*,P 与截断 r，映射 T ↦ λ₁(M(T)) 严格递减，从而 λ·λ₁(M(T))=1 至多一根，T_c(λ,μ\*,P) 良定义。
— μ\*=0 时这**已由 `P4_uniqueness_strategy.md` 用锥不变性完整证明**（定理 1(b)）。μ\*>0 的现状：`P4D_coulomb_uniqueness.md` 只证到**窗内**（固定 N_c）、且 μ̃ < inf_W μ̃\_\*(ϖ̄,N_c)；**跨窗在 r=3 处真实失效**（§2.1），故一般只能取 T_c:=sup。

**（II）Einstein 极值刚性（可变谱 P，定理 2 的推广）。**
记 ϖ_rms:=√⟨ω²⟩/2πT，Q(P):=λ₁(𝔎(P,T)−μ̃𝔎_c)，Q(E):=λ₁(ℌ(ϖ_rms)−μ̃𝔎_c)。
*猜想 U-E（界半句）.* Q(P) ≤ Q(E)：固定 λ,⟨ω²⟩,μ\*,r，Einstein 单频谱使库仑下的 T_c 极大。
*猜想 U-E-刚（严格半句）.* 等号 ⟺ P 为点质量。
— μ\*=0 时**已由定理 2 用核级 Jensen + 单指标推论 A′ 完整证明**（等号 ⟺ 点质量）。μ\*>0 的现状：`P4D_coulomb_extremal_threshold.md` 的**定理 CE** 证到 μ̃ < μ̃\_\*^{CE}(P,T,N_c) 时 Q(P) ≤ Q(E)（且 <）。

**⚠ 一条必须澄清的承重措辞（对照 `P4_main_theorems.md` §2 推论 (v)）。** 推论 (v) 写"定理 2 的上界对库仑束逐字成立（𝔎_c⪰0 算子序）"。这句话为真，但它给的是
> λ₁(M_P) = λ₁(A_P − μ̃𝔎_c) ≤ λ₁(A_P) ≤ h(ϖ_rms)　（**μ\*=0 的 Einstein 值**），

即"束顶本征值 ≤ **μ\*=0** 的 Einstein 上界"——这是**免费**的（𝔎_c⪰0 ⟹ M_P⪯A_P，加定理 2）。它**不是**猜想 U-E 的 Q(P)≤Q(E)（两侧都在 μ\*>0）：把同一个半正定 μ̃𝔎_c 从两个不同算子里减去，**不保持** λ₁ 的序（顶本征向量不同、不对易）。探针 §7(E) 直接印出这条区别：`free≤hE` 恒真，而 `Q(P)≤Q(E)` 才是要证的非平凡命题。**这正是需要另立定理 CE 的原因**，也是 v0.1 文档里最容易被夸大的一处。

## 2. 简并 / 双根发生在哪里（任务第 2 项）

μ\*>0 有**两类**不同的简并，机制完全不同，必须分开：

### 2.1 跨窗 r=3 双根（真实特征，非证明缺口）

沿物理阶梯 N_c(ϖ̄)=⌊rϖ̄⌋，λ₁(M(T)) 在每个 N_c 跳变处**不连续**；小窗口（r 小）时是**下跳**。r=3 时下跳给出显式非唯一 λ-区间（`P4D_coulomb_uniqueness.md` §6，逐字核对 + 本文探针独立复现 + mpmath 抽验）：

> **λ=1、μ̃=0.10、r=3、ϖ̄ 跨过 N_c: 5→6（ϖ̄≈2.000）**：λ₁(M) 从 >1 下跳到 **0.99888**（λ=1 自身双根）。
> mpmath dps=30、N=80：Nc=5 → λ₁=1.0073959，Nc=6 → λ₁=**0.99888135**（与源文件 0.998882 逐位符）。
> float64 N=400（探针 §7(B)）：ϖ̄=1.995(Nc=5)→1.005132，ϖ̄=2.000(Nc=6)→**0.998882**。

**机制**：这是映射 T↦N_c(T)=⌊ω_c/2πT⌋ 的**阶梯不连续**，不是任何单个算子的本征值简并。跳变两侧是**两个不同的**算子 M(N_c) 与 M(N_c+1)，各自的 λ₁ 都单重、顶本征向量各自良定义——**跳的是数值，不是简并**。
**⟹ 这里 Perron–Frobenius / 不可约性无能为力**：两侧算子都不可约、λ₁ 都单重，问题不在算子结构而在 N_c(T) 的离散化。诚实结论（`P4D_coulomb_uniqueness.md` (H2)、`P4D_coulomb_operator.md` Layer 1）：跨窗唯一性需对 r 的正则性充分条件（数值上 r≥5 似乎够），否则 **T_c 必须以 sup 定义**。r=3 的双根是阶梯模型的真实物理，不是缺陷。

### 2.2 窗内近交叉 κ≥1 双根（真正的"未证带"）

窗内（固定 N_c）的失效机制完全不同，来自**近交叉**（`P4D_coulomb_uniqueness.md` §5，逐字核对）：
- 控制参数 **κ := 2μ̃c₁²/γ**，c₁:=⟨u_c,ψ₁⟩，γ:=μ₁(A)−μ₂(A)。
- 秩一负扰动把 λ₁(M) 从 μ₁(A) 往下压；当 2μ̃c₁² ≈ γ（κ≈1）时，λ₁(M) 被压到 A 的第二本征值 μ₂(A) 附近，**λ₁(M) 与 λ₂(M) 近简并**，顶本征向量近似翻转为 ψ₂。
- 已知窗内反例：N_c=4、ϖ̄≈0.74、μ̃∈[0.322,0.334]，κ(0.33)=2.05，λ₁(M)−μ₂(A)≈4.1e−5。
**⟹ 这里才是 μ\*>0 特有的、"算子层面"的简并**；也正是任务设想 PF 可能有用的地方。§4 给出否定评估：M 在此处并非 PF-正的。

## 3. "锥 / 单指标 k=1"机制为何失效（μ\*=0 vs μ\*>0 对照）

### 3.1 μ\*=0 的机制（回顾，**不重证**）
定理 2 的刚性引擎（`P4_main_theorems.md` §1-2、`P4_uniqueness_strategy.md` §3.A；Explore 子agent逐行核对）：
1. **推论 B′（半群保锥）**：F 非增 ⟹ 𝒪[F] 在阶梯基下 Metzler ⟹ e^{t𝒪[F]}C⊂C（C={v≥0 且非增}）⟹ 顶本征空间 **E₁∩C≠{0}**。
2. 取 v∈E₁∩C，Rayleigh 于较大核一侧 + **单指标推论 A′** 于差核：
   ⟨v,𝒪[d]v⟩ ≥ a_{L₀}²·d(1) > 0（只要 d(1)>0），因为 d≥0 逐点使整个二次型 ≥0、无相消，剩下的 k=1 对角项 Q_{LL}(δ₁)≥u_0²=1=𝒪[d]_00 的贡献冲不掉。
3. **关键**：整套论证**只需 E₁∩C≠{0}，不需要 λ₁(A) 单重、不需要 Krein–Rutman、不需要 Hellmann–Feynman**（`P4_uniqueness_strategy.md` §3 注 (i)、(iv) 四处明写）。这就是任务简报说的"PF 对 μ\*=0 是不必要的"。

### 3.2 μ\*>0 三条正性结构全部失效
库仑束 M=A−μ̃𝔎_c 破坏了上面第 1 步赖以成立的两种正性；且自然的备选也被证伪：

**(a) 锥 C 不变性（非负 + 非增；阶梯基 Kamke 正性）—— 定量死亡。**
广义引理 B（`P4D_coulomb_uniqueness.md` 命题 2.1）：M 在阶梯基 Metzler ⟺ μ̃ ≤ μ_Metz(ϖ̄,N_c) := min_{L≠L′,W^c>0} W^F_{L,L′}/W^c_{L,L′}。定量 **μ_Metz ~ ϖ̄²/N_c³**（ϖ̄=1、N_c=10 给 1.5e−3；N_c=40 给 2.7e−5），比物理 μ̃∈[0.04,0.33] **低 2–4 个量级**。⟹ 锥 C 不变性在 μ\*>0 下不可救。

**(b) 正卦限不变性（标准基 Metzler：off-diag ≥ 0）—— 物理锚点上多数失效。**
标准基 Metzler（比 (a) 弱）阈值 ~ min_{n,m<N_c} A_{nm}/(2u_nu_m)。探针 §7(C) + 补测（本文 §7）：
- 物理锚点 (λ=1,μ\*=0.13,r=3)=(ϖ̄=2.5,N_c=7)：Metzler **成立**（PF 给 v≥0）；
- 但 (λ=1,r=10)=(ϖ̄=2.2,N_c=22)、(λ=3,r=10)=(ϖ̄=0.6,N_c=6)、(λ=0.4,r=3)=(ϖ̄=51.2,N_c=153)：Metzler **失效**（分别有 330 / 12 / 10684 个负 off-diag）。
⟹ 大 N_c（宽库仑窗）时正卦限正性也塌，PF 对 M **沉默**。

**(c) 备选"振荡锥"（Gantmacher–Krein，连续差至多一次变号）—— 被证伪。**
束顶本征向量的**变号次数恒为 2**（小 n 正、n≈N_c 处负、尾部再正），且与截断 N 无关。探针 §7(D)：(ϖ̄,N_c)∈{(1,10),(2,20),(5,40)}、μ̃=0.13、N∈{200,400,800} 全给 **sign-changes=2**。且与 §7(C) 一致：**M Metzler ⟺ 顶向量 0 变号；M 非 Metzler ⟺ 顶向量出锥（2 变号）**。故"至多一次变号"的锥是错的对象。

**小结（任务第 2 项的诚实否定答案）**：μ\*>0 时不存在一个使束顶本征向量落入其中的、能让单指标 A′ 直接开火的不变凸锥。单指标机制**没有锥向量可作用**——这是它失效的根本原因，不是技术困难。

## 4. Perron–Frobenius / 不可约性到底给出多少刚性（任务第 3 项，核心）

**任务设想**：PF-不可约性应是破除 μ\*>0 简并的正确工具。**诚实评估：部分对、部分错，且必须精确区分"对哪个算子"。**

### 4.1 PF 给出什么（对 A = 𝔎_ph，**必需**）
**引理 0（PF 单重性）**（`P4D_coulomb_uniqueness.md` 引理 0、`P4D_coulomb_extremal_threshold.md` 步骤 2）：A_P=𝒪[F_P] 的非对角元 = u_nu_m[F_P(\|n−m\|)+F_P(n+m+1)]，因 F_P(k)>0 对所有 k（P≠δ₀）**每个非对角元严格为正 ⟹ A 不可约 ⟹ Perron–Frobenius：λ₁(A) 单重、ψ₁>0 逐点**；再由 F_P 非增 + 推论 B′ 得 ψ₁∈C。
探针 §7(C) 逐点核验：ϖ̄∈{0.5,1,2,5}，A 的 min off-diag ∈ [7.6e−8, 7.5e−6] 全 >0，γ=μ₁−μ₂ >0，ψ₁（up to sign）min >0。
**这条在 μ\*>0 是"真实的假设增量"**（`P4D_coulomb_uniqueness.md` (H4) 明记）：μ\*=0 的证明**刻意避开了** λ₁ 单重（§3.1 第 3 点），而 μ\*>0 的秩一预解式约化（引理 1）与 Hellmann–Feynman（引理 4）**同时需要 ψ₁ 唯一** ⟹ 必须重新引入 PF。**⟹ 任务直觉"PF 是 μ\*>0 的正确工具"在这个精确意义上成立**：PF 是 μ\*=0 不需要、μ\*>0 却必需的新地基。

### 4.2 PF 不给出什么（对 M，**不是破简并工具**）
**关键区分：不可约性 ≠ PF 可用性。** PF 定理要求算子（在合适基下）**非负**（Metzler/正性），而不仅仅是不可约（图连通 / 非零模式满）。探针 §7(C) 显示：
- M=A−μ̃𝔎_c 在**所有**测过的情形都是**图不可约的**（off-diag 模式满、稠密）；
- 但 M 在物理 μ̃ 多数情形**非 Metzler**（有负 off-diag，§3.2(b)）。
⟹ **M 图不可约但不满足 PF 的符号前提**，PF 对 M 沉默：既不能断言 λ₁(M) 单重，也不能断言其顶向量正。§2.2 的近交叉简并（λ₁(M)≈λ₂(M)）恰恰发生在这个 PF 失效的区域。
**⟹ 任务设想"PF-不可约性破除 r=3 双根 / 近交叉简并"不成立**：
- 跨窗 r=3 双根（§2.1）：两侧算子各自 PF 良好、简并来自 N_c(T) 离散化，PF 无关；
- 窗内近交叉（§2.2）：M 非 PF-正，PF 无入手点。
真正破简并的是**秩一预解式微扰（解析、久期方程）**，且**只在阈值 μ̃<μ̃\_\* 以下**有效——不是 PF、不是任何正性方法。在真正的简并区（κ≥1 或跨窗），**没有**正性方法存活（§3.2 三条全塌）。

### 4.3 一句话结论
> PF-不可约性在 μ\*>0 的作用是**为无扰声子算子 A 提供 λ₁ 单重 + ψ₁∈C 的地基**（引理 0，μ\*=0 免掉、μ\*>0 必需）；它**不是**束 M 的破简并/刚性工具（M 丢失 PF 的符号前提）。破简并靠秩一预解式阈值，且该阈值以上（近交叉、跨窗）**目前无任何正性论证**——这是本问题的硬核。

## 5. 引理骨架（可行路线 + 关键开放引理）

以下 A 段是**已在 P4D 文件中落地**的路线（本文件只归并、不重证）；B 段是**真正开放的关键引理**。

### 5.A 已落地（μ̃ < μ̃\_\* 下可证，(H1)–(H6) 边界内）
- **引理 0（PF 单重性）**：A 非对角元 >0 ⟹ λ₁(A) 单重、ψ₁>0∈C、c₁=⟨u_c,ψ₁⟩>0。*状态*：有限 N 解析（PF）；N→∞ 需紧性/不可约性延拓（(H5) 开放）。
- **引理 1（秩一久期约化）**：κ:=2μ̃c₁²/γ<1 ⟹ λ:=λ₁(M) 是 φ(λ)=2μ̃Σ_j c_j²/(μ_j−λ)=1 在 (μ₂,μ₁) 内唯一根，v=(A−λ)^{−1}u_c，μ₁−λ≤2μ̃c₁²。*状态*：解析（初等）。
- **引理 2（角度界）**：κ<1 ⟹ tanθ ≤ 2μ̃c₁‖u_⊥‖/(γ−2μ̃c₁²)，θ:=∠(v,ψ₁)。*状态*：解析。
- **引理 3（鲁棒化推论 A′）**：⟨v̂,𝒪[d]v̂⟩ ≥ cos²θ[q₁−2b·tanθ−m·tan²θ]，q₁:=⟨ψ₁,𝒪[d]ψ₁⟩>0（推论 A′ + ψ₁∈C + d(1)>0）。右端 >0 ⟺ tanθ<𝔱_max。*状态*：解析。
- **引理 4（Hellmann–Feynman）**：窗内 T∂_Tλ₁(M)=−⟨v̂,𝒪[f]v̂⟩（引理 1 单重性合法）。*状态*：解析。
- **定理（U-C 窗内）/ 定理 CE（U-E 界半句）**：μ̃ < μ̃\_\*(=𝔱γ/(2c₁‖u_⊥‖+2𝔱c₁²)) ⟹ 结论成立且严格。11 个物理锚点全部 PROVED（float64 高估、余量最紧 1.079）。*状态*：解析链 + 六常数 float64（(H1) 待区间化，承重量 γ、c₁）。

### 5.B 关键开放引理（本策略的真正贡献：指认硬核）

**开放引理 L\*（阈值到临界值的抬升）.** 存在与物理锚点集合不交的判据，使得 U-C/U-E 在 **μ̃\_\* < μ̃ < μ̃_crit** 的"未证带"内仍成立（(H3)：该带因子 ~1.4–3，已知窗内反例 §2.2 恰落其外沿，min μ̃_crit/μ̃\_\*=1.4025）。
*为什么难*：
1. 引理 1–3 全在 **κ<1** 下有效；未证带正是 κ 逼近并越过 1 的区，久期方程的"顶根落在 (μ₂,μ₁) 内"不再自动（`P4D_coulomb_uniqueness.md` 引理 1 的反例：u_c∈span{ψ₁} 时根塌到 μ₂）。
2. 需要**定量控制 c₂=⟨u_c,ψ₂⟩** 与 λ₁(M) 对 μ₂(A) 的近交叉——即 A 的**第二**本征向量结构，而 PF 只管第一。网格上 min\|c₂\|=1.93e−3 恰在反例格取到。
3. **正性全塌**（§3.2）：无 Rayleigh-on-cone 的软论证可用，只能走"近交叉的解析刻画"（待办：给出 κ(ϖ̄,N_c)≥1 区域的闭式，证其与物理锚点不交，`P4D_coulomb_uniqueness.md` §8 待办 5）。

**开放引理 L\*\*（多原子 P 的极值刚性）.** 定理 CE 目前只对**单原子 Einstein 核** A_P=ℌ(ϖ̄) 逐字（(H6)）；姊妹探针在 **P=0.8δ(0.3s)+0.2δ(4.0s)、N_c∈[5,12]、μ̃≈0.26** 找到真实的**窗内非单调**。μ̃=0.26 正是 λ=0.5、μ\*=0.13 锚点的值 ⟹ **多原子极值刚性在物理 μ̃ 可能真的失效**，L\*\* 需先在多原子 A_P 上重算六常数，判断 μ̃\_\*^{CE} 是否仍正确排除该 P。

**真实负结果（非开放引理，是模型特征）.**
- 跨窗 r=3 双根（§2.1）：T_c 唯一性在 r=3 物理区**真的**只能取 sup；PF 与任何算子论证都不能改变，除非改 r≥5 或换非阶梯截断模型。
