## 2. h↔T_c 反解的 λ³ 系数（Jacobian 推导）

由 λh(ϖ)=1、h = L + c₀ + b₁/L + b₂/L² + b₃/L³（L := ln(ω_E/2πT_c)），求 T_c 的 λ 展开
  T_c = (ω_E/2π) e^{c₀} e^{−1/λ} [1 + b₁λ + b₂^Tc λ² + b₃^Tc λ³ + O(λ⁴)]。

**方法**：置 t := λ = 1/x，把 L(t) 展成 L = 1/t + a₀ + a₁t + a₂t² + a₃t³ + O(t⁴)，代入 h(L) = 1/t 逐阶匹配 t⁰,t¹,t²,t³ 求 a₀,a₁,a₂,a₃（sympy 符号求解，`theory/notes/_scratch_ir/inv2.py`），得
  a₀ = −c₀，a₁ = −b₁，a₂ = −b₁c₀ − b₂，a₃ = −b₁² − b₁c₀² − 2b₂c₀ − b₃。
再把「bracket」:= e^{−L+1/t−c₀} 按 t 展开（同一脚本），系数为
  [t⁰]=1，[t¹]=b₁，[t²]=b₁²/2+b₁c₀+b₂ (=b₂^Tc，与既有推导逐字一致)，
  **[t³] = b₁³/6 + b₁²c₀ + b₁² + b₁b₂ + b₁c₀² + 2b₂c₀ + b₃ =: b₃^Tc。**

**交叉核验**：(a) 该 λ²系数公式代回给出 b₂^Tc = −0.0967183971…，与 `p4_moment_tower.py` 已交付值逐位一致；(b) 数值反解——对 λ=0.03,0.02,0.015,0.01 数值求根 h(L)=1/λ、算 bracket、扣除已知的 1、b₁λ、b₂^Tcλ² 项、除以 λ³、线性外推 λ→0——给出 0.054935，与闭式公式 0.054970 相差 3.5e-5（属外推截断误差，公式本身是精确级数系数、数值反解只是独立佐证，非替代）。

## 3. γ-依赖：b₃ 携带 γ，b₃^Tc 不携带（与 b₂/b₂^Tc 同型）

符号展开（`theory/notes/_scratch_ir/gamma_dep_check2.py`，把 C = γ+ln4−½ 代入 b₃ = 2κ₃−4κ₂C+2κ₁(C²−b₁) 并按 γ 幂次收集）：
```
b₃ = [γ⁰ 项] + γ¹·(4κ₁ln4 − 2κ₁ − 4κ₂) + γ²·(2κ₁)
```
γ² 系数是 2κ₁ = b₁ = 0.358407… ≠ 0，故 **b₃ 显式携带 γ（甚至到 γ² 阶）**，与 b₂ 只到 γ¹ 阶不同——阶数随 tower 深度增长，因为 C = γ+ln4−½ 在 Λ→ln ϖ 重展开中会出现到 C^{n-1} 的幂次。

物理量 b₃^Tc 则完全 γ-free（`theory/notes/_scratch_ir/gamma_dep_check.py` 符号验证）：
```
b₃^Tc = (4/3)κ₁³ − 4κ₁² + 4κ₁κ₂ + 2κ₁ − 4κ₂ + 2κ₃
```
是 κ₁,κ₂,κ₃ 的纯有理系数多项式，γ 和 ln4 精确抵消——与 b₂^Tc = 2κ₂−b₁+b₁²/2 的抵消模式完全一致（h↔T_c 的 Jacobian 每阶都恰好吸收 c₀ 的 γ-依赖）。门脚本中数值核验 |b₃^Tc − (4κ₁³/3−4κ₁²+4κ₁κ₂+2κ₁−4κ₂+2κ₃)| < 1e-45。

**双精度一致落空**：无一在任一精度下找到关系，且两个精度间没有「假象消失」的情况（不同于 `p4_moment_tower.py` 记录的 κ₂ dps=45 七基假象——此处若某精度出现虚假关系、另一精度会消失，本次两个精度从头到尾都是 None，说明连虚假关系的噪声都没有出现，是更干净的空结果）。

**严格性边界（务必如实）**：
- PSLQ 空结果**不是**不在 ℚ[π²,π⁴,π⁶] 中的证明，只是双精度、maxcoeff=10⁷ 范围内的证据。
- **权分级启发**（同 b₂ 的论证 (c)）：κ_n 预期是超越权 n+1 的周期；κ₃ 是 weight-4（偶权！），故权分级本身**不排斥** κ₃ ∈ ℚ[π⁴] 之类——这与 κ₂（weight-3，奇权，天然排斥于 ℚ[π²]）不同。κ₃ 的非-ℚ[π²,π⁴,π⁶] 成员性**完全依赖数值 PSLQ 证据**，没有权宇称论证支持，比 κ₂ 的判决弱。
- b₃ 的 γ-依赖（§3）意味着 b₃ ∉ ℚ[π²] 这一结论若要从「γ 的 γ²系数非零」论证，仍**条件于 γ 的超越性/无理性等公开算术问题**（与 b₂ 的判决同一障碍，且因为到 γ² 阶更深）。
- b₃^Tc 是 γ-free 的物理量，其非-ℚ[π²,π⁴,π⁶] 成员性**不悬于 γ 公开问题**，是本节最干净的物理判决——但同样只是 PSLQ 证据级、不是证明。

**结论**：weight-4 的 tower 机制无阻碍地延伸（求积、β/b 重排、Jacobian 反解全部干净给出数值），κ₃/β₃/b₃/b₃^Tc 在双精度 PSLQ 下皆与 {1,π²,π⁴,π⁶} 无关系，与「每阶周期权递增、偶权也未必落回 ℚ[π²] 家族」的图景一致；但 weight-4 是偶权，缺少 κ₂ 那种权宇称的先验排斥论证，判决严格性弱于 b₂ 一档。
