## 2. h↔T_c 反解的 λ³ 系数（Jacobian 推导，未改动，与 v1 相同）

由 λh(ϖ)=1、h = L + c₀ + b₁/L + b₂/L² + b₃/L³（L := ln(ω_E/2πT_c)），求 T_c 的 λ 展开
  T_c = (ω_E/2π) e^{c₀} e^{−1/λ} [1 + b₁λ + b₂^Tc λ² + b₃^Tc λ³ + O(λ⁴)]。

**方法**：置 t := λ = 1/x，把 L(t) 展成 L = 1/t + a₀ + a₁t + a₂t² + a₃t³ + O(t⁴)，代入 h(L) = 1/t 逐阶匹配 t⁰,t¹,t²,t³ 求 a₀,a₁,a₂,a₃（sympy 符号求解，`theory/notes/_scratch_ir/inv2.py`），得
  a₀ = −c₀，a₁ = −b₁，a₂ = −b₁c₀ − b₂，a₃ = −b₁² − b₁c₀² − 2b₂c₀ − b₃。
再把「bracket」:= e^{−L+1/t−c₀} 按 t 展开（同一脚本），系数为
  [t⁰]=1，[t¹]=b₁，[t²]=b₁²/2+b₁c₀+b₂ (=b₂^Tc，与既有推导逐字一致)，
  **[t³] = b₁³/6 + b₁²c₀ + b₁² + b₁b₂ + b₁c₀² + 2b₂c₀ + b₃ =: b₃^Tc。**

这一步是纯代数恒等式（不依赖 κ₃ 的数值），v1 交付时即已核验正确，此处不受 §0 的 bug 影响；只是代入 §1 订正后的 b₃ 数值，b₃^Tc 相应改变。

## 3. γ-依赖：b₃ 携带 γ，b₃^Tc 不携带（符号恒等式，未改动）

符号展开（`theory/notes/_scratch_ir/gamma_dep_check2.py`，把 C = γ+ln4−½ 代入 b₃ = 2κ₃−4κ₂C+2κ₁(C²−b₁) 并按 γ 幂次收集）：
```
b₃ = [γ⁰ 项] + γ¹·(4κ₁ln4 − 2κ₁ − 4κ₂) + γ²·(2κ₁)
```
γ² 系数是 2κ₁ = b₁ = 0.358407… ≠ 0（不依赖 κ₃，故此结论不受 §0 bug 影响），故 **b₃ 显式携带 γ（甚至到 γ² 阶）**，与 b₂ 只到 γ¹ 阶不同。

物理量 b₃^Tc 则完全 γ-free（`theory/notes/_scratch_ir/gamma_dep_check.py` 符号验证，同样是关于 κ_j 符号的恒等式，不依赖 κ₃ 数值）：
```
b₃^Tc = (4/3)κ₁³ − 4κ₁² + 4κ₁κ₂ + 2κ₁ − 4κ₂ + 2κ₃
```
是 κ₁,κ₂,κ₃ 的纯有理系数多项式，γ 和 ln4 精确抵消。代入订正后的 κ₃ 数值仍然满足此恒等式（门脚本数值核验）。
