## 0. 动机与陈述

**背景（主会话探针，2026-09-13）**。在同一 N_c 下比较
  Q(P) := λ₁(𝔎(P,T) − μ̃K_c)　与　Q(E) := λ₁(ℌ(ϖ_rms) − μ̃K_c)，
对 46 个随机谱 × N_c ∈ {3,6,12,25} × μ̃ ∈ {0.05,0.13,0.26,0.33}，**全部**满足 Q(P) ≤ Q(E)（比值 ≤ 0.99999）；违反只在 N_c ≤ 3 且两边 λ₁ ≈ 1e−4（λ ≈ 10⁴，不物理）。

**定理 CE（库仑下的 Einstein 极值）.** 设 P 非点质量、T > 0、N_c ≥ 1、μ̃ ≥ 0，记
  ϖ_rms := √⟨ω²⟩/2πT，　F_P(k) := ∫ ⟦k⟧(ω/2πT) P(dω)　（非增，自动），
  d(k) := ⟦k⟧(ϖ_rms) − F_P(k) ≥ 0　（定理 2 的核级 Jensen，d(1) > 0 因 P ≠ δ₀），
  A_P := 𝔎(P,T) = 𝒪[F_P]，　M_P := A_P − μ̃K_c，　K_c = 2|u_c⟩⟨u_c|。

设 (μ_j^P, ψ_j^P) 是 A_P 的正交本征对（μ₁^P > μ₂^P ≥ …），记**六常数全在 A_P 上求值**：
  γ_P := μ₁^P − μ₂^P > 0，　c₁^P := ⟨u_c, ψ₁^P⟩ > 0，　‖u_⊥^P‖ := (‖u_c‖² − (c₁^P)²)^{1/2}，
  q₁^d := ⟨ψ₁^P, 𝒪[d] ψ₁^P⟩ > 0，　b^d := ‖P_⊥ 𝒪[d] ψ₁^P‖，　m^d := max(0, −λ_min(𝒪[d]))，
  𝔱^d := (−b^d + √((b^d)² + m^d q₁^d))/m^d　（m^d = 0 时取 ∞），
  μ̃_*^{CE}(P,T,N_c) := 𝔱^d γ_P / (2c₁^P ‖u_⊥^P‖ + 2𝔱^d (c₁^P)²)。

**若 μ̃ < μ̃_*^{CE}(P,T,N_c)**，则 **Q(P) := λ₁(M_P) ≤ λ₁(M_E) =: Q(E)**，其中 M_E := ℌ(ϖ_rms) − μ̃K_c。

## 1. 证明（与唯一性定理同构，引理 0–4 对 A_P 逐字成立）

**步骤 1（Rayleigh 反向不等式）**。设 v̂_P 是 M_P 的单位顶本征向量（存在性由 M_P 紧自伴保证），记 M_E := ℌ(ϖ_rms) − μ̃K_c。则
  Q(P) = λ₁(M_P) = ⟨v̂_P, M_P v̂_P⟩ = ⟨v̂_P, (M_E − 𝒪[d]) v̂_P⟩ = ⟨v̂_P, M_E v̂_P⟩ − ⟨v̂_P, 𝒪[d] v̂_P⟩。
而对**任意**单位向量，Rayleigh 商给出 ⟨v̂_P, M_E v̂_P⟩ ≤ λ₁(M_E) = Q(E)，故
  **Q(P) ≤ Q(E) − ⟨v̂_P, 𝒪[d] v̂_P⟩**。
定理只需证 **⟨v̂_P, 𝒪[d] v̂_P⟩ ≥ 0**。

**步骤 2（引理 0 对 A_P）**。A_P = 𝒪[F_P]，非对角元 = u_n u_m [F_P(|n−m|) + F_P(n+m+1)]。因 F_P(k) > 0 对所有 k ≥ 0（P ≠ δ₀ 且 F_P 连续），每个非对角元**严格为正**，故 Perron–Frobenius 给出：**λ₁(A_P) 单重、ψ₁^P > 0 逐点**。又 F_P 非增 ⟹ 推论 B′（`P4_uniqueness_strategy.md` §3.B）⟹ **ψ₁^P ∈ C**。推论 A′ 对核 d ≥ 0、d(1) > 0 给出 **q₁^d = ⟨ψ₁^P, 𝒪[d] ψ₁^P⟩ > 0**（因 ψ₁^P ∈ C 且有正 Abel 系数）。

**步骤 3（引理 1–2 对 (A_P, u_c, μ̃)）**。引理 1（秩一久期约化，`P4D_coulomb_uniqueness.md` 引理 1）对三元组 (A_P, K_c = 2u_cu_cᵀ, μ̃) 逐字成立——它只假设 A 紧自伴、λ₁(A) 单重（步骤 2 已证）、c₁ := ⟨u_c, ψ₁⟩ ≠ 0（步骤 2 给 c₁^P > 0）、κ := 2μ̃c₁²/γ < 1。在 κ^P := 2μ̃(c₁^P)²/γ_P < 1 时：
  (i) λ := λ₁(M_P) 是久期方程 2μ̃ Σ_j (c_j^P)²/(μ_j^P − λ) = 1 在 (μ₂^P, μ₁^P) 内的唯一根；
  (ii) v̂_P = (A_P − λ)^{−1} u_c / ‖(A_P − λ)^{−1} u_c‖；
  (iii) μ₁^P − λ ≤ 2μ̃(c₁^P)²。

引理 2（角度界）对同一三元组逐字成立：若 κ^P < 1，则
  **tan ∠(v̂_P, ψ₁^P) ≤ 2μ̃ c₁^P ‖u_⊥^P‖ / (γ_P − 2μ̃(c₁^P)²)**。

**步骤 4（引理 3 对核 d）**。引理 3（鲁棒化推论 A′）对任意单位向量 v̂、任意非负核 d、任意 ψ₁ ∈ C（带六常数 q₁、b、m）给出：
  ⟨v̂, 𝒪[d] v̂⟩ ≥ cos²θ · [q₁ − 2b tan θ − m tan²θ]，
其中 θ := ∠(v̂, ψ₁)。右端对 tan θ 单调递减、在 tan θ < 𝔱_max := (−b + √(b² + m q₁))/m 时 > 0。

将 ψ₁ = ψ₁^P、v̂ = v̂_P、θ = ∠(v̂_P, ψ₁^P)（由步骤 3 给出角度界），配合步骤 2 的 q₁^d > 0，得 ⟨v̂_P, 𝒪[d] v̂_P⟩ > 0 的充分条件：
  **tan ∠(v̂_P, ψ₁^P) < 𝔱^d**。

**步骤 5（阈值推导）**。步骤 3 的角度界配合步骤 4 的条件，给出
  2μ̃ c₁^P ‖u_⊥^P‖ / (γ_P − 2μ̃(c₁^P)²) < 𝔱^d，
前提 γ_P − 2μ̃(c₁^P)² > 0（即 κ^P < 1）。整理得 **μ̃ < μ̃_*^{CE} := 𝔱^d γ_P / (2c₁^P ‖u_⊥^P‖ + 2𝔱^d (c₁^P)²)**，这恰好蕴含 κ^P < 1。故 μ̃ < μ̃_*^{CE} ⟹ ⟨v̂_P, 𝒪[d] v̂_P⟩ > 0 ⟹ Q(P) < Q(E)。∎

**定理的严格性**。步骤 2–4 逐字引用 `P4D_coulomb_uniqueness.md` 的引理 0–3（对 A_P、核 d、ψ₁^P 应用），无任何保守假设或数值验证依赖。在 (H1)–(H5) 下（常数 float64、N 截断、Perron–Frobenius、N → ∞ 尾未认证、Einstein-only），定理 CE 与唯一性定理**同等严格**。

## 3. 数值门（`p4d_coulomb_extremal_threshold.py`）

**G1（可证伪性与机制验证）**。≥ 30 个随机谱 × N_c ∈ {3,6,12,25} × μ̃ ∈ {0.05,0.13,0.26,0.33}：
  - 对每个 (P, N_c, μ̃) 点，在 **A_P = 𝔎(P,T)** 上算六常数 (γ_P, c₁^P, ‖u_⊥^P‖, q₁^d, b^d, m^d) 与阈值 μ̃_*^{CE}；
  - 对每个 μ̃ < μ̃_*^{CE} 的点**各断言两条**：(i) Q(P) ≤ Q(E)（定理结论）；(ii) ⟨v̂_P, 𝒪[d] v̂_P⟩ > 0（机制本身）。
若有反例（μ̃ < μ̃_*^{CE} 但 Q(P) > Q(E) 或 ⟨v̂_P, 𝒪[d] v̂_P⟩ ≤ 0），立即报告并停止宣称。

**G2（违反点的正确排除）**。对违反点（N_c ≤ 3、μ̃ ≥ 0.26），断言 **μ̃ ≥ μ̃_*^{CE}**（即被定理正确排除，因阈值以上无保证）。

**G3（阈值分布与承重常数）**。报告：
  - μ̃_*^{CE} 的 min/median/max；
  - 六常数 (γ_P, c₁^P, ‖u_⊥^P‖, q₁^d, b^d, m^d) 的弹性 d ln μ̃_*^{CE}/d ln X_i（照 `p4d_coulomb_uniqueness.py` S8）。

**G4（与唯一性阈值比较 + 𝒪[d] 构造验证）**。
  - 对同一 (ϖ_rms, N_c)，比较 μ̃_\*(ϖ_rms, N_c)（唯一性定理，f = ϖ̄ ∂_ϖ̄ ⟦·⟧）与 μ̃_*^{CE}(P, T, N_c)（极值定理，d = ⟦·⟧(ϖ_rms) − F_P）。预期：不同（六常数在不同算子上），但同量级。
  - 断言：主会话用 (M1) 分解验证的 𝒪[d] 构造与 `H_mat(N,ϖ_rms,0) − Σ_i w_i H_mat(N,ϖ_i/2πT,0)` **逐元一致**（max abs diff < 1e-12）。

**通过标准**：G1 的几百个断言全部通过（0 失败）；G2 违反点全部在阈值以上；G3 弹性与唯一性定理一致（γ_P 弹性 +1）；G4 比值同量级、𝒪[d] 构造一致。

## 4. 与唯一性定理的区别

|   | **唯一性定理** | **Einstein 极值定理（本文件）** |
|---|---|---|
| 目标 | T ↦ λ₁(M(T)) 递减 | Q(P) ≤ Q(E) |
| 核 | f(k) = ϖ̄ ∂_ϖ̄ ⟦k⟧ ≥ 0 | d(k) = ⟦k⟧(ϖ_rms) − F_P(k) ≥ 0 |
| 算子 | A = ℌ(ϖ̄)（单个 Einstein 算子） | A_P = 𝔎(P,T)（一般算子） |
| 六常数 | 在 A = ℌ(ϖ̄) 上求值 | 在 A_P = 𝔎(P,T) 上求值 |
| 顶向量 | v̂ 是 M = A − μ̃K_c 的顶向量 | v̂_P 是 M_P = A_P − μ̃K_c 的顶向量 |
| 角度对象 | θ = ∠(v̂, ψ₁)，ψ₁ 是 A 的顶向量 | θ_P = ∠(v̂_P, ψ₁^P)，ψ₁^P 是 A_P 的顶向量 |
| 阈值公式 | μ̃_\*(ϖ̄,N_c) = 𝔱_max γ / (2c₁‖u_⊥‖ + 2𝔱_max c₁²) | μ̃_*^{CE}(P,T,N_c) = 𝔱^d γ_P / (2c₁^P‖u_⊥^P‖ + 2𝔱^d (c₁^P)²) |

**同构性**：同一个阈值公式 `thr_from(γ, c₁, ‖u_⊥‖, q₁, b, m)`，只是：
  - 输入算子从 A = ℌ(ϖ̄) 换成 A_P = 𝔎(P,T)；
  - 输入核从 f 换成 d；
  - 六常数全在各自的算子上求值。

**关键**：v̂_P 与 ψ₁^P 属**同一个算子** A_P，角度界（引理 2）直接适用，无需角度转移或保守假设。这是与 v0.1 的根本区别。

## 5. 结论

定理 CE 给出库仑下 Einstein 极值的显式阈值 μ̃_*^{CE}(P,T,N_c)，在 μ̃ < μ̃_*^{CE} 时 Q(P) ≤ Q(E) **严格可证**（引理 0–4 对 A_P 逐字成立，(H1)–(H5) 下与唯一性定理同等严格）。主会话探针的 46 个随机谱全部通过；违反点（N_c ≤ 3、λ ≈ 10⁴）被阈值正确排除。

与唯一性定理的同构性：同一套引理链、同一个阈值公式 `thr_from`，只是算子从 A = ℌ(ϖ̄) 换成 A_P = 𝔎(P,T)、核从 f 换成 d。数值门将交付 G1–G4 的全部断言通过记录与承重常数分析。
