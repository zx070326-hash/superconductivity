## 1. 记号与设定（继承上游）

- **谱测度** P∈𝒫：ℝ₊ 上概率测度，⟨ω²⟩:=∫ω²P(dω)<∞，P≠δ₀。
- **无量纲频率** ϖ:=ω/2πT，ϖ̄:=⟨ω⟩/2πT。
- **Einstein 算子** ℌ(ϖ):=𝒪[⟦·⟧(ϖ)]，其中 ⟦k⟧(ϖ):=ϖ²/(k²+ϖ²)，核-通用算子 𝒪[f]:=−L1[f]+L2[f]+L3[f]（见 P4_main_theorems.md §0）。
- **Einstein 函数** h(ϖ):=λ₁(ℌ(ϖ))；一般算子 𝔎(P,T)=𝒪[F_T]，F_T(k):=∫⟦k⟧(ω/2πT)P(dω)；𝔨(P,T):=λ₁(𝔎(P,T))。
- **谱形参数**：ω=⟨ω⟩(1+ξ)，⟨ξ⟩=0，σ²:=⟨ξ²⟩（相对方差），γ₃:=⟨ξ³⟩/σ³（偏度）。
- **有限截断** ℌ^(N)(ϖ)=P_N ℌ(ϖ) P_N（前 N 个 Matsubara 频率的主子块压缩），𝔥^(N)(ϖ):=λ₁(ℌ^(N)(ϖ))；𝔨^(N)(P,T) 类似定义。

**关键结构**：ℌ^(N)(ϖ) 的矩阵元**只依赖 n,m,ϖ，不依赖截断维数 N**（见 P4_interchange_uniformity.md §1）⟹ ℌ^(N) 是 ℌ 的**嵌套压缩**，这是换序一致性的基础。

## 2. 定理 S（谱形展开，真算子）

**定理 S（强耦合谱形展开，μ*=0）.** 设 P∈𝒫 紧支、满足定形族假设（|ξ|≤σ·η_max、有界峭度 U6），ϖ̄∈[a,b]⊂(0,∞) 其中 a>0。则存在函数 κ(ϖ̄)、c₃(ϖ̄) 与余项常数 K_*(ϖ̄)，使得真算子满足

  **| 𝔨(P,T) − h(ϖ̄)[1 + ½κ(ϖ̄)σ² + c₃(ϖ̄)γ₃σ³] | ≤ K_*(ϖ̄) σ⁴**，　　　(S.1)

其中

- **κ(ϖ̄) = lim_{N→∞} κ_N(ϖ̄)**，κ_N(ϖ̄) = ϖ̄²⟨v_N|ℌ^(N)″(ϖ̄)|v_N⟩ / 𝔥^(N)(ϖ̄)，v_N 为 ℌ^(N)(ϖ̄) 的单一顶本征向量；
- **c₃(ϖ̄) = lim_{N→∞} c_{3,N}(ϖ̄)**，c_{3,N}(ϖ̄) = (1/6)ϖ̄³⟨v_N|ℌ^(N)‴(ϖ̄)|v_N⟩ / 𝔥^(N)(ϖ̄)；
- **K_*(ϖ̄) = ϖ̄⁴B₄^∞η_max²/24 + ½ϖ̄⁴(B₂^∞)²/g_alt(ϖ̄)**，B₂^∞、B₄^∞ 为 ℌ 的二阶、四阶 ϖ-导数的算子范数上界（认证），g_alt(ϖ̄)=μ₂(ϖ̄)−α(ϖ̄)>0 为认证谱隙下界。

**证明形态**：**混合**（解析论证 + 计算机辅助证书）。
- **解析部分**（P4_interchange_uniformity.md §2–§3）：
  1. 支柱一（算子范数收敛）：‖ℌ−ℌ^(N)‖→0 带显式尾率 ρ_N(ϖ̄)（HS 范数 + 解析 Schur 包络）；
  2. 支柱二（极限谱隙）：δ(ϖ̄)=μ(ϖ̄)−α(ϖ̄)>0（Rayleigh 下界 + Cholesky-deflation 上界）⟹ λ₁ 单一且严格孤立；
  3. 支柱三（gap 不坍缩）：Poincaré 交错 λ₂(ℌ^(N))≤λ₂(ℌ)≤α、λ₁(ℌ^(N))≥μ₂ ⟹ inf_{N≥2} gap_N(ϖ̄) ≥ g_alt(ϖ̄)>0（全严格、无 N₀、无 float64）；
  4. 组装：对每个 N，有限-N 定理（P4_rigorous_tc_bound.md §4 T5 Part 1）给 |𝔨^(N)−𝔥^(N)(…)| ≤ K_N σ⁴；由 B₂^∞、B₄^∞ 一致于 N 与 gap_N≥g_alt 得 K_N≤K_*(ϖ̄) 一致于 N；令 N→∞，由支柱一+二保证 𝔨^(N)→𝔨、𝔥^(N)→𝔥、κ_N→κ、c_{3,N}→c₃（Davis–Kahan），取极限得 (S.1)。
- **计算机辅助部分**（`p4_interchange_uniformity.py`，1668 检查）：
  1. **区间形态**（ϖ̄∈[0.2,60]）：inf_{ϖ̄∈[0.2,60]} inf_{N≥2} gap_N ≥ 0.043585（246 点几何网格 + 分段 Schur Lipschitz 包络 + Poincaré 交错，见 P4_interchange_uniformity.md §2.4 与区间扩展两段）；
  2. **节点值**（ϖ̄∈{0.3,1/√3,1,2,3,5,7,10,15,20,30,40,60}）：δ(ϖ̄)、g_alt(ϖ̄)、B₂^∞(ϖ̄)、B₄^∞(ϖ̄)、K_*(ϖ̄)、s_max(ϖ̄) 全部认证（mpmath dps≥30 + 显式舍入垫 + Cholesky SPD 判定）；
  3. **N=400 一致性检验**：worst |rem|/(K_*σ⁴)=0.139<1（非空泛），σ⁴ 率真实。

**定理有效区间**：ϖ̄∈[0.2,60]（μ*=0）；μ̃∈{0,0.1,0.13,0.26,0.33} 时分别为 [0.2,60] / [0.5391,60] / [0.6427,60] / [1.1686,60] / [1.5666,60]（见 P4_interchange_uniformity.md §3 区间扩展）。

**关键假设**（必须前置）：
- **(U6) 定形族**：|ξ|≤σ·η_max、有界峭度。矩展开的 O(σ⁴) 率**要求有界峭度**——领头被弃项 ∝⟨ξ⁴⟩=峭度·σ⁴；定形族峭度有界故 O(σ⁴)，但退化极限（质量→δ）下峭度→∞，余项退为 O(σ²)。物理上无害（真实声子谱不锐化成 δ），但定理须显式写此假设。
- **(U5) λ 上界非定理**：λ_* 的物理上界（动理学稳定，P3 §4）与 Tc 界（KAY，有定理）无共同证明基础。产品形态 = 「给定 λ 的严格 Tc 上界」+「λ 的物理上界（非严格）」两层分开写。
- **(U4) μ*=0**：KAY 全套无库仑赝势。μ*>0 的上界逐字成立（K_c⪰0 算子序），但唯一性只有窗内结果（见 P4_main_theorems.md §6）。

**与 P4-A 的关系**：P4_rigorous_tc_bound.md §2 的主命题 P4-A 给出 𝔨^(N) 的有限-N 形式展开（每个固定 N 的矩展开 + 一阶微扰）；定理 S 是 P4-A 在 N→∞ 的极限，由 P4_interchange_uniformity.md §3 的换序一致性保证这个极限合法（K_N 一致于 N）。

## 3. 推论 S.1（Tc 的展开）

**推论 S.1（Tc 对谱形的依赖）.** 在定理 S 的假设下，临界温度 T_c(λ,P) 满足

  **T_c(λ,P) = T_c^E(λ,⟨ω⟩) · [1 + a₂(λ,ϖ̄)σ² + a₃(λ,ϖ̄)γ₃σ³ + O(σ⁴)]**，　　(S1.1)

其中
- **T_c^E(λ,⟨ω⟩) := ⟨ω⟩/(2πϖ̄_E)** 为 Einstein 谱 δ_{⟨ω⟩} 的 Tc（由 λh(ϖ̄_E)=1 隐函数定义 ϖ̄_E）；
- **a₂(ϖ̄_E) = ½κ(ϖ̄_E) / L(ϖ̄_E)**；
- **a₃(ϖ̄_E) = c₃(ϖ̄_E) / L(ϖ̄_E)**；
- **L(ϖ̄) := ϖ̄h′(ϖ̄)/h(ϖ̄)** 为对数导数。

**推导**（自足，逐步）：
1. **Tc 条件与参考点**：λ𝔨(P,T_c)=1；Einstein 参考 λh(ϖ̄_E)=1（固定 λ 与 ⟨ω⟩，定义 ϖ̄_E=⟨ω⟩/2πT_c^E）。
2. **谱形展开**：由定理 S，λ𝔨(P,T) = λh(ϖ)[1 + ½κ(ϖ)σ² + c₃(ϖ)γ₃σ³] + O(σ⁴)，其中 ϖ=⟨ω⟩/2πT。
3. **关键观察**：ϖ̄ 随 T 变化，写 ϖ̄ = ϖ̄_E(1+ε)，其中 ε = ε₂σ² + ε₃γ₃σ³ + O(σ⁴)（待定）；因 δ = O(σ²)，κ(ϖ̄) 与 c₃(ϖ̄) 的 ϖ̄-修正进 O(σ⁴/σ⁵)，故在领头阶可用 κ(ϖ̄_E)、c₃(ϖ̄_E)。
4. **h 的展开**：h(ϖ̄) = h(ϖ̄_E(1+ε)) ≈ h(ϖ̄_E)[1 + L(ϖ̄_E)·ε + O(ε²)]，其中 L := ϖ̄h′/h。
5. **代入 Tc 条件**：h(ϖ̄_E)[1 + L·ε][1 + ½κσ² + c₃γ₃σ³] = h(ϖ̄_E) + O(σ⁴)。消 h(ϖ̄_E) 并展开：
   (1 + L·ε)(1 + ½κσ² + c₃γ₃σ³) = 1 + O(σ⁴)
   ⟹ L·ε + ½κσ² + c₃γ₃σ³ + L·ε·(½κσ² + …) = O(σ⁴)。
   因 ε = O(σ²)，交叉项 L·ε·σ² = O(σ⁴) 可丢。
6. **匹配系数**：σ² 阶：L·ε₂ + ½κ = 0 ⟹ ε₂ = −½κ/L；σ³ 阶：L·ε₃ + c₃ = 0 ⟹ ε₃ = −c₃/L。
7. **回到 T_c**：T_c = ⟨ω⟩/(2πϖ̄) = ⟨ω⟩/(2πϖ̄_E(1+ε)) = T_c^E·(1+ε)^{−1} ≈ T_c^E(1 − ε + O(ε²))，故
   **T_c/T_c^E = 1 − ε₂σ² − ε₃γ₃σ³ + O(σ⁴) = 1 + (½κ/L)σ² + (c₃/L)γ₃σ³ + O(σ⁴)**。

**数值检验**：用两/三原子离散谱（σ 小、已知精确 Tc）与 H_matrix 求解器比较 (S1.1) 的预测；σ→0 时 (实际−预测)/预测 按 σ⁴ 收敛。**校验点**：N=1、ϖ̄_E=1 时 h=½、L=1、κ=−1 ⟹ a₂=−½（谱展宽压低 Tc，符合物理）。见配套脚本 `p4_strong_coupling_expansion.py`。

## 4. 推论 S.2（与定理 2 的一致性）

**推论 S.2（定理 2 的 σ² 约束）.** 定理 2（Einstein 极值）断言 T_c(λ,P) ≤ T_c^E(λ,√⟨ω²⟩)，其中 ω_rms=√⟨ω²⟩=⟨ω⟩√(1+σ²)。因 T_c^E(λ,ω) 在固定 λ 下正比于 ω（h 只依赖 ω/T），故

  T_c^E(λ,ω_rms) / T_c^E(λ,⟨ω⟩) = √(1+σ²) ≈ 1 + ½σ² + O(σ⁴)。

定理 2 的严格性要求：**a₂(ϖ̄_E) ≤ ½**（对所有 λ、所有 ϖ̄_E），即 **κ(ϖ̄_E) ≤ L(ϖ̄_E)**。

**解析核验**（应做、本稿只勾勒）：
- a₂ = ½κ/L；定理 2 要求 ½κ/L ≤ ½，即 **κ ≤ L = ϖ̄h′/h**。
- **物理边界**：ϖ̄→0 时 h ≈ 𝔤(2)ϖ̄²，κ→2（P4-A 极限行为），L = ϖ̄·2ϖ̄/ϖ̄² = 2 ⟹ κ/L→1，即 a₂→½ **饱和定理 2 的界**（与定理 1(c) 在 λ→∞ 被饱和一致，都是小 ϖ̄/大 λ 渐近锐）。
- ϖ̄>1/√3 后 κ<0（N=1 变号点），L>0 恒成立 ⟹ κ<L 自动满足，余量随 ϖ̄ 增大。
- **数值核对**（配套脚本）：在 ϖ̄∈{0.1,0.3,0.5,1,2,3,5}、N=100 上验证不等式 κ≤L 逐点成立，报告余量 L−κ（应在 ϖ̄→0 趋于 0、ϖ̄>0.577 后因 κ<0 而变大）。

## 5. 推论 S.3（Allen–Dynes 对照）

**推论 S.3（与 Allen–Dynes 形状因子的对照）.** Allen–Dynes 1975 给出 Tc 的拟合式（见 P3_tc_max_pressure.md §2，Xie 2022 转录）：

  Tc = (f₁f₂ ω_log/1.20) exp[−1.04(1+λ)/(λ−μ*(1+0.62λ))]，

其中 f₂ 是形状因子：

  f₂ = {[1 + (ω̄₂/ω_log − 1)λ²] / [λ² + (1.82(1+6.3μ*)(ω̄₂/ω_log))²]}^{1/2}，

ω̄₂ 是 α²F 的二阶矩的某个组合（见 Allen–Dynes 原文 eq. (3)，本稿从 Xie 2022 二手转录）。

**小 σ 展开**（形式，待核验）：
- 设 ω̄₂/ω_log = 1 + β·σ² + O(σ⁴)（β 取决于 ω̄₂ 与 ω_log 的定义差异）；
- f₂ ≈ [1 + β·σ²·λ²]^{1/2} / [1 + (1.82…)²·(1+β·σ²)]^{1/2} ≈ 1 + (β·λ² − (1.82…)²·β)/2 · σ² + O(σ⁴)。

**对照表**（只做对照、不宣称一致）：

| 项 | 定理 S (S1.1) | Allen–Dynes f₂ 小 σ 展开（二手，待核） |
|---|---|---|
| σ² 系数 | a₂(ϖ̄_E) = ½κ/L | [需从 f₂ 闭式展开，取决于 β] |
| σ³ 项 | 有（c₃γ₃/L） | 无（f₂ 对称于谱形） |
| 机制 | 微扰论 + 矩展开 | 经验拟合 |

**诚实边界**：
- Allen–Dynes f₂ 的小 σ 展开**本稿未自己推导**，上表中 AD 侧的 σ² 系数需从原文或 Xie 2022 补全；
- f₂ 定义中的 ω̄₂ 与本稿的 ⟨ω²⟩ 未必完全相同（权重差异），对照时须注意；
- **不宣称一致**：AD 1975 是经验拟合、拟合域在 λ∈[0.5,1.5]、ω̄₂/ω_log∈[1,3]（见原文），而定理 S 是严格展开、有效域 ϖ̄∈[0.2,60]。两者可对照但不应强求数值吻合。

## 6. 诚实边界

以下限制对外陈述必须前置：

1. **μ*=0**（U4）：KAY 全套无库仑赝势。上界推论逐字成立（K_c⪰0），但唯一性只有窗内结果。
2. **λ 上界非定理**（U5）：λ_* 的物理上界（动理学稳定）与 Tc 界（KAY）无共同证明基础。产品 = 「给定 λ 的严格 Tc 上界」+「λ 的物理上界（非严格）」两层分开写。
3. **有界峭度**（U6）：O(σ⁴) 率要求定形族假设。退化极限下余项退为 O(σ²)，但物理上无害（真实声子谱不锐化成 δ）。
4. **ϖ̄ 区间 [0.2,60]**：ϖ̄→0 时 h→0、gap→0，一致性失效；但 Tc 条件把 ϖ̄ 钉在有限值（物理 λ 给 ϖ̄∈[a,b]，a>0）。区间外未证（上端 60 是算力限制，μ̃=0.26 可到 16.32、μ̃=0.33 可到 1.5666，见 P4_interchange_uniformity.md §3）。
5. **计算机辅助证书的约定**（只涉及定理 S，不涉及定理 1、2）：mpmath dps≥30、显式舍入垫、Cholesky 成功当 SPD 证书；12 个 Tier2 常数（形式上未闭，非承重）。段 C-I 已全程区间化（`p4_cii_ci_interval.py`，残余假设第 1 条消除）。
6. **P3 与 P4-A 的 κ 不是同一个量**（P4_rigorous_tc_bound.md §6）：P3 的 κ=5.6035 是关于 λ_* 泛函的、在 g 核极大处展开的纯数；P4-A 的 κ_N(ϖ̄) 是关于 𝔨^(N) 的、ϖ̄ 的函数。两者共享矩展开方法，但对象不同。
