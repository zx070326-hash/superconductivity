## 1. 设定与记号

u_n := (2n+1)^{-1/2}（n ≥ 0）。对 f : ℕ_{≥1} → ℝ，核-通用算子逐元定义为

　𝒪[f]_{nm} = −δ_{nm}·2u_n²·Σ_{k=1}^{n} f(k) + (1−δ_{nm})·f(|n−m|)·u_nu_m + f(n+m+1)·u_nu_m。

记 A := 𝔊(2) = 𝒪[1/k²]，H_n^{(2)} := Σ_{k=1}^{n} 1/k²（H_0^{(2)}=0）。展开：

　A_{nn} = u_n²(1/(2n+1)² − 2H_n^{(2)})，　A_{nm} = u_nu_m(1/(n−m)² + 1/(n+m+1)²)（n≠m）。

**𝔤(2) := λ₁(A) := max spec A。**

**关键代换.** 对 v ∈ ℓ² 令 **p_n := u_n v_n**（等价 v_n = √(2n+1)·p_n）。于是 ‖v‖² = Σ_n (2n+1)p_n²，且下面每个双线性量都是 p 的**有理**函数 —— 所有 u_n 的无理性成对抵消。这是整篇证明能停留在 ℚ 上的唯一原因。

记
　K(n,m) := 1/(n+m+1)² + [n≠m]/(n−m)²，
则
　⟨v,Av⟩ = Σ_{n,m} p_np_m K(n,m) − 2Σ_n H_n^{(2)} p_n²，　(Av)_n = u_n·g_n，
　g_n := Σ_m p_m K(n,m) − 2H_n^{(2)} p_n。

## 2. 引理 0（A 是 Hilbert–Schmidt，故紧）

**引理 0.** ‖A‖²_HS = Σ_{n,m} A_{nm}² < ∞。故 A 是 ℓ² 上的紧自伴算子，𝔤(2) = max spec A 是**取到的本征值**，且 A 的谱除 {0} 外是离散的。

*证.* 对角：括号 1/(2n+1)² − 2H_n^{(2)} ∈ [−2ζ(2), 1]，故 A_{nn}² ≤ 4ζ(2)²/(2n+1)²，
　Σ_n A_{nn}² ≤ 4ζ(2)²·(π²/8) = ζ(2)²π²/2。
非对角：用 (x+y)² ≤ 2x²+2y² 与 2/((2n+1)(2m+1)) ≤ 1/(2n+1)² + 1/(2m+1)²，
　Σ_{n≠m} A_{nm}² ≤ Σ_{n≠m}(1/(2n+1)²+1/(2m+1)²)(1/(n−m)⁴+1/(n+m+1)⁴) ≤ 2·(π²/8)·(2ζ(4)+ζ(4)) = 3ζ(4)π²/4。
二者均有限。∎

（解析界 = 21.364；真值 ‖A‖²_HS = 3.8496。界很松，但这里只用**有限性**。）

## 3. 引理 1（精确重排恒等式）与 A ⪯ B

**引理 1.** 对每个有限支撑的实 v（p_n = u_n v_n）：

> ⟨v,Av⟩ = ⟨v,Bv⟩ − ½·D[p]，　　(L1)

其中
　⟨v,Bv⟩ := Σ_{n,m≥0} p_np_m/(n+m+1)² + Σ_{n≥0} ψ′(n+1)·p_n²，
　D[p] := Σ_{n≠m≥0} (p_n−p_m)²/(n−m)² ≥ 0，
　ψ′(n+1) = Σ_{k>n} 1/k² = ζ(2) − H_n^{(2)}。
即 B 是逐元为 **B_{nm} = u_nu_m/(n+m+1)² + δ_{nm}·u_n²·ψ′(n+1)** 的算子。

*证.* 代入 p_n = u_nv_n：
　⟨v,Av⟩ = Σ_{n≠m} p_np_m/(n−m)² + Σ_{n,m} p_np_m/(n+m+1)² − 2Σ_n H_n^{(2)}p_n²。
对第一和用极化 2p_np_m = p_n² + p_m² − (p_n−p_m)²，并令
　c_n := Σ_{m≥0, m≠n} 1/(n−m)² = ζ(2) + H_n^{(2)}
（m>n 的一半给 ζ(2)，m<n 的一半给 H_n^{(2)}），得
　Σ_{n≠m} p_np_m/(n−m)² = Σ_n c_n p_n² − ½ D[p]。
于是对角系数变成 c_n − 2H_n^{(2)} = ζ(2) − H_n^{(2)} = ψ′(n+1)。p 有限支撑时所有和绝对收敛。∎

**推论 1′（A ⪯ B）.** 对一切有限支撑 v 有 ⟨v,Av⟩ ≤ ⟨v,Bv⟩；两个二次型都连续（A 有界，B 迹类，见引理 3），故对一切 v ∈ ℓ² 成立。即 **A ⪯ B**（二次型序）。

> 这一步是整条路线的支点：A 的**负谱**（λ_min = −0.9898）全部来自 Dirichlet 型 −½D[p]，把它扔掉换来的 B 是**正的迹类**算子，于是「第二本征值上界」可以用迹来做。直接对 A 用迹或 Hilbert–Schmidt 都失败（‖A‖²_HS = 3.85 给出 √(3.85−ρ²) = 1.45 > ρ，Temple 的前提 β < ρ 不成立）。

## 4. 引理 2（B ⪰ 0）

**引理 2.** B ⪰ 0。

*证.* Hankel 核有矩表示 1/(n+m+1)² = ∫₀^∞ t e^{−(n+m+1)t} dt，故对有限支撑 p
　Σ_{n,m} p_np_m/(n+m+1)² = ∫₀^∞ t e^{−t} (Σ_n p_n e^{−nt})² dt ≥ 0，
而 Σ_n ψ′(n+1)p_n² ≥ 0 显然。稠密性 + B 有界给出一般 v。∎

## 5. 引理 3（间隙常数 β = 13/25）

**引理 3.** λ₂(A) ≤ λ₂(B) ≤ **β := 13/25**，因而 sup(spec A ∖ {λ₁}) ≤ 13/25。

*证.* 分四步。

**(i) B 迹类.** tr B = Σ_{n≥0} B_{nn} = Σ_{n≥0} [1/(2n+1)³ + ψ′(n+1)/(2n+1)] < ∞（每项 O(n^{-2})）。

**(ii) 迹给出 λ₂(B) 的上界.** 由引理 2 全部本征值 ≥ 0 且和为 tr B；又 λ₁(B) ≥ ⟨e₀,Be₀⟩ = B₀₀ = 1 + ζ(2)。故
　λ₂(B) ≤ Σ_{i≥2} λ_i(B) = tr B − λ₁(B) ≤ tr B − B₀₀ = Σ_{n≥1} B_{nn} =: β₀。

**(iii) β₀ 的闭式上界.** 用经典闭式 Σ_{n≥1} 1/(2n+1)³ = (7/8)ζ(3) − 1，以及中点法则（引理 4b）
　ψ′(n+1) = Σ_{k>n} 1/k² ≤ ∫_{n+1/2}^∞ dx/x² = 1/(n+½) = 2/(2n+1)，
于是 Σ_{n≥1} ψ′(n+1)/(2n+1) ≤ Σ_{n≥1} 2/(2n+1)² = 2(π²/8 − 1) = π²/4 − 2。合并：
> β₀ ≤ (7/8)ζ(3) + π²/4 − 3 = (7/8)ζ(3) + (3/2)ζ(2) − 3。

**(iv) 有理化证书.** 为了不引用 ζ(2)、ζ(3) 的**十进制展开**，把两个 ζ 值各用 10 项部分和 + 中点尾界替代：
　ζ(2) ≤ H_10^{(2)} + 1/(10+½) = **2089289/1270080** =: R₂，
　ζ(3) ≤ H_10^{(3)} + 1/(2(10+½)²) = **19236689947/16003008000** =: R₃，
则
> (7/8)R₃ + (3/2)R₂ − 3 = **9497876347/18289152000** = 0.51931748… < 13/25 = 0.52。

这是两个显式有理数之间的**一条**不等式，可以手算核对。

**(v) 传到 A.** 由推论 1′ 与 Courant–Fischer 极小极大（A ⪯ B、二者紧自伴 ⟹ λ_k(A) ≤ λ_k(B) 对每个 k）：λ₂(A) ≤ λ₂(B) ≤ β₀ ≤ 13/25。∎

**推论（谱分离，Temple 的前提）.** 下文将给出 ρ > 13/25 的试探向量。设 P 为 A 在 (β,∞) 上的谱投影。A 紧且 β > 0 ⟹ P 有限秩，秩 = 大于 β 的本征值个数（计重数）。若秩 ≥ 2，则在 P 的值域里取任一 1 维子空间 S，max{⟨v,Av⟩ : v ⊥ S, ‖v‖=1, v ∈ ran P} > β，对一切 S 取 min 仍 > β，即 λ₂(A) > β，与引理 3 矛盾。故秩 ≤ 1；又 λ₁ ≥ ρ > β 迫使秩 = 1。于是

> **spec(A) ∩ (13/25, ∞) = {λ₁}，且 λ₁ 单重。**

这正是 Temple 不等式所需的条件（注意：这里要的是"除 λ₁ 外的谱点全 ≤ β"，不能只说"λ₂ ≤ β"就了事，上面这段就是把二者接上的那一步）。

数值旁证（脚本 Stage 2）：β₀ 真值 0.5104653，(7/8)ζ(3)+π²/4−3 = 0.5192009，λ₂(B) = 0.2449263，λ₂(A) = 5.354×10⁻⁴。β = 13/25 相对真实 λ₂ 非常粗，但只在 Temple 分母上损失因子 (ρ−λ₂)/(ρ−β) = **1.651**。

## 6. 引理 4（核比较 + 中点法则 + 尾和）

**(4a) 核比较.** 对整数 0 ≤ m < N₁ ≤ n：(n−m)(N₁+1) ≥ (n+1)(N₁−m)，因而
> 1/(n−m)² ≤ (N₁+1)² / ((n+1)²(N₁−m)²)。

*证.* (n−m)(N₁+1) − (n+1)(N₁−m) = (n − N₁)(1 + m) ≥ 0。两边皆正，可平方。∎

**(4b) 中点法则.** 若 f 在含 [a−½, a+½] 的开区间上凸，则 f(a) ≤ ∫_{a−½}^{a+½} f(x)dx。
*证.* 凸性给 f(x) ≥ f(a) + f′₊(a)(x−a)；区间关于 a 对称，积分掉线性项。∎
**推论.** f 在 (c,∞) 上凸且 K−½ > c ⟹ Σ_{k≥K} f(k) ≤ ∫_{K−½}^∞ f(x)dx。

（本文在三处用到它：ψ′ 的界、R₂/R₃ 的尾、以及下面的 (4c)。）

**(4c) 尾和.** 对整数 N₁ ≥ 1：
> T(N₁) := Σ_{n≥N₁} 1/((n+1)⁴(2n+1)) ≤ **1/(N₁(2N₁+1)³)**。

*证.* 令 h(x) = 1/((x+1)⁴(2x+1))，定义域 (−½,∞)。则
　(log h)″ = 4/(x+1)² + 4/(2x+1)² > 0，
故 h 对数凸，从而凸。由 (4b)，
　T(N₁) ≤ ∫_{N₁−½}^∞ h(x)dx = ∫_a^∞ dt/(2t⁵ − t⁴)，　a := N₁ + ½
（代 t = x+1，并用恒等式 (x+1)⁴(2x+1) = 2t⁵ − t⁴）。对 t ≥ a，
　2t⁵ − t⁴ = 2t⁵(1 − 1/(2t)) ≥ 2t⁵(1 − 1/(2a)) = 2t⁵(2a−1)/(2a)，
于是
　T(N₁) ≤ (2a/(2a−1))·½·∫_a^∞ t^{-5}dt = (2a/(2a−1))/(8a⁴) = 1/(4a³(2a−1))
　　　　 = 8/(4(2N₁+1)³·2N₁) = 1/(N₁(2N₁+1)³)。∎

这个界到 O(1/N₁) 是**紧**的：比值 T(N₁)·N₁(2N₁+1)³ 单调升到 1（N₁=20 时 0.9931，N₁=5000 时 0.99997）。脚本 Stage 3 对 1 ≤ N₁ ≤ 400 及 N₁ = 1000, 5000 逐一核验。

## 7. 定理（证书）

**定理 (*).** 固定整数 M ≥ 1、整数 N₁ ≥ M 与正有理数 p₀,…,p_{M−1}。令 v ∈ ℓ² 为
　v_n = √(2n+1)·p_n（n < M），v_n = 0（n ≥ M）。
定义**有理**量
　‖v‖² = Σ_{n<M} (2n+1)p_n²，
　Q = Σ_{n,m<M} p_np_m K(n,m) − 2Σ_{n<M} H_n^{(2)}p_n²，　ρ = Q/‖v‖²，
　g_n = Σ_{m<M} p_m K(n,m) − 2H_n^{(2)}p_n·[n<M]，
　W = Σ_{m<M} p_m((N₁+1)²/(N₁−m)² + 1)，
　R = Σ_{n<M} (g_n − ρ(2n+1)p_n)²/(2n+1) + Σ_{M≤n<N₁} g_n²/(2n+1) + W²/(N₁(2N₁+1)³)，
　r² = R/‖v‖²。
若 ρ > 13/25，则

> **ρ ≤ 𝔤(2) ≤ ρ + r²/(ρ − 13/25)。**　　(*)

*证.*

**下界.** Rayleigh 商：𝔤(2) = max spec A ≥ ⟨v,Av⟩/‖v‖² = ρ。（§1 的展开式给出 ⟨v,Av⟩ = Q。）

**残差 R 是真残差的上界.** 由 (Av)_n = u_n g_n 与 √(2n+1) = u_n(2n+1)，
　(Av − ρv)_n = u_n g_n − ρ√(2n+1)p_n = u_n·(g_n − ρ(2n+1)p_n)，
故
　‖Av − ρv‖² = Σ_{n≥0} u_n²(g_n − ρ(2n+1)p_n)² = Σ_{n≥0} (g_n − ρ(2n+1)p_n)²/(2n+1)。
n ≥ M 时 p_n = 0，被加项为 g_n²/(2n+1)，其中 g_n = Σ_{m<M} p_m K(n,m) > 0（所有 p_m > 0、所有核项正）。对 n ≥ N₁ 用 (4a) 与 1/(n+m+1)² ≤ 1/(n+1)²：
　K(n,m) ≤ [(N₁+1)²/(N₁−m)² + 1]/(n+1)²　⟹　0 < g_n ≤ W/(n+1)²，
于是
　Σ_{n≥N₁} g_n²/(2n+1) ≤ W²·Σ_{n≥N₁} 1/((n+1)⁴(2n+1)) = W²·T(N₁) ≤ W²/(N₁(2N₁+1)³)（引理 4c）。
把 n < N₁ 的部分逐项精确保留，得 ‖Av − ρv‖² ≤ R，即 r² ≥ ‖Av−ρv‖²/‖v‖²。

**上界（Temple 不等式）.** 令 w := v/‖v‖，λ₁ := 𝔤(2)，β := 13/25。由引理 3 的推论，spec(A) ∩ (β,∞) = {λ₁}，故对任一谱点 μ：μ = λ₁ 时 (μ−λ₁)(μ−β) = 0；μ ≠ λ₁ 时 μ ≤ β < ρ ≤ λ₁，两因子同为非正/非正之积 ≥ 0。因此 (A−λ₁)(A−β) ⪰ 0，于是
　0 ≤ ⟨w,(A−λ₁)(A−β)w⟩ = ‖Aw‖² − (λ₁+β)ρ + λ₁β。
又 ‖Aw − ρw‖² = ‖Aw‖² − ρ²，故 ‖Aw‖² = ρ² + ‖Aw−ρw‖² ≤ ρ² + r²。代入：
　0 ≤ r² + ρ² − (λ₁+β)ρ + λ₁β = r² + ρ(ρ−β) − λ₁(ρ−β)，
由 ρ − β > 0 得 λ₁ ≤ ρ + r²/(ρ−β)。∎

> **注（为什么 Temple 而不是 Collatz–Wielandt）.** Temple 的宽度是 r²/(ρ−β)，对试探向量误差是**二阶**的；CW 界 sup_n (Aw)_n/w_n 是**一阶**的。见 §10 的定量比较。另外 Temple 只需要**一个**尾界（引理 4c），CW 需要对每个 n 一致地控制**三个**无穷和。

## 10. 用到的经典不等式与定理（完整清单）

1. **Rayleigh 商变分原理**：λ₁ = max spec A ≥ ⟨v,Av⟩/‖v‖²（A 自伴有界）。
2. **Temple 不等式**（1928）：本文 §7 给出了完整的两行证明，不引用外部结果。
3. **Courant–Fischer 极小极大**：A ⪯ B、二者紧自伴 ⟹ λ_k(A) ≤ λ_k(B)。
4. **迹类算子的迹 = 本征值之和**（Lidskii；对 B ⪰ 0 只需单调收敛，不需要一般 Lidskii）。
5. **Hausdorff–Hankel 矩表示** 1/(s+1)² = ∫₀^∞ t e^{−st}dt（引理 2）。
6. **Hilbert–Schmidt ⟹ 紧**（引理 0）。
7. **凸函数的中点法则**（引理 4b，附证明）。
8. **初等代数**：极化恒等式、(x+y)² ≤ 2x²+2y²、AM–GM 形式 2ab ≤ a²+b²。
9. **两个经典闭式**：Σ_{n≥1}1/(2n+1)³ = (7/8)ζ(3) − 1，Σ_{n≥1}1/(2n+1)² = π²/8 − 1。

## 11. 与 Collatz–Wielandt / 加权 Schur 路线的比较（为何降级为交叉检验）

主会话建议的路线是：A = D + B_off，B_off 逐元 ≥ 0（A 的所有非对角元确实严格为正），对任意逐元正权 w（不必属于 ℓ²）有 λ₁(A) ≤ sup_n (Aw)_n/w_n。

**这条路线是对的** —— 我独立复核过，而且它有一行自足的证明（加权 Schur 检验形式，不必引用 Perron–Frobenius 或不可约性）：设 A 对称、**非对角元 ≥ 0**、w > 0 逐元、且 (Aw)_n ≤ s·w_n 对一切 n。取 c := 2ζ(2) 使 A + cI 逐元 ≥ 0（A 的对角元 ≥ −2ζ(2)u_n² ≥ −2ζ(2)）。对 ‖v‖=1，用 2|v_n||v_m| ≤ (w_m/w_n)v_n² + (w_n/w_m)v_m²：

　⟨v,(A+cI)v⟩ ≤ Σ_{n,m}(A+cI)_{nm}|v_n||v_m| ≤ Σ_n (v_n²/w_n)·((A+cI)w)_n ≤ (s+c)‖v‖²，

故 λ₁(A) = λ₁(A+cI) − c ≤ s。A 的非对角元 u_nu_m(1/(n−m)²+1/(n+m+1)²) 确实严格为正，前提满足。∎

它也确实可算。但它被降为交叉检验，原因有二，都是定量的（脚本 Stage 7）：

**(a) 一阶 vs 二阶.** CW 的超出量 sup_n (Aw)_n/w_n − λ₁ 对 w 的误差是**一阶**的，Temple 是**二阶**的。实测（权 = A_M 的顶本征向量 + 在 n=M−1 连续拼接的 c/(n+1)³ 尾）：

| 权 | CW 上界 | 超出量 |
|---|---|---|
| p_n = 1/(n+1)² | 1.3721914 | 5.4×10⁻² |
| p_n = 1/((n+1)(n+2)(n+3)) | 1.3627904 | 4.5×10⁻² |
| head(M=12)+尾 | 1.364788211 | 4.67×10⁻² |
| head(M=40)+尾 | 1.335704096 | 1.76×10⁻² |
| head(M=100)+尾 | 1.325753030 | 7.61×10⁻³ |
| head(M=200)+尾 | 1.322074101 | 3.93×10⁻³ |
| head(M=400)+尾 | 1.320145342 | 2.01×10⁻³ |
| head(M=800)+尾 | 1.319153922 | 1.01×10⁻³ |

超出量按 ~0.8/M 衰减（sup 恒在拼接点 n = M−1 取到）。即使 M=800，CW 也比 **M=12** 的 Temple（5.2×10⁻⁵）差 20 倍，比 M=30 的 Temple（1.2×10⁻⁶）差近 10³ 倍。

> **陷阱（我自己踩过）.** CW 的 sup 必须对**一切** n 取。我第一次扫描时只算到 n < 400，M=800 的权在 n=799 处的峰值被漏掉，得到一个假的 6×10⁻⁸ 超出量。表里的数字是把扫描范围扩到 n < min(2M, 900) 之后的正确值。这类"漏掉 sup 位置"的错误正是 CW 路线在论文里难以自证的地方 —— 解析地证明 sup 不在别处，本身就是一项额外工作。

**(b) 需要解析控制的对象数量.** CW 要对**每个** n 一致地给出三块的解析上界：L1 对角块 Σ_{k≤n}1/k²（可以用 ζ(2) − 显式尾）、L2 块 Σ_{m≠n} w_mu_m/|n−m|²、L3 块 Σ_m w_mu_m/(n+m+1)²；再加上「小 n 逐个估、大 n 靠单调性或积分比较」的分段论证。Temple 只需要**一个**尾界（引理 4c），其余全是有限有理算术。

结论：CW 可行但工作量与最终宽度都远劣。**保留在脚本 Stage 7 作为独立交叉检验**：它给出的每个上界都 ≥ 真值，与 Temple 的区间相容。

其余备选路线的状态（都没走）：
- 锥 C + Abel 分解 + 闭式 Q_{LL′}：能给出结构性信息，但对 λ₁ 的**上界**仍需一个 λ₂ 间隙，回到引理 3。
- rank-one + Schur 可控余项（仿 (S3)）：可行但常数更差。
- Hilbert–Schmidt 地板 λ₁ ≤ ‖A‖_HS = 1.962：确实成立，但太松（宽 49%），且不能配合 Temple（见 §3 的注）。

## 12. 诚实边界（必读）

**(A) 哪些步骤是纯解析的。** 引理 0、1、2、3、4 与定理 (*) 的**全部证明**是解析的：闭式恒等式、凸性、迹不等式、极小极大、Temple。定理 (*) 的**验证**（给定 p、N₁ 算出 ρ、W、r²、g_hi 并核对 ρ > 13/25）是有限次**精确有理数**四则运算，没有浮点、没有舍入余量、没有区间算术 —— 原则上可以手算，实际上由 `fractions.Fraction` 完成。

**(B) 哪里用了数值优化。** 只有一处：**试探向量 p 的挑选**。
- CERT-A、CERT-B 的 p 是 `round(scale × v₁(A_M))`，v₁ 是 M×M 截断矩阵顶本征向量的 float64 值（scale 分别为 200、10⁴）。脚本 Stage 4 把这条生成规则本身也做成了回归检查。
- CERT-A′ 的 p 额外做了 ±2 的整数微调（暴力搜索），比原始舍入略窄。脚本记录的检查是「与原始舍入每个分量相差 ≤ 2」，如实反映这一点。
- CERT-C、CERT-D 同样是 `round(scale × v₁(A_M))`，scale = 10⁸、10¹⁴，并已冻结为脚本里的整数字面量（见 §8.4/§8.5）；这样本稿引用的端点不依赖 LAPACK 逐位可复现性。
- N₁ 的选取（12/16/40/80/500）是手工权衡：增大 N₁ 把「解析尾」换成「精确头部残差」，恒为改善，代价只是 O(N₁·M) 次有理运算。

**关键点：p 和 N₁ 的来源完全不影响 (*) 的有效性。** (*) 对**任意**正有理 p 与任意 N₁ ≥ M 成立；数值只决定界有多紧，不决定界是否正确。这就是「参数可以数值找，最终不等式必须解析验证」的分界线，本稿严格落在这条线的正确一侧。

**(C) 脚本在证明里扮演什么角色。** `p4_g2_analytic_bounds.py` 是**回归闸门**，不是证明：它把本稿每个闭式、每条不等式、每个常数，在 N = 400/800/1600 三个截断上，与 §1 逐元定义直接构造的矩阵逐格比对（Stage 6 对每个证书核验 ‖v‖²、ρ、g_n、「证书 r² ≥ 真残差」、包络 g_n ≤ W/(n+1)²、「解析尾 ≥ 真尾」、以及区间包含 λ₁(A_N)）。389 项检查，0 失败，约 8 s。若有人改动本稿的任何常数，闸门会当场报错。

**(C′) 证伪测试（Stage 8）。** 上面所有证书都用**近本征向量**的 p，此时 r² 极小，符号错误或过弱的包络原则上可以藏在里面而不被发现。因此脚本另外用 400 个**随机**正有理 p 去砸 (*)：形状包括 1/(n+1)、1/(n+1)²、1/(n+1)³、常数、纯随机、单点加尖、以及**倒序**（p 递增，离顶本征向量最远），M ∈ [1,30]，N₁ 从 M（引理 4a 最紧的用法）到 200。若引理 1 → A ⪯ B → β → 谱分离 → Temple 这条链，或引理 4a/4c 的包络，有任何一处方向错了，总会有一次抽样给出**不包含** 𝔤(2) 的区间。

实测：209 个 ρ > 13/25 的可用抽样**全部**包含 𝔤(2)，0 次证伪；其余 191 个因 ρ ≤ 13/25 被 `certificate()` 里的 assert 拒绝 —— (*) 对它们本来就不适用，这是显式拒绝而非静默放宽。随机抽样里最紧的上界余量是 hi − 𝔤(2) = 2.7×10⁻²（decay2, M=4）。

**(D) 我不完全确定的地方。**
0. **对抗审查已查出的两处（均已修正，记录在此不删）。**
   - **(D0-a) 写稿曾有一句可被一行算术推翻的假断言**：说 CERT-D「已窄于」mpmath 参照、解析界「取代」数值界。实际 CERT-D 绝对宽度 6.108×10⁻¹⁰，参照 3.737×10⁻¹⁰，CERT-D **宽 1.63 倍**。根源是拿 CERT-D 的**相对**宽度去比参照的**绝对**宽度。已改为「同量级、尚未超过、取 M≈250 可真正超过」。这条错误不影响任何引理与证书本身，只影响一句对外宣称 —— 但正因为它是宣称，更容易被引用出去。
   - **(D0-b) 脚本曾漏掉定理 (*) 的承重假设 p_n > 0**。`certificate()` 只校验了 `N1 ≥ M` 与 `ρ > β`，没有校验正性。喂入带符号的 p（例如 p = (−34, −7, 8)、N₁ = 3）时，W 的各项正负相消而 g_n 的各项不相消，解析尾 W²T(N₁) 会**低估真尾 30 倍**，返回的 r² = 0.72534 小于真残差 0.72610，于是 `hi` 根本不是上界。出厂的五个证书 p 全为正整数，**已发布的数字不受影响**；但一个自称「回归闸门」的脚本漏掉被它把关的定理的承重假设，不该带进附录。已补 assert，并把这个反例固化为 Stage 8 的两项检查（拒绝带符号 p；独立确认该反例确实使 g_n 变号、包络失效）。
