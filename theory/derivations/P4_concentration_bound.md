## 1. 精确预解恒等式 (★)(★★)　【PROVED，解析】

记 g̃(k) := k²/(k²+x) = 1 − f(k) ≥ 0（g̃ **递增**，g̃(0)=0，g̃(∞)=1）。逐元线性 + (S1)：

    A = 𝒪[f] = 𝒪[1] − 𝒪[g̃] = (2uuᵀ − I) − 𝒪[g̃].

代入 Av = hv，令 s = ⟨u,v⟩：2s·u − v − 𝒪[g̃]v = h v，即 (h+1)v = 2s·u − 𝒪[g̃]v，于是

    **v_n = (2s/(h+1))·u_n − (1/(h+1))·(𝒪[g̃]v)_n**              (★)

    **v = 2s·((h+1)I + 𝒪[g̃])^{-1} u**                          (★★)

(★) 的主项**精确** ∝ u_n，无逐-n 的 h-压制——这正是数值观测到 v_n ≈ v₀u_n（n ≲ √x）
的结构性原因。等价改写给出一条**恒等式**（无需展开 𝒪[g̃]）：

    **(𝒪[g̃]v)_n = 2s·u_n − (h+1)·v_n**.                        (1.1)

*证明*　(S1) 的代数证明见 `P4_main_theorems.md`；其余为一行代换。`ck` 复核：(★) 残差
≤ 1e-10、(★★) 残差 ≤ 1e-9、(1.1) 残差 ≤ 1e-10，在 x ∈ {0.01,…,1600} 九点。∎

> **关于 (★★) 的算子适定性**：u ∉ ℓ² ⟹ uuᵀ、𝒪[1]、𝒪[g̃] 均**非** ℓ² 有界算子，故 (★★)
> 中的预解式只在有限截断意义下（或作用在 v 这一具体、快衰减的向量上）良定义。**本文所有
> 承重估计都走 (★)/(1.1) 的逐分量形式**，其中只出现 (𝒪[g̃]v)_n = Σ_m(𝒪[g̃])_{nm}v_m，该级数
> 绝对收敛（被 Σ_m u_m|v_m| = s < ∞ 控制），无适定性隐患。(★★) 仅作直观与数值验证之用。

## 2. 符号结构、精确归约、s-无关性　【PROVED，解析】

**2.1 符号分解.** 写 𝒪[g̃] = P − D_{g̃}，其中
- P_{nm} := u_nu_m[g̃(|n−m|)𝟙_{m≠n} + g̃(n+m+1)] ≥ 0（**逐元非负**，因 g̃ ≥ 0）；
- (D_{g̃})_{nn} := (2/(2n+1))Σ_{k=1}^{n} g̃(k) ≥ 0（对角，D₀ = 0，D_n ↗ 1）。

故 (𝒪[g̃]v)_n = (Pv)_n − (D_{g̃})_n v_n，其中 (Pv)_n ≥ 0、(D_{g̃})_n v_n ≥ 0。

**2.2 顶分量上界 v₀ ≤ 2s/(h+1).** 第 0 行无对角亏损（Σ_{k=1}^{0} 为空），故
(𝒪[g̃]v)₀ = (Pv)₀ ≥ 0。代入 (★) 的 n=0：v₀ = 2s/(h+1) − (𝒪[g̃]v)₀/(h+1) ≤ 2s/(h+1)。
`ck` 复核九点全过。∎

**2.3 精确廓线公式.** 定义**修正比** ε_n := (𝒪[g̃]v)_n / (2s·u_n)。由 (★)，
v_n = (2s/(h+1))u_n(1 − ε_n)，取 n=0（u₀=1）：v₀ = (2s/(h+1))(1 − ε₀)。相除：

    **r_n = v_n/(v₀ u_n) = (1 − ε_n)/(1 − ε₀)**.                 (2.1)

**2.4 充分条件（归约）.** 由 2.2，v₀ ≤ 2s/(h+1)，故 c·v₀·u_n ≤ c·(2s/(h+1))u_n；而
(★) 给 v_n = (2s/(h+1))u_n(1−ε_n)。于是

    **ε_n ≤ 1 − c 　⟹ 　v_n ≥ c·v₀·u_n**.                       (2.2)

（把承重的 v₀ 松弛为 2s/(h+1)，比 (2.1) 略保守——丢掉 (1−ε₀)^{-1} ≥ 1 的增益——但让证明
只需**修正比的上界**，不需 ε₀。所以整个任务归约为：**在 n ≤ a√x 上界定 ε_n**。）

**2.5 s-无关性.** 展开 (𝒪[g̃]v)_n 并丢掉非正对角亏损（对 ε 的**上界**安全）：

    ε_n ≤ (1/(2s))·[ Σ_{m≠n} g̃(|n−m|) w_m + Σ_{m} g̃(n+m+1) w_m ].   (2.3)

右端每个 w_m 都将用 §3 的**正比于 s** 的先验界替代，故 **s 在 ε 的界中精确抵消**——
最终 ε 界只依赖 h 与 x，与 v 的归一化常数、与 s、与 v₀ 无关。`ck` 复核：含-s 与 s-无关两式
逐点差 ≤ 1e-12。这一点很重要：它把「需要知道未知本征向量的 s」这一循环依赖彻底消掉。

## 3. 先验界（源自本征方程，用**真实核** f，非 f ≤ x/k² 的松弛）　【PROVED，解析】

把 Av = hv 逐分量展开（D^f_n := (2/(2n+1))Σ_{k=1}^{n} f(k) ≥ 0，用 u_m v_m = w_m）：

    (h + D^f_n) v_n = u_n·[ Σ_{m≠n} f(|n−m|) w_m + Σ_{m} f(n+m+1) w_m ].   (3.0)

**(P) 逐点界.** f ≤ 1、w ≥ 0 ⟹ 方括号 ≤ Σ_{m≠n}w_m + Σ_m w_m ≤ 2s。又 D^f_n ≥ 0，故
h v_n ≤ 2s u_n，得

    **w_n = u_n v_n ≤ (2s/h)·u_n²　对一切 n**.                  (P)

**(P′) bootstrap 逐点界.** 把 (P) 回代进 (3.0) 的方括号：

    方括号 ≤ (2s/h)[ Σ_{m≠n} f(|n−m|) u_m² + Σ_{m} f(n+m+1) u_m² ] =: (2s/h)·a_n，

于是 h v_n ≤ u_n(2s/h)a_n，得

    **w_n ≤ (2s/h²)·u_n²·a_n**,　a_n := Σ_{m≠n} f(|n−m|)u_m² + Σ_{m} f(n+m+1)u_m².   (P′)

关键：a_n 随 n **衰减**（数值 a_n·(2n+1)/F_tot ∈ [3.3,4.5]，即 a_n ≈ 4F_tot/(2n+1)），
故 (P′) 给出真正的 **1/n² 尾**——这正是把 (2.3) 变成**收敛级数**、绕开 u∉ℓ²（Σu_m² 发散）
致命障碍的那一步。合并：**B(m) := min((2s/h)u_m², (2s/h²)u_m²a_m) = (2s/h)u_m²·min(1, a_m/h)**
是 w_m 的严格逐点上界。`ck` 复核 (P)(P′) 逐点非违反（≤ 1e-6），x ∈ {4,25,100,400,1600}。

**(T) 尾质量界.** (3.0) 两边乘 u_n（并丢 D^f_n ≥ 0）：h w_n ≤ u_n²·方括号。对 n ≥ M 求和、
交换求和序、用 n ≥ M ⟹ u_n² ≤ 1/(2M+1)，及 Σ_{n≠m}f(|n−m|) ≤ 2F_tot、Σ_n f(n+m+1) ≤ F_tot：

    **Σ_{m≥M} w_m ≤ 3·F_tot·s / (h·(2M+1))**.                   (T)

**(F) F_tot 闭式界.** F_tot := Σ_{k≥1} f(k) = x·Σ_{k≥1}1/(k²+x) = (π√x/2)·coth(π√x) − 1/2
（标准恒等式 Σ_{k≥1}1/(k²+a²) = (π coth πa)/(2a) − 1/(2a²)，a=√x）。coth 递减、
coth(π√x) ≤ coth(π) < 1.0037（x ≥ 1）⟹

    **F_tot ≤ 0.502·π·√x　(x ≥ 1)**,　且 F_tot ≥ (π√x)/2 − 1/2.   (F)

`ck` 复核 (T)、(F) 全过（(F) 与截断级数在解析尾界内吻合）。

> **为何 (T) 在大 x 下把尾杀死**：(T)+(F) 给 Σ_{m≥β√x}w_m ≤ 3(0.502π√x)s/(h·2β√x)
> = (0.753π/β)·s/h。而 h ~ (1/2)ln x（见 §4），故尾质量 / s ≤ O(1/(β ln x)) → 0。
> 这是「集中」在大 x 下成立的定量根源。

## 4. 主定理：廓线下界　【结构 PROVED；常数 = h 下界的有限核验】

**4.1 ε 的显式上界.** 把 B(m) 代入 (2.3)，2s 抵消（§2.5）：

    **ε_n ≤ Ψ_n(x,h) := (1/h)·Σ_{m} u_m²·min(1, a_m/h)·[ g̃(|n−m|)𝟙_{m≠n} + g̃(n+m+1) ]**.   (4.1)

Ψ 是**收敛**级数（因 min(1,a_m/h)·u_m² ~ 1/m²）。Ψ_n(x,h) 关于 h **严格递减**（前因子 1/h
与 min(1,a_m/h) 同时随 h 减小）。

**4.2 h 的 Rayleigh 下界（闭合最后一处依赖）.** h = λ₁(A) = sup_{‖ψ‖=1}⟨ψ,Aψ⟩ ≥
⟨ψ,Aψ⟩/‖ψ‖²，取试探向量 ψ = u·𝟙_{[0,L)}（有限支撑，Rayleigh 商是有限求和，可有理核验）：

    **h ≥ h_lo(x) := max_L ⟨u𝟙_{[0,L)}, A u𝟙_{[0,L)}⟩ / ‖u𝟙_{[0,L)}‖²**.

`ck` 复核 h_lo/h ∈ [0.93, 0.96]（x=16…6400），且 h_lo ↗ 与 (1/2)ln x 同阶（实测略优）。
因 (P)(P′) 对任何 h' ≤ h 仍成立（放大右端），把 h_lo 代进 B(m) 与 (4.1) 得**严格**上界
ε_n ≤ Ψ_n(x, h_lo)，其数值只需 h_lo 与 x。

**定理（廓线集中）.** 设 x > 0，h_lo(x) 为上述 Rayleigh 下界。则对一切 0 ≤ n ≤ a√x，

    **v_n ≥ c(a,x)·v₀·u_n**,　　c(a,x) := 1 − max_{0≤n≤a√x} Ψ_n(x, h_lo).

### 7.1 精确归约（把 Prop 4 的 (7) 换成本文常数底）

cone-coercivity **定理 1（锥矫顽性）**：对任意非负核 φ，`⟨v,𝒪[φ]v⟩ ≥ κ_{L3}[φ,v] :=
Σ_{n,m} φ(n+m+1) u_n u_m v_n v_m`（其证明只用 v∈C 的锥代数，非负逐项）。取 φ=g_E：

    E(x) = ⟨v,𝒪[g_E]v⟩ ≥ κ_{L3}[g_E,v] = Σ_{n,m} g_E(n+m+1) w_n w_m,　w=u∘v.

cone-coercivity **Prop 4 式 (7)** 给的行-n 廓线底是 `r_n := v_n/(v₀u_n) ≥ 2/(h+1) ∼ 1/ln x`
（**随 x 衰减**），代入其式 (8) 得 `κ_prof ∼ 1.6 v₀²/(x ln x)`——**丢一个 log**。

**本文定理**把 (7) 换成 `r_n ≥ c(a,x)`（**常数**、**无 h 压制**），即 `w_n = u_n v_n ≥ c·v₀·u_n²`。
代入同一 κ_{L3} 层，并把非负和**限制在 n,m ≤ a√x**（每项 ≥0，限制合法）：

    **E(x) ≥ κ_{L3}[g_E,v] ≥ c(a,x)²·v₀²·Φ_{≤a√x}(x)**,　Φ_{≤a√x} := Σ_{n,m≤a√x} g_E(n+m+1)u_n²u_m².   (7.1)

这正是 §7.4 缺口 #4 所要求的对象（其原话："a rigorous `v_n ≥ c v₀ u_n` for n≲√x would
immediately give κ_prof ≳ c²v₀²Φ ∼ 1/x"）。

### 7.2 log 抵消 ⟹ 真阶 1/x

(7.1) 给出 1/x 而非 1/(x ln x)，源于**两个 log 恰好抵消**（数值门 §7.6 逐条核验）：

- **Φ_{≤a√x} 保留完整 (ln x)/x 阶**（对任意固定 a>0）：实测 `x·Φ_full` 随 ln x **线性**上升，
  斜率 `d(x·Φ)/d(ln x) = 0.124–0.125`（即 Φ ∼ 0.125·(ln x)/x）；截断到 a=1 保留全 Φ 的 ~77%、
  a=½ 保留 ~40%，**两者仍 ∝ ln x**（只损常数，不损阶）。
- **v₀² ∼ 1/ln x**：实测 `v₀²·ln x` 随 x 缓升、保持 O(1)（1.88→2.87，趋于 ~4），
  且 N-收敛（v₀²=0.3761 @ x=1600、N∈{1360,2176}，差 <1%；主会话 N∈{1500,3000,6000} 得 0.376135）。

故 `c²·v₀²·Φ_{≤a√x} ∼ c²·(1/ln x)·(ln x/x) = const/x`。**判决量**（数值门）：
`x·v₀²·Φ(a=1)` 在 x∈[25,3600] 上**平坦 ≈ 0.378**（max/min<1.01），`a=½` 时 ≈ 0.20——
即 (7.1) 右端 = c²·(平坦常数)/x，**真阶 1/x**。对照：cone-coercivity 原 `κ_prof/E` 随 x 从
0.59 **降到** 0.09（丢 log），本文 thread-through/E（保守 c、a=½）从 0.017 **升到** ~0.12 的
**正常数**——与 E **同阶**。
