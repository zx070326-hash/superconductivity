## 1. 精确设定（与 `p4_remainder_interchange.py` 逐字一致）

KAY II 算子在固定 ϖ 上：ℌ(ϖ) = −ℌ₁(ϖ) + ℌ₂(ϖ) + ℌ₃(ϖ) on ℓ²(ℕ₀)，⟦n⟧(ϖ):=ϖ²/(n²+ϖ²)，
- (ℌ₁)_{nn} = (1/(2n+1)) Σ_{k=1}^n 2⟦k⟧(ϖ)　（对角，n=0 时为 0）
- (ℌ₂)_{nm} = (1−δ_{nm}) ⟦|n−m|⟧(ϖ) / √((2n+1)(2m+1))
- (ℌ₃)_{nm} = ⟦n+m+1⟧(ϖ) / √((2n+1)(2m+1))

**关键结构事实（脚本 `H_matrix` 逐字核）**：(n,m) 矩阵元的解析式**只依赖 n,m,ϖ，不依赖截断维数 N**。故

  **ℌ^(N)(ϖ) = P_N ℌ(ϖ) P_N**，　P_N = 前 N 个坐标上的正交投影，　　(1)

## 2. 三根支柱

### 2.1 支柱一 · 压缩的算子范数收敛（含显式尾率）

**引理 1（标准）.** A 紧自伴 ⟹ ‖A − P_N A P_N‖ → 0。证：A − P_N A P_N = (I−P_N)A + P_N A(I−P_N)，故
  ‖A − P_N A P_N‖ ≤ ‖(I−P_N)A‖ + ‖A(I−P_N)‖ = 2‖(I−P_N)A‖　　(2)
（末式用 A 自伴 ‖A(I−P_N)‖=‖((I−P_N)A)^*‖=‖(I−P_N)A‖）。A 紧 ⟹ ‖(I−P_N)A‖→0。∎

**显式尾率（认证用）.** 用 HS 范数放大算子范数：
  ρ_N(ϖ) := 2‖(I−P_N)ℌ(ϖ)‖_HS = 2 ( Σ_{n≥N} Σ_{m≥0} ℌ_{nm}(ϖ)² )^{1/2}．　　(3)
- 对角 ℌ₁ 贡献：(ℌ₁)_{nn} ≤ C₁(ϖ)/(2n+1)，C₁(ϖ):=2Σ_{k≥1}⟦k⟧(ϖ)=πϖ coth(πϖ)−1（闭式，用 Σ_{k≥1}ϖ²/(k²+ϖ²)=(πϖcoth πϖ−1)/2）。**注意**：对角算子的算子范数 = max 元 ~ C₁/(2N)，比 HS 尾（~1/√N）更快；认证时对 ℌ₁ 用 max-元界 max_{n≥N}(ℌ₁)_{nn}，对 ℌ₂+ℌ₃ 用 HS 尾界（zeta/积分估计，仿 P4-C `prop5_tail`）。
- ⟹ ρ_N(ϖ) 有显式、可认证的 →0 上界。数值预估（ϖ̄≈1）N₀≈30–40 即足（与 T5 观察 gap 在 N~32 稳定一致）。

### 2.2 支柱二 · 极限算子的单一性（KAY 自己的机器）+ 认证谱隙下界

真算子 A=ℌ(ϖ)（或 𝔎(P,T)）紧自伴，谱离散、仅在 0 处凝聚。分两步：

**2.2a 单一性（定性，用 KAY 现成的正算子改写，researcher finding 3，A 级）.** KAY **不对 𝔊/𝔎 直接用 Perron–Frobenius**（−𝔎₁ 破坏逐元素正性）。他们把顶本征值问题改写成正算子不动点：**ℭ(η) := (ηℑ + 𝔎₁)⁻¹(𝔎₂ + 𝔎₃)**（KAY II eq.(46), p.20），负号被吸进对角**正**预解式 (ηℑ+𝔎₁)⁻¹>0，而 𝔎₂+𝔎₃ 逐元素正 ⟹ ℭ(η) 逐元素正紧 ⟹ Krein–Rutman：ρ(ℭ(η))=1 的本征模在正锥、**单一**。等价性（researcher 自算，B 级，我方复核）：ℭ(η)Ξ=Ξ ⟺ 𝔎Ξ=ηΞ，故 η=𝔤 时 ρ(ℭ)=1 的单一性 ⟺ **𝔎 顶本征值 𝔤 单一**。KAY 在 γ-model 侧（p.25）逐字写了此结论（"non-degenerate … by Krein–Rutman"，有限秩侧 Perron–Frobenius）；**标准 Eliashberg 侧 𝔨(P,T) 未明写单一性**——我方补一句与 p.25 逐字平行的陈述即可（KAY 自称 "straightforward adaptation"，很便宜）。⟹ **顶本征值单一对所有 P、所有 ϖ 定性成立，不依赖数值。**
- 副产物：单一性正是 Corollary 3（p.13）末句「N→∞ 亦成立」隐含依赖的本征向量收敛的前提（researcher finding 5，B 级）——KAY 一字未证，本文件补上。

**2.2b 认证谱隙下界 δ(ϖ)（定量，供支柱三的 Weyl 用）.** 单一性给 δ>0 的存在性，但支柱三需要**显式正下界**：
- 下界 λ₁ ≥ μ(ϖ)：Rayleigh 商（几何试探向量或 N=400 顶本征向量），严格（有限支撑精确内积）。
- 上界 λ₂ ≤ α(ϖ)：**P4-C 的 Cholesky-deflation α-证书**（cI−P_{N_a}AP_{N_a} SPD 的 Cholesky 判定 + 解析尾界），γ=2 已给 λ₂(𝔊)≤2.0e-2；对 ℌ(ϖ̄) 同法。
- ⟹ δ(ϖ) := μ(ϖ) − α(ϖ) > 0 认证。（单一性由 2.2a 独立保证，α-证书只负责量化 δ，两者互不循环。）

### 2.3 支柱三 · Weyl 稳定 + 有限直查 ⟹ inf_N gap_N 有正下界

Weyl 不等式（自伴，逐指标）：|λ_k(A_N) − λ_k(A)| ≤ ‖A_N − A‖ ≤ ρ_N(ϖ)。故
  gap_N(ϖ) = λ₁(A_N)−λ₂(A_N) ≥ [λ₁(A)−ρ_N] − [λ₂(A)+ρ_N] = gap(∞,ϖ) − 2ρ_N(ϖ) ≥ δ(ϖ) − 2ρ_N(ϖ)．　(4)
取 N₀(ϖ) := min{N : 2ρ_N(ϖ) < δ(ϖ)/2}（引理 1 保证存在、支柱一给显式 N₀）。则

  **inf_{N≥2} gap_N(ϖ) ≥ min( min_{2≤N<N₀} gap_N(ϖ)，δ(ϖ)/2 ) =: g_*(ϖ) > 0**．　　(5)

（min_{2≤N<N₀} 是有限个有限矩阵的谱隙，每个 >0 且可直接计算/认证。）

### 2.4 一致性 in ϖ̄ 与诚实边界

上三支柱在**每个固定 ϖ̄** 给 g_*(ϖ̄)>0。对 Tc 相关的**紧区间** [a,b]⊂(0,∞)（a>0）：ρ_N(·)、δ(·)、gap_N(·) 均随 ϖ̄ 连续（矩阵元及其本征值连续依赖 ϖ），紧集上取 inf 得 **inf_{ϖ̄∈[a,b]} g_*(ϖ̄) =: g_** > 0**。
- **诚实边界（必须前置写）**：ϖ̄→0 时 ⟦n⟧(ϖ)=ϖ²/(n²+ϖ²)→0 ⟹ ℌ(ϖ̄)→0、所有本征值→0、gap→0——**一致性在 ϖ̄→0 失效**。但 Tc 条件 𝔨(P,T_c)=1/λ 把 ϖ̄=⟨ω⟩/2πT_c 钉在离 0 有界的有限值（物理 λ 给 ϖ̄∈[a,b]，a>0）。此即 U5「给定 λ 的严格 Tc 上界」框架——**λ 侧的物理上界另论，与本换序一致性逻辑独立**。
- ϖ̄→∞ 端：算子范数与 B₂/B₄ 随 ϖ̄ 增大（−𝔊₁ 前若干对角元 ~ϖ̄），故上区间端 b 取物理有限值即可，非障碍。

## 3. 组装：K_N 一致 ⟹ 真算子的 O(σ⁴) 定理

T5 的常数（`p4_remainder_interchange.py` 逐字）：
  K_N(ϖ̄) = ϖ̄⁴B₄ η_max²/24 + ¼ ϖ̄⁴ B₂² / (gap_N − ϖ̄²B₂σ₀²)，　B₂=sup_J‖ℌ^(N)″‖，B₄=sup_J‖ℌ^(N)⁗‖．

- **B₂,B₄ 一致于 N（免费）**：ℌ^(N)^{(j)}(ϖ)=P_N ℌ^{(j)}(ϖ)P_N（逐元素 ϖ-求导与固定指标截断可换），压缩不增范数 ⟹ ‖ℌ^(N)^{(j)}‖ ≤ ‖ℌ^{(j)}(ϖ)‖，后者是极限算子的算子范数（HS，认证）。故 B₂≤B₂^∞, B₄≤B₄^∞ 一致于 N。
- **分母一致**：gap_N ≥ g_** > 0（§2.4）、B₂≤B₂^∞ ⟹ 取 σ₀ 足小使 ϖ̄²B₂^∞σ₀² < g_**/2，则分母 ≥ g_**/2 一致。
- ⟹ **K_N(ϖ̄) ≤ K_*(ϖ̄) := ϖ̄⁴B₄^∞η_max²/24 + ½ϖ̄⁴(B₂^∞)²/g_** < ∞，一致于 N**。

**定理（P4-换序，条件性消除）.** 设 P 紧支、定形族（|ξ|≤σ·η_max、有界峭度，U6），ϖ̄∈[a,b]⊂(0,∞)。则极限 κ(ϖ̄):=lim_N κ_N(ϖ̄)、c₃(ϖ̄):=lim_N c_{3,N}(ϖ̄) 存在（顶本征向量范数收敛，由 §2 谱隙 + 范数收敛保证），且真算子满足

  | 𝔎(P,T) − 𝔥(ϖ̄)(1 + ½κ(ϖ̄)σ² + c₃(ϖ̄)γ₃σ³) | ≤ K_*(ϖ̄) σ⁴，　　(6)

其中 𝔥(ϖ̄)=ρ(ℌ(ϖ̄))（或 𝔎 的 P-积分版）。**证**：对每个 N，T5 Part 1 给 |𝔨^(N)−𝔥^(N)(…)| ≤ K_N σ⁴ ≤ K_* σ⁴。令 N→∞：𝔨^(N)→𝔨（引理 1 + Weyl，λ₁ 连续）、𝔥^(N)→𝔥、κ_N→κ、c_{3,N}→c₃（§2 谱隙保证顶本征向量收敛）。取极限得 (6)，常数 K_* 与 N 无关故过极限保持。∎

**⟹ T5 顶命题（真算子 O(σ⁴) 展开）由「条件性成立」升为「定理」**，在 ϖ̄∈[a,b]（物理 Tc 区间）、定形族假设下无条件。C_∞ 作为真 Tc 渐近常数的严格性、以及把展开用于 Conjecture 2 的路径，其换序障碍随之清除（保留 λ 侧 U5 与 μ*=0 的 U4 系统性限制）。

**推论（一般-P 收敛，独立于 σ-展开的干净增量）.** 支柱一（引理 1：‖A−A_N‖→0）+ 支柱三（Weyl 逐指标）已直接给出：对**任意** P∈𝒫、任意 T>0，

  𝔨^(N)(P,T) → 𝔨(P,T)　（N→∞），且由嵌套压缩的 min-max 单调 **𝔨^(N)↑𝔨**（上收敛）。　　(7)

**这正是 KAY II 只以散文断言、正文未证的命题**（Theorem 4 仅给不等式 Λ<1/𝔨^(N)；researcher finding 1，A 级）。(7) 是本文件不依赖 σ-展开、也不依赖谱隙的部分——半页标准泛函分析，**是我方相对 KAY 的独立、可单独陈述的贡献**。对外用中性措辞（"KAY 断言、我方给出证明"）。谱隙（支柱二）只在把展开的**系数** κ_N→κ、c_{3,N}→c₃ 传到极限时才需要（Davis–Kahan：本征向量收敛需单一性 + 正隙），(7) 的本征**值**收敛不需要。
