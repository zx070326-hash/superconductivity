## 0. 定位与结果摘要

命题 5（已合并）证明了**定性**结果：各向同性算子是各向异性算子的压缩（Qᵀ𝒜Q = λ̄·H），故 λ₁(𝒜) ≥ λ̄h(ϖ)，即各向异性从不降低线性化 Tc。本稿把它升级为**定量**：对 Tc 的增强量给出显式下界，且下界分子恰好是耦合矩阵各向异性的方差型度量。

**主结果（定理 A + 引理 1，证明全解析）**：设 𝒜 = 𝒜_aniso(ϖ) 为 S 片费米面的各向异性 KAY 算子，e 为 H(ϖ) 的单位顶本征向量，u := √w，λ̄ := wᵀλw，z := λw（Z-行和，即各带有效耦合），则

$$\boxed{\;\lambda_1(\mathcal{A}) \;\ge\; \bar\lambda\, h(\varpi) \;+\; \frac{h(\varpi)^2\,\mathrm{Var}_w(z)}{\bar\lambda\, h(\varpi) - \mu(\varpi)}\;}$$

其中 Var_w(z) := Σᵢwᵢzᵢ² − λ̄²，μ(ϖ) := λ_min(𝒜(ϖ))。分子是**纯纤维量**（与 Matsubara 结构无关），各向同性耦合时恒为零；Z-通道（重整化项）经恒等式 Mu = 0 **精确消失**（不是近似）。

**Tc 换算（定理 B）**：以 ϖ_i := h⁻¹(1/λ̄) 为各向同性参照临界点，则

$$\frac{T_c^{\mathrm{aniso}}}{T_c^{\mathrm{iso}}} \;\ge\; \frac{\varpi_i}{\hat\varpi}, \qquad \hat\varpi := \inf\{\varpi:\ \bar\lambda h(\varpi) + E(\varpi) \ge 1\},\quad E(\varpi) := \frac{h^2\,\mathrm{Var}_w(z)}{\bar\lambda h(\varpi)-\mu(\varpi)}.$$

## 2. 引理 1（纤维恒等式：Z-通道精确消失）

**引理 1.** 对任意实对称 λ 与概率权重 w：
(i) **Mu = 0**（u = √w）；
(ii) ⟨ψ,𝒜ψ⟩ = λ̄h（r = λ̄h，精确）；
(iii) **𝒜ψ − λ̄h·ψ = h·e⊗(Λu − λ̄u)**，从而
$$V := \|\mathcal{A}\psi - \bar\lambda h\,\psi\|^2 = h^2\,\|\Lambda u - \bar\lambda u\|^2 = h^2\,\mathrm{Var}_w(z).$$

*证.* (i) (Mu)ᵢ = Σⱼ Λ_ij√w_j − zᵢ√wᵢ = √wᵢ(Σⱼ λ_ij w_j − zᵢ) = 0。
(ii) 𝒜ψ = He⊗Λu + Ze⊗Mu = h·e⊗Λu（由 (i)），与 ψ = e⊗u 取内积：⟨ψ,𝒜ψ⟩ = h·uᵀΛu = hλ̄。
(iii) 由 (ii) 的第一行直接相减；范数用 ⊗ 正交：‖e⊗(Λu−λ̄u)‖² = ‖Λu − λ̄u‖²（e 单位）。而 (Λu)ᵢ = Σⱼ √wᵢλ_ij√w_j·√w_j = √wᵢ zᵢ，即 **Λu = √w∘z**，故 ‖Λu‖² = Σᵢwᵢzᵢ²，‖Λu − λ̄u‖² = Σᵢwᵢzᵢ² − λ̄² = Var_w(z)（uᵀΛu = wᵀz = λ̄ 已用）。∎

**物理诠释**：各向异性的自然载体是 **Z-行和 z = λw 的 FS 加权方差**——即「各带有效耦合的离散度」，而不是 λ_ij 矩阵本身的任何逐元素度量。z 常值 ⟺（对一般 w）耦合各向同性 ⟺ 增强界的分子为零。数值上 V_dir 与 h²Var_w(z) 在随机 S = 2, 3 矩阵上吻合到 ≤ 1e−11（Stage 0 门）。

**S = 2 的显式结构**（MgB₂/H₃S 算例用）：M = λ₁₂·[[−w₂, √w₁w₂], [√w₁w₂, −w₁]] = −λ₁₂·vvᵀ，v = (√w₂, −√w₁)——M 是秩 1 的、纯带间结构：带间耦合为零 ⟹ M = 0；M 的大小度量「两带_gap 通道混合强度」，且 Mu = 0 对所有 λ₁₂ 成立。

## 3. 定理 A（Bhatia–Davis 方差不等式 ⟹ 增强的显式下界）

**定理 A.** 设 A 有界自伴，spec(A) ⊆ [μ, λ₁]，λ₁ := max spec，μ ≤ min spec。对单位 ψ 记 r := ⟨ψ,Aψ⟩，V := ⟨ψ,A²ψ⟩ − r²。则
$$V \;\le\; (\lambda_1 - r)(r - \mu).$$
特别地，若 r > μ：**λ₁ − r ≥ V/(r − μ)**。

*证.* 谱定理 ψ = Σcᵢvᵢ，pᵢ := |cᵢ|²（Σpᵢ = 1）。r = Σpᵢλᵢ，⟨ψ,A²ψ⟩ = Σpᵢλᵢ²。逐点地，对 t ∈ [μ, λ₁]：g(t) := (λ₁−t)(t−μ) ≥ 0（凹二次，两端零点）。加权求和：
0 ≤ Σpᵢg(λᵢ) = −Σpᵢλᵢ² + (λ₁+μ)r − λ₁μ ⟹ ⟨A²⟩ ≤ (λ₁+μ)r − λ₁μ，
V = ⟨A²⟩ − r² ≤ (λ₁+μ)r − λ₁μ − r² = (λ₁−r)(r−μ)。∎

（这就是 Bhatia–Davis 方差界：随机变量取值于 [μ, λ₁] 时方差 ≤ 两端距离之积。等号 ⟺ ψ 的谱测度集中在 {μ, λ₁}；两带算例的紧度 ~0.3–0.6（§6），一致于「谱测度部分集中在两端」。）

**推论 A（本稿主界）.** 取 A = 𝒜(ϖ)、ψ = e⊗u、μ = μ(ϖ) := λ_min(𝒜(ϖ))（任一更低下界亦可）、r = λ̄h、V = h²Var_w(z)（引理 1）。**条件 r > μ 无条件成立**：解析粗界 μ_c := −‖Λ‖‖H‖ − ‖M‖‖Z‖ < 0 < λ̄h = r，而把 μ 换成任何更低的 μ_c 只会放大 (r−μ)（界变宽但有效）；数值上精确 μ(ϖ_i) ∈ [−0.74, −0.50]（三个算例）：
$$\lambda_1(\mathcal{A}(\varpi)) \;\ge\; \bar\lambda h(\varpi) + \frac{h(\varpi)^2\,\mathrm{Var}_w(z)}{\bar\lambda h(\varpi) - \mu(\varpi)}.$$

**三条 remarks。**
1. **无隙条件**。经典 Temple–Kato 上界形式需要 λ₁ − λ₂ 隙；本界只触谱的**下端点** μ——因为 g(t) ≥ 0 在整段 [μ, λ₁] 成立，不需要隔离任何本征值。这就是「费米面耦合矩阵（及截断算子）是有限维的、谱直接可算」这一输入的准确位置：**μ 是有限矩阵的最小本征值，与主稿无穷维 ℌ 的隙证书（引理 C）毫无关系**。
2. **各向同性退化**。Var_w(z) = 0 ⟹ 界右端第二项为 0，退化回命题 5 的 λ₁ ≥ λ̄h；且此时 λ₁(𝒜) = λ̄h **精确成立**（§6 Gate 3：数值增强 ≤ 1e−8，因为各向同性耦合时 𝒜 = λ̄[wwᵀ⊗L23 − I⊗Z]，在 range(Q) 上二次型 = λ̄⟨·,H·⟩，在 w⊥ 上 ≤ 0）。定性（命题 5）与定量（本稿）在极限处一致。
3. **纤维级变体（推论 A′）**。同一个 Bhatia–Davis 用于 S×S 阵 Λ 本身（试验向量 u）：
   $$\lambda_{\max}(\Lambda) - \bar\lambda \;\ge\; \frac{\mathrm{Var}_w(z)}{\bar\lambda - \lambda_{\min}(\Lambda)}.$$
   这给「耦合矩阵各向异性度量 ⟹ 增强量」一条**只用 S×S 谱**的显式链，但其分母是 λ_min(Λ) 而非 μ(𝒜)；注意它**不能**与 λ₁(𝒜) 直接拼接——见 §5.4（h·λ_max(Λ) 是 λ₁(𝒜) 的上估计而非下估计，实测在三个算例全部偏高）。

## 4. 定理 B（Tc 换算：不是线性的，要过 h⁻¹）

固定 (λ_ij, w, ω_E)。令 ϖ := ω_E/(2πT)，G(ϖ) := λ₁(𝒜(ϖ))（耦合已折进算子；临界定理 λ𝔨 ≥ 1 的各向异性版本即 G ≥ 1）。Tc 用**sup 约定**（与主稿 §8 的注一致）：
$$T_c^{\mathrm{aniso}} := \frac{\omega_E}{2\pi}\cdot\sup\{\tfrac{1}{\varpi}:\ G(\varpi)\ge 1\}.$$
各向同性参照：G_iso(ϖ) = λ̄h(ϖ)，ϖ_i := h⁻¹(1/λ̄)（h 于 (0,∞) 严格递增——主稿推论 (i)，定理级）。

**定理 B.**
(i) **T_c^aniso ≥ T_c^iso**。*证*：G(ϖ_i) ≥ λ̄h(ϖ_i) = 1 ⟹ ϖ_i ∈ sup 集。∎（不用单调性）
(ii) **定量换算**。令 E(ϖ) := h(ϖ)²Var_w(z)/(λ̄h(ϖ) − μ(ϖ))（定理 A 的界，逐点成立），且 ϖ̂ := inf{ϖ : λ̄h(ϖ) + E(ϖ) ≥ 1}（非空：ϖ_i 属之；下有界；λ̄h 连续、μ(ϖ) 是连续矩阵族的本征值故连续 ⟹ 集合闭，inf = min）。则
$$T_c^{\mathrm{aniso}} \ge \frac{\omega_E}{2\pi\,\hat\varpi} \quad\Longrightarrow\quad \frac{T_c^{\mathrm{aniso}}}{T_c^{\mathrm{iso}}} \ge \frac{\varpi_i}{\hat\varpi} =: \rho_{\mathrm{bound}}.$$
*证*：在 ϖ̂ 处 G(ϖ̂) ≥ λ̄h(ϖ̂) + E(ϖ̂) ≥ 1 ⟹ ϖ̂ ∈ sup 集。∎
(iii) **真值比**：数值上 G(ϖ) 在 (0, 60] 严格递增（26 点对数网格，Stage 4 门；这是**数值事实不是定理**——各向同性情形的相应单调性是定理（主稿定理 1(b)），各向异性情形未证），故交点唯一，记 ϖ_a := G⁻¹(1)，ρ_true := ϖ_i/ϖ_a ≥ ρ_bound。

**非线性 remark（为什么必须过 h⁻¹）**。临界点附近 λ̄h(ϖ_c) ≈ 1，把增强吸收所需的质量为 Δϖ ≈ enh/(λ̄h′)，故
$$\delta T_c/T_c \approx \Delta\varpi/\varpi_c \approx \frac{enh}{\varpi_i\,\bar\lambda\,h'(\varpi_i)} \neq enh$$
（enh → E(ϖᵢ) 得下界版）。**自洽性验证（M1，N=40）**：真增强 enh_crit = 0.1633、ϖᵢh′ = 0.954 ⟹ 线性化 δTc/Tc ≈ 0.1633/(0.954·0.4993) = 0.343 vs 精确 ρ_true − 1 = 0.345——换算公式与 h⁻¹ 根一致到线性阶。ϖh′ < 1 时本征值增强被**放大**（MgB₂：0.16 → 34%）；H₃S：ϖh′ = 0.594，放大更强但 enh 本身只有 0.5%。换算不是线性的，也不可用「ΔTc/Tc = ½Δλ/λ」式的强耦合标度代替（§5.4）。

## 7. 诚实边界

**严格性分类（一行，不可漏读）**：定理 A / 定理 B 在**有限 N**下是解析证明（μ 取同一截断矩阵的精确 λ_min，非外部粗界，见 §1「μ 的来源」）；物理上关心的 N → ∞ 极限增强量仅由 Gate 5 的双 N 数值稳定性（~1e−5）支持，**未经严格论证**；G(ϖ) 的各向异性单调性同样**未证明**（仅 26 点网格数值事实，定理 B 的 sup 约定不依赖它，但「交点唯一」的读法依赖它）。

1. **模型**：所有带共用单一 Einstein 频率（承命题 5 的设置）；带分辨 α²F_ij(ω) 不在算子内。MgB₂ 的 σ/π 频率分离、H₃S 的真实 α²F(k,ω) 形状都被抹平——故绝对 Tc 只作 context，交付量是同模型内的比值。
2. **参数**：λ_ij、w_i 为代表性示意值（一手数据未能获取——WebSearch 不可用；出处按文献名给出，数值待 cite-check 后替换）。锚「1.05–1.10」系任务给定；其**定义**（对哪个参照系的增强）在两带文献中不唯一，本稿统一用 λ̄-平均参照（与命题 5 的压缩恒等式同构）。
3. **单调性**：G(ϖ) = λ₁(𝒜(ϖ)) 的严格递增是数值事实（26 点网格），非定理；定理 B 用 sup 约定**不依赖它**，它只影响「交点唯一」的读法与二分求根的合法性。各向异性单调性的解析证明是遗留问题。
4. **N→∞**：所有量取 N = 40 截断值；Gate 5 的双 N 一致（~1e−5）支持稳定性，但本稿未做无穷维算子的严格包围过渡（与主稿 (vi) 的单调收敛机制相容，未形式化）。
5. **紧度**：界在随机系综的紧度 ~0.3–0.7（门 2），不是渐进锐的；两带情形等号条件（谱测度集中于 {μ, λ₁}）不满足。想把界推紧需要 Davis–Kahan 型的二阶修正，未做。
6. **μ 的截断依象**：μ(ϖ) 取截断谱端点；若换解析粗界 μ ≥ −‖Λ‖‖H‖ − ‖M‖‖Z‖，界变宽但仍成立（门 0 的 BD 检查即按「任一下界可行」设计）。
