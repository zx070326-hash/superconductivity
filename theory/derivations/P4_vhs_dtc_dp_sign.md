# P4 · van Hove 奇点到 ε_F 的距离如何决定 dTc/dP 的符号（H3S 圆顶）

作者：主会话　状态：**v0.1（2026-09-08，经 `p4-review2` 对抗性核验加固；数值验证 `p4-numerics` 与一手数据 `p4-vhs-data` 在跑）**
**一句话**：把 ε_F 附近 van Hove 峰到费米面的能量距离 δ 当作压力可调旋钮，能量依赖 DOS 的 Eliashberg 给出一个**窗口平均增强因子** E(δ)（宽度 = 峰本征宽 Γ + 推迟窗 ~ω_log 的洛伦兹）。dTc/dP 分解为**vHs 增强项**（正，当峰随压力趋近 ε_F）与**声子硬化背景项**（负，λ 随压力减小压过 ω_log 变硬）。圆顶峰 = 两项平衡；vHs 是否穿过 ε_F 决定峰被"钉"在穿越点附近（穿）还是纯平衡点（不穿）——H3S 数据定位。

**v0.1 可信度分层（reviewer 核验后必读）**：
- **机器精度已验证**：(2)(3)(6) 的代数（scipy 无穷限数值积分 + 有限差分，误差 1e-12~1e-14）；§4 极限表六行。
- **稳健结论**：符号判据 **sign(dE/dδ)=−sign(δ)**——在更一般的多宽度 Matsubara 窗求和下严格保持，比 (4) 的单洛伦兹形式可信度更高。
- **近似（非精确）**：(4) 的单一宽度 W_eff 洛伦兹是插值（真实是多宽度窗之和；玩具模型示等效宽度在 δ=0 与尾部差 ~18%）。峰位、两侧斜率这类**定量**预言依赖它，符号级结论不依赖。
- **v0.1 待验证的核心假设（最重要的未决项）**：§1 的"δ 是主旋钮"是**假设、非论证**——(5) 补入了 a(P)、Γ(P)、μ*(P) 的直接项，其相对量级须由 `p4-numerics` 扫 ∂lnTc/∂a、∂lnTc/∂Γ vs ∂lnTc/∂δ 判定。若接近 Lifshitz 转变时峰高/峰宽演化压过峰位移动，框架需重新称量。

关系：与 P2 §5 同源（都由 ε_F 附近 DOS 结构设定"有效能标"）；是 Bianconi–Jarlborg Lifshitz / Quan–Pickett vHs 图像的定量 DOS-Eliashberg 版；P1b §3.4 已把它列为 α(P) 的竞争机制之一，P4 给它解析形式。

## 0. 问题

H3S 立方相 Tc(P) 是一个圆顶：~195 K@141 → **~203 K@155（峰）** → ~170 K@200–230（Drozdov 2015，`surveys/h3s_tc_of_p_alpha_of_p_2026-09-08.md`）。ε_F 附近有一个来自 S–H σ 键鞍点的 van Hove/平带峰（Quan–Pickett 2016；Bianconi–Jarlborg 2015）；Mishra 记其 @200 GPa 在 ε_F 下方 ~40–50 meV 且随压力趋近 ε_F（P2 §5.5，待 `p4-vhs-data` 回原文核实）。

**问**：把 vHs 到 ε_F 的距离 δ(P) 当旋钮，能否解析地给出 dTc/dP 的符号，进而定位圆顶峰？峰是不是就在 vHs 穿过 ε_F 处？

## 1. 模型 DOS

ε_F 处 ξ=0，vHs 峰在 ξ = −δ（δ>0 表示峰在 ε_F 下方）。取归一化 DOS

  N(ξ)/N_b = 1 + a · Γ² / [ (ξ+δ)² + Γ² ]　　(1)

N_b 背景 DOS，a 峰的相对高度（峰值处 1+a），Γ 峰半宽（HWHM）。压力通过 **δ(P)、a(P)、Γ(P)** 进入；主旋钮是 δ(P)（峰相对 ε_F 的位置），dδ/dP<0 表示峰随压力趋近 ε_F。用洛伦兹是为了下面能闭式卷积；真实 3D 鞍点是单边 √ 型、2D 是对数型（§4 讨论形状敏感性）。

## 2. 能量依赖 DOS 的 Eliashberg → 窗口平均增强 E(δ)

各向同性、能量依赖 DOS 的线性化 φ=ZΔ 方程在 Tc（φ→0）：

  φ(iω_n) = πT Σ_m [λ(n−m) − μ*(ω_c)] · ∫dξ (N(ξ)/N_b) · φ(iω_m) / ( ω̃_m² + ξ² )，　ω̃_m ≡ ω_m Z_m

ξ 积分是把归一化 DOS 对一个 HWHM=|ω̃_m| 的洛伦兹窗（中心在 ε_F）做平均：

  ∫dξ (N/N_b)/(ω̃_m²+ξ²) = (π/|ω̃_m|) · Ñ(|ω̃_m|)，
  **Ñ(W) ≡ (W/π)∫dξ (N(ξ)/N_b)/(ξ²+W²)**　　(2)

即：能量依赖 DOS 相对常数 DOS，把第 m 项乘以 Ñ(|ω̃_m|)——**一个中心在 ε_F、HWHM 等于该 Matsubara 频率的 DOS 窗口平均**（Kirzhnits–Maksimov–Khomskii / Pickett 能量依赖 DOS 形式）。**隐含假设（KMK 框架标准输入，v0.1 显式列出）**：Z_m、φ_m 视为 ξ-局域（不依赖能带位置 ξ），故可提出 ξ 积分外。对 (1) 式两个洛伦兹的卷积闭式：

  Ñ(W) = 1 + a · Γ (Γ+W) / [ δ² + (Γ+W)² ]　　(3)

配对由 |ω_m| ≲ ω_log 的项主导（λ(n−m) 在 ω_log 以上按 (ω_log/ω)² 衰减），故进入 Tc 的**有效增强**取窗宽 W ~ c·ω_log（c~O(1)，含 Z 与 Matsubara 截断）：

  **E(δ) ≡ Ñ(W~ω_log) = 1 + a·Γ·W_eff / (δ² + W_eff²)，　W_eff ≡ Γ + c·ω_log**　　(4)

**E(δ) 是 δ 的洛伦兹，宽度 = 本征峰宽 + 推迟窗**。极限自洽（§4）：W→0,δ=0 → E=1+a（峰完全分辨）；W→0,δ≠0 → E=1+aΓ²/(δ²+Γ²)=N(ε_F)/N_b（就是费米面处 DOS 值）；W 大 → E→1+aΓ/W（峰被抹平，增强 ~ 面积/窗宽）。**推迟只展宽有效峰、不移动其极大（对称峰极大恒在 δ=0）**。

**(4) 是插值近似，不是精确结果（reviewer 核验）**：真实情形是对不同 m 各自宽度 |ω̃_m| 的洛伦兹窗 Ñ(|ω̃_m|) 按核 [λ(n−m)−μ*] 加权求和，多宽度洛伦兹之和不是单一宽度洛伦兹。玩具求和（7 个 Matsubara 模式、类 (ω_log/ω)² 权重）示：从 δ=0 取值反推的等效宽度与从尾部反推的差 ~18%。**因此把 (4) 的单一 W_eff 当精确函数只在半定量意义上成立；峰位、圆顶两侧斜率这类定量预言受此近似限制，须由 §5 数值直接解校准。但下面 §3 的符号判据不依赖 (4) 的精确形式**——见 (6) 下方。

**μ* 通道**：subtraction [λ(n−m)−μ*] 在 ξ 积分前发生，故同一 Ñ(|ω̃_m|) 也乘 μ*。但 μ*(ω_c) 的求和延伸到 ω_c ≫ ω_log，大 m 处窗宽 W~ω_c 使 Ñ(W~ω_c)≈1（峰被抹平）——物理上支持"vHs 峰不显著增强 μ*"（与 §7 直觉一致）。但把窗口平均叠加在已按常数 DOS 做过 Tolmachev 约化的 μ*(ω_c) 上，两层近似的自洽性未经推导，是 §7 承认的待填坑。

## 3. dTc/dP 分解与符号判据

Tc 由完整 Allen–Dynes（含 f₁、f₂ 强耦合因子）给出——**下面只用 Λ ≡ ∂ln Tc/∂λ_eff > 0 这一单调性**，不展示闭式（裸 McMillan = AD 在 f₁=f₂=1 的退化，在 λ_eff=1.8–2.6 低估 Λ 达 27%–61% 且随 λ 恶化，reviewer 实测；§5 的 Λ 与 Tc 一律由求解器直接解全非线性 Eliashberg 得到，不套闭式）。

λ_eff = λ_b·E(δ, a, Γ) 同时依赖峰位 δ、峰高 a、峰宽 Γ（三者皆随 P 变）。Tc 还直接依赖 ω_log、μ*。完整全微分：

  **d ln Tc/dP = ∂lnTc/∂lnω_log·(dlnω_log/dP) + Λ·dλ_eff/dP + ∂lnTc/∂μ*·(dμ*/dP)**　　(5)
  dλ_eff/dP = E·(dλ_b/dP) + λ_b·[ **∂E/∂δ·(dδ/dP)** + ∂E/∂a·(da/dP) + ∂E/∂Γ·(dΓ/dP) ]

其中（(6) 已用有限差分验到 1e-12）：

  ∂E/∂δ = −2δ·(E−1)/(δ²+W_eff²)，　**sign(∂E/∂δ) = −sign(δ)**（多窗口求和下严格保持，最稳健的结论）　　(6)
  ∂E/∂a = ΓW_eff/(δ²+W_eff²) > 0，　∂E/∂Γ = a·[(δ²+W_eff²)(2Γ+cω_log) − ΓW_eff·2W_eff]/(δ²+W_eff²)²

**核心假设（v0.1 明确为假设、待 §5 数值检验，不再当既定）**：把 **δ(P) 当主旋钮**，即假定 vHs 增强项 Λλ_b·∂E/∂δ·(dδ/dP) 在量级上压过峰形项 ∂E/∂a·(da/dP)、∂E/∂Γ·(dΓ/dP)。物理理由（仅是理由、非证明）：压力区间内峰**位置**相对 ε_F 变 O(0.1 eV)（甚至穿越），而峰的**内禀形状** a、Γ 是能带属性、分数变化较慢。**但接近 Lifshitz 转变时 a、Γ 可能快速演化甚至主导**——`p4-numerics` 将测 ∂lnTc/∂δ、∂lnTc/∂a、∂lnTc/∂Γ 三者及（配 `p4-vhs-data` 的 dδ/dP、da/dP、dΓ/dP 量级）三乘积的相对大小来裁决。若假设不成立，"δ 竞争判据"需重新称量。

在 δ 主导假设下，(5) 归为两项（其余为高阶）：

- **vHs 增强项**　T_vHs = Λ·λ_b·(∂E/∂δ)·(dδ/dP)
- **背景项**　　　T_bg = ∂lnTc/∂lnω_log·(dlnω_log/dP) + Λ·E·(dλ_b/dP) + ∂lnTc/∂μ*·(dμ*/dP)

**判据**（**符号级结论，不依赖 (4) 的洛伦兹精确形式，只用 (6) 的符号**）：
1. vHs 在 ε_F 下方（δ>0）且随压力趋近（dδ/dP<0）：(6) 给 ∂E/∂δ<0，×(dδ/dP<0) ⇒ **T_vHs>0**（增强随压力涨，抬 Tc）。
2. 声子硬化：d ln ω_log/dP>0（抬 Tc 前因子）但 dλ_b/dP<0（压 Tc）；强耦合下 Λ·λ_b·|dλ_b/dP| 通常压过 ω_log 增益 ⇒ **T_bg<0**（耦合随压力减弱，压 Tc）。这条"硬化压过前因子"是**经验规律、非模型内证明**（圆顶必然存在依赖它成立）。
3. **圆顶峰（dTc/dP=0）= T_vHs = −T_bg**：正的 vHs 增强增益恰好被负的硬化背景抵消。
   - **|T_vHs|>|T_bg|**：dTc/dP>0，圆顶上升沿（峰下方），vHs 增强赢。
   - **|T_vHs|<|T_bg|**：dTc/dP<0，圆顶下降沿（峰上方），硬化背景赢。

**两条须明示的隐含假设（reviewer）**：
- **T_bg 并非严格独立于 δ**："背景项"含 Λ·E(δ)·(dλ_b/dP)，经 E(δ) 隐含依赖峰位。穿越点附近（δ→0，∂E/∂δ→0）把它当常数是二阶精度、合理；但离穿越点较远时 T_bg 是 δ 的缓变函数，影响"圆顶两侧斜率"的**定量**值，不影响符号级结论。
- **dδ/dP 在感兴趣区间内保号**（默认峰单调趋近，dδ/dP<0）。若非单调（Lifshitz 演化中峰先远离后趋近），T_vHs 随 dδ/dP 反号而反号（∂E/∂δ 的 −sign(δ) 结构不变），产生额外 dTc/dP=0 点 ⇒ 圆顶出现肩部/次级峰。本模型不排除此情形，作为显式假设列出。

**峰的位置——两种情形，由"vHs 是否穿过 ε_F"决定**：

- **(a) 穿过 ε_F**（δ 在区间内过零）：δ→0 时 (6) 给 dE/dδ→0 ⇒ T_vHs→0，故在穿越点 dTc/dP = T_bg < 0——**穿越点已在峰之上**；峰在略靠下方（δ*>0 小）处，即 **vHs 到 ε_F 前 Tc 已见顶**。穿越后（δ<0，峰移到 ε_F 上方）dE/dδ>0、dδ/dP<0 ⇒ T_vHs<0，与负背景**同号叠加** ⇒ 下降加速。**预言：圆顶不对称，高压侧（穿越后）比低压侧陡。**
- **(b) 不穿过 ε_F**（δ 始终 >0）：峰是纯 T_vHs 与 T_bg 的平衡点，δ* 有限；增强在全区间单调随压力增大，但在峰上方被硬化压过。

无论哪种，**dTc/dP 的符号 = vHs 增强增益与声子硬化背景的竞争；vHs 距离 δ(P) 设定增强项的大小与（情形 a 的）符号翻转**。

## 4. 极限检查

| 极限 | E(δ) / 结果 | 说明 |
|---|---|---|
| 平 DOS（a→0） | E→1，T_vHs→0 | dTc/dP 只剩背景项，退化到无 vHs 的常规硬化图像 ✓ |
| 峰在 ε_F（δ=0） | E=1+aΓ/(Γ+ω_log·c)（极大），dE/dδ=0 | 对称峰增强极大、增益项瞬时为零 ✓ |
| 无推迟（ω_log→0, W_eff→Γ） | E=1+aΓ²/(δ²+Γ²)=N(ε_F)/N_b | 回到 BCS-with-DOS：Tc 只看 ε_F 处 DOS 值 ✓ |
| 宽峰 Γ≫ω_log | W_eff≈Γ，E≈1+aΓ²/(δ²+Γ²)（推迟无关） | 峰比声子宽 → 就是局域 DOS 值，推迟不重要 ✓ |
| 窄峰 Γ≪ω_log | W_eff≈c·ω_log，E≈1+aΓω_log/(δ²+ω_log²) | 峰比声子窄 → 推迟窗展宽有效峰、削弱增强（∝Γ/ω_log），与 P2 §5.1 "DOS 缺损" 同一物理 ✓ |
| δ→∞（峰远离） | E→1 | 远处 vHs 不影响 ✓ |

与 P2 §5.1 的关系（**v0.1 弱化，reviewer**）：P2 的静态泛函 I(ω₀)−1（"DOS 缺损"）与这里的 E(δ)−1（"DOS 峰增强"）**共享数学结构**——都是 DOS 与一个能量尺度为 ~ω_log 的核做卷积平均，都指向"有效能标由 √(Γ²+ω_log²)-量级窗口设定、不是裸 E_F"。**但不是可靠的独立互证**：P2 自身 v0.7（§5.5–5.6）已把那个静态泛函降级为"数字上凑巧、无机制支持的代理量"（真正决定顶角符号的是 Z/Δ 两通道结构，不是静态 DOS 缺损）。所以此处只主张**数学结构相似**，物理机制是否同源**未定**；不把 P2 §5.1 当作 P4 的佐证锚点。

## 5. 数值验证计划（`p4-numerics` 在跑）

复用 `theory/solvers/eliashberg_iso.py`（支持能量依赖 DOS N(ε)、质量缩放、库仑核）。**铁律：所有 Tc 与 Λ 由求解器直接解全非线性 Eliashberg 得到，不套 McMillan/AD 闭式**（绕开 §3 提到的 Λ 偏差争议——reviewer 指出这是 P4 定量预言可信的前提）。
1. **验证 E(δ) 闭式**：放入模型 DOS (1)，固定 λ_b、ω_log、μ*，扫 δ，求解器直接测 Tc(δ)；用常数 DOS 下的 Tc↔λ 映射（同一求解器）反解 λ_eff(δ)、得 E_num(δ)。与 (4) 拟合定标 c。**同时报告：δ=0 附近拟合的 W_eff vs 尾部拟合的 W_eff 是否一致**（量化单窗口近似误差，reviewer 玩具模型预期 ~18% 漂移）。
2. **验证符号 (6)**：确认 sign(∂E/∂δ)=−sign(δ) 严格成立（比洛伦兹形式更稳健）；扫 δ 跨零，看穿越时的加速下降（情形 a 不对称）。
3. **★ 检验"δ 主旋钮"假设（v0.1 新增，最关键）**：在基线点独立扫峰高 a、峰宽 Γ，测 ∂lnTc/∂a、∂lnTc/∂Γ，与 ∂lnTc/∂δ 同表比量级；配 `p4-vhs-data` 的 dδ/dP、da/dP、dΓ/dP 量级，比三乘积 ∂lnTc/∂δ·(dδ/dP) vs ∂lnTc/∂a·(da/dP) vs ∂lnTc/∂Γ·(dΓ/dP)。**这决定 §3 的核心假设成不成立**——若峰形项同量级或更大，框架需重构。
4. **复现 H3S 圆顶**：用 `p4-vhs-data` 的 δ(P)、λ_b(P)、ω_log(P)、a(P)、Γ(P)，求解器解 Tc(P)，与 Drozdov 圆顶（峰 155 GPa、两侧斜率）比。检验点：峰位、是否不对称、dTc/dP 两侧符号。
5. 非谐/量子核只经 λ_b(P)、ω_log(P) 进入，不单列。

## 7. 假设与不确定

- **★ 最大未决：δ 是主旋钮（假设，非论证）**——(5) 已保留 a(P)、Γ(P)、μ*(P) 直接项，δ 主导须由 §5.3 数值裁决；接近 Lifshitz 转变时峰高/峰宽可能主导，则框架需重构。见 §3。
- **dδ/dP 在感兴趣区间内保号**（否则圆顶出肩部/次级峰，§3）。
- **(4) 单窗口洛伦兹是插值**（多宽度 Matsubara 窗之和，~18% 宽度漂移）；峰位/斜率等定量预言受限，符号级结论 (6) 不受限。
- **μ* 的竞争未细算（折进背景）**：vHs 在 ε_F 也抬高 N(ε_F) → 抬高裸 μ；但 μ*(ω_c)=μ/[1+μ ln(E_F/ω_c)] 的 Tolmachev 对数在窄峰下缩短（有效 E_F ~ W_eff 变小）→ μ* 变大、压 Tc。净效应通常仍是净吸引增强（λ 无阻尼进入、μ 被对数压制），但很窄的峰会让 μ* 反噬。§2 论证大 m 窗 ~ω_c 使峰对 μ* 影响小，但"窗口平均叠加在已按常数 DOS 约化过的 μ* 上"两层近似的自洽性未推导。v0.2 要把 μ*(δ) 显式化。
- **峰形**：真实 3D 鞍点 DOS 是单边 √ 型（一侧 cusp），2D 是对数发散；洛伦兹是可解析的替身。单边峰会让 E(δ) 不对称 → 峰位偏离 δ=0，可能与情形 (a) 的不对称叠加。形状敏感性待数值扫（用真实 H3S DOS vs 洛伦兹拟合）。
- **Allen–Dynes vs McMillan**：H3S λ~1.8–2.6，裸 McMillan 低估 Λ 27%–61%（reviewer 实测，随 λ 恶化，P1 round1 同类病灶）；§3 只用 Λ>0 单调性（符号安全），§5 数值一律用求解器直接解、不套闭式。
- **W_eff 的 c 常数**未定，靠数值标定（§5.1）；在此之前 §3 只用符号结论，不报峰位数值。
- **ε_F 对同位素近似不变**（电子结构量），故 P4 是纯电子侧、与同位素无关的机制；它对 α 的贡献经 λ_b、ω_log 的同位素依赖间接进入（与 P1 四因子不重复计）。
