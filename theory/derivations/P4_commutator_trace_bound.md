## 2. bound1 ≤ bound2：使 (i) 非必需的解析恒等式

**命题 4**（代数恒等式，rigor: **analytic**）。对同一 γ>0（可以是 γ_true 或
任何合法的下界 γ_lo），定义

    bound1(γ) := (2/x)·Var_v(B)/γ,        Var_v(B) := ‖(I−P₁)Bv‖² = ‖Bv‖²−q²
    bound2(γ) := (2/x)·‖[A,B]v‖²/γ³

则 **bound1(γ) ≤ bound2(γ)** 对任意 γ>0 恒成立。

*证明*（一行，来自已证的 (4.2)）：(4.2) 给 ‖(I−P₁)Bv‖ ≤ ‖[A,B]v‖/γ，两边平方、
乘正数 (2/x)/γ：

    (2/x)·‖(I−P₁)Bv‖²/γ ≤ (2/x)·‖[A,B]v‖²/γ³.   □

（(4.2) 本身是命题 3 的解析结论，见 `P4_concavity_q_route.md` §4.1；本稿不重复
其证明，只用其结论。）

**独立数值复核**（本稿 Part 3，rigor: numerical-evidence 佐证 analytic 结论）：
用真隙 γ_true，在同一 18 点网格上验证链条

    bound1(γ_true) ≤ bound2_v(γ_true) := (2/x)‖[A,B]v‖²/γ_true³
                    ≤ bound2_F(γ_true) := (2/x)(‖[A,B]‖_F/√2)²/γ_true³

**全部 18 点链条成立**（例：ϖ=1.54，bound1=0.010307 ≤ bound2_v=0.015459 ≤
bound2_F=0.015471；ϖ=20，bound1=0.000275 ≤ bound2_v=0.000329 ≤ bound2_F=0.000329）。
第二个不等号是 (4.3) 的直接推论（‖[A,B]v‖≤‖[A,B]‖_F/√2），数值上几乎取等
（rank-2 有效结构，见下）。

**含义**：只要用 bound1 代替 bound2 去控制 |C|，就完全不需要 ‖[A,B]‖_F 的
解析上界——只需要 Var_v(B) 的上界，而 Var_v(B) 有 Bhatia–Davis 现成控制
（Var_v(B) ≤ (β_max−q)(q−β_min)，β_max/min 为 B 的谱端点）。这把 (i) 从
「阻塞性必需」降级为「若能做到会更省事，但不是唯一路径」。
