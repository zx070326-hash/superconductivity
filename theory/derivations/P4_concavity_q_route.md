## 1. (Q1) 核层面的求导恒等式

**命题 1**  ∂_x f = (f − f²)/x，逐点对一切 k ≥ 1、x > 0 成立；从而由 𝒪 对核的线性性，

    𝒪[∂_x f] = (𝒪[f] − 𝒪[f²])/x = (A − B)/x.

*证明*  直接微分：∂_x f = ∂_x [x/(k²+x)] = k²/(k²+x)²。另一方面

    (f − f²)/x = f(1−f)/x = [x/(k²+x)]·[k²/(k²+x)]/x = k²/(k²+x)²，

两式相等。𝒪 是核 ↦ 矩阵的线性映射（L1、L2、L3 三项都对核线性），
且 k ↦ ∂_x f(k;x) 与 f、f² 同样在 k ≥ 1 上有界可和，级数一致收敛，
故可逐项交换求导与 𝒪 的构造。∎

Gate 1 数值复核：max‖𝒪[∂_x f] − (A−B)/x‖_∞ < 1e-13（10 个 x 点）。

**推论 1.1**  g = ∂_x(f²) = 2f·∂_x f = 2(f² − f³)/x，故 𝒪[g] = 2(B − 𝒪[f³])/x，
于是

    E = 2(q − ⟨v, 𝒪[f³] v⟩)/x.                                    (1.1)

Gate 3、Gate 5 复核（误差 ≤ 4.9e-17）。注意 (1.1) 只是**恒等式**，
不是 (A) 的证明；见 §3 的说明。

## 2. (Q2) Feynman–Hellmann 与 H″ = −q′/x

**命题 2**  在 x > 0 上 h 可微，且

    x h′(x) = h(x) − q(x),                                        (2.1)

从而 h″(x) = −q′(x)/x。**引理 C（h 在 (0,∞) 上严格凹）⟺ q 在 (0,∞) 严格递增。**

*适用性前提*（须逐条落实，这是本节的实质内容）：

(i) **紧性与自伴性**。A(x) 自伴，且由 Schur/Holmgren 行和界 ‖A‖ < ∞；
    核 f(·;x) ∈ ℓ¹ 使 A(x) 为 Hilbert–Schmidt，故紧。谱为可数实点谱，
    仅在 0 处聚点。

(ii) **顶本征值单重**。这是 Feynman–Hellmann 可用的关键，也是 (2.1) 中
    v 唯一（至多差符号）的来源。单重性由 **隙 > 0** 保证，而隙 > 0 有
    **独立来源**，不依赖本节任何结论：
      - ϖ ∈ (0, 2]：重排恒等式的二阶 trace 界给 λ₂ ≤ 0.58·h
        （`theory/notes/2026-09-13_gap_lorentz_probe.md`）；
      - ϖ ≥ 2：秩一路线给 λ₂ ≤ Θ\* = 0.6349 < h(2) = 1.336，
        故 h − λ₂ ≥ h − Θ\* > 0。
    两段在 ϖ = 2 处重叠，无缝隙。**这一独立性很重要**：若单重性依赖
    凹性，论证就循环了。

(iii) **x ↦ A(x) 的解析性**。f(k;x) = x/(k²+x) 对每个 k 在 x > 0 上实解析，
    且行和界在 x 的紧子区间上一致，故 A(x) 在算子范数下实解析。

由 (i)–(iii)，Kato 的解析扰动定理给出：h(x) 与 v_x 在 x > 0 上实解析
（单重本征值不发生分岔），且 Feynman–Hellmann 成立：

    h′(x) = ⟨v_x, (∂_x A) v_x⟩ = ⟨v_x, 𝒪[∂_x f] v_x⟩.

代入命题 1：h′ = ⟨v, (A−B)v⟩/x = (h − q)/x，即 (2.1)。∎

对 (2.1) 再求一次导：h′ = (h−q)/x ⟹ x h″ + h′ = h′ − q′ ⟹

    h″(x) = −q′(x)/x.                                             (2.2)

因 x > 0，h″ < 0 ⟺ q′ > 0。∎

Gate 2 复核 v ∈ C（非负、非增）；Gate 4/6 复核 (2.1)(2.2) 的数值一致性。

**评价**：(Q1) 是纯代数，干净。(Q2) 的推导本身干净，但它依赖 (ii)，
即隙 > 0；而隙下界在 ϖ ∈ [1.4,1.7] 上恰是 §4 的缺口所在。
两处对隙的需求不同——(ii) 只要 **隙 > 0**（定性），
§4 要 **隙的定量下界**——所以 (Q2) 不受 §4 缺口影响。

## 3. (A) E(x) > 0：解析证成

**定理 A**  对一切 x > 0，E(x) = ⟨v_x, 𝒪[g] v_x⟩ > 0。

*证明*  g(k) = 2xk²/(k²+x)³ ≥ 0 对一切 k ≥ 0，且 g(1) = 2x/(1+x)³ > 0。
Gate 2 之上，v_x ∈ C := {非负、非增} （锥不变性，见 `P4_main_theorems.md` §3）。
`P4_uniqueness_strategy.md` §2.A 的 **推论 A′** 给出：
若 w ∈ C 非零、核 φ ≥ 0 且 φ(1) > 0，则 ⟨w, 𝒪[φ] w⟩ > 0。
取 w = v_x、φ = g 即得。∎

**注（一条重要的排除）**：我原本试图用 (1.1) 把 (A) 归约为
⟨v,𝒪[f³]v⟩ < ⟨v,𝒪[f²]v⟩，再由 f³ < f² 逐点序推出。**这条路不通也不必要**：
𝒪 不保核的逐点序（−L1 负对角使 λ_min(𝒪[g]) < 0，实测为负），
所以逐点 f³ < f² 不给算子序，弱形式仍需额外论证。
推论 A′ 直接作用于 g 本身，绕开了整个比较问题。(1.1) 保留为恒等式（有独立用途），
但**不是** (A) 的证明路径。

## 4. (B) |C| < E：归约至单一谱隙缺口

由二阶扰动理论，C := q′ − E = −(2/x) Σ_{j>1} ⟨v, B w_j⟩²/(h−λ_j) ≤ 0 自动，
且

    |C| ≤ (2/x)·‖(I−P₁)Bv‖²/γ,     γ := h − λ₂ (隙).             (4.1)

### 4.1 精确恒等式消去试探向量

**命题 3**  (A − h)(I−P₁)Bv = (I−P₁)[A,B]v，从而

    ‖(I−P₁)Bv‖ ≤ ‖[A,B]v‖/γ.                                     (4.2)

*证明*  Av = hv 给 [A,B]v = ABv − BAv = (A−h)Bv。而 (A−h) 与 P₁ 交换、
且 (A−h)P₁ = 0，故 (I−P₁)[A,B]v = (I−P₁)(A−h)Bv = (A−h)(I−P₁)Bv。
A−h 限制在 ran(I−P₁) 上可逆，谱含于 (−∞, λ₂−h]，故其逆的范数 ≤ 1/γ。∎

Gate 8 复核：相对误差 ≤ 1.2e-14。**这一步无试探向量、无 Davis–Kahan**，
因此绕开了先前被排除的 τ/u 重叠不足问题（重叠仅 0.17–0.78）。

### 4.2 交换子的迹形式：去掉本征向量

关键结构观察：**[A,B] 反对称**（A、B 各自对称 ⟹ [A,B]ᵀ = −[A,B]），
故其奇异值成对出现，于是

    ‖[A,B]v‖ ≤ ‖[A,B]‖₂ ≤ ‖[A,B]‖_F/√2,                          (4.3)

且 Frobenius 范数有**纯迹形式，不含本征向量**：

    ‖[A,B]‖_F² = −tr([A,B]²) = 2 tr(A²B²) − 2 tr(ABAB).           (4.4)

Gate 8 复核 (4.4) 与反对称性（skew ≤ 2.9e-17，trace form 误差 ≤ 2.7e-14）。

**这里有一个先前被误判的点**：协调者报告 ‖[A,B]‖ 在 ϖ=20 时达 11.0、
随 ϖ 线性增长，因而必须保留「作用在 v 上」。实测不是这样——那个 11.0 是
**Schur 行和界**，对该交换子松约 5.9 倍。真正的谱范数满足

    ‖[A,B]‖₂ / ‖[A,B]v‖ ∈ [1.0000, 1.0009]   (ϖ ∈ [0.2, 40])

即 **v 本质上就是交换子的最大化向量**，且 ‖·‖_F/√2 与 ‖·‖₂ 三位数字吻合
（交换子实际有效秩为 2）。所以 (4.3) 几乎无损，**本征向量可以完全去掉**。
N=300/600 一致（Gate 10，相对漂移 ≤ 6.5e-5）。

## 5. 诚实边界

1. **(B) 未完全解析闭合**。用全段最坏隙 0.42h 时，ϖ ∈ [1.46,1.63] 上
   (4.5) 超过 E 最多 **1.096 倍**（ϖ=1.54）。我**没有**调参掩盖：
   Gate 9 显式打印 HOLE 并断言缺口不逃出 [1.4,1.7]。
   真隙下全程闭合，但真隙是数值量，不构成证明。

2. **§4.4 的闭合是有条件的，不算数**。用逐点 λ₂_hi/h 表 + 线性插值确实
   全段闭合（最劣 0.901），但保守阶梯版本在 ϖ=1.54、1.60 仍失败（1.099、1.030）。
   差的是 λ₂_hi/h 在 [1.4,1.8] 上的逐点值——这是**有限次可计算的量**
   （该表由 tr B_ϖ² 的显式级数给出），补齐它很可能就闭合，但我没有做。

3. **完全解析的交换子界仍缺**。(4.4) 是迹形式，但我尚无 tr(A²B²)、tr(ABAB)
   的闭式上界；Gate 9 用的是**数值算出的** ‖[A,B]‖_F。我试过
   ‖[A,B]‖_F ≤ 2‖A‖₂‖B‖_F 等 submultiplicative 界，松 9.7–16.8 倍，
   ϖ ≥ 1 全部失效（Part 2 实测）。所以 (B) 即便补上隙界，
   仍需交换子的解析上界才算完整。这是**第二个**独立缺口。

4. **小 ϖ 的高阶零点未定阶**。ϖ=0.2 时 ‖[A,B]v‖ = 1.45e-5，
   ϖ=0.5 时 2.28e-3，比值提示 ϖ 的高次幂（粗估 ~ϖ⁶）。定出这个阶数
   可让小 ϖ 段自动闭合，但我没有推导出确切阶数。

5. **C ≤ 0 未在网格上逐点数值确认**。Gate 6 用中心差分估 q′，
   O(dx²) 误差使 2.4% 的点出现虚假 C > 0（均在 |C|/E < 0.01 处）。
   C ≤ 0 本身由二阶扰动理论解析保证，故这不是实质问题，但数值门
   **不**断言逐点 C ≤ 0，只报告 |C|/E ≤ 0.184。

6. **未验证的量**：λ₂ 在 ϖ ≥ 20 时数值转负（Gate 9 表内 h−λ₂ 仍正），
   属截断效应，我未追查；这不影响结论，因该段余量 4 倍以上。

7. **本文不含引理 C 的完整证明**。链条为
   引理 C ⟸ q′ > 0 ⟸ E > 0 且 |C| < E；其中 E > 0 已证（定理 A），
   |C| < E 差 §5.2、§5.3 两个缺口。
