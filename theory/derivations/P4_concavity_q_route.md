## 1. (Q1) 核层面的求导恒等式

**命题 1**  ∂_x f = (f − f²)/x，逐点对一切 k ≥ 1、x > 0 成立；从而由 𝒪 对核的线性性，

    𝒪[∂_x f] = (𝒪[f] − 𝒪[f²])/x = (A − B)/x.

*证明*  直接微分：∂_x f = ∂_x [x/(k²+x)] = k²/(k²+x)²。另一方面

    (f − f²)/x = f(1−f)/x = [x/(k²+x)]·[k²/(k²+x)]/x = k²/(k²+x)²，

两式相等。𝒪 是核 ↦ 矩阵的线性映射（L1、L2、L3 三项都对核线性），
且 k ↦ ∂_x f(k;x) 与 f、f² 同样在 k ≥ 1 上有界可和，级数一致收敛，
故可逐项交换求导与 𝒪 的构造。∎

Gate 1 数值复核：max‖𝒪[∂_x f] − (A−B)/x‖_∞ < 1e-13（10 个 x 点）。

**推论 1.1**  g = ∂_x(f²) = 2f·∂_x f = 2(f² − f³)/x，故 𝒪[g] = 2(B − 𝒪[f³])/x，
于是

    E = 2(q − ⟨v, 𝒪[f³] v⟩)/x.                                    (1.1)

Gate 3、Gate 5 复核（误差 ≤ 4.9e-17）。注意 (1.1) 只是**恒等式**，
不是 (A) 的证明；见 §3 的说明。

## 2. (Q2) Feynman–Hellmann 与 H″ = −q′/x

**命题 2**  在 x > 0 上 h 可微，且

    x h′(x) = h(x) − q(x),                                        (2.1)

从而 h″(x) = −q′(x)/x。**引理 C（h 在 (0,∞) 上严格凹）⟺ q 在 (0,∞) 严格递增。**

*适用性前提*（须逐条落实，这是本节的实质内容）：

(i) **紧性与自伴性**。A(x) 自伴，且由 Schur/Holmgren 行和界 ‖A‖ < ∞；
    核 f(·;x) ∈ ℓ¹ 使 A(x) 为 Hilbert–Schmidt，故紧。谱为可数实点谱，
    仅在 0 处聚点。

(ii) **顶本征值单重**。这是 Feynman–Hellmann 可用的关键，也是 (2.1) 中
    v 唯一（至多差符号）的来源。单重性由 **隙 > 0** 保证，而隙 > 0 有
    **独立来源**，不依赖本节任何结论：
      - ϖ ∈ (0, 2]：重排恒等式的二阶 trace 界给 λ₂ ≤ 0.58·h
        （`theory/notes/2026-09-13_gap_lorentz_probe.md`）；
      - ϖ ≥ 2：秩一路线给 λ₂ ≤ Θ\* = 0.6349 < h(2) = 1.336，
        故 h − λ₂ ≥ h − Θ\* > 0。
    两段在 ϖ = 2 处重叠，无缝隙。**这一独立性很重要**：若单重性依赖
    凹性，论证就循环了。

(iii) **x ↦ A(x) 的解析性**。f(k;x) = x/(k²+x) 对每个 k 在 x > 0 上实解析，
    且行和界在 x 的紧子区间上一致，故 A(x) 在算子范数下实解析。

由 (i)–(iii)，Kato 的解析扰动定理给出：h(x) 与 v_x 在 x > 0 上实解析
（单重本征值不发生分岔），且 Feynman–Hellmann 成立：

    h′(x) = ⟨v_x, (∂_x A) v_x⟩ = ⟨v_x, 𝒪[∂_x f] v_x⟩.

代入命题 1：h′ = ⟨v, (A−B)v⟩/x = (h − q)/x，即 (2.1)。∎

对 (2.1) 再求一次导：h′ = (h−q)/x ⟹ x h″ + h′ = h′ − q′ ⟹

    h″(x) = −q′(x)/x.                                             (2.2)

因 x > 0，h″ < 0 ⟺ q′ > 0。∎

Gate 2 复核 v ∈ C（非负、非增）；Gate 4/6 复核 (2.1)(2.2) 的数值一致性。

**评价**：(Q1) 是纯代数，干净。(Q2) 的推导本身干净，但它依赖 (ii)，
即隙 > 0；而隙下界在 ϖ ∈ [1.4,1.7] 上恰是 §4 的缺口所在。
两处对隙的需求不同——(ii) 只要 **隙 > 0**（定性），
§4 要 **隙的定量下界**——所以 (Q2) 不受 §4 缺口影响。

## 3. (A) E(x) > 0：解析证成

## 4. (B) |C| < E：归约至单一谱隙缺口

由二阶扰动理论，C := q′ − E = −(2/x) Σ_{j>1} ⟨v, B w_j⟩²/(h−λ_j) ≤ 0 自动，

    |C| ≤ (2/x)·‖(I−P₁)Bv‖²/γ,     γ := h − λ₂ (隙).             (4.1)

### 4.1 精确恒等式消去试探向量

**命题 3**  (A − h)(I−P₁)Bv = (I−P₁)[A,B]v，从而

    ‖(I−P₁)Bv‖ ≤ ‖[A,B]v‖/γ.                                     (4.2)

*证明*  Av = hv 给 [A,B]v = ABv − BAv = (A−h)Bv。而 (A−h) 与 P₁ 交换、
且 (A−h)P₁ = 0，故 (I−P₁)[A,B]v = (I−P₁)(A−h)Bv = (A−h)(I−P₁)Bv。
A−h 限制在 ran(I−P₁) 上可逆，谱含于 (−∞, λ₂−h]，故其逆的范数 ≤ 1/γ。∎

Gate 8 复核：相对误差 ≤ 1.2e-14。**这一步无试探向量、无 Davis–Kahan**，
因此绕开了先前被排除的 τ/u 重叠不足问题（重叠仅 0.17–0.78）。

### 4.2 交换子的迹形式：去掉本征向量

关键结构观察：**[A,B] 反对称**（A、B 各自对称 ⟹ [A,B]ᵀ = −[A,B]），
故其奇异值成对出现，于是

    ‖[A,B]v‖ ≤ ‖[A,B]‖₂ ≤ ‖[A,B]‖_F/√2,                          (4.3)

且 Frobenius 范数有**纯迹形式，不含本征向量**：

    ‖[A,B]‖_F² = −tr([A,B]²) = 2 tr(A²B²) − 2 tr(ABAB).           (4.4)

Gate 8 复核 (4.4) 与反对称性（skew ≤ 2.9e-17，trace form 误差 ≤ 2.7e-14）。

**这里有一个先前被误判的点**：协调者报告 ‖[A,B]‖ 在 ϖ=20 时达 11.0、

### 7.1 bound1（一次隙幂）严格优于 bound2

记 Var_v(B) := ⟨v, B² v⟩ − q²。因 P₁ = |v⟩⟨v| 且 P₁Bv = q·v，

    (I−P₁)Bv = Bv − q v ⟹ ‖(I−P₁)Bv‖² = ‖Bv‖² − q² = Var_v(B).

于是 (4.1) 直接就是

    |C| ≤ (2/x)·Var_v(B)/γ.                        (bound1，一次隙幂)

**命题 4（bound1 ≤ bound2）**  对任意正隙下界 γ，

    (2/x)·Var_v(B)/γ ≤ (2/x)·‖[A,B]v‖²/γ³ ≤ (2/x)·‖[A,B]‖_F²/(2γ³) = (4.5).

*证明*  由 (4.2) ‖(I−P₁)Bv‖ ≤ ‖[A,B]v‖/γ，平方得 Var_v(B) ≤ ‖[A,B]v‖²/γ²；
两端除以 γ 得第一个不等号。第二个不等号即 (4.3)（‖[A,B]v‖ ≤ ‖[A,B]‖₂ ≤
‖[A,B]‖_F/√2）。∎

**推论**：§4.2–§4.3 从 (4.1) 走到 (4.5) 时，(4.2)(4.3) 各引入一次隙幂，
把一次幂放大成三次幂——这正是 §4.3 定位的病因（「(4.5) 对 γ 三次依赖，
0.42³≈0.074 把余量吃光」）。**留在 (4.1) 即可**：既不需要 ‖[A,B]‖_F 的解析
上界（§5.3 第三点消解——它是 bound2 的产物，不是问题的本质），也对隙的松弛远
不敏感（一次幂 vs 三次幂）。Gate 11 复核 bound1 ≤ bound2 全谱成立，并打印二者
对 E 的比值（例 ϖ=1.5：b1/E=0.149 vs b2/E=1.833；ϖ=20：0.248 vs 0.523）。

### 7.2 解析谱隙下界 γ_lo（闭合 [1.46,1.63] 洞）

γ = h − λ₂ ≥ γ_lo := h_lo(x) − λ₂_hi(x)，两片都解析：

**h_lo（h 的解析下界）**。取固定试探集 W = {e₀, (1/(n+1))ₙ, (1/√(2n+1))ₙ}
（后两者截断到 60 维）。每个 Rayleigh 商 ⟨w, A w⟩/‖w‖² 是 x 的**有理函数**
（w 固定、核 f(k;x)=x/(k²+x) 对 x 有理，级数在 k 上闭式可和）。由变分原理
h ≥ max_{w∈W} ⟨w, A w⟩/‖w‖² =: h_lo。数值上 h_lo/h ≥ 0.852（ϖ∈[0.2,40]，Gate 12）。

**λ₂_hi（λ₂ 的解析上界）**。设 Gdom ⪰ ℌ 为重排控制算子（丢掉 ≥0 的
Dirichlet 型，逐元为正）：

    (Gdom)_{nm} = u_n u_m f(n+m+1) + δ_{nm} u_n² T(n),   T(n) = Σ_{k>n} f(k).

由 min-max：Gdom ⪰ ℌ ⟹ λ₂(ℌ) ≤ λ₂(Gdom)；又 λ₂(Gdom)² ≤ Σ_{j≥2} λ_j²
= tr Gdom² − λ₁(Gdom)²，且 λ₁(Gdom) ≥ (Gdom)₀₀（对称非负阵的对角元 ≤ 最大本征值）。
故

    λ₂(ℌ) ≤ √(tr Gdom² − (Gdom)₀₀²).

tr Gdom² 是显式二重级数（`2026-09-13_gap_lorentz_probe.md` §2.3），
(Gdom)₀₀ = u₀²(T(0)+f(1)) 解析。再与秩一路线的 Θ* = 0.6349 取小：
λ₂_hi = min(√(tr Gdom² − (Gdom)₀₀²), Θ*)。

### 7.4 归约到单一不等式

由 (1.1) E = 2(q − m₃)/x，m₃ := ⟨v, 𝒪[f³] v⟩，故 (q − m₃) = xE/2。闭合条件
(2/x)·Var/γ < E 等价于

    Var_v(B) < γ · (q − m₃) = γ · xE/2.            (闭合条件)

**引理 C 的证书残余至此归约为这一条不等式**：链条为
引理 C ⟸ q′ > 0 ⟸ E > 0 且 |C| < E，其中 E > 0 已证（定理 A），
γ ≥ γ_lo 已解析（§7.2），|C| ≤ (2/x)Var/γ 严格（bound1，§7.1），
只差 Var_v(B) 的解析上界满足 (闭合条件)。用真 BD 输入余量 ≥ 3.2 倍。

### 7.5 诚实残余：Var_v(B) 的解析上界

唯一仍非解析的输入是 (闭合条件) 左端 Var_v(B) 的**解析上界**。定义
「预算」:= γ_lo·(q−m₃)/Var（Var 可放大多少倍仍闭合，>1 即闭）。Gate 15 表：

诚实结论：

1. **BD**（真 β_max,β_min,q）处处入预算（放大 1.26–1.58），但需要 β_max、q

   x²‖D‖²（用 Var_v(B) = x²·Var_v(D)）只在 ϖ≳8 入预算，中段失败
   （ϖ=3 时 5.78 > 5.11）。

3. 小 ϖ 段预算极大（ϖ=0.5 为 123），任何粗界都够；真正难的是**中段 ϖ∈[1.5,3]**，
   预算 ~5–7 而 v 的近最优性最吃紧。
