### 1.C 结构恒等式（主会话探针，2026-09-11，`_scratch_ir` 内联，float64 验证到 1e-15）

记 u_n := (2n+1)^{-1/2}（**与 ϖ 无关**），𝒪 为核-通用算子（§6 of `P4_conjecture2.md`）。常核恒等式 **𝒪_N[1] = 2uuᵀ − I**（逐元验证 1e-16），故由 ⟦k⟧ = 1 − k²/(k²+x)：

  **ℌ(x) = 2uuᵀ − I − W(x)，　W(x) := 𝒪[k ↦ k²/(k²+x)]**，　x=ϖ²。

W(x) 的核 k²/(k²+x) 是 x 的完全单调函数（x→∞ 时 →0，故 ℌ → 2uuᵀ − I 的"发散"极限即 h ~ ln ϖ 的来源：u∉ℓ²）。**秩一久期方程**：h=λ₁(ℌ) 是 F(h,x) := 2⟨u,(h·I + M(x))^{-1}u⟩ = 1 的唯一根，M:=I+W，需 h > −λ_min(M)（实测 −λ_min(M) = 0.45/1.20/1.56 @ ϖ=1/5/20，远高于 λ₂(ℌ)≈2e-3，故顶本征值恰是该根、其余谱在 −λ_min(M) 以下，**这也是谱隙 g ≥ h + λ_min(M) 的一个免费解析下界候选**）；顶本征向量 v ∝ (h+M)^{-1}u，Hellmann–Feynman h′ = ⟨y,ℌ′y⟩/‖y‖² 与之一致。**对段 C-II 的意义**：h 的凹性 ⟺ 超图 {(h,x): F(h,x) ≥ 1} 凸 ⟸ F 关于 (h,x) 联合拟凹——把二阶微扰问题换成了一个关于预解式 (h+M(x))^{-1} 的凸性问题；已排除的方向：x↦M(x) 若算子凹则 F 联合凸（方向相反、无用）。待渐近探针给 W(x) 的标度形状后再判。

### (B2) 渐近形式：展开在 1/ln ϖ，**不在** 1/ϖ

分派书预设的 h = a ln ϖ + c₀ + c₁/ϖ + c₂/ϖ² **是错的**。等参数个数的正面对比（ϖ≥20 的 10 点，最大残差）：

| #参数 | 1/ϖ 幂族 | 1/L 族（L:=ln ϖ） |
|---:|---:|---:|
| 3 | 1.9e−3 | 4.6e−5 |
| 4 | 7.5e−4 | 4.0e−6 |
| 5 | 3.7e−4 | 6.9e−7 |

1/L 族在每个参数量级上都赢 2–3 个数量级；1/ϖ 族的残差还带明显的符号交替系统结构。结论：

  **h(ϖ) = a·ln ϖ + c₀ + b₁/ln ϖ + b₂/ln²ϖ + b₃/ln³ϖ + …**

- **a = 1**：自由拟合给 a = 0.999954；把小 ϖ 端逐点丢掉，1−a 从 4.2e-5 单调降到 5.4e-6（ϖ≥500）。

- 最佳 log 模型在 ϖ=10..20000 全程残差 ≤ 6e-7。

### (B3) x²H″(x) → −a/2 的收敛速率是 **O(1/ln²ϖ)**，不是 O(1/ϖ²)

由 1/L 级数逐项微分（u:=ln x=2L）：

  ϖh′(ϖ) = 1 − b₁/L² − 2b₂/L³ − …，  x²H″(x) = −½ + (b₁/2)/L² + (b₁/2+b₂)/L³ + …

数值确认：(x²H″+½)·L² 在 ϖ=10..2e4 上从 0.0973 平稳爬到 0.1629，L→∞ 外推 0.1779（预测 b₁/2=0.1718）；(1−ϖh′)·L² → 0.3528（预测 b₁=0.3436）。同样两个误差乘 ϖ² 则从 1.8 爆到 6.6e5。

### 1.F.1 记法与「半移格点」——本节全部技巧的来源

置 **D := 1/ϖ、s_n := (n+½)D**、w_n := (2n+1)^{-1}、p_n = w_n^{1/2}、G(y) := 1/(1+y²)。则三条**精确**恒等：

  (i) w_n = D/(2 s_n)；　(ii) s_n − s_m = (n−m)D **且** s_n + s_m = (n+m+1)D；　(iii) s_n 是 [nD,(n+1)D] 的**中点**。

(ii) 说明 Toeplitz 下标 |n−m| 与 Hankel 下标 n+m+1 **同时**成为格点的差与和——Hankel 的「+1」被半移吸收（这是整节的关键，用 n/ϖ 则做不到）；(i)+(iii) 说明每个和 Σ_n w_n u(s_n) 恰是积分 **I[u] := ½∫₀^∞ u(s) ds/s** 的中点求和，误差 O(D²)。又 ⟦k⟧ = G(k/ϖ)，故 **ℌ 的核与试探向量是同一个 Lorentz 函数**。试探向量取分派书的**半移版**

  **τ_n := p_n G(s_n) = p_n ϖ²/(ϖ²+(n+½)²)，B := ‖τ‖²，t̂ := τ/√B，ρ := ⟨t̂,ℌt̂⟩。**

（与分派书 t_n = p_n(1+(n/ϖ)²)^{-1} 的唯一差别；数值上 ρ 同量级，但它使下面三条恒等式**精确**。）

### 1.F.2 三条精确代数恒等式（引擎）

**(M1) Lorentz 加法**：对一切 s,σ ≥ 0，

  G(s−σ)+G(s+σ) − 2G(s)G(σ) = R(s,σ) = **2s²σ²(5+s²+σ²) / [(1+(s−σ)²)(1+(s+σ)²)(1+s²)(1+σ²)] ≥ 0**

（初等：两个分母分别是 1+2(s²+σ²)+(s²−σ²)² 与 1+s²+σ²+s²σ²，差的分子恰为 s²σ²(5+s²+σ²)）。配 (ii) 得**算子恒等式**

  **ℌ(ϖ) = 2ττᵀ + 𝓡 − 𝒟，　𝓡_{nm} := p_np_m R(s_n,s_m) ≥ 0（逐元），𝒟 := diag(w_n + ℓ_G(n)) ∈ [0,1]**，ℓ_f(n) := (2/(2n+1))Σ_{k≤n}f(k/ϖ)。

（𝒟_{nn} ≤ 1 因 G ≤ 1 ⟹ Σ_{k≤n}G ≤ n。逐元核对 < 1e-13，ϖ∈{3,7,20,45}。）

**(M2) 对 f(0)=0 的核**（本文用 φ₀(y) := y²/(1+y²)³ 与 κ(y) := y²/(1+y²)² = G−G²）：取**两个交叉项**

### 1.F.3 五条闭式界（每条都是 ϖ 的公式 + 显式常数）

记 **2A := Σ_n[1/a_n − a_n/(a_n²+x)] = Re ψ(½+iϖ) + γ + 2ln2**（a_n=n+½，精确），**B = A − xA′(x) = A + (ϖ/4)·Im ψ′(½+iϖ)**（精确）。

### 1.H.2 Tier 2（30 个嵌套/pad 常数 + 6 个 T̄ sup）：为何未做到全程区间算术

这 30 个常数（nR2、V_nR2 + φ/κ 各自的 {GU,fU,lU,UU} 与 V-配对 = 18 个；W_nm、GU_nm（nm∈{G,φ,κ}）与 V-配对 = 12 个）与 6 个 T̄ sup 都含一个**内层 σ-剖面积分**，外层再对 s 积分/取 sup。原型区间实现（`theory/notes/_scratch_ir/test_profile0.py`、`test_profilek.py`，未提交，逐段验证过正确性）确认：当外层 s-格与内层 σ 剖面的自变量范围重叠（σ~s 是嵌套结构决定的、不可避免的常态区域），naive 区间算术把本应强相关的子表达式当独立处理，宽度随外层格宽爆炸；实测 357-格外层网格求 nR2 单项耗时 102 s、相对宽度仍 184%——在 20 分钟运行预算内无法收紧到有意义的界。

### 2.A.1 「区间化」在这里具体指哪三件事

§1.A.8 第 1 条点了三处，逐一：

1. **舍入垫没了。** 原版所有认证量按安全方向加 `ROUND_PAD = 1e-12`（以及 `alpha_certificate_H` 内的 `+1e-25`）——那是一个**未量化**的浮点误差吸收器。本文件 `PAD = mp.zero` 并在 Stage A′ 断言其为零；它的职能由外向舍入接管，而外向舍入是**构造性可量化**的。精确地说：承重路径上只出现 `+ − × ÷`、整数幂、`min/max` 与 `iv.sqrt`，每一个都返回包含精确实数结果的区间。**唯一需要的超越函数是反正切**（闭式尾积分用），而它**不取自 mpmath**——`iv.atan2` 在 mpmath 1.3.0 里**并非外向舍入**（`mpf_atan2` 先以 prec+4 **就近**舍入算 `mpf_atan(mpf_div(y,x))`，只对最后一步施加方向舍入；实测约 9% 的随机操作数不包含真值，最坏 0.24 ulp@prec103）。本文件的 `iv_atan_nn`/`iv_pi_half` 只用 `+ − × ÷ √` 与整数幂重建：先用 `atan t = 2 atan(t/(1+√(1+t²)))` 减半到 |t| ≤ 2^-4，再取交错级数 20 项并用**交错级数余项定理**给出严格余项。这一条是对抗性核查揪出的唯一必修项（§2.A.7 M-1）。此外 Stage A′ 有一条**源码级回归闸**，用 `tokenize` 断言 Secs 0–6（一切产生界的代码）里不出现任何 mpmath 超越函数调用。
2. **正定性是被认证的，不是被假定的。** 原链条对一个 **float64** 头块的 mpf 拷贝跑 `mp.cholesky`，把「没抛异常」当作 SPD——两个洞：算术不精确，且矩阵是那个 float64 的、不是精确算子的头块。本文件：(a) 头块 `head_iv` 直接在 `iv` 里由精确核（整数 k 与精确二进制细胞端点）生成，故区间矩阵 [A] 可证包含精确头块；(b) `chol_pd` 是逐行区间 Cholesky，返回 `(ok, min_pivot_lb)`，判据是**每个枢轴区间的下确界 > 0**，依据是下面这条标准定理（模块 docstring 内给了自洽证明，不外借）：

> **定理（区间 Cholesky ⟹ 一致正定；Alefeld 1980，见 Rump, BIT 46 (2006) 433–452 §2）.** 设 [S] 为对称区间矩阵，对其跑每步外向舍入的区间 Cholesky。若算法跑完且每个枢轴区间 [d_i] 满足 inf[d_i] > 0，则**每个**对称实矩阵 S ∈ [S] 正定。
> *证.* 固定对称 S ∈ [S]，对 S 跑**精确** Cholesky。按行归纳：设前 i−1 行的精确量满足 L^S_{ij} ∈ [L_{ij}]。对 j<i，L^S_{ij} = (S_{ij} − Σ_{k<j}L^S_{ik}L^S_{jk})/L^S_{jj}，由归纳假设与区间运算的**包含性**，它落在算法算出的区间内——前提是除数区间 [L_{jj}] 不含 0，而 inf[L_{jj}] = √(inf[d_j]) > 0。对 j=i，精确被开方量 d^S_i = S_{ii} − Σ_{k<i}(L^S_{ik})² ∈ [d_i]，故 d^S_i ≥ inf[d_i] > 0：精确 Cholesky 第 i 步有定义且枢轴为正。归纳闭合 ⟹ S = L^S(L^S)ᵀ、L^S 可逆 ⟹ S ≻ 0。∎
> 只用到包含性与 Sylvester 判据，**完全不涉及 Cholesky 的数值稳定性**——这正是它能取代「没抛异常」的理由。

3. **格是精确的。** 粗节点是 2^-10 的整数倍、**全部**端点是 2^-16 的整数倍（`is_dyadic` 逐个验），故相邻细胞**逐位相接**，认证细胞之并可证覆盖 (0, W_max]。`check_tiling` 显式验 `a_0 = w̄₀`、`b_j = a_{j+1}`（精确相等）、每个细胞非退化且端点二进；`run_L` 另有一条**「阶梯确实走到了被请求的 W_max」**的断言（若某粗细胞 6 次二分仍不闭，整跑失败而不是静默报一个更小的 W——§2.A.7 S-1）。(0, w̄₀] 由 Stage S 覆盖，故 x→0 端仍无缺口。

另外，**α 那条链上的第二个独立浮点洞也一并修掉了**：原版 `alpha_certificate_H` 的头块是 float64 矩阵 `H_mat(Na,w)` 再逐元 `mp.mpf(float(·))`；区间版直接从核表在 `iv` 里精确构造，O(Na²)。

### 2.A.2 单边界记账纪律（防「宽度被 max 吃掉」）

所有初等运算在 `iv` 里做，但**每个具名认证量立刻塌缩成单个 mpf 端点**（`LB`/`UB`，都是精确端点），单调性理由逐条写在代码行内：

```
E_hi   = ê_ψ,hi + s·(N_hi + |q̂_ψ|_hi)            各变量皆 ↑  ⟹ 全部 UB
F_lo   = q̂_φ,lo − s²(a_φ,hi + N_hi) − 2s·ê_φ,hi  ↓于 s,a,N,ê；↑于 q̂ ⟹ q̂ 用 LB，余用 UB
g_lo   = max(θ_lo − L₁,hi·hw, μ₂,lo) − α_hi
pos    = b⁴·E_hi²/g_lo                            ↑于 E_hi，↓于 g_lo
hpp_ub = −2·F_lo + 2·pos  <  0                    ← 全段唯一的结论
```

这挡掉两个经典洞：(i)「某个中间量的区间宽度炸了却被后面的 `max` 吞掉」——每个量只有一个端点在流动时不可能；(ii)「两个区间比较结果歧义」（`mpmath.iv` 的歧义比较返回 `None`）——比较两侧都是 mpf 端点。最后一层 mpf 组合一律走 `sub_lo/add_hi/mul_hi/div_hi`（裸 mpf 运算是**就近**舍入，会破坏单边性）。

### 2.A.5 诚实边界（引用前必读）

1. **仍然非区间的成分只有三类，且没有一类是界**：
   (a) **`numpy.linalg.eigh` 给出的试探向量 v̂ 与头块紧缩向量 u**。对**任何**固定向量，Rayleigh 商是 λ₁ 的合法下界、`λ₂(A) ≤ λ_max(PAP)` 也成立，故它们只影响界的**紧度**、不影响**合法性**；其 float64 分量按它们本来的样子（精确二进制有理数）进入 `iv`，归一化在 `iv` 内完成。
   (b) **粗步长、细分次数、Ns/Na、Cholesky 位移 c 的种子的「选取」**（`_L1_hint`、`support_size`、`na_band`、`lam2_head_iv` 的 c₀）。选取决定「认证哪些不等式」，不决定「它们是否成立」；每个被选中的量随后都在 `iv` 里重新认证（`_L1_hint` 另有 Stage A′ 的 1.5 倍相容检查兜底；c 是被区间 Cholesky 认证的位移，种子错只会导致升级重试或失败，不会导致假通过）。
   (c) **Stage A′ 与原脚本的对拍**：显式标注为**证据**，不进入任何界。
2. **超越函数只用了反正切，且是本文件自己造的**。`iv_atan_nn` 的正确性依赖：减半恒等式、交错级数余项定理，以及 `iv.sqrt` 的外向性（mpmath 对两个端点分别调用 `mpf_sqrt(·, prec, round_floor/round_ceiling)`，方向舍入作用在开方本身）。**`iv.sqrt` 是承重路径上最后一个仍然信任 mpmath 库实现的基元**：门里有对 600 bit 参考的包含性证据检查（本层累计 40300 个操作数 0 次不包含，第 2-a 层独立地 0/40000），且该检查是**判别性**的（同时断言一个就近舍入的点值 `sqrt` 在同一组操作数上会错过同一参考，实测 296/300，否则「0 次不包含」毫无意义）——但那仍然是**证据、不是证明**。想完全消除这一条，需要把 `iv.sqrt` 也换成 Newton 迭代 + 区间验证；**本节没有做**。详见核查记录 §丁.2。

### 2.A.6 与 §1.H（M3）的分工，以及残余假设第 1 条还剩什么

§1.H 处理的是**段 C-II** 的 52 个常数（28 严格区间 / 36 记账余量）；本节处理的是**段 C-I 整段**（端到端区间）。两者独立、互不引用。

因此可以写进 `P4_main_theorems.md` 的句子是——**「残余假设第 1 条已对段 C-I 消除」**，不是「已消除」。截至 2026-09-12，第 1 条覆盖的剩余实体是：

1. **M1–M4 的常数**（§1.E–§1.H；`p4_cii_m*_interval.py`）。其中 36 个 Tier-2 量按 §1.H.6 第 1 条仍是 float64 + 自收敛余量记账；且这批脚本刚发现**两处真实的包含失效**（见下），复核后数字可能微调。
2. **`p4_interchange_uniformity.py` 的隙机器**。
3. **段 C-II**（本节未动）。

**不再**属于第 1 条的：§4.1 的 𝔤(2) 夹逼。原先那里的 `mp.quad` + 舍入垫数值夹逼已被第 1 层用纯解析的双侧界取代（`P4_g2_analytic.md` v1.1，commit `d163ae4`），`P4_main_theorems.md` v0.4 起 §4.1 已照此改写。**定理 1 与定理 2 现已没有计算机辅助成分**；本节是对 §1.A 这个**更强但范围更大**的陈述（H 在 (0, 14400] 上严格凹）的证书，不是定理 1 的前提。

与之相关的两处外部发现（本节据以做了 §2.A.5 第 8 条的自查，本节自身均不受影响）：

- **`iv.atan2` 在 mpmath 1.3.0 里并非外向舍入**（本节 §2.A.7 M-1 首先发现并已从本模块彻底移除）。`p4_cii_m3_interval.py:99` 的 `atan_iv(y) = iv.atan2(y, 1)` 落在 M3/M4 的承重路径上（`atan_jet` → `d_jet`/`Lo_jet` → `Θ*`/`β` → `bounds3()`），故 ϖ_A″ = 9.8319 与 M4 的 9.711925 都需复核。
- **`p4_cii_m3_interval.py:652-655` `theta_star_iv()` 的垫取自二分宽度**（第 2-a 层发现）：`margin = float(b - a)` 是二分区间宽度 ≈ 2.3e−41，而 `v = float(val)` 的 float64 误差 ≈ 5e−17，于是区间以 4.8e−17 **在不安全方向**错过真 Θ*。这类缺陷是**自我遮蔽**的——内层收敛越好，垫越小，失效越严重。推出的通则：**垫必须覆盖它所代表的误差源**；任何「高精度算完、返回窄类型」的路径至少要留一个**窄类型**的 ulp，绝不能用高精度侧的量。
