## 0. 陈述

记 x := ϖ²，H(x) := h(√x) = λ₁(ℌ(√x))。

**定理 E（Einstein 极值，目标）**。对所有 P∈𝒫（⟨ω²⟩<∞）、所有 T>0：
  𝔨(P,T) ≤ h(ϖ_rms)，　ϖ_rms := √⟨ω²⟩ / 2πT。
等价地：对所有 λ>0，只要 Einstein 谱 δ_{ω_E}、ω_E=√⟨ω²⟩ 在温度 T 正常态线性稳定（λh(ϖ_rms)<1），P 也稳定。**物理**：固定 λ 与 ⟨ω²⟩，Einstein 谱是 Tc 的极大者，对全部 λ 成立（非仅大 λ 渐近）。**推论**：全 λ 尖锐上界曲线 T_c(λ,P) ≤ T_c^E(λ, √⟨ω²⟩)；KAY Conjecture 2 的界半句是其 λ→∞ 推论（h(ϖ)<𝔤(2)ϖ²）。

**证明骨架（两行）**。(A) 𝔨(P,T) ≤ ∫H(ϖ²)P(dω)；若 **H 在 (0,∞) 上凹（引理 C）**，Jensen 给 ∫H(ϖ²)P ≤ H(∫ϖ²P) = h(ϖ_rms)。∎　**⟹ 定理 E ⟺ 引理 C（单变量凹性）**。

**数值探针**（`notes/_scratch_ir/concave_probe.py`、`loewner_probe.py`，float64 证据）：H″(x)<0 在 x∈[1e-3,3600] 的 63 个网格点无一例外（H″(1)=−0.328；大 x 处 H″≈−1/(2x²)，即 H ~ ½ln x，与 BCS 弱耦合 𝔨 ~ ln ϖ 一致）；40 组随机两原子谱 𝔨(P)/h(ϖ_rms) 最大 0.99996。**否定的捷径**：ℌ′(ϖ) 非半正定（λ_min≈−0.5）、x↦ℌ(x) 非算子凹（λ_min(D)≈−0.47），故无 Loewner 型免费论证，凹性必须走本征值二阶微扰 + 大 x 解析。

## 1. 引理 C 的证明计划（与 Conjecture 2 同构：证书段 + 解析段）

**二阶微扰恒等式**（单一顶本征值 λ₁、本征向量 v、谱隙 g）：λ₁″ = ⟨v,A″v⟩ + 2Σ_{j≥2}|⟨v_j,A′v⟩|²/(λ₁−λ_j)，第二项 ≥0 且 ≤ 2‖(I−P)A′v‖²/g。以 x 为变量：ℌ_x=ℌ′(ϖ)/(2ϖ)、ℌ_xx=(ℌ″(ϖ)−ℌ′(ϖ)/ϖ)/(4ϖ²)，得

  4ϖ²·H″(x) ≤ ⟨v,ℌ″v⟩ − ⟨v,ℌ′v⟩/ϖ + 2‖(I−P)ℌ′v‖²/g　　(C\*)

引理 C 在 cell 上 ⟸ (C\*) 右端的认证上界 < 0。三项分别：⟨v,ℌ″v⟩ 上界（mpmath 二次型 + DK 角度 + 尾）、⟨v,ℌ′v⟩ 下界（Stage M 已有）、‖(I−P)ℌ′v‖² 上界（Stage M 的 DK 残差机器）、g 下界（认证谱隙）；Lipschitz 用 3 阶包络。

- **段 C-I（证书，(0, X]）**：x→0 端 4ϖ²H″ → −2c₂·(常数) 有界远离 0（H(x)=𝔤(2)x − c₂x² + …，H″(0)=−2c₂=−2.386），无 ϖ→0 缺口（与 Conjecture 2 段 I 同理、可能需同样的"两边相消"技巧）；大 x 端 4ϖ²H″ ~ −2/x 趋零而 DK 误差不趋零 ⟹ **必有墙**，预计 X 对应 ϖ≈10–20。
- **段 C-II（解析，x ≥ X）**：**这是本项目的研究核心。** h(ϖ) = ln ϖ + c₀ + o(1)（BCS 弱耦合对数），需带导数控制的严格渐近，或一个绕开渐近的凹性论证。候选路线待 researcher/探针给线索：(i) 显式试探向量给 h 的严格双侧界 ln ϖ + c ± ε(ϖ)，配合 H″ 的差分论证；(ii) 与可精确求解的比较算子（如 ⟦k⟧→1_{k≤ϖ} 的截断算子、或 Hilbert 型矩阵）的 Loewner 夹逼；(iii) 大 ϖ 标度极限 n=ϖs 的积分算子，其顶本征值的凹性解析可证 + 有限 ϖ 修正的严格界。

### (B2) 渐近形式：展开在 1/ln ϖ，**不在** 1/ϖ

分派书预设的 h = a ln ϖ + c₀ + c₁/ϖ + c₂/ϖ² **是错的**。等参数个数的正面对比（ϖ≥20 的 10 点，最大残差）：

| #参数 | 1/ϖ 幂族 | 1/L 族（L:=ln ϖ） |
|---:|---:|---:|
| 3 | 1.9e−3 | 4.6e−5 |
| 4 | 7.5e−4 | 4.0e−6 |
| 5 | 3.7e−4 | 6.9e−7 |

1/L 族在每个参数量级上都赢 2–3 个数量级；1/ϖ 族的残差还带明显的符号交替系统结构。结论：

  **h(ϖ) = a·ln ϖ + c₀ + b₁/ln ϖ + b₂/ln²ϖ + b₃/ln³ϖ + …**

- **a = 1**：自由拟合给 a = 0.999954；把小 ϖ 端逐点丢掉，1−a 从 4.2e-5 单调降到 5.4e-6（ϖ≥500）。
- **c₀ = 0.46353**（a:=1 且允许一个 c/ϖ² 项的 5 参数模型）。
- b₁ = +0.3436、b₂ = −0.2544、b₃ = +0.060（模型依赖，见诚实边界）。
- 最佳 log 模型在 ϖ=10..20000 全程残差 ≤ 6e-7。

### (B3) x²H″(x) → −a/2 的收敛速率是 **O(1/ln²ϖ)**，不是 O(1/ϖ²)

由 1/L 级数逐项微分（u:=ln x=2L）：

  ϖh′(ϖ) = 1 − b₁/L² − 2b₂/L³ − …，  x²H″(x) = −½ + (b₁/2)/L² + (b₁/2+b₂)/L³ + …

数值确认：(x²H″+½)·L² 在 ϖ=10..2e4 上从 0.0973 平稳爬到 0.1629，L→∞ 外推 0.1779（预测 b₁/2=0.1718）；(1−ϖh′)·L² → 0.3528（预测 b₁=0.3436）。同样两个误差乘 ϖ² 则从 1.8 爆到 6.6e5。

**对段 C-II 的含义**：任何解析论证的余项只按 1/ln²ϖ 衰减，**不能指望 1/ϖ 型小量**，这是本段最重要的负面信息。正面信息是主项余量很大：修正 +b₁/(2L²) 在 ϖ=10 处只有 +0.018（占 −½ 的 3.7%），且符号为正（从上方趋近 −½），所以 |x²H″| 的最小值出现在**小** ϖ 端而不是大 ϖ 端，凹性裕度随 x 增大而变好。

### (B8) 一个**精确的 rank-one 约化**与标量 secular 方程（本段最强线索）

因 𝒪 对核线性且 ⟦k⟧(ϖ) = 1 − m_ϖ(k)、m_ϖ(k) := k²/(k²+ϖ²)：

  **𝒪_N[1] = 2uu^T − I_N**,  u_n=(2n+1)^(−1/2)   （精确：其非对角部分是 2uu^T 减去自身对角 diag(1/(2n+1))，而 L1 对角是 diag(2n/(2n+1))，两个对角恰好合成单位阵）
