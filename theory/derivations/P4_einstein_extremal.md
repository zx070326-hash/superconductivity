两个量在 ϖ→0 都是 O(1)、在大 ϖ 都 ~ϖ^{-4}，**没有任何相消**。(I1)–(I3) 是本段仅有的两处新推导（另一处见 §1.A.4 的 ‖v′‖ 界）。

### 1.A.3 x→0 的精确极限与首 cell（无缺口）

φ₀=ψ₀=1/k⁴ ⟹ F(0)=c₂、E(0)=‖(I−P₀)𝔊(4)v₀‖<∞；又 g(ϖ)=ϖ²g̃(ϖ)、g̃(0)=𝔤(2)−λ₂(𝔊(2))≥1.30443，故 (C\*\*) 的正项 = 2ϖ⁴E²/(ϖ²g̃) = **2ϖ²E²/g̃ → 0**。于是

  **H″(0) = −2c₂ = −2.38633…，(C\*) 右端 = 4ϖ²H″ = −8c₂·x + O(x²) = −9.5453·ϖ² + O(ϖ⁴)。**

首 cell 因此在**重标度算子**上做：𝔥(ϖ) := ℌ(ϖ)/ϖ² = 𝔊(2) − ϖ²𝔎(ϖ)（段 I 的恒等式 (I)，本文件 Stage A 再次逐元核验），它的顶本征值在 ϖ→0 一致单重孤立（而 ℌ(ϖ) 本身整个谱塌到 0，Davis–Kahan/Rayleigh 机器在那里全部退化）。cell (0, 0.3] 的四个量：θ̃ ≥ λ̂_𝔊 − b²·q̂_κ,hi、α̃ = α_{𝔊(2)} + b²·‖𝔎‖、‖r̃‖ ≤ ‖r_{𝔊(2)}‖ + b²(‖𝔎‖+|q̂_κ|)、g(ϖ) ≥ ϖ²(θ̃−α̃)，全部对 ϖ∈[0,0.3] 一致，**无 Lipschitz 爆炸**。结果：

  **sup_{x∈(0,0.09]} H″(x) ≤ −0.722723**（F_lo=0.472511，正项 0.111150，pos/F=0.235，sin∠ ≤ 2.46e-1，g̃_lo=1.041129）。

（同一 cell 机器取 a=b=0 即给上面的 H″(0) ≤ −2.386326296。）λ̂_𝔊 = **1.318140211762671**、‖r_{𝔊(2)}‖ = **2.20791e-5** 与段 I 逐位相同（独立实现，互为交叉核）。

### 1.A.4 逐 cell 机器（与 Stage M 同一纪律，两处新推导）

cell [a,b]（0<a≤b）、p=中点、hw=半宽、v̂ = ℌ^{(Ns)}(p) 的 float64 顶本征向量补零至 ℓ²、Ns = max(140, 10ϖ)：

- **二次型是精确的、且 cell 一致界无 Lipschitz 松弛**。⟨v̂,𝒪[f]v̂⟩ = Σ_{k≥1}f(k)c_k（结构系数 c_k=T_k+U_k−P_k，O(Ns²) 预计算一次、每核 O(Ns)；Stage A 对 f=ℌ/φ/ψ 与直接双重和逐位核对）。φ_ϖ、ψ_ϖ、κ_ϖ **对 ϖ 逐点单调下降**，故 c_k 的正负分裂给**精确**的 cell 包络 Σ(c_k⁺f_b − c_k⁻f_a) ≤ q̂(ϖ) ≤ Σ(c_k⁺f_a − c_k⁻f_b)（Stage A 在 5 个内点验证包夹）。实测 **c_k ≥ 0 于全部 347 个 cell**（脚本报数），此时下界在 ϖ=b 处**取到**——这一项零代价；但分裂式不依赖该观察。
- **θ、‖r‖、α、DK 角**同 Stage M：θ=Rayleigh 商（有限支撑 ⟹ mpmath 精确）；残差 **含尾耦合**（m<Nr=4Ns 行精确、m≥Nr 用 `coupling_restricted`；`P4D_coulomb_operator.md` §2.4b 的修正在此同样承重）；α 由粗网格 `alpha_certificate_H`（Na 分档 70/140/280）+ 段包络 + L₁·粗宽/2；s_p = ‖r‖/(θ−α)。
- **（新推导 2）cell 一致角用 ‖v′‖ ≤ 2ϖ³E/g，不用 ‖ℌ′‖/g。** 由 v′=(λ₁−ℌ)⁺ℌ′v 得 ‖v′‖ ≤ ‖(I−P)ℌ′v‖/g，而 ℌ′=2ϖA_x 配 (I3) 给 **‖(I−P)ℌ′v‖ = 2ϖ³E**。朴素界 ‖ℌ′‖/g 在 ϖ=20 处比它松 ~20 倍（0.375 vs 0.0165），直接逼出 ~20× 的 cell 数。于是 sin∠(v̂,v(ϖ)) ≤ s_p + hw·sup‖v′‖ 与 E ≤ ê_ψ + s(‖𝒪[ψ]‖+|q̂_ψ|) 构成一个**单调不动点迭代**：从粗界 E ≤ ‖𝒪[ψ]‖ 出发迭代 ≤12 次，每一步都是合法上界、且单调下降（脚本内 break 条件保证）。
- **ê 的 cell 一致化用导数核的 Schur 界**：|∂_ϖψ_ϖ| ≤ 4b/(k²+a²)³、|∂_ϖφ_ϖ| ≤ 6b·k²/(k²+a²)⁴ ≤ 6b/(k²+a²)³ ⟹ ê_f(ϖ) ≤ ê_f(p) + hw·(4b 或 6b)·R₃，R₃ = Rsum[(1,a,3)]。
- **判据**：g_lo = max(θ−L₁hw, μ₂) − α，**b⁴·E_hi²/g_lo < F_lo** ⟹ sup_{x∈[a²,b²]}H″(x) ≤ −2F_lo + 2b⁴E_hi²/g_lo < 0。
- **C²（算子范数）的合法性**（Stage B）：ϖ∈[a,b]、a>0 时 3 阶段包络 `schur_full_seg_w0(a,b,3)` 有限（表见脚本输出：[20,20.5] 处 L₃=0.0267、[1,1.1] 处 11.83），给 ‖ℌ(w+δ)−ℌ(w)−δℌ′−δ²ℌ″/2‖ ≤ |δ|³L₃/6 与 ℌ″ 的范数连续（Stage B 内以 N=400 的 float64 余项做证据核）；x→0 端改用 A(x)=x𝔊(2)−x²𝒪[1/(k²(k²+x))]，核对 x 解析、各阶 x-导数被 j!/k^{2j+2} 控制、Schur 罩 ≤ 1.656383 ⟹ **A 在 x=0 邻域解析**。顶本征的单重孤立性**逐 cell 自带认证**（θ_cell>α ⟹ 谱投影秩 1），不外借基准区间定理。

### 1.A.7 何处停、为何停（如实报）

**(C\*) 本身永远不是障碍。** float64 探针（`notes/_scratch_ir/conc_probe5.py`，未提交、非证书；N=16ϖ）给 (C\*\*) 正负两项的**真实**比值

  (x²E²/g)/F = 0.1717 (ϖ=10) → 0.1872 (20) → 0.1937 (30) → 0.1989 (45) → 0.2020 (60) → 0.2059 (90) → **0.2090 (130)**，

即二阶微扰的正项只有 |⟨v,A_xx v⟩| 的 **1/5**，且随 ϖ 几乎不动（一个十倍程只涨 0.037）。**所以 §1 预期的「大 x 处 4ϖ²H″ ~ −2/x 趋零而 DK 误差不趋零 ⟹ 必有墙」在 (C\*) 层面不成立**：F 与 E² 同步以 ϖ^{-4} 衰减，比值有界。（另：x²F → 0.3077、x²H″ → −0.492 (ϖ=60)，与 §0 的 H″≈−1/(2x²) 一致。）

**本证书的墙是机器的，有两条，都不是 (C\*) 的：**
1. **α 的 Schur 包络 ∝ ϖ/Na**。本次 Na 封顶 280（Cholesky 是 O(Na³)，Na=280 时 4.8 s/节点，93 个粗节点已占 Stage L 的一半机时）。ϖ=45 处 α≈1.72 已吃掉 θ=4.35 的 40%（g_lo 2.52 vs 真隙 4.35，正项被放大 1.7×）。线性外推，**Na=280 固定时 ϖ≈80–90 处 α→θ、g_lo→0**，证书硬失效。取 Na ∝ ϖ 可消除这条，代价 O(ϖ³)。
2. **成本**。cells/e-fold ∝ ϖ^{0.6}（ϖ≈1 处 ~10，ϖ≈44 处 ~200），每 cell 成本 ∝ Ns² ∝ ϖ²；Stage L 607 s 中细 cell 约 300 s、粗 α 约 300 s。

**⟹ X=45 是 10 分钟预算下的选点，不是方法的极限。** 同一脚本 `EXT 60` 可继续（预计 ~16 min），再往上须先把 Na 抬起来。

### 1.A.8 诚实边界

1. **mpmath 不是区间算术**。所有认证量按安全方向加 ROUND_PAD=1e-12（绝对；最小的认证量 F_lo≈7.7e-8 仍比它高 5 个数量级）。与基线文件不同的是，**本文件的核表在 mpmath 中由精确输入直接生成**，没有 float64 逐元舍入要吸收；float64 只出现在 (a) 试探向量 v̂（按定义精确，任何向量都给合法但更弱的界）、(b) 证据表、(c) 被 import 的 `alpha_certificate_H` 的头块（那正是它自己的 ROUND_PAD 覆盖的）。
2. 结论只在 **x ∈ (0, 2025]（ϖ ≤ 45）**；**段 C-II 未动**，弱耦合极限（λ→0，ϖ→∞）不覆盖。⟹ 定理 E 目前只对**支撑在 ω ≤ 45·2πT 内的 P** 成立，按 §4 分层陈述，不写全 λ。
3. 「H 在 [0,2025] 上凹」用到 H 在 x=0 处的连续性/解析性（Stage B）；证书本身给的是 x∈(0,2025] 的逐点 H″<0 与 x=0 的 H″(0)≤−2.3863。
4. **未审**：(C\*) 的推导、(I1)–(I3)、‖v′‖≤2ϖ³E/g 的自洽迭代、cell 一致化、Stage S 的重标度写法，待 reviewer 对抗核。
