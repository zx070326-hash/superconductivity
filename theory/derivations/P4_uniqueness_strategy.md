## 1. 结构

记 u_n=(2n+1)^{-1/2}、核-通用算子 𝒪[f]=−L1[f]+L2[f]+L3[f]（`P4_conjecture2.md` §6.2），线性于 f。

## 2. 两条组合引理（与 P、T、ϖ 全部无关）

**引理 A（矩形部分和正性）**。对所有 k ≥ 1、L,L′ ≥ 1：
  Q_{LL′}(δ_k) := ⟨e_L, 𝒪[δ_k] e_{L′}⟩ = Σ_{n<L, m<L′} 𝒪[δ_k]_{nm} ≥ 0。
显式：Q_{LL′}(δ_k) = Σ_{n<L}[u_n u_{n+k}1_{n+k<L′} + u_n u_{n−k}1_{k≤n}] + Σ_{n<L, 0≤k−1−n<L′} u_n u_{k−1−n} − 2Σ_{k≤n<L} u_n²。
方阵 L=L′ 有闭式 Q_{LL}=2Σ_{m=k}^{L−1}u_m(u_{m−k}−u_m) + Σ_{n<min(L,k), k−1−n<L} u_n u_{k−1−n} ≥ 0（u 递减，逐项非负；主会话验证到 1e-15）。矩形情形（L≠L′）逐项不再全非负（行 n∈[max(L′,k),L) 贡献 u_n(u_{n−k}1_{n−k<L′}−2u_n) 可负），须整体论证。**数值**：k,L,L′ ≤ 500 穷举，min = 0（仅 Q₁₁(δ₂)=0 型退化取到），其余 >0（`_scratch_ir/uniq_probe3.py`、`uniq_probe6.py`）。
**推论 A′**：对任何 f ≥ 0 与任何 v∈C，⟨v,𝒪[f]v⟩ = Σ_k f(k) Σ_{L,L′} a_L a_{L′} Q_{LL′}(δ_k) ≥ 0；且 v≠0 时严格：某 a_L>0，⟨v,𝒪[f]v⟩ ≥ a_L² f(1) Q_{LL}(δ₁) ≥ a_L² f(1) u_0² > 0（只要 f(1)>0，对 f_{P,T} 成立当 P≠δ₀）。⟹ **对 v∈C\{0}，ϖ ↦ ⟨v,ℌ(ϖ)v⟩ 严格递增**。

**引理 B（Kamke 拟单调性 / 锥不变性）**。对所有 K ≥ 0、L ≠ L′（L,L′ ≥ 1）：
  W_{L,L′}(K) := (𝒪[1_{k≤K}] e_{L′})_{L−1} − (𝒪[1_{k≤K}] e_{L′})_L ≥ 0，
即 𝒪[1_{k≤K}] 在阶梯基 {e_L} 下的非对角系数非负（K=∞ 即 𝒪[1]=2uuᵀ−I：W=2S_{L′}(u_{L−1}−u_L)−1_{L=L′} ≥ 0 平凡）。**数值**：K ≤ 120 ∪ {150,200,300,499,∞}、L,L′ ≤ 500 穷举，min = 0（大量精确零，如 K=10 时 (L,L′)=(12,1)…），无负值（`uniq_probe6.py`）。对 Einstein、2 原子、20 原子、指数、幂、阶梯、高斯、随机递减核均 ≥ 0；对 δ_k（非单调核）**为负**（k=3,L=2,L′=1：−0.447）——故引理 B 真正依赖核的单调性，Abel 分解 F = Σ_K (F(K)−F(K+1))1_{k≤K}（系数 ≥0）把它化归到阶梯核。
**推论 B′**：对任何非增 F ≥ 0，生成元 𝒪[F] 在阶梯基下是 Metzler 型 ⟹ 半群 e^{t𝒪[F]} 保持 C（有限 N 截断：C_N 由 e_1..e_N 生成，非对角系数 ≥0 且末行系数 (𝒪e_{L′})_{N−1} 对 L′<N 是非对角元之和 ≥0；N→∞ 用强收敛 + C 闭）。

## 3. 主论证（给定引理 A、B）

设 T′ > T。𝔎′:=𝔎(P,T′) 紧自伴、λ₁′:=λ₁(𝔎′)>0。谱投影 P₁ = s-lim_{t→∞} e^{t(𝔎′−λ₁′)}（顶本征空间 E₁，其余谱 <λ₁′ 衰减）。由推论 B′，e^{t𝔎′}C ⊂ C，故 P₁C ⊂ E₁∩C（C 闭）。若 E₁∩C={0} 则 P₁ 在稠密集 C−C 上为零 ⟹ P₁=0，矛盾。取 v′∈E₁∩C，‖v′‖=1。则
  λ₁(𝔎(T)) ≥ ⟨v′,𝔎(T)v′⟩ = λ₁′ + ∫[⟨v′,ℌ(ω/2πT)v′⟩ − ⟨v′,ℌ(ω/2πT′)v′⟩]P(dω) > λ₁′，
因 ω/2πT > ω/2πT′ 且推论 A′ 给 ϖ↦⟨v′,ℌ(ϖ)v′⟩ 严格递增（P 在 ω>0 有正质量）。∎
**注**：(i) **不需要**顶本征值单重、不需要 Krein–Rutman、不需要 Hellmann–Feynman；(ii) 不需要 P 紧支；(iii) 同法给出 Einstein 情形 h 在全 ℝ₊ 严格递增（KAY III Thm 5 的 [0,ϖ_*) 推广到 ℝ₊），Stage M 的 [√2,30] 证书成为推论；(iv) 顶本征向量落在 C 中——探针：Einstein 与 2–20 原子 P 的 Perron 向量 0/100 违反 v≥0 且非增，且 v·√(2n+1) 亦非增（`uniq_probe.py`、`uniq_probe3.py`）；**库仑束 ℌ−μ̃K_c 的 Perron 向量 58/75 违反锥条件**（K_c 破坏结构），故本策略只覆盖 μ\*=0，μ\*>0 的唯一性另议。

### 3.A 主论证的严格写法（主会话，2026-09-12）

**设定**。P∈𝒫，P((0,∞))=1，⟨ω²⟩<∞。对 T>0 记 F_T(k):=∫⟦k⟧(ω/2πT)P(dω)、𝔎_T:=𝒪[F_T]（KAY II 的 𝔎(P,T)，逐元 P-平均）。F_T ≥ 0、非增、F_T(k) ≤ ⟨ϖ²⟩/k²，故 𝔎_T 有界自伴（Schur 界）且紧（KAY II Prop 2；本文只用有界自伴 + 顶谱为本征值，后者由 `P4_conjecture2.md` §6 的认证或 KAY 的紧性给出）。
