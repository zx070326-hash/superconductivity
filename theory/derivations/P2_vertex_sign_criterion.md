## 0. 问题的重新表述

PROGRAM.md 的 P2 原问："推导 δTc/Tc 的领头阶表达式，作为 ω_log/E_F 与 ⟨q⟩/2k_F 的函数，画增强/压制相图。" 调研后发现两件事改变了问题的形状：

1. **文献里没有现成的 Q_c*(m) 判据**——PGS 系原始论文不在 arXiv，后续论文只给定性（小 Q_c → 增强）。这是真空白。
2. **Schrödi 2020 的自洽全带宽解挑战了 PGS 图像**：顶角函数不是小 q 峰化的，α = ω_ph/E_F 越大越正、越各向同性；他们还明说各向同性 FSR 近似"severely underestimates"顶角效应。所以"用 Q_c 参数化"在强非绝热区可能失去意义。

因此 P2 v0 不从模型推 Q_c*(m)，而先**从第一性原理数据反推顶角修正的经验标度律**，再决定用哪个理论框架去解释它。

## 1. 从 Mishra 数据反推：顶角修正的同位素标度

定义 δ ≡ ln(Tc^{na}/Tc^{adia})（同一谱、同一 μ*，只开关一阶顶角图）。PGS 领头阶：顶角修正 ∝ 绝热参数 m = ω/E_F，而 ω ∝ M^{-1/2} → **δ_D/δ_H = 1/√2 = 0.707**（在 s_λ 与 E_F 对同位素不变的近似下）。

Mishra Figshare 数据（`p1_mishra_tc_table.py` 的 Tc）：

| 处理 | 情形 | δ_H | δ_D | δ_D/δ_H | δα_nad = (δ_D−δ_H)/ln2 |
|---|---|---|---|---|---|
| FSR（常 DOS） | 200 GPa 谐波 μ*=0.16 | −0.218 | −0.143 | **0.66** | +0.108 |
| | 200 GPa 非谐 μ*=0.16 | −0.208 | −0.149 | **0.72** | +0.085 |
| | 200 GPa 非谐 μ*=0.12 | −0.184 | −0.131 | **0.71** | +0.077 |
| | 160 GPa 非谐 μ*=0.16 | −0.076 | −0.045 | 0.60 | +0.044 |
| | 160 GPa 非谐 μ*=0.12 | −0.066 | −0.043 | 0.65 | +0.033 |
| FBW（能量依赖 DOS） | 200 GPa 谐波 | −0.053 | −0.041 | 0.79 | +0.016 |
| | 200 GPa 非谐 μ*=0.16 | −0.060 | −0.039 | 0.65 | +0.030 |
| | 200 GPa 非谐 μ*=0.12 | −0.051 | −0.038 | 0.76 | +0.018 |
| | 160 GPa 非谐 | −0.023 | −0.024 | 1.04 | −0.001 |

（符号说明：这里 δα_nad 定义为 −Δδ/ln2 的相反数，即 α^{na} − α^{adia} = −(δ_D − δ_H)/ln 2 … **注意**：α = −Δln Tc/ln 2，顶角把 H 压得更多 → α^{na} < α^{adia}，所以 δα_nad = −(δ_H − δ_D)/ln2 … 表中列的是 (δ_D − δ_H)/ln 2 = |δα_nad|，实际 δα_nad 为负，与 P1 §4.1 的 −0.085 一致。）

**读法（v0.1，含 reviewer 的不确定度）**：
- 常 DOS 下，200 GPa 的三种情形给 δ_D/δ_H = 0.66–0.72 ± 0.05（σ_Tc = 1 K），**与 M^{-1/2} 标度（0.707）相容**——这是"没有明显矛盾"级别的检验，不是高精度检验（Tc 噪声 ±4–8% 与 ±7% 的吻合同量级）。仍是第一性原理数据对 PGS 领头阶标度 P ∝ ω/E_F 的一次直接对照，Mishra 原文没有做。所需假设：s_λ 对 H/D 相同、E_F 对同位素不变、顶角效应线性于 m——三者在 P1 §3.2b 框架下都只近似成立。
- 160 GPa 的比值（0.60–0.65 ± 0.07–0.13）与 0.707 的偏离**不显著**（<1.7σ）。稳健的是**绝对量**：δ_H 从 −0.076 (160 GPa) 到 −0.208 (200 GPa)，顶角效应增强近 3 倍，而 ω_log 变化不到 10%——变的是 E_F^eff。Mishra 2026 说 H3S 的 E_F^eff 由 ε_F 下方的 vHs 特征决定（≈40–50 meV @200 GPa）；vHs 随压力靠近 ε_F 使 m 增大。**顶角修正对压力的敏感度远大于对同位素的敏感度，是 α(P) 的主要驱动之一。**
- FBW 下 δ 小 3–4 倍，比值噪声大：能量依赖 DOS 削弱顶角效应本身（不只是削弱其同位素依赖）。这与 P1 发现的 DOS×顶角交叉项是同一现象的两个侧面。

**推论**：在 H3S 的参数区，顶角修正 (a) 压制 Tc（δα_nad = −0.085 ± 0.019，稳健），(b) 对 ln Tc 的效应与 ∝ M^{-1/2} 相容，(c) 被能量依赖 DOS 削弱约 2/3。(b) 意味着领头阶线性标度在 m ~ 1 仍可用作零阶描述。

## 2. 与 PGS 静态极限的定量对照（v0.1：s_λ 更正）

EPL 42, 667 静态极限：Z₀ ≈ 1 + λ − λ²(π/4)(ω₀/(Q_c² E_F))。把顶角效应写成有效耦合 λ_eff = λ[1 + λP̄]，则 δ = s_λ · ln(1 + λP̄) ≈ s_λ λ P̄。**注意**：这是把 Z 通道与 φ 通道的顶角修正压成一个数（文献明说两通道泛函形式不同，`surveys/P2_vertex_formulas_2026-09-08.md` §2），只作量级估计。

用 200 GPa 非谐 FSR μ*=0.16：λ = 1.72（Figshare 谱的积分），s_λ = **1.27**（本求解器 `log_sensitivity("lambda")` 对该谱的实测值；v0 误写 0.95，reviewer M1），δ_H = −0.208 → **λP̄_H ≈ −0.16，P̄_H ≈ −0.095**；D：P̄_D ≈ −0.07。

PGS 静态：P_s = −ω₀/(ω₀ + E_F)。取 ω₀ = ω_log = 110 meV，要得到 P_s = −0.095 需 **E_F^eff ≈ 1.0–1.15 eV**——比 Mishra 的 vHs 拟合值（40–50 meV）大 20 倍，比裸 E_F（~17 eV 从带底算）小 15 倍。三种"E_F"差两个量级，说明 **PGS 单参数 m 的定义本身是问题**：顶角函数是 k' 积分（cond-mat/9806012 的 P_pol、P_ex），有效电子能标由 α²F 的动量结构与 DOS 形状共同决定，不能由一个数代表。这与 Schrödi 的"Q_c 失去意义"是同一件事。

## 3. 对 LaH10 的含义

P1 的 LaH10 反常（α_exp ≈ 0.57–0.71 > ½，理论 0.41）若要由顶角修正解释，需要 δα_nad > 0，即顶角修正对 H 的压制**小于**对 D 的，或顶角修正在 LaH10 里是增强型。H3S 数据表明在 m ~ 1–3、λ ~ 1.5–2.3 的区间顶角是压制型且与 M^{-1/2} 相容。LaH10：λ ≈ 2.7（Errea 2020，163 GPa）、ω_log ≈ 96 meV，DOS 在 ε_F 处相对平缓（Fm-3m 笼，无 H3S 那种 vHs 尖峰）。**以下是类比而非计算**（reviewer E）：若 E_F^eff 由 ε_F 附近 DOS 变化的能标决定（Mishra 的定义），则 LaH10 的 E_F^eff 大于 H3S → m 更小 → 顶角效应**更小**而不是反号。但 §2 刚证明单参数 m 在 H3S 内部就相差两个量级，所以这个类比的可靠性有限；LaH10 需要自己的顶角计算。在此之前的判断：**顶角修正解释 LaH10 反常的路径基本关闭**，除非 LaH10 的电声耦合动量结构极端小 q 主导（PGS 动态极限 P_d > 0）——这需要 LaH10 的 α²F(q) 分辨，Errea 2020 未发表。剩下：DOS 位形（P4）或实验数据问题。

## 4. 一阶理论的数值检验（v0.2，`p2_vertex_numeric.py`，`p2_out/`）

implementer 按 `P2_numeric_SPEC.md` 把 GPS99 Eq. (6)（一阶顶角、自由传播子、Matsubara 求和已做）在各向同性模型下数值积分（cosθ 积分做奇异性减除；四个解析极限 P_s、P_d、P_pol、v_F q/ω 判据全部复现到 <1%）。发现并改正了规格里的一处错误（v_F q = 4E_F·Q 而非 2E_F·Q），并指出原文第 3 页"v_F q/ω_q > 1 时 P 为正"是原文笔误（第 1 页引言写的是 "< 1 时为正"，与 P_s < 0 / P_d > 0 自洽）。

**H3S 参数**（ω₀ = 110 meV，E_F^free = 24.1 eV 使 N_free(E_F) = N(E_F)，DOS 用 QE 全表或常数），Q 在 [0, Q_c] 内平均、Einstein 传播子加权：

| 权重 | Q_c | P̄_H (const) | P̄_H (H3S DOS) | P̄_D/P̄_H | DOS 削弱 |
|---|---|---|---|---|---|
| flat | 0.1 | +0.045 | +0.033 | 0.77 | 0.72 |
| flat | 0.3 | +0.018 | +0.015 | 0.82 | 0.84 |
| flat | 1.0 | +0.0076 | +0.0075 | 0.95 | 1.00 |
| Q dQ | 0.1 | +0.016 | +0.014 | 0.67 | 0.82 |
| Q dQ | 1.0 | −0.0014 | −0.0003 | 0.64 | (零交叉附近，不稳) |

对照第一性原理目标：P̄_H ≈ −0.095、比值 0.66–0.72、DOS 削弱 ≈ 2/3。

**判断**：
1. **符号不对**。E_F^free = 24 eV 下静态区 |P_s| = ω₀/(ω₀+E_F) ≈ 0.005，小到被 Q → 0 的前向散射正尖峰（动态区 P_d > 0）压过，flat 平均全为正。这不是代码问题，是一阶自由传播子理论在"E_F 取裸费米能"时的真实输出。
2. **量级差 10–20 倍**（|P̄| ~ 0.005–0.04 vs 0.095）。
3. 同位素比值和 DOS 削弱在 Q_c 小时接近目标（0.67–0.77、0.72），但对权重和 Q_c 敏感，不稳健。

**结论**：把 E_F 取为裸费米能的 PGS 一阶理论**不能**复现 H3S 的第一性原理顶角修正。这与 Schrödi 2020 的判断一致（一阶各向同性近似 "severely underestimates"），也与 §2 的反推一致——要得到 P̄ ≈ −0.095 需要 E_F^eff ≈ 1 eV 而非 24 eV。**有效电子能标不是裸 E_F，是费米面附近 DOS 结构（H3S 的 vHs）设定的尺度**——Mishra 2026 定义 η = ω_log/E_F^eff 正是这个意思。正在做的补充扫描（E_F ∈ {0.5, 1, 2, 5, 24} eV，H3S DOS 形状不变）会给出完整 (Q, ω) 结构下的 E_F^eff，把 §2 的静态闭式反推升级。

**对 P2 问题的重新定位**：判据不是 Q_c*(m)，而是 **"有效 E_F 由什么决定"**。一阶理论的形式（GPS Eq. 6）是对的，缺的是输入——k' 求和里的传播子应当带上真实的、能量依赖的谱权重（vHs 附近的准粒子），而不是自由电子色散 + 常数 N(0) 归一化。这把 P2 和 P4（DOS 位形）合并成同一个问题。

## 4b. 下一步（v0.2 更新）

## 5. 假设与不确定

- Tc 由能隙消失温度读取，网格 1–2 K；reviewer 用 √(Tc−T) 拟合外推 39 个文件得 RMS 0.54 K → 每个 δ 的 σ ≈ 0.01（σ_Tc=1 K 保守），200 GPa FSR 的 δ_D/δ_H σ ≈ 0.05，160 GPa σ ≈ 0.07–0.13；FBW 情形 δ 本身 0.02–0.06，比值不可信
- **数据集身份**：Figshare 数据集 ↔ arXiv:2510.25902（逐 Tc 匹配，λ 2.29→1.72，μ*=0.16，静态 200 GPa）；arXiv:2608.14949 表 I 是另一次独立计算（ML/SSCHA，λ_anh=1.49，μ*=0.13，量子修正压力 210 GPa），两者不互相佐证
- s_λ 取本求解器对 Figshare 非谐谱的实测值 1.27（μ*=0.16）/1.18（μ*=0.12）
- "E_F^eff" 的三种定义不可互换，§2 的对照只说明 PGS 单参数化不够，不构成对 PGS 的定量检验
- §3 对 LaH10 的判断是类比（DOS 形状 → E_F^eff → m），不是 LaH10 自己的顶角计算
