## 0. 问题的重新表述

PROGRAM.md 的 P2 原问："推导 δTc/Tc 的领头阶表达式，作为 ω_log/E_F 与 ⟨q⟩/2k_F 的函数，画增强/压制相图。" 调研后发现两件事改变了问题的形状：

1. **文献里没有现成的 Q_c*(m) 判据**——PGS 系原始论文不在 arXiv，后续论文只给定性（小 Q_c → 增强）。这是真空白。
2. **Schrödi 2020 的自洽全带宽解挑战了 PGS 图像**：顶角函数不是小 q 峰化的，α = ω_ph/E_F 越大越正、越各向同性；他们还明说各向同性 FSR 近似"severely underestimates"顶角效应。所以"用 Q_c 参数化"在强非绝热区可能失去意义。

因此 P2 v0 不从模型推 Q_c*(m)，而先**从第一性原理数据反推顶角修正的经验标度律**，再决定用哪个理论框架去解释它。

## 1. 从 Mishra 数据反推：顶角修正的同位素标度

定义 δ ≡ ln(Tc^{na}/Tc^{adia})（同一谱、同一 μ*，只开关一阶顶角图）。PGS 领头阶：顶角修正 ∝ 绝热参数 m = ω/E_F，而 ω ∝ M^{-1/2} → **δ_D/δ_H = 1/√2 = 0.707**（在 s_λ 与 E_F 对同位素不变的近似下）。

Mishra Figshare 数据（`p1_mishra_tc_table.py` 的 Tc）：

| 处理 | 情形 | δ_H | δ_D | δ_D/δ_H | δα_nad = (δ_D−δ_H)/ln2 |
|---|---|---|---|---|---|
| FSR（常 DOS） | 200 GPa 谐波 μ*=0.16 | −0.218 | −0.143 | **0.66** | +0.108 |
| | 200 GPa 非谐 μ*=0.16 | −0.208 | −0.149 | **0.72** | +0.085 |
| | 200 GPa 非谐 μ*=0.12 | −0.184 | −0.131 | **0.71** | +0.077 |
| | 160 GPa 非谐 μ*=0.16 | −0.076 | −0.045 | 0.60 | +0.044 |
| | 160 GPa 非谐 μ*=0.12 | −0.066 | −0.043 | 0.65 | +0.033 |
| FBW（能量依赖 DOS） | 200 GPa 谐波 | −0.053 | −0.041 | 0.79 | +0.016 |
| | 200 GPa 非谐 μ*=0.16 | −0.060 | −0.039 | 0.65 | +0.030 |
| | 200 GPa 非谐 μ*=0.12 | −0.051 | −0.038 | 0.76 | +0.018 |
| | 160 GPa 非谐 | −0.023 | −0.024 | 1.04 | −0.001 |

（符号说明：这里 δα_nad 定义为 −Δδ/ln2 的相反数，即 α^{na} − α^{adia} = −(δ_D − δ_H)/ln 2 … **注意**：α = −Δln Tc/ln 2，顶角把 H 压得更多 → α^{na} < α^{adia}，所以 δα_nad = −(δ_H − δ_D)/ln2 … 表中列的是 (δ_D − δ_H)/ln 2 = |δα_nad|，实际 δα_nad 为负，与 P1 §4.1 的 −0.085 一致。）

**读法**：
- 常 DOS 下，200 GPa 的三种情形给 δ_D/δ_H = 0.66–0.72，**与 M^{-1/2} 标度（0.707）吻合到 ±7%**。这是用第一性原理数据对 PGS 领头阶标度 P ∝ ω/E_F 的一次直接检验，Mishra 原文没有做这个比较。
- 160 GPa 的比值偏低（0.60–0.65），且 δ 本身小 3 倍：顶角效应随压力从 160→200 GPa 增强近 3 倍，而 ω_log 变化不到 10%，所以变的是 E_F^eff——Mishra 2026 说 H3S 的 E_F^eff 由 ε_F 下方的 vHs 特征决定（≈40–50 meV @200 GPa）；vHs 随压力靠近 ε_F 使 m 增大。**顶角修正对压力的敏感度远大于对同位素的敏感度，是 α(P) 的主要驱动之一。**
- FBW 下 δ 小 3–4 倍，比值噪声大（Tc 网格 1–2 K，δ 只有 0.02–0.06）：能量依赖 DOS 削弱顶角效应本身（不只是削弱其同位素依赖）。这与 P1 发现的 DOS×顶角交叉项是同一现象的两个侧面。

**推论**：在 H3S 的参数区（λ ≈ 1.5–2.3，m ≡ ω_log/E_F^eff ≈ 1–3 按 Mishra 的 E_F^eff），顶角修正 (a) 压制 Tc，(b) 对 ln Tc 的效应近似 ∝ M^{-1/2}，(c) 被能量依赖 DOS 削弱 2/3。(b) 意味着领头阶线性标度在 m ~ 1 仍近似成立——比 Migdal 参数的表面值所暗示的要好。

## 2. 与 PGS 静态极限的定量对照

EPL 42, 667 静态极限：Z₀ ≈ 1 + λ − λ²(π/4)(ω₀/(Q_c² E_F))。把顶角效应写成有效耦合 λ_eff = λ[1 + λP̄]，则 δ = s_λ · ln(1 + λP̄) ≈ s_λ λ P̄。

用 200 GPa 非谐 FSR μ*=0.16：λ = 1.72（Figshare 谱的积分；Mishra 2608 表 I 用 SSCHA 谱给 1.49——两套非谐声子不同，本稿用 Figshare 数据自身的 λ），s_λ ≈ 0.95（本求解器，λ≈1.7），δ_H = −0.208 → **λP̄_H ≈ −0.22，P̄_H ≈ −0.13**；D：P̄_D ≈ −0.09。

PGS 静态：P_s = −ω₀/(ω₀ + E_F)。若取 ω₀ = ω_log = 110 meV，要得到 P_s = −0.13 需 **E_F^eff ≈ 0.74 eV**——比 Mishra 的 40–50 meV 大一个量级，比裸 E_F（~17 eV 从带底算）小一个量级。三种"E_F"差两个量级，说明 **PGS 单参数 m 的定义本身是问题**：顶角函数是 k' 积分（cond-mat/9806012 的 P_pol、P_ex），有效电子能标由 α²F 的动量结构与 DOS 形状共同决定，不能由一个数代表。这与 Schrödi 的"Q_c 失去意义"是同一件事。

## 3. 对 LaH10 的含义

P1 的 LaH10 反常（α_exp ≈ 0.57–0.71 > ½，理论 0.41）若要由顶角修正解释，需要 δα_nad > 0，即顶角修正对 H 的压制**小于**对 D 的，或顶角修正在 LaH10 里是增强型。H3S 数据表明在 m ~ 1–3、λ ~ 1.5–2.3 的区间顶角是压制型且 ∝ M^{-1/2}。LaH10：λ ≈ 2.7（Errea 2020，163 GPa）、ω_log ≈ 96 meV，DOS 在 ε_F 处相对平缓（Fm-3m 笼，无 H3S 那种 vHs 尖峰）→ E_F^eff 大 → m 小 → 顶角效应**更小**而不是反号。**顶角修正解释 LaH10 反常的路径基本关闭**，除非 LaH10 的电声耦合动量结构极端小 q 主导（PGS 动态极限 P_d > 0）——这需要 LaH10 的 α²F(q) 分辨，Errea 2020 未发表。剩下：DOS 位形（P4）或实验数据问题。

## 4. P2 的下一步（重新定义）

1. **经验标度律的普适性**：Mishra 2608.14949 表 I 给了 YH6、YH9、LaBeH8、PdH/D/T 的 anh 与 anh+ver Tc（FBW，μ*=0.13/0.085）。PdH/D/T 三个同位素的顶角效应 < 0.05 K 不可用；YH6/YH9 只有 H。**需要 Mishra 的 YH6/YD6 数据**——问作者或看 2608.14949 的 SM/Figshare 是否含 D。
2. **理论侧**：放弃 Q_c 参数化；改用 cond-mat/9806012 的 P_pol + P_ex 一般式，输入 Mishra 的 H3S DOS（`band/H3S.dos`）和一个模型 g²(q)，数值积分 k' 得 P(ω; N(ε))，看能否复现 P̄_H ≈ −0.13 与 M^{-1/2} 标度、以及 DOS 削弱效应。这是"最对但最重"的路径（调研建议 3），先做 H3S 单点验证。
3. **求解器**：第二阶段的顶角核钩子按 EPL 42,667 的 λ_Z = λ[1 + λP_V] 只作用 Z 通道（调研建议 1）作为最低阶；φ 通道暂置零并标注不完整。用它复现 Mishra 的 δ_H、δ_D 数量级。
4. **α(P) 作为判别量**（P4 合并）：160→200 GPa 顶角效应增强 3 倍，DOS 效应变号——同位素系数的压力依赖比单点 α 更能分解四因子。H3S 有 Villa-Cortés 的 α(P)（含 DOS 无顶角）与 Mishra 的两点（含顶角）——可以拼一条理论 α(P) 与 Drozdov 2015 Fig. 2c 的 Tc(P) 对比。

## 5. 假设与不确定

- Tc 由能隙消失温度读取，网格 1–2 K → 每个 δ 的不确定度 ≈ 0.01，比值 δ_D/δ_H 在 200 GPa FSR 的不确定度 ≈ ±0.05；FBW 情形 δ 本身 0.02–0.06，比值不可信
- Figshare 数据集的非谐声子是 ZG 位移法（arXiv:2510.25902），与 2608.14949 的 ML/SSCHA 不同（λ_anh 1.72 vs 1.49）
- s_λ 取本求解器的 Einstein 谱值，真实谱形会改 ±10%
- "E_F^eff" 的三种定义不可互换，§2 的对照只说明 PGS 单参数化不够，不构成对 PGS 的定量检验
