# Klein 1977 的 μ\* 无关声明：判不掉，但拆出了「驱动 vs 放大」（2026-09-18）

> **一句话**：Klein PRL 39,574 (1977) p.576 自称其反同位素效应预测「与 μ\* 的具体值无关」，
> 与仓库亏损预算的 `dα/dμ* ≈ −4.3` 表面相抵。**本轮判不掉他**（他解的是 Eliashberg 方程，
> 不是 McMillan，要判需要他的 `α²F`），但拆出两件有用的：
> **(1)** 两个互不相同的 Tc 泛函（McMillan 指数、我们的 Eliashberg 机器）**一致**给出强 μ\* 依赖
> ⟹ 我们的 −4.3 **不是** Einstein 代理或阶跃截断的赝物；
> **(2)** Klein 的「光学模机制」与我们的「81% 库仑」**并不冲突**，它们回答的是不同问题
> ——**驱动**是 λ(M) 上升（双方一致），**放大**是库仑项的非线性（分歧只在这一处）。
>
> **附带（计划外、且更承重）**：`isotope_pdh_discriminating_test_2026-09-18.md` 用的实验靶心带
> `[−0.322, −0.290]` **窄了 4.4 倍**。真正在证据里的带是 `[−0.3223, −0.1789]`。
> 同一个 Schirber–Northrup 实验被 Klein 引作 8.0/9.8、被 Errea 引作 8.0/10.0，**在 α 上值 0.029**。

## 2. McMillan/AD 指数下的精确条件 [analytic]

McMillan(1968) 与 Allen–Dynes(1975) 共用指数（前因子常数 1.45 vs 1.2 **在同位素比里抵消**，
故本节对两者同时成立）：

```
ln Tc = ln(Θ/A) − D(λ, μ*),    D(λ,μ*) := 1.04(1+λ) / (λ − μ*(1+0.62λ))
```

记 `x := ln(Θ_H/Θ_D)`，`L := ln(M_D/M_H)`。则

> **`α = α_Θ + α_λ(μ*)`，其中 `α_Θ = x/L`（**不含 μ\***），`α_λ(μ*) = [D(λ_D,μ*) − D(λ_H,μ*)]/L`**

⟹ **`α_λ(μ*) ≡ 0`（作为 μ\* 的函数）当且仅当 `λ_D = λ_H`。**

证明是一行：`D(λ,·)` 对固定 `λ` 是 `μ*` 的严格递增函数（分母递减、分子为正），
故 `μ* ↦ D(λ_D,μ*) − D(λ_H,μ*)` 恒为零当且仅当两条曲线重合，即 `λ_D = λ_H`。∎

**数值反证（脚本 `[4]` 段）**：令 `λ_D := λ_H = 0.54`，则 `α` 在 `μ* = 0 / 0.085 / 0.13` 三处
给出 **`+0.297452` 逐位相同**，等于 `α_Θ`。而 Klein 自己的 Table I 是 `λ: 0.54 → 0.62`。

⟹ **在 McMillan 这个泛函形式内，他陈述的那种无关性不可能成立。**
（这**不**等于说他的 Eliashberg 解不成立——见 §1(c)。）

## 3. 两个泛函一致：我们的 −4.3 不是代理赝物 [numerical-evidence]

把 Klein 的 `λ` 对代进 McMillan，固定声子输入扫 `μ*`：

| `μ*` | 0.000 | 0.040 | 0.060 | **0.085** | 0.100 | 0.130 |
|---|---|---|---|---|---|---|
| `α`（McMillan，Klein 的 λ 对） | −0.0615 | −0.1466 | −0.2003 | **−0.2815** | −0.3397 | −0.4845 |
| `α_budget`（我们的机器，PdH 的 λ 对） | −0.076 | −0.214 | −0.292 | **−0.399** | −0.469 | −0.620 |

| | McMillan | 我们的机器 |
|---|---|---|
| `dα/dμ*` @ 0.085 | **−3.62**（解析导数与 FD 差 3.4e−10） | **≈ −4.3** |
| 库仑通道占 α 的份额 @ 0.085 | **78.2%** | **81%** |

**两个结构完全不同的 Tc 泛函**（一个是闭式指数、一个是 Matsubara 算子的最大本征值）
**在符号、量级、份额上一致**。

⟹ **承重推论**：`isotope_pdh_discriminating_test_2026-09-18.md` §5.4 的 `dα/dμ* ≈ −4.3`
**不是** Einstein 代理、不是阶跃库仑截断 `N_c=⌊rϖ⌋`、也不是 `N` 截断的赝物。
1968 年的 McMillan 指数里就已经有这个强依赖。

⚠ **两张表的 λ 对不同**（Klein 0.54/0.62 vs Errea SSCHA 0.40/0.46），
所以这是**量级一致性检验，不是逐点复现**。不要把两行当同一个量对比。

## 4. 「驱动 vs 放大」——分歧其实很窄

Klein p.576 把机制归给**光学模**：

> "Since the mechanism for the opposite isotope effect is included in the **optic-mode
> contribution**, this effect tends to go away as x decreases…"

配 Fig. 2 的 `α_opt²/α_ac²` 比值曲线。而我们的预算把 81% 归给**库仑通道**。
**这两句话并不矛盾，它们回答的是不同问题：**

| | 内容 | Klein | 我们 | 一致？ |
|---|---|---|---|---|
| **驱动** | 什么让 `λ` 随质量上升 | 光学模非谐：`⟨ω²⟩_H` 比谐波值高 **20%**（p.575 逐字） | `λ(M)` 反常上升是**全部**驱动力（把 `λ_D` 退回 `λ_H`，α 立刻回到 +0.414） | **一致** |
| **放大** | `μ*` 把这个驱动放大多少 | 「与 μ\* 具体值无关」 | ≈ **5×**（−0.076 → −0.399），`dα/dμ* ≈ −4.3` | **分歧，且只在这一处** |

⟹ **正确的对外表述**：我们与 Klein 在**机制**上一致（都是 λ(M) 的非谐上升驱动），
分歧**仅限于库仑项的放大倍数**。这比「我们和 1977 年的文献冲突」精确得多，
也比「我们复现了 Klein」诚实得多。

**Klein 那句话里唯一在我们这边也成立的读法是「符号鲁棒」**：
上表 `μ* ∈ [0, 0.13]` 全部给 `α < 0`，**包括 `μ* = 0`**。
反同位素效应的**存在**确实不需要库仑项；需要库仑项的是它的**大小**。
（原文用了 "quantitative prediction"，字面上不支持这个弱读法；但这是唯一能同时容纳两边证据的读法。）

## 5. ⛔ 计划外的承重发现：实验靶心带窄了 4.4 倍

主会话读 Klein Table I（x=1.00 行）页图，**他自己印的实验列**与仓库笔记用的配对**不一致**：

| 来源 | `Tc(H)/Tc(D)` (K) | `α_exp` |
|---|---|---|
| **Klein Table I 脚注 a = ref 12（Schirber–Northrup）** | **8.0 / 9.8** | **−0.2931** |
| **Klein Table I 脚注 b = ref 13（Miller–Satterthwaite）** | **9.1 / 10.3** | **−0.1789** |
| Errea ref[8]（Schirber–Northrup，二手引用） | 8.0 / 10.0 | −0.3223 |
| Errea ref[7]（Stritzker–Buckel，二手引用） | 9.0 / 11.0 | −0.2898 |

**两处问题：**

1. **同一个实验（Schirber–Northrup）被两篇二手文献引成不同的数**：Klein 记 `9.8`、Errea 记 `10.0`。
   在 α 上值 **0.0292**。哪个对，**需要 Schirber–Northrup 1974 原文**，本轮未取。
2. **Miller–Satterthwaite（−0.1789）在仓库笔记里完全缺席。**

⟹ 证据里真正的实验带是 **`[−0.3223, −0.1789]`，宽 0.1434**；
`isotope_pdh_discriminating_test_2026-09-18.md` 假定的是 `[−0.3223, −0.2898]`，宽 0.0325。
**窄了 4.4 倍。**

**方向审计（必须做，否则会把这条读成「结论垮了」）**：
新增的 Miller–Satterthwaite 把带**朝不那么负**的方向加宽。我们的 `−0.399` 在整条带的**下方**，
故**最近边缘的过冲不变**，仍是 **0.0769**（由 Errea 引的 SN 值 −0.3223 定）。

⟹ **垮掉的不是「过冲」这个结论，而是它的精度声明。**
「系统性过冲 0.08–0.11」这个区间宽度 0.03 是从一个宽度 0.0325 的假靶心带来的；
真带宽 0.143 ⟹ 正确写法是「**过冲至少 0.077；上界取决于采信哪一组实验值，最大 0.22**」。

（这正是 CLAUDE.md「先分清『数字错』还是『证书松』」的一个实例：
`α_budget = −0.399` 这个**数字**没错、N 已收敛；错的是它被拿去比对的**靶心**。）
