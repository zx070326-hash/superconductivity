## 问题

氢化物的部分同位素系数 α_H 能否写成"理想 ME 值 + 库仑 + 非谐 + 非绝热 + DOS 四项修正"，并用 H3S/LaH10/YH6/YH9/PdH 的实测 α_H 约束四项的相对大小？

## 假设（本轮生效的）

A1 各向同性 ME；A3 Tolmachev 形式（存疑，数值标定）；A5 T=0 零点；A7 闭式只作示意，定量以 Eliashberg 数值为准；A8 部分同位素时 nad/DOS 项按 H 投影权重缩放（尚未生效）；A11 δα_μ 取 ω_c 完全跟 H 模的一支。

## 推导（关键步骤）

1. 主公式：显式全微分 α = −dlnω_log/dlnM − s_λ·dlnλ/dlnM − (∂lnΦ/∂μ*)·dμ*/dlnM − Σ s_k·dln r_k/dlnM，四项按进入渠道分类。
2. 库仑项：固定裸 μ，ω_c ∝ M^{-1/2} → δα_μ = (μ*²/2)∂lnΦ/∂μ* < 0。
3. 非谐项拆两通道：频率移动（单模 SCHA 四阶，δα = η[¼ − s_λ/2]，符号 = −sgn η_eff，因 s_λ ≥ ½ 数值成立）；谱重分布（无闭式，由 SSCHA 的 H/D 谱定义）。
4. 部分同位素：Rainer–Culetto 泛函导数定义 w_H；H3S 由 Errea 2015 表 I 标定 w_H(Tc) = 0.90、w^{(ω)} = 0.80。

## 数值验证（求解器 v0，32 测试全绿）

- 全同位素、谐波、μ* 固定：α = 0.5000（基本检验通过）
- **闭式对 μ* 的敏感度系统偏大**：λ=1.84 Einstein 谱，μ*=0.25 时数值 α = 0.444 vs McMillan 0.384；μ*=0.30 时 0.423 vs 0.302。McMillan 分母 λ−μ*(1+0.62λ) 变小夸大了 ∂lnTc/∂μ*。
- H3S 型三分量谱：w_H(Tc) = 0.91–0.93（与 Errea 数据标定的 0.90 一致）；δα_μ^{(H)} = −0.011 / −0.027 / −0.060（μ*=0.10/0.16/0.25）
- s_λ 数值 vs McMillan：λ=2 时 0.89 vs 0.75，λ=3 时 0.72 vs 0.47——McMillan 低估，AD 更近

## 与实验对比（H3S 第一轮账）

| 项 | 值 |
|---|---|
| 理想 ½w_H | 0.45（Errea 谐波 ME） |
| δα_anh | −0.10（Errea 非谐 ME，谱重分布为主） |
| δα_μ | −0.025（数值，μ*=0.16 随 ω_c） |
| 理论小计 | **0.32** |
| 实验 | **0.44**（203/150 K，H/D 压力未严格匹配）|
| 差额 | **+0.12 ± 0.1** → 只能来自非绝热或 DOS |

数据选择的脆弱点：Errea 原文对照的是早期 D₂S 90 K → α≈1.07，本账用终版 D₃S 150 K → 0.44。差额对这个选择极端敏感（+0.12 vs +0.7）。

## 结论与未解决点

**结论**
1. 四因子分解在结构上成立（显式全微分），无双重计数（reviewer 复核）。
2. 库仑与非谐（净硬化）只能压低 α；α 高于"谐波 + 库仑"理论值是非绝热或 DOS 的指纹。这是 P1 的判别逻辑，两轮审稿后站得住。
3. **H3S 的非谐 α 移动（−0.10）主要不是频率移动通道**：SSCHA 给 H3S/D3S 几乎相同的 λ（1.84/1.87），单模四阶模型预言的 dlnλ/dlnM ≈ 0.2 不成立；Errea 描述的是模间谱重分布。这条是本轮最有物理内容的发现，但论证依赖 Errea 的定性描述，需 SSCHA 的 H/D 两套 α²F 形状才能坐实。
4. **McMillan/AD 闭式在氢化物 μ* 区间不可用于定量**：库仑压制被高估 2–4×。YH6 的 α=0.40 若全归库仑需 μ*≈0.33 而非 0.25，"全归库仑"更难成立。
5. H3S 差额 +0.12 与实验不确定度同量级，单体系不能判别。
