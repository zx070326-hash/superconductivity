## 1. 显式条件（analytic 部分，仍然正确且有用）

对 AD 闭式 `Tc = (ω_log/1.2)·exp[−1.04(1+λ)/D(λ,μ*)]`，`D := λ − μ*(1+0.62λ)`：

```
∂lnF/∂lnλ = λ · (−1.04) · [D − (1+λ)(1−0.62μ*)] / D²
```

（`F := Tc/ω_log`；对 `λ` 求导后乘 `λ` 转成对数导数，闭式、零数值近似，`analytic`。）

`α(M)=0` 的显式条件：

```
α_ω(M) = (∂lnF/∂lnλ)|_{λ(M)} · (dlnλ/dlnM)|_M
```

其中 `α_ω(M) := −dlnω_log/dlnM` 是纯谱学量、`dlnλ/dlnM` 是非谐 λ 增强的质量依赖——两者都**不能**由单个模型给出，必须从数据内插，这就是 §2 的问题所在。

## 2. 内插散布（已在 §0 给出核心数字，此处补充方向审查）

- `quadratic-loglog`：二次曲率允许 `dlnλ/dlnM` 随 M 连续变化，是三者中最"平滑"、最符合"物理量应连续依赖质量"直觉的方案，**但它同样是唯一的插值假设，没有独立验证**（三点二次插值总能精确过三点，曲率纯属数学产物,不是物理输入）。
- `piecewise-powerlaw`：在 D 点强制导数不连续（H-D 段与 D-T 段用不同局部指数），物理上对应"H→D 与 D→T 是两种不同机制"的隐含假设——这个假设**没有物理依据**，纯粹是内插人为选择,但恰恰是这条线让 `M*` 在 `μ*` 稍增大后逃逸/消失。
- `global-powerlaw-lsq`：假设整个 M 范围内 `λ, ω_log` 服从单一幂律（常数对数导数），是三者中"先验最强"的假设，也是唯一给出「无解」的方案。
- **方向审查**：三个方案在给出根的地方，根都偏向 D 一侧（`2.19–2.44` vs. D–T 中点 `2.52`），没有一个方案把根推到 T 一侧或更远——在这个意义上"偏向 D"是稳的；但"精确在哪、是否存在"完全不稳。

### 新陈述凭什么对

- **存在性（`analytic`，MVT）**：对数平均在 `[H,D]` 为负、在 `[D,T]` 为正 ⟹ 任何经过三点的 `C¹` 内插 `α(M)` 在 `(M_H,M_T)` 内至少一个零点。位置**确实**依内插而异（`2.25` vs `2.44`，差 0.19 u）——这一条原文是对的。
- **★ 不变性恒等式（`analytic`）**：设观测量 `O(M;p)` 在 `M*` 处有单根，`p` 是任一扰动（`μ*`、谱形状偏移 `δ`……）。隐函数定理：
  ```
  dM*/dp = −(∂O/∂p)|_{M*} / (∂O/∂M)|_{M*}
  ```
  分母 `∂O/∂M` **与 `p` 无关**。于是对任意两个扰动 `p, q`：
  ```
  |dM*/dp · Δp| / |dM*/dq · Δq|  =  |∂O/∂p · Δp| / |∂O/∂q · Δq|
  ```
  即 **「机制灵敏度 / 干扰灵敏度」这个判别性比值在「报 `O` 的值」与「报 `O` 的零点位置」两种参数化下逐字相等**。
  数值（`numerical-evidence`，中心差分 `h=1e-6`，`Δμ*=0.09`、`Δδ=0.0638`）：

- **所以负面判决成立，且成立的理由是结构性的**：`M*` 把 α(D→T) 的**条件数**从刀口修好了（值不再在零点附近发抖），

  这与 §3 原文「`α(D→T)` 的符号判断需要更高精度的 μ*」并不矛盾：那是**条件数**层面；判别性层面两者相同。
