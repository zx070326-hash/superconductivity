## 2. 四处缺陷（每处独立成立）

### D4（最致命，analytic）：用 Carbotte 当实轴估计时，`R_real` **就是** `R_carb`，不经过 x/y

agent 设 `c := O_carb/O_mat`，`O_real := c·O_mat`。代回去 **`O_real ≡ O_carb`**，恒等。
所以「Carbotte 给的实轴修正下的 R」没有任何自由度可估——它**只能**是
`|∂O_carb·Δλ| / |∂O_carb·Δμ*| = 1.3777`。

**这个数 agent 手上本来就有**：它引用的正是我 §4 的那张表，`R_Carb = 1.3777` 印在同一行。
它把一个已经算完的量拆成 `x`、`y` 两个「待估参数」，再去估其中一个，
于是估出了一个与恒等式不符的答案。

**验收**：把正确的 `(x,y)` 代回 agent 自己的 `R_real` 公式，得 **1.3777**，
与直接算的 `R_carb` 差 **2.2e−16**。公式本身没错，错的是喂进去的 `x`。

### D2（主缺陷，analytic）：`c` 是比值，agent 冻结了分母

`_chk_realaxis_budget_2026-09-20.py:207-208`：

```python
O_mat_plus_approx  = O_base   # Assume Delta_(iω_0) roughly Tc-independent (weak coupling)
O_mat_minus_approx = O_base
```

于是 Carbotte 的**全部**强耦合增量被记到 `c` 头上。但 `O_mat` 自己也随 λ 涨，
**涨幅 agent 手上已有**（就是 `∂O·Δλ/O`）：

```
Δln O_carb = +0.041526        (Carbotte 侧)
Δln O_mat  = +0.044862        (松原侧，= 0.20767/4.6290)
x_correct  = Δln O_carb − Δln O_mat = −0.003335     ← 相消 92.0%
```

注释里的理由 *"Delta_(iω₀) roughly Tc-independent (weak coupling)"* 也自相矛盾：
锚点 λ=1.876 是**强耦合**，且表里 `O_mat` 从 4.41 走到 4.82（±4.5%），并非 Tc-无关。

## 4′. 与我自己 §9 的对账：13.5× 与 6.74× 是两个不同的量

`gap_ratio_mainsession_verification_2026-09-20.md` §9.2 报 **「单通道余量：λ 6.74×」**，
本文 §3 报 **13.5×**。两者**都对**，量的定义不同，**不要混引**：

| 预算定义 | 目标 | 所需 `x` | 与 `x_correct=−0.003335` 之比 |
|---|---|---|---|
| **把 λ 信号完全抵消**（分子 → 0） | `∂O·Δλ + O₀x = 0` | **−0.044862** | **13.5×** |
| **把 `R` 压到 1**（只动 λ 轴） | `\|分子\| = \|分母\|` | **−0.0225** | **6.74×** |

第二个是 `R_real = 1` 的**近根**（绝对值方程有两根，§9.1 的 `[−6.73%, −2.25%]`），
所以它总比第一个**近**（此处近 2.0×）。

- **与 agent 对账时用 13.5×**——它自己的 `dc_dlam_extreme = −dO_dlam/O_base` 就是第一种定义，
  同定义比较才是同量纲。
- **做判决（`R` 会不会翻转）时用 6.74×**——那才是「离 FAIL 还有多远」。

两者都 **>5×** ⟹ 无论取哪个定义，λ 轴按分档规则都**不承重**，§0 的判决不变。
真正近的是 μ\* 轴（§3 的 +34.9%），与 §9.2 的「μ\* 2.89×」同向、同结论。
