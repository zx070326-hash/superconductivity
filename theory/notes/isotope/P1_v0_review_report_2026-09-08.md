## 一、致命问题（会改变结论）

### F1. §3.2 结论"极强耦合下 δα_anh→0"与文档实际使用的 McMillan 公式矛盾，而且方向相反 —— CONFIRMED（数值验证）

**位置**：§6 清单第4条 + §3.2 eq (3.4) + H3S 数值例子。

**问题**：§6 清单说"Allen–Dynes 强耦合渐近 Tc∝ω√λ 给 δα_anh→0"，但文档所有实际数值（§3.1 表、§3.2 的 s=0.75、脚本 `p1_sympy_checks.py`）都用的是不含 f1f2 修正因子的纯 McMillan 公式 exp[−1.04(1+λ)/D]。两者渐近行为：

纯 McMillan：`lim_{λ→∞} lnΦ = -1.04/(1-0.62μ*)`，是有限常数 → `∂lnTc/∂lnλ → 0`（不是 1/2！这正是 McMillan 公式在强耦合下"饱和"的经典缺陷，Allen-Dynes 1975 引入 f1f2 就是为了修这个）。

用纯 McMillan 算 δα_anh 的系数 (¼−s/2)：
```
μ*=0.13:  λ=2:-0.124  λ=2.64:-0.023  λ=2.858(过零点)  λ=3:+0.013  λ=10:+0.184  λ→∞:+0.244(=1/4，不是0！)
```
即 δα_anh 不趋于 0，而是趋于其最大值 +η/4，且在 λ≈2.86–4.2（依赖 μ*）变号——这与 §2 推论1"μ*与非谐都给不出 α>½"直接矛盾。

用完整 Allen-Dynes（含 f1, f2，r=ω2/ωlog=1.2–2.5 敏感性测试）：s(λ) 单调升向 1/2，coef 恒负，从不变号，λ=1000 时仍是 -0.0006（真正趋于 0）。

```
             McMillan coef    AD coef(r=1.5)   比值
λ=1.84:        -0.162           -0.277          1.7×
λ=2.64:        -0.023           -0.195          8.5×
λ=3.0:         +0.013           -0.180          变号！
```

**结论**：§3.2 所有定量结果建立在一个已知在 λ≳1.5-2 失效的公式上，而 §6 用来验证的却是另一个公式的渐近行为。必须先统一到 Allen-Dynes f1f2（或求解器精确解），再重新算判据点和 H3S 数值。

### F2. §2 主公式 (2.1) 与 §3.2 的实际推导结构性不自洽 —— CONFIRMED

eq (2.1) 定义 `s_k ≡ ∂lnΦ/∂ln r_k |_{λ,μ*,其余r固定}`（明确要求固定 λ）；但 §3.2 的推导路径是 α = -dlnω_log/dlnM - (∂lnΦ/∂lnλ)·(dlnλ/dlnM)，其中 dlnλ/dlnM = η/2 ≠ 0——非谐效应的全部物理内容就是 λ 随 M 变。这与 (2.1) 的字面定义矛盾。

建议的修正形式：
```
α = -dlnω_log/dlnM - (∂lnΦ/∂lnλ)(dlnλ/dlnM) - (∂lnΦ/∂μ*)(dμ*/dlnM) - Σ_k(∂lnΦ/∂ln r_k)(dln r_k/dlnM)
```
并论证非绝热、DOS 修正是否也反馈到 λ。

### F3. 部分同位素系数 s_k → s_k^{(H)} 的推广没有推导，却是 §4 整个实验对比的基础 —— CONFIRMED（缺推导）
