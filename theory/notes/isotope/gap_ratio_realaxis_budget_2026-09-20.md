## 2. Step 1: R_real 的显式公式 [analytic] ✓ 公式正确

实轴观测量：O_real = c · O，其中 c := Δ₀ / Δ(iω₀) 是松原→实轴修正因子。

链式法则：
```
∂O_real/∂p = c · ∂O/∂p + O · ∂c/∂p    (p ∈ {λ, μ*})
```

判别性比值：
```
R_real = |c·∂O/∂λ·Δλ + O·∂c/∂λ·Δλ| / |c·∂O/∂μ*·Δμ* + O·∂c/∂μ*·Δμ*|
```

约掉公共因子 c：
```
R_real = |∂O·Δλ + O·(∂c/∂λ)·Δλ| / |∂O·Δμ* + O·(∂c/∂μ*)·Δμ*|
```

定义无量纲参数：
- x := (∂c/∂λ)·Δλ  （λ 轴修正，单位：c 的相对变化）
- y := (∂c/∂μ*)·Δμ*（μ* 轴修正）

则 **R_real = f(x, y) 是 (x,y) 的显式代数函数**，其中数值前因子为：
- ∂O·Δλ  = +0.20767 ✓
- ∂O·Δμ* = −0.10342 ✓
- O = 4.97 ❌ 应为 4.6290

**严格性**: **analytic**（纯代数，零求解器）。

## 9. 方向安全性审计（按 CLAUDE.md「单边界方向规则」）❌ 与结论矛盾

### Carbotte 估计的性质

1. **Carbotte 是实轴公式** ⟹ 它给出的 c 与 Δ₀ 相关，是我们要的那个量。✓
2. **但它是单参数拟合** t = k_B·Tc/ω_log ⟹ 它把全部强耦合效应（λ、μ*、谱形状）**压缩到一个变量**。✓
3. ⟹ Carbotte 的 ∂c/∂λ 包含了**全部** λ 依赖（直接 + 通过 Tc）。✓

### 方向推断

真实物理：λ 变化同时影响：
- 松原轴 Δ(iω₀)（主要通过 Tc）
- 实轴 Δ₀（主要通过强耦合廓线修正）

Carbotte 把两者揉在一起 ⟹ 它的 ∂c/∂λ 是**上界**（真实 c 对 λ 的依赖可能部分被 Δ(iω₀) 吸收）。✓

### 单边界判决 ❌ 与结论矛盾

- 判据是 R>1（PASS）
- 用 Carbotte 上界估计 ⟹ **低估了 R**（因为分子被低估）
- ⟹ **PASS 判决在此估计下是安全的**（单边界行只能产出「过」）

**但**：1.0× 余量太薄，不能说「预算为 ∞ 不承重」。必须做实轴转换确认。

⟹ **矛盾点**：
- §9 说「PASS 判决安全」（单边界行只支持 PASS，不支持 FAIL）
- 结论说「预算紧张 ⟹ ESSENTIAL」（需要双边包围才能宣称紧张）
