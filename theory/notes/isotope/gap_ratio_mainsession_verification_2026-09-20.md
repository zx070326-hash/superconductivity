## 2. 订正一（错在哪）：「弱耦合门禁未过」是 N 截断伪影

agent 报「λ=0.5 给 ~3.63、λ=0.1 预期 ~4.8，相对 BCS 3.528 有 +36% 系统偏差」，
据此建议「投入实轴转换成本」。

**这两个数里只有第一个是算出来的，第二个是外推**，而且**外推的方向与 BCS 极限相反**：
它推断「λ 下降 ⟹ ratio 上升」，但弱耦合极限下 `2Δ/kTc` 必须**降**向 BCS 3.5278。

真因：`Δ(iω₀)` 在 `T_low = 0.02 Tc` 上求解时，松原间距 `2πk_BT_low` 极小，
要覆盖 `w_cut` 需要的截断数有闭式

```
N_req = w_cut / (2π k_B T_low) = w_cut / (2π k_B · 0.02 · Tc)        [analytic，定义式]
```

`N_req ∝ 1/Tc` ⟹ **Tc 越小需求越大，而门禁恰恰跑在最小 Tc 处。**

实测（Einstein `ω_E=50 meV`，`μ*=0`，`w_cut=500 meV`，`T_low=0.02Tc`），
`w_max_cov := 2πk_B T_low N` 是实际覆盖到的最高松原频率：

## 9. 实轴修正的预算（2026-09-20）

> 脚本 `../_scratch_ir/_chk_main_realaxis_budget_2026-09-20.py`（纯代数 + Carbotte 闭式，零求解器）。
> **消费点**：判决 `R > 1`（λ 轴信号压过 μ* 干扰）。

### 9.1 预算的显式形式 [analytic]

设实轴修正因子 `c(λ,μ*) := Δ₀/Δ(iω₀)`，真实观测量 `O_real = c·O`。中心差分下

```
S_p = c₀·D_p + O₀·δc_p        (p ∈ {λ, μ*})
R_real(r_λ, r_μ) = |D_λ + O₀·r_λ| / |D_μ + O₀·r_μ|，   r_p := δc_p/c₀
```

`c₀` **整体约掉** ⟹ **预算只取决于 `c` 的参数依赖，与 `c` 本身的大小无关。**
这是本节最有用的一条：实轴能隙比松原首点大 2–3% 这件事**本身完全无害**，
有害的只有「大多少」是否随 (λ, μ*) 变。

代入自洽支实测 `D_λ=+0.20765, D_μ=−0.10340, O₀=4.6233`（我从 §4 的四个 `O` 重算，
复现 `R=2.0082`）：

| 退化情形 | 翻转阈值 |
|---|---|
| **λ 信号被完全吃掉** | `r_λ = −4.49%`，即 `dln c/dln λ = −0.299` |
| 只动 λ 通道，`R_real=1` | `r_λ ∈ [−6.73%, −2.25%]` |
| 只动 μ* 通道，`R_real=1` | `r_μ < −2.25%` 或 `r_μ > +6.73%` |

`r_λ` 是「λ 变 15% 时 `c` 变几个百分点」；`r_μ` 是「μ* 变 0.05 时 `c` 变几个百分点」。
⟹ **预算 ≈ `c` 需在这两段上稳定到 2.25% 以内。**

这条**加强**而非削弱 §9 的结论：真正承重的那个比值本来就对约定免疫。

### 11.3 我自己那条猜测被**证伪**（分两段写的第二段）

我在派诊断前告诉执行方：倾向「有限增量」才是对的对象，因为 `μ*` 通道指数敏感、
「局部导数 × 有限步」会被曲率污染。**实测：不是。**

| 量 | `w_cut=500` | `w_cut=1069` |
|---|---|---|
| `R_ME`：有限增量 ÷ 导数×Δ | **1.0009**（+0.1%） | **1.0023**（+0.2%） |
| `R_Tc`：有限增量 ÷ 导数×Δ | **1.0002**（+0.0%） | **0.9960**（−0.4%） |

⟹ 在 `Δλ/λ = 0.15`、`Δμ* = 0.05` 这个步长上，**曲率分叉 ≤ 0.4%，不是 FAIL 的成因**。
原则（消费点要的是有限不确定度下的实际位移，不是无穷小导数）**仍然成立**，
但它在本例**没有可测的后果**——不得拿它当归因。

### 11.4 剩下那 ~5% 的次要成因：执行方用了**单边**差分

同锚点下执行方 `dO/dλ = +0.6813`、`dO/dμ* = −1.6810`，我中心差分给 `+0.7268 / −1.7765`（差 6–7%）；
其基点 `Tc₀ = 191.39 K`、`O₀ = 4.6500` 与我在 `(1069, 0.02·Tc)` 上**逐位相同**
⟹ 基点无分歧，分歧在差分格式：**单边差分误差是 `O(h)`，中心差分是 `O(h²)`**，
`h = 15%` 时一阶项恰是所见的 6%。

它在 `R_ME` 上**大部分抵消**（其 2.2811 vs 我 2.3027，仅差 0.9%），
但在 `R_Tc` 上不抵消（其 1.6137 vs 我 1.5413，差 4.7%）
⟹ 净增益的 5.9% 分歧几乎全部来自这里。**改中心差分即可**，与 `w_cut` 无关。

### 11.5 门的修法

锚点规格补成：`(λ=1.876, ω_E=106.9 meV, μ*=0.13, **w_cut=500 meV**, N=1600, T_low=0.03·Tc, 中心差分)`
⟹ `R_ME = 2.0080`、`R_Tc = 1.3710`、净增益 `= 1.4646`。
`T_low` 取 0.02 而非 0.03 只动 `R_ME` +0.65%（`2.0080 → 2.0211`）⟹ 可放进 ±2% 容差，
**但 `w_cut` 不行，必须写死。**

⟹ 记入事故表：**一个只写了部分约定的验收门，会把「执行方实现有别」和「我的目标数有错」
两种相反情形都伪装成同一个 FAIL。目标常数必须与它的全部约定一起交付**，
这是「目标常数必须随消费点一起交付」的同一条纪律在**约定**维度上的推广。
