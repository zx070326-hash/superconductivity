## 0. 陈述

设 ℓ²(ℕ₀)，u_n=(2n+1)^{-1/2}，D_u=diag(u)，e₀ 为第一 Matsubara 基矢。对核 f:ℕ₀→ℝ，

```
L1[f] = diag( (2n+1)^{-1} · 2 Σ_{k=1}^{n} f(k) )          （Z / 质量重整化通道，对角）
P[f]  = L2[f] + L3[f],   L2_nm=(1-δ_nm) f(|n-m|) u_n u_m,  L3_nm = f(n+m+1) u_n u_m   （Δ / 配对通道）
𝒪[f]  = -L1[f] + P[f],      𝒪'[f] := +L1[f] + P[f]
```

线性化 Eliashberg 算子（各向同性单带、平坦 DOS）：

```
M = -L1[φ_Z] + P[φ_Δ],     φ_Z = 总谱权（≥0），  φ_Δ = 符号组合
```

玻色核类 **𝒫** := { f(k)=∫₀^∞ ω²/(ω²+k²) dP(ω) : P≥0 有限测度 }（ω 以 2πT 为单位）。
Berk–Schrieffer 结构：φ_Z=f₊+f₋，φ_Δ=f₊−f₋，f₊,f₋∈𝒫。

> **定理 I（Δ 通道免疫）.** 设 f₊,f₋∈𝒫，φ_Z≥0 满足 Σ_{k≤n}φ_Z(k) ≥ Σ_{k≤n}(f₊+f₋)(k) ∀n≥1（Eliashberg 情形取等）。记 ℌ₊:=𝒪[f₊]，其谱 μ₁>μ₂≥…，顶向量 ψ₁，c₁:=|⟨ψ₁,e₀⟩|，γ:=μ₁−μ₂。则
>
> ```
> M ⪯ ℌ₊ + ρ(f₋)·e₀e₀ᵀ ,      ρ(f₋) := f₋(0) − f̂₋(π) ∈ [0, f₋(0))
> ```
> 从而对所有 j≥1，λ_{j+1}(M) ≤ λ_j(ℌ₊)，并且
> ```
> λ₂(M) ≤ μ₁ − c₁²γ = (1−c₁²)μ₁ + c₁²μ₂         —— 对 ρ 一致，即与排斥的强度/宽度/形状无关
> ```

**物理读法**：排斥在配对通道里想干什么都行——任意强、任意谱形、任意秩——第二本征值被一个**只由吸引部分决定**的数值封顶。排斥能压低 λ₁，但压不出简并。秩一（单模）主导性对 Δ 通道免疫。

## 1. 证明

### 引理 1（Bochner / Poisson）—— analytic

f∈𝒫 ⟹ f 延拓成 ℤ 上的正定序列，符号

```
f̂(θ) = Σ_{k∈ℤ} f(k) e^{-ikθ} = ∫ πω · cosh(ω(π−θ))/sinh(πω) dP(ω) ≥ 0 ,  θ∈[0,2π]
```

（用 Σ_{n∈ℤ} e^{-inθ}·2a/(a²+n²) = 2π cosh(a(π−θ))/sinh(aπ)）。cosh(ω(π−θ)) 在 θ=π 取最小，故

```
min_θ f̂(θ) = f̂(π) = ∫ πω/sinh(πω) dP(ω) > 0 .
```

### 引理 2（偶扇区压缩）—— analytic

对 ℤ 上任意正定 f 与 x∈ℓ²(ℕ₀)，取关于 −1/2 的反射延拓 X_n=x_n, X_{−1−n}=x_n (n≥0)。则

```
⟨X, T̃ X⟩ = 2 ⟨x, (T_f + H_f) x⟩ ,   T_f=[f(n−m)], H_f=[f(n+m+1)],   ‖X‖²=2‖x‖²
```

而 ⟨X,T̃X⟩ ≥ f̂(π)‖X‖²，故

```
T_f + H_f ⪰ f̂(π) · I      （对任意 N 截断同样成立：它是无穷矩阵的主压缩）
```

由 P[f] = D_u(T_f+H_f)D_u − f(0)D_u²（L2 挖掉对角即扣掉 f(0)D_u²）得

> **推论 2.1**　P[f] ⪰ −( f(0) − f̂(π) ) D_u² = −ρ(f)·D_u² 。

### 引理 3（初等不等式）—— analytic

对一切 ω>0：

```
ψ(ω) := 2ω²/(ω²+1) + πω/sinh(πω) − 1 ≥ 0 ,      ψ(ω) = (2 − π²/6)ω² + O(ω⁴) ,  2−π²/6 = 0.355066…
```

*证*：两边乘 (1+ω²)sinh(πω)>0，等价于 q(ω):=πω(1+ω²) − (1−ω²)sinh(πω) ≥ 0。展开成奇幂级数，ω^{2j+1} 的系数为

```
j=0:  π − π = 0
j=1:  2π − π³/6 = 1.115473…            > 0
j≥2:  π^{2j−1}·[ 2j(2j+1) − π² ] / (2j+1)!  > 0    （2j(2j+1) ≥ 20 > π² = 9.8696）
```

全部非负 ⟹ q(ω)≥0 ∀ω≥0。∎（不需要分区间估计；整个 (0,∞) 一次拿下。）

### 引理 4（免疫核心：Z 通道支配排斥的 Δ 通道）—— analytic

对每个 f∈𝒫：

```
𝒪'[f] = L1[f] + P[f] ⪰ −ρ(f) · e₀e₀ᵀ ,        ρ(f)=f(0)−f̂(π)
```

*证*：由推论 2.1，𝒪'[f] ⪰ L1[f] − ρ(f)D_u² =: diag(a)，

```
a_n = [ 2Σ_{k=1}^{n} f(k) − f(0) + f̂(π) ] / (2n+1)
```

- n=0（空和）：a₀ = f̂(π) − f(0) = −ρ(f)。
- n≥1：f≥0 ⟹ Σ_{k≤n}f(k) ≥ f(1)，故 a_n ≥ [2f(1)+f̂(π)−f(0)]/(2n+1) = ∫ψ(ω)dP(ω)/(2n+1) ≥ 0（引理 3）。

于是 diag(a) ⪰ −ρ(f)e₀e₀ᵀ。∎

> **这一步是全部内容所在**：Eliashberg 里同一段谱权 f₋ 同时出现在 Z 通道（正定对角 L1）和 Δ 通道（P）。L1 的对角增长 2Σ_{k≤n}f(k)/(2n+1) **逐点压住** P 的最负部分 −ρ(f)u_n²，唯一漏网的是 n=0（那里和是空的）。漏的那一格是**秩一**的。

### 定理 I 的证明 —— analytic

φ_Z 的部分和条件 ⟹ L1[φ_Z] ⪰ L1[f₊+f₋]（两者都是对角，逐项比较）。故

```
M = −L1[φ_Z] + P[f₊] − P[f₋] ⪯ −L1[f₊] − L1[f₋] + P[f₊] − P[f₋] = ℌ₊ − 𝒪'[f₋] ⪯ ℌ₊ + ρ(f₋)e₀e₀ᵀ
```

Weyl 单调性给 λ_j(M) ≤ λ_j(ℌ₊+ρe₀e₀ᵀ)；秩一扰动的 Cauchy 交错给 λ_{j+1}(ℌ₊+ρe₀e₀ᵀ) ≤ λ_j(ℌ₊)。

**λ₂ 的一致界**（对 ρ 一致）：记 B=ℌ₊+ρe₀e₀ᵀ, x=λ₂(B), c_j=⟨ψ_j,e₀⟩。若 x≤μ₂ 则 x ≤ μ₁−γ ≤ μ₁−c₁²γ（c₁²≤1），完毕。否则 x∈(μ₂,μ₁)，久期方程 1 = ρΣ_j c_j²/(x−μ_j) 成立。置 d=μ₁−x>0：

```
ρc₁²/d = ρ Σ_{j≥2} c_j²/(x−μ_j) − 1 ≤ ρ(1−c₁²)/(x−μ₂) = ρ(1−c₁²)/(γ−d)
```

（j≥2 项分母 x−μ_j ≥ x−μ₂ = γ−d > 0，全为正；Σ_{j≥2}c_j²=1−c₁²；丢掉 −1 只会放大右边）。整理得 c₁²(γ−d) ≤ (1−c₁²)d，即 **d ≥ c₁²γ**。∎

（c₁=0 时 λ₂(B)=μ₁，界取等，仍成立；x 恰为 ℌ₊ 某本征值时限制到相应不变子空间同理。）

**ℌ₊ 的顶本征值是简单的**：f₊>0 时 P[f₊] 的非对角元 f₊(|n−m|)u_nu_m>0，加对角不改变不可约性，Perron–Frobenius ⟹ ψ₁>0 逐点，故 c₁>0、μ₁>μ₂。

## 2. 推论

### 推论 I.1（静态库仑：完全免疫）—— analytic

瞬时库仑排斥只进 Δ 通道且在 KAY 表示下是**秩一半正定**的：P_C = 2μ̃ u_c u_cᵀ ⪰ 0（u_c[n]=u_n·1_{n<N_c}）。它没有 Z 伙伴，但也不需要：

```
M = ℌ₊ − 2μ̃ u_c u_cᵀ ⪯ ℌ₊   ⟹   λ₂(M) ≤ μ₂(ℌ₊)
```

即库仑**完全不能**抬高第二本征值。它能做的只是沿 Cauchy 交错把 λ₁ 从 μ₁ 压向下界 μ₂——杀死配对，但永远不制造近简并。这正是 P4D 里"κ≈2 近交叉点"处真 gap/λ₁→1.001 的结构原因（见 memory `negative-kernel-gap-collapse-is-z-channel-artifact-2026-09-16`）。

### 推论 I.2（免疫预算 = c₁²）—— analytic + numerical-evidence

Tc 定义为 λ₁(M)=1。记 μ₁=λ₁(ℌ₊) 在**同一温度**下的值（排斥把 Tc 压低 ⟹ μ₁>1），定义压制份额

```
s := 1 − 1/μ₁  ∈ [0,1)      （排斥在 Tc 处吃掉的配对本征值比例）
```

则由定理 I（μ₂≈0）：

```
λ₂(M) ≤ (1−c₁²)μ₁ + c₁²μ₂   <  1 = λ₁(M)     ⟸     s < c₁²  （μ₂=0 时充要于此界）
gap/λ₁ ≥ 1 − (1−c₁²)μ₁ − c₁²μ₂
```

> **c₁² —— 顶配对模在第一 Matsubara 频率上的权重 —— 就是免疫预算：排斥可以吃掉最多 c₁² 份额的配对本征值，顶模的孤立性才可能在原理上受威胁。**

c₁²(ϖ) 与阈值 μ₁^max=1/(1−c₁²)（**numerical-evidence**：float64 `eigvalsh`，N=400 与 N=800 四位一致；ϖ≥30 处 μ₂ 有 ~1e-2 截断噪声，不影响 c₁²）：

## 3. 逃逸路径（定理不覆盖什么）

定理的假设逐条对应一条唯一的破坏机制：

| 被违反的假设 | 物理意义 | 是否物理可实现 |
|---|---|---|
| Σφ_Z ≥ Σ(f₊+f₋) 失效（Z 通道负权） | Z<1，负质量重整化 | **否**（α²F≥0 ⟹ Z 通道权重非负） |
| f₋ ∉ 𝒫 | 排斥谱密度变号 | **否**（谱密度 ≥0） |
| u_n=(2n+1)^{-1/2} 本身改变 | DOS 结构：van Hove 使 τ_n 变成 n- 与 T- 依赖 | **是** —— 唯一的物理逃逸口 |

即：**在各向同性单带 Eliashberg 里，摧毁秩一主导性的唯一物理通道是 DOS/Z 通道。** 这与 `dimension_universality_2026-09-16.md` 的结论（van Hove 破坏的正是 τ_n 的 T-无关性、KAY 框架本身）咬合成同一句话的两半。

## 5. 这句话为什么是物理（而不是重新包装）

1. **解释了两参数经验公式为什么能成立**。Allen–Dynes 型 Tc(λ,⟨ω⟩,μ*) 把配对不稳定性当成单个标量（顶本征值）的函数。定理 I 说：在配对通道里无论加多强的排斥，临界模都仍是一个孤立单模——所以"用一个标量参数化"不是拟合运气，是谱结构的结论。
2. **给出一个可证伪的否定预言**。各向同性单带 Eliashberg 中**不存在**由排斥强度/谱形驱动的配对模竞争或能级交叉。任何观察到的配对模竞争必须来自 DOS/Z 通道、各向异性或多带——不能来自"库仑/自旋涨落太强"。
3. **把 μ\* 的角色降级**。μ\* 只沿 Cauchy 交错移动 λ₁（推论 I.1 给出它的确切下界 μ₂(ℌ₊)），完全不碰谱的秩结构。
4. **c₁² 是一个新的无量纲控制数**：顶配对模在第一 Matsubara 频率上的权重 = 免疫预算，ϖ 的显函数（表见 §2）。

## 7. 诚实边界

1. §2 表中的 c₁²(ϖ) 数值是 float64 截断谱计算，**numerical-evidence**。定理 I 本身不用这些数（它对任意 ℌ₊ 成立）；只有"物理域落在预算内"这句判断依赖它们。
2. 定理只覆盖各向同性单带、平坦 DOS、KAY 形式的算子。多带/各向异性下 P 的正定性论证（引理 2 的反射延拓）不直接搬运。
3. ρ(f)=f(0)−f̂(π) 这个常数是从引理 2 的**最坏符号**（θ=π）来的，对宽核 (ϖ≫1) 几乎等于 f(0)；对软核 (ϖ≪1) ρ→0，免疫是完全的。中间区没有做更细的优化。
4. 未做区间算术：本文没有 certificate 级结论，只有 analytic（定理）与 numerical-evidence（表格/核验）两类。
