## 2. μ\*>0 时的算子：精确形式（回答问题 2）

仓库里的形式是**算子束（pencil）而非可相减的单算子**（`P4D_coulomb_operator.md:22–30`）：

```
Tc 判据：Q_{λ,μ*}(Ξ) = ⟨Ξ, (ℑ − λ𝔎_ph + μ*𝔎_c) Ξ⟩ ⪰ 0 失去正定性
单参数约化：束正定 ⟺ λ₁(M) < 1/λ，   M := 𝔎_ph − μ̃𝔎_c,   μ̃ := μ*/λ
𝔎_c = 2|u_c⟩⟨u_c|,   u_c[n] = (2n+1)^{-1/2}·𝟙_{n<N_c},   N_c = ⌊ω_c/2πT⌋
```

要点（全部 analytic 或已证伪订正，`P4D_coulomb_operator.md` §1）：

1. **是秩一、半正定**：`𝔎_c = 2|u⟩⟨u|`。首版 researcher 组装里的 `−D`（对角挖除）项**已被证伪**（`p4d_coulomb_falsify.py` GATE C/D：−D 变体的 Tolmachev 斜率背离 −1；ϖ=2、N_c≥256 时 Tc 条件无解）。所以**团队 lead 问题里的「−μ\* u uᵀ」在归一化常数上要乘 2**：是 −**2**μ̃|u_c⟩⟨u_c|，因子 2 = 正频像与负频像（m=−n−1）各一次。
2. **精确恒等式**（`P4D_coulomb_uniqueness.md:38`，两行证明、非数值发现）：**𝔎_c(N_c) = P_{N_c}(𝒪[1] + I)P_{N_c}**，由 𝒪[1]=2uuᵀ−I 得。
3. **权重 u_n=(2n+1)^{-1/2}**（不是指示向量），这是全部对数行为的来源；‖u_c‖² = S(N_c) = ½ln N_c + ½(γ_E+ln4) + O(N_c^{-2})，即 Morel–Anderson 对数，**非一致有界**。
4. **μ\* 只进能隙（Δ）通道，不进 Z 通道**（Marsiglio eq.22 核实，A 级）——这同时是 −D 被证伪的原因。
5. **对称化是建模选择（B 级）**：Marsiglio eq.23 的核是非对称的 −2μ\*|v⟩⟨u|；KAY 自伴框架用 −2μ\*|u⟩⟨u|。对称化代价实测 ω_c/ω_E=5/10/20/50 处 μ\* 相对差 −3.5%/−0.79%/−0.17%/−0.022%。
6. **N_c 依赖 T**，经 N_c=⌊ω_c/2πT⌋ 带回温度依赖，且是阶梯函数（这制造了 §3 末尾的跨窗问题）。**但在定理 E 的语境里 T 固定、ω 变动，故 N_c 固定**——这一点对 §4.4 的审计结论很关键。

### 3.1 锥路线在 μ\*>0 下的精确死法（`P4D_coulomb_uniqueness.md` §1–§2，主要结论 analytic）

- **事实 1.3（𝔎_c 的 Kamke 闭式，analytic）**：W^c_{L,L′} = 2·S(min(L′,N_c))·(u_{L−1}𝟙_{L−1<N_c} − u_L𝟙_{L<N_c}) ≥ 0 **处处**，支集恰为 L ≤ N_c 的 N_c 行。
  ⟹ M=A−μ̃𝔎_c 的 Kamke 矩阵是 W^F − μ̃W^c：**被减去的是一个处处非负的生成元块**，于是阶梯基下的非对角系数变负、**Metzler 性质被破坏 ⟹ 引理 B 失效 ⟹ 推论 B′（半群保锥）失效 ⟹ M-b/M-c/M-d 连锁断裂**。
- **广义引理 B 成立但定量无用（§2，命题 2.1 analytic + 数值表）**：Metzler 性质当且仅当
  `μ̃ ≤ μ_Metz(F,N_c) := min_{L≠L′, W^c>0} W^F_{L,L′}/W^c_{L,L′}`，
  而 **μ_Metz ~ ϖ̄²/N_c³**（ϖ̄=1 时 N_c=10 给 1.5e−3、N_c=40 给 2.7e−5），比物理 μ̃∈[0.04,0.33] **低 2–4 个量级**。原文逐字：「**锥不变性路线在 μ\*>0 下不可救**」「**这是对任务第 2 项最强形式的诚实否定答案**」。
- **出锥是系统性的，不是边缘现象（§2.C，numerical-evidence，N=200/400/800 一致）**：μ̃>0 时顶向量**一律出锥**，且**变号次数恒为 2**（小 n 正、n≈N_c 附近负、尾部再正）。⟹ Gantmacher–Krein「至多一次变号」的振荡锥**被证伪**，不是正确的替代不变集。
- **主要破坏参数不是「出锥」而是「近交叉」**：κ := 2μ̃c₁²/γ。已知的窗内单调性反例（N_c=4、ϖ̄≈0.74、μ̃≈0.322）处 κ=2.05，机制是 λ₁(M) 被压到与 A 的 μ₂ 近交叉（间距 4.1e−5），不是渐进出锥（§5）。

### 4.3 这个窗口对定理 E 到底承不承重

需要分清两件事：

- **定理 E 的主证明链（E1–E5）根本不用 H 的凹性**——它用的是**核级** Jensen（逐 k）＋引理 M。所以 H_μ 的凹性失效**不直接**打击定理 E。
- 但在 μ\*>0 下，`pairing_duality_theorem` §5.1 走的是**另一条路线**：λ₁(M) 关于 P 仿射族的 sup ⟹ 关于 P **凸** ⟹ 在紧凸集 K_C 上的极大化在**极点**取到。这条路线里 H_μ 的凹性是**必需的**：K_C={P: ∫ω²dP=C} 有两条线性约束，其极点是**最多两原子**的测度，**不是**点质量；把 2-原子压到 1-原子**正是** H_μ 的凹性（弦在函数下方）。§5.1 原文「极值在极点 delta_sqrt(C) 取到——只要 H_mu(x) 凹」把这两步并成了一句，**该处的「极点」措辞不准确**（δ_{√C} 不是 K_C 的极点；它是 H_μ 凹性带来的**第二步**的产物）。结论不变，但推理链条少了一节。
- 另一方面，**凹性在一个子窗内失效 ≠ Jensen 失效**：2-原子归约要的是弦不等式 w·H(x₁)+(1−w)·H(x₂) ≤ H(x̄)，一个靠近 0 的局部凸区完全可能仍被整体弦条件压住。**所以 §5.3 的发现是「一条充分条件断了」，不是「极值性断了」。** 来源没有把这两句分开写。

### 4.4 ★ 审计发现：那张 H_μ'' 表用的不是物理库仑窗（源码级，我读代码得出，未跑）

`spectral_efficiency.py:354–360`：

```python
def h_mu_val(varpi, mu_tilde, N=N_MU):
    Nuse = max(N, int(5 * varpi))
    H = build_H_fast2(varpi, Nuse)
    u = 1.0 / np.sqrt(2.0 * np.arange(Nuse) + 1.0)     # ← 没有 1_{n<N_c}
    M = H - 2 * mu_tilde * np.outer(u, u)
```

**`u` 是整段未截断的向量**，即等价于取 **N_c = Nuse = 200**。而物理上 N_c = ⌊ω_c/2πT⌋ = ⌊r·ϖ⌋，物理锚点（`P4D_coulomb_uniqueness.md` §4）的 N_c 是 **6…153，典型 6–45**。差别不是记号问题：

- ‖u_c‖² = S(N_c)：S(200)≈3.63 对 S(10)≈2.13、S(6)≈1.88 ——**该表把库仑强度放大了约 1.7–1.9×**。

## 7. 补洞路线（按性价比排序）

> 统一的技术事实：**所有路线最终都归约到同一个标量符号**
> `⟨v̂_P, 𝒪[d] v̂_P⟩ ≥ 0`，其中 v̂_P 是 M_P=𝔎(P,T)−μ̃K_c 的顶向量。

### 路线 1（★ 首选）：把定理 CE 在物理锚点上求值 + 把六常数区间化

**要证的**：(a) 在 LaH10/H₃S 等锚点的 (P,T,N_c,μ̃) 上算 μ̃_*^{CE} 并验证 μ̃ < μ̃_*^{CE}；(b) 给 (γ_P, c₁^P, ‖u_⊥^P‖, q₁^d, b^d, m^d) 六个量的**区间包络**；(c) 把 9 点采样 inf 升为区间包络；(d) N→∞ 尾。

**难度诚实估计**：
- (a) **低**——脚本已在（`p4d_coulomb_extremal_threshold.py`），是一次求值 + 一张表；同时把 G1–G4 的门禁记录补上。**这一步应当立刻做，它决定后面还值不值得做。**
- (b) **中高，但瓶颈已定位且与本会话别的线共享**：`P4D_coulomb_uniqueness.md` (H1) 的 2026-09-15 测量订正逐字说——**γ 不是瓶颈**（Na=560 可清过，是 Na³ 算力问题）；**真瓶颈是 c₁**（弹性 −1.47…−1.58，需要 ψ₁ 的**逐分量**上界在 n<N95 处从 ~1.9× 收到 ~1.03×）。这正是 `p4-concentration-bound` 与本会话 `c1sq-bound` / `gamma-c1sq-tighten` 在做的事。**不是新工作，是把已有的 c₁ 工作接过来。**
- (c)(d) **中**，机械但费算力。
- **推论 I.1（analytic）已白送了谱隙 ≥ γ(1−κ) 这一环**。

**产物形态**：条件定理「μ̃ < μ̃_*^{CE}(P,T,N_c) ⟹ Tc(P) ≤ Tc^E」+ 物理锚点全覆盖表。**这是唯一一条已经有完整证明骨架、只差常数的路线。**

### 路线 2：把 §4.4 的表在物理 N_c 上重算，判定失效窗是真是假

**要证的**：无（这是测量，不是证明）。用 `u_c[n]=u_n·𝟙_{n<N_c}`、N_c=⌊r·ϖ_rms⌋（r∈{3,10}）、多个 N 做收敛检查，重跑 H_μ''(x) 表；并补做 §4.5 说的**近简并 2-原子跨窗检验**。

**难度**：**很低**（改一行 + 重跑）。**价值很高**：它决定 `paper_tc_insensitivity_core_statement` 的 Honesty boundary 应该怎么重写，也决定路线 3 值不值得开。
**注意方向规则**：这是在找一个**上界/不等式是否被违反**；若出现 H_μ''>0，那只说明「凹性这条充分条件断了」，**不能**据以宣称极值性失败（要宣称失败必须构造出真的 Q(P)>Q(E) 的 P）。

### 路线 3：绕开凹性——直接证 ⟨v̂_P, 𝒪[d] v̂_P⟩ ≥ 0 的**无阈值**版本

**要证的**：利用引理 1(ii) 的**精确**结构 v̂_P=(A_P−λ)^{-1}u_c（不是扰动近似），把 𝒪[d] 在这个具体预解式向量上的二次型直接定号。可用的已有零件：
