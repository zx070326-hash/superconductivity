## 1. 问题的精确陈述

### 1.1 对象

μ̃ := μ\*(ω_c)/λ，u_n=(2n+1)^{−1/2}，(u_c)_n = 𝟙_{n<N_c}·u_n，N_c=⌊ω_c/2πT⌋，

  𝒪[f]_{nm} = u_n u_m [ f(|n−m|)(1−δ_{nm}) + f(n+m+1) ] − δ_{nm}·2u_n²·Σ_{k=1}^{n} f(k)，
  ℌ(ϖ) = 𝒪[k ↦ ϖ²/(k²+ϖ²)]，　**M(P) = 𝒪[F_P] − 2μ̃ u_c u_cᵀ**，　Tc 边界：λ·λ₁(M)=1。

**(⟸) 已在仓库，是 `analytic`，不是我的**：`mustar_extremality_recheck_2026-09-16.md` §6 的 **(CVX)**——

### 2.6 领头阶判据 λ < 2μ\*_rms 的独立重推（`analytic`）

设 Tc = C ω̄ exp(−1/(λ−μ\*(ω̄)))，μ\*(ω̄)=μ/(1+μL)，L=ln(ω_c/ω̄)。
dμ\*/dL = −μ²/(1+μL)² = −μ\*²，dL/d ln ω̄ = −1 ⟹ **dμ\*/d ln ω̄ = +μ\*²**。
又 d(−1/(λ−μ\*))/dμ\* = −1/(λ−μ\*)²，故

  **d ln Tc / d ln ω̄ = 1 − μ\*²/(λ−μ\*)²。**

软化（d ln ω̄ < 0）抬高 Tc ⟺ 该导数为负 ⟺ μ\* > λ−μ\* ⟺ **λ < 2μ\*(ω̄)**。∎
与 `mustar_extremality_failure_map` §4 的领头阶判据**逐字一致**（我从零推，未看它的推导）。
**⚠ 我第一次推时把 d(−1/(λ−μ\*))/dμ\* 的符号搞反、得到「软化永远降 Tc」的相反结论**；

Cauchy 交错免费给 λ₁(A) ≥ λ₁(A−tB) ≥ λ₂(A)（唯一无条件结论）；
Aronszajn–Krein / 久期方程（Golub 1973, SIAM Rev. 15, 318）`x(t) ∝ (A−λ(t))⁻¹u` **是正性丢失的机制**；
eventual-positivity 文献（Noutsos LAA 412 (2006) 132；Tsatsomeros；Daners–Glück）刻画「哪些矩阵最终正」，**不给扰动阈值**；

**⟹ §2.5 的结论在这里得到外部印证：不要去找「正性能撑到多大排斥」的定理，它不存在；
