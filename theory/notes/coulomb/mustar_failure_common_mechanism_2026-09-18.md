## 1. 统一坐标：秩一久期恒等式（`analytic`）

记 A := 𝒪[F]（μ\*=0 的算子），谱 μ₁ > μ₂ ≥ ⋯，本征向量 ψ_j；u_c := P_{N_c}u；
c_j := ⟨ψ_j, u_c⟩；M := A − 2μ̃ u_c u_cᵀ；h := λ₁(M)；**亏损** d := μ₁ − h；
g_j := μ₁ − μ_j（故 g₂ = μ₁−μ₂ 是 μ\*=0 的谱隙）。

久期方程（把 Mv = hv 与 u_c 配对）：

    2μ̃ Σ_j c_j²/(μ_j − h) = 1 .

把 j=1 项分出来，记 **S := Σ_{j≥2} c_j²/(g_j − d) > 0**、**θ := 2μ̃S**，得

> **(U1)**　**d = 2μ̃ c₁² / (1 + θ)** 　　（`analytic`）

并且 v ∝ (A−h)^{-1}u_c = (c₁/d)ψ₁ − Σ_{j≥2} c_jψ_j/(g_j−d)，故与 ψ₁ 的倾角 Θ 满足

> **(U2)**　**tan Θ = (d/c₁)·√S₂**，　S₂ := Σ_{j≥2} c_j²/(g_j−d)² 　（`analytic`）

**(U1)(U2) 的数值确认**（`_unified.py` Gate 1，125 点 ϖ×μ̃×N_c）：
最劣相对误差 **3.24e-12**（U1）、**4.11e-11**（U2）。

**读法**：μ\*>0 的全部一次效应只经**三个**标量进场——
**重叠 c₁²**（「沿顶模式的分量」）、**混合 θ**（「被次模式回推的程度」）、

    eta := d/g₂ ∈ (0,1)      （亏损吃掉 μ\*=0 谱隙的比例；h−μ₂ = g₂(1−eta)）

## 2. 五处失效各自的精确判据

### 2.1 失效 (1)：跨窗双根

物理路径 N_c(T) = ⌊rϖ⌋（r := ω_c/ω_E），T↓ ⟹ ϖ↑。窗内 λ₁ 连续上升，

> **精确判据**：双根 ⟺ 某窗界处 **J < 0** 且 1/λ 落在 (λ₁⁺, λ₁⁻) 内。

**X = J 的符号；Y = 0。** 且（§3 命题 P2）有**解析**的单边界

## 3. 共同祖先：v ∈ C，以及**同一个** Rayleigh 步（`analytic`）

μ\*=0 理论里，单调性与极值性都经**推论 A′**：
对 d ≥ 0（不必单调）与 v ∈ C := {v ≥ 0 且非增}，⟨v, 𝒪[d]v⟩ ≥ a_{L₀}²d(1) ≥ 0。

**三个命题共享一个证明模板，且库仑项在每一个里都精确抵消。**

> **命题 P1（窗内单调性）**（`analytic`）。N_c 固定，ϖ′ > ϖ，d := ⟦·⟧(ϖ′) − ⟦·⟧(ϖ) ≥ 0。
> 以 v_ϖ 为试探向量：
> λ₁(M(ϖ′)) ≥ ⟨v_ϖ, M(ϖ′)v_ϖ⟩ = λ₁(M(ϖ)) + ⟨v_ϖ, 𝒪[d]v_ϖ⟩。
> **v_ϖ ∈ C ⟹ λ₁ 严格递增。**

> **命题 P2（跨窗下跳）**（`analytic`）。u′ = u_c + δ，δ = e_{N_c}/√(2N_c+1)。
> 以 v′（N_c+1 的顶向量）为试探向量：
> λ₁(M(N_c)) ≥ ⟨v′, M(N_c)v′⟩ = λ₁(M(N_c+1)) + 2μ̃[(v′·u′)² − (v′·u_c)²]，即
> **J ≤ −2μ̃ (v′·δ)(2 v′·u_c + v′·δ)**。
> **v′ ∈ C ⟹ v′·δ ≥ 0 且 v′·u_c ≥ 0 ⟹ J ≤ 0（v′_{N_c}>0 时严格）。**
> 逆否：**上跳必须出锥**——出锥是上跳的**必要**条件。

> **命题 P3（Einstein 极值性，全 μ̃ ≥ 0）**（`analytic`）。同 T、同 N_c、⟨ω²⟩ 固定，
> d := F_E − F_P ≥ 0 逐点（x↦x/(k²+x) 凹 + Jensen）。以 v_P 为试探向量：
> λ₁(M_E) ≥ ⟨v_P, M_E v_P⟩ = λ₁(M_P) + ⟨v_P, 𝒪[d]v_P⟩。
> **v_P ∈ C ⟹ λ₁(M_P) ≤ λ₁(M_E)**，即极值性成立。
> **库仑项在两侧是同一个算子、逐项相消，μ̃ 不进证明。**

**⟹ μ\* 在极值性证明里打掉的东西，恰好只有一件：v_P 的锥归属。**
Lemma M 的其余成分（推论 B′ 半群保锥、Abel 分解、引理 A/B）只关乎 𝒪[d]，
**与秩一库仑项完全无关、一行不必重证**。（这比仓库现有的「窗内单调性 = 秩一预解式定理
+ 六个 float64 常数 + κ<1 前提」短得多，且是解析的；建议单独立项核验后并入。）

## 5. 物理含义

### 5.1 跨窗双根 = 硬截断赝物（判决：赝物，有定量阈值）

把指示函数换成**物理光滑**窗（库仑截断在频率宽度 Δ 上抹开）：

    w_n(β) = 1/(1+exp((n+½ − rϖ)/β))，　β = Δ/(2πT) = (Δ/ω_E)·ϖ（Matsubara 指标单位）

> Matsubara 间距的 1%。⟹ **Tc 的唯一性在物理上并未因 μ\*>0 而失去**；
> 失去的是「⌊·⌋ 模型」的唯一性。论文里「Tc 只能按 sup 定义」应保留为
> **模型陈述**，并加这一句定量的赝物判定。

**注意：这一条不能推广到失效 (2)。** 同样的光滑化对锥只给 ≤1 个数量级的改善、
且在 β ≳ 4 后反而变差（`_cone_beta.py`：ϖ=2、N_c=20 的 μ̃_cone 从 1.40e-3 升到
最好 1.59e-2@β=8，仍低于物理 μ̃）。**同一条边缘，两种敏感度差 10³ 倍**——
这本身就是「不存在共同控制量」的又一个证据。
