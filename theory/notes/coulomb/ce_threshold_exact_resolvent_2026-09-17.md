## 1. 定理 CE′（精确预解式形式）

沿用定理 CE 的记号（A_P、u_c、μ̃、d、𝔱^d、(μ_j, ψ_j)、c_j := ⟨u_c, ψ_j⟩）。设 c₁ ≠ 0
且存在 j ≥ 2 使 c_j ≠ 0。记 j\* := max{j ≥ 2 : c_j ≠ 0}，

    λ := (μ_{j*}, μ₁) 内 2μ̃ Σ_j c_j²/(μ_j − λ) = 1 的唯一根,
    tanΘ_P(μ̃) := (μ₁ − λ)·( Σ_{j≥2} c_j²/(λ − μ_j)² )^{1/2} / c₁.

**若 tanΘ_P(μ̃) < 𝔱^d，则 Q(P) ≤ Q(E)。**

*证明*。引理 1(i) 给出 λ 的存在唯一：φ(λ) := 2μ̃ Σ_j c_j²/(μ_j−λ) − 1 在 (μ_{j\*}, μ₁) 上
φ′ = 2μ̃ Σ c_j²/(μ_j−λ)² > 0 严格增，λ→μ₁⁻ 时 j=1 项 → +∞、λ→μ_{j\*}⁺ 时该项 → −∞，
故唯一根。**这一段只用 c₁ ≠ 0、c_{j\*} ≠ 0，不用 κ := 2μ̃c₁²/γ_P < 1**（κ<1 只是
引理 1(iii) 与引理 2 的前提，本路线两者都不用）。
引理 1(ii) 给 v̂_P = (A_P−λ)^{−1}u_c/‖·‖，在 {ψ_j} 下系数为 c_j/(μ_j−λ)，故
cos∠(v̂_P, ψ₁) 分量为 c₁/(μ₁−λ)，得上式 tanΘ_P **恒等式**（非不等式）。
代入引理 3（鲁棒化推论 A′）：tanΘ_P < 𝔱^d ⟹ ⟨v̂_P, 𝒪[d] v̂_P⟩ > 0；
再由定理 CE 步骤 1 的 Rayleigh 反向不等式得 Q(P) ≤ Q(E)。∎

**阈值良定**：tanΘ_P 在 μ̃ 上严格增（久期方程给 dλ/dμ̃ < 0；(μ₁−λ) 与 S₂(λ) 都随 λ 减而增），
故 μ̃_\*^{CE′} := tanΘ_P = 𝔱^d 的唯一交点。[analytic 论证 + numerical-evidence 复核：
14 行 × 400 个 μ̃ ∈ [1e-4,1]，tanΘ_P 与 λ 的单调性违反 = 0，最劣 dλ = −3.28e-7 < 0]

## 2. 为什么旧界松：三个可分离的损失

旧界 tanΘ ≤ 2μ̃c₁‖u_⊥‖/(γ_P − 2μ̃c₁²)。精确式与之相比，损失依次为：

1. **分母**：精确分母是 1 + 2μ̃S_⊥（S_⊥ := Σ_{j≥2}c_j²/(λ−μ_j)），旧界用 (γ_P−2μ̃c₁²)/(2μ̃c₁²) 的形式；
2. **分子**：精确是 c₁√S₂ 而非 c₁‖u_⊥‖——即用 ‖(λ−A_P)^{−1}u_⊥‖ 而非 ‖u_⊥‖/γ_P；
3. **λ 代入**：旧界把 λ 换成最劣端点。

中间产物（脚本中的 `tan_new2`）只做 1+2、把 3 留成一个显式位移
δ := 2μ̃c₁²/(1+2μ̃S_⊥⁰)、λ ≥ μ₁−δ、S₂(λ) ≤ Σc_j²/((μ₁−μ_j)−δ)²，
已经把 MgB₂ r=10 从 0.736 抬到 0.950（仍差 5%）；只有把 3 也做精确（解久期）才越线。
故**三处损失里第 3 处（λ 的代入）是主导**，这与「余量 1.002 的 H₃S r=10 旧界 tan=0.955
而精确 tan=0.440」一致（2.2 倍全在 λ）。

## 4. 核验（W1 纪律：订正本身独立复核）

1. **两套独立方案**：tanΘ_P 由久期根算一遍，再由 `eigh(M_P)` 的顶向量与 ψ₁ 的夹角算一遍
   （完全不同的代码路径）——14 行最劣相对差 **4.3e-13**。
2. **序关系**：tan_sec ≤ tan_new2 ≤ tan_old 在全部 14 行成立（两个中间界都是上界，
   精确值必须最小）。若哪一行倒序即说明某个"上界"不是上界——无倒序。
3. **κ<1 的解除做了直接检验**：在 μ̃ = 2·γ_P/(2c₁²)（即 κ = 2，远在旧前提之外）处，
   久期根与 λ₁(eigh M_P) 的绝对差 ≤ **2.6e-16**，tanΘ 相对差 ≤ 6.8e-15，14 行全过。
   ⟹ 引理 1(i)(ii) 确实不需要 κ<1，thr_CE′ 超出 γ_P/(2c₁²) 的那几行（LaH10 163 r=10、
   LaH10 214 r=10、LaH10 264 r=10、H₃S r=10、Nb r=10、MgB₂ r=10）是**有效**的。
   *附注*：即便不采信这一解除，14 行的**判决**也不受影响——所有锚点 μ̃ 本身都低于
   γ_P/(2c₁²)（最紧的 MgB₂ r=10：0.2097 < 0.2375），保守取 min(thr_CE′, γ_P/(2c₁²))
   仍给 MgB₂ r=10 余量 1.133，14/14 照样通过。
4. **c_j 非退化**（久期区间端点为真）：c₁ ∈ [0.906, 1.298]，|c₂| ∈ [7.8e-3, 1.45e-1]。
5. **N 收敛**：thr_CE′ 在 N = 400 / 800 / 1600 上五位不变（三个最紧锚点 × r ∈ {3,10}）。
