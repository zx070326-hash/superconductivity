## 1. 亏损恒等式：分子只剩方差

固定均值 x̄ 的集合上，δ_P := f_x̄ − F_P 对 P **仿射**，端点是两原子测度（Bauer）。
对 P = wδ_{x₁}+(1−w)δ_{x₂}，令 s=k²、V=w(1−w)(x₁−x₂)²、ỹ=wx₂+(1−w)x₁：

  δ(s) = x̄/(s+x̄) − w·x₁/(s+x₁) − (1−w)·x₂/(s+x₂) = s·[(s+ỹ)(s+x̄) − (s+x₁)(s+x₂)] / [(s+x₁)(s+x₂)(s+x̄)]

分子中 s² 抵消；s¹ 系数是 (x̄+ỹ)−(x₁+x₂) = 0；常数项是 x̄ỹ − x₁x₂ = V。故

  **δ(k) = V·k² / [(k²+x₁)(k²+x₂)(k²+x̄)]**   ……（DEF）

`probe_deficit_cone_identity.py` 第 (1) 部分：8 组随机两原子测度，最劣偏差 **2.2e-16**。

**推论（锥的显式刻画）**：𝒟_x̄ := {δ_P : mean P = x̄} = conv{ V·ψ_{x₁,x₂} }，
ψ_{x₁,x₂}(k) = k²/[(k²+x₁)(k²+x₂)(k²+x̄)]。
这**取代**了 `mustar_extremality_recheck` §5 留下的开放问题「物理 δ 张成的锥是什么」——
答案是一个显式二参数有理族，不是抽象的「Stieltjes 核的 Jensen 亏损」。
与一般 δ≥0 的关键差别：(DEF) 有 **k⁻⁴ 尾**且光滑；E4 的反例 δ_k 是**单通道尖峰**，不在锥内。

小展开极限 x₁,x₂→x̄ 给 ψ₀(k) = k²/(k²+x̄)³，即 −½∂²f/∂x²。

## 2. H″ 的两项分解：极值性项与能级排斥项

f 的两条恒等式（直接微分，`analytic`）：

  ∂f/∂x = f(1−f)/x，  ∂²f/∂x² = −2f²(1−f)/x² = −2k²/(k²+x)³

故 ψ₀ = f²(1−f)/x²（`probe_psi0_f2f3.py`：20 组，最劣相对偏差 **8.2e-16**）。
M(x) = 𝒪[f_x] − Cm，Cm 与 x 无关 ⇒ M′ = 𝒪[∂_x f] = (A−B)/x，M″ = −2𝒪[ψ₀]。
顶本征值的二阶微扰（无结构假设，对任意 μ\* 成立）：

  **H″(x) = ⟨v,M″v⟩ + R = −2Ψ + R**，  Ψ := ⟨v,𝒪[ψ₀]v⟩，
  **R := 2Σ_{j≠1}⟨w_j,M′v⟩²/(h−λ_j) ≥ 0**

- **Ψ ≥ 0 ⟺ Einstein 点是二阶极大**（极值性）
- **H″ ≤ 0 ⟺ R ≤ 2Ψ**（凹性，严格更强）

**归属订正**：Ψ **不是新的**。仓库 `P4_concavity_q_route.md` §1 已定义
g := ∂_x(f²) = 2xk²/(k²+x)³ 与 E := ⟨v,𝒪[g]v⟩，而 g = 2x·ψ₀ ⇒ **E = 2xΨ**；
其 §4 的 C := q′−E 即 **C = −xR**。我是重新推导出来的，应记在该文件名下。

## 3. 对仓库 C 闭式的订正：只在 μ*=0 成立

`P4_concavity_q_route.md` §4 写 C = −(2/x)Σ_{j>1}⟨v,Bw_j⟩²/(h−λ_j) ≤ 0（**自动**非正）。
该式用到 ⟨w_j,Av⟩ = h⟨w_j,v⟩ = 0，即**顶向量是 A 的本征向量**。
μ\*>0 时顶向量满足 Mv = hv、M = A − Cm，故 ⟨w_j,Av⟩ = ⟨w_j,Cm v⟩ ≠ 0，闭式失效，
且 C 不再自动非正（真实的 C = −xR 仍非正，但那要靠微扰论而非该闭式）。

我第一版 `probe_lemmaC_AB_mustar.py` 正是盲用了该闭式，得到「(A)(B) 全通过」的**假结论**。

**μ\*>0 时最大差 6500×**（x=0.01,μ̃=0.05：naive 5.30e-6 vs 真值 3.48e-2）。
