## 2. 定理 TA（两原子约化）—— `analytic`

### 2.1 陈述

> **定理 TA.** 固定 T>0、N_c ≥ 0、μ̃ ≥ 0 与 x̄ > 0。记 𝒫(x̄) := {P 概率测度 : ∫ϖ²dP = x̄}，
> 𝒫₂(x̄) := 𝒫(x̄) 中**至多两个原子**的元素。则
>
>   **sup_{P∈𝒫(x̄)} λ₁(M_P) = sup_{P∈𝒫₂(x̄)} λ₁(M_P)。**
>
> 同一结论对 μ̃=0 逐字成立，也对任何**与 P 无关**的自伴加性扰动逐字成立。

### 2.2 证明（三步，全初等）

**(i) λ₁ 是一族仿射泛函的 sup。** F_P(k) ≤ x̄/k² ∈ ℓ¹ ⟹ 𝒪[F_P] 是 Hilbert–Schmidt、M_P 有界自伴，
故 λ₁(M_P) = sup{⟨v,M_Pv⟩ : ‖v‖=1, v **有限支撑**}（有限支撑向量在单位球面稠密，二次型连续）。
对支撑在 [0,N) 的固定 v，由 𝒪 对核的逐元线性性有**结构系数**展开
  ⟨v,M_Pv⟩ = ∫ ψ_v(x) dP̃(x) − 2μ̃⟨v,u_c⟩²，　ψ_v(x) := Σ_{k=1}^{2N−1} c_k(v)·x/(k²+x)，
P̃ 是 P 在 ω ↦ x=(ω/2πT)² 下的推前。**ψ_v 在 [0,∞) 上连续有界**（|ψ_v| ≤ Σ|c_k| < ∞）。
（`c_k(v)` 的显式形式与直接二次型的对拍：**12/12 组，差 ≤1e-11 相对**，见脚本 `struct_coeffs`。）

**(ii) 单个仿射泛函的 sup = 凹包络值 = 两原子上的 sup。** 设 ψ 在 [0,∞) 上有界，
ψ̂(y) := sup{Σλᵢψ(xᵢ) : Σλᵢ=1, Σλᵢxᵢ=y}（凹化）。则 ψ̂ 凹、有限、≥ψ，故对任何均值 x̄ 的 P̃，
取 ψ̂ 在 x̄ 处的超梯度 s：∫ψ dP̃ ≤ ∫ψ̂ dP̃ ≤ ψ̂(x̄) + s(∫x dP̃ − x̄) = ψ̂(x̄)。
反向：ψ̂(x̄) 本身是**两点**组合的 sup——(x̄, Σλᵢψ(xᵢ)) 落在 ℝ² 中 {(xᵢ,ψ(xᵢ))} 的凸包内，
而一元函数的凸包在给定横坐标处由**上凸包的一条边**（即两个顶点）实现。故
  **sup{∫ψ dP̃ : ∫x dP̃ = x̄} = ψ̂(x̄) = sup{θψ(x₁)+(1−θ)ψ(x₂) : θx₁+(1−θ)x₂ = x̄}。**

**(iii) 换序。** sup_P sup_v = sup_v sup_P（恒等式），于是
  sup_{𝒫(x̄)}λ₁ = sup_v sup_{𝒫(x̄)}⟨v,M_·v⟩ = sup_v sup_{𝒫₂(x̄)}⟨v,M_·v⟩ = sup_{𝒫₂(x̄)}λ₁。∎

## 3. 定理 SC（强耦合端无条件闭合）—— `analytic`

### 3.1 陈述

> **定理 SC.** 固定 ω_c>0、μ\*≥0、λ>0 与 ⟨ω²⟩=ω_rms²，记 **r := ω_c/ω_rms**。
> 若**存在 ϖ♯ < 1/r 使 λ·h(ϖ♯) ≥ 1**（h(ϖ)=λ₁(ℌ(ϖ)) 是 μ\*=0 的 Einstein 函数），则
>
>   **T_c(λ,P;μ\*) ≤ T_c(λ,E;μ\*)　对一切 P∈𝒫（第二矩 = ω_rms²）与一切 μ\*≥0。**
>
> **显式充分条件：λ > 1 + r²。**

### 3.2 证明

记 T♯ := ω_c/2π。由 N_c(T)=⌊ω_c/2πT⌋，**T > T♯ ⟺ N_c(T)=0 ⟺ u_c = 0**，
此时对**任何** Q 有 M_Q(T) = 𝒪[F_{Q,T}]——库仑项整项消失，μ\* 完全不进场。

**(1) T_c(λ,E) > T♯。** 取 T := ω_rms/(2πϖ♯) > ω_rms/(2π/r) = ω_c/2π = T♯（因 ϖ♯ < 1/r）。
在该 T 处 N_c=0，故 λ₁(M_E(T)) = h(ϖ♯)，于是 λλ₁(M_E(T)) ≥ 1 ⟹ T 属于定义 T_c 的集合 ⟹ T_c(λ,E) ≥ T > T♯。
（**不需要 h 的连续性**——把假设写成「存在 ϖ♯ < 1/r」而不是「λh(1/r)>1」正是为了这个。）

**(2) 情形 T_c(λ,P) ≤ T♯**：由 (1) 直接得 T_c(λ,P) ≤ T♯ < T_c(λ,E)。∎

**(3) 情形 T_c(λ,P) > T♯**：由 sup 的定义，存在 T_j → T_c(λ,P) 且 T_j > T♯、λλ₁(M_P(T_j)) ≥ 1。

（**定理 2**，核级 Jensen + 引理 M，`analytic`）。于是 λλ₁(M_E(T_j)) ≥ 1 ⟹ T_j ≤ T_c(λ,E)，
取极限得 T_c(λ,P) ≤ T_c(λ,E)。∎

**显式条件**：ℌ(ϖ)_{00} = u_0²⟦0+0+1⟧ − ℓ(0) = ⟦1⟧(ϖ) = ϖ²/(1+ϖ²)（一行，`analytic`），

### 4.3 Abel 记账恒等式 (AB)：障碍塌成一个标量 —— `analytic`

设 a_L := (v_P)_{L−1} − (v_P)_L（Abel 系数，v_P = Σ_L a_L e_L，e_L=𝟙_{[0,L)}），
S⁻ := {L : a_L<0}，**ξ := Σ_{L∈S⁻}|a_L|e_L**，**w := v_P + ξ = Σ_{L∉S⁻}a_L e_L**。则
**w 与 ξ 都是 e_L 的非负组合 ⟹ 两者都在锥 C 内**，且

>   **(AB)　⟨v_P,𝒪[d]v_P⟩ = G₁₁ − 2G₁₂ + G₂₂，**
>   G₁₁ := ⟨w,𝒪[d]w⟩ ≥ 0、G₂₂ := ⟨ξ,𝒪[d]ξ⟩ ≥ 0（**推论 A′**）、G₁₂ := ⟨ξ,𝒪[d]w⟩ ≥ 0（**引理 A**：⟨e_L,𝒪[d]e_{L′}⟩ ≥ 0）。

三个符号事实全部是仓库已证的解析引理，`d ≥ 0` 是核级 Jensen。于是

>   **Rayleigh 步成立 ⟺ ϱ := 2G₁₂/(G₁₁+G₂₂) ≤ 1。**

**三个量对 d 都是一次齐次 ⟹ ϱ 对 d 的标度不变**（P → Einstein 时不退化），
这一点与定理 CE 的 𝔱^d 相同、而与「用 Λ‖ξ‖² 付代价」的朴素做法不同（后者对 d→0 必然失效）。

**(AB) 是锥判据的严格加强**：锥成立 ⟺ ξ=0 ⟺ G₁₂=G₂₂=0 ⟹ ϱ=0。
**一条被证伪的捷径**：用 AM–GM 把 (AB) 弱化成 `G₁₂² ≤ G₁₁G₂₂` **没有用**——
AM–GM 只在 G₁₁≈G₂₂ 时紧，而实测 G₂₂/G₁₁ ~ 1e-3…1e-2。
实例（ϖ=1, N_c=6, μ̃=0.05）：G₁₁=1.51e-1、G₁₂=1.05e-2、G₂₂=6.15e-4，
AM–GM 判**失效**（G₁₂²=1.11e-4 > G₁₁G₂₂=9.28e-5），而真值 ⟨v_P,𝒪[d]v_P⟩ = **+1.31e-1**，稳稳为正。

**ξ 的结构**（numerical-evidence，阈值 a_L < −1e-9·max|a|）：
- 温和形状 + 小 μ̃：S⁻ **恰好是单点 {N_c}**——独立复现 `mustar_failure_common_mechanism` §2.2 的 (C2)
  「锥破处恒在截断边缘 n=N_c−1」。实测 (ϖ,N_c,μ̃)=(1,6,0.01/0.05) 与 (2,10,0.01/0.05) 均 `#neg=1`、标签 `[N_c]`。
- 但**极端形状 + 物理 μ̃ 下 S⁻ 是一个宽块**（400–1500 个标签，从 L=1 起），
  且**不是浮点噪声**（用相对阈值筛过，被筛掉的噪声项对 ξ 的贡献 ≤7.9e-7）。
