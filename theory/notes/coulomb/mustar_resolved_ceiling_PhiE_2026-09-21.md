## 5. 两条天花板的关系（子任务：交叉点 / 预算对 min{} 算）

### 5.1 互不蕴含（级别：analytic）

设归一谱测度 `dP ∝ 2α²F(ω)/(λω)dω`，则 `ω̄₁ := ⟨ω⟩_P = 2A/λ`、`ω̄₂ := ⟨ω²⟩_P^{1/2}`。

* Leavens/Carbotte 界 `= c(μ*)·λω̄₁/2` — **一阶矩**（等价地零阶矩 A）。
* 本仓库界 `= C_∞√λ·ω̄₂·𝔣_E·Φ_E` — **二阶矩**。

我们的 Jensen 路线（核级凹性 `x↦x/(k²+x)`，`x=ϖ²` + 引理 M）在**固定 λ** 下只能给出
`Tc(P) ≤ Tc_E(λ, ω_rms)`，而该 Einstein 谱的面积 `A_E = λω_rms/2 ≥ A_P`
（Cauchy–Schwarz）⟹ 这条链条只能产出 `c(μ*)A_E`，**永远产不出 `c(μ*)A_P`**。
反向同理（面积界不含 λ 信息）。⟹ **两条界互不蕴含。**

### 5.2 精确比值恒等式 (★)（级别：analytic，给定两条界的定义）

定义 Einstein 谱的**面积效率** `c_μ(λ) := 2Tc_E(λ,μ*,r)/(λω_E)`，于是按定义 `c(μ*,r) = max_λ c_μ(λ)`。
我们的 μ\* 分辨界在 Einstein 谱上**取等**（它就是 `Tc_E`），因此对任意可容谱

```
(面积界)/(我们的 μ*分辨界) = [ c(μ*,r) / c_μ(λ) ] · ( ω̄₁ / ω̄₂ )        (★)
```

第一个因子 **≥1 恒成立**（`c` 是 `c_μ` 的极大值），第二个 **≤1 恒成立**（Cauchy–Schwarz）。
**数值验证：六条真实谱上 LHS=RHS，相对误差 ≤ 2.2e−16。**

### 5.3 ⟹ 「λ\* = (2C_∞/c)²」这个读法必须标级（一次**订正**，分两段写）

**(a) 旧陈述错在哪。** `λ* = (2C_∞/c(μ*))²`（μ\*=0 时 2.5057）是面积界对上
**(II) 一行界** `C_∞√(λ⟨ω²⟩)` 的交叉点。一行界是我们自己机器的 **λ→∞ 渐近**，
比 (III) 松了整整 `1/𝔣_E(λ)`（λ=1 时 1.594×，λ=5 时 1.075×）。
把它当「两个泛函的交叉」会同时犯两个错：

* 对 **(III) λ 分辨**版：交叉条件是 `c_0(λ) = c(μ*,r)`，而 `c_0(λ) := 2Tc_E(λ,0)/λ` 是**单峰**的
  （峰值 0.23087 在 λ=1.1425）⟹ 解集是一个**区间**，不是半直线。
  实测（r=10）：μ\*=0.10 ⟹ 面积界更紧的区间是 **λ∈[0.56, 3.46]**；μ\*=0.13 ⟹ **[0.53, 4.05]**；

* 对 **(IV) μ\* 分辨**版：由 (★)，在 Einstein 点（ω̄₁/ω̄₂=1）**根本不存在交叉**——
  面积界永不更紧，仅在 λ=λ_opt(μ\*) 处相等。

**(b) 新陈述凭什么对。** (★) 把判决塌成**一条不等式、两个可测比值**：

```
面积界更紧  ⟺  ω̄₁/ω̄₂  <  ρ_crit(λ,μ*,r) := c_μ(λ)/c(μ*,r)  ≤ 1
```

**与「闭式交叉判据 `λ* = 2.5057·(ω̄₂/ω̄₁)²`」的关系（独立复核，结论：对，但只在 level (II)）**：

* **常数随 μ\* 变**：μ\*>0 时 `2.5057` 必须换成 `(2C_∞/c(μ*,r))²` ＝ 4.3020(μ\*=0.10) / 4.8621(0.13) / 6.1818(0.20)。
  若面积侧用 `c(μ*)` 而矩侧仍用 `2.5057`，就是**混级**，会系统性地把材料判到面积侧。
