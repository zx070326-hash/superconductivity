## 1. 裸方程：Nambu 自能，一般 DOS N(ξ)

各向同性电声自能（Migdal 近似）：

```
Σ̂(iω_n) = -T Σ_m D(ω_n-ω_m) ∫dξ N(ξ) τ₃ Ĝ(iω_m,ξ) τ₃
```

D(ω_n-ω_m)=λ(n-m)（声子传播子，已含耦合常数归一化）。Nambu 格林函数（Δ→0 前，保留 φ_m=Z_mΔ_m）：

```
Ĝ(iω_m,ξ) = -[iω̃_m τ₀ + ξτ₃ + φ_m τ₁] / (ξ² + ω̃_m² + φ_m²),    ω̃_m := ω_m Z_m
```

用 τ₃τ₀τ₃=τ₀, τ₃τ₃τ₃=τ₃, τ₃τ₁τ₃=−τ₁：

```
τ₃ Ĝ τ₃ = -[iω̃_m τ₀ - ξτ₃ + φ_m τ₁] / (ξ²+Ẽ_m²),   Ẽ_m := √(ω̃_m²+φ_m²)
```

对 ξ 积分（近似 3：假设 N 偶对称）：奇函数 ξ/(ξ²+Ẽ_m²) 项积分为零。定义

```
χ(E) := ∫dξ N(ξ)/(ξ²+E²)      （一般 DOS 的壳积分，χ≥0 恒成立）
```

得到**两个通道共享同一个 χ(Ẽ_m)，但乘在不同的分子上**：

```
Σ̂(iω_n) = T Σ_m λ(n-m) χ(Ẽ_m) [iω̃_m τ₀ + φ_m τ₁]
```

匹配分量（Z 通道取 τ₀ 系数、Δ 通道取 τ₁ 系数）：

```
ω_n(Z_n-1) = T Σ_m λ(n-m) · ω̃_m·χ(Ẽ_m)          ...... (Z-eq)
φ_n        = T Σ_m [λ(n-m)-μ*_c] · φ_m·χ(Ẽ_m)   ...... (Δ-eq)
```

**这一步是全文的枢纽**：χ(Ẽ_m) 在两个方程里的确是**同一个函数、同一个宗量**——dos-escape"Z/Δ 共享同一 ξ 积分分母"的结构论证到这里为止是对的。但两个方程里 χ 乘的分子不同：Z 通道乘 ω̃_m，Δ 通道乘 φ_m。这个差异不是细节，是接下来一切的根源。

## 2. 线性化（Δ→0）：两个通道的"有效源权重"分道扬镳

Ẽ_m → |ω̃_m|。定义 flat 参考 χ_flat(E):=πN(0)/E，g(E):=χ(E)/χ_flat(E)（→1 当 flat）。**注意 g(0)=1 是一般性质**：当 E→0，χ(E) 与 χ_flat(E) 都由 N(0)/E 的同一个领头奇异性主导（只要 N(0)>0），两者比值趋于 1——这不是假设，是壳积分的渐近行为，对任何在 E_F 处连续正的 N(ξ) 成立。

**Z-eq 的源权重** G(ω̃_m):=ω̃_m·χ(|ω̃_m|) = g(ω̃_m)·[ω̃_m·χ_flat(|ω̃_m|)] = g(ω̃_m)·πN(0)sgn(ω_m)。

关键：ω̃_m·χ_flat(|ω̃_m|) = ω̃_m·πN(0)/|ω̃_m| = πN(0)·sgn(ω_m) 是**与 m 无关的常数**（对 flat DOS 而言）。所以 flat 极限下 Z-eq 根本不含任何 m 依赖的 DOS 形状因子——这正是教科书 Z 方程 Z_n-1=(πN(0)T/ω_n)Σλ(n-m)sgn(ω_m) 里为什么看不到任何 1/(2m+1) 型权重的原因：**它被 ω̃_m 和 χ 的 1/ω̃_m 精确抵消了**。一般 DOS 下这个抵消不完整，剩下的正是 g(ω̃_m)：

```
Z_n - 1 = (πN(0)T/ω_n) Σ_m λ(n-m)·sgn(ω_m)·g(ω̃_m)
```

**g 挂在源指标 m 上，乘的是 sgn(ω_m)（数量级 O(1)），不含任何额外 1/(2m+1) 因子。**

**Δ-eq 的源权重** H(ω̃_m):=χ(|ω̃_m|) = g(ω̃_m)·πN(0)/|ω̃_m|。这里没有 ω̃_m 去抵消 1/ω̃_m，所以 **flat 极限下 H_flat(ω̃_m)∝1/(2m+1) 本身就是非平凡的、源自 DOS 壳积分**：

```
φ_n = T Σ_m [λ(n-m)-μ*_c] · φ_m · g(ω̃_m)·πN(0)/|ω̃_m|
```

代入 |ω̃_m|=(2|m|+1)πT（领头阶 Z_m≈1，近似 6）：

```
Z_nΔ_n = N(0) Σ_m [λ(n-m)-μ*_c] · g(ω̃_m)·Δ_m/(2m+1)
```

**这与标准教科书线性化 Eliashberg 方程 Z_nΔ_n=πTΣ[λ-μ*]Δ_m/|ω_m| 的 flat 极限（g≡1）逐字吻合**（Carbotte RMP 1990 型方程），交叉核验了整条推导链没有系统性符号/归一化错误。

## 3. 对称化：只有 Δ 通道天然产生 (2n+1) 型自伴权重

Δ-eq 的核 K_{nm}=N(0)[λ(n-m)-μ*_c]·g(ω̃_m)/(2m+1) **只在 m 上不对称**（λ 本身对称，但乘的 g/(2m+1) 只挂在源指标）。标准相似变换 Δ_m=ψ_m/√(w_m)，w_m:=g(ω̃_m)/(2m+1)：

```
ψ_n/√(w_n) = Σ_m λ(n-m)√(w_m)ψ_m   ⟹   ψ_n = Σ_m [√(w_n)λ(n-m)√(w_m)] ψ_m
```

对称核 √(w_n)λ(n-m)√(w_m) 正是 P=L2+L3 的形式，**u_n²=w_n=g(ω̃_n)/(2n+1)**——这一步严格重现了 KAY 的 ξ_n=√(2n+1)θ_n 代换（flat 极限 g≡1 时精确还原）。**这部分与 Ansatz A 完全一致，Ansatz A 对 P 通道是对的。**

**Z-eq 没有类似的相似变换需求**——它的源权重 g(ω̃_m) 乘的是 sgn(ω_m)（不含 1/(2m+1)），而它自己是对角算子，本来就"自伴"，不需要任何对称化操作。它唯一的 (2n+1) 来自把 ω_n(Z_n-1) 除到 LHS 变成 Z_n-1 时除以 ω_n∝(2n+1) 这个**纯运动学**操作，与 g 完全无关：

```
L1[g,f]_n = (2/(2n+1)) · Σ_{k=1}^n g(ω̃_k)·f(k)
```

**判决**：L1 里的 1/(2n+1) 是"除以 ω_n"这个外部操作的产物，作用在**外部（场点）指标 n**上；L1 求和内部的 g(ω̃_k) 是 DOS 权重，作用在**源指标 k** 上。这两者是完全独立的两个对象，不应该、也推不出合并成一个整体作用在 n 上的 g(ω̃_n)/(2n+1)。dos-escape 的 Ansatz A 把这两个来源不同的东西捏在一起（"处处统一替换"），这一步没有推导支持——本文认为这正是它论证里唯一的漏洞，源头在于把"Z、Δ 共享同一个 χ 函数"（§1，这个是对的）误推成"Z、Δ 的最终权重函数形式相同"（这一步不成立，因为 χ 在两个方程里乘的分子不同：ω̃_m vs φ_m，导致源权重一个是 g（无 1/(2m+1)），一个是 g/(2m+1)）。

## 5. 引理 4 在 Ansatz C 下：条件成立，条件是 g 单调性

重做 §引理 4 的代数。ρ(f)=f(0)-f̂(π) 不变（Δ 通道正定性论证 §引理 1-2 全程不含 u_n，对任意正权重成立，见 `dos_escape_channel_2026-09-16.md` Step 2 对 Ansatz A 引理 2 的论证——这部分与 g 挂法无关，照搬）。推论 2.1 给 P[g,f] ⪰ -ρ(f)·D_u²，D_u²=diag(g(ω̃_n)/(2n+1))。故

```
a_n = L1[g,f]_n - ρ(f)·g(ω̃_n)/(2n+1) = (1/(2n+1))·[ 2Σ_{k=1}^n g(ω̃_k)f(k) - g(ω̃_n)ρ(f) ]
```

**与 Ansatz A 的关键区别**：括号内不再有 w_n 作为公共正因子提出——g(ω̃_k)（k≤n，求和内部）与 g(ω̃_n)（外部，n 本身）**是不同的值**，除非 g 是常数。

**充分条件（analytic）**：若 g 关于 n **单调不增**（即 ω̃ 越大、χ/χ_flat 越小——DOS 权重集中在费米面附近，van Hove 型增强），则对 k=1..n 有 g(ω̃_k) ≥ g(ω̃_n)（k≤n ⟹ ω̃_k≤ω̃_n），于是

```
2Σ_{k=1}^n g(ω̃_k)f(k) ≥ g(ω̃_n)·2Σ_{k=1}^n f(k) ≥ g(ω̃_n)·2f(1) ≥ g(ω̃_n)·[2f(1)+f̂(π)-f(0)] = g(ω̃_n)·ψ-型量 ≥ 0
```

（最后一步用引理 3 的 ψ(ω)≥0，与原证明逐字相同）。**⟹ a_n≥0 对 n≥1 恒成立，漏网仍是秩一（n=0 那格，a₀=-g(ω̃_0)ρ(f)=-ρ(f)，因为 g(0)=1）**。也就是说：**只要 DOS 是费米面增强型（g 不增）——van Hove 奇点、窄峰、任意集中在 E_F 附近的结构——定理 I′ 逐字成立，与 Ansatz A 的判决一致。**
