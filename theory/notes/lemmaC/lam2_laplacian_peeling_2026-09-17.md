## 1. 背景：为什么攻 λ₂

12 格 Davis–Kahan 判据

    ratio = x²·E_hi²/(g_an·F_lo),   s := res/g_an,
    E_hi = e_ψ + s(|q_ψ| + n_ψ),    F_lo = (1−s²)F_t − 2s·e_φ − s²n_φ

里 **`g_an` 出现三次**（自己一次，再经 `s` 喂进 E_hi 与 F_lo），是整个构造中杠杆最大的量。
`g_an = h − (λ₂ 的解析上界)`。仓库现行取

    gap_an(ϖ,h) = 0.4·h   (ϖ ≤ 2)          [即 λ₂ ≤ 0.6h]
                = h − Θ*  (ϖ > 2),  Θ* = 0.6349287917881079

而 **真值 λ₂/h ≈ 4.3e-4 … 7.5e-4**——解析界松约 1000 倍。敏感度探针
（`_chk_lam2_sensitivity.py`）给出：若能证到 λ₂ ≤ 0.4h，12 格最劣从 0.5751 掉到 0.2951；
再往下迅速饱和。**目标因此是 ε = 0.4，不必追更小。**

## 2. 引理 Λ [analytic]

记 `A = B − Δ`，`B = Bᵀ` **逐元 ≥ 0**，`Δ` 对角（不需要 Δ ≥ 0）。

**(i) 加权拉普拉斯非负。** 对任意正权 `p`，令
`L_p := diag( Σ_{m≠n} B_{nm} p_m/p_n ) − B_off`（`B_off` = B 去掉对角）。则 `L_p ⪰ 0`：

    ⟨y, L_p y⟩ = Σ_{n<m} B_{nm} [ y_n²·p_m/p_n + y_m²·p_n/p_m − 2 y_n y_m ]
               ≥ Σ_{n<m} B_{nm} [ 2|y_n y_m| − 2 y_n y_m ]  ≥ 0,

中间一步是 AM–GM（`a·t + b/t ≥ 2√(ab)`，取 `t = p_m/p_n`）。注意 `L_p` 虽含非对称权，
但**是对称矩阵**（非对角元为 `−B_{nm}`，权只进对角）。

**(ii) 分解 + Weyl。** `A = −L_p + diag(δ_p)`，`δ_{p,n} := Σ_m B_{nm} p_m/p_n − Δ_nn`
（m=n 项权为 1，即 `B_nn`）。Weyl 不等式 `λ_{i+j−1}(X+Y) ≤ λ_i(X) + λ_j(Y)` 取 `i=1, j=k+1`，
配 `λ₁(−L_p) = 0`：

    λ_{k+1}(A)  ≤  δ_p 的第 (k+1) 大分量.                                    (*)

**(iii) 剥指标。** 对有限集 `S`（`|S| = k`）令 `p_m = ε`（`m ∈ S`）。则对**每个** `ε > 0`，

    λ_{k+1}(A) ≤ sup_{n∉S} δ_{p,n} ≤ ε·sup_{n∉S}( Σ_{m∈S} B_{nm}/p_n ) + P_S(p),
    P_S(p) := sup_{n∉S} [ Σ_{m∉S} B_{nm} p_m/p_n − Δ_nn ].

右端对 ε 是线性的，令 ε ↓ 0 得

    λ_{k+1}(A)  ≤  P_S(p)   （对任意 |S| = k 与任意正权 p）.                  (**)

**没有极限交换问题**：不等式对每个 ε 单独成立，只需右端在 ε→0 有极限。∎

`k = 0, p ≡ 1` 就是经典行和（Gershgorin 型）界。我们要的是 `k = 1, S = {0}`。

**(iv) 这条路线的理论极限 [analytic]。** 由 Collatz–Wielandt（`A` 在 `S` 补上的限制是
Metzler 矩阵，非对角元 ≥ 0），

    min_{p>0} P_S(p) = λ₁( A^{(S)} ),   A^{(S)} := A 删去 S 中的行列,

而 Cauchy 交错直接给 `λ_{k+1}(A) ≤ λ₁(A^{(S)})`。**所以 (**) 的加权版本在最优权处正好
是 Cauchy 交错，不多不少**；权 `p` 的作用是给出 `λ₁(A^{(S)})` 的可解析计算的上估。

## 3. 应用到 `A = O[f_ϖ]` [numerical-evidence]

`O[φ]_{nm} = u_n u_m[φ(|n−m|)1_{n≠m} + φ(n+m+1)] − δ_{nm}(2/(2n+1))Σ_{k=1}^n φ(k)`，
`u_n = (2n+1)^{−1/2}`，`f_ϖ(k) = ϖ²/(k²+ϖ²) > 0`。于是

    B_{nm} = u_n u_m [ f(|n−m|)1_{n≠m} + f(n+m+1) ] ≥ 0 ,
    Δ_nn   = 2 u_n² Σ_{k=1}^n f(k) ≥ 0 ,

引理 Λ 的前提全部满足。取 `S = {0}`，`p_n = (2n+1)^{−β/2}`：

    λ₂(A) ≤ P_β(ϖ) := sup_{n≥1} [ Σ_{m≥1} B_{nm} p_m/p_n − Δ_nn ] .

**为什么剥掉 n=0 就够**：`δ_{p,n}`（未剥时）的实测廓线在 `n=0` 处有唯一尖峰
（ϖ=1：1.2142, 0.3780, 0.1789, 0.1028, …，单调下降），而 `B_{n0}` 恰好把 `n≥1` 各行的
盈余吃掉——ϖ=0.3, n=1 处 `δ_1 = 0.04425`，`B_{10} = 0.06038`，剥后变成 **负数**。

## 4. 已做的自检

1. **引理 Λ 的对抗性随机检验**（`_chk_peel_lemma_stress.py`）：40000 次，随机 `N∈[2,8]`、
   `k∈[0,3]`、四种 `B` 稀疏/尺度模式、`Δ` 有时取负、`p` 取 `10^{N(0,1.2)}`。
   最劣余量 `bound − λ_{k+1} = −1.33e-15`（等号命中，非违反）；`B = J`、`k=0` 时
   取到**精确等号**（N=3,5,8 均给 λ₁ = bound = N）。**界是紧的，不是空泛的。**
2. **单边方向审计**：`P_β` 是 λ₂ 的**上界** ⟹ `g_an` 的**下界** ⟹ DK 比值只会比真值**更差**。
   全部截断按此方向处理：
   - m-求和尾部 **向上加 pad**（`u_n·2x/(√(2MT+1)(MT−n−1))`；β ≥ 0 时 `p_m/p_n ≤ 1`，
     `u_m ≤ (2MT+1)^{−1/2}`，`f(m−n)+f(m+n+1) ≤ 2x/(m−n)²`，`Σ_{m≥MT}(m−n)^{−2} ≤ (MT−n−1)^{−1}`），
     **不丢弃**；
   - `sup over n` 截断在 `NROW = 150`，实测 argmax ∈ {1,2,3}，**非绑定**（已打印）。
3. **有限截断的相容性**：证书用的是 `N×N` 截断 `A_N`。`Δ` 是对角、其定义
   （`2u_n²Σ_{k=1}^n f(k)`）**与 N 无关**；`B_N` 的行和比无穷行和**小**，故
   `δ^{(N)}_n ≤ δ^{(∞)}_n`，**用无穷 m-求和算出的 `P_β` 对一切 N 都是合法上界**。

在 ϖ=0.30 处 α 从 1.40 提到 2.10 可把比值降到 0.271，但那会牺牲 ϖ=20 端。

> ⚠ **这不是 CERT-B 格数的结论。** 上表数的是"逐点判据需要几格"，
> 而真正的证书格数由**区间算术的包裹宽度**决定（格越宽，区间外扩越厉害）。
> 正确的读法是：**判据本身已在全域处处有富余，证书格数从此由区间宽度单独决定，
> 不再被判据的紧绷程度绑住**。具体 CERT-B 成本必须在区间链上重测。
> 另：加密脚本的局部细化跑到了 ϖ=0.264（0.8257），**那已在定义域 [0.30,20] 之外**，
> 不构成违例。

## 5. 升格到 certificate 还欠什么（诚实清单）

- **(a) m-求和尾部的闭式上界**。现在是数值 pad。`Σ_{m≥M} (2m+1)^{−(1+β)/2}[f(m−n)+f(m+n+1)]`
  是有理函数的和，闭式/积分比较应当可做，但**未做**。
- **(b) `sup over n` 的有限化**。需要证 `δ_{p,n}` 在 `n ≥ n₀` 单调下降（实测 `n ≥ 3` 单调），
  从而 sup 只须检查有限多个 `n`。**未证**——这是最可能纸笔可证的一条，已派给 `lam2bound`。
- **(c) `ϖ` 在格内变动时 `P_β(ϖ)` 的区间包裹**。现在是 11 点扫描（`numerical-evidence`），
  区间算术版本未写。
- **(d)** 上面 12 格表里 `E_hi/F_lo/res` 等量仍是 float64；真正的 CERT-B 要走
  `lemmaC_cert_size.py` 那条区间链。本篇只回答"λ₂ 界值不值得换"，**不是证书**。
