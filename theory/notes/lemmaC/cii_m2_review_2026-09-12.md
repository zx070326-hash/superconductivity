## 2. ε1 的推导缺口 · DOWNGRADE（结论仍真，ϖ_A′ 最多上移到 8.52）
`rev7_eps1.log`、`rev7_dump.log`、`rev7_eps_rig.log`。M2 声称 ε1_f := q(ln(1+ϖ∫\|f″\|) + ∫\|f″\|/(∫\|f″\|+D))「由 (L3)+(L4)」界住 Σ_n w_nG(s_n)²\|ℓ_f(n)−Λ_f(s_n)/s_n\|。按所写引理能推出的是 Σ_n w_n ε_f(s_n) = T₁+T₂+T₃（丢 G²≤1）：

- T₁ = Λ_f(D/2)·Σ_n w_n/s_n = Λ_f(D/2)·π²/(4D) → q·π²/12（用 Λ_f(D/2) ≤ (D/2)³/3）；
- T₂ = q·Σ_{n≤n₁} n/(n+½)² = q[ψ(n₁+3/2)−ψ(3/2) − ½(ζ(2,3/2)−ζ(2,n₁+3/2))]，n₁=⌊V/(2D)⌋；
- T₃ = q(V/2D)·ζ(2,n₁+3/2) ≤ q·(1+O(D))。

**ε1 的括号里没有 T₁ 的 π²/12 = 0.822**。ε1 数值上仍是上界，只因 T₂ 比 ln(1+ϖV) 小一个常数（Σ_{n≤n₁}1/(n+½) ≈ ln n₁ + 0.037，而 ln(1+ϖV) ≈ ln n₁ + ln 2；再加 −½Σ(n+½)^{−2} 的 −0.467）。精确闭式（mpmath）给 (T₁+T₂+T₃)/ε1 = 0.914(ϖ=6) / 0.913(8.48) / 0.926(45) / 0.953(1000) / 0.987(1e12)，渐近 → (ln ϖV + 0.625)/(ln ϖV + 1) < 1，**故 ε1 ≥ Σ_n w_n ε_f(s_n) 对一切 ϖ 为真、可证，但证明须写出上面三项与 ψ/ζ 的常数比较，docstring 与 §1.G.1 都没有**；Stage 4 的检查只验证 ε1 ≥ Σ 真误差（比 0.30），不验证 ε1 ≥ Σ 逐 n 界（比 0.60–0.84）。若把 ε1 换成从所写引理直接可得的 q[π²/12 + ln(1+ϖV) + V/(V−D)]，ϖ_A′ = 8.5185；ε2 同样处理（q²[4ln(1+ϖV) + 2V²/(V−D)²]）再加 0.003，共 **8.5219**；比值@45 只动 4e-5。ε2 本身：逐 n 界平方和（不带 G²）/ε2 = 0.27–0.45，其推导（Λ_f(D/2)² 项给 7ζ(3)D⁴/576、min² 项给 ≈q²(4 ln n₁+2)）闭合，无缺口。

**建议**：在 (L3)+(L4) 后补一行：Σ_n w_n ε_f(s_n) ≤ q[π²/12 + (ψ(n₁+3/2)−ψ(3/2)) − ½(ζ(2,3/2)−ζ(2,n₁+3/2)) + (V/2D)ζ(2,n₁+3/2)] ≤ ε1_f，后一不等式用 ψ(n₁+3/2)−ψ(3/2) ≤ ln(n₁+1)−ψ(3/2) ≤ ln(1+ϖV) − ln 2 − ψ(3/2) 与 ½Σ_{n≥1}(n+½)^{−2} = π²/4−2 即得（渐近常数余量 0.375·q，ϖ ≥ 6 全程 ≥ 0.23·q）。或直接改用 8.52 版本。
