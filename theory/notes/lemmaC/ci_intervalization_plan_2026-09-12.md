## 1. 段 C-I 的数值断言清单

段 C-I 的**唯一结论**是：对每个细胞 [a,b]，`hpp_ub = -2 F_lo + 2 pos < 0`，因而 sup_{x∈[a²,b²]} H″(x) < 0。所有其他数值量都是为这一个不等式服务的中间界。把它们按「在区间算术下需要什么」分类：

| 类 | 断言 | 实例数（EXT→45） | 载体 |
|---|---|---|---|
| **(A) 标量不等式** | `hpp_ub < 0`；`ratio ≤ TARGET`（只是细化判据，不承重）；`γ>0`、`g_lo>0`、`s<1` 三个守卫；`k1,k2,k3 ≥ 0`（μ₂ 单调性）；Stage S 的 4 条 | 347 细胞 × 1 + 3 守卫；92 粗细胞 × 3；Stage S 4 | `cell_L` / `cell_S` 末尾 |
| **(B) 矩阵正定性** | `alpha_certificate_H` 的 Cholesky(cI − PAP)，Na∈{70,140,280}；Stage S 的 `alpha_G2`(Na=200) | 93 粗节点 + 若干 band-boundary 重认证 + 1 | **这是残余假设点名的那一条** |
| **(C) 级数/积分上界** | `S1_of`（Σ_{k≥1}env，部分和 + 积分尾）、`tail_int`（4 个闭式）、`tail_sum`、`tail_sq`（matvec 行尾）、`rsum`（Schur 行和 ⟹ ‖O[f]‖）、`row_env`/`col_env`/`schur_tailblock`/`schur_coupling`/`coupling_restricted`、`schur_full_seg_w0`（L1=sup‖ℌ′‖） | 每细胞约 8 个实例 ⟹ ≈2800 | 全部是「有限和 + 单调积分尾」，机械 |
| **(D) 段一致 sup 估计** | `spec_seg(a,b,j)`（sup_{w∈[a,b]}\|∂^j⟦k⟧\| 的混合端点写法）；`qform_lo/hi` 的 c_k 符号分裂包夹；Lipschitz 余量 hw·6b·R3 与 hw·4b·R3；`alpha_cell` 的 max(c_A,c_B)+L1·hw | 每细胞 6 个 ⟹ ≈2100 | 闭式 + 单调性，机械 |
| **(E) 本征值隔离** | θ ≤ λ₁（Rayleigh）；α ≥ λ₂（= (B)+(C)）；μ₂ ≤ λ₁（2×2 闭式）；g_lo ≤ gap；Davis–Kahan 角 s ≥ sin∠(v̂,v)；‖v′‖ 自洽迭代 (V1)–(V3) | 每细胞 5 ⟹ ≈1750 | 依赖 (A)(B)(C)(D)，本身只是组合 |

合计：**347 个承重标量结论**，由约 **7000 个初等界断言** 与 **94 个矩阵正定性证书** 支撑。加上 Stage A/B/E 的 ~230 条自检/证据（float64 对拍、有限差分、恒等式逐元核）——**这些不承重**，(I1)(I2)(I) 有代数证明，Stage A 的 float64 对拍只是防打字错。

**关键观察（决定可行性）**：整条链的**结构余量是 25%**（接受判据 `pos/F_lo ≤ 0.75`，实测最紧细胞 0.75@ϖ=64、0.52@ϖ=44）。区间化引入的额外宽度是相对 ~1e-20（见 §3），比 25% 小 19 个数量级。**因此不需要加密格、不需要提高 dps。** 这是本次任务与 M4 的根本差别：M4 要把 1e-5 量级的常数做到 1% 精度，这里只要把 0.75 做到 0.7500000001。

推论（区间版预算，(0,45]）：

* `cell_L`：主体是 `matvec`（O(Nr·Nv)=4Ns² 项 fdot）与 `_ehat`（2 个 matvec）⟹ **×8**。347 细胞 × 平均 1 s × 8 ≈ **2800 s 单核**。
* `alpha` Cholesky：自写 iv Cholesky（O(Na³/6)），比 `mp.cholesky` 慢约 3–4× ⟹ Na=280 约 **12–15 s/节点**；93 节点 ≈ **1100 s 单核**。
* `schur_full_seg_w0`：numpy → iv 是 ×500 的悬崖（Mrows=200 × Mcols=8000 = 1.6e6 项 ⟹ 3.8 s/次）。**缓解**：把 Mcols 降到 1200（尾部用同一个闭式积分补，界只变松 ~1.5e-3，而 L1≈3.5 且只经 θ−L1·hw 进入 ⟹ 影响 5e-4，无关紧要），再按粗细胞缓存 ⟹ 0.6 s × 93 ≈ **56 s**。
* `S1_of`/`rsum`：`rsum` 线性于包络常数 C ⟹ `rsum((C,A,p)) = C·rsum((1,A,p))`，且对 a 单调 ⟹ **每粗细胞只算一次**（用粗细胞左端点 A，对其内所有细胞都是合法的更大界）⟹ 186 次 × 0.13 s ≈ **24 s**。
* Stage S：`alpha_G2`(Na=200) iv Cholesky ≈ 4 s；G(2) 残差 M_RES=2400 × Nv=200 ≈ 1e6 项 ⟹ 2.4 s。

**(0,45] 总计 ≈ 4000 s 单核；按粗细胞并行 22 进程 ⟹ 3–5 min 墙钟。**

**(45,120]**：原单核 52141 s，其中 Stage L 51567 s，绝大部分是 Na 按 `ceil(14w/20)*20`（上限 1000）增长的 Cholesky（Na=1000 时 `mp.cholesky` ≈ 174 s/节点 × ~200 节点 ≈ 35000 s）。区间版 ×4 ⟹ ≈ 2e5 s 单核 ⟹ 22 核 **3–5 h 墙钟**。可行，但要后台跑，且是第二优先。

## 3. 相消分析：哪些地方直接区间化会爆？（M4 的 s→0 条件数 8e18 在这里的对应物）

逐一测量了每个减法的相消深度（相消深度 = log10(最大项 / 结果)）：

| 位置 | 表达式 | 相消深度 | 判决 |
|---|---|---|---|
| 结构系数 | `c_k = T_k + U_k − P_k`，T,U,P = O(1) 而 c_k 最小 1.8e-6 | **≤ 6 位** | 安全（dps=30 留 24 位） |
| 残差 | `r = ℌ(p)v̂ − θv̂`，‖ℌv̂‖≈θ≈4.3 而 ‖r‖=s_p·γ≈0.012 | ≤ 2.5 位 | 安全 |
| Rayleigh | `θ = Σ c_k f_H(k)`，项 ~O(1)，和 ~4.3 | 0 位 | 安全 |
| (C**) 装配 | `−2F_lo + 2pos`，pos/F_lo ≤ 0.75 | 0.6 位 | 安全（**这就是 §1.3 无相消写法的全部意义**） |
| Stage S | `θ̃ = λ̂ − b²q̂κ`，b≤0.3 | 0 位 | 安全 |
| μ₂ | `√(tr²−4det)`，tr²=0.44 而 −4det=+6.66（同号相加） | 0 位 | 安全 |
| **α 的 Cholesky** | `cI − PAP`，c≈1e-7、λ_max(PAP)≈0、λ_max(cI−PAP)≈1.3 ⟹ cond ≈ **1.3e7** | 7 位 | 安全但**是唯一需要盯的地方**；区间 Cholesky 的宽度增长 ~n·cond·eps = 280×1.3e7×8e-31 ≈ 3e-21 ≪ 1e-7 |

**结论：段 C-I 里没有 M4 式的相消灾难。** 原因是 §1.3 已经先做过一次代数重写：把 (C\*) 的 `⟨v,ℌ″v⟩ − ⟨v,ℌ′v⟩/ϖ`（两项都 →2𝔤(2)，差是 O(ϖ²)）用恒等式 (I1) 换成了**单个正核** −2𝒪[φ_x]。M4 需要的「先代数重写再区间化」这一步，段 C-I 的作者在 2026-09-11 就已经做完了。这是本任务比 M4 容易得多的根本原因。

唯一的真实风险是 **α 的 Cholesky 在 c≈1e-7 处几乎奇异**。缓解：把 c 的锚点从 `λ_max^{f64}(PAP)+1e-7` 改成**升级循环**（1e-9 → ×10 → 1e-4），因为 α = c + ‖B‖ + ‖D‖ 而 ‖B‖+‖D‖ 在 ϖ≥10 时是 0.83–1.72（对抗核报告 §3 的实测），**c 完全不承重**：把 c 放大到 1e-3 对 α 的影响是 0.06%，对 g_lo（≈2.5）的影响是 2.5e-5。

## 4. 正定性怎么给区间证书：四条路的取舍

需要的是 α ≥ sup_{w∈[A,B]} λ₂(ℌ(w))，机器是
  λ₂(ℌ) ≤ max(λ₂(A_head), λ₁(D)) + ‖B‖ ≤ c + ‖D‖ + ‖B‖，其中 c ≥ λ_max(PAP)（P 是头块顶向量的紧缩）。
所以要证的是 **cI − PAP ≻ 0**（Na×Na，Na ≤ 280）。

**(i) 区间 Cholesky —— 选它。** 代价 O(Na³/6) iv 运算；Na=280 ⟹ 12–15 s。所需定理是标准的，而且可以三行自洽证明（写进新模块 docstring，不外借）：

> **定理（区间 Cholesky ⟹ 一致正定；Alefeld 1980 / Rump, BIT 46 (2006) 433–452 §2）.** 设 [S] 是对称区间矩阵，对其运行区间 Cholesky（每步向外舍入），若算法跑完且每个对角枢轴区间满足 inf[L_ii] > 0，则**每个**对称 S ∈ [S] 正定。
> *证.* 固定对称 S ∈ [S]，对 S 跑精确 Cholesky。按 k 归纳：若前 k 步的精确量 L^S_ij ∈ [L_ij]（区间运算的包含性），则第 k+1 步要开根的量 S_kk − Σ_{j<k}(L^S_kj)² 被 [L_kk]² 包含，其下界 = (inf[L_kk])² > 0，故该量 > 0，第 k+1 步有定义且枢轴为正。归纳完成 ⟹ S = LLᵀ 且 L 可逆 ⟹ S ≻ 0。∎

这一条**同时**关掉残余假设里的「Cholesky 成功当作正定证书」：原版只对 float64 头块的 mpf 拷贝做 Cholesky，得到的是「那个 float64 矩阵正定」；区间版对**精确头块的区间包围**做，得到的是「精确算子的头块满足 λ₂ ≤ c」。（原版头块 `A_np = H_mat(Na,w)` 是 float64，然后 `mp.mpf(float(...))`——这是一个独立于 Cholesky 的漏洞，区间版一并修：头块直接在 iv 里从核表精确构造，O(Na²) ≈ 1 s。）

**(ii) Gershgorin / 对角占优** —— 弃。cI − PAP 完全不对角占优（PAP 的非对角元与对角同量级），Gershgorin 给出的下界是负的，永远不可能过。

**(iii) 区间 Rayleigh + Kato–Temple** —— 弃。Kato–Temple 给的是**单个**本征值的双边界，需要先知道相邻本征值的隔离；这里要的是「λ_max(PAP) ≤ c」即**整个谱的上界**，Rayleigh 只能给下界。要用 K–T 就得先隔离 PAP 的全部谱，反而更贵。

**(iv) 位移浮点 Cholesky + Higham 后向误差定理** —— 留作 ϖ>45 的加速备选，不作主路。做法：对 S − δI 跑 mpf Cholesky（可用 `mp.fdot` 快路），若跑通则 S − δI + Δ = L̃L̃ᵀ ⪰ 0 且 ‖Δ‖ ≤ γ_n‖S−δI‖（γ_n = n·eps/(1−n·eps)，Higham *ANLA* Thm 10.3–10.5，对任何「每次运算正确舍入」的算术成立，mpmath mpf 满足），故 δ > γ_n‖S‖ ⟹ S ≻ 0。严格、且比区间 Cholesky 快 3–4×。**不作主路的理由**：它是先验误差界而非区间运算，审查时容易被归到「mpf + 垫」那一类；只在 Na≥560 的 120 延伸里作为交叉校验/降级方案，并显式标注。

## 5. 单边界记账纪律（避免「宽度在中间量上爆了却被 max 吃掉」）

所有初等运算在 `iv` 里做，但**每个具名认证量立即塌缩成单侧端点**（`LB(x)=x.a` 或 `UB(x)=x.b`，都是精确的 mpf 端点），并在代码里逐条注明单调性理由：

```
E_hi = ê_ψ,hi + s·(N + |q̂_ψ|)          ↑ 于 ê, s, N, |q̂|      ⟹ 全用 UB
F_lo = q̂_φ,lo − s²(a_φ + N) − 2s·ê_φ,hi ↓ 于 s, a_φ, N, ê_φ；↑ 于 q̂_φ,lo ⟹ q̂ 用 LB，其余 UB
g_lo = max(θ_lo − L1_hi·hw, μ₂_lo) − α_hi                      ⟹ 如标注
pos  = b⁴·E_hi²/g_lo                    ↑ 于 E_hi，↓ 于 g_lo    ⟹ E_hi 用 UB、g_lo 用 LB
hpp_ub = −2·F_lo + 2·pos                                        ⟹ 判 hpp_ub < 0
```

这样做的三个好处：(1) 不会出现区间比较的歧义（`s_new >= s` 这类）；(2) 不会有「宽度被 max 吃掉」——每个量只有一个端点在流动；(3) 与 §4 的 `s` 自洽迭代兼容（(V1)–(V3) 是「合法上界 ↦ 合法上界」的仿射增映射，每个迭代值独立合法，对抗核报告靶 3b 已确认）。

另外三条纪律，直接对应 reviewer 预期的洞：

* **「某处仍然用了 mpf 再包成 iv」**：核表（`tab_H/phi/psi/kappa/gamma`）全部在 iv 里从**整数** k 与**精确二进制** w 构造；`envelope` 的 S1 不再用 numpy float64 求和。唯一允许的 float64 入口是**试探向量**与**格的选取**（见下），两者都不是界。
* **「格的端点用浮点算」**：粗格改成**确定性规则 + 步长向下取整到 2^-10 的整数倍**，故所有端点都是精确二进制小数、跨机器逐位可复现；细格用 `np.linspace(A,B,k+1)`（float64 精确二进制，相邻细胞共享同一个 bit-for-bit 端点）。新增显式**铺砌检查**：`a_0 == 0`、`b_j == a_{j+1}`（精确相等）、`b_last ≥ WMAX`。
* **「试探向量来自 float64 eigh」**：合法——任何固定向量都给合法界（Rayleigh 下界 + Davis–Kahan）。区间版把 float64 分量当作**精确二进制有理数**（它就是），只在 `u_n = v_n/√(2n+1)` 的开方处引入 ~1e-30 相对宽度。归一化亦在 iv 内完成。
