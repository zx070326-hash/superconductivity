## 1. R1 · ϖ̄ 网格 → 紧区间

### 1.1 加密网格实测（`e1_finegrid.py`，121 点：每相邻节点间 20 等分，384 s）

对每个 ϖ̄ 重跑证书的 `rayleigh_mu`、`alpha_certificate_H`、N∈[2,400] 全部 gap_N、N₀、g_*、以及 `cert_opnorm_inf(ϖ̄,1)`（‖H′‖ 认证值，记 L）：

- **δ(ϖ̄)=μ−α 在 [0.3,5] 上严格单调递增，无任何下陷**：0.1008(0.3) → 0.2489(0.5) → 0.6573(1) → 1.1962(2) → 1.4941(3) → 1.8038(5)。121 点 Cholesky 全 SPD。
- gap₄₀₀(ϖ̄) ≥ δ(ϖ̄) 处处成立；argmin_N gap_N = 400 处处成立（gap_N 随 N 单调递减，N 小于 N₀ 的直查从不决定 g_*，见 §2）。
- L=‖H′‖ 认证值 ∈ [0.31, 0.97]，峰值 0.968 在 ϖ̄≈0.66。

结论：**不存在节点没抓到的下陷**。R1 不是概念问题。

### 1.2 但「7 节点 + Lipschitz 可信」定量不成立（`e8_lipclose.py`）

真谱隙 gap(ϖ̄)=λ₁−λ₂ 满足 |gap(w)−gap(w′)| ≤ 2L|w−w′|，L=sup‖H′‖。对每个节点 cell [w_i,w_j] 取闭合下界 min_w max(δ_i−2L(w−w_i), δ_j−2L(w_j−w))。两种 L：
- L_grid：cell 内加密网格上 `cert_opnorm_inf(·,1)` 的 max（**非严格 sup**，对 7 节点情形已是最乐观）；
- L_seg：**严格** sup_{w∈[a,b]}‖H′(w)‖，用分段包络 |∂_w⟦k⟧| ≤ 2w/(k²+w²) ≤ 2b/(k²+a²) 代入全矩阵 Schur 行和界（对称包络矩阵 E ≥ |H′| 逐元 ⟹ ‖H′‖ ≤ max 行和），**无回归**。

## 3. α-证书 Weyl 分块链 · CONFIRMED

H=[[A,B],[Bᵀ,D]]，X=diag(A,D)，Y=[[0,B],[Bᵀ,0]]，‖Y‖=‖B‖（Y 的奇异值即 B 的奇异值各取两次）。λ_k 一律取 min-max 意义（紧算子：第 k 个正本征值，不足则为 0）。

- **(a) λ₂(X) ≤ max(λ₂(A), λ₁(D))**：设 X 谱降序第二个为 s₂。若 s₂ > λ₁(D)，则 s₁ ≥ s₂ 都不属 D，故 s₂=λ₂(A)；否则 s₂ ≤ λ₁(D)。恒成立（作为 = 不恒成立——λ₁(D)>λ₁(A) 时 λ₂(X)=max(λ₁(A),λ₂(D))——但只需 ≤，脚本注释写的是 ≤，无误）。
- **(b) max(λ₂(A), λ₁(D)) ≤ c + ‖D‖**：需 c ≥ 0。成立，因 PAP=(I−uuᵀ)A(I−uuᵀ) 恒有 PAP·u=0（‖u‖=1 时精确，float64 下 ~1e-16），故 λ_top(PAP_f) ≥ −1e-16，c=λ_top+1e-7 > 0（表中 ϖ̄=2,3,5 处 c=1.000e-7 正是 λ₂(A)<0 时 c 落到 pad 上的情形，逻辑仍对）。‖D‖ ≥ 0 平凡。
- **(c) λ₂(H) ≤ λ₂(X) + ‖Y‖**：min-max Weyl λ_k(X+Y) ≤ λ_k(X)+λ₁(Y) 对任意 k、有界自伴成立；不需要 k=1。
- **λ₂(A) ≤ λ₁(PAP)**：PAP=QAQ，Q=I−uuᵀ 对称；对 x⊥u，Qx=x，故 PAP 在 u^⊥ 上的二次型 = A 的，交错给 λ₁(PAP|_{u^⊥}) ≥ λ₂(A)。**‖u‖ 是否精确为 1 不影响**（Q 在 u 方向的本征值 1−‖u‖² 只改变 u 方向的值）。
- Cholesky：mpmath dps=30 浮点 Cholesky 成功 ⟹ M+ΔM SPD，‖ΔM‖ ≲ n·10⁻³⁰‖M‖ ~ 1e-27 ≪ 1e-7 pad。严格。

## 4. Schur 包络 · CONFIRMED（含 Stage 1b 未测的导数阶）

逐条核对 `row_env` 注释：
- ψ(t)=c_j(w)/(t²+w²)^{p_j}，对一切 w>0、一切阶在 [0,∞) 上单调递减——**ϖ̄=5 无例外**（分母单调，分子不含 t）。
- H2 m<h：n−h+1 > n/2 对 n 奇偶都成立；Σ_{m<h}(2m+1)^{−1/2} ≤ √(2h−1)：归纳 √(2h−1)+(2h+1)^{−1/2} ≤ √(2h+1) ⟺ 4h²−1 ≤ 4h² ✓；2h−1 ≤ n ✓；√n/√(2n+1) ≤ 1/√2 ✓。
- H2 m≥h：2h+1 ≥ n+1 ✓；Σ_{m≠n}ψ(|n−m|) ≤ 2S1 ✓。H3 两半 ✓。五项各自随 n 递减 ✓。
- 导数包络：|k²−3w²| ≤ 3D、5w⁴+10k²w²+k⁴ ≤ 10D²、3w⁴+10k²w²+3k⁴ ≤ 10D² 逐一成立。IntTail 三个闭式核对无误。
- `col_env`、`schur_coupling`、`schur_tailblock` 的行/列和归属（利用 H 对称）✓。
- **补测（`e4_env.py`）**：Stage 1b 只对 order=0 做 soundness；但 orders 1–5 进入 `cert_opnorm_inf` → B₂^∞/B₄^∞。我对 ϖ̄∈{0.3,1,5}×order 1–5×N∈{2,10,40,120,200}，N_big=1500，测 true/env：row ≤0.78、col ≤0.92、schur_offhead ≤0.55，全部 <1。

**HS 路线（`hs_offhead`）小瑕疵**：U(n) 的 m≥h 项写成 Z2/(2(2n+1))，注释「same split as row_env」只能推出 Z2/(2(n+1))（1/(2m+1) ≤ 1/(n+1)）。数值上 LHS/RHS ≤ 0.34（ϖ̄=5, n=2；`e3_hs.py`），成立但未推导。**不 load-bearing**：`rho_bound=min(schur,hs)` 中 HS 只在 N ≤ 22（ϖ̄=5）/ N ≤ 3（ϖ̄=0.3）胜出，而 N₀ ≥ 28，N₀ 与全部 Weyl 断言均由 Schur 支决定。若采纳 §2.2 交错路线，ρ_N 的 HS 支彻底退出。

## 5. B₂^∞/B₄^∞ 的 sup over J · DOWNGRADE（形式）

`cert_sup_on_J`：sup_J ≤ 网格 max + L·h/2，L = 网格 max of ‖H^{(j+1)}‖ 认证值。**L 自身不是 J 上的 sup**，严格应为 L ≤ L_grid + (h/2)·sup‖H^{(j+2)}‖ → 回归。实测（`e6_supJ.py`，ngrid=201）：
- order 2 漏项 ≤ 1.0e-4（ϖ̄=1），相对 B₂ ≤ 2.4e-4；order 4 需 6 阶导，`_brk_der` 无 6 阶，**现有代码闭不了**。
- 两阶的 argmax 都落在 J 左端点 a（在网格上），slack 只为排除内点尖峰。
- ngrid=201 足够（slack/B ≤ 0.5%）。

修法（与 §1.3 同一招）：L 改用分段包络 sup_{w∈[a,b]} ψ_{j+1}(k;w) ≤ c_{j+1}(b)/(k²+a²)^p 的 Schur 界——**5 阶包络已有，不需要 6 阶**，一步闭合。代价：L 放大 2–7 倍（Schur vs eigvalsh），slack 仍 ≤ ~4% of B。

## 7. 其余攻击点（守住了）

- **反循环**：与主会话结论一致，不复述。
- **式(4) 的 padded 符号**：λ₂(padded)=max(λ₂(mat),0) ≥ λ₂(mat)，gap_mat ≥ gap_padded，安全。（交错路线下此步不再需要。）
- **压缩单调 ‖H^{(N)(j)}‖ ≤ ‖H^{(j)}‖**：压缩不增范数，平凡；Stage 4 数值单调 ✓。

## 8. 总评

**这个证书是否把 T5 的「数值证据」升级成了「计算机辅助证书」？** 是——**在 7 个 ϖ̄ 节点上**。三支柱的每一步（Schur 尾率、Rayleigh 下界、Cholesky-deflation 上界、Weyl 分块链）我逐条推了一遍，没有一步不严格；数值 soundness 我又在 Stage 1b 未覆盖的导数阶上补测通过。

**R1/R2 是「工程缺口」还是藏着概念问题？**
- **R1 藏着一个措辞/论证问题，不是概念问题**：§3 定理写「ϖ̄∈[a,b]」，§2.4 用连续性+紧性取 inf，但连续性推不出节点之间为正——这是循环。定量上，7 节点靠 Lipschitz 闭合在 ϖ̄≈0.36 就失败（最乐观 L 也为负），所以「Lipschitz 可信」这句话本身是错的。好消息是 121 点加密网格证明 δ(ϖ̄) 单调无下陷，且无回归的分段 Schur Lipschitz 常数在 121 点上闭合全区间，inf gap(∞,·) ≥ 0.092。**修法明确、6 分钟算力，但必须做，定理才配叫区间定理。**
- **R2 不是缺口，是冗余**：g_* 从未由 float64 支决定；而且交错不等式 λ₂(A_N) ≤ λ₂(A) ≤ α 直接给出比现 g_* 大 1.3–1.9× 的全严格下界，N₀、ρ_N、float64 直查、padded 符号讨论全部可从支柱三删去。建议改写支柱三为一行：inf_{N≥2} gap_N ≥ μ₂(ϖ̄) − α(ϖ̄)。

**建议对外措辞**：当前 =「在物理 ϖ̄ 节点 {0.3,…,5} 上的计算机辅助证书」；补 §1.3 的 121 点 + 分段 Schur 闭合后 = 「在 [0.3,5] 上的计算机辅助证书，inf gap ≥ 0.092、g_** ≥ 0.046（Weyl 路线）」。Stage 5 一律称「有限-N 一致性检验」。
