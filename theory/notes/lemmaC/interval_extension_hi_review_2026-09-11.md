## 1. 逐 cell 链与大 Na 包络 · CONFIRMED

### 1.1 逻辑链（逐行核 `cell_job` / `alpha_cell_ub_Na`）
`cell_job((a,b,kna))`：Na=head_size(b)；cA、cB 各自在**该 Na** 上 Cholesky；`alpha_cell_ub_Na(a,b,cA,cB,Lw,Na)` 用**同一 Na** 算 `schur_coupling(Na,b)`/`schur_tailblock(Na,b)`（spec_seg(a,b,0)）；L=`schur_full_seg_w0(a,b,1)` 与 Na 无关（它界的是全算子 ‖H′‖，压缩 A′=P_Na H′ P_Na 只减不增）。cell 之间无共享量（每个 cell 一个独立进程，返回 dict）。与 X1 的 `alpha_side` 相比少了「跨带重认证」分支——这里两端点本来就都按 b 的 Na 认证，没有跨带 cell 的概念。**每个 cell 的四个量都在同一 Na 上**。

## 4. X5 节点 · CONFIRMED

- **尺寸修正的推理**：Rayleigh 试探向量 v 支撑 Nv ⟹ ⟨v,Hv⟩/‖v‖² ≤ λ₁(H_N) 对**任意 N ≥ Nv** 成立（v 落在 N 维子空间内），且 ≤ λ₁(H) 恒成立；N<Nv 时无序关系。N=max(2000,2Nv) 是充分条件。数值（`rev3_interlace.py`，自写 H）：ϖ̄=60 处 λ₁(960)=4.628642988 < λ₁(1500) < μ=λ₁(1920)−1e-12=4.628648253 < λ₁(3000)=4.628648544——首跑在 60 误报正是 N=1500<Nv=1920，在 30/40 不报是 1500≥Nv；诊断与修法都对。
- **服务器原样重算**（`rev3_srv_node.py`）：节点 30：μ=3.9464752952、α=0.4246470264、μ₂=1.6624286882、B₂=0.0487828814、B₄=0.0099242577；节点 60：μ=4.6286482534、α=0.4595579724、μ₂=1.6656031892、B₂=0.0236986925、B₄=0.0012654905。5 位舍入后与日志行逐位同。
- **K_*/s_max 重推**（`rev3_arith.py`/`rev3_kna14.py`）：K=ϖ̄⁴B₄η²/24 + ½ϖ̄⁴B₂²/g，s_max=min(0.25, 0.95√(g/(2ϖ̄²B₂)))。用日志 4 位数：2.1157e3/3.1454e3/5.8259e3（相对差 1.3e-3/3.0e-3/1.3e-2，60 处 B₄=0.0013 只有 2 位有效数字所致）；用全精度服务器值：**2.1184e3 / 5.7510e3、s_max 0.1128 / 0.0799**，与日志逐位同。一致性条件 ϖ̄²B₂s² < g/2 三点成立（0.559<0.619、0.553<0.613、0.544<0.603）。
- **float64 不进界**：μ 是 mpmath 精确二次型；α 是 mpmath Cholesky；进界的只有试探向量与 float64 元素。舍入（`rev3_round.py`，3300 个采样元素与 mpmath 精确值对比）：Nv=1920、ϖ̄=60 时 max 相对误差 3.0e-15、‖A_f−A‖_F ≤ 3.6e-14；Na=960 时 1.6e-14——均 ≪ ROUND_PAD=1e-12。继承备注不变：`cert_sup_on_J` 头块 opnorm 是 float64 eigvalsh 无 pad（基线原样）。
