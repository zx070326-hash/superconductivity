## 2. 推导（解析部分）

### 2.1 命题 1：D5 与 (C\*\*) 是同一个分解　[analytic]

Feynman–Hellmann 与 Kato 二阶公式（λ₁ 单重孤立、A(x) 范数解析）：

  H″ = ⟨v,A_xx v⟩ + 2⟨A_x v,(H−A)⁺A_x v⟩。

A_x = 𝒪[∂_x f_x] = 𝒪[k²/(k²+x)²]，而 k²/(k²+x)² = 1/(k²+x) − x/(k²+x)² = f_x/x − xψ_x，故 A_x = A/x − x𝒪[ψ_x]，(I−P)A_x v = −x·r（因 (I−P)Av = 0）。A_xx = 𝒪[∂²_x f_x] = −2𝒪[φ_x]。于是

  **H″ = −2F + 2x²⟨r,(H−A)⁺r⟩ ≤ −2F + 2x²E²/g**　（(C\*\*) 复现）。

另一边，q-路线：H″ = −q′/x = −(E_q + C)/x。E_q = ⟨v,𝒪[∂_x(f²)]v⟩ 而 ∂_x(f²) = 2xk²/(k²+x)³ = 2xφ_x，故 **E_q = 2xF**。又 C = q′ − E_q = 2⟨(I−P)Bv,(H−A)⁺(I−P)A_x v⟩；B = 𝒪[f²] = x²𝒪[ψ_x] 给 (I−P)Bv = x²r，(I−P)A_xv = −xr，故 **C = −2x³⟨r,(H−A)⁺r⟩**。两式合并即 −(E_q+C)/x = −2F + 2x²⟨r,(H−A)⁺r⟩，与 Kato 式逐字相同。∎

推论：|C| < E_q ⟺ 2x²⟨r,(H−A)⁺r⟩ < 2F；`P4_gap_via_variance.md` 的 bound1 = (2/x)Var_v(B)/γ = 2x³E²/γ 恰是 (C\*\*) 的 DK 替换项乘 x。**所以「D5 缺一个廓线上界」与「C-I 靠 DK」是对同一个量 E² = Var_v(𝒪[ψ_x]) 的两种界法，不是两条路线。** 数值上（§4.1 表）pos_exact/(2F) 与 |C|/E_q 两列在 4 位上逐点相同。

### 2.2 命题 2：无本征向量的 Rayleigh 下界　[analytic]

**重排恒等式**（重推）。f ≥ 0、Σf < ∞，v ∈ ℓ²，p_n := u_n v_n。L1 项 = −Σ_n 2p_n²Σ_{k≤n}f(k)；L2 项按 2p_np_m = p_n²+p_m²−(p_n−p_m)² 极化，Σ_{n≠m}f(|n−m|)p_np_m = Σ_n p_n²[Σ_{k≥1}f(k) + Σ_{k≤n}f(k)] − ½D_f[p]，D_f[p] := Σ_{n≠m}f(|n−m|)(p_n−p_m)² ≥ 0；L3 项 = ⟨p,Hank_f p⟩，(Hank_f)_{nm} = f(n+m+1)。对角合并：Σ_{k≥1}f + Σ_{k≤n}f − 2Σ_{k≤n}f = T_f(n) := Σ_{k>n}f(k)。故

  ⟨v,𝒪[f]v⟩ = Σ_n p_n² T_f(n) + ⟨p,Hank_f p⟩ − ½D_f[p]。　　(R)

（无穷维合法性：Σp_n² ≤ ‖v‖² = 1，各和被 ‖f‖₁Σp² 绝对控制。）

**命题 2**。设 φ, f ≥ 0，Σf, Σφ < ∞，φ ≤ c·f 逐点（c > 0），v 为 𝒪[f] 的顶单位本征向量、h = ⟨v,𝒪[f]v⟩。则

  ⟨v,𝒪[φ]v⟩ ≥ c·h − m₁ − ‖Hank_{cf−φ}‖_F，　m₁ := Σ_{k≥1}(cf − φ)(k)，　‖Hank_{cf−φ}‖_F² = Σ_{k≥1} k·(cf−φ)(k)²。

*证*。D_φ ≤ c·D_f（逐项）。对 f 用 (R)：½D_f[p] = Σp²T_f + ⟨p,Hank_f p⟩ − h。对 φ 用 (R) 并代入：

  ⟨v,𝒪[φ]v⟩ ≥ Σp²T_φ + ⟨p,Hank_φ p⟩ − c[Σp²T_f + ⟨p,Hank_f p⟩ − h] = c·h − Σ_n p_n²(cT_f − T_φ)(n) − ⟨p,Hank_{cf−φ}p⟩。

(cT_f − T_φ)(n) = Σ_{k>n}(cf−φ)(k) ≥ 0 且随 n 递减，故 ≤ 其 n=0 值 m₁；Σp_n² ≤ 1；⟨p,Hank p⟩ ≤ ‖Hank‖₂‖p‖² ≤ ‖Hank‖_F；Hankel 中 n+m+1 = k 的格点恰 k 个。∎

**用途**：这是本文找到的唯一一个**不需要 v 的任何信息**却能给出 ⟨v,𝒪[φ]v⟩ 正下界的工具（它用掉的是 ⟨v,𝒪[f]v⟩ = h 这条信息）。对 φ = φ_x、f = f_x，c = max_k φ_x/f_x = 1/(x(1+x)²)（x<1 时最大值在 k=1），数值捕获率 F_lo/F ≈ 0.40–0.51 于 ϖ ∈ (0, 2]（Hankel 项用真 λ_max 时；用 Frobenius 时 x→0 处 0.32），见 §4.3。**与 `deep-lemmaC-analytic` 的 κ_{L3} 捕获（0.58–0.68）同量级但机制不同**：κ_{L3} 丢 L1+L2 项、需要廓线；命题 2 不丢任何项、不需要廓线，代价是要一个 φ/f 的逐点比 c。

### 2.3 定理 S：x ∈ (0, 0.03] 上的纸笔证明　[analytic]

**定理 S**。对 0 < x ≤ x₀ := 0.03（ϖ ≤ 0.1732），H″(x) ≤ −0.15 < 0。

*证*。用重标度算子 𝔄(x) := A(x)/x = 𝔊(2) − xK(x)，K(x) := 𝒪[1/(k²(k²+x))]（结构恒等式 (S2)）。

(i) **两个 Schur 常数**。𝒪⁺ 记逐元取绝对值。u-加权 Schur 检验：‖𝒪[φ]‖ ≤ max_n{Σ_{m≠n}u_m²φ(|n−m|) + Σ_m u_m²φ(n+m+1) + (2/(2n+1))Σ_{k≤n}φ(k)}。对 φ = 1/k⁴：n=0 行 = Σ_{m≥1}1/(m⁴(2m+1)) + Σ_{m≥0}1/((m+1)⁴(2m+1)) ≤ 1.3725；n=1 行 = 1 + Σ_{j≥1}1/((2j+3)j⁴) + Σ_{m≥0}1/((2m+1)(m+2)⁴) + 2/3 ≤ 1 + 0.2111 + 0.0678 + 0.6667 = 1.9454；n ≥ 2：Toeplitz 部分 ≤ 1/n⁴ + (1/3)·2ζ(4) ≤ 0.784，Hankel ≤ 1/81 + (1/3)(ζ(4)−1−1/16−1/81) ≤ 0.015，L1 ≤ (2/5)ζ(4) ≤ 0.433，合 ≤ 1.232。故 **κ₄ := 1.95 ≥ ‖𝒪⁺[1/k⁴]‖**。因 1/(k²(k²+x)) ≤ 1/k⁴、ψ_x ≤ 1/k⁴ 逐点且 Schur 界对 |矩阵元| 单调：‖K(x)‖ ≤ κ₄，‖𝒪[ψ_x]‖ ≤ κ₄。（数值核对：2×10⁵ 项行和最大值 1.94535 于 n=1。）

(ii) **隙**。λ₁(𝔄) ≥ ⟨t,𝔄t⟩ ≥ 1.3081 − κ₄x（CERT-A 向量 t，⟨t,𝔊(2)t⟩ = 110484293/84456000）；λ₂(𝔄) ≤ λ₂(𝔊(2)) + x‖K‖ ≤ 13/25 + κ₄x（Weyl）。故 g = x·g̃，**g̃ ≥ 0.7881 − 2κ₄x = 0.7881 − 3.9x > 0**，λ₁ 单重孤立，(C\*\*) 可用；又 h ≥ h_lo := x(1.3081 − κ₄x)。

(iii) **F 的下界**（命题 2，φ = φ_x、f = f_x、c = 1/(x(1+x)²)）：F ≥ c·h_lo − m₁(x) − hF(x)，其中 c·h_lo = (1.3081 − 1.95x)/(1+x)²（x 递减）；(cf−φ)(k) 在 k=1 恒为 0，k ≥ 2 时 = 1/((1+x)²(k²+x)) − k²/(k²+x)³ 对 x 递减（充分条件 3k²(1+x)³ ≤ 2k⁶，k ≥ 2、x ≤ 0.03 成立），故 **m₁(x) ≤ m₁(0) = ζ(2) − ζ(4) = 0.56261**，**hF(x) ≤ hF(0) = √(ζ(3) − 2ζ(5) + ζ(7)) = 0.36953**。

(iv) **装配**（各项在 (0,x₀] 上的单调方向已标）：

  H″ ≤ −2F + 2xE²/g̃ ≤ −2F_lo(x₀)·[1 − x₀κ₄²/(g̃_lo(x₀)F_lo(x₀))]，
  F_lo(x₀) = (1.3081−0.0585)/1.0609 − 0.56261 − 0.36953 = 1.17787 − 0.93214 = **0.24573**，
  g̃_lo(x₀) = 0.7881 − 0.117 = **0.6711**，
  比值 = 0.03 × 3.8025/(0.6711 × 0.24573) = 0.11408/0.16491 = **0.6917**，
  ⟹ H″(x) ≤ −2 × 0.24573 × 0.3083 = **−0.1515**。∎

**诚实边界**：真值 H″ ≈ −2.32 于 x ≤ 0.03（§4.1），定理 S 松 15 倍，全部松在 E ≤ κ₄（真 E ≈ 0.15，13 倍）与 g̃（0.67 vs 真 1.31，2 倍）。x₀ 若要推到 0.04 需把 m₁、hF 在 x₀ 处取值（显式级数，`certificate` 或 `rational-exact` 可做但不再是 ζ 闭式、不再是 `analytic`）或分两格；无本征向量链的**极限**是 x ≈ 0.07（ϖ ≈ 0.27，§4.3），再往上 E 的 13 倍损失不可承受。

### 2.4 命题 4：压缩归约　[analytic]（只是重述，不是路线）

H_N(x) := λ₁(P_N A(x) P_N) 单调 ↑ H(x)（压缩 + v ∈ ℓ²）。若每个 H_N 凹，则 H 作为凹函数的逐点极限凹。反向不成立。数值上 N ∈ {1,…,200} 全部 H_N 在 x ∈ [10⁻³, 10⁴] 网格上凹（`lemmaC_finiteN_concavity.py`，[numerical-evidence]）。每个 H_N 是 x 的代数函数（特征多项式系数为 x 的多项式，清分母后次数 ~ N²），其凹性是可判定的半代数命题——但 N 必须 ≳ 10ϖ，判定复杂度随 N 爆炸，且无 N-一致的论证。**记为重述，不作路线。**

## 6. 结论与未解决点

### 6.1 引理 C 能否解析化——分层判决

**(A) 纸笔 analytic，全 (0,∞)：不能（置信度 85%）。**障碍是**本质的**（相对于「顶本征值凹性」这个命题本身，而不只是相对于现有路线）：
1. 所有已知路线是同一个不等式 pos < 2F（命题 1），其中 pos ∝ E² = Var_v(𝒪[ψ_x]) 是隐式向量 v 的方差。
2. 不用 v 的信息去界 E²，现有工具（算子范数、Bhatia–Davis、命题 2 型重排）丢 ≥ 9 倍（ϖ ≥ 2）到 170 倍（ϖ ≤ 0.3）；紧区间余量 ≤ 7 倍 ⟹ 无本征向量链只到 x ≈ 0.07（§4.3），纸笔闭式常数版只到 0.03（定理 S）。
3. 用 v 的信息就要一个试探向量：闭式族的残差再小（§4.4 到 10⁻⁴），其六个 Rayleigh 型量仍是 (ϖ,α) 的**双重级数**，除 a = ϖ 这一特殊点外无闭式；而 a = ϖ 恰是残差最差的选择。所以「纸笔」与「残差够小」在这里是互斥的。
4. 结构性绕路（Loewner 序、算子凹、压缩到有限维）都已排除或只是重述（§2.4；`P4_einstein_extremal.md` §0、(B5)）。`P4_main_theorems.md` §1 注的「λ₁ 对核凸 vs 核对 x 凹」是这件事的根。

**(B) `certificate`（段 C-II 同级，区间算术），(0.03, ∞)：大概率能（置信度 70%）。**路线 R′（§5）。数值上 12 格全闭、最劣 0.585；风险在格一致化，可用加格化解。

**(C) `rational-exact`（CERT-B/D 型），[0.3, 8.5]：能（置信度 80%）。≈ 8 格 / ≈ 150 个有理数**（采样划分）～**≈ 20 格 / ≈ 500 个有理数**（格一致包络严格化后）（§4.6）。它没有浮点、没有舍入垫、没有区间算术，与仓库对 CERT-B 的处理同类；但 500 个有理数不是纸笔可验的。**按用户 2026-09-17 的裁定（CLAUDE.md §1 四级），这一档就是 `rational-exact`，介于 analytic 与 certificate 之间，不得简称为 analytic**——即**做成了，引理 C 仍不是 `analytic`**。

**(D) 已证成的纸笔 analytic 段：x ∈ (0, 0.03]（定理 S）。**首个不依赖任何数值向量的引理 C 片段。

### 6.2 对 team-lead 两个具体问题的回答

- 「紧区间比无穷远端容易」：**对一半**。不等式余量上对（真二阶占比 ≤ 0.15，x→0 时 →0；大 ϖ 端是 0.25）；工具上不对（H 隐式，紧区间工具箱无一适用；能用的只有有限覆盖 + 试探向量）。真正的难点区不是 (0, 8.48] 整段，而是 **ϖ ∈ [0.3, 2]**：隙分数最低（0.42–0.76）、廓线正在从 𝔊(2) 形状过渡到 log-Lorentz 形状（α 从 5 降到 1.6）。

### 6.3 对四条已排除路线的看法

`deep-lemmaC-analytic` 的四条尝试都是在**无本征向量**（廓线/锥矫顽）框架内找 F 型量的 ≥ 0.9 捕获率。本文不推翻其中任何一条的判决；但其总结「唯一缺失的输入是 v 的更精细下界或上界廓线」**应改写**：紧区间上缺的不是廓线（F 型量本来余量就大），而是 E² 的控制，而 E² 只有靠试探向量 + DK；试探向量存在且是显式的（§4.4）。
