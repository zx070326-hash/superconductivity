## 1. 一般核的重排恒等式（纠正错误认识）

### 1.1 定理：对任意非负核 f ≥ 0

**定理**. 设 f : ℕ_{≥1} → [0,∞)，Σ_k f(k) < ∞。对有限支撑 v，记 p_n := u_n v_n，则

```
⟨v, 𝒪[f] v⟩ = Σ_n p_n² T_f(n) + ⟨p, Hank_f p⟩ - ½D_f[p]
```

其中
- T_f(n) := Σ_{k>n} f(k)（尾和）
- Hank_f 是 Hankel 核：(Hank_f)_{nm} = f(n+m+1)
- D_f[p] := Σ_{n≠m} f(|n-m|)(p_n - p_m)² ≥ 0（广义 Dirichlet 型）

**证明**. 从 𝒪[f] 的逐元定义，代入 p_n = u_n v_n，L1（对角）+ L2（非对角，极化
2p_np_m=p_n²+p_m²-(p_n-p_m)²）+ L3（Hankel）三项合并对角项，用
c_f(n):=Σ_{m≠n}f(|n-m|)=Σf(k)+Σ_{k=1}^n f(k) 得 L1+L2对角 = Σp_n²[Σf(k)−Σ_{k=1}^n f(k)]
= Σp_n²T_f(n)。∎

**推论**. D_f[p] ≥ 0（逐项非负）⟹ 𝒪[f] ⪯ B_f，其中在原坐标：
```
(B_f)_{nm} = δ_{nm}·u_n²·T_f(n) + u_n u_m·f(n+m+1)
```

**关键**：这个恒等式对**任何** f ≥ 0、Σf < ∞ 成立，不需要 f = 1/k² 的特定形式。

### 1.2 为何初判错误

初版笔记误认为"1/(n-m)² 的特定形式是必需的"。实际上对 k^{-2}：D_f[p]=Σ(p_n-p_m)²/(n-m)²
（经典 Dirichlet 型）；对 ⟦k⟧(ϖ)：D_f[p]=Σ(p_n-p_m)²·ϖ²/(|n-m|²+ϖ²)（加权型，仍≥0）。
两者都非负，都能吸收部分负谱，只是 k^{-2} 的 D 更大（吸收更彻底），但非必需。

## 2. 应用到 Lorentz 核

### 2.1 Lorentz 核的具体形式

对 ⟦k⟧(ϖ) = ϖ²/(k²+ϖ²)，有 T_ϖ(n) = Σ_{k>n} ϖ²/(k²+ϖ²)、Hank_ϖ(n,m) = ϖ²/((n+m+1)²+ϖ²)、
D_ϖ[p] = Σ_{n≠m} [ϖ²/(|n-m|²+ϖ²)]·(p_n-p_m)² ≥ 0，因此 ℌ(ϖ) ⪯ B_ϖ，其中
(B_ϖ)_{nm} = δ_{nm}·u_n²·T_ϖ(n) + u_n u_m·ϖ²/((n+m+1)²+ϖ²)。

### 2.2 λ₂ 上界：二阶 trace 界

由 Weyl 单调性（A⪯B ⟹ λ_k(A)≤λ_k(B)）：λ₂(ℌ)≤λ₂(B_ϖ)。**关键观察**：B_ϖ 不必正定也能用
二阶 trace 界 λ₂(B)≤√(tr B²−λ₁(B)²)（对任何自伴算子成立，由 Σλ_i²=tr B² 与 Cauchy-Schwarz）。
进一步由 λ₁(B_ϖ)≥λ₁(ℌ)=h(ϖ)≥h_lo：
```
λ₂(ℌ) ≤ √(tr B_ϖ² - λ₁(B_ϖ)²) ≤ √(tr B_ϖ² - h_lo²)
```

### 2.3 tr B_ϖ² 的显式级数

记 f(k)=ϖ²/(k²+ϖ²)，(B_ϖ)_{nn}=u_n²·[T_ϖ(n)+f(2n+1)]，故：
```
tr B_ϖ² = Σ_n [T_ϖ(n) + f(2n+1)]²/(2n+1)² + 2Σ_{n<m} f(n+m+1)²/[(2n+1)(2m+1)]
```

### 2.4 小 ϖ 渐近行为

当 ϖ→0：f(k)≈ϖ²/k²、T_ϖ(n)≈ϖ²ψ'(n+1)、f(2n+1)²≈ϖ⁴/(2n+1)⁴。对角/非对角主贡献都
∝ϖ⁴（Σψ'(n+1)²/(2n+1)² 与相应双和均为有限常数），因此 **tr B_ϖ² ~ C_0·ϖ⁴**（ϖ→0），
C_0 为可计算数值常数。

## 6. 解析化路线图

**已有的解析成分**：(1) 重排恒等式，纯代数，对任意 f≥0 成立；(2) h_lo=ϖ²/(1+ϖ²)，有理函数；
(3) tr B_ϖ² 的级数表达式（§2.3），每项是 ϖ 的初等函数（含 arctan(ϖ/k)），可部分和+尾界。

**解析化的障碍**：T_ϖ(n)=Σ_{k>n}ϖ²/(k²+ϖ²) 涉及 Polygamma/Digamma 函数的有限差分，无初等
闭式；tr B_ϖ² 的部分和+尾界需对每个 ϖ 分段处理（类似层一引理 4c）。

**可行路线**（证书级，类似层一 CERT-B）：选取截断 N₁（如 50）→ 前 N₁ 项精确有理和 →
解析不等式界住尾项 Σ_{n≥N₁}T_ϖ(n)²/(2n+1)² → 得 tr B_ϖ² 的双侧有理端点包围 → 对每个
ϖ∈{0.2,...,2.0} 给出证书。这是**逐 ϖ 的解析证书**，不是 ϖ 的解析函数。
