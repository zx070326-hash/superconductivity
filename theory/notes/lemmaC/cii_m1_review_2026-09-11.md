## 1. 恒等式 · CONFIRMED
`rev6_algebra.log` [1][1b][1c][1d]。(M1) 的两个分母展开与分子 s²σ²(5+s²+σ²) 由 sympy `simplify(together(...))` 归零；对角项：全和的 m=n 项是 w_n[G(0)+G(2s_n)] = w_n + w_nG(2s_n)，真实对角是 w_nG(2s_n) − ℓ_G(n)，差恰为 w_n + ℓ_G(n) = 𝒟_nn——这正是「𝒟 里为何有个 w_n」的答案，(M2) 因 f(0)=0 无此项、𝒟_f = diag(ℓ_f) ✓。0 ≤ 𝒟_nn ≤ (1+2n)/(2n+1) = 1。

## 2. (a) · 结论 CONFIRMED、证明步 DOWNGRADE
`rev6_ab.log`。Binet 链：Re ln z = ½ln(ϖ²+¼)、Re 1/(2z) = 1/(4ϖ²+1)、\|t²+z²\| ≥ Im z² = ϖ、∫t/(e^{2πt}−1) = 1/24 ⟹ 余项 ≤ 1/(12ϖ)（实测 ×12ϖ = 0.124/0.050/0.022/0.001，界成立且随 ϖ 更松）✓。2A−2B = ΣΞ(a_n)、∫Ξ = ½、V_η = 3/2（η″ = 12u(u²−1)/(1+u²)⁴，单次变号）✓。**问题**：中点法则 Peano 表示 ∫_n^{n+1}f − f(n+½) = ∫K f″，K(u)=u²/2 (u≤½)、(1−u)²/2 (u≥½)，0≤K≤1/8、∫K=1/24。由此 \|E\| ≤ sup\|f″\|/24（每格）或 \|E\| ≤ (1/8)∫\|f″\|（全域），**没有** (1/24)∫\|f″\|。所以严格可写的是 2B−1 ≥ ln ϖ + c₀ − 1/(12ϖ) − 1/(4ϖ²) − **3/(16ϖ²)**。实测 ϖ²(ΣΞ−½) → 1/24 = 0.04167（EM 首项），故原式 1/16 数值成立、只是无证。对 c₀ 下半「首个严格证明」的措辞：改常数后仍是定理。（ϖ=1000 处 nsum 直接和差 4e-4 是 mpmath 对 1/n³ 尾的加速失效，脚本自带带尾格点和 5e-8 一致，非发现。）

## 3. (c) · CONFIRMED，松的来源
`rev6_truth.log` [3]。‖𝓡‖ 与 ϖ 无关（0.4791，8→200），因 𝓡 是固定积分算子 (s,σ)↦R(s,σ)/(2√(sσ)) 在 L²(ds) 上的中点离散。Schur 的极值权是 Perron 向量：用它得 sup = 0.47907 = ‖𝓡‖（对逐元正矩阵 Schur 用 Perron 权取等）；用 p 得 Θ\* = 0.6349。Perron 向量·√(2n+1) 在 s=0.1/0.5/1/1.5/3/6 为 80/1610/3811/4778/3394/879（归一到 n=0）——远非常数，故 p 权丢 33%。若 M2 想收 g_lo，可换权 p_n·χ(s_n)（χ 取 Perron 形状的初等近似），但目前 Θ\* 在 g_lo 里只占 0.63、瓶颈在 DK 传播（脚本瓶颈表：g_lo→真隙只把 ϖ_A 从 7.78 拉到 3.64），不是承重项。

## 4. (d) · CONFIRMED
`rev6_const.log`。三个可识别的闭式（mpmath `identify`，16 位）：c_Δ = 3π²/32 − 7/8、phi_tDt = 7/48 − 3π²/256、kap_tDt = 1/2 − 3π²/64；nD2 与双重积分常数未识别。0.1257572 与 0.1277654 应为 0.1257569、0.1277655（文档小数，代码不受影响）。

## 5. (e) · 代数 CONFIRMED、一处漏 pad DOWNGRADE
`rev6_assembly.log`、`rev6_qk.log`。自写装配（Θ_f 用 240 点 quad 网格，比脚本 60001 点粗）ϖ_A = 7.7758；去 pad 后 7.2493（pad 值 ϖ_A 0.53，即 pad 在 ϖ≈8 处并不小——M2 的 majorant 若比 0.25/ϖ² 大 2× 以上，ϖ_A 会上移到 ~8.5，仍远低于 45）。E_hi 在 ϖ_A 处的分解：e_κ 0.399 + s\|q_κ\| 0.055 + s‖𝒦‖ 0.160；F 侧 2s·e_φ 0.041、s²NP 0.011——DK 传播（尤其 s‖𝒦‖）承重与文档一致。

**漏 pad**：`bounds()` 中 `q_k = 4K1 + (kap_GU − kap_tDt)/B` 无 pad，`schur_norm` 的 2G·I[f] 与 Λ_f/s 两项无 pad（`THETA_STAR` 在 g 里有 −pad ✓，Stage 5 的 sup Σ_n ≤ Θ\*+pad 检查也 ✓，但 NP/NK 的行和 lattice→continuum 未 pad）。q_κ 格点真值在 ϖ=7.776/8/10/20 比闭式大 2.0e-3/1.9e-3/1.2e-3/3.2e-4（约 PAD/2、同号），代入真 q_κ 后 ϖ_A = 7.7825。NP/NK 有 2× 余量，数值无险。**这是装配清单问题**（哪些量算「格点→连续」被 pad），交 M2 一并补：q_κ 加 +pad，Schur 行和加 +pad。

## 6. 空泛性 · CONFIRMED，精确表述
「g ≥ h+λ_min(M)」对 ℓ² 上的 ℌ **恒等于 g ≥ 0**（λ_min(M) = −h 精确，M 作为二次型在 {⟨u,w⟩ 有限} 稠密域上定义；不需 M 有界）。对每个截断 N 它是真命题且非空泛，但值随 N 单调降、~1/ln N → 0，且无法经压缩交错回传到 ℓ²（λ_k(ℌ_N) ≤ λ_k(ℌ)，对 λ₂ 上界是反向）。「3.54」「2.92」这类数都是 span{v,z} 二维变分给的**上界**，不是 h_N+λ_min(M_N) 的值。文档 §2.3 措辞「VACUOUS on ℓ²」准确。
