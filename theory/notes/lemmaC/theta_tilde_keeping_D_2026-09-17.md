## 2. 引理 Λ 恰好适用 [analytic]

§1.F.2 写明 `𝓡_{nm} := p_np_m R(s_n,s_m) ≥ 0（逐元）`、`𝒟 := diag(w_n + ℓ_G(n))` 对角——
这正是引理 Λ（`lam2_laplacian_peeling_2026-09-17.md`）的前提 `A = B − Δ`，`B ≥ 0` 逐元。
取 `k = 0`（不剥）、权 `q_n = p_n`：

    λ₁(𝓡−𝒟) ≤ sup_n [ Σ_m p_n p_m R(s_n,s_m)·(p_m/p_n) − 𝒟_nn ]
             = sup_n [ Σ_m w_m R(s_n,s_m) − 𝒟_nn ]                          (S̃)

`q = p` 时括号里第一项**逐字就是仓库的 Schur 行和**。所以 (S̃) 与仓库现行界唯一的区别
就是那个 `− 𝒟_nn`。

## 3. 连续极限：两项在 s→∞ 同阶相消 [analytic]

两项都是间距 `D = 1/ϖ` 的**中点求和**：

- `Σ_m w_m R(s_n,s_m) → Θ(s) = [ln(1+s²) + 2s·arctan s]/(2(1+s²))`（仓库 §1.F.3(c) 留数结果）
- `𝒟_nn = (1 + 2Σ_{k=1}^n G(k/ϖ))/(2n+1) = (D·Σ_{k=−n}^{n}G(kD))/(2s_n) → arctan(s)/s`
  （因 `1 + 2Σ_{k=1}^n G(kD) = Σ_{k=−n}^{n} G(kD)` 是 `∫_{−s_n}^{s_n}G = 2arctan s_n`
  在 `2n+1` 个宽 `D` 的格上的中点和，总宽恰为 `2s_n`）

`s→∞` 时 `Θ(s) = π/(2s) − 1/s² + ln s/s² + …`，`arctan(s)/s = π/(2s) − 1/s² + …`——
**`π/(2s)` 与 `1/s²` 两阶同时相消**，余下 `Θ̃(s) ~ ln s/s² → 0⁺`。
`s→0` 时 `Θ̃ → −1`。故 `Θ̃` 有界且 sup 在有限 `s` 取到：

    **Θ̃(s) := Θ(s) − arctan(s)/s ,   Θ̃* := sup_{s>0} Θ̃(s) = 0.0737378188046  @ s̃ = 2.86906499489**

对照 `Θ* = 0.63492879`：**小 8.61 倍**，且 `Θ̃` 与 `Θ` 一样是初等闭式，
驻点方程同样可写（`_chk_theta_tilde.py` 用 `mp.findroot` + `s∈[1e−4,1e6]` 两万点粗扫复核，
粗扫最大 0.07373437 < 驻点值，一致）。

    Σ_{m≥0} w_m R(s,s_m) = D · Σ_{m≥0} Φ_s(s_m),    Φ_s(σ) := R(s,σ)/(2σ)

### 5.1.1 `C_R ≤ 6` —— 已证，部分分式路线（2026-09-18，取代以下全部免根尝试）

> **定理 (C_R)** [analytic]．对一切 `s > 0`，`s·V₂[Φ_s] ≤ 6`。故 `C_R ≤ 6`。
>
> *证.* `Φ_s(σ) = s²σ(5+s²+σ²)/[(1+(s−σ)²)(1+(s+σ)²)(1+s²)(1+σ²)]` 关于 `σ`
> 分子 3 次、分母 6 次，且（`s>0` 时）六个极点互异、全为单极点、**虚部模全为 1**：
>
>     σ ∈ {s+i, s−i, −s+i, −s−i, i, −i}
>
> 无多项式部分 ⟹ `Φ_s = Σ_j r_j/(σ−p_j)`，留数（sympy 精确）
>
>     r(s+i) = −i/(4(s+i)),  r(s−i) = i/(4(s−i)),  r(−s+i) = i/(4(s−i)),
>     r(−s−i) = −i/(4(s+i)),  r(i) = r(−i) = 1/(2(s²+1))
>
> 四个 `±s±i` 的模同为 `1/(4√(1+s²))`、两个 `±i` 的模同为 `1/(2(1+s²))`，故
>
>     **Σ_j |r_j| = 1/√(1+s²) + 1/(1+s²)**
>
> 逐项二阶导 `Φ_s'' = Σ_j 2r_j/(σ−p_j)³`，而 `|σ−p_j|² = (σ−Re p_j)² + 1`，于是
>
>     V₂[Φ_s] = ∫_0^∞|Φ_s''| ≤ 2Σ|r_j|·∫_0^∞ dσ/((σ−a_j)²+1)^{3/2}
>             ≤ 2Σ|r_j|·∫_{−∞}^{∞} dx/(x²+1)^{3/2} = 2Σ|r_j|·2 = 4Σ|r_j|
>
> （`∫(x²+1)^{−3/2}dx = x/√(x²+1)`，全轴值**恰为 2**。）代入：
>
>     s·V₂[Φ_s] ≤ 4s/√(1+s²) + 4s/(1+s²) < 4 + 2 = 6
>
> 第一项 `< 4` 显然；第二项 `≤ 2` 即 `(s−1)² ≥ 0`（sympy 验余项恰为 `(s−1)²/(1+s²)`）。∎
>
> **没有变号计数、没有 `M/m`、没有根隔离、没有格点，且关于 `s` 一致。**
> 顺带：`sup_{s>0} 4sΣ|r_j|` 的精确值是 `3√3 = 5.196152422706632`（sympy `maximum`），
> 但上面两行初等不等式已够，**承重链不引 CAS 的 `maximum`**。

## 11. `sup over n` 的解析有限化 [analytic]

欠账 (c) 原本写成「需证 `δ_n` 在 `n ≥ n₀` 单调」。**这条路不必走**——因为判据里用的
从来不是 `δ_n` 本身，而是 §5.1 的**解析包络**：对每个 `n`

    δ_n := Σ_m w_m R(s_n,s_m) − 𝒟_nn ≤ Θ̃(s_n) + pad_R(s_n) + pad_D(s_n) =: E(s_n),
    E(s) = Θ̃(s) + c/s,   c := (D²/8)(C_R + V₂[G]/2)

`c/s` 恒递减，所以 **`E` 在 `Θ̃` 递减的区间上递减**，`sup_n E(s_n)` 就落到有限个 n 上。
于是有限化只剩一个单变量初等不等式：**`Θ̃′(s) < 0` 对 `s ≥ s₁`**。

**引理 F.** `Θ̃′(s) = N(s)/[s²(1+s²)²]`，
`N(s) = −s³ln(1+s²) + s³ + 3s²arctan s − s + arctan s`，且 `N(s) < 0` 对一切 `s ≥ 3`。

*证.* 分母恒正。对 `x = 1/s ∈ (0,1]` 有 `arctan x ≥ x − x³/3`（交错级数，`x≤1`），故
`arctan s = π/2 − arctan(1/s) ≤ π/2 − 1/s + 1/(3s³)`，于是
`3s²arctan s ≤ (3π/2)s² − 3s + 1/s`；又 `arctan s ≤ π/2`。代入得 `N(s) ≤ −ψ(s)`，

    ψ(s) := s³(ln(1+s²) − 1) − (3π/2)s² + 4s − 1/s − π/2

`ψ′(s) = 3s²(ln(1+s²)−1) + 2s⁴/(1+s²) − 3πs + 4 + 1/s²`。`s ≥ 3` 时 `ln(1+s²) ≥ ln 10 > 2.302`，
故 `3s²(ln(1+s²)−1) > 3.906s²`，丢掉非负的 `2s⁴/(1+s²)` 得
`ψ′(s) > 3.906s² − 3πs + 4`，其判别式 `9π² − 62.5 > 0`、大根 `< 1.86 < 3` ⟹ **`ψ′ > 0` 于 `s ≥ 3`**。
又 `ψ(3) = 27(ln10 − 1) − 13.5π + 12 − 1/3 − π/2 > 27(2.302) − 13.5(3.1416) + 12 − 1/3 − 1.5708
= 2.83 > 0`。故 `ψ > 0`、`N < 0` 于 `s ≥ 3`。∎

（只用到 `ln 10 > 2.302`、`π < 3.1416` 两个标准常数有理界 ⟹ 全程 **analytic**。
数值旁证：`Θ̃′` 与 `N/[s²(1+s²)²]` 在 9 个点逐位相同；`min ψ = 2.854 @ s=3`、
`min ψ′ = 27.21 @ s=3`（`s∈[3,1e6]` 400 点）；`N < 0` 在 `s∈[2.8691,1e6]` 2000 点直接成立。）

**推论（有限化）.** `E` 在 `[3,∞)` 严格递减，故

    S̃(ϖ) ≤ sup_n E(s_n) = max_{0 ≤ n ≤ ⌈3ϖ⌉} E(s_n)        （s_n = (n+½)/ϖ ≤ 3 ⟺ n ≤ 3ϖ−½）

**是显式有限的最大值**，不再是无穷 sup。⟹ 欠账 (c) 对本链关闭。
注意 **`P_β` 的同名欠账并不因此关闭**——它没有这个包络结构，那条仍开着。

> ⚠ `δ_n` **本身**是否单调仍未证（`lam2bound` 给出 4 个 ϖ × 4000 点 0 违例的数值证据，
> 并把 `δ_n = Θ̃(s_n) + e_n` 拆开，`Θ̃` 那半有解析依据、`e_n` 那半没有）。
> **本节绕开了这个问题**：判据用包络不用 `δ_n`，所以 `e_n` 的单调性是**不需要的**。

**粗路线草图**（方向已审，每步都朝上界）：

1. 丢掉 `−ℓ_G(n) ≤ 0`（被减项，丢掉**抬高**上界 ✓）。
2. `f` 递减且 `n+m+1 > |n−m|`（m ≥ 1 时两侧都成立）⟹ `K(n,m) ≤ 2f(|n−m|)`（`m ≠ n`）；

   若误用 `2f(0) = 2` 会炸掉。
3. `f(k) = ϖ²/(k²+ϖ²) ≤ ϖ²/k²` ✓。
4. 按 `|m−n| ≤ n/2` 分段：近段 `(2m+1)^{−c} ≤ (n+1)^{−c}`（`c=(1+β)/2`）；

### 12.5 `MT` 尾 pad：从零复核通过 [analytic]

`Σ_{m≥MT} K(n,m)u_m p_m/p_n·u_n ≤ u_n·2ϖ²/(√(2MT+1)(MT−n−1))`，三步逐字给出 pad 公式：

1. `p_m/p_n ≤ 1`（`m > n`、`β ≥ 0`）——丢弃是**抬高**，对上界安全 ✓
2. `K(n,m) ≤ 2f(m−n) ≤ 2ϖ²/(m−n)²`，`u_m ≤ (2MT+1)^{−1/2}`（`m ≥ MT`）✓
3. `Σ_{k≥K}k^{−2} ≤ ∫_{K−1}^∞x^{−2}dx = 1/(K−1)`，取 `K = MT−n` 得 `1/(MT−n−1)` ✓

驱动的 `m` 循环是 `arange(1, MT)`（即 `m ≤ MT−1`），pad 恰好接上 `m ≥ MT`，不重不漏。
⟹ **这条欠账关闭，公式无需改动。**
