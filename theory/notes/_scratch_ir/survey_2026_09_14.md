## TIER 1: Would change paper identity / close largest open problem

### 1. Smooth Coulomb cutoff restores μ*>0 global uniqueness

**Statement**: Replace sharp step N_c=floor(r·ω) with smooth χ(t)=1/(1+t^(2p)), p≥2.

Sharp cutoff has N_c downjumps at window boundaries => λ₁(M) non-monotonic => double roots (P4D_coulomb_uniqueness.md §6: r=3 真实失效 at λ=1, μ=0.10). Smooth χ with dχ/dt ≤ 0 makes dλ₁/dω analytic:

```
dλ₁/dω = D_ph - μ*·D_c
D_ph = <v, dO/dω v> > 0  (phonon, always positive)
D_c = 4<v,u><v, du/dω>  where  du/dω = -(t/ω)·(dχ/dt)·p_n
```

When dχ/dt ≤ 0 continuous => D_c ≥ 0 => derivative strictly positive => no downjumps.

**Why now**: Step-model downjumps are known obstacle. Smooth cutoff is physically equivalent Morel-Anderson but structurally different: perturbation formula splits into two terms, both with definite sign when χ monotone.

**Difficulty**: Medium (numerical → analytic). Need to:
- Prove D_ph - μ*·D_c > 0 for physical μ* (bound ratio μ*·D_c/D_ph < 1)
- Show smooth χ preserves Tolmachev slope d(1/μ*)/d ln ω_c = -1
- Verify K_c rank-one => α-side inheritance still white-delivered

**Expected impact**: Close largest open item. μ*>0 uniqueness from window-level (current Theorem, r≥4 numerical) to global (all r≥r_min analytic). Window-crossing regularity layer disappears.

**Discriminating probe (30min)**: COMPLETED  
`nx_coul.py scan_mono` over (r,μ) grid:

Residual r=4, μ=0.26, p=2 dip -4e-7 converges to zero: N=400→1600 stays -4.05e-7.

Analytic margin `nx_coul.py margin`: dλ₁/dω = D_ph - μ*·D_c, ratio μ*·D_c/D_ph:

**Conclusion**: Smooth cutoff eliminates r=3 failures. Need analytic proof μ*·D_c/D_ph < 1 for physical parameters => uniqueness closes.

### 2. H''(x) implicit-function identity => Lemma C analytic

**Statement**: H(x)=h(√x) concavity via exact second-order perturbation split:

```
H''(x) = t1 + t2
t1 = <v, O[d²f/dx²]v> ≤ 0  (kernel concavity, always negative)
t2 = 2<w, (hI-M)^(-1)w> ≥ 0  (level repulsion, always positive)
```

where w=(I-P_v)(dO/dx)v, v=eigenvector, M=O[f]-2ττ^T by (S3).

**Key identities** (verified to machine precision 1e-16):
- v = (hI-M)^(-1)τ / |.| exactly (Woodbury + secular equation F(h)=1)
- M = R - D split, Neumann series converges for h > ||R||
- Ratio t2/|t1| ∈ [0.12, 0.24] over ω∈[0.3,800], approaches 1/4 at ∞

**Why now**: Three completed keys:
1. (S3) Lorentz addition H=2ττ^T+R-D gives M explicitly
2. Secular equation F(h)=2<τ,(hI-M)^(-1)τ>=1 (Theorem W) => v∝(hI-M)^(-1)τ exact
3. Numerical evidence: t2/|t1| bounded away from 1

If t2/|t1| < 1 provable => H''<0 analytic => Lemma C from certificate to pure analysis. Main paper's last computer-assisted dependency disappears.

**Difficulty**: High. Three sub-problems:
- Control Neumann remainder ||(hI+D)^(-1)R||^k for v approximation
- Bound t2/|t1| < 1 uniformly (numerical max 0.237 suggests slack)
- Show bound persists ω→0 and ω→∞ (weak/strong coupling asymptotics)

**Expected impact**: Main paper identity change. §5 "Concavity of H" becomes analytic theorem not certificate appendix. Lemma C gap (after g(2) analytization) closes => Theorems 1+2+C all pure analysis, zero numerical.

### 5. Jensen-class kernel characterization

**Statement**: Theorem 2 uses kernel-level Jensen: F_T(k) = ∫[x/(k²+x)]P(dx) ≤ <x>/(k²+<x>) requires x↦x/(k²+x) concave each k. Characterize full Jensen class.

**Finding**: f(k,x) = g(x)·[x/(k²+x)]^a with a≤1 stays in class (d²/dx² ≤ 0 for all k,x).

Examples:
- Debye cutoff f(k,x) = [x/(k²+x)]·𝟙[k≤K_c]: product concave × x-independent => concave
- Vertex a=3/2: d²/dx² = 3(-4k²+x)/[4(k²+x)^(7/2)] changes sign at x=4k²
- Vertex a=2: d²/dx² = 2(-2k²+x)/(k²+x)^4 changes sign at x=2k²

**Why now**: Theorem 2 proof depends on this concavity. Literature discusses vertex corrections but never asks whether Jensen survives. Debye model most common, confirming it stays in class non-trivial.

**Difficulty**: Low. Symbolic d²/dx² computed (sympy), numerical verification on Debye done. Write proposition with proof, show vertex-corrected a>1 exits class.

**Expected impact**: Theorem 2 scope precisely delimited. Shows vertex corrections break extremal property. Independent mathematical result, appendix or follow-up.

**Discriminating probe (30min)**: COMPLETED. Sympy exact d²/dx² formulas, numerical test confirms Debye preserves Jensen pointwise.
