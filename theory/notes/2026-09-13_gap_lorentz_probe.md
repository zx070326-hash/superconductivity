# Probe: 层一重排恒等式能否推广到 Lorentz 核？

**日期**: 2026-09-13  
**状态**: 探针级（成败如实报告）  
**任务**: 测试能否将层一的重排恒等式从核 k^{-2} 推广到 Lorentz 核 ⟦k⟧(ϖ)=ϖ²/(k²+ϖ²)，使解析的谱隙下界 g_lo = h_lo - λ₂_hi 达到真隙的 ≥ 0.4 倍（ϖ ∈ [0.3, 2]）。

## 1. 层一重排恒等式回顾（核 k^{-2}）

### 1.1 关键结构

对 𝔊(2) = 𝒪[k^{-2}]，层一使用：

1. **代换** p_n := u_n v_n → 所有双线性量变为 p 的有理函数
2. **重排恒等式**（引理 1）:
   ```
   ⟨v,Av⟩ = ⟨v,Bv⟩ - ½D[p]
   ```
   其中
   - D[p] = Σ_{n≠m}(p_n-p_m)²/(n-m)² ≥ 0（Dirichlet 型，吸收负谱）
   - B_{nm} = u_n u_m/(n+m+1)² + δ_{nm}u_n²ψ'(n+1)

3. **B ≥ 0**（引理 2）: Hankel 核 1/(n+m+1)² 有矩表示 → 正性

4. **λ₂ 上界**（引理 3）: λ₂(A) ≤ λ₂(B) ≤ tr B - B₀₀ ≤ β₀ ≤ 13/25

5. **Temple**：λ₁(A) ≤ ρ + r²/(ρ - β)

### 1.2 核心性质

核 k^{-2} 的 K(n,m) 分解为：
```
K(n,m) = 1/(n-m)² + 1/(n+m+1)²
```

- **1/(n-m)² 项**：允许极化恒等式
  ```
  Σ_{n≠m} p_n p_m/(n-m)² = Σ_n c_n p_n² - ½D[p]
  ```
  其中 c_n = Σ_{m≠n}1/(n-m)² = ζ(2) + H_n^{(2)}

- **1/(n+m+1)² 项**（Hankel）：矩表示 → B ≥ 0

**这两个性质缺一不可**。前者吸收负谱，后者保证 B 正定，trace 界才有用。

## 2. Lorentz 核的结构

### 2.1 核函数

Lorentz 核：
```
⟦k⟧(ϖ) = ϖ²/(k²+ϖ²)
```

部分分式分解：
```
ϖ²/(k²+ϖ²) = ϖ²/k² - ϖ⁴/(k²(k²+ϖ²))
```

因此：
```
ℌ(ϖ) = ϖ²𝔊(2) - 𝒪[ϖ⁴/(k²(k²+ϖ²))]
```

也可用 (S1) 写成：
```
ℌ = 2uu^T - I - W,  W = 𝒪[k²/(k²+ϖ²)]
```

### 2.2 K(n,m) 的形式

对 ℌ(ϖ)，核函数在算子中出现为：
```
K_ϖ(n,m) = ϖ²/(|n-m|²+ϖ²) + ϖ²/((n+m+1)²+ϖ²)
```

**关键问题**: 这**不是** 1/(n-m)² + 1/(n+m+1)² 的形式。

第一项：
```
ϖ²/(|n-m|²+ϖ²) ≠ 1/(n-m)²
```

无法用相同的极化恒等式提取 Dirichlet 型 Σ(p_n-p_m)²/(n-m)²。

## 3. 尝试推广的失败

### 3.1 能否提取 Dirichlet 型？

对 ℌ(ϖ)，如果尝试写：
```
Σ_{n≠m} p_n p_m · ϖ²/(|n-m|²+ϖ²) = ?
```

用标准极化 2p_n p_m = p_n² + p_m² - (p_n-p_m)²：
```
= Σ_{n≠m}(p_n² + p_m²) · ϖ²/(|n-m|²+ϖ²) / 2 - Σ_{n≠m}(p_n-p_m)² · ϖ²/(|n-m|²+ϖ²) / 2
```

第一项：
```
Σ_n p_n² · Σ_{m≠n} ϖ²/(|n-m|²+ϖ²) =: Σ_n p_n² c_n(ϖ)
```

第二项：
```
-½ Σ_{n≠m}(p_n-p_m)² · ϖ²/(|n-m|²+ϖ²)
```

**问题**：这**不是** Dirichlet 型 D[p] = Σ(p_n-p_m)²/(n-m)²。

因子 ϖ²/(|n-m|²+ϖ²) ≠ 1/(n-m)²，且依赖 ϖ。无法写成固定的二次型。

### 3.2 能否构造正算子 B_ϖ？

即使放弃精确重排恒等式，尝试直接找 B_ϖ 使：
- ℌ ⪯ B_ϖ（二次型序）
- B_ϖ ≥ 0
- λ₂(B_ϖ) 可解析界住

**尝试 1**: 用 ℌ = ϖ²𝔊(2) - (正核算子)

虽然结构上 ℌ ≤ ϖ²𝔊(2)，但：
- ϖ²𝔊(2) 本身有负谱（𝔊(2) 的 λ_min = -0.990）
- 无法直接用 trace 界

**尝试 2**: 直接对 ℌ 用 trace 界

见下节数值测试：完全失效。

## 5. 为何层一对 𝔊(2) 有效但对 ℌ(ϖ) 无效？

### 5.1 层一的成功：负谱被移除

对 𝔊(2)：
1. 重排恒等式 ⟨v,Av⟩ = ⟨v,Bv⟩ - ½D[p]
2. D[p] ≥ 0 吸收了 A 的全部负谱（λ_min = -0.990）
3. 得到的 B ≥ 0，无负本征值
4. tr B - B₀₀ 给出有意义的 λ₂ 上界

**关键**: B 的 trace 只包含非负本征值。

### 5.2 对 ℌ(ϖ) 的失败：负谱无处安放

对 ℌ(ϖ)：
1. 无法提取 Dirichlet 型（核结构不同）
2. 无法构造正算子 B_ϖ 使 ℌ ⪯ B_ϖ
3. 直接对 ℌ 用 trace：ℌ 的负谱（约 -1 量级）贡献到 tr(ℌ) 中
4. tr(ℌ) - λ₁ 甚至是负数

**根本原因**: Lorentz 核的 K_ϖ(n,m) 不具备允许 Dirichlet 提取的代数结构。

## 6. 结论与建议

### 6.1 探针结论

**层一的重排恒等式无法推广到 Lorentz 核 ⟦k⟧(ϖ)。**

具体失效点：
1. 核分解 K_ϖ(n,m) = ϖ²/(|n-m|²+ϖ²) + ϖ²/((n+m+1)²+ϖ²) 不具备 1/(n-m)² + Hankel 的形式
2. 无法提取 Dirichlet 型 Σ(p_n-p_m)²/(n-m)²
3. 未找到正算子 B_ϖ 使 ℌ ⪯ B_ϖ
4. 直接 trace 界因 ℌ 的负谱而完全失效（松 10³-10⁴ 倍）

**数值验证**: 对 ϖ ∈ [0.3, 2]，无法达到目标 λ₂_hi ≤ 0.6·h(ϖ)。

### 6.2 替代方向

既然层一路线不可行，需考虑：

**(a) 引理 M 型单调性论证**  
若能证明 ⟦k⟧(ϖ) 在某种意义下可被更简单的核上界，再用 Lemma M 传递。但需要保持隙结构，非平凡。

**(b) 证书级计算**  
类似凹性证明的方式，直接对 λ₂(ℌ(ϖ)) 做区间算术包围。代价是需要逐 ϖ 计算，无法给出 ϖ 的解析函数。

**(c) 扰动理论精细化**  
ℌ = ϖ²𝔊(2) - 𝒪[ϖ⁴/(k²(k²+ϖ²))]，若能给出第二项对 λ₂ 的**紧**扰动界（不只是算子范数），可能有戏。需要用到 Davis-Kahan 或 Bauer-Fike，但通常给出的是绝对误差，不保持相对隙。

**(d) Lorentz 核的特殊分解**  
寻找 ⟦k⟧(ϖ) 特有的代数性质。例如：
- 是否能写成某种卷积或生成函数形式？
- 是否与其他已知正核有简单关系？

目前未找到。

### 6.3 对主任务的影响

任务要求"层一的解析隙界能否推广到 ϖ ∈ [0.3, 2]"。

**答案**: **否**。

**建议**: 对 ϖ ∈ [0.3, 2] 的隙界，若要解析化，需要全新路线或接受证书级计算。
