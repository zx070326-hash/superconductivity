## 1. 一般核的重排恒等式（纠正错误认识）

### 1.1 定理：对任意非负核 f ≥ 0

**定理**. 设 f : ℕ_{≥1} → [0,∞)，Σ_k f(k) < ∞。对有限支撑 v，记 p_n := u_n v_n，则

```
⟨v, 𝒪[f] v⟩ = Σ_n p_n² T_f(n) + ⟨p, Hank_f p⟩ - ½D_f[p]
```

其中
- T_f(n) := Σ_{k>n} f(k)（尾和）
- Hank_f 是 Hankel 核：(Hank_f)_{nm} = f(n+m+1)
- D_f[p] := Σ_{n≠m} f(|n-m|)(p_n - p_m)² ≥ 0（广义 Dirichlet 型）

**证明**. 从 𝒪[f] 的逐元定义：

𝒪[f]_{nm} = -δ_{nm}·2u_n²·Σ_{k=1}^n f(k) + (1-δ_{nm})·f(|n-m|)·u_n u_m + f(n+m+1)·u_n u_m

代入 p_n = u_n v_n：

**L1 项（对角）**:
```
-Σ_n (2u_n v_n)² · Σ_{k=1}^n f(k) = -Σ_n p_n² · 2Σ_{k=1}^n f(k)
```

**L2 项（非对角）**:
```
Σ_{n≠m} f(|n-m|) u_n v_n u_m v_m = Σ_{n≠m} f(|n-m|) p_n p_m
```

用极化 2p_n p_m = p_n² + p_m² - (p_n-p_m)²：
```
= Σ_n p_n² · Σ_{m≠n} f(|n-m|) - ½Σ_{n≠m} f(|n-m|)(p_n-p_m)²
= Σ_n p_n² · c_f(n) - ½D_f[p]
```

其中 c_f(n) := Σ_{m≠n, m≥0} f(|n-m|) = Σ_{k=1}^∞ f(k) + Σ_{k=1}^n f(k)（对称拆分）。

**L3 项（Hankel）**:
```
Σ_{n,m} f(n+m+1) p_n p_m = ⟨p, Hank_f p⟩
```

**合并对角项**:
```
L1 + L2 对角 = Σ_n p_n² [c_f(n) - 2Σ_{k=1}^n f(k)]
               = Σ_n p_n² [Σ_{k=1}^∞ f(k) + Σ_{k=1}^n f(k) - 2Σ_{k=1}^n f(k)]
               = Σ_n p_n² [Σ_{k=1}^∞ f(k) - Σ_{k=1}^n f(k)]
               = Σ_n p_n² T_f(n)
```

其中 T_f(n) = Σ_{k>n} f(k) = Σ_{k=1}^∞ f(k) - Σ_{k=1}^n f(k)。∎

**推论**. D_f[p] ≥ 0（逐项非负）⟹ 𝒪[f] ⪯ B_f，其中

```
B_f := diag(T_f(n)/(2n+1)) + Hank_f（在 v 坐标）
```

即在原坐标 B_f 的矩阵元为：
```
(B_f)_{nm} = δ_{nm}·u_n²·T_f(n) + u_n u_m·f(n+m+1)
```

**关键**: 这个恒等式对**任何** f ≥ 0、Σf < ∞ 成立，不需要 f = 1/k² 的特定形式。

### 1.2 为何初判错误

初版笔记误认为"1/(n-m)² 的特定形式是必需的"。实际上：

- 对 k^{-2}：D_f[p] = Σ(p_n-p_m)²/(n-m)²（恰为经典 Dirichlet 型）
- 对 ⟦k⟧(ϖ)：D_f[p] = Σ(p_n-p_m)²·ϖ²/(|n-m|²+ϖ²)（加权 Dirichlet 型，仍 ≥ 0）

两者都非负，都能吸收部分负谱。只是 k^{-2} 的 D 更大（因 1/(n-m)² > ϖ²/(|n-m|²+ϖ²)），故吸收得更彻底，但不是必需的。

## 2. 应用到 Lorentz 核

### 2.1 Lorentz 核的具体形式

对 ⟦k⟧(ϖ) = ϖ²/(k²+ϖ²)，有：

- T_ϖ(n) = Σ_{k>n} ϖ²/(k²+ϖ²)
- Hank_ϖ(n,m) = ϖ²/((n+m+1)²+ϖ²)
- D_ϖ[p] = Σ_{n≠m} [ϖ²/(|n-m|²+ϖ²)] · (p_n-p_m)² ≥ 0

因此：
```
ℌ(ϖ) ⪯ B_ϖ
```

其中 B_ϖ 的矩阵元为：
```
(B_ϖ)_{nm} = δ_{nm}·u_n²·T_ϖ(n) + u_n u_m·ϖ²/((n+m+1)²+ϖ²)
```

### 2.2 λ₂ 上界：二阶 trace 界

由 Weyl 单调性（A ⪯ B ⟹ λ_k(A) ≤ λ_k(B)）：
```
λ₂(ℌ) ≤ λ₂(B_ϖ)
```

**关键观察**: B_ϖ **不必正定**也能用二阶 trace 界：
```
λ₂(B) ≤ √(tr B² - λ₁(B)²)
```

这对任何自伴算子成立（由 Σλ_i² = tr B² 与 Cauchy-Schwarz）。

进一步，由 λ₁(B_ϖ) ≥ λ₁(ℌ) = h(ϖ) 且有下界 h_lo：
```
λ₂(ℌ) ≤ √(tr B_ϖ² - λ₁(B_ϖ)²) ≤ √(tr B_ϖ² - h_lo²)
```

### 2.3 tr B_ϖ² 的显式级数

```
tr B_ϖ² = Σ_n [(B_ϖ)_{nn}]² + 2Σ_{n<m} [(B_ϖ)_{nm}]²
```

其中：
- 对角平方：
  ```
  [(B_ϖ)_{nn}]² = u_n⁴·T_ϖ(n)² + 2u_n⁴·T_ϖ(n)·ϖ²/((2n+1)²+ϖ²) + u_n⁴·ϖ⁴/((2n+1)²+ϖ²)²
                = [T_ϖ(n)/(2n+1)² + ϖ²/((2n+1)²+ϖ²)/(2n+1)²]²
  ```

简化：记 f(k) = ϖ²/(k²+ϖ²)，则
```
(B_ϖ)_{nn} = u_n²·T_ϖ(n) + u_n²·f(2n+1) = u_n²·[T_ϖ(n) + f(2n+1)]
```

故
```
Σ_n [(B_ϖ)_{nn}]² = Σ_n [T_ϖ(n) + f(2n+1)]²/(2n+1)²
```

- 非对角平方：
  ```
  Σ_{n<m} [(B_ϖ)_{nm}]² = Σ_{n<m} u_n² u_m² · f(n+m+1)²
                        = Σ_{n<m} f(n+m+1)²/[(2n+1)(2m+1)]
  ```

因此：
```
tr B_ϖ² = Σ_n [T_ϖ(n) + f(2n+1)]²/(2n+1)² + 2Σ_{n<m} f(n+m+1)²/[(2n+1)(2m+1)]
```

其中 f(k) = ϖ²/(k²+ϖ²)，T_ϖ(n) = Σ_{k>n} ϖ²/(k²+ϖ²)。

### 2.4 小 ϖ 渐近行为

当 ϖ → 0：

- f(k) = ϖ²/(k²+ϖ²) ≈ ϖ²/k²（主项）
- T_ϖ(n) ≈ ϖ²·Σ_{k>n} 1/k² = ϖ²·ψ'(n+1)
- f(2n+1)² ≈ ϖ⁴/(2n+1)⁴

对角项主贡献：
```
Σ_n T_ϖ(n)²/(2n+1)² ≈ ϖ⁴·Σ_n [ψ'(n+1)]²/(2n+1)²
```

其中 Σ_n [ψ'(n+1)]²/(2n+1)² 是有限常数（因 ψ'(n+1) ~ 1/n² ⟹ 被加项 ~ n^{-6}，收敛）。

非对角项主贡献：
```
2Σ_{n<m} ϖ⁴/[(k²+ϖ²)²(2n+1)(2m+1)] ≈ ϖ⁴·[常数]
```

因此 **tr B_ϖ² ~ C_0·ϖ⁴**（ϖ → 0），其中 C_0 是可计算的数值常数。

## 3. h_lo(ϖ) 的下界选择

### 3.1 最简选择：⟨e₀, ℌ e₀⟩

```
h_lo = ⟨e₀, ℌ e₀⟩ = (ℌ)₀₀ = u₀²·[f(1) - 2·0] + ... 
```

由 𝒪[f] 的对角元公式 A_{nn} = u_n²·[f(2n+1) - 2H_n]（H_n = Σ_{k=1}^n f(k)），对 n=0：
```
H₀ = 0, f(k) = ϖ²/(k²+ϖ²)
(ℌ)₀₀ = u₀²·f(1) = 1·ϖ²/(1+ϖ²) = ϖ²/(1+ϖ²)
```

因此：
```
h_lo(ϖ) = ϖ²/(1+ϖ²)
```

这是**有理函数**，解析且易算。

### 3.2 CERT-B 试探向量（可选的更强下界）

层一 CERT-B 用 p = (10000, 2286, 704, 275, 129, 70, 41, 27, 18, 13, 9, 7) 在 𝔊(2) 上得到 ρ = 1.318109...

对 ℌ(ϖ)，同样的 p 给出 Rayleigh 商：
```
ρ_ϖ = ⟨v, ℌ v⟩ / ‖v‖² = Q_ϖ / ‖v‖²
```

其中
```
Q_ϖ = Σ_{n,m<12} p_n p_m K_ϖ(n,m) - 2Σ_{n<12} H_n^ϖ p_n²
K_ϖ(n,m) = ϖ²/(|n-m|²+ϖ²) + ϖ²/((n+m+1)²+ϖ²)
H_n^ϖ = Σ_{k=1}^n ϖ²/(k²+ϖ²)
```

这是 p、ϖ 的**有理函数**（分母为整数多项式），可精确计算。

但为简化，本探针使用 h_lo = ϖ²/(1+ϖ²)。

## 6. 解析化路线图

### 6.1 已有的解析成分

1. **重排恒等式**：纯代数，对任意 f ≥ 0 成立
2. **h_lo = ϖ²/(1+ϖ²)**：有理函数
3. **tr B_ϖ² 的级数表达式**：
   ```
   Σ_n [T_ϖ(n) + f(2n+1)]²/(2n+1)² + 2Σ_{n<m} f(n+m+1)²/[(2n+1)(2m+1)]
   ```
   每项是 ϖ 的初等函数（含反正切 arctan(ϖ/k)），可部分和 + 尾界

### 6.2 解析化的障碍

要使 λ₂_hi = √(tr B_ϖ² - h_lo²) 完全解析，需要：

- **T_ϖ(n) 的闭式或紧界**：
  ```
  T_ϖ(n) = Σ_{k>n} ϖ²/(k²+ϖ²) = ϖ²·Σ_{k>n} 1/(k²+ϖ²)
  ```
  这涉及 Polygamma 或 Digamma 函数的有限差分，没有初等闭式。

- **tr B_ϖ² 的部分和 + 尾界**：
  可用 N₁ 项精确和 + 解析尾界（类似层一的引理 4c），但需要对每个 ϖ 分段处理。

### 6.3 可行路线

**证书级**（类似层一 CERT-B）：

1. 选取截断 N₁（如 N₁ = 50）
2. 计算前 N₁ 项的精确和（有理算术）
3. 用解析不等式界住尾项：
   ```
   Σ_{n≥N₁} T_ϖ(n)²/(2n+1)² ≤ [解析上界]
   ```
4. 得到 tr B_ϖ² 的双侧包围（有理数端点）
5. 对每个 ϖ ∈ {0.2, 0.3, ..., 2.0} 给出证书

这是**逐 ϖ 的解析证书**，不是 ϖ 的解析函数，但每个 ϖ 都有有理数端点的严格包围。
