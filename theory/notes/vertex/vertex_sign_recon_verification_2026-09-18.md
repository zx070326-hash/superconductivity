## 1. 问题 4 是错的（两次）

报告 §3 写：

> 顶角核不再是 Herglotz/Pick 族。…`γ = Δ/√(ω²+Δ²)` **不是 Δ 的凹函数** —
> 它在 Δ=0 附近是 `Δ − Δ³/(2ω²) + O(Δ⁵)`，二阶导 ∝ `−3Δ/ω²` 在 Δ>0 为负、
> **但整体符号依赖 ω**。所以核级 Jensen 不适用。

sympy 精确求导：

    ∂²/∂Δ² [ Δ/√(ω²+Δ²) ] = −3Δω²/(Δ²+ω²)^{5/2}

对**一切** `ω ≠ 0` 与 `Δ > 0` 严格为负 ⟹ **`γ^Δ` 在 `Δ ≥ 0` 上严格凹，且关于 ω 一致**。
「符号依赖 ω」不成立：符号只依赖 `sgn Δ`。

真正会变号的是**另一个** γ：

    ∂²/∂Δ² [ ω/√(ω²+Δ²) ] = ω(2Δ² − ω²)/(Δ²+ω²)^{5/2}，  在 Δ = ω/√2 变号

报告把 `γ^ω` 的性质安到了 `γ^Δ` 头上。

**第二重错误（更要紧）**：即使 `γ^Δ` 真的不凹，也与「核级 Jensen」无关。
P4 定理 2 的 Jensen 走的是**声子测度** `P(dω)`：`F_T(k) = ∫ ϖ²/(k²+ϖ²) P(dω)`，
凹性是 `x ↦ x/(k²+x)` 关于 `x = ϖ²` 的凹性。**Δ 根本不是那个变量。**
所以问题 4 既点错了函数、也点错了变量，整条理由作废。

## 2. 问题 2 是错的：线性化后核是矩阵，不是张量

报告 §3 写：「即使线性化到 Δ→0（`Z_m^{(0)}`、`K^V` 矩阵），核仍是 `λ_{m−m′}λ_{m′−m″}`
——这是一个**四指标张量**收缩，不是 `f(|m−m′|)` 的两指标核。」

仓库自己的实现直接否掉这句（`p2_schrodi_fsr.py:328`）：

```python
def kv_delta(lam, C, D):
    """K^V_Δ[m,k] = -λ_{m-k}·[C(m,k)+C(k,m)] + D(m,k)"""
    return -lam * (C + C.T) + D
```

`C`、`D` 都是 `(m,m)`，交叉图的自由指标 `j` 在 `vertex_kernels` 内部就被求和掉了。
**必然如此**：Tc 按定义是线性化本征值问题 `Δ = mat·Δ` 的 `λ_max = 1`，
线性算符作用在 `Δ` 上只能是两指标的。

**真正阻断 P4 的是别的三条**（`_chk_vertex_kernel_structure.py` 实测，n_pos=24/40）：

| 假设 | Migdal 核 Λ | `K^V_Δ` |
|---|---|---|
| Toeplitz（只依赖 `m−k`） | 缺陷 0.00e+00 | **否**，同一对角线内相对散布 ≈ 2.0 |
| 对称 | 是 | **是**（`‖K−Kᵀ‖ = 0`，机器零） |
| 元素定号 | `min = 9e−4 > 0` | **否**，离对角元 `min −8.10 / max +0.13`，正负各半 |
| 沿行随 `\|m−k\|` 单调 | 是 | **否** |

⟹ Abel 分解（引理 A/B 要 `f(|n−m|)` 且 `f` 单调）、锥不变性（推论 B′）确实都用不了。
**报告的结论成立，换掉两条理由即可。**

⚠ 但报告漏了一条**正面**事实：`K^V_Δ` **精确对称**。这意味着变分 / min–max 工具
**没有**随 Abel 机器一起失效——「不兼容」这个平判过重。下一节就靠这条。

### 它买到什么

设 `S(P) = S₀ + P·π³T²·K^V_Δ`，`mat = D₁⁻¹ S D₂⁻¹`，`D₁ = diag(z₀)`、`D₂ = diag(|ω|)`。
若 `S₀` 对称（**μ\*=0 时精确成立**，实测 `‖S₀−S₀ᵀ‖/‖S₀‖ = 0`），取 `X = D₁^{1/2}D₂^{−1/2}`：

    X · mat · X⁻¹ = (D₁D₂)^{−1/2} S (D₁D₂)^{−1/2}  ——对称

（`z₀ > 0` 已验：`min z₀ = 1.0772`。）于是

    **K^V_Δ ≼ 0  ⟹  λ_max(T,P) ≤ λ_max(T,0) 对一切 P>0  ⟹  Tc^{Δ-vertex} ≤ Tc^{Migdal}**

一行变分，**对一切谱、一切温度、一切 Matsubara 频率**，不需要低频近似、
不需要 `⟨s′s″s‴⟩` 的符号、没有 m≥5 反号的缺口。这比版本 1 **强**，而且是**有限矩阵命题**
（`C`、`D` 有显式求和式，见 `vertex_kernels` docstring），不是「符号簿记」。

### 新的版本 1
