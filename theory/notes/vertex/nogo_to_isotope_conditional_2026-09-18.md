## 1. 背景核实（先分清两件事，任务书要求）

`theoremI/delta_channel_immunity_2026-09-16.md` 的**定理 I**（配对通道排斥无法摧毁秩一主导性）
与 `vertex/vertex_sign_recon_verification_2026-09-18.md` 的 **`K^V_Δ ≼ 0`** 是**两个不同对象**：

- 定理 I：任意 `f₋∈𝒫`（正定谱密度）进 Δ 通道的**线性**排斥核 `P[f₋]`，秩一主导性有一致上界 `λ₂(M)≤(1-c₁²)μ₁+c₁²μ₂`；这是关于 **Eliashberg 方程本身**（配对通道核的线性算子）的结构定理，不涉及非绝热顶角修正。
- `K^V_Δ`：Schrödi (2020) FSR factorized 核下、**领头阶非绝热顶角修正**线性化后作用在配对方程上的**对称矩阵**（`-Λ∘(C+Cᵀ)+D`），是 Eliashberg 方程之外的**修正项**，与 Migdal 定理失效相关，与定理 I 的排斥核是完全不同的物理来源。

本文只处理后者（顶角）。前者（定理 I）与本文的关系仅在于：两者都是"Δ 通道只能压低而非增强"型结论，但机制、证明工具、适用范围都不同，**不能互相借用严格性**。

## 2. (A) 条件式预言：从"Tc 单边压低"到"α 位移符号"

### 2.1 为什么"顶角压低 Tc"本身不决定 α 的符号——先把陷阱写清楚

设顶角修正给出 `ln Tc(M) = ln Tc^{Migdal}(M) + δ_Δ(M)`，`δ_Δ(M) ≤ 0`（由 `K^V_Δ≼0` 的单调性，§2.2 复核）。

```
α_total(M) := -d ln Tc/d ln M = α_Migdal(M) - dδ_Δ/d ln M
```

`δ_Δ ≤ 0` 处处成立，**不蕴含** `dδ_Δ/d ln M ≠ 0`。若 `δ_Δ` 是一个与 `M` 无关的常数负偏移（例如某种"处处压低 10%"且压低幅度不随同位素变化），则 `dδ_Δ/dlnM = 0`，**顶角修正对 α 毫无贡献**——这正是 team-lead 任务书点名的陷阱。要让顶角修正影响 α，**必须**找到 `δ_Δ(M)` 本身的质量依赖来源。

### 2.2 质量依赖的入口：`Ω_ph(M) ∝ M^{-1/2}`，不是 `P`

Schrödi FSR 顶角强度由无量纲相空间因子 `P ~ 1/(4E_F^eff)` 控制（`vertex_sign_theorem_recon_2026-09-17.md` §1；`p2_schrodi_fsr.py:264` `p3d_dimensional_estimate`）。`E_F^eff` 是**电子**量——在 Born–Oppenheimer 近似下，晶格离子质量替换（H→D）**不改变电子结构**，故 `P` 对 `M` 的显式依赖可忽略（零阶）。

质量依赖的真正入口是 `K^V_Δ` 内部的声子传播子 `λ(k) = λΩ²/(Ω²+ν_k²)`（`ν_k=2πkT` 松原频率）——`Ω` 是声子频率，谐波近似下 `Ω(M) ∝ M^{-1/2}`。`K^V_Δ` 是 `λ` 的**二次**函数（`C` 含一个 `λ` 因子、`D` 含两个），所以顶角修正项整体正比于 `λ²`（`P2_round2` 已指出"顶角项 ∝ λ² 是领头阶"），而 `λ` 本身既含耦合强度也含 `Ω` 的信息（通过 `ν_k` 的比例）。

**绝热参数论证**（标准物理事实，非本仓定理）：Migdal 定理在绝热极限 `Ω/E_F → 0` 精确成立，即顶角修正**必须**在此极限下消失。`Ω(M)∝M^{-1/2}` 是同位素替换改变非绝热参数的**唯一**杠杆（`E_F` 不变）。故：

```
|δ_Δ(M)|  是  Ω(M)  的增函数  ⟹  是  M  的减函数
```

即更重的同位素（更小的 `Ω`、更绝热）顶角修正**更弱**。

### 2.3 符号推导

记 `x(M) := -δ_Δ(M) ≥ 0`（压低的对数份额）。由 §2.2，`x(M)` 是 `M` 的减函数：`dx/dlnM < 0`。

```
Δα_Δ-vertex := α_total - α_Migdal = -dδ_Δ/dlnM = dx/dlnM < 0
```

**⟹ `Δα_Δ-vertex < 0`——顶角修正把同位素指数往负方向推，且推的方向与"轻同位素受压更多"直接对应（H 比 D 被压得更狠，`Tc_H` 相对 `Tc_D` 被拉低，α 变负）。**

这一步除了代数（恒等式）之外，**关键前提是 §2.2 的绝热参数论证**——它不是本仓的定理，是标准 Migdal–Eliashberg 物理（Migdal 1958 的绝热极限论证）。**本文不试图把它升级为 analytic**：它属于"物理输入"，不属于本仓证明机器管辖的对象。

## 4. (B) 可证伪性与数量级

### 4.1 量级估计——两条互相独立的锚点，都不精确，但方向一致

**锚点 1（本仓 FSR 模型，`Delta_only`，线性区）**：`Δα_Δ-vertex = P·(k_H-k_D)/ln(M_D/M_H)`，
`k_H-k_D = −4847-(-3352) = −1495 meV⁻¹`，`ln(M_D/M_H)=0.6923`。取 `P=P_3D=2.60e-4 meV⁻¹`（量纲估计）：

```
Δα_Δ-vertex ≈ 2.60e-4 × (−1495) / 0.6923 ≈ −0.56    （线性外推，已知在此 P 值处不成立，仅示量级下限）
```

**锚点 2（文献"EPW FSR 目标"，`both` 配置，`δ_H=−0.21, δ_D=−0.15`，本仓视为已确立的外部参照数）**：

```
Δα_(Z+Δ)-vertex = (δ_H-δ_D)/ln(M_D/M_H) = (−0.21+0.15)/0.6923 ≈ −0.087
```

这是 **Z+Δ 两通道合并**的效应（Z 通道升 Tc、部分抵消 Δ 通道），不是纯 Δ 通道；
按本仓已确立的"Δ 通道约 2× 主导"（`P2_round2` §0），纯 Δ 通道分量应比 `−0.087` 更负。

**⟹ 数量级判断：`|Δα_Δ-vertex|` 在 `0.05–0.6` 之间，中心估计 `~0.1–0.3`**——

### 4.3 与 PdH 判别性测试线的可分离性——反直觉的关键发现

## 5. (C) 轻量侦察：`K^V_Δ ≼ 0` 升到 analytic 大概要证什么

**结构**（`vertex_sign_recon_verification_2026-09-18.md` §3 已证 analytic）：
`K^V_Δ = -Λ∘(C+Cᵀ) + D`，`Λ` 是 `λ(a-b)` 的 Toeplitz 矩阵，
`C(a,b) = Σ_j λ(a-j)s(j)s(j+b-a)`，`D(a,b) = Σ_j λ(a-j)λ(j-b)s(j)s(a+b-j)`，`s(n)=sgn(2n+1)`
（在 FSR 的 `m≥0` 索引下 `s≡+1`，符号因子退化为平凡）。

**要证的命题**：对一切 `λ_pos≥0` 对应的 `λ(k)=λΩ²/(Ω²+k²)`（即 `λ∈𝒫` 的 Toeplitz 符号族）与一切有限截断 `N`，
`K^V_Δ ⪯ 0`。

**候选工具**：
1. **Bochner/Toeplitz 正定性**（定理 I 引理 1 已用过）：`Λ` 本身作为 `𝒫`-核的 Toeplitz 矩阵是 **PSD**（`λ̂(θ)≥0`）。
2. **Schur 积定理**：若能独立证明 `C+Cᵀ ⪯ 0`，则 `Λ∘(C+Cᵀ) ⪯ 0`（Hadamard 积：PSD 与 NSD 的积保 NSD），
   从而 `-Λ∘(C+Cᵀ) ⪰ 0`——**这个方向对我们不利**（把 `K^V_Δ` 往正的方向推），
   所以真正需要证明的是 **`D` 的负定性压过 `-Λ∘(C+Cᵀ)` 的正定性**，或者 `C+Cᵀ` 其实不是定号的、
   需要更细的联合估计（类似定理 I 引理 4 把两个通道的贡献放在一起算，而非分别定号再相加）。
   **这一步没有捷径**：`C+Cᵀ` 的符号需要单独核实（本文未算），若它是 PSD 而非 NSD，
   Schur 积路线直接失败，退回需要联合处理 `-Λ∘(C+Cᵀ)+D` 整体。
3. **`λ⋆λ` 的 Bochner 结构**：`D` 里的双重卷积 `Σ_j λ(a-j)λ(j-b)` 对应序列 `(λ⋆λ)(k)` 的 Fourier 符号
   `λ̂(θ)² ≥ 0`——**这个符号本身总是非负**，与 `𝒫` 无关，是 `λ⋆λ` 自动落在"非负符号"核类的直接推论。
   这提示 `D`（去掉符号因子 `s`、去掉有限截断的边界效应）在**无穷**索引下会是某个 PSD Toeplitz 算子的主压缩，
   与定理 I 引理 2 的"reflection 压缩" 技术路线相似——但 FSR 的索引集 `m≥0` **没有**定理 I 用的
   `ℤ` 上偶延拓对称性（那里 `X_{-1-n}=x_n` 靠 Matsubara 频率的奇性），这里的边界处理需要重新做。
