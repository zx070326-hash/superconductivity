## 1. 「净压低 Tc」目前是什么级别的结论？

**严格性：numerical-evidence**（P2 §5.6，`p2_schrodi_fsr.py`）

已验证参数范围：
- H3S/D3S @ 200 GPa：λ=1.72, ω_log=110 meV, E_F^eff≈0.96 eV（DOS 缺损反推）
- Einstein 单模校验（对照组）
- 线性响应 P→0 极限（两个 P 值 1e-6/1e-5 给一致斜率）

**数值结果**（Schrödi FSR factorized 核）：
```
         Z-only    Δ-only    两通道    Δ/Z 倍数
H3S      +2333     −4847     −2506      2.08
D3S      +1676     −3352     −1675      2.00
```

三个定性事实（numerical-evidence 级）：
1. **Z 通道升 Tc、Δ 通道压 Tc、净效应为负** — 符号与 EPW FSR（δ_H=−0.21）一致
2. **同位素比 δ_D/δ_H ≈ 0.67** — 与 EPW 0.71、M^{-1/2}=0.707 相容
3. **量级过估 3–4×**（Mishra 2507 指出 factorized 核比精确双频 λ^V 大 3–4 倍）— 不作定论

**已知反号区**（Schrödi 2020 原文，p.9）：
- 强非绝热（α = ω_ph/E_F 大）时顶角修正**可正可负可忽略**，依赖维度与动量结构
- MgB2 σ 带（2D、小费米面）：顶角**增强** Tc 1.0–2.5× — 动态区（小 q 前向散射）主导
- Pb（常规金属、平 DOS）：顶角修正对 Tc **无影响**（7.2→7.2 K）

**参数区边界**：H3S 的「压制」结论在**各向同性 FSR + factorized 核**下成立。Schrödi 完整解（全带宽、动量分辨）发现顶角函数**不是小 q 峰化的**，且 α 越大越正、越各向同性 — 与 PGS 一阶图像**相反**。所以 numerical-evidence 的有效范围是「FSR 近似对氢化物适用」这个前提内，Schrödi 自己说 FSR "severely underestimates" 顶角效应。

**结论 Q1**：净压低 Tc 在 H3S 参数区的 numerical-evidence 是稳健的（符号 + 同位素比），量级因 factorized 核过估不定量。反号区（MgB2 型 2D 小费米面）与无效应区（Pb 型平 DOS 大 E_F）都在**氢化物参数区之外**。但这是「FSR + factorized 核」的结论，不是「自洽全带宽解」的结论 — 后者在强非绝热区可能反号（Schrödi 原文）。

## 2. 符号定理的精确数学陈述该怎么写？

**候选陈述 A（最强，likely 为假）**：
> 对所有各向同性电声谱 P∈𝒫 与温度 T，Pietronero–Grimaldi 一阶顶角修正（crossed diagram, Fig. 1(b) of Schrödi 2020）对线性化 Eliashberg Tc 的净效应 ≤ 0，即 Tc^{vertex} ≤ Tc^{Migdal}。

**为什么可能为假**：MgB2 σ 带反例（2D）；Schrödi 原文明说可正可负。

**候选陈述 B（受限到 3D 氢化物参数区）**：
> 在 3D、各向同性、费米面限制（FSR）近似下，对满足 ω_log/E_F^eff ≳ 0.1（非绝热参数）且 E_F^eff 由费米面附近 DOS 缺损决定的体系，一阶顶角修正的 Z/Δ 两通道净效应使 Tc 降低，降低量标度为 λ² · (正的相空间因子) · f(ω_log/E_F^eff)。

**问题**：
- 「E_F^eff 由 DOS 缺损决定」这句在 P2 §5.5 被证明**无机制支持** — DOS 缺损泛函 (5.1) 的数值吻合是巧合
- f 的具体形式未知（factorized 核给的过估 3–4×）
- 「领头阶」是对什么小量展开？P2 §5.2 的 δ = s_λ λ P̄ 已是 λ 的**二阶**（顶角项 ∝ λ²），所以「领头阶」= λ² 项

**候选陈述 C（可证版本，价值存疑）**：
> 在 Schrödi FSR factorized 核模型（Eq. 23–24）下，对 Einstein 谱 δ_ω，若相空间因子 P > 0，则配对通道（Δ）的顶角修正对 Tc 的效应为负，且其绝对值大于重整化通道（Z）的正效应。

**这个版本的问题**：
- 只对 factorized 核成立（已知过估）
- 只在线性响应 P→0 内验证过
- 陈述里的「本征值」还是「配对能隙」？Schrödi 求解的是 Δ_m，Tc 由 Δ→0 判据定义

**我的建议陈述（诚实版）**：
> **定理（条件于 FSR + factorized 核）.** 在各向同性、费米面限制的 Eliashberg 框架内，若电声耦合核 factorized 为 λ_{m−m′}λ_{m′−m″}，则一阶顶角修正（Schrödi Eq. 19）对配对能隙 Δ_m 的净效应使 Tc 降低，原因是配对通道修正（Eq. 24 的四项和）主导且为负。

**展开的小量**：顶角项系数 P（量纲 [能量]^{-1}，数量级 1/(4E_F^eff)）；线性响应在 P·T² 对 T² 展开到一阶。

**「降低 Tc」= Δ_m 在所有 Matsubara 频率 m 上被压制 ⟹ Δ→0 的温度升高 ⟹ Tc 降低。**

## 3. 它和 P4 算子结构兼容吗？

**核心回答：不兼容。这是最有价值的发现。**

### P4 算子结构的承重假设

P4 的机器建立在算子 𝒪[f] 上（P4_main_theorems.md §0）：

```
𝒪[f] := −L1[f] + L2[f] + L3[f]
L1 对角、L2/L3 非对角，f: ℕ_{≥1} → ℝ
核 F_T(k) = ∫ ϖ²/(k²+ϖ²) P(dω)，ϖ = ω/(2πT)
```

**关键性质**（引理 M 的前提）：
1. **F 非增**（因 x/(k²+x) 对 k 递减）
2. **F ∈ ℓ¹**（因 ≤ ⟨ϖ²⟩/k²）
3. **𝒪[F] 的 λ₁ > 0 且是本征值**（因 F(1) > 0）
4. **核 F 是 Herglotz/Pick 函数族的 Stieltjes 积分** — x/(k²+x) 于 x 严格凹

这四条让引理 M（核单调性）与定理 2（Einstein 极值，核级 Jensen）成立。整套定理的逻辑是：**核的序 ⟹ 本征值的序**。

### 顶角修正的核结构

Schrödi FSR 的顶角修正核（Eq. 23–24）：

```
Z_m = 1 + (πT/ω_m)Σλ_{m−m′}γ_{m′}^{ω} 
      + P·(π³T²/ω_m)Σλ_{m−m′}λ_{m′−m″}·(四个 γ 三次项)

Δ_m = (πT/Z_m)Σλ_{m−m′}γ_{m′}^{Δ}
      + P·(π³T²/Z_m)Σλ_{m−m′}λ_{m′−m″}·(另四个 γ 三次项)
```

其中 γ^{ω} = ω/√(ω²+Δ²)、γ^{Δ} = Δ/√(ω²+Δ²)。

**问题 1**：顶角项是 **λ·λ 的双重和**，不是 ∫f(k)P(dω) 的单重积分形式 — **不能写成 𝒪[F] 的形式**。

**问题 2**：即使线性化到 Δ→0（Z_m^{(0)}、K^V 矩阵），核仍是 **λ_{m−m′}λ_{m′−m″}** — 这是一个**四指标张量**收缩，不是 f(|m−m′|) 的两指标核。

**问题 3**：Z 通道与 Δ 通道的核**不同**（Eq. 23 vs 24 的括号内四项不一样）— P4 的 𝒪[f] 对所有通道用**同一个 f**。

**问题 4**（最致命）：顶角核不再是 Herglotz/Pick 族。Schrödi Eq. 24 的四项是 γ^{Δ/ω} 的三次单项式，而 γ = Δ/√(ω²+Δ²) **不是 Δ 的凹函数** — 它在 Δ=0 附近是 Δ − Δ³/(2ω²) + O(Δ⁵)，二阶导 ∝ −3Δ/ω² 在 Δ>0 为负、但整体符号依赖 ω。所以**核级 Jensen 不适用**。

### 能否扩展 P4 框架？

**路线 A**：把 𝒪[f] 推广到双指标核 𝒪[K]，K(m,m′)。
- **障碍**：引理 A/B（矩形部分和正性、Kamke 拟单调）的证明用了 f(|n−m|) 的对称性与 f(k) 的单调性 — 对一般 K 两者都没有
- **Abel 分解失效**：推论 B′（半群保锥）需要 F = Σ_K (F(K)−F(K+1))·1_{k≤K}，这要求核只依赖 |m−m′| 的差

**路线 B**：证明顶角修正后的**总核** F_total = F_Migdal + F_vertex 仍在 P4 的核类里。
- **问题**：F_vertex 是 λ·λ 双重和，不能写成 ∫⟦k⟧(ϖ)P(dω) — 除非做「等效单频谱」近似，但那正是 factorized 核被 Mishra 指出过估 3–4× 的原因

**路线 C**（最有希望但仍困难）：只证「Δ 通道顶角修正为负」，不管 Z 通道，不用 P4 框架。
- 这回避了「两通道竞争」的复杂性
- 但 Δ 通道的核仍是四指标张量，引理 M 不适用
- 需要一个新的「张量核单调性」定理 — **这是值得投入的地方，但不是几周的工作**

**结论 Q3**：顶角修正的核**不在 P4 算子类 𝒪[f] 里**，差在：(1) 双重和 vs 单重积分；(2) 四指标 vs 两指标；(3) 两通道核不同；(4) 不是 Pick 函数的积分。P4 整套定理（引理 M、定理 2、引理 C）**不能直接继承**。扩展 P4 框架需要推广 Abel 分解与锥不变性到张量核 — 这是结构性困难，不是技术困难。

**证据**：`p2_schrodi_fsr.py` 的线性响应斜率
**价值**：已完成，是后续的起点

### 版本 1（最易，analytic，价值有限）★推荐先做这个
**陈述**：在 Schrödi FSR 线性化方程（Δ→0）下，配对通道顶角核 K^V_Δ 的四项和在低频 Matsubara 点上的符号为负。
**方法**：P2 §5.6 已给出 s′s″Δ‴/|ω‴| 型的符号分析 — 把它变成严格不等式
**难度**：解析推导，主要是符号簿记

**投入**：1–2 周（主会话 + reviewer）

### 版本 2（中等，只在弱耦合）
**陈述**：当 λ ≪ 1 时，一阶顶角修正 δTc/Tc ∝ −λ² · (正系数) · f(ω/E_F)。
**方法**：在 λ→0 极限下 Z_m → 1、γ^{Δ} → 0，线性化方程简化，可能得到显式符号
**难度**：需要控制 λ² 项的系数，P2 §5.6 的 McMillan 型估计是这个方向
**价值**：覆盖 Pb（λ=1.29，顶角无效应）与 H3S（λ=1.72，顶角显著）之间的过渡
**投入**：4–6 周

### 版本 3（困难，推广 P4 到张量核）
**陈述**：对双指标核 K(m,m′) = Σλ_{m−m′}λ_{m′−m″}·g(m″)（g≥0），若 K 满足某种「张量单调性」，则 λ₁(𝒪[K]) 关于 K 单调。
**方法**：尝试推广 Abel 分解到 K — 这是 P4 引理 M 的核心，但对张量核未知能否做
**难度**：结构性创新，可能需要新的锥分解
**价值**：若成功，能把 P4 全套定理推广到顶角修正；是「几个月」级的目标
**投入**：3–6 个月（不保证成功）

### 版本 4（最难，自洽解）
**陈述**：Schrödi 完整方程（Eq. 23–24，非线性）的自洽解满足 Tc^{vertex} < Tc^{Migdal}。
**方法**：不动点定理 + 隐函数定理，或者变分不等式
**难度**：γ^{Δ}(Δ_m) 的非线性使方程是 implicit 的，需要新的分析工具
**价值**：这才是「定理」该有的完整性，但远超出当前工具箱
**投入**：≥ 1 年（博士论文级）

**结论 Q4**：最小可证版本是**版本 1**（factorized 核下配对通道符号，1–2 周）。它把 P2 §5.6 的 numerical-evidence 升到 analytic，但不触及 Z 通道竞争、不推广 P4 框架。版本 2（弱耦合，4–6 周）有独立物理价值（覆盖 Pb 到 H3S 过渡）。版本 3（张量核单调性，3–6 个月）是「值得几个月」的唯一候选，但不保证成功。版本 4 是博士论文，不是这个项目的范围。

## 5. 对「该不该投入几个月」的判断

**我的建议：不投入。** 理由如下：

### 理由 1：符号定理对核心论题的贡献比预期弱

PROGRAM.md §0 的核心论题是：
> 高压氢化物让 Eliashberg 四个前提**同时**逼近失效 ⟹ 我们在一个**自己正在失效的理论内部**证了天花板 ⟹ 结构性张力。

符号定理只解除**一个**前提（Migdal）。即使证出「领头阶顶角只降 Tc」，其余三个前提（非谐、μ* 重整化、DOS 非恒定）仍然失效 — **天花板仍在失效边缘内部**。所以符号定理不能把 P4 从「关于模型的定理」升级为「关于自然的定理」— 它只把「四个失效前提」减少到「三个失效前提」，张力依然存在。

### 理由 2：numerical-evidence 已足够支撑论文

P2 §5.6 的数值结果（符号 + 同位素比与 EPW 一致）已经是可发表的 finding。升级到 analytic 的增益是：
- **不是**从「可能错」变成「一定对」— numerical-evidence 在其参数范围内是可复现的
- **是**从「只对 H3S 验证过」变成「对满足某些条件的体系成立」— 但这些条件（FSR + factorized 核）本身就是近似

而代价是 3–6 个月（版本 3）且不保证成功。论文可以诚实地写：
> "We numerically demonstrate that leading-order vertex corrections lower Tc in H3S under the FSR approximation with factorized kernel (Schrödi 2020). The sign and isotope ratio are consistent with EPW full-bandwidth results. An analytic proof for the tensor-kernel case remains open."

这已经是对纲领的贡献 — **定量验证了「顶角修正在氢化物参数区为负」这个长期悬而未决的问题**。

### 理由 3：版本 3 的风险/收益比不佳

版本 3（推广 P4 到张量核）的风险：
- **可能做不出来**：Abel 分解依赖核的对称性与单调性，张量核两者都没有 — 可能根本不存在类似的分解
- **即使做出来，应用范围窄**：只对 factorized 核成立，而 Mishra 已指出它过估 3–4× — 所以定理的物理相关性有限

收益：
- 把 P4 框架推广到更一般的核 — **这是方法论贡献，不是物理贡献**
- 对氢化物 Tc 预测的改进：无（numerical-evidence 已足够）

### 理由 4：有更高杠杆的方向

P4 six-direction round（memory/p4-six-direction-round-2026-09-15.md）列的方向里，以下几个的**杠杆更高**：
- **γ-model Coulomb 方向**（D4）：Anderson–Morel 屏蔽 + 无拟合氢化物 Tc — 这是**定量可测**的
- **弱耦合 secular series**（D5）：T_c = 0.253ω_E e^{-1/λ}(1+0.358λ) — 这是**解析**的且 Mishra 已在用
- **μ*>0 极值性的物理区域**（`mustar_extremality_failure_map_2026-09-17.md`）：窗内定理已接近闭环，跨窗规则性是剩余缺口

这些方向要么解析闭环（D5）、要么定量可测（D4、μ*窗内），都比「把 numerical-evidence 升到 analytic（在已知过估的 factorized 核假设下）」的增益大。

### 但如果一定要做，先做版本 1

版本 1（配对通道符号，1–2 周）是**低风险高确定性**的：
- P2 §5.6 已给出符号分析的骨架（s′s″Δ‴/|ω‴| 项）
- 只需把「低频处 ⟨s′s″s‴⟩ ≈ 正」变成严格不等式
- 不触及张量核推广的结构性困难

它的价值是把 P2 从「mechanism resolved (numerical)」升到「mechanism proved (analytic, under factorized kernel)」— 这对论文叙事有帮助，虽然物理结论不变。

## 6. 附录：P2 当前状态的诚实边界

为避免过度乐观，列出 P2 §5.6–5.7 的**已知限制**：

1. **FSR 近似的适用性未验证**：Schrödi 原文说 FSR "severely underestimates" 顶角效应 — 意思是 FSR 给的数值比全带宽解**小**，但方向可能一致。P2 没有做 H3S 的全带宽解来验证这一点。

2. **factorized 核过估 3–4×**：Mishra 2507 明确指出，需要精确双频 λ^V(iω,iω′) — P2 用的 λ_{m−m′}λ_{m′−m″} 是过估。所以 P2 的量级（δ_H = −0.21 in factorized vs −0.095 in EPW）**不能**当作「理论预测与实验比较」。

3. **动量结构被积掉了**：P2 §5.5 证明各向同性一阶顶角的 Eliashberg 平均 P̄_eff **恒正**（除非用偏大 q 权重）— 负号来自 Z/Δ 两通道结构，**不是**顶角函数 P(Q,ω_q) 本身。但 Schrödi 完整解发现顶角函数**不是 Q 峰化的** — 所以 P2 的「两通道解释」可能只在 FSR 内成立。

4. **LaH10 反常未解决**：P2 §5.3 用 DOS 缺损泛函判断 LaH10 顶角仍为压制型（约 H3S 一半）— 所以顶角不能把 α 推过 ½。但 §5.3 的泛函在 §5.5 被证明**无机制支持**，所以这个判断的置信度降低。

5. **MgB2 增强机制未整合**：MgB2 σ 带的顶角增强（Cappelluti 2002）来自 2D + 小 q 动态区 — P2 承认这是「式 (5.1) 适用边界另一端」，但没有统一的判据能同时预测 H3S（压制）与 MgB2（增强）。

**结论**：P2 解决的是「为什么 H3S 的 EPW FSR 顶角为负」（答案：Δ 通道主导），**不是**「领头阶顶角在所有体系都压低 Tc」（这个全称陈述为假）。所以符号定理即使证出来，也只能是「在满足某些条件的体系里」— 而这些条件的边界尚未清楚。

## 总结：四个问题的答案

**Q1. 净压低 Tc 目前是什么级别？**
- numerical-evidence（H3S/D3S @ FSR + factorized 核）
- 符号 + 同位素比与 EPW 一致，量级过估 3–4× 不定量
- 反号区（MgB2）与无效应区（Pb）在氢化物参数区外

**Q2. 精确数学陈述？**
```
定理（条件于 FSR + factorized 核）：
在各向同性、费米面限制的 Eliashberg 框架内，
若电声耦合核 factorized 为 λ_{m−m′}λ_{m′−m″}，
则一阶顶角修正对配对能隙的净效应使 Tc 降低，
因配对通道修正主导且为负。
```
展开的小量：P（相空间因子，∼1/E_F^eff）
「降低 Tc」= Δ_m 被压制 ⟹ Tc 降低

**Q3. 与 P4 算子结构兼容吗？**
- **不兼容**（最重要发现）
- 顶角核是四指标张量（双重和），P4 的 𝒪[f] 是两指标（单重积分）
- Z/Δ 两通道核不同，P4 用同一个 f
- 顶角核不是 Pick 函数积分，核级 Jensen 不适用
- 推广需要「张量核 Abel 分解」— 结构性困难

**Q4. 最小可证版本？**
1. **版本 1**（1–2 周）：factorized 核下配对通道符号 — analytic
2. **版本 2**（4–6 周）：弱耦合 λ ≪ 1 — 覆盖 Pb 到 H3S
3. **版本 3**（3–6 个月，不保证成功）：张量核单调性 — 推广 P4
4. **版本 4**（≥ 1 年）：自洽解的不动点定理 — 博士论文级

**我的判断：不投入几个月。**
- numerical-evidence 已足够支撑论文
- 符号定理只解除一个失效前提（Migdal），核心张力仍在
- 版本 3 风险高（可能做不出来）且收益有限（只对 factorized 核）
- 有更高杠杆方向（γ-model、弱耦合 secular、μ* 窗内）
- **若一定要做，先做版本 1**（1–2 周，低风险）
