# 探针：Tc 上界 ↔ 计算复杂度下界——2 小时快扫

**任务来源**：team-lead 派发的投机探针，猜想「Tc 上界本质是计算复杂度下界：找基态 = NP-hard，我们证明 Tc 有严格上界 = 存在多项式时间可验证的证书」。
**结论：(b) 无根据，放弃。** 下面是判断依据，按团队要求的四步给出。

---

## 1. 复杂度理论快扫

- **局域哈密顿量问题（Local Hamiltonian Problem）是 QMA-complete**（Kitaev 1999；Kempe–Kitaev–Regev 5-local 版；后续压到 2-local、1D 8-态版）。这是「NP 的量子类比」——判定基态能量是否低于/高于阈值。真实、成熟的结果。[arXiv:0704.3142](https://arxiv.org/abs/0704.3142)
- **谱隙判定问题在一般平移不变哈密顿量族上是不可判定的**（Cubitt–Pérez-García–Wolf, *Nature* 2015；1D 版 Bausch–Cubitt–Lucia–Pérez-García 2020）。这是目前物理常数/多体问题与计算理论最硬的已知联系——但结论是**不可判定性**，不是「Tc 编码了某个具体复杂度类常数」。[Nature 528, 207](https://www.nature.com/articles/nature16059)
- **随机 k-SAT 的可满足性阈值**是统计力学相变问题（Mézard–Parisi–Zecchina 一系），用 replica 方法把 SAT 实例映射为稀释自旋玻璃的零温基态，阈值 α_c(3)≈4.3 是这条线上最有名的常数。这是「统计物理方法研究组合优化」的真实、成熟范式——但对象是**自旋玻璃/约束满足**，不是配对/Eliashberg 核。
- **没有找到**任何将 Lovász θ、Ramsey 数、或其他组合复杂度常数与 BCS/Eliashberg 型 Tc 直接联系的文献。这类常数出现在图论极值问题（独立数上界、超图染色）里，与本项目 Tc 上界的解析来源（谱核最大本征值）在结构上不同源。

**判断**：真实存在的桥梁——(a) 局域哈密顿量 QMA-hard，(b) 谱隙不可判定，(c) SAT 统计力学——都要求哈密顿量族带**可调的组合/图结构**（多体相互作用图、任意局域项）才能编码困难实例。这是关键筛选条件，见第 2 节。

## 2. 编码尝试：P4 的核能不能装下 3-SAT？

看了本仓库 P4 (KAY) 实际在证什么（`theory/derivations/INDEX.md` §4）：Tc 上界的证明对象是一个**固定形式的自伴积分核**（Eliashberg-型配对核，库仑项是显式**秩一**半正定算子 𝔎_c=2|u⟩⟨u|），"实例"只是几个连续标量参数（λ、μ*、谱函数 P(ω) 的矩）。整条证明链条——引理 M（核单调性）、定理 E（Einstein 极值）、𝔤(2) 解析化——把「对所有谱 P 求 sup」这个看似无穷维的问题**解析地约化**成显式闭式或几十/几千步区间算术检查（见 `P4_interchange_uniformity.py`：1668 检查、112.5 秒；`P4_g2_analytic.md`：纯有理数精确算术）。

这直接说明两件事：

1. **没有可调的组合自由度可供编码。** QMA-hardness / SAT 构造都需要「许多相互作用的局域自由度、结构任意可选」才能把 3-SAT 的子句-变量关联图塞进哈密顿量。P4 的核是解析确定、单参数族（本质是 λ、μ*、⟨ω²⟩ 等矩量），没有位置可以塞入任意 3-SAT 实例的子句结构。
2. **该问题本身在 P 里，而且已经被本项目自己解出来了。** 定理 2′（矩量阈值定理，p≥2 iff）、定理 E（Einstein 谱极值）把"对任意谱函数求 Tc 上确界"这个本来看起来像变分/组合优化的问题，规约成了对一个显式表达式的求值——这是"难问题→易问题"的**反向**证据：如果这类 Tc 极值问题真的编码计算困难性，就不该存在这种解析塌缩。

结论：尝试编码 3-SAT → 配对哈密顿量 → Tc 失败，不是因为没想到技巧，而是**P4 的数学对象本身没有可编码结构的自由度**（它是低维矩量泛函，不是任意图上的多体相互作用）。Richardson–Gaudin 型可积配对模型是这条线上唯一稍微沾边的严肃结构，但可积性恰恰意味着"容易"（多项式时间可解），跟 NP-hard 反着走。

## 3. 常数对比

- C_∞ = (1/2π)√𝔤(2) ≈ 0.18273：来源是本项目 §4.1 的 𝔤(2) 解析双侧界（1.3181093–1.3181616），本质是某个显式级数/积分核范数的闭式值。
- 复杂度理论里的常数（Lovász θ 函数值、Ramsey 数 R(k,k) 的增长率常数、SAT 阈值 α_c(k)）都来自**离散组合结构的极值**（图不变量、超图密度阈值），量纲和生成机制与「自伴积分算子的谱范数」完全不同源。
- 没有数值上的巧合（做了粗略量级对比：0.18273 vs 已知的 α_c(3)/10≈0.43、θ 函数典型值量级也不搭），也没有结构性理由期待重合。

**判断**：常数层面无证据，纯属不同数学宇宙的对象。

## 4. 可证伪性检验

若「Tc 编码复杂度」为真，最起码应该有：**评估某族 Tc（或临界 λ_c）对某类可调谱结构 P(ω) 的复杂度会随着谱的组合复杂度（例如离散化点数/模式数 N）超多项式增长**，或者存在某个特定谱族使 Tc 判定本身成为已知 NP-hard 问题的实例。

设计的小实验（未执行，评估层面已经能判断不必做）：取离散化 α²F 为 N 个 δ 函数模式的直方图，把"是否存在权重分配使矩量 (⟨ω⟩,⟨ω²⟩) 落在给定区间且 Tc>阈值"当作一个约束满足问题——但**本项目的定理 2′、定理 E 已经给出这个问题的解析刻画**：极值谱（对固定矩量约束下的 Tc sup）就是 Einstein 谱（单模式），复杂度在模式数 N 上是 O(1)（跟 N 无关，因为极值总在退化到单模的角点取得）。也就是说，如果真去做这个实验，**这里的证据是先验地指向"否"**：本项目自己的核心定理就是这个问题的多项式时间闭式解。

## 结论与建议

**(b) 无根据，放弃。** 三条真实存在的物理↔复杂度桥梁（QMA-hard 局域哈密顿量、谱隙不可判定性、SAT 统计力学）都依赖哈密顿量族带**任意可调的组合/相互作用图结构**；P4 的 KAY 算子是解析确定的低维矩量泛函，没有这种自由度，且项目自身的极值定理已经把"对任意谱求 Tc 上确界"规约为多项式时间可解的闭式问题——这是朝着"容易"而非"困难"方向的强证据，而非中性证据。常数层面（C_∞ vs Lovász θ / Ramsey / SAT 阈值）无重合、无结构理由。

**不建议深挖。** 如果团队将来想认真做"超导 ↔ 计算复杂度"这个方向，唯一有实质内容的切入点是**弗拉斯特化配对模型 / 自旋玻璃型 BCS**（带任意随机耦合矩阵的配对哈密顿量，而非本项目的解析确定核）——但这是一个与当前 P4 无关的全新研究项目，不是 P4 证明技术的自然延伸，不建议在当前分支下继续投入。
