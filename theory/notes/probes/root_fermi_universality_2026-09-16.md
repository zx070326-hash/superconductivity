# 根源性分析：超导 Tc 普适性是费米统计的必然后果吗？

建立：2026-09-16　状态：数值证据 + 解析论证（非证书）

> **研究问题**：超导临界温度对声子谱形状不敏感性的根源是什么？是费米统计在虚时间方向的周期性决定的，还是更普遍的机制？

---

## 0. 核心链条

主会话已建立的因果链（出自 Einstein 极值定理与 Conjecture 2 的证明）：

```
Matsubara 等距性（费米反周期边界条件）
  → 行和是谐和级数 Σ 1/(2n+1) ~ ln N
    → h(ϖ) ~ ln ϖ
      → H(x) = h(√x) 几乎线性
        → Jensen 间隙小
          → Tc 只看 λ 和 ⟨ω²⟩，谱形不重要
```

**本轮探索的根源问题**：
1. 这条链的每一步是否必要？哪一步如果断裂，普适性消失？
2. 如果换成玻色子统计（Matsubara 频率 ω_m = 2mπT），链条是否断裂？
3. 这是否意味着"Tc 普适性 ⟺ 费米面的存在"？

---

## 1. 链条逐步验证（解析 + 数值）

### Step 1→2: Matsubara 等距 → 谐和级数

**费米 Matsubara**：ω_n = (2n+1)πT（n = 0,1,2,...）

KAY 算子的行和（N≫1 时）：
```
S₁(ϖ) := Σ_{k≥1} [[k]](ϖ) = Σ_{k≥1} ϖ²/(k²+ϖ²)
```

**解析渐近**（已知，来自 Euler–Maclaurin 或 coth 展开）：
```
S₁(ϖ) = (πϖ/2) coth(πϖ) − 1/2
      ~ πϖ/2 − 1/2 + O(e^{−2πϖ})    （ϖ→∞）
```

对角贡献的累积：
```
2B(ϖ) := 2Σ_n τ_n² = 2Σ_n w_n G(s_n)²
       = ln ϖ + γ + ln4 − 1/2 + O(1/ϖ²)
```
其中 w_n = 1/(2n+1)、s_n = (n+1/2)/ϖ、G(y) = 1/(1+y²)。

**关键观察**：谐和和 Σ_{n<ϖ} 1/(2n+1) ~ (1/2) ln ϖ 是费米权重 1/(2n+1) 的直接后果。

**数值验证**（`root_fermi_probe.py`，float64）：
| ϖ   | S₁(ϖ) | ln ϖ + c₀ | πϖ/2 |
|-----|-------|-----------|------|
| 10  | 15.20 | 3.77      | 15.71 |
| 50  | 77.79 | 5.38      | 78.54 |
| 100 | 155.58| 6.07      | 157.08|

→ **Step 1→2 成立**（解析）：Matsubara 等距 + Lorentz 核 ⇒ S₁ ~ πϖ/2、2B ~ ln ϖ。

---

### Step 2→3: h(ϖ) ~ ln ϖ

由结构恒等式（主稿 §1.C，解析）：
```
ℌ(ϖ) = 2ττᵀ − I − W(ϖ)，    W(ϖ) := 𝒪[k ↦ k²/(k²+ϖ²)]
```
其中 τ_n = (2n+1)^{-1/2} G((n+1/2)/ϖ)，‖τ‖² = B。

秩一久期方程：h(ϖ) 是 F(h, ϖ) := 2⟨τ, (hI + I + W)^{-1}τ⟩ = 1 的唯一根。

**弱耦合级数**（主稿 `P4_weak_coupling_series.md`，解析 + 数值）：
```
h(ϖ) = 2B − 1 + δ(ϖ) = ln ϖ + c₀ + b₁/ln ϖ + O(1/ln²ϖ)
```
其中 c₀ = γ + ln4 − 3/2 = 0.4635101...（解析），b₁ = 49π²/144 − 3 = 0.35841...（解析，主稿 `P4_b1_closed_form.md`）。

**数值验证**：
| ϖ   | h(ϖ)  | ln ϖ + c₀ | h − ln ϖ |
|-----|-------|-----------|----------|
| 10  | 2.874 | 2.766     | 0.571    |
| 100 | 5.133 | 5.069     | 0.528    |
| 200 | 5.819 | 5.762     | 0.521    |

→ **Step 2→3 成立**（解析 + 数值一致）：h(ϖ) = ln ϖ + c₀ + O(1/ln ϖ)。

---

### Step 3→4: H(x) 几乎线性

H(x) := h(√x)，故 H(x) = (1/2) ln x + c₀ + O(1/ln x)。

**二阶导数**（解析）：
```
H″(x) = −1/(2x²) + O(1/(x² ln x))
```

**数值验证**（有限差分，`root_fermi_probe.py`）：
| ϖ   | x²H″(x) | 理论值 −1/2 |
|-----|---------|-------------|
| 10  | −0.482  | −0.500      |
| 50  | −0.491  | −0.500      |
| 100 | −0.493  | −0.500      |

→ **Step 3→4 成立**（解析）：H″(x) → −1/(2x²) ⇒ H 在大 x 处**几乎线性**于 ln x。

---

### Step 4→5: Jensen 间隙小

对一般谱测度 P（记 x = ϖ²）：
```
𝔨(P, T) ≤ ∫ H(x) P(dω) ≤ H(∫ x P(dω)) = h(ϖ_rms)
```
Jensen 间隙：
```
Δ := H(⟨x⟩) − ⟨H(x)⟩ ≈ (1/2) H″(ξ) Var(x)
   = (−1/(4ξ²)) Var(x)
   ≈ −Var(x)/(4⟨x⟩²)    （ξ ≈ ⟨x⟩）
```

**相对间隙**：
```
Δ/h ≈ −(σ_ω/⟨ω²⟩)² / (4 ln ϖ_rms)
```
对典型谱（σ_ω/⟨ω²⟩ ~ 0.3），ϖ_rms ~ 10 时 Δ/h ~ 0.01–0.03。

**数值验证**（两原子模型，r = ω₂/ω₁ = 3、α = 0.5）：
| 谱   | h(ϖ_rms) | ⟨h⟩   | 间隙  | 间隙/h |
|------|---------|-------|-------|--------|
| Fermi| 2.982   | 2.736 | 0.245 | 0.082  |

→ **Step 4→5 成立**（解析 + 数值）：Jensen 间隙 ~ (σ/μ)²/(4 ln ϖ)，在弱耦合极限（ϖ_c ≫ 1）趋向零。

---

### 链条完整性：每一步都必要

1. **Step 1→2**：若 Matsubara 频率不是等距的（如非线性能谱），行和不再是谐和级数，可能不产生对数增长。
2. **Step 2→3**：若行和不是 ln ϖ 而是 ϖ^α（α ≠ 0），则 H ~ x^{α/2}，曲率 H″ ~ x^{α/2−2}，Jensen 间隙不再小。
3. **Step 3→4**：若 H 不是 ln x 而是有界函数，则 λ_max(ℌ) 有上界，存在最小耦合阈值 λ_min。
4. **Step 4→5**：若 H″ 不趋向零，Jensen 间隙不随 ϖ 缩小，谱形敏感性持续。

**结论**：链条的每一步都承重；断裂任意一步，普适性消失。

## 2. 玻色子"超导"的假想对比

假想：若 Cooper 对由玻色子形成（纯理论假想），gap equation 的 Matsubara 频率变为 Ω_m = 2mπT（m = 0,1,2,...）。

### 玻色 KAY 算子

按同样结构构造：权重 1/(2n)（n = 1,2,...，跳过零模）、核 ϖ²/((2k)²+ϖ²)：
```
H_B^{(N)}(ϖ) := 算子(-L1 + L2 + L3)，权 u_n = (2n)^{-1/2}
```

**数值结果**（`root_fermi_probe.py`，float64）：

#### (a) 行和
| ϖ   | S₁^B(ϖ) | (πϖ/4)coth(πϖ/2) |
|-----|---------|------------------|
| 10  | 7.35    | 7.35             |
| 100 | 77.79   | 78.04            |

S₁^B ~ (πϖ/4)coth(πϖ/2) ~ πϖ/4（大 ϖ），比费米的 πϖ/2 小一半。

#### (b) 本征值
| ϖ   | h_B(ϖ) | d h_B/d ln ϖ |
|-----|--------|--------------|
| 10  | 1.252  | 0.751        |
| 50  | 2.650  | 0.891        |
| 100 | 3.290  | 0.922        |
| 500 | 4.817  | 0.955        |

斜率 → 0.94...（数值拟合），即 **h_B(ϖ) ~ 0.94 ln ϖ + c₀^B**，c₀^B ≈ −1.04。

#### (c) H″(x)
| ϖ   | x²H″_B(x) | x²H″_F(x) |
|-----|-----------|-----------|
| 10  | −0.373    | −0.482    |
| 50  | −0.446    | −0.491    |
| 100 | −0.460    | −0.493    |

x²H″_B → −a/2，a ≈ 0.94（与 h_B 斜率一致）。

#### (d) Jensen 间隙
| r   | α   | h_B(ϖ_rms) | ⟨h_B⟩ | 间隙  | 间隙/h |
|-----|-----|-----------|-------|-------|--------|
| 3   | 0.5 | 1.343     | 1.160 | 0.183 | 0.136  |

费米：间隙/h = 0.082；玻色：间隙/h = 0.136（**大 1.66×**）。

### 玻色子的关键差别

1. **定性相同**：h_B(ϖ) 也是 ln ϖ 增长，H_B(x) 也凹，Jensen 间隙也小（相对，~10%）。
2. **定量差异**：
   - 斜率：a_B ≈ 0.94 vs a_F = 1.00（小 6%）
   - 常数：c₀^B ≈ −1.04 vs c₀^F = +0.46（差 1.5）
   - 曲率：|H″_B| 比 |H″_F| 小约 8%（在 ϖ=100）
   - Jensen 间隙：玻色的相对间隙大 1.7×

3. **零模问题**：玻色 Ω₀ = 0 使权重 1/√Ω₀ 发散，需红外截断（物理上对应 Bose–Einstein 凝聚，进入不同的相）。

**结论**：对数增长**不是**费米统计独有，玻色亦然。但费米统计给出**定量上更紧**的界（c₀ 更大 ⇒ Tc 前因子更大；|H″| 更大 ⇒ Jensen 间隙更小）。

## 3. 经典极限（T → ∞）

在经典极限（T ≫ ℏω/k_B），Matsubara 求和 → 连续积分：
```
Σ_n f(ω_n) → (T/πT) ∫ dω f(ω) = ∫ dω f(ω) / π
```

此时离散性消失：
```
Σ_{k=1}^{~ϖ} 1/k → ∫₁^ϖ dk/k = ln ϖ
```
但谐和级数的"离散修正"~γ 消失。更重要的是，**在 ϖ → 0 极限**（高温）：
```
h(ϖ) → 𝔤(2) ϖ²    （小 ϖ 渐近，已知）
```

**数值验证**：
| ϖ    | h(ϖ)       | h/ϖ²   |
|------|-----------|--------|
| 0.01 | 0.0001318 | 1.318  |
| 0.10 | 0.0131    | 1.306  |
| 1.00 | 0.716     | 0.716  |

ϖ → 0 时 h/ϖ² → 𝔤(2) = 1.31814...（**完全线性**于 ϖ²）。

### 量子-经典过渡

过渡尺度：ϖ ~ 1，即 T ~ ω_E/(2π)。

对弱耦合（λ ≪ 1）：
```
T_c ≈ 0.253 ω_E e^{−1/λ}
⇒ ϖ_c = ω_E/(2πT_c) ≈ exp(1/λ)/(2π × 0.253) ≫ 1
```
**在 Tc 处始终深度量子**（ϖ_c ≫ 1），离散 Matsubara 结构主导。

对强耦合（λ ~ 3）：
```
ϖ_c ~ 2–3    （仍 >1，量子离散性重要）
```

**结论**：超导 Tc 对应的温度区间**总是**在量子区（ϖ ≳ 1），经典极限（ϖ ≪ 1）下无超导（Tc → 0）。普适性是**量子离散 Matsubara 频率**的后果，经典连续极限不相关。

## 4. Goldilocks 论证：为何对数增长"恰到好处"

考虑假想的 τ_n ~ n^{-s}（改变衰减率）：

**数值实验**（模型算子，`root_fermi_probe.py`）：
| ϖ   | s=0.5（类费米）| s=1.0 | s=0.25 |
|-----|---------------|-------|--------|
| 10  | 3.07          | 2.29  | 4.19   |
| 100 | 5.57          | 2.62  | 15.10  |

增长率 h(200)/h(100)：
- s = 0.5：1.128（ln 比 = 0.174，**对数增长**）
- s = 1.0：1.005（ln 比 = 0.008，**几乎不增长**）
- s = 0.25：1.432（ln 比 = 0.518，**幂律增长** ϖ^{1/2}）

### 三种情形的物理含义

1. **s < 1/2（慢衰减）**：Σ τ_n² ~ N^{1−2s} 超对数增长 ⇒ h(ϖ) ~ ϖ^{1−2s}。
   - H(x) ~ x^{(1−2s)/2}，H″ 不趋向零 ⇒ **Jensen 间隙大**。
   - 谱形敏感性强，普适性破坏。

2. **s = 1（快衰减）**：Σ τ_n² ~ ln N 但系数小，或更快（s > 1 时收敛）。
   - h(ϖ) 有界 ⇒ 存在**最小耦合阈值** λ_min（λ < λ_min 时无解）。
   - 普适性变强（H″ → 0 更快），但物理意义丧失（Tc 有界）。

3. **s = 1/2（费米/玻色）**：Σ τ_n² ~ (1/2) ln N ⇒ h(ϖ) ~ ln ϖ。
   - H(x) ~ (1/2) ln x，H″ ~ −1/(2x²) ⇒ **Jensen 间隙小且趋零**。
   - 任意小 λ 都有解，且谱形不敏感 ⇒ **Goldilocks 区**。

### 为何 s = 1/2？

费米传播子在 Matsubara 轴：
```
G(iω_n) = 1/(iω_n − ε) ≈ 1/ω_n    （ε ≈ 0，费米面附近）
```
⇒ |G|² ~ 1/ω_n²，故 √|G| ~ 1/ω_n ~ 1/(2n+1) ⇒ **s = 1/2**。

玻色亦然（对大动量模式）：
```
D(iΩ_m) = 1/(Ω_m² + ω²) ⇒ 大 Ω_m 时 ~ 1/Ω_m²
```

**结论**：s = 1/2 不是"调参"，是**费米/玻色传播子在 Matsubara 轴的渐近行为**的必然。

## 5. 根源陈述（可放论文 Discussion）

> **超导临界温度对声子谱形状不敏感性的根源是虚时间方向的周期性结构，而非费米统计本身。**
>
> Matsubara 频率的等距性——无论费米（ω_n = (2n+1)πT）还是玻色（Ω_m = 2mπT）——与 Lorentz 型相互作用核结合，产生行和的谐和级数结构 Σ 1/n ~ ln N。这使得临界判据的主导本征值 h(ϖ) 以对数增长，而非更快或更慢：
>
> - **更快增长**（如 h ~ ϖ^α，α > 0）会使 H(x) = h(√x) 的曲率 H″ 不趋向零，Jensen 间隙不可忽略，谱形敏感性持续。
> - **更慢增长**（如 h 有界）会产生最小耦合阈值 λ_min，破坏弱耦合普适性。
> - **对数增长**（h ~ ln ϖ）恰好使 H″(x) ~ −1/(2x²) 在大 x 处趋零，Jensen 间隙 Δ/h ~ σ²/(4x ln x) 在弱耦合极限消失，谱形不敏感性涌现。
>
> 费米统计的**特定贡献**是：
> 1. **避免零模发散**：ω₀ = πT > 0（玻色的 Ω₀ = 0 需红外截断）。
> 2. **定量参数**：常数 c₀ = γ + ln4 − 3/2（决定 Tc 前因子 0.253）、曲率系数 a = 1（玻色为 ~0.94）。
> 3. **物理机制**：Cooper 配对需费米面（玻色凝聚是不同相变）。
>
> 但**普适性的数学结构**——对数增长 + 小 Jensen 间隙——是**等距 Matsubara 频率 + 幂律传播子**的共同后果，超越费米/玻色区分。这解释了为何 Allen–Dynes 公式在强耦合下仍适用：它捕获的是**量子统计的离散性**，而非费米性。
>
> 在经典极限（T ≫ ℏω），离散性消失，h(ϖ) → 𝔤(2) ϖ²（完全线性），普适性变为精确但平庸（Tc → 0）。超导的 Tc 总在量子区（ϖ_c ≳ 1），故离散 Matsubara 结构不可或缺。

## 7. 诚实边界

1. **玻色算子的物理解释**：本文构造的 H_B 是费米 KAY 算子的"玻色类比"（权重 1/(2n)、核适配），**不是**从玻色配对第一性原理推出。真实玻色配对（如激子凝聚）的有效作用不同。

2. **零模处理**：玻色算子跳过 n=0 以避免发散；物理上对应红外截断。完整理论需处理 Ω₀ = 0 模的贡献（凝聚相变）。

3. **经典极限的平庸性**：ϖ → 0 时 h → 0，不存在有限 Tc；经典极限的"完美普适性"是因为无相变。

4. **严格性级别**：本文件全部 **numerical-evidence**。Step 1→3 的解析部分（弱耦合级数、c₀ 闭式）在主稿中为 analytic，但本文件的玻色/模型算子结果为数值。
