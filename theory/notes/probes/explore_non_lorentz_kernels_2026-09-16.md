## 0. 设定回顾

KAY 的核-通用算子（`P4_main_theorems.md` §0，逐字）：
  𝒪[f] := −L1[f] + L2[f] + L3[f]，
  L1 对角 = (2n+1)⁻¹Σ_{k=1}^n 2f(k)；L2 = (1−δ)f(|n−m|)/√((2n+1)(2m+1))；L3 = f(n+m+1)/√((2n+1)(2m+1))。

Einstein 算子 ℌ(ϖ) := 𝒪[⟦·⟧(ϖ)]，其中 **⟦k⟧(ϖ) := ϖ²/(k²+ϖ²) = G(k/ϖ)，G(y):=1/(1+y²)**——这就是团队消息里说的「Lorentz 核」：把它写成 G(k/ϖ) 就看出它是**标准 Lorentzian**，标度变量 y=k/ϖ，源头是玻色子传播子 2ω/(ω_n²+ω²) 在 Matsubara 轴上的值。h(ϖ):=λ₁(ℌ(ϖ))。

弱耦合极限 h(ϖ) = ln ϖ + c₀ + b₁/ln ϖ + …（c₀=γ+ln4−3/2）目前的**证明**（定理 W/W′，`P4_weak_coupling_series.md`）走的是 **(M1) Lorentz 加法恒等式** ℌ=2ττᵀ+𝓡−𝒟，这条恒等式本身是 Lorentzian 部分分式（有理函数在乘法下封闭）给出的代数偶然，不是 Matsubara 结构的必然。本探索要回答：**去掉 Lorentz 的代数偶然、只留 Matsubara 等距 + 单软标度核形，h~lnϖ 还在不在？系数是不是还是 1？**

## 2. h~ln ϖ 的必要条件——解析论证

KAY 的存在性引理 X（`P4_main_theorems.md` §1）给出一个**精确、核形状无关**的锚点：常数核 f≡1 时
  𝒪[1] = 2uuᵀ − I（精确恒等式，u_n=(2n+1)^{-1/2}），
故 𝔥^{(N)}(∞) = 2S_N−1，S_N=Σ_{n<N}1/(2n+1) ~ ½ln N + (γ+ln4)/2。

**这正是 BCS/Eliashberg 教科书里的「Cooper 对数」**：Matsubara 频率求和 Σ_n 1/(2n+1) 在硬截断 N 处发散如 ln N，源头是 u_n 的调和衰减（Matsubara 频率等距间隔 + 1/ω_n 型配对易感度），与相互作用核的形状**完全无关**——这是标准 BCS 弱耦合对数的算子版本。

有限 ϖ 的 h(ϖ) 是把「硬截断 N」换成核 f(k,ϖ) 在 k~ϖ 附近的**软**截断：只要核满足
  (i) f(k,ϖ)→1（固定 k，ϖ→∞）——「平台」区 k≪ϖ 与常数核一致；
  (ii) f(k,ϖ)→0 且衰减快于 1/k（固定 ϖ，k→∞）——尾部可和，不产生新发散；
  (iii) f 对 k 单调不增（物理上：越远的 Matsubara 频率耦合越弱）；

则直觉上 h(ϖ) 应该和「N=ϖ 硬截断」同阶——即 **ln ϖ 的系数应恒为 1**，核形状只能进到二阶项（常数 c₀ 依赖于 K 的具体轮廓、乃至软化过渡区的"有效带宽"，但不影响对数系数）。这是「Matsubara 结构（谐和衰减）决定领头对数、核形状只决定截距」这一命题的启发式版本；**边界情形**在于条件 (ii)：若核尾部衰减恰好 ~1/k（如 γ-model 取 γ=1）或更慢（γ<1，或 Lindhard 型 ~1/|ω_n|），尾部求和本身贡献一个**新的**对数（k 求和 Σ1/k 本身发散），届时领头阶可能变成 ln²ϖ 或核形状相关的非整数幂，而不再是纯 ln ϖ + O(1)——这是 Kohn-Luttinger 型核（Lindhard 尾 ~1/|ω_n|）落在的**危险区**，需要单独处理（§4）。

（此段是启发式论证，不是证明；下面用数值直接检验。）

### 读数

1. **ln ϖ 系数普适地 → 1**：8 个形状迥异的核（有限支撑截断 gap、幂律衰减快慢差 3 倍、Gaussian 超指数尾、纯指数尾）在能测到的范围内 slope 全部落在 0.96–1.13，且**离基线越远（Yukawa 大 gap）收敛越慢但方向对**——α=5 的 slope 从 45→135 的 1.129 单调降到 135→300 的 1.043，正朝 1 逼近（gap α 相对 ϖ 越来越小，恢复到「无 gap」渐近行为，符合预期）。这与 §2 的启发式论证一致：**领头对数系数由 Matsubara 谐和结构（u_n~(2n+1)^{-1/2}）锁定，核形状锁不动它**。

3. **幂律边界情形**（γ=1.5，衰减比 Lorentz 慢但仍 >1）**N-收敛残差最大**（2.6e-5，比其余大 4 个量级），印证 §2 的警告：γ 越接近临界值 1，尾部收敛越慢，需要更大 N 才稳（该点仍在可信范围内，只是收敛速率的量化提示）。**没有测 γ≤1**（尾部不可和，𝒪[f] 是否仍紧算子存疑，超出本轮范围）。

**结论（numerical-evidence 级）**：**h(ϖ) = ln ϖ + c₀(核形状) + o(1) 这一形式对"单软标度、平台+快速衰减尾"的整个核家族普适成立，ln ϖ 前的系数恒为 1（不依赖核形状），核形状只重整化常数项 c₀。** 这与"BCS 弱耦合对数普适、只有前因子依赖细节"的标准物理图像吻合，且把这条图像从"folklore"落实成了一个可数值检验的、跨 8 个具体核家族一致的陈述。

## 4. Matsubara 结构 vs 核形状——各自的角色

**结论先行**：h~lnϖ 这个"物理结论"活下来了（数值证据），但 KAY **证明它的具体机器**大部分是 Lorentz 专属、活不下来。两者要分开报。

### 4.1 活下来的（Matsubara 结构专属，核形状无关）

- **引理 M（核单调性）**：证明只用到 (i) F 非增、Σ F(k)<∞、F≢0；(ii) G∈ℓ¹；(iii) F≤G 逐点——**完全不看核的具体形状**，只要求「非增」。因此：
  - 定理 1(b)（T_c 唯一性，T↦𝔨(P,T) 严格单调）
  - 定理 1(c) 型的"一般 P ⇐ 极值谱"Jensen 化约
  这两条对**表 §1 里任何一个非增核族**（Lorentz、Yukawa、幂律 γ-model 全部满足非增）**原样成立**，不需要重新证明——这是本轮最有用的收获：**KAY 的核心单调性机器是核-形状无关的，Lorentz 只是 KAY 论文选的具体例子，不是引理 M 需要的假设**。
- **引理 X（存在性）与 𝒪[1]=2uuᵀ−I**：对任何核族只要求 f(k,ϖ)→1 pointwise（ϖ→∞ 或 T→0），与核形状无关，精确恒等式本身不含 Lorentz 假设。
- **h~lnϖ 的领头对数系数=1**：§3 数值证据，来自 u_n 调和权重，非 Lorentz 专属（§2 论证 + §3 数值）。

### 4.2 死不掉、但被替换成开放问题的（核形状敏感）

- **定理 2（Einstein 极值）的证明依赖 x↦x/(k²+x) 在 x=ϖ² 严格凹**——这是 Lorentz 的**具体代数性质**，不是"非增"这类弱条件。对幂律核 f=x^{γ/2}/(k^γ+x^{γ/2})（x=ϖ²），凹性是否对所有 γ 成立**未检验**（本轮未做）——这是唯一一条"定理 2 是否推广"依赖的开放问题，留给下一轮（可能需要对每个 γ 单独验证 ∂²_x f ≤ 0，或找到凹性失效的 γ 反例）。
- **(M1) Lorentz 加法恒等式 ℌ=2ττᵀ+𝓡−𝒟**：这是**有理函数在乘法下封闭**给出的代数偶然（G(s)G(σ) 可以用 R(s,σ) 这个「加法公式」精确重排），对 Yukawa/幂律/Gaussian **没有类似的封闭形式**（Gaussian 乘积仍是 Gaussian，理论上或有类似分解，但团队未验证；幂律乘积一般不封闭）。
- **定理 W/W′（久期级数双侧包围 + 三项渐近 + b₁ 闭式）**：整条证明链条挂在 (M1) 上，**不可移植**——非 Lorentz 核想要 h(ϖ) 的**证书级**双侧包围，需要一条全新的代数路线（如果核没有加法公式，大概率只能退到"数值证据级"或粗糙的 Schur/HS 尾界，界会松很多）。
- **c₀ 的闭式值**：γ_E+ln4−3/2 是 Lorentz 专属数字；其它核族的 c₀ 需要各自的标度极限积分（§3 数值已给出量级，闭式未做）。

### 4.3 Kohn-Luttinger / flat-band——超出 𝒪[f] 框架本身

- Kohn-Luttinger 型核（Lindhard 函数尾 ~1/|ω_n|）如果真的比 1/k 慢或恰好 ~1/k，按 §2 的边界警告，**领头阶可能不是纯 ln ϖ**（Cooper log 本身可能被二次修正，或需要动量积分先做完才能退化成纯频率核，退化过程本身可能引入额外对数）。这条**没有数值检验**（需要先具体化 Lindhard 函数在 Matsubara 轴上的显式形式，工作量超出本轮），留作后续方向。
- flat-band 型（配对来自 Berry curvature，本质上是**动量**结构而非**频率**结构）多半根本不落在"频率差核"这个框架里——它对应的是 𝒪[f] 里 f 与 |n−m|、n+m+1 无关（f≡常数，瞬时相互作用），这时 KAY 自己的 𝒪[1]=2uuᵀ−I 恒等式就是答案（引理 X 已覆盖），**不需要新核**，需要的是重新审视量子几何怎么进入 v（本征向量）或 λ（有效耦合常数）而不是进入频率核形状——这是一个不同维度的问题，本轮不展开。

## 5. 给团队的结论摘要

1. **h(ϖ) ~ ln ϖ + c₀ 是普适的（numerical-evidence，8 个核族一致）**：ln ϖ 前系数恒为 1，来自 Matsubara 等距 + u_n 调和权重，不是 Lorentz 专属；c₀ 是核形状的"指纹"，方向符合直觉（尾部衰减越慢 c₀ 越大）。
2. **KAY 的单调性机器（引理 M/X，定理 1(b)(c) 型的一般 P 化约）对任何"核在 k 上非增"的族原样成立**——这是核形状无关的坚实结论，值得写进正文作为"框架推广"的证据。
3. **定理 2（Einstein 极值）的凹性假设是核形状敏感的**，幂律 γ-model 是否满足未检验，是下一轮最有价值的具体缺口。
4. **定理 W/W′ 与 b₁ 闭式完全挂在 Lorentz 代数偶然上**，不可移植；非 Lorentz 核想要证书级弱耦合展开需要各自独立的代数路线（或接受更松的 Schur/HS 尾界）。
5. **Kohn-Luttinger（Lindhard 尾）处在 §2 警告的边界/危险区**（尾部衰减可能不够快），**flat-band 本质上不是新核而是需要频率核之外的结构**——两者都需要专门的后续探索，本轮未数值验证。

**未做/超出本轮范围**：幂律核凹性的系统验证、Lindhard 核的显式数值实现、c₀ 的闭式推导（非 Lorentz 族）、γ≤1 边界情形。
