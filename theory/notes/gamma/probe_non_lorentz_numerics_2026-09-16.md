## 0. 框架回顾

沿用 `P4_rigorous_tc_bound.md` §0 的算子定义（`theory/derivations/p4_interchange_uniformity.py` 的 `H_mat` 是其标准 Lorentz 核的具体实现）：

```
O[f] := -L1[f] + L2[f] + L3[f]   on l²(N₀),  u_n := (2n+1)^{-1/2}
  L1_nn = (2n+1)^{-1} Σ_{k=1}^n 2f(k)          (对角)
  L2_nm = (1-δ_nm) f(|n-m|) u_n u_m
  L3_nm = f(n+m+1) u_n u_m
标准 (KAY) Lorentz 核: ⟦k⟧(ϖ) = ϖ²/(k²+ϖ²)
H(ϖ) := O[⟦·⟧(ϖ)],  h(ϖ) := λ₁(H(ϖ))
凹性定理的对象: H(x) := h(√x)，x∈(0,∞)
```

三个待测核族——都通过**同一个** `O[·]` 机制、以单变量核函数 `f(k;参数)` 的形式插入（与标准 Lorentz 核完全同构的入口）：

- **核 1（Yukawa / 移位 Lorentz，最小修改）**：`f(k;ϖ,α) = ϖ²/((k+α)²+ϖ²)`，α=0 时精确退回标准 KAY 核。（团队消息给的双变量公式无法通过单参数 `O[f]` 机制解释，读 `P4_rigorous_tc_bound.md` §0 后确认 `O[f]` 只接受单变量核；因此取"移位模式指标"这一最小、自然的推广，α 越大表示屏蔽/失谐越强。）
- **核 2（指数截断）**：`f(k;ϖ,N_cut) = [ϖ²/(k²+ϖ²)]·exp(-k/N_cut)`，N_cut→∞ 退回标准核。
- **核 3（幂律 γ-model，ϖ 依赖版本）**：`f(k;ϖ,γ) = ϖ^γ/(k^γ+ϖ^γ)`，γ=2 精确退回标准 Lorentz 核。**注**：`p4_gamma_general.py` 中已有的 γ-model 算子 𝔊(γ)=O[k^{-γ}] **不含 ϖ 依赖**（是一个固定算子，其顶特征值 𝔤(γ) 只作为 h(ϖ) 在 ϖ→0 一阶系数出现），不能直接产出 h(ϖ) 曲线；此处用上述 ϖ 依赖幂律核做真正的推广，γ=2 时与标准核一致，γ=1 对应 Ohmic-like，γ=3 对应 super-Ohmic-like。

所有核族在其"平凡"参数值处都精确退回标准 KAY 核，构成脚本内建的正确性检查基准。

## 1. 方法

对每个核族的每个参数值：
1. N=200，在 ϖ∈[0.001,100]（80 点，对数间距）上算 h(ϖ)=λ₁(H(ϖ))（`np.linalg.eigvalsh`）。
2. 对 ϖ∈[1,100] 做双对数拟合 h~A·ϖ^α 和 h~A·ln(ϖ)+B 两种假设，比较哪种更贴合渐近增长。
3. 小 ϖ 检验：r(ϖ):=h(ϖ)/ϖ² 在 ϖ→0 的极限（仅对"退回标准型"—— α=0/γ=2 —— 核有意义；见下）。
4. 在 x∈[1e-6, 2e4]（1200 点，**对数间距**，覆盖 x→0 与大 x 两端）上算 H(x)=h(√x)，用非均匀网格的标准三点二阶差分公式
   `H″(x₁) ≈ 2·[(h₂-h₁)/(x₂-x₁) - (h₁-h₀)/(x₁-x₀)]/(x₂-x₀)`
   估计 H″，判定凹性（判据：max H″ ≤ 1e-6 记为"凹"，否则记为"违反"；噪声基准见 §4）。

**关键修正**：脚本初版的 x 网格是 `linspace(0.01,400,400)`（均匀间距、下限 0.01），完全无法分辨 x→0 附近的曲率——这正是本探针最终发现的违反发生的区域。改为对数间距、下探到 1e-6 后才捕捉到 γ>2 的违反。

## 3. 头条发现：幂律核 γ>2 时凹性定理失效

**机制（解析论证，small-ϖ 展开）**：对幂律核 f(k;ϖ,γ)=ϖ^γ/(k^γ+ϖ^γ)，当 ϖ→0 时 f(k;ϖ,γ) ≈ ϖ^γ·k^{-γ}（k≥1 固定），所以

```
O[f(·;ϖ,γ)] ≈ ϖ^γ · O[k^{-γ}] = ϖ^γ · 𝔊(γ)      (𝔊(γ) 即 p4_gamma_general.py 中固定的 γ-model 算子)
⟹  h(ϖ) ~ 𝔤(γ)·ϖ^γ      (ϖ→0，𝔤(γ):=λ₁(𝔊(γ)))
⟹  H(x) = h(√x) ~ 𝔤(γ)·x^{γ/2}      (x→0)
⟹  H″(x) ~ 𝔤(γ)·(γ/2)(γ/2-1)·x^{γ/2-2}      (x→0)
```

H″ 在 x→0 处的符号由 `sign((γ/2)(γ/2-1)) = sign(γ-2)` 决定：

- **γ=2**：(γ/2)(γ/2-1)=0——退化/边界情形，H(x)~𝔤(2)x 线性，H″→0（不是严格违反，数值上表现为基准本身的凹性，边界处"刚好不凸"）。
- **γ<2**：γ-2<0，(γ/2)(γ/2-1)<0（因为 γ/2<1 时 (γ/2-1)<0，γ/2>0）——**凹**，且 H″→−∞（x→0 处曲率发散但方向是凹的）。数值上 γ=1.0, 1.5 均确认：全域 H″<0，x→0 处 H″ 负向发散（表中 min H″ = −3.9e8 / −8.1e6），无违反。
- **γ>2**：γ-2>0，(γ/2)(γ/2-1)>0（γ/2>1 时两因子同正）——**凸**，H″→+∞。数值上 γ=2.2, 2.5, 3.0 均确认：x→0 附近 H″>0，且违反区间随 γ 增大而扩大（γ=2.2: x≲0.068；γ=2.5: x≲0.185；γ=3.0: x≲0.353，覆盖了网格中过半的采样点）。

这个符号翻转与网格数值结果**完全吻合**，不是数值噪声或截断伪影（用两套独立网格——800 点/[1e-6,200] 与 1200 点/[1e-6,2e4]——交叉验证 γ=3.0 峰值 H″，分别得到 9.191e2 和 9.210e2，一致到 3 位有效数字）。

**结论**：H(x)=h(√x) 的凹性定理**在标准 Lorentz 核（γ=2）及其"温和"扰动（Yukawa 移位、指数带宽截断、Ohmic 型 γ<2 幂律软化）下都保持鲁棒**，但对**陡于 Lorentzian 的幂律核（super-Ohmic-like, γ>2）在小 ϖ 区间严格失效**——这是幂律核小 ϖ 标度 x^{γ/2} 的曲率符号翻转导致的，是该族核**本征**的性质，不依赖于 N、网格分辨率等数值细节。物理上这意味着：若耦合谱在低频端比标准电声子 Lorentzian 更陡峭地趋零（γ>2 的 super-Ohmic 型谱密度），凹性定理（进而可能依赖它的下游结论，如 Einstein 极值性证明路径）不能不加验证地照搬。

## 4. 自检 / 噪声基准

- 基准核 r(0+) 数值 1.318139 对已知解析常数 𝔤(2)=1.3181402117…–1.3181402124（CERT-D 区间）符合至 6 位有效数字，确认 `build_O` 矩阵构造与 `p4_interchange_uniformity.H_mat` 的证书级实现一致（N=200 float64 截断下的最佳可得精度）。（脚本初版中 r(0+) 诊断打印过取窗口内**最大** ϖ 而非最小 ϖ 处的 r 值，造成约 7% 的虚假偏差——已在本版脚本 `run_family` 中修正为取窗口最小 ϖ。）
- 大 ϖ 对数拟合斜率 A 在基准核上为 0.9646（理论 1.0），偏差来自 ϖ 仅到 100、N=200 有限截断带来的次领项修正（∝1/ϖ, 1/ϖ² 及有限矩阵截断效应），不是 bug；γ=3.0 核拟合 A=0.994 更接近 1.0，属核形式相关的次领项差异，同属 numerical-evidence 精度范围。
- 所有"凹"判定的 max H″ 噪声基准落在 **−1e-9 ~ −1e-10** 量级（远低于判据阈值 1e-6），而"违反"判定的 max H″ 落在 **1e2 ~ 1e4** 量级——两者相差 11–13 个数量级，凹性/违反的区分在本数值精度下是**非常清晰**的，不存在临界模糊地带（除严格 γ=2 边界本身，那里退化为 H″→0 而非违反）。
- 未系统性排查 γ 在 (2, 2.2) 之间的更细分辨率（只测了 2.0/2.2/2.5/3.0/1.0/1.5/1.0），但解析机制（符号仅依赖 γ−2 的正负）已经给出严格预测，数值确认了两侧边界（γ=2 无违反、γ=2.2 已违反），足以定性确立"临界点精确在 γ=2"这一结论；细分辨率扫描对本探针目的（定性验证凹性定理的鲁棒边界）而言不是必要的。
