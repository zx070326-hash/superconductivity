## 2. v2：加权 Schur 界（`certificate`）

加权 Schur 检验：A 非负、p=q=u（u_m=(2m+1)^{−1/2}）时
‖A‖ ≤ √( sup_n (1/u_n)Σ_m A_nm u_m · sup_m (1/u_m)Σ_n A_nm u_n )。
非对角 𝔊_nm = u_n u_m g(n,m)，所以加权行和坍缩成 **Σ_m g(n,m)/(2m+1)**，衰减 m^{−1−γ}：对**所有** γ>0 收敛，且远紧于 v1 的非加权行和（衰减 m^{−γ−½}，需 γ>½）。

记 H̄_γ(n)=1+∫_1^n x^{−γ}dx ≥ Σ_{k≤n}k^{−γ}；T̄_β(J)=J^{−β}+J^{1−β}/(β−1) ≥ Σ_{k≥J}k^{−β}（β>1）。

**‖C‖**：A_sup ≤ H̄_γ(N+1)/(2N+3) + T̄_{1+γ}(N+2)/2 + T̄_{1+γ}(N+1)/2（n 无关）；B_sup = B_{N+1}（每项在 m 上非增，有限 iv 精确和）。
**‖𝔊^BB‖**：行 n>N 拆成 (a) 对角 2H̄_γ(n)/(2n+1)+(2n+1)^{−1−γ}、(b) Hankel T̄_{1+γ}(N+1)/2、(c) 右 Toeplitz H̄_γ(n)/(2n+1)+T̄_{1+γ}(n+1)/2、(d) 左 Toeplitz：j≤n/2 部分 H̄_γ(n)/(n+1)，j>n/2 部分 (4/(2N+3))^γ[1/(2N+3)+1/(2γe)]。每块在 n 上非增（(d1) 在 n≥3 后非增，脚本 docstring 有推导），各自取 n=N+1 即为 sup。**这修了 D3。**

## 3. v3：块对角参照的 Davis–Kahan（关键收紧，`analytic` 引理 + `certificate` 数值）

**观察**：𝔊^BB 的对角是 −𝔊₁_nn + (2n+1)^{−1−γ} < 0（𝔊₁_nn ≥ 2/(2n+1) > (2n+1)^{−1−γ}），‖𝔊^BB‖ 被这个**负**对角主导，而它把尾部本征值往**下**推，对顶本征向量毫无威胁。float64：γ=1, N=400 时 λ_max(𝔊^BB)=+0.00023 vs ‖𝔊^BB‖=0.0179（差 80 倍）。

**引理**（方向显式）：A′ Hermitian，λ_max(A′)=μ₁ 单重、单位本征向量 ê₁，spec(A′)∖{μ₁} ⊂ (−∞, μ₁−δ]；𝔊=A′+E′，ν₁=λ_max(𝔊)，w=cosθ ê₁+sinθ z。用 P=I−ê₁ê₁* 投影 𝔊w=ν₁w：(A′|_P−ν₁)(sinθ z) = −PE′w ⇒ sinθ·dist(ν₁, spec A′|_P) ≤ ‖E′‖；Weyl 给 ν₁ ≥ μ₁−‖E′‖ ⇒ **sinθ ≤ ‖E′‖/(δ−‖E′‖)**。

| | A′ | E′ | ‖E′‖ 上界 | δ |
|---|---|---|---|---|
| v2（沿用 v1 结构） | 𝔊^(N) ⊕ 0 | [[0,C],[Cᵀ,𝔊^BB]] | ‖C‖+‖𝔊^BB‖ | μ₁ − max(λ₂^head, 0) |
| **v3** | 𝔊^(N) ⊕ 𝔊^BB | [[0,C],[Cᵀ,0]] | **‖C‖** | μ₁ − max(λ₂^head, **λ_max(𝔊^BB)**) |

两种情形 ê₁=(v₁,0) 都是 A′ 的本征向量（尾部为零），μ₁=λ_max(A′) 也都成立（v3 需 λ_max(𝔊^BB)<μ₁，差三个量级）。

**λ_max(𝔊^BB) 的证书**：加权 Gershgorin（D=diag(u) 相似变换不改谱）λ_max ≤ sup_n[G_nn + rad(n)] ≤ 0 + sup_n rad(n) = (b)+(c)+(d1)+(d2)，即 v2 的 ‖𝔊^BB‖ 界去掉对角项 (a)。

## 5. 教训（写入 memory）

1. **同一脚本第四处** "常数替身不等式"：D1 是教科书级的积分比较方向错（∫_J^∞ 下估递减级数尾和），前三处是发散级数给有限数。agent 写的 "use ∫_J^∞ directly" 这种注释要按不等号方向逐条核。
2. **"worst row = 第一行"** 在双侧 Toeplitz 尾块里不成立；任何 sup_n 主张必须给出单调性证明或逐段区间界。
3. **‖E‖ 不是 DK 的正确输入**——当扰动块有大的负对角时，把它并进参照算子只付 λ_max 的代价。这是本轮最大收益（c₁² 差距 17%→2.6%），且推导比原来更短。
