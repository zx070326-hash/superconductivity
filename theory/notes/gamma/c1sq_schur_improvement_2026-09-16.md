## 1. Schur 检验：吃进逐点衰减，不用全局夹逼

**Schur 不等式**（标准，任意矩阵 M）：
```
‖M‖ ≤ √( sup_i (行和 R_i) · sup_j (列和 K_j) ),   R_i=Σ_j |M_ij|, K_j=Σ_i |M_ij|
```
应用到 C（n ≤ N < m 分块）：
```
R_n = Σ_{m>N} |C_{nm}| = u_n Σ_{m>N} u_m ( f(m−n) + f(n+m+1) )
K_m = Σ_{n≤N} |C_{nm}| = u_m Σ_{n=0}^N u_n ( f(m−n) + f(n+m+1) )
```

**关键**：R_n 和 K_m 的内部求和分别对 **f(m−n)、f(n+m+1) 的每一项**单独出现，
而 f(k) 的逐点上界 f(k) ≤ ϖ²/k²（k≥1）直接作用在每项上——不需要先夹到 f̂(0) 再求和。
这正是旧界丢掉的信息。

## 2. 行和 R_n 上界（解析，无穷维尾控制，n=0..N 逐个算）

n ≤ N 固定，内部求和 m > N 是无穷尾，需要解析控制。

**方向审计（每步都是上界代入正项和/积）**：
1. u_m ≤ u_{N+1} 对所有 m ≥ N+1（u_n=(2n+1)^{-1/2} 单调递减）。
2. 代入：R_n ≤ u_n u_{N+1} · Σ_{m>N} ( f(m−n) + f(n+m+1) )
            = u_n u_{N+1} · ( Tail(N+1−n) + Tail(n+N+2) )
   其中 Tail(J) := Σ_{j≥J} f(j)，J ≥ 1 整数。

**Tail(J) 的解析上界**（两条独立路线，取 min）：

### 路线 (a)：积分比较 + arctan 有理下界（J 相对 ϖ 小时紧）

**方向**：f 在 x≥0 单减 ⟹ f(j) ≤ ∫_{j−1}^j f(x)dx（标准积分检验），伸缩：
```
Tail(J) ≤ ∫_{J−1}^∞ ϖ²/(ϖ²+x²)dx = ϖ · ( π/2 − arctan((J−1)/ϖ) )
```
**方向**：arctan(y) ≥ y/(1+y²) 对 y≥0（初等：y=0 等号，导数差 2y²/(1+y²)² ≥ 0 单增）。
代入：π/2 − arctan(y) ≤ π/2 − y/(1+y²)，故
```
Tail(J) ≤ ϖ · ( π/2 − y/(1+y²) ),   y := (J−1)/ϖ
```
**纯有理** + 常数 π/2（用 `+iv.pi` 触发，仓库约定），**完全不调用 iv.atan / iv.atan2**
（已知本机不 enclose 坑）。

### 路线 (b)：逐项 1/j² 比较 + 有理伸缩（J 相对 ϖ 大时紧）

**方向**：f(j) = ϖ²/(ϖ²+j²) ≤ ϖ²/j² 对 j≥1（分母只变大）。
**方向**：Σ_{j≥J} 1/j² ≤ 1/(J−1) 对 J≥2（伸缩 1/j² ≤ 1/(j(j−1)) = 1/(j−1)−1/j）。
J=1：Σ_{j≥1}1/j² ≤ 1 + Σ_{j≥2}1/j² ≤ 1+1=2（粗但有效，避开 π²/6 超越常数）。
```
Tail(J) ≤ ϖ² · ( 2  若 J≤1;  1/(J−1)  若 J≥2 )
```

**合并**：Tail(J) := min( bound(a), bound(b) )。两者都是同一非负量的独立有效上界，
min 仍是有效上界（且更紧）。

**sup_n R_n**：**不能假设最坏在 n=N**（float64 核验 `c1sq_schur_closed.py`：
ϖ=30,100 @ N=500 时 argmax 在 n=0，不在 n=N）。故用 **O(N) 循环**，
逐个算 R_n 上界（每个都是有效上界），取有限集的 max（仍是有效上界）。

## 3. 列和 K_m 上界（m=N+1 精确值，无需尾控制）

m > N 固定，内部求和 n=0..N 是**有限和**（N+1 项），**直接用 iv 精确算**，不是界。

**单调性（证明，非假设）**：对固定 n，u_m、f(m−n)、f(n+m+1) 均关于 m 单减
（u 单减；f 单减且 m−n、n+m+1 均随 m 增）。非负单减函数的和仍单减。
故 K_m 关于 m 单减（m > N），sup_{m>N} K_m = K_{N+1}（**精确**，不是界）。

**方向审计**：计算 K_{N+1} 时，n 求和是显式有限 iv 加法（N+1 项），每项
```
u(n) · ( f((N+1)−n) + f(n+(N+1)+1) )
```
都是正项 iv 区间运算，外层乘 u(N+1)，全程上界方向（取 hi() 提取上端点）。

## 4. 新 ‖C‖ 界

```
‖C‖_schur ≤ √( Rsup · Ksup ),   Rsup := max_{n=0..N} R_n_上界,  Ksup := K_{N+1}（精确）
```
**方向**：Schur 不等式本身；√ 和乘积保持单调（非负）；Rsup 是逐 n 上界的 max（上界）；
Ksup 是单调性证明下的精确值（不是界）。合并后仍是 ‖C‖ 的有效上界。

**严格性**：
- Tail(J) 公式：**analytic**（积分比较 + arctan 有理下界 + 1/j² 伸缩，全程初等不等式）。
- Rsup 循环、Ksup 有限和：**certificate**（iv 区间算术，外向舍入，有限次运算）。
- ‖C‖_schur：**certificate**（组合上述两者）。
