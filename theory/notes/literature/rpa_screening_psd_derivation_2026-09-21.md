## 证明路线

### 第一步：Lindhard 函数的 Lehmann 谱表示

Lindhard 极化函数（retarded Green 函数）：
```
χ₀(q,ω) = Σ_{k,αβ} [f(ε_k^α) − f(ε_{k+q}^β)] / [ω + ε_k^α − ε_{k+q}^β + iη]
```
其中：
- k 是动量，α/β 是能带/轨道指标
- f(ε) 是 Fermi-Dirac 分布
- η → 0⁺ 是无穷小正实数（因果性）

**关键性质**：χ₀ 的虚部（spectral function）
```
Im χ₀(q,ω) = −π Σ_{k,αβ} [f(ε_k^α) − f(ε_{k+q}^β)] δ(ω + ε_k^α − ε_{k+q}^β)
```

**物理解读**：
- f(ε_k) − f(ε_{k+q}) ≥ 0 当 ε_k < ε_{k+q}（吸收过程，ω > 0）
- f(ε_k) − f(ε_{k+q}) ≤ 0 当 ε_k > ε_{k+q}（发射过程，ω < 0）
- δ 函数保证能量守恒：ω = ε_{k+q} − ε_k

因此：
```
Im χ₀(q,ω) ≤ 0  for ω > 0    (损耗正)
Im χ₀(q,ω) ≥ 0  for ω < 0
```

这是 **因果性（causality）** 的直接结果：retarded Green 函数在上半平面解析。

---

### 第二步：谱表示与 Kramers-Kronig 关系

由于 χ₀ 是因果 Green 函数，存在谱表示：
```
χ₀(q,ω) = ∫_{-∞}^{∞} dω' ρ(q,ω') / (ω − ω' + iη)
```
其中谱密度：
```
ρ(q,ω) = −(1/π) Im χ₀(q,ω)
```

**关键观察**：
- ρ(q,ω) ≥ 0 for ω > 0（粒子-空穴激发谱）
- ρ(q,ω) ≤ 0 for ω < 0（时间反演对称性）

对于 **静态情况** ω = 0（超导理论中的常见简化）：
```
χ₀(q,0) = ∫ dω' ρ(q,ω') / (−ω') = −∫ dω' ρ(q,ω') / ω'
```

**注**：静态 χ₀ 是实数，且通常 χ₀(q,0) < 0（Thomas-Fermi 屏蔽）。

---

### 第三步：Dyson 级数与正定性传递

RPA 屏蔽相互作用的 Dyson 方程：
```
W = v + vχ₀W
```
解得：
```
W^RPA = v[1 − vχ₀]⁻¹ = v + vχ₀v + vχ₀vχ₀v + vχ₀vχ₀vχ₀v + ...
```

**核心论证**：
1. **裸势正定**：v(q) = 4πe²/q² ≥ 0（Coulomb 势的 Fourier 变换）
2. **每项都是正定 kernel 的乘积**：
   - 第 n 项：`v(χ₀v)^{n−1}` 
   - 在实空间，这是卷积：`∫ v(r−r') χ₀(r'−r'') v(r''−r''') ... dr'dr''...`
3. **PSD 算符的卷积仍 PSD**（见下方引理）

**引理（正定性传递）**：
若 A ⪰ 0, B ⪰ 0 是积分算符核，则卷积 `C(r,r'') = ∫ A(r,r') B(r',r'') dr'` 也满足 C ⪰ 0。

**证明草图**：
```
⟨ψ|C|ψ⟩ = ∫∫∫ ψ*(r) A(r,r') B(r',r'') ψ(r'') dr dr' dr''
        = ∫ dr' [∫ ψ*(r) A(r,r') dr] [∫ B(r',r'') ψ(r'') dr'']
        = ∫ dr' |φ(r')|² [with φ(r') = ∫ A(r,r')^{1/2} ψ(r) dr]
        ≥ 0  (if A,B ⪰ 0)
```
（严格证明需用算符分解，此处略。）

### 第四步：收敛性与级数和

Dyson 级数收敛条件：
```
‖vχ₀‖ < 1
```

在物理系统中：
- 高频极限：χ₀(q,ω) → 0 as ω → ∞（粒子-空穴连续谱）
- 大动量极限：χ₀(q,ω) ~ −N(0)/q²（Thomas-Fermi）
- 因此 vχ₀ 在物理参数下通常 < 1

当级数收敛时，每项 ⪰ 0 ⟹ 和 ⪰ 0。

**注意**：若 vχ₀ → 1（屏蔽发散），系统接近不稳定性（如电荷密度波），此时 RPA 失效。

## 多带情况的推广

对于多轨道系统（铁基、MgB₂ 等），χ₀ 和 W 都是矩阵：
```
χ₀^{αβ}(q,ω) = Σ_k [f(ε_k^α) − f(ε_{k+q}^β)] / [ω + ε_k^α − ε_{k+q}^β + iη]
W^{αβ} = [v⁻¹ − χ₀]⁻¹_{αβ}
```

**关键修改**：
1. 谱表示逐分量成立：ρ^{αβ}(q,ω) 是矩阵值
2. **对角化论证**：在能带本征基下，χ₀ 是对角块
3. 正定性逐块传递（需验证混合项）

**技术难点**：非对角 χ₀^{αβ} (α≠β) 的符号？
- **答案**：Lehmann 表示仍成立，但 Im χ₀^{αβ} 的符号依赖于带间跃迁
- **保守结论**：多带情况需额外检查 Hermiticity + 谱条件

**当前推导适用范围**：
- **单带**：完全 analytic
- **多带，对角近似**（χ₀^{αβ} ≈ δ_{αβ} χ₀^{αα}）：analytic
- **多带，非对角**：需验证 χ₀ 的 Hermiticity 和谱表示形式（待补充）

## 静态极限的简化证明

对于超导理论中常用的 **静态 RPA**（ω = 0）：

**引理（静态 Thomas-Fermi 屏蔽）**：
```
W^{TF}(q) = v(q) / [1 + v(q)χ₀(q,0)]
           = v(q) / ε(q)
```
其中 ε(q) = 1 + v(q)χ₀(q,0) 是介电函数。

**物理论证**：
1. 静电能量泛函：`U = ½ ∫∫ ρ(r) W(r−r') ρ(r') dr dr'`
2. W 是有效静电势 ⟹ U ≥ 0（能量正定性）
3. ⟹ W 作为双线性形式必 PSD

**数学论证**：
1. χ₀(q,0) 是实数（Kramers-Kronig）
2. 通常 χ₀(q,0) < 0（screening）⟹ ε(q) > 1
3. ⟹ W(q) = v(q)/ε(q) > 0 且 < v(q)（屏蔽削弱但保持正定）
