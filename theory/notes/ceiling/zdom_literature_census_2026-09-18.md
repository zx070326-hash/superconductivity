## 0. 判据拆成两层（这是本普查的主要结论）

| 层 | 要什么 | 文献可得性 |
|---|---|---|
| **(C3a) 判定 (Z-dom)** | 只要**约定**：`Λ^Z`、`Λ^Δ` 各自由哪些非负片构成 | **几乎总是可得**——它就是论文的 Eliashberg 方程本身 |
| **(C3b) 算出 `ρ(M2″_Z)`** | `λ^ph_ij`、`λ^sf_ij` **两张数值表** + 各自的谱形/特征频率 | 视论文而定，这才是真瓶颈 |

两个已证的**约定级**充分条件（`analytic`，一行，不需要任何数值）：

> **(K1) 加减型约定**：`Λ^Z = Λ^ph + Λ^sf`、`Λ^Δ = Λ^ph − Λ^sf`，两片各自逐元非负
> ⟹ (Z-dom) **由三角不等式自动成立**（仓库已有）。
> **(K2) 单玻色子 + 形状因子型约定**：`Λ^Z_ij = λ_ij`（无符号）、`Λ^Δ_ij = g·F_ij·λ_ij`，`λ ≥ 0`
> ⟹ (Z-dom) ⟺ **`g·|F_ij| ≤ 1` 逐元**；特别地 `|F| ≤ 1` 时 **`g ≤ 1` 即充分**。

⚠ **(K2) 必须按 `F` 的类型拆成两行——余量天差地别，不许并列写**（team-lead 复核时指出）：

| 子类 | `F` | (Z-dom) 条件 | 余量 | 保护性 |
|---|---|---|---|---|
| **(K2a) 连续形状因子**（d 波 `F = cos2θ cos2θ′`） | `|F| ≤ 1`，**除反节点外严格 `< 1`** | `g·|F| ≤ 1` | `g = 0.78`（#5）⟹ **22%**，且 `|F| < 1` 处更宽 | — |
| **(K2b) 纯符号型**（s± 片/带指标 `F_ij = s_is_j`，`s_i = ±1`） | **恒 `|F| ≡ 1`** | **`g ≤ 1`** | **零——`g = 1.001` 即出界** | ✗ `g` 是自由拟合标量，同一约定内 `g > 1` 是合法拟合 |

⟹ **(K2b) 的 `g ≤ 1` 是紧条件，必须逐篇核 `g` 的实际取值，不得由 `|F| ≤ 1` 推出**；
「#5 的 d 波 `g = 0.78` 覆盖」**不能顺推成「s± 也宽松」**。
（这正是新纪律的形状：**承重命题的反例住在等式面上**，而 `|F| ≡ 1` 就是那个面。）
⚠ 本轮人口里 **(K2b) 有 0 篇**——它是约定层的**警示**，不是观察到的类；已读的 s± 论文全走 (K1)（见 §3b）。

⟹ **在 (K1) 或 (K2)-with-`g|F|≤1` 的论文里，(Z-dom) 不需要两张表就已判定为真。**
剩下真正判不了的，是**既不走 (K1) 也不走 (K2)** 的那一类：把符号直接塞进**一个** `λ_ij`
并让它**同时驱动两个通道**——那正是仓库 (R1) 的 115× 反例形状。**这一类在文献里真实存在**（见 §1 第 4 行）。

## 3. 最值钱的一条：失效模式在文献里真实存在，而且是**逐篇**的，不是逐材料的

#4（arXiv:2210.06231）与 #1/#2/#3 **同一作者、同一材料族**，但约定不同：

- #1–#3：`Λ^Z = λ^ph + λ^sf`（两片皆 ≥0），`Λ^Δ = λ^ph − λ^sf` ⟹ (Z-dom) 自动 ⟹ **A**；
- #4：Eq.(1)（Z）与 Eq.(2)（Δ）**共用同一个 `Λ_kj`**，而输入里 `λ^s_12 < 0`
  ⟹ **Z 通道拿到负的带间贡献**，即「制造配对吸引却不缴质量重整化的税」
  ⟹ 正是仓库 (R1) 那个 **115×** 反例的形状 ⟹ **C，天花板对它逐字不适用**。

⟹ **分类的单位必须是「论文的约定」，不是「材料」。**
同一个 LiFeAs/铁基，换一篇论文就可能从 A 掉到 C。
写覆盖清单时不能写「铁基 = 覆盖」，只能写「用 (K1)/(K2,g≤1) 约定的计算 = 覆盖」。

⚠ 我**不判断** #4 的物理对错（Z 通道该不该拿负号是模型作者的选择）；
我只判断**天花板的前提在它上面不成立**。

## 3b. 余量普查：s± 支**处处取等**，但取等的两种机制安全性完全不同

team-lead 要的「已读 s± 篇里的 `g`（或等价的带间符号幅度）」——**答案是这些论文里没有 `g`，
因为它们全走 (K1)**。(K1) 下的等价量是逐元余量

> **`m_ij := |Λ^Δ_ij| / Λ^Z_ij = |λ^ph_ij − λ^sf_ij| / (λ^ph_ij + λ^sf_ij) ≤ 1`**，
> (Z-dom) ⟺ `m_ij ≤ 1`（自动）；**`m_ij = 1` ⟺ `λ^ph_ij` 与 `λ^sf_ij` 中至少一个为 0**。

逐篇核出的**支集**（我本人读的原文位置，全部为作者明写的赋值，非推断）：

| # | 论文 | `λ^ph` 的支集 | `λ^sf` 的支集 | 交集 | ⟹ `m_ij` |
|---|---|---|---|---|---|
| 1 | arXiv:1304.3638（LiFeAs 四带） | 仅 `(1,1)`（Eq.(4) 的 `λ_11`，Table 2 第 4/5 行 0.86/0.90；正文：`λ^ph_ii = λ^ph_ij = 0` 为出发假设，只补回 `λ_11 ≠ 0`） | 仅带间 `(1,3),(2,3),(1,4),(2,4)` 及其转置（正文：`λ^sf_ii = 0`，「SF 只给带间」） | **∅** | **≡ 1（每个非零元）** |
| 2 | arXiv:1101.3473（四化合物三带） | 情形 2 仅对角 `λ^ph_ii = 0.35`（`Ω_0^ph = 18 meV`）；情形 1/3 `λ^ph ≡ 0` | 仅带间（正文：`λ^sf_ii = 0`，「only interband sf coupling」） | **∅** | **≡ 1** |

⟹ (Z-dom) 在每个非零元上恰好取等，余量为零，且这是逐 k 的**
（支集不交 ⟹ 在每个 `(i,j)` 上两个函数中只有一个非零 ⟹ `|Λ^Δ_ij(k)| = Λ^Z_ij(k)` 对**所有** k）。

### ★ 但这个「零余量」和 (K2b) 的「零余量」**不是一回事**

| | (K1) 支集不交 | (K2b) `g ≤ 1` |
|---|---|---|
| 取等 | `m_ij ≡ 1` | `g|F| = 1` |
| 越界要付出什么 | **必须离开 (K1) 约定本身**——在两片皆 ≥0 的前提下，任何非负扰动都让 `m_ij` **严格下降**（给对角加 `λ^sf_ii > 0` 或给带间加 `λ^ph_ij > 0` 都使 `|Λ^Δ| < Λ^Z`） | **一个拟合数字改一位**——`g` 是自由标量，`g = 1.001` 在同一约定内合法 |
| ⟹ | **安全的等号面**：它是类的极点，类内无法越过 | **危险的等号面**：无结构保护 |

⟹ 越界的真实途径只有 #4 那一条：**把符号直接塞进一个同时驱动两通道的 `λ_ij`**（`λ^s_12 < 0`），
即**换约定**，不是「(K1) 的参数取得不好」。这与 §3 的结论一致（分类单位是约定）。

### 一条对天花板数值的连带简化（`analytic`，给 s± 支）

支集不交 ⟹ `M2^ph` 纯对角、`M2^sf` 纯非对角 ⟹
**`M2″_Z = diag(M2^ph) + c_GF·offdiag(M2^sf)`**（`c_GF = π²/(6𝔤(2))`），
即 (Z-dom-k) 的对角项里 `c_GF·M2^sf_ii` 一项**在这一族上恒为零**。

⚠ **「零余量」不是坏消息，也不是好消息，要说准**：(Z-dom) 是**前提**不是待收紧的量，
取等意味着天花板链上这一步 **无损**（把 `|Λ^Δ|` 换成 `Λ^Z` 不放大任何东西）；
它**不**意味着天花板更容易被违反——违反需要 `m_ij > 1`，而 (K1) 内不可能。

## 6. 诚实边界

1. 我没有做穷举检索。**「B 类 0 个」只对 §2 写死的人口成立**，且几乎肯定是选样效应
   （我能读到全文的，恰好是把方程印全的那批）。若把只报「有效 `λ_ij`」的唯象拟合文献扫进来，B 会立刻非零。

   **按材料计数会放大单篇论文的权重**——所以 §2 同时给了按条目与按材料两种口径。
3. #5 的 `g = 0.78` 是**最佳掺杂 YBCO 一个拟合点**；欠掺/过掺、别的化合物的 `g` 我没查。
   「d 波覆盖」不能从这一个数推广到整族。
4. `Λ^ph`/`Λ^sf` 逐元非负在 (K1) 里是**假设**（作者取 Lorentz 型非负谱）。若某篇的 `α²F^sf_ij` 自身变号，
   (K1) 的三角不等式论证不再适用。我读到的四篇里没有这种情形。
5. **(K2b)（纯符号型 `|F| ≡ 1`）在本轮人口里 0 篇。** §0 那一行是**约定层的警示**，不是观察到的类；
   若后续扫到这类论文，必须取到 `g` 的数，不得因「已读的 d 波 `g = 0.78`」或「`|F| ≤ 1`」放行。
