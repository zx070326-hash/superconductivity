1. **(ML3-abs) 不需要 Eq.(37)（`Λ^sf_ij ≥ 0` 逐元）。** 它被严格更弱的一对条件蕴含：
   **(i)** `Λ^sf ⪰ 0`（band-space PSD）—— **免费**；

## 1. Team B 的拆分松在哪

天花板消费的是（`multiband_ceiling_lift_2026-09-18.md` §2 的 (ML1)(ML2)）

```
L(k) := diag(R^Z(k)) − Λ̃^Δ(k) ⪰ 0     （对每个 k）,     R^Z_i := (Λ̃^Z w)_i / w_i,   w_i = √N_i
```

Team B §2 按 `L` 对 `Λ^ph`、`Λ^sf` 的线性性拆成

```
L = [diag(R^ph) − Λ̃^ph] + [diag(R^sf) + Λ̃^sf] =: L^ph + M
```

再要求 `M ⪰ 0` **独立**成立。`L^ph ⪰ 0` 是无条件的，所以拆分**声音**（`L^ph ⪰ 0 ∧ M ⪰ 0 ⟹ L ⪰ 0`），
但它**丢掉了 `L^ph` 的富余**：`L^ph` 通常严格正定，可以吸收 `M` 的一部分亏损，拆分后这部分余量被扔掉。

Team B 为拆分给的理由是：纯自旋涨落极限 `Λ^ph = 0` 是普查表里需独立覆盖的边界情形，
在该极限下 `L = M` ⟹ `M ⪰ 0` 必须独立成立。**这对那一个普查条目成立**，
但**不能外推到 `Λ^ph ≠ 0` 的 FeSe**——而 FeSe 正是本轮的判决对象。
⟹ 这是一起「把边界情形的要求当成一般要求」的作用域错误，不是计算错误。

## 2. 不拆分：一个恒等式

**引理 (L-id)〔analytic，我手推〕。** 对任意**对称** `Λ̃` 与任意正权重 `w`，令 `R_i := (Λ̃w)_i / w_i`，则

```
xᵀ(diag(R) − Λ̃)x  =  ½ Σ_{i≠j} Λ̃_ij ( √(w_j/w_i)·x_i − √(w_i/w_j)·x_j )²        (L-id)
```

*证明*（一行配方）：`Σ_ij Λ̃_ij (w_j/w_i) x_i²` 按 `Λ̃` 的对称性对称化为
`½ Σ_ij Λ̃_ij [(w_j/w_i)x_i² + (w_i/w_j)x_j²]`，减去 `Σ_ij Λ̃_ij x_i x_j = ½ Σ_ij Λ̃_ij · 2x_i x_j`，
每一项恰好配成 `(√(w_j/w_i)x_i − √(w_i/w_j)x_j)²`。`i=j` 的项给 `(x_i − x_i)² = 0`。∎

**两个直接推论**：
- **对角元不进**。`Λ̃` 的对角元在 (L-id) 右侧完全消失 ⟹ 任何基于 (L-id) 的条件都只约束 i≠j。
- **`w` 恒在核里**。取 `x = w` 时每一项为零 ⟹ `diag(R) − Λ̃` 恒有零本征值，`min eig ≤ 0` 总成立，
  「`min eig = 0`」才是 PSD 的标志。（数值上这给了一条自检：见 §3 F 段 `min eig L^Z = −0.0000`。）

**定理 (U)〔analytic〕。** 设 `Λ^Z = Λ^ph + Λ^sf`、`Λ^Δ = Λ^ph − Λ^sf`（Team B §1 的约定，无库仑）。若
- **(i)** `Λ^sf ⪰ 0`，且
- **(ii)** `(Λ^ph + Λ^sf)_ij ≥ 0` 对所有 `i ≠ j`，

则 `L := diag(R^Z) − Λ̃^Δ ⪰ 0`。

*证明*：(i) ⟹ `Λ^Z − Λ^Δ = 2Λ^sf ⪰ 0` ⟹ `−Λ̃^Δ ⪰ −Λ̃^Z` ⟹ `L ⪰ diag(R^Z) − Λ̃^Z =: L^Z`。
由 (L-id) 与 (ii)，`L^Z` 的二次型逐项非负 ⟹ `L^Z ⪰ 0` ⟹ `L ⪰ 0`。∎

**条件 (i) 是免费的**〔analytic〕：`Im Λ^SF = 2 f^xc (Im χ) f^xc` 对实对称 `f^xc` 是**合同变换**，
Sylvester 惯性律 + passivity（`Im χ ⪰ 0`）⟹ `Im Λ^SF ⪰ 0` **被迫**，零自由度。
（见 `../meta/eq37_content_is_in_the_offdiagonal_2026-09-22.md`。**不要去数值检验它，那是恒等式。**）

⟹ **承重的只剩 (ii)，而 (ii) 严格弱于 Eq.(37)**：给定 `Λ^ph ≥ 0` 逐元，
`Λ^sf_ij ≥ 0` ⟹ `(Λ^ph+Λ^sf)_ij ≥ 0`，反之不然。

## 7. 追加（同日晚）：Loewner 序路线**恰好就是**条件 (i)——「接口 FAIL」要收窄

> 起因：`rpa-deep-dive` 报「PSD（Loewner）序 ⟹ (Z-dom) 逐元」**接口不成立**，给了一个精确 2×2 反例，

**它对的那一半**：`Λ^Z=diag(2,2)`、`Λ^Δ=[[0,−19/10],[−19/10,0]]` ⟹
`Λ^Z∓Λ^Δ` 两个矩阵的 `tr=4`、`det=39/100` 全 `>0` ⟹ Loewner 序 `−Λ^Z ⪯ Λ^Δ ⪯ Λ^Z` 成立；
而逐元 `|Λ^Δ_12|=19/10 > 0 = Λ^Z_12`。**「Loewner ⟹ 逐元 (Z-dom)」确实为假**〔rational-exact，2 个 2×2 / 4 个有理数〕。

**它错的两处**：

1. **它引的消费点在一个已被划掉的块里。** 它抄的 `multiband_ceiling_route_Gprime_2026-09-18.md:189–190`
   （`(Z-dom)` + `N_ij := ‖𝒪[Λ̃^Δ_ij]‖` + Horn–Johnson）整段带 `~~ ~~` 删除线，末尾写着「**已证伪，见上**」；
   同文件 `:185` 明说「**未被证伪的部分**：(Z-dom) 这个前提、引理 (ML3-abs) …… 全部照常成立，
   死掉的**只有**把块界换成 `|M2^Δ|` 的那一步」。活着的消费点有两个，都不是它引的那个：
   **(ML3-abs)**（`:191–197`，结论 `L := diag(R^Z) − Λ̃^Δ ⪰ 0`）与 **(Z-dom-k)**（§8.3，逐元非负 + 三角不等式，
   给 `Tc ≤ C_∞√(ρ(M2″_Z))`）。
2. **它的反例过得了活着的消费点。** 同一对矩阵，取 `w=(1,1)`：`R^Z=(2,2)`，
   `L = [[2,19/10],[19/10,2]]`，`det=39/100 > 0` ⟹ **`L ⪰ 0` 成立**。
   机制正是定理 (U)：其隐含分解 `Λ^ph=[[1,−19/20],[−19/20,1]]`、`Λ^sf=[[1,19/20],[19/20,1]]` 满足
   (i)（`det=39/400>0`）与 (ii)（`offdiag(Λ^Z)=0 ≥ 0`）。
   ⟹ **逐元 (Z-dom) 失效 ⇏ 天花板失效**；(Z-dom) 是充分条件，不是消费点本身。〔rational-exact〕

**真正的结论（比 FAIL 有信息，一行 analytic）**：Loewner 序与定理 (U) 的条件 (i) 是**同一件事**——
```
−Λ^Z ⪯ Λ^Δ ⪯ Λ^Z   ⟺   Λ^Z − Λ^Δ = 2Λ^sf ⪰ 0  且  Λ^Z + Λ^Δ = 2Λ^ph ⪰ 0
```
即「**(i)，外加白送一个 `Λ^ph ⪰ 0`**」。所以 PSD 序路线**不是死路，是 (U) 的前一半**；
它对后一半（(ii)，`Λ^Z` 非对角的**符号**）零贡献。缺口的位置因此被钉死在 (ii) 上，与 §0–§5 的判断一致。
**方向纪律**：这条等价是充要的，两边都可用；但它**不**提供 (Z-dom-k) 所需的「两片各自逐元非负」，
所以 §8.3 那条腿仍然只能走 (K1) 型约定，不能走 PSD 序。

**对派活的后果**：PSD 序方向**不再派新活**——不是因为它 FAIL，而是因为它买到的正是已经免费的那一半
（(i) 由合同变换 + Sylvester + passivity 无条件给出，见 §1），预算为 ∞。
