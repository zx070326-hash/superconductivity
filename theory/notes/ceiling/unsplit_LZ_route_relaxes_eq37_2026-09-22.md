## 1. Team B 的拆分松在哪

天花板消费的是（`multiband_ceiling_lift_2026-09-18.md` §2 的 (ML1)(ML2)）

```
L(k) := diag(R^Z(k)) − Λ̃^Δ(k) ⪰ 0     （对每个 k）,     R^Z_i := (Λ̃^Z w)_i / w_i,   w_i = √N_i
```

Team B §2 按 `L` 对 `Λ^ph`、`Λ^sf` 的线性性拆成

```
L = [diag(R^ph) − Λ̃^ph] + [diag(R^sf) + Λ̃^sf] =: L^ph + M
```

再要求 `M ⪰ 0` **独立**成立。`L^ph ⪰ 0` 是无条件的，所以拆分**声音**（`L^ph ⪰ 0 ∧ M ⪰ 0 ⟹ L ⪰ 0`），
但它**丢掉了 `L^ph` 的富余**：`L^ph` 通常严格正定，可以吸收 `M` 的一部分亏损，拆分后这部分余量被扔掉。

Team B 为拆分给的理由是：纯自旋涨落极限 `Λ^ph = 0` 是普查表里需独立覆盖的边界情形，
在该极限下 `L = M` ⟹ `M ⪰ 0` 必须独立成立。**这对那一个普查条目成立**，
但**不能外推到 `Λ^ph ≠ 0` 的 FeSe**——而 FeSe 正是本轮的判决对象。
⟹ 这是一起「把边界情形的要求当成一般要求」的作用域错误，不是计算错误。

## 2. 不拆分：一个恒等式

**引理 (L-id)〔analytic，我手推〕。** 对任意**对称** `Λ̃` 与任意正权重 `w`，令 `R_i := (Λ̃w)_i / w_i`，则

```
xᵀ(diag(R) − Λ̃)x  =  ½ Σ_{i≠j} Λ̃_ij ( √(w_j/w_i)·x_i − √(w_i/w_j)·x_j )²        (L-id)
```

*证明*（一行配方）：`Σ_ij Λ̃_ij (w_j/w_i) x_i²` 按 `Λ̃` 的对称性对称化为
`½ Σ_ij Λ̃_ij [(w_j/w_i)x_i² + (w_i/w_j)x_j²]`，减去 `Σ_ij Λ̃_ij x_i x_j = ½ Σ_ij Λ̃_ij · 2x_i x_j`，
每一项恰好配成 `(√(w_j/w_i)x_i − √(w_i/w_j)x_j)²`。`i=j` 的项给 `(x_i − x_i)² = 0`。∎

**两个直接推论**：
- **对角元不进**。`Λ̃` 的对角元在 (L-id) 右侧完全消失 ⟹ 任何基于 (L-id) 的条件都只约束 i≠j。
- **`w` 恒在核里**。取 `x = w` 时每一项为零 ⟹ `diag(R) − Λ̃` 恒有零本征值，`min eig ≤ 0` 总成立，
  「`min eig = 0`」才是 PSD 的标志。（数值上这给了一条自检：见 §3 F 段 `min eig L^Z = −0.0000`。）

**定理 (U)〔analytic〕。** 设 `Λ^Z = Λ^ph + Λ^sf`、`Λ^Δ = Λ^ph − Λ^sf`（Team B §1 的约定，无库仑）。若
- **(i)** `Λ^sf ⪰ 0`，且
- **(ii)** `(Λ^ph + Λ^sf)_ij ≥ 0` 对所有 `i ≠ j`，

则 `L := diag(R^Z) − Λ̃^Δ ⪰ 0`。

*证明*：(i) ⟹ `Λ^Z − Λ^Δ = 2Λ^sf ⪰ 0` ⟹ `−Λ̃^Δ ⪰ −Λ̃^Z` ⟹ `L ⪰ diag(R^Z) − Λ̃^Z =: L^Z`。
由 (L-id) 与 (ii)，`L^Z` 的二次型逐项非负 ⟹ `L^Z ⪰ 0` ⟹ `L ⪰ 0`。∎

**条件 (i) 是免费的**〔analytic〕：`Im Λ^SF = 2 f^xc (Im χ) f^xc` 对实对称 `f^xc` 是**合同变换**，
Sylvester 惯性律 + passivity（`Im χ ⪰ 0`）⟹ `Im Λ^SF ⪰ 0` **被迫**，零自由度。
（见 `../meta/eq37_content_is_in_the_offdiagonal_2026-09-22.md`。**不要去数值检验它，那是恒等式。**）

⟹ **承重的只剩 (ii)，而 (ii) 严格弱于 Eq.(37)**：给定 `Λ^ph ≥ 0` 逐元，
`Λ^sf_ij ≥ 0` ⟹ `(Λ^ph+Λ^sf)_ij ≥ 0`，反之不然。

（`k=0` 时权重 `2ω/(ω²+0) ≡ 2/ω`）。三组谱型逐位相符，相对差 `0.00e+00`〔numerical-evidence〕。
⟹ **印出的 `λ_ij` 把 (ii) 的 k=0 实例判死，且两个方向都判——不是「只能给 FAIL」。**
而 k=0 确实在需要的指标集内：(ML1)（L.70）的 Laplacian 项求和是 `Σ_{k≥0}`（`𝒵_0 = diag(u_n²)`），
配对项才从 `Σ_{k≥1}` 起 ⟹ **`Λ̃(0)` 只经 `L(0)` 进入**，而 `L(0) ⪰ 0` 正是 (U) 要保的东西。

**但 §4 的总判词仍成立，理由换了。** k=0 通过**不**外推到 k≥1。显式反例
`α²F^Z = G(6,2;1.0) − G(70,8;2.0)`：`λ^Z(0) = +0.9403`（k=0 **通过**）而 `λ^Z(7) = −0.9374`（k=7 **违反**），
违反幅度 `0.9969 × λ^Z(0)`；5 万–80 万点网格上逐位稳定到 10 位（`−0.9373951253`，16× 加密不动）
⟹ 不是求积赝物〔numerical-evidence，已做网格收敛〕。
机制是解析的：`λ_ij(k) = ∫ (2/ω)·φ_k(ω)·α²F_ij dω`，`φ_k(ω) = ω²/(ω²+(2πTk)²)` 对 ω **递增**，
把权重自低频挪向高频；`k→∞` 时 `λ_ij(k)·(2πTk)² → M2_ij := ∫2ω α²F_ij dω`
（实测 ratio 0.2819 → 0.9666 → 0.99965 → 0.999997 → 0.99999997；`M2^Z` 手算 `−5554.6` 对上脚本 `−5553.96`）。
⟹ **k 族的两端都钉在已知量上**：k=0 是印出的 `λ_ij`，k→∞ 由 `M2_ij`（`= λ⟨ω²⟩`）支配；
**只有中间的 k 需要谱形状**。这比 §4 的「逐 ω 未测」窄得多，也说清了具体该算什么。

净效果：§4 的「印出数据单靠自己给不出 (ii) 的 PASS」**不撤回**；
但其理由（「积分为正 ⇏ 被积函数处处为正」）**是错的**，正确理由是「k=0 通过 ⇏ k≥1 通过」。
判词写法随之改：不再写「积分级通过；逐 ω **未测**」，而写
**「k=0 与 k→∞ 两端可判；中间 k 未测」**。

### 8.2 库仑那道选择题前提为假：`Λ^Δ` 里**没有** `C`

**第一段：§4 错在哪。** §4 问「加入 `C` 后 `Λ^Δ` 写成 `Λ^ph−Λ^sf−C` 还是 `Λ^ph−Λ^sf+C`」，
并（正确地）拒绝从物理直觉推这个符号。但读原文后：**这个二选一本身不存在**——
在这条链里库仑层**根本不进 `Λ^Δ`**。`multiband_ceiling_lift_2026-09-18.md` §6.1 (μ1)（L.245–247）给的形状是

```
M_{(n,i),(m,j)} = 2 μ_ij · w^{(i)}_n w^{(j)}_m   (Gram 形)，    𝕆_μ := 𝕆 − M
```

即库仑是一个**独立算子被整体减掉**（L.230 扫描列的 `𝕆 − μ*_ij⊗K_c` 同形），
不是 `Λ̃(k)` 的逐元加项；`Λ̃` 与 `M2` 自始至终只用**未加库仑的** `α²F_ij`（L.341 明说）。
⟹ 我在 §4 设的那道选择题问错了对象。

**第二段：新陈述凭什么对，以及它比 §4 强。** 由 (μ1)：`μ ⪰ 0 ⟹ M ⪰ 0 ⟹ 𝕆_μ ⪯ 𝕆`〔analytic〕。
定理 (U) 给 `𝕆 ⪯ 𝕆_pair`。Loewner 序传递 ⟹

```
μ ⪰ 0  且  (U)(i)(ii)    ⟹    𝕆_μ ⪯ 𝕆 ⪯ 𝕆_pair
```

且 `λ₁` 对 `⪯` 单调（Weyl）⟹ 对 `𝕆` 的上界**逐字**也是对 `𝕆_μ` 的上界。
**方向审**：天花板是 `Tc` 的**上**界、`Tc` 由 `λ₁ = 1` 定出 ⟹ `λ₁` 变小只会让 `Tc` 变低
⟹ 用 `𝕆` 的界覆盖 `𝕆_μ` **方向正确**（单边界方向规则的一次正用）。
两组条件作用在**不同对象**上（`μ` vs `α²F^ph/α²F^sf`），无耦合、无新前提。
⟹ **§4 的「定理 (U) 目前只覆盖声子+自旋涨落两片，不含库仑层」写弱了：
库仑层免费复合进来，代价只是 `μ ⪰ 0`，而那正是 CANONICAL 已立的 (C2)。**

**前提非空（不是恒真式）**：同表 L.231–232 的负对照——`μ*` 逐元 ≥0 但**非 PSD** 时 ratio 46.7、
带间负时 9.70，**均违反** ⟹ `μ ⪰ 0` 真在承重。
**仍未测**：`μ*` 的**频率依赖**版本——L.332–333 明说 (μ3) 的 Anderson–Morel 约化只对**静态** `μ_ij` 证过。
本节的复合**只用到 `M ⪰ 0`**，故在可分近似下仍成立；但若要从物理的 `μ` 出发论证 `μ* ⪰ 0`，那一环未证。

| 结论 | 级别 |
|---|---|
| ω 积分坐在 `Λ̃(k)` 内部；(ii) 是对 `λ_ij(k)` 的条件；印出的 `λ_ij` 就是 `λ_ij(0)` | `analytic`（读定义 L.44） |
| (ML1) Laplacian 求和含 k=0、配对项自 k≥1 起 ⟹ `Λ̃(0)` 只经 `L(0)` 进入 | `analytic`（读 L.70） |
| k=0 通过 ⇏ k≥1 通过（显式反例，违反 0.9969×，网格收敛 10 位） | `numerical-evidence` |
| `λ_ij(k)·(2πTk)² → M2_ij`（k 族高端由 `M2` 支配） | `analytic`（控制收敛）+ 数值确认 |
| `μ ⪰ 0 ⟹ 𝕆_μ ⪯ 𝕆 ⪯ 𝕆_pair`，库仑层免费复合 | `analytic`（(μ1) + 传递性 + Weyl） |
| 「`Λ^Δ` 里 `C` 的符号」这道选择题**前提为假** | `analytic`（读 (μ1) 的形状） |

**对派活的后果**：
- §4 的两个挡路项**均已判掉，不再派**。
- 唯一新开的口子是「中间 k 的 `λ^Z_ij(k)`」：它需要两片各自的 `α²F_ij(ω)` **谱形状**，
  而按 `zdom_iron_based_zero_dof_2026-09-21.md` 的台账，**无文献同时真算声子与自旋涨落两通道**
  ⟹ **数据不存在，缺口在数据侧不在数学侧**。不派；改记为数据缺口。
