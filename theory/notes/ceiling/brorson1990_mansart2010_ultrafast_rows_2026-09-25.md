## 2. 定义同构（G3）

**Brorson：PASS。** Eq.(1) 逐字 `T_e ∂T_e/∂t ≃ −(3ħ/πk_B) λ⟨ω²⟩ (T_e − T_l)`，`⟨ω²⟩` "defined by McMillan"
⟹ 即 Allen PRL 59,1460 Eq.(14) 的**首项**、同一个 `λ⟨ω²⟩`。因此上游的方向审计原样继承：丢掉的修正项为负 ⟹ **`X_fit ≤ X_true`**。
另有作者自陈的一条加强：NbN 与 V₃Ga 弛豫时间≈脉宽，其值 "should cautiously be regarded as **lower bounds**"（期刊页 2174）——与 Allen 方向**同向**。

**Mansart：定义同构但换算链有歧义（§5）。** 三温度模型（电子 + 强耦合声子子集 T₁ + 其余晶格 T₂），`g = (6ħγ/πk_B) λ⟨ω²⟩`（其 Ref.28）。
⚠ 这里的 `λ⟨ω²⟩` 只是**与 T₁ 子集耦合的那部分**：电子–T₂ 耦合在模型里被置零 ⟹ 若真实存在，拟合出的 `X` 是**全谱 `X` 的下估**——方向与判别器所需**相反**（见 §5）。

## 5. RMTA κ 的订正（结论 2、3）——两段分写

### 5a. 旧陈述错在哪

Tier-0 §5 与 Bose 2008 那篇给头条的 RMTA 风险包封是 **Sc κ=1.3969 ⟹ r(Nb₃Ge) ≤ 0.7399**，并在
[`savrasov_vs_pap1977_crossmethod_eta_2026-09-25.md`](savrasov_vs_pap1977_crossmethod_eta_2026-09-25.md) §7.4-3 写「A15 全是 Nb/V 基，RMTA 在 Nb 上可用 ⟹ 最紧点落在 RMTA 可靠的那一侧」。
缺陷：两者都是**理论 vs 理论**（RMTA vs 线性响应），而在 V 上**两种理论一起**高于实验
（Savrasov `λ_V=1.19`、Pap(I) `1.055`，实验侧 `λ_exp=0.80`、`λ_lit=0.82`）⟹ 理论间一致不排除共同高估；
「Nb/V 基」把 Nb 的 3% 推广到了 V，**V 从未被实验锚定过**。

### 5b. 新陈述凭什么对

`κ := X_RMTA / X_exp`，`X_RMTA = η_tot(I)/M × 4180.159`（单位常数 = (137.0959/2.120450)²，与 Tier-0 脚本一致，脚本内核过）。
**方向**：`X_exp ≤ X_true` ⟹ `κ ≥ κ_true` ⟹ 印出的 κ 是**上**界；头条包封 `r_true ≤ r·√κ` 需要的正是 κ 上界 ⟹ **方向安全**。

| 材料 | X_RMTA | X_exp | κ | κ(X_exp−1σ) | 备注 |
|---|---|---|---|---|---|
| Cu | 30.0 | 29 | 1.034 | 1.200 | |
| Nb | 343.2 | 320 | **1.072** | 1.183 | Cu 覆层 |
| Ti | 422.7 | 350 | 1.208 | 1.321 | |
| **V** | 565.7 | 280 | **2.020** | 2.176 | Cu 覆层；`X_exp` 与 `λ_lit·⟨ω²⟩=288.6` 相差 <5% |
| V₃Ga | 762.8 | 370 | **≤2.062** | 2.461 | Klein 1979 同源 η（η_A 子晶格合计）；作者自称下界 ⟹ 上界上加上界 |
| Cr | 337.8 | 128 | 2.639 | 2.990 | **300 K 反铁磁（T_N≈311 K）——对象失配** |

V 的 κ≈2 是**实验对实验也对得上**的（Brorson 的 X 与 λ_lit·⟨ω²⟩ 相符），不是单一测量的偶然；
但它**没有**区分「RMTA/线性响应共同高估 e-ph」与「覆层/表面使 V 的读数偏低」——后者会让 κ 被**高**估，对头条是保守方向，不削弱下表的 PASS。

**Nb₃Ge 头条（r=0.626，翻判决需 κ=2.5518）重解：**

| κ 来源 | κ | r(Nb₃Ge) ≤ |
|---|---|---|
| 旧：Sc（Bose 2008） | 1.3969 | 0.7399 |
| Nb 元素 / 1σ | 1.072 / 1.183 | 0.6483 / 0.6810 |
| V 元素 / 1σ | 2.020 / 2.176 | 0.8898 / 0.9234 |
| V₃Ga（Klein 同源 A15）/ 1σ / 2σ | 2.062 / 2.461 / 3.051 | 0.8989 / **0.9820** / **1.0935 翻** |
| Cr（对象失配，仅如实报） | 2.639 | 1.0170 翻 |

**读法**：
- Nb₃Ge 是 Nb 基 ⟹ **最近邻证据是 Nb 的 κ≈1.07**，给 r ≤ 0.65–0.68。V/V₃Ga 的 κ 迁移到 Nb₃Ge **没有证据支撑也没有证据反对**——**指示性**。
- 但 V₃Ga 是**同一作者、同一方法、同一结构类**的 η（Klein 1979 同表），这是迄今与 Nb₃Ge 最「同源」的实验锚 ⟹ 不能以「是 V 不是 Nb」为由丢掉。
  按它：头条在 1σ 下以 **~2%** 余量 PASS、在 2σ 下翻。
- 反向的缓冲（均未量化、只定符号）：Brorson 自称 V₃Ga 值是下界（真 X 更大 ⟹ 真 κ 更小）；Allen 修正项为负（同向）。
- ⟹ **判词**：「Nb₃Ge r=0.626 PASS」在 Nb 锚下稳固；在最悲观的同源 A15 锚下**临界**。**先前「余量 1.83×（κ）」的说法作废，改为「Nb 锚 2.4×、同源 A15 锚 1σ 1.04×」**。
- V₃Ga 自身的**实验分母** r = 0.4045（Tc=16.5）= Tier-0 RMTA 版 0.282·√κ——**恒等式**，不是独立证据，不计入语料。

## 6. Mansart（结论 4）

**g→X 换算因子已判定为 6**：印出区间 "6.8 < g < 8.0 mJ/K/s/m³" 的单位**缺一个十的幂**（排印）；
只有用因子 6 时存在某个 10^k（k=17）使区间 [58.94, 69.34] 括住作者的 64 meV²，因子 3 下不存在任何 10^k 括住（投毒：把 64 换成 128，因子 3 必须变成可括住——实测成立）。
晶格常数 a=3.96、c=12.98 Å 为文献常用值、**未一手取**；判别只要求其误差 ≪2×。

**判别器预算**：阈值 `X* = (Tc/K)² = 128.11 meV²`（Tc=24 K，"same batches" ⟹ **G1 满足**）。
印出 `X≈64` ⟹ **r = 1.4148**；Table I 四行 r ∈ [1.357, 1.471]。判别器（「各向同性声子 Eliashberg 解释不了 24 K」）需 X **上**界 ⟹ 条件式：**除非 X 被低估 ≥ 2.0016×**。

**为什么不能无条件入账**——两个已点名、方向都不利的机制，第一个的量级恰为 2×：
1. 印出 ODE 是 `2C_e ∂T_e/∂t = …`。若 "2" 是排印而拟合代码用 `C_e`，则 `X_Allen = 128` ⟹ **r = 1.0004**，落在阈值上。
2. 三温度模型把电子–T₂ 耦合置零 ⟹ 若真实存在，`X_fit` 低估全谱 X（§2），量级未定。

机制 1 的量级**恰为** 2×（把 r 推到 1.0004）；机制 2 方向不利、量级未定 ⟹ 与上游基准（Wu 两法分歧 1.065×）比，这一行的余量**不是** 1.9×「稳固」，而是**被一个未排除的因子 2 吃掉**。
⟹ Mansart 行记为**条件式判别器，不入账**；上游 §3 的「铁基 `2.00×`」二手数字在此被**一手复现**（1.4148² = 2.0016），但其可用性判为否。
