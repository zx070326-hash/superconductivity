## 2. 任务 1：#4（arXiv:2210.06231）独立重读，二次确认 C 类

### 2.1 一手材料

本轮自取 `arxiv.org/pdf/2210.06231`（Ummarino, Torsello，*S+-+d wave multiband Eliashberg theory for the
iron pnictides*），`pdftotext -layout -enc UTF-8` 转录（`_umm2210.06231.txt`）。这是与 census 上一轮**独立的第二次抓取**
（census 原文档没有留下这篇的脚本/PDF，只给了正文摘录）。

**Eq.(1)（Z 方程）**：

```
ωnZk(ωn,φ) = ωn + πT Σ_j ∫dφ'/2π  Λkj(ωn,ωm,φ,φ') Nj Z(ωm,φ')
```

**Eq.(2)（Δ 方程，第 105 行）**：

```
Zk∆k = πT Σ_j ∫dφ'/2π [Λkj(ωn,ωm,φ,φ') − μ*kj(φ,φ')] × …
```

**Eq.(3)**：`Λkj = 2∫ΩdΩ α²F_kj(Ω,φ,φ')/[(ωn−ωm)²+Ω²]`。

**Eq.(6)**：`α²F_jk(Ω,φ,φ') = λ^s_jk α²F^s_jk(Ω) + λ^d_jk α²F^d(Ω)cos(2φ)cos(2φ')`。

**输入值（第 206–210 行，逐字）**：`λ1s2 < 0`（正文明写「负带间 s 波耦合」），`λ1d2 > 0`。

### 2.2 判定：这不是「取不到证据」，是「(Z-dom) 的前提在这篇论文里为假」

对照 (K1)/(K2) 的定义：

- **(K1)** 要求 `Λ^Z = Λ^ph + Λ^sf`（两个各自非负的片相加）、`Λ^Δ = Λ^ph − Λ^sf`——**这里没有两个片**，
  Z 方程与 Δ 方程用的是**同一个** `Λkj`（Eq.1 与 Eq.2 里逐字相同的符号），不存在可拆分的「加减两片」。
- **(K2)** 要求 `Λ^Z_ij = λ_ij ≥ 0`（Z 通道的耦合本身非负）、`Λ^Δ_ij = g·F_ij·λ_ij`——
  但这里 `Λ^Z_kj ≡ Λkj`，而 `Λkj` 由 Eq.(6) 定义，其中 `λ^s_12 < 0` 是**直接输入的负数**，
  没有任何非负的 `λ_ij` 可以剥离出来单独喂给 Z 方程。

⟹ 这不是「(Z-dom) 判不了」，而是**Z 方程本身接收了一个可正可负的耦合**——
对真实的电声自能重整化，`Z` 通道的耦合恒等于 `2∫Ωα²F/[...]`，`α²F ≥ 0` 是谱函数的定义性质，
不可能为负；而这篇论文的 `α²F_jk` 由 Eq.(6) **人为构造**为 `λ^s·α²F^s + λ^d·α²F^d·cos2φcos2φ'` 的线性组合，
`λ^s_12` 被**当作自由拟合参数**取负值。**这是模型本身在探索「若把负号也塞进 Z 通道会怎样」的现象学实验，
不是对某个真实材料的第一性原理描述**（作者摘要原话：「in a general way」capture the essential physics）。

### 2.3 有没有第三条约定级充分条件能收进它？—— 没有，且理由是结构性的

**判定：不存在。** 理由：

1. **(Z-dom) 的两条已知充分条件 (K1)/(K2) 的共同骨架是「Z 通道的耦合来自一个独立构造的非负对象」**
   （(K1) 是两个非负片的和；(K2) 是单个非负 `λ_ij` 乘无符号形状因子）。
   这篇论文的建模选择直接打破了这个骨架——它**没有**一个「Z 通道专用的非负耦合」，
   `Λ^Z` 与 `Λ^Δ` 共用**同一个**可正可负的对象。任何试图收纳它的「第三条件」都必须放弃
   「Z 通道非负」这条最基本的物理要求，那样就不再是给 (Z-dom) 找充分条件，而是在讨论一个
   Z 通道本身可能违反因果/稳定性的病态模型。
2. 我尝试的唯一可能出路——**把 `λ^d_12`（正）与 `λ^s_12`（负）看成 (K1) 式的两片**——不成立：
   这两片在 Eq.(6) 里靠**不同的形状因子**（`1` vs `cos2φcos2φ'`）区分，不是「同一 `(k,j)` 位置上
   声子/自旋两个物理机制各自非负」，且 `λ^s_12` 本身（不带形状因子的那一片）就已经是负的——
   把它拆成「两个非负片之和」在数学上做不到（负数不能写成两个非负数的和，除非其中一个片本身取负，
   这就绕回了同一个问题）。
3. **这与 CANONICAL §2(a) 的「𝒫 对减法不封闭」是同一类结构障碍的又一次现身**：任何试图从一个
   带号对象里「挤出」两个非负片的努力，本质上都是在做 `𝒫` 减法不封闭已经堵死的那件事。

⟹ **#4 保持 C 类，且升级为「结构性排除」而非「证据缺失」**——前者比后者更强、更不可能被将来的新论文推翻
（只要还是同一种「单一带号 Λ 同驱两通道」的建模范式，就永远是 C）。

## 6. 诚实边界（本轮没做到什么）

1. **§2.3「不存在第三条件」不是穷举证明**，是对 (K1)/(K2) 骨架的结构性论证——不能排除未来有人发明一条
   完全不同形状的充分条件。但在「Z 通道耦合本身可正可负」这个建模事实不变的前提下，我认为**任何**
   充分条件都必须先解决「怎么从一个带号对象里定义出非负的 Z 通道耦合」这个前置问题，而这在数学上
   与「𝒫 对减法不封闭」是同一障碍。
2. **重费米子、有机超导体两族完全未检索**——不是「查过为空」，是**没有查**。
3. **FeSe 的 (Z-dom)（区别于已判定的 λ_ij 判据）仍未判定**——需要 `Λ^ph_ij(ω)` 与 `Λ^sf_ij(ω)` 两张独立的谱函数表，
   census 与本轮都未拿到（Essenberger PRB 94,014503 (2016) 仍是付费墙，仓库纪律下**挂用户**，本轮未尝试重新取件）。
