## 1. 桥梁：把两个天花板放进同一信息类（`analytic`）

三个矩，同一个 α²F：

| 记号 | 定义 | 阶 |
|---|---|---|
| `A`  | `∫α²F dω`      | 0  |
| `λ`  | `2∫α²F/ω dω`   | −1 |
| `M2` | `2∫α²F·ω dω`   | +1 |

Cauchy–Schwarz（对数凸性）：

```
A² = (∫ √(α²F/ω)·√(α²F·ω) dω)² ≤ ∫(α²F/ω)dω · ∫(α²F·ω)dω = (λ/2)(M2/2)
⟹  A ≤ √(λ·M2)/2 ,  等号 ⟺ ω ≡ const ⟺ Einstein
```

⟹ **Leavens 的 `kTc ≤ c(μ*,r)·A` 可以只用 (λ, M2) 表述**：`kTc ≤ c·√(λM2)/2`。
两个天花板于是吃**完全相同的输入**，可比。

**消费点**：固定 `η/M=9.172`（⟺ 松原单位下 `M2=1.453151466`，T=300 K）、`μ*=0.13`，
问「达到 300 K 所需的 λ 下限」。无量纲化 `A/(2πTc)=λω̄₂/2` ⟹

```
Leavens:  λ ≥ λ_area := 1/(π²c²M2)              （必要条件）
我们:     λ ≥ λ*     := ②(c) 认证的族阈值        （必要条件）
```

**方向审计**：两者都是「真所需 λ」的**下**估（必要条件比真条件弱）⟹ 两侧同向，
数**越大**排除**越强**，可以直接比大小。单边界方向规则在此不构成障碍。


⟹ 先降后升，极小在 `N_c≈6` 附近。机制：顶本征向量 `v` **出节点**后，
给全正的 `u_c` 添加分量反而**减小** `|⟨u_c,v⟩|` ⟹ 压制变弱。
这与 memory `mustar-extremality-two-routes-closed-2026-09-23` 记的
「失效由库仑驱动（v 出节点）」是同一机制。
⟹ **凡涉及 `N_c` 的扫描都不得用单调性省格。**
