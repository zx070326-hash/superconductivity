## §2 它漏了什么（两条约定风险，都是我读页图查出的）

### (R1) ★ Eq.(1) 写的是 `ω_D/1.45`，不是 `ω_log/1.2` —— 差点作废整条反解

页图逐字：`T_c = (ω_D/1.45)·exp[−1.04(1+λ)/(λ−μ*(1+0.62λ))]`，
而 Eq.(4) 的 AD 式前因子是 `f₁f₂·ω_log/1.2`。

⟹ **纸面上 `Tc^AD/Tc^Mc ≠ f₁f₂`**，差一个 `(ω_log/1.2)/(ω_D/1.45)`。
反解机器的整个第一步就建在 `比值 = f₁f₂` 上 ⟹ 若该列真用 `ω_D`，本篇**不能当对照**。
teammate 没报这条，因为它只跑了「代进去能不能复现」，没核前提。
（这正是 memory `ad-tc-two-columns-backsolve-omega2` 里列的「用之前必过的三道」的第 1 道。）

**关闭方式，两条独立证据**（§4）：

1. **区间重叠检验 10/10**（判据见 §4 的方法论订正）。
2. **更强的一条**：若真用 `ω_D/1.45`，则反推所需的 `ω_D/ω_log` 要对
   **5 个不同晶体结构、两个压强**同时落在 1.142–1.272（中位 **1.2102**）。
   而 `1.45/1.2 = 1.2083` 恰在正中 ⟹ 这个"`ω_D`"不是物理量，
   是「前因子其实是 `ω_log/1.2`」的算术影子。
   ⟹ **Eq.(1) 正文的 `ω_D` 是记号沿用（McMillan 原文的写法），实算用 `ω_log`。**

判级：`numerical-evidence`。

### (R2) 正文把 `ω̄₂` 叫 "mean square frequency"（少了 root）—— 已关闭

若真是**均方**而非**根均方**，则 `r := ω̄₂/ω_log` 的量纲与定义全错。
**Eq.(6) 页图带 `^{1/2}`**：`ω̄₂ = [(2/λ)∫α²F(ω)ω dω]^{1/2}`，与 AD75 **同一个量**。
⟹ 正文是措辞松，**判据取自公式、不取自名字**（CLAUDE.md §1「不要从名字推语义」）。风险关闭。

### 副产品：`(r−1)` 无开方式的**第三条独立见证**

Eq.(4) 页图逐字：`f₂ = 1 + λ²(ω̄₂/ω_log − 1)/(λ² + [1.82(1+6.3μ*)(ω̄₂/ω_log)]²)`
——分子是 `(ω̄₂/ω_log − 1)`，**无平方、无开方**。
独立于 AD75 原文与 arXiv:2010.12225 Eq.(S6)，是第三条。见 `f2_defect_repair_2026-09-25.md`。

## §4 ★方法论订正：复现别人的表，必须传播**输入侧**的印刷精度

我第一版用的判据是 `|算出 − 印出| < 1 K`，那是拍脑袋的。
正确判据：**印出为整数 ⟹ 算出区间 ∩ `[印出−0.5, 印出+0.5]` ≠ ∅**。

按此重判，**只**传播输出舍入时给 **7/10**，三行落在区间外
（I4/mmm 两行；以及 YThH₁₈ μ\*=0.13：算 163.47 vs `[163.5,164.5)`，**只差 0.03 K**）。
若就此收笔，我会写下「(M1) 部分失效、模型可能不符」——**那是假 FAIL**。

把**输入**的印刷精度一并传播（λ 印两位 ⟹ ±0.005；ω_log 印一位 ⟹ ±0.05）后：**10/10 重叠**。

⟹ **纸面精度不足会被误判成物理/约定不符，进而误杀一条本来成立的前提。**
这条比本篇的主结论更可复用：凡「零参数复现文献表」的判据，输入侧的有效位数必须进区间。

## §5 ★★真正的阳性对照在反解方向，只有 2 点★★

teammate 交付的是**正向**（`ω̄₂ → Tc^AD`）。反解机器走的是**反向**：
`Tc^AD/Tc^Mc → f₁f₂ → f₂ → 解 r`。反向有正向没有的失效模式：
`f₂(r)` **非单调**（极大在 `r* = 1+√(1+λ²/c²)`，两个根）、以及**整数舍入被放大**。
⟹ 只有反向跑通并与印出的 `r` 比对，才是 (M2) 的对照。

**★「无根」不是失败，是机器自己拒答——fail-safe，不是 fail-silent。**
λ 小 ⟹ `f₂−1 ~ λ²(r−1)/Λ₂²` 被压到 0.4–0.9%，而 Tc 印成 1–2 位整数使比值噪声达 6–33%
⟹ 目标 `f₂` 被噪声顶到 `f₂` 的**极大值以上**，二分无根。
信噪相差 **~70×**（13.6–17.0 vs 0.011–0.242）。
⟹ 这些行**不是「宽到无法证伪」，是「根本没有信息」**——结论同、机理不同，
且后者是机器的**优点**：无信息时报错，不吐一个看似合理的 `r`。

## §6 自由度审计：为什么是 2 点而不是 10 点

(M2) 的**固有误差**已在 AD75 29 行合成对照上实测（`backsolve-failure-modes-M1-M2-split`）：
λ<1.2 中位误差 **0.0273**、λ≥1.2 为 **0.0042**，差 **6.5×**
⟹ **λ<1.2 的行本来就该整行弃用**，不是「通过了所以有效」。

本表 λ = 2.54 / 0.50 / 0.41 / 0.60 / 0.49 ⟹ **5 行里 1 行落在可用域内**。
该行 2 个 μ\* 端点 ⟹ **有效对照点 = 2**。
两条独立机制（固有误差 6.5× 劣化、§5 的信噪拒答）**指向同一批行**——互相印证，不是重复计数。

**精度实话**：`r = 1.2829`，反解区间相对宽度 **4.0% / 5.2%** ⟹ `r` 只定到 **±0.026**，
**不是 ±0.01**。这与 memory 里「不得声称 r 定到 ±0.01」一致。
