## 3. ★ 方向审计 —— 这一节决定哪个判词能下、哪个不能

Allen **Eq. (14)** 的完整形式（页图逐字）：

```
γ_T = (3ℏλ⟨ω²⟩ / πk_B T_e) · ( 1 − ℏ²⟨ω⁴⟩/(12⟨ω²⟩k_B²T_eT_L) + … )
```

Wu 的 Fig 3b 式 **= Eq.(14) 的首项**（丢掉修正因子）配 `T_e = √(T_L²+ΘF)`
（把 `√(T_L²+ΘF)` 展开即逐项复现其 `(1+T_L²/2ΘF)`）。修正项**为负** ⟹ 给定实测 `τ_fast`：

```
X_fit = λ⟨ω²⟩_true · (1−δ)  <  λ⟨ω²⟩_true ,   δ > 0
```

⟹ **分母被低估 ⟹ `r_true` 被高估。**

| 判词 | 需要 `r_true` 的哪一侧 | 本方向偏置 | 结论 |
|---|---|---|---|
| **PASS**（天花板未被违反，`r_true < 1`） | **上**界 | 偏高 ⟹ 保守 | ✅ **合法** |
| **排名**（`r_true > 0.6260`，夺冠） | **下**界 | 偏高 ⟹ **偏向夺冠** | ❌ **不得下** |

这与 Errea 表那轮**同形**（同一个数，两种判词方向相反）。

**但「不安全」可以换算成一个可交付的预算**——比单纯扣住判词有用得多：

```
夺冠临界:  λ⟨Ω²⟩ ≤ 2.7220 × 10⁴ meV²  (Tc = 219 K)
```

## 5. ★★ 规定性产物 —— 零 DFT、零 μ\*、单次实验即可判

天花板改写成实验可直接代入的形式：

```
T_c[K]  ≤  2.120450 · √( λ⟨Ω²⟩ [meV²] )          （C_∞ × 11.6045181）
等价：   λ⟨Ω²⟩  ≥  ( T_c / 2.120450 )²
```

| 目标 `T_c` [K] | 所需 `λ⟨Ω²⟩` [meV²] | 所需 `√` [meV] |
|---|---|---|
| 77 | 1.319×10³ | 36.3 |
| 150 | 5.004×10³ | 70.7 |
| 200 | 8.896×10³ | 94.3 |
| 250 | 1.390×10⁴ | 117.9 |

⚠ 这是**必要**条件，不是充分条件（`μ*>0` 与谱形状只会把 `T_c` 往下压）。

**这条规则对实验的用法**（用理论指导实验）：
1. 在同一样品上测 `τ_fast`（温度依赖或通量依赖）与 `T_c`；
2. 代入上式；`T_c > 2.120450√(λ⟨Ω²⟩)` 指向天花板被证伪——**但见 §5a：这条判词不是无条件的**；
3. 反过来，任何**尚未**测出 `T_c` 的候选材料，只要超快测得 `λ⟨Ω²⟩ < 2.00×10⁴ meV²`，
   就指向「不可能达到室温」——**同样见 §5a：本条原写作无条件排除，已订正为条件式**。

**对计算的用法（优化计算路径）**：判断一个候选是否值得做全套 `α²F` + Eliashberg，
只需先算 `η/M = Σ_a η_a/M_a`（Hopfield 参数，**不需要声子谱**，只需力常数/刚性近似），
与上表比对；低于阈值者直接出局。这正是 Allen 1987 摘要所说的
"the relative simplicity of the product λ⟨ω²⟩ = η/M has made possible many microscopic calculations"。
⚠ **此段用的是计算量 `η/M`，不经超快拟合 ⟹ 不受 §5a 缺陷影响**（它没有那个负修正项）；
但若改用超快实测值代入，就落进 §5a 的条件式。

这是一处**可被后续实验判死**的真张力，也是本路线最值得下一步投入的地方。

### 7a. 自由度审计：这**不是**第四条独立诊断

`λω̄₂²` 随 `P` **非单调**（@163 塌下去），而 `λω_log²` 单调递增。
看起来像 @163 的第四条独立诊断——**不是**。两列只差一个因子 `r²`，且 `λ`/`ω_log` 那一列单调
⟹ 非单调性**完全**由 `r(163)=1.1302` 偏低产生，而那正是已有的第二条诊断。
按 DOF 规则（一组数当 N 个检验之前先数自由度），**不计入独立证据**，只算同一事实换了个量再现。
