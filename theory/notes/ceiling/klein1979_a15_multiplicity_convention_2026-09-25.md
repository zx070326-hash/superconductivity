## 1. 问题

Klein–Boyer–Papaconstantopoulos, **PRL 42, 530 (1979)** TABLE I 印出 `η_A`、`η_B`（eV/Å²）。
A15 是 `A₃B`，A 位重数 3。两种读法：

```
M2_min  := η_A/M_A + η_B/M_B        （η_A 已是 A 子晶格合计）
M2_mult := 3η_A/M_A + η_B/M_B       （η_A 是单原子，需乘 3）
```

`M2_mult > M2_min` ⟹ 天花板更高 ⟹ `r` 更小。
仓库主判决取 `M2_min`，**理由一直只是「保守」**（单边界方向规则：`M2_min` PASS ⟹ `M2_mult` PASS）。
本篇查的是**另一个问题**：哪个才是**作者的约定**。

## 3. 先验证反演机械本身

论文自陈（页图，右栏）：

> `Both λ and T_c were determined for these compounds using estimated values of the`
> `Nb-site phonon moments from the experimental results for Nb₃Sn.`

即 **Nb₃Ge 的声子矩是借 Nb₃Sn 的**。用 `√⟨ω²⟩ = √(M2/λ_calc)·κ` 反演（`κ = 750.2803 K`）：

| | 反演 √⟨ω²⟩ |
|---|---|
| Nb₃Ge | **214.99 K** |
| Nb₃Sn | **214.90 K** |
| 相对差 | **0.042%** |

⟹ 两者在 0.1% 内重合，**与论文自陈的「借用」完全吻合**
⟹ 我的反演式 `λ_calc = M2/⟨ω²⟩` **就是作者用的那个式子**（至多差一个重数公因子），反演机械可信。

⚠ **但这一条对两种约定都成立**（√3 是公因子）⟹ 它验证的是**机械**，**不判约定**。

## 5. ★ 自由度审计：先分清哪些观测**不能**判约定

换约定 `M2_min → M2_mult` 等价于把**每一个** `√⟨ω²⟩` 乘同一个 `√3 = 1.7321`。
⟹ **任何比值型观测在换约定下恒不变，判别力为 0**：

- 簇比 `V/Nb = 1.3269` vs 质量标度 `√(M_Nb/M_V) = 1.3505`（符合度 **98.3%**）
  —— 这条很漂亮（说明反演值确实**像真声子频率**，验证了机械），
  但它**两种约定下完全相同**，**不得**当作支持任一约定的证据。
- §3 的 Nb₃Ge/Nb₃Sn 借用重合 —— 同理，判别力 0。

⟹ **只有「绝对能标 vs 外部锚」这一类观测才有判别力。**
（CLAUDE.md「把一组数字当 N 个独立检验之前先数自由度」。）

## 6. 有判别力的判据：绝对能标是否可能

模型无关的硬约束：**`√⟨ω²⟩ ≤ ω_max`**（均方根频率不超过谱的上端），A15 实测 `Θ_D` 在 230–330 K 量级。

| 约定 | 全表 √⟨ω²⟩ | 判 |
|---|---|---|
| **M2_min** | **[195, 291] K** | Nb₃X ~196–218、V₃X ~264–291，**全部落在 A15 声子能标内**；且 V 轻于 Nb ⟹ V 簇更高，**物理方向正确** |
| M2_mult | [338, 504] K | V₃X 要求 **456–504 K**，**超过任何已知 A15 的 Θ_D 本身 40–60%**，而 `√⟨ω²⟩` 本应**低于** `ω_max` ⟹ **物理上不可能** |

> **[numerical-evidence] 判词：`η_A`、`η_B` 已是 A / B 子晶格的合计量，`M2_min` 是作者的约定。**
> `M2_mult` 被证伪的裕度：V₃X 的 504 K vs `Θ_D ≈ 315 K`，超出 **+60%**。

## 7. 订正 teammate `a15-mult-convention` 的两处支撑

**它的结论我复核后同意**（见 §6）。但两处支撑必须改——

### 7.1 「~200 K」的**消费点错了**

teammate 把作者正文的 `~200 K` 当成「作者喂给 λ 的 ⟨ω²⟩」。页图逐字（期刊页 531 **左栏**）：

> `For instance, we find a value of μ* = 0.1–0.2 using the **Morel-Anderson formula**,¹⁰`
> `our fitted values of μ, and typical values of the A15 d-band width (~0.2 eV) and`
> `average phonon frequencies (~200 K).`

⟹ 这个 `~200 K` 是代进 **Morel–Anderson 公式估 μ\*** 的，**不是 λ 的声子矩**。
λ 的真正来源在同页：

> `Results are shown in Table I, along with the T_c values calculated using the`
> `**Allen-Dynes expression**¹³ and the **phonon density of states of Schweiss et al.**¹⁴`

（CLAUDE.md：重算前先确认那个量到底作用在**哪个变量**上，不要从名字推语义。）
该句**仍可**当作「作者认为 A15 平均声子频率的量级」的旁证，但级别要降，
且**不得**说成「作者自己反解得到的就该是这个数」。

### 7.2 相对差算错了锚

teammate 口头引 `√⟨ω²⟩ = √(3/5)Θ_D ≈ 0.775Θ_D`，却把相对差算在**裸 Θ_D** 上（报 Nb₃Sn「−7.6%」）。两者不能混：

| 化合物 | Θ_D | w_min（vs Θ_D / vs 0.775Θ_D） | w_mult（vs Θ_D / vs 0.775Θ_D） |
|---|---|---|---|
| Nb₃Ge | 302 K | 215.0（−28.8% / −8.1%） | 370.7（+22.8% / +58.4%） |
| Nb₃Sn | 232 K | 214.9（−7.4% / **+19.5%**） | 371.5（+60.1% / +106.6%） |
| V₃Si | 315 K | 290.7（−7.7% / **+19.1%**） | 501.2（+59.1% / +105.3%） |

⟹ 换成 Debye 模型锚 `0.775Θ_D` 后，`w_min` 其实是**偏高 10–20%**，不是「−7.6%」。
**但判决方向不变**：`w_mult` 在两种锚下都高出 60–160%。
⟹ 结论存活，支撑换成 §6 的「硬约束 `√⟨ω²⟩ ≤ ω_max`」，不再依赖 Debye 模型的 0.775 系数。

⚠ 那三个 `Θ_D` 是 **WebSearch 二手转述、未读一手**，只作数量级锚使用。
