## 2. 生成式：两者都是第一性原理，拟合赝物假说被证伪

这是本篇的**主结论**，也是 MgB₂ 先例真正该被套用的地方。

### 2.1 先把 MgB₂ 先例的教训陈述对 [analytic，本篇新证]

MgB₂ `μ*` 那次的毛病**不是**「判据漏看了某个自由度」。把它说成那样会推出错误的检查清单。
正确陈述：

> **命题（判据是完全不变量）。** 设 `V` 对称、对角严格为正，约定群按 `V ↦ D V D`（`D = diag(d_i)`，`d_i > 0`）作用
> ——这正是仓库约定无关定理（`λ_ij = f(i)g(j)V_ij`）商掉的那个群。取 `d_i := 1/√(V_ii)`（**唯一确定**），
> 则 `V` 被送到相关矩阵 `C`：`C_ii = 1`、`C_ij = V_ij/√(V_ii V_jj)`。
> 故 `C` 是**完全不变量**；而判据比值恰为 `r_ij = C_ij²`。
> ⟹ **`{r_ij}` 连同 `V_ij` 的符号，穷尽了整张表的全部约定无关内容。**

脚本 §1：2000 组随机（`d=2..6`，含负非对角、失衡 `D`）验 `|r(V) − r(DVD)|` 与 `|r − C²|`，最劣 **1.4e−14**。

⟹ **根本不存在「判据看不见的残余自由度」。** MgB₂ 的真实毛病是：它看见的那**一个**不变量
`= p₁₁p₂₂/(p₁₂p₂₁) = 2.23×2.48`，是从第一性原理 refs [15]/[16] **搬进来的**，不是那篇文章拟合出来的。
⟹ 正确的检查清单只有一条：**那个不变量是算出来的，还是被某个 ansatz 钉死的？**
这是关于**生成式**的问题，只能靠读 Computational Details 回答，**数印出来几个数没用**。

### 2.2 CaC₆：Metropolis 双 BZ 积分，零拟合 [L1，我自跑 `pdftotext -layout -enc UTF-8 -f 3 -l 3`]

Sanna et al., PRB **85**, 184514 (2012)，p.184514-3 «III. COMPUTATIONAL DETAILS» 逐字：

> The double Brillouin zone integration appearing in the definition of the band-resolved Eliashberg functions
> in Eq. (11) is evaluated with a **Metropolis integration scheme**. Random k points are generated on the
> Brillouin zone, then each k point is accepted or rejected with a probability depending on ξ_k, and its weight
> is set inversely proportional to the acceptance probability. We use a set of about **2 × 10⁴ accepted k points
> per band**. Then, electron-phonon matrix elements on this random mesh are obtained via **interpolation** from
> those calculated on the regular grid.

配套：ESPRESSO、GGA-PW、超软赝势、30 Ry / 300 Ry、**6×6×6** k 网格、电声矩阵元在 **10×10×10** 上。

⟹ 每个 `λ_JJ'` 是一次**独立**的随机双 BZ 积分，被积的是真正 k 分辨的 DFPT `g^ν_{k,k'}`。
**链条里没有任何拟合标度、没有任何 DOS 比值约化。** 与 MgB₂ `μ*` 在结构上完全不同。
**⟹ 赝物假说 (b) 对 CaC₆ 证伪。**

**转录自检**：我的表逐项与 `_chk_cac6_lambda_ij_criterion.py` 相同（含它订正过的 `(1b,2a)=0.105`、`(3a,2a)=0.145`），

## 3. CaC₆：违反有多少抗得住它自己的噪声

§2.2 的同一句话给出一个**新的**代价：表里每个数都带蒙卡噪声。
（2026-09-18 篇 §3/§5 限制 2 **已经**从经验上观察到「三带那两对与表自身噪声同量级」——
**那条观察不是本篇的**；本篇新增的是它的**机制来源**（Metropolis）、**逐对的严格舍入区间**、以及**逐对显著性**。）

### 3.1 两把尺子

**(i) 舍入区间 [rational-exact]，严格。** 印到小数点后三位 ⟹ 每个印出值 `x` 的真值在 `[x−1/2000, x+1/2000]`。
全部用 `fractions.Fraction` 精确有理算术。

**⚠ 方向审计（CLAUDE.md 单边界方向规则）**：本节的判决是 **FAIL（违反）**。
一个 FAIL **永远不能**由把比值**抬高**的单边估计支持。故只用

```
r_min = (λij − h)(λji − h) / ((λii + h)(λjj + h))      ← 与印出数字相容的最小比值
```

`r_min > 1` ⟹ 违反抗得住印刷舍入。`r_max` 只作参照，**任何判决都不从它读出**。

**(ii) 蒙卡噪声 [numerical-evidence]，是估计不是界。**
细致平衡 `N_J λ_JJ' = N_J' λ_J'J` 是 Eq.(11) 的**精确推论**（`⟨|g|²⟩` 对称），
物理上不可能使它非零 ⟹ **它的残差就是这张表的经验误差棒**。实测最劣：三带 **1.32%**、六带 **1.80%**。
比值含 4 个元 ⟹ `σ_ratio = 2 × σ_entry`（三带 2.64%、六带 3.60%）。

> **方向记账**：我把**最劣**残差当作**典型**逐元 σ，这**高估**噪声 ⟹ 使违反显得**更不**显著
> ⟹ 对 FAIL 判决是**保守**方向。且噪声只被用来把对子**移出**「稳」列，从不用来移入。

### 4.3 ★ 但这条 OPEN 咬不动 (Z-dom) [analytic]

**这才是对派活方那个「(Z-dom) 会不会被威胁」的回答，而且它不需要先解掉 §4.2。**

> **命题（(Z-dom) 的符号规范不变性）。** 设 `S = diag(s_i)`、`s_i ∈ {±1}`，并设链条消费的分解至多差这个规范：

>
> ```
> |Λ^Δ_ij| = |s_i s_j| · |Λ^ph_ij − Λ^sf_ij| = |Λ^ph_ij − Λ^sf_ij| ≤ Λ^ph_ij + Λ^sf_ij = Λ^Z_ij
> ```
>

而 §4.1 读到的两个模式**都**是 `s_i s_j` 型（`s = (+1,−1)`）——对 2×2 而言，
「对角一个号、非对角另一个号」**正是**该型唯一的非平凡对称模式，也正是 s± 规范。

⟹ **(Z-dom) 写在绝对值上，所以我从图里读到的那些负号对它完全无关。**
**FeSe 的负非对角声子元不威胁 (Z-dom)，且这个结论不依赖 §4.2 的 OPEN 被解决。**
