### (A1) 为什么仿射

```
G(k) = Σ_j λ_j ϖ̄_j²/(ϖ̄_j² + k²)  =  ∫ 2ω/(ω² + (2πTk)²) dν(ω)      ← 对 ν 线性
```

`K` 的每个矩阵元是 `G` 的线性组合 ⟹ 对 `ν` 线性。库仑项 `−2μ*u_cu_cᵀ` 与 `ν` **无关**

⟹ 紧（Prokhorov）。两个约束函数 `ω⁻¹, ω` 的一致可积性由同两个不等式给出。

⟹ 中间出现一条**两个工具都不收的带**，而且**细分消不掉它**（`γ` 不随盒子变小）。
逐盒算 `γ` 时两区**有重叠**（实测：`λ₁=0.278` 的盒子 `R₀=0.9206<1` 且 `μ>γ=0.181`，两边都收）。
⟹ 这是「**换了界就要重解**」的同一形状：把一个更松的 `γ` 代进原来的分区，
量到的不是「省了多少时间」，而是「分区本身失效」。

**物理判词（`certificate`）**：任何谱 `α²F ≥ 0`，只要

的**比较未做**：三个数各自的输入数据不同（`A` vs `(λ, ⟨ω²⟩ )`），直接比大小就是

有 `A ≤ √(λ·M2)/2`（Einstein 处取等）⟹ 面积天花板可以整体搬进本节的约束集里。**下一轮做。**

### 12.7 逐箭头门：B2 只测了「每个叶子上的上界 < 1」，那不是全部判词

判词 `sup_{ν∈𝒞̄} λ₁ < 1` 由三条箭头串成，B2 只覆盖第三条。另两条单独测
（`_chk_main_bb_coverage_and_arrowwise_2026-09-23.py`，λ=3.29 的 312 个叶子）：

| ① 归约 | 紧化极点集 = `(q,σ)` 闭正方形 | P0/P0b（§12.1） | 最劣 `4.4e−16` |

B4b 同时给出一条旁证：全体 2496 个采样成员的 float64 `max λ₁ = 0.999392831`，

⚠ B4b 的参照量是 float64 截断本征值（`numerical-evidence`，且对真算子是**下估**）
⟹ 它只能抓「上界比真值还小」的粗缺陷，**不能**替代区间算术；判词仍由 B2 的区间量出。

### 12.8 另一侧：`λ₁` 的认证**下**界 ⟹ 阈值被双侧夹住 + 投毒门

分支定界只产上界，全链单边 ⟹ 按 §10.8 的方向规则它**只能**给 PASS。
要证明这套工具不是 fail-open，需要一个方向相反的认证量：Rayleigh 商
`μ(v) = ⟨v,Mv⟩/⟨v,v⟩ ≤ λ₁(M)`（变分原理，任意有限支撑 `v`）
⟹ **iv 下的 `μ` 下端 `μ_lo` 是 `λ₁` 的认证下界**，`μ_lo > 1` ⟹ 该成员确实破天花板。

⚠ 方向说明：这里的「下估」支持 FAIL，**不违反**单边界方向规则——
规则说的是「下估一个**上界**只支持 PASS」；这里下估的是**被界的量 `λ₁` 本身**，两件事。

**GATE B3a**（Einstein 成员，`Nv=80`, `L=280`，`certificate`）：

⟹ **临界 `λ` 被双侧认证夹在 `[3.29, 3.31]`（宽 0.6%）**，两端都是 `certificate`。

### 12.9 一处自己抓到的缺陷 + 修正的复核

**旧陈述错在哪。** `certify` 的限额判据写成 `nleaf + len(stack) > maxbox`。
DFS 的栈深 ≤ `maxdepth`、`nleaf` 在投毒场景里几乎不增 ⟹ **这个量永远到不了限额**，
程序会去遍历深度 `maxdepth` 的整棵树（实测 λ=3.36 跑满 19 分钟未停，被我杀掉）。
改为数**已处理盒数** `nproc`。

**新陈述凭什么对（分开写，按 §W1 纪律）。** 该缺陷只决定「什么时候放弃」，
不进任何一次**接受**判定（接受条件是 `R₀<1` 或 `KT<1`，与限额无关）
⟹ 三个 PASS 跑（自然清空栈、0 失败盒）的盒子数在逻辑上不受影响。
但这是推理，不是证据，所以 **GATE B5** 用修好的代码重跑 λ=3.20：
`处理 331 盒，叶 161（R₀ 10 / KT 151），深度 11，最劣 0.999735983，失败 0`
⟹ **与修正前逐位相同（161）**，`worst` 逐位相同。修正已复核。
