## 引理 μ-1（Gram 形，取代 Kronecker 形）[analytic]

设多带库仑块 `M_ij = μ_ij · w^{(i)} (w^{(j)})ᵀ`，`w^{(i)} ∈ ℝ^N` **任意**。若 `μ ⪰ 0`（B×B 对称半正定），则 `M ⪰ 0`。

*证*。对 `v = (v_1,…,v_B)`，记 `a_i := ⟨v_i, w^{(i)}⟩`。则
  `⟨v, Mv⟩ = Σ_{ij} μ_ij ⟨v_i, w^{(i)}⟩⟨w^{(j)}, v_j⟩ = aᵀ μ a ≥ 0`。∎

三行，无需 Kronecker 特征值定理。**收益不在证明长度，在假设**：

| | 交付版 §6.1 | 引理 μ-1 |
|---|---|---|
| 形式 | `μ* ⊗ K_c`（**同一个** `K_c` 跨所有带对） | `μ_ij w^{(i)}(w^{(j)})ᵀ`（每带各自的 `w`） |
| 蕴含 | 库仑截断 `N_c` 必须**跨带相同** | `N_c^{(i)}` 可**逐带不同** |
| 蕴含 | 窗口内权重 `u_n` 必须跨带相同 | 每带可有自己的态密度权重廓线 |

多带材料的库仑截断由**共同的** `ω_c` 定，但 `N_c^{(i)} = ⌊ω_c/2πT⌋` 其实确实跨带相同；
真正被放开的是**权重廓线**——各带 DOS 不同时 `w^{(i)}` 本就不同。交付版的 Kronecker 写法
**在这一点上是假设，不是推论**。引理 μ-1 把它删掉了。

数值一致性：4000 组（B=2..5，`N_c^{(i)}` 故意取不等，`μ = AAᵀ`）最小本征值 `−3.07e-14`；
恒等式 `⟨v,Mv⟩ = aᵀμa` 逐点误差 `5.7e-14`。对照组（`μ` 逐元非负但非 PSD）最小本征值 `−7.69`
⟹ **PSD 是承重前提，不是技术方便**（与交付版表中 46.7× 违反同向）。

## 引理 μ-2（物理自动性的前半：屏蔽核 ⟹ Gram）[analytic]

设 `V` 是核 `V(k−k′)`，其 Fourier 变换 `V̂(q) > 0` 逐点（屏蔽库仑 `V̂(q)=4πe²/(q²+k_s²)` 满足）。
则对**任意** `ρ_1,…,ρ_B`（不必非负），`μ_ij := ⟨ρ_i, V ρ_j⟩` 是 `{V^{1/2}ρ_i}` 的 Gram 矩阵 ⟹ `μ ⪰ 0`。

*证*。`V̂ > 0` 逐点 ⟹ 由 Bochner 定理 `V` 是正定核 ⟹ 算子 `V ⪰ 0` ⟹ `V^{1/2}` 存在，
`μ_ij = ⟨V^{1/2}ρ_i, V^{1/2}ρ_j⟩`。Gram 矩阵恒 PSD。∎

⟹ 交付版 §9 把这条标成「我的物理论证，不是定理」**是低估了**：给定 `V̂>0`，它是定理。
真正的物理假设只有一条，而且是标准的：**屏蔽后的库仑相互作用在动量空间逐点为正**。

数值一致性：500 组（RPA/Thomas–Fermi 型 `V̂`，随机非负 `ρ_i`，B=2..5）最小归一化本征值 `+2.7e-4 > 0`。

## 引理 μ-3（物理自动性的后半：Anderson–Morel 保 PSD）[analytic]

设 `μ ⪰ 0`，`L := ln(E_F/ω_c) > 0` 是**标量**（共同截断）。则 `μ* := μ(I+Lμ)^{-1} ⪰ 0` 且对称。

*证*。`μ` 与 `(I+Lμ)^{-1}` 是同一个矩阵的函数 ⟹ 对易 ⟹ `μ* = f(μ)`，`f(x)=x/(1+Lx)`。
`μ` 的谱 ⊂ `[0,∞)`，而 `f ≥ 0` 且在 `[0,∞)` 上良定（`1+Lx ≥ 1`）⟹ 谱映射给 `spec(μ*) ⊂ [0,∞)`；
函数演算保对称性。∎

数值一致性：2000 组（B=2..5，`L ∈ [0.05,8]`）最小归一化本征值 `+5.6e-8 > 0`，对称性 `1e-9` 内保持。

⚠ **[订正 2026-09-18]** 本条原写「前提『`L` 是标量』是实质的……这是本条唯一的真缺口」。
**该缺口不存在**，见下面的引理 μ-3′：走合同变换而非谱映射，`L` 只需对称，标量性与对易性都不需要。
由 `universality-lift` 指出，主会话从零重导（手推两行 + `_scratch_ir/_chk_am_congruence_indep.py`）。

## 引理 μ-3′（合同形，取代 μ-3；逐带截断已覆盖）[analytic]

设 `μ ⪰ 0`，`L` 对称（**不必标量、不必与 `μ` 对易**），记 `S := μ^{1/2}`。则

> 　**`μ* := (I+μL)^{-1}μ = S(I+SLS)^{-1}S`**，
> 　且当 `μ ≻ 0` 时：**`μ* ⪰ 0` ⟺ `I + SLS ≻ 0`**。

*证*。`S(I+SLS) = S + S·SLS = (I+μL)S` ⟹ 两边左乘 `(I+μL)^{-1}`、右乘 `(I+SLS)^{-1}` 得
`(I+μL)^{-1}S = S(I+SLS)^{-1}`，再右乘 `S` 并用 `SS=μ` 得恒等式；它显然对称
（`S` 与 `(I+SLS)^{-1}` 各自对称，形如 `SMS`）。判据：`⟨v,μ*v⟩ = ⟨Sv,(I+SLS)^{-1}Sv⟩`，
`μ ≻ 0` ⟹ `S` 可逆 ⟹ `Sv` 遍历全空间 ⟹ `μ* ⪰ 0 ⟺ (I+SLS)^{-1} ⪰ 0 ⟺ I+SLS ≻ 0`。∎
（`μ` 奇异时只剩「⟸」，因为 `Sv` 只遍历 `range(S)`。）

**落到逐带截断**：AM 输运 `μ*_ij = μ_ij − Σ_k μ_ik L_k μ*_kj`，对数挂在**中间态的带指标**上
⟹ `L = diag(ℓ_i)`，`ℓ_i = ln(W_i/ω_c^{(i)})`。`ℓ_i ≥ 0`（截断不超过带宽）⟹ `SLS ⪰ 0`
⟹ `I+SLS ⪰ I ≻ 0` ⟹ **PSD，无条件**。μ-3 的标量前提整条删掉。

★ **但 `ℓ_i ≥ 0` 只是充分条件，判据比它窄**（这是我在 `universality-lift` 版本之上的一处收紧）：
真正要求的只是 `λmin(SLS) > −1`。实测：`L=diag`、**至少一个 `ℓ_i<0`** 的 17669 组里，
`μ*` **仍 PSD 的有 3063 组（17.3%）**；而 `I+SLS ≻ 0` 与 PSD 判决 **17669/17669 完全一致**。
⟹ 材料侧该问的不是「有没有某带 `ω_c > W`」，而是那个负 `ℓ_i` **够不够大**。

数值（`_chk_am_congruence_indep.py`，未提交，一致性用，不承重）：
恒等式在 `L=diag(ℓ>0)` 4000 组、`L` 对称 PSD 非对易 4000 组上 **0 失败**，
其中 `max‖[μ,L]‖ = 93.6`（远离对易）；两组 `μ*` 非 PSD 各 **0**。
前提非空：一般不定对称 `L`，20000 组里 **17076 组**把 `μ*` 打成非 PSD。

## 推论（天花板的 μ\*>0 版本）[analytic，条件于引理 (G)]

`𝕆_μ := 𝕆 − M`，`M` 如引理 μ-1。由 μ-1，`M ⪰ 0` ⟹ `𝕆_μ ⪯ 𝕆` ⟹ `λ₁(𝕆_μ(T)) ≤ λ₁(𝕆(T))` 对**每个** T。

**不需要 `λ₁` 对 T 单调**。记 `Tc[g] := sup{T : g(T) ≥ 1}`。
`g_μ ≤ g_0` 逐点 ⟹ `{T : g_μ(T) ≥ 1} ⊆ {T : g_0(T) ≥ 1}` ⟹ `Tc_μ ≤ Tc_0 ≤ C_∞√ρ(M2)`。

这一步值得单列：仓库里 `Tc` 的定义本来就是「对下跳取 sup」（`p4d-coulomb-global-tc` 的约定），
所以**不必借用唯一性定理的 T-单调性**——那条定理在多带算子上并未证过，借了就是越级。
集合包含比单调性弱，而这里够用。

⟹ **天花板 `Tc ≤ 0.1827262477·√ρ(M2)` 在 `μ* ⪰ 0` 下逐字成立**，与 `μ*` 的大小无关，
且 `M2` 仍只需**未加库仑的** `α²F_ij`。（整条链仍条件于引理 (G)，见 `multiband_ceiling_route_Gprime_2026-09-18.md`。）

## ★ 落到真实材料：一条可证伪的一行判据

上面把「`μ* ⪰ 0` 是否成立」从物理问题变成了**可查的算术问题**——只要 `μ*_ij` 是从屏蔽核算出来的，
它自动 PSD。**但多带文献里 `μ*_ij` 常常是拟合值**（MgB₂ 的 σ/π 双带、LaH10 的多带处理都有这种做法），
拟合不保证 PSD。于是：

### 引理 μ-4（判据的约定无关形式）[analytic]（2026-09-18 订正后新增）

文献里库仑项有两种写法，**对称化步骤不同**，混用会给出错误判决：

| | 约定 (A) | 约定 (B) |
|---|---|---|
| 方程里的库仑项 | `Σ_j μ_ij N_j Δ_j` | `Σ_j μ_ij Δ_j` |
| 哪个对象对称 | `μ_ij` 本身 | `K_ij := μ_ij/N_j` |
| 作用在 `Δ` 上的核 | `μ·diag(N)` | `K·diag(N)` |
| 对称化（`ψ_i := √N_i Δ_i`） | `√(N_i) μ_ij √(N_j)` | `√(N_i) K_ij √(N_j) = √(N_i/N_j)·μ_ij` |

两式**不可互换**：把 (A) 的公式套在 (B) 的数上，得到的矩阵根本不对称
（MgB₂ 两组实测 off-diag 1.6565 vs 1.1832 / 2.0429 vs 1.2689）。

**但判据本身可以写成约定无关的形式。** 设 `N_j > 0`。对任意指标集 `S`，
`μ_S = K_S · diag(N_S)` ⟹ **`det(μ_S) = det(K_S)·∏_{j∈S} N_j`** ⟹ 每个主子式与 `K` 的同号。
约定 (A) 下 `K = μ`，该式平凡成立。故**两种约定下同一句话**：

> **判据 PSD**：`μ` 的**全部主子式 ≥ 0`**。
> B=2 时 ⟺ `μ_11 ≥ 0`、`μ_22 ≥ 0`、**`μ_11 μ_22 ≥ μ_12 · μ_21`**。

*证*。对称化是合同变换（`diag(N)^{1/2}` 可逆）⟹ 保 PSD 判决；
`K` 对称且 PSD ⟺ 其全部主子式 ≥ 0（标准），再由上面的行列式恒等式换回 `μ`。∎

⚠ **注意是 `μ_12·μ_21`，不是 `μ_12²`**。约定 (A) 下 `μ` 对称、两者相同；
约定 (B) 下 `μ` **不对称**（`μ_12/N_2 = μ_21/N_1` 才是对称条件），写成平方就错。
随机检验：`μ_12·μ_21` 形式在两约定下 **0/200000** 不匹配；`μ_12²` 形式在约定 (B) 下
**7082/200000** 给出错误判决。脚本 `_scratch_ir/_chk_psd_criterion_conv_indep.py`（未提交）。

若通过 ⟹ 天花板对该材料逐字适用；若不通过 ⟹ **天花板不适用，且这本身是对那组拟合值的一个物理质疑**
（由引理 μ-2，任何来自正屏蔽核的 `μ` 都 PSD，非 PSD 的拟合值意味着拟合把非物理的东西吸收进了 `μ*`）。

### ★ 但「通过」在第一性原理值上是**没有信息量**的

由引理 μ-2，任何形如 `μ_ij = ⟨ρ_i, V ρ_j⟩`（`V̂>0`）的 `μ` **必然** PSD；
由引理 μ-3，AM 输运后仍 PSD。Mazin 的接触势模型、Moon–Kim–Chang 的第一性原理介电矩阵
**都是这个形状** ⟹ 它们通过判据是**被定理强制的**，不是关于材料的证据。
（`mustar-psd-materials` 在这两组上测得的 PASS，其价值是对引理 μ-2 的一次一致性检验。）

⟹ **非 PSD 只可能来自拟合。** 唯一有判别力的对象是用实验量（Tc、比热跳变、双能隙、
同位素指数）反解出的 `μ*_ij`。这把材料侧搜索的目标钉死了。

⚠ **[订正 2026-09-18]** 本节原写「对称化成 `μ̃_ij := √(N_i) μ*_ij √(N_j)`」并把它当作
**唯一**的对称化式，**那是约定 (A) 的式子，在约定 (B) 下错**（由 `mustar-psd-materials` 指出、
主会话从零复核确认，`_scratch_ir/_chk_mgb2_symmetrisation.py`）。原文同时写着「约定核对未做」，
却已经把其中一个约定的式子当作定论——**这正是「未核」应当阻止的动作**。
现已换成上面的引理 μ-4（两约定并列 + 约定无关判据）。
