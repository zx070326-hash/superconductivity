## 1. 定理（无条件版）

设各向异性 Eliashberg 的谱函数分解为 `α²F^Z = α²F^ph + α²F^sf`、`α²F^Δ = α²F^ph − α²F^sf`，
两片**各自逐元非负**。记 `M2^X_ij := ∫ 2ω α²F^X_ij(ω) dω`、`κ := (2πT)²`，

```
c_GF := (π²/6)/𝔤(2) = 1.2479204046
M2″_Z := diag(M2^ph + c_GF·M2^sf) + c_GF·offdiag(M2^ph + M2^sf)

          T_c  ≤  C_∞ · √( ρ(M2″_Z) ) ,        C_∞ = (1/2π)√𝔤(2) = 0.1827262477
```

**严格性**：链上每一步 `analytic` —— (ML1) / (ML3-abs) / (G′-1) 分块 Cauchy–Schwarz /
仓库引理 M / 定理 GF-mix / Horn–Johnson 8.1.18 逐元谱半径单调。
**唯二的非 `analytic` 成分**：
1. `𝔤(2)` 与 `C_∞` 的数值 —— `rational-exact`（按仓库既有档位）；
2. **物理前提 (Z-dom)** —— 不是数学缺口，是对文献的**前提核对**，见 §3。

**锐版（条件成立，不推荐主攻）**：`T_c ≤ C_∞√(ρ(M2^Z))`，额外需要「缺口 1」
（`𝕆_pair` 顶本征向量在物理锥内，`numerical-evidence` 0/400+1500）。
**证出缺口 1 的全部收益 = `√c_GF = 1.1171035783`（11.7%）**，实际材料上 MgB₂ 1.2% / LiFeAs 式 10.1%。
按预算优先纪律 **11.7% 不够格当主攻**（对照：当初降级引理 (G) 用的口径是 12–73%）。

> ⚠ `√c_GF` 有两个都**声音**的数：CERT-B 下端 `1.11711666484`、CERT-D 下端 `1.11710357844`。

## 2. 为什么是这个形状（两条不可绕的边界）

**(a) `𝒫` 是凸锥，对减法不封闭 ⟹ 符号必须在算子层消掉，不能在矩层消掉。**
`𝒫` 元素（正 Einstein 混合）的尾**恰好**是 `k⁻²`；`Λ^ph−Λ^sf` 可以给出 `k⁻⁴` 尾 ⟹ 掉出 `𝒫`
⟹ `M2^ph−M2^sf` **不是任何非负测度的矩、不界任何东西**（用它不是松，是**空**）。
反例：`ϖ_ph=0.1, λ^ph=10` / `ϖ_sf=5, λ^sf=M2^ph/ϖ_sf²` ⟹ `M2^Δ=0` 精确而 `λ₁(𝕆)=0.115511`（N=100…1600 六位不动）。
**且失效区不是零测角落**：定向扫 `r := M2^sf/M2^ph`，r=1 → 45/45 违反、0.99 → 39/39（最劣 73×）、0.9 → 20/31、0.5 → 0/42
⟹ **整个强补偿端塌掉，正是 s± 材料所在的一端**。
⟹ 凡 `M2^Δ`、`|M2^Δ|`、`ρ(|M2^Δ|)` 的写法**都注定不可修**。唯一可行：先 `‖𝒪[a−b]‖ ≤ ‖𝒪[a]‖+‖𝒪[b]‖`
把符号消掉，**再对两个仍在 `𝒫` 里的片各自取矩**。`c_GF` 就是这次「提前消符号」的全部代价。
（与仓库 `γ>2 ∩ 𝒫 = ∅` 是同一事实。）
⚠ 该 no-go 只否掉**矩路线**；换一个对带号 `f` 仍有定义的泛函（如 `C_f` 本身）不在其射程内——那是另一条路，未做。

**(b) (Z-dom) 不是形式条件。** 去掉它、用**单个**带号矩阵同时驱动两通道，天花板被违反到 **115×**。
