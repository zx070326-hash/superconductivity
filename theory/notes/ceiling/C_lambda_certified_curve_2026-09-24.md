### 1.1 ~~结构：紧度比随 λ 单调升~~ → **判据换掉**（2026-09-24 自订正）

**旧陈述错在哪。** 初稿写「`C_upper/C_∞` = 0.466 → … → 0.792 单调升 ⟹ 结构性佐证」。
**判据选错了，是一处方向错误**：`C_upper` 是**上界**，真值只满足 `C ≤ C_upper`。
**一列上界单调升，对真值 `C(λ)` 的单调性什么都不证**——上界的升降同时受真值和
「这一格收紧到多深」两件事支配，而后者是算力的函数，不是物理的函数。
补表立刻暴露了这一点：λ=8 的 `C_upper`(0.150915) **比** λ=10 的 (0.150565) **还大**，
那一列不再单调。若照旧判据读，会报出一个「紧度比在 λ≈8 掉头」的**假发现**。
（根因就是上面那格：λ=8 上侧只到 `f=0.025`，比别人松一级 ⟹ 上界偏高 3.6% 括号宽。）

**新陈述凭什么对。** 换成两条判据，各自标级：

## 2. 方向审计（承重）

两侧的方向是**相反**的，必须分开写：

- **上侧**：区间分支定界在 `w < ω̄*` 处认证 `sup_{𝒞̄} λ₁ < 1` ⟹ 真阈值 `ω̄* ≥ w`
  ⟹ `C = 1/(2π w √λ)` 是 `C` 的**上界**。
- **下侧**：Rayleigh 商在 `w > ω̄*` 处给 `μ_lo > 1`（单个成员即可，`sup ≥ 成员`）
  ⟹ 真阈值 `ω̄* ≤ w` ⟹ 同式给 `C` 的**下界**。

⟹ 必须有 `w_up < ω̄₂^E < w_lo`，等价 `C_lower < C_E < C_upper`。**这是可证伪的**（见 §4 V2）。

前提 **GATE D**（沿用）：`ω̄` 增大 ⟹ `λ₁` 增大，全部 λ 一致。

### 3.0 `FAIL-stop` 行印出的 `worst` 是**下估**，不许读成「差一点就过了」

λ=1.0 的 `f=0.060` 那行印着 `worst=0.999984044`，**小于 1**，看上去像「已经过了」。
不是。判定式在生产脚本第 80 行：

```python
ok = (len(Rres["fails"]) == 0) and (Rres["worst"] < 1.0)
```

该行 `worst < 1` 为真 ⟹ `ok=False` **只能**来自 `fails` 非空，即**有盒子未判定**。
⟹ 印出的 `worst` 是**已判定盒子上的 max**，是真 `sup` 的**下估**。
按单边界方向规则（`CLAUDE.md` §1）：**下估只支持 FAIL，永不支持 PASS。**
这一格没有证书，`f=0.060` 这个更紧的界**不存在**，不得援引。
（这也是为什么 §1 的表把「上侧收紧深度」单列一列：漏掉它就会把 λ=8 的松上界
