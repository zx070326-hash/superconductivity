## 1. 定理 GF 自含重证（`analytic`）

记号同 `P4_main_theorems.md` §0。`f: ℕ_{≥1}→[0,∞)` 非增、`Σf<∞`（⟹ `𝒪[f]` Hilbert–Schmidt、紧自伴）。

**(Z) 反射恒等式.** 取 `w∈ℓ²(ℕ)`，令 `y_n := u_n w_n`（`n≥0`），偶延拓 `y_{−1−n} := y_n`。
ℤ 上记 `ω_n := |2n+1|`、`ν(n) := (ω_n−1)/2 ∈ ℕ`、`S(m) := Σ_{k≤m} f(k)`。则

- `L2+L3` 的二次型：把 ℤ 拆成 `ℕ ∪ (−1−ℕ)`，四块分别给 `f(|n−m|)`（同侧）与 `f(n+m+1)`（异侧，因 `|n−(−1−m)| = n+m+1`），
  故 `Σ_{n,m∈ℤ} f(|n−m|) y_n y_m = 2·[L2+L3 型]`（约定 `f(0):=0`）。
- `L1` 的二次型：`Σ_{n≥0} (2S(n)/(2n+1)) w_n² = Σ_{n≥0} 2S(n) y_n² = Σ_{n∈ℤ} S(ν(n)) y_n²`。
- `‖w‖² = Σ_{n≥0}(2n+1)y_n² = ½⟨y,Ωy⟩`，`Ω := diag(ω_n)`。

⟹ **`⟨w,𝒪[f]w⟩/‖w‖² = [ T_f(y) − 2Σ_ℤ S(ν(n)) y_n² ] / ⟨y,Ωy⟩`**，`T_f(y) := Σ_{n,m∈ℤ} f(|n−m|)y_ny_m`。
（偶 `y` 与 `⟨y,Ωy⟩<∞` ⟺ `w∈ℓ²`，所以 sup 的范围一一对应。）

**Parseval.** `ŷ(θ) := Σ_n y_n e^{inθ}`，`σ_f(θ) := Σ_{k≥1} f(k) cos kθ`（绝对收敛，连续）。
`T_f(y) = ∫ 2σ_f(θ)|ŷ(θ)|² dθ/2π`。

**定理 GF.** 令 `C_f := −min_θ σ_f(θ)`。则
　**`−λmin(𝒪[f]) ≤ max( f(1), 2C_f )`**。

*证*. `−λmin = sup_y [2Σ S(ν(n))y_n² − T_f(y)] / ⟨y,Ωy⟩`。
(i) `−T_f(y) = ∫(−2σ_f)|ŷ|² ≤ 2C_f ∫|ŷ|² = 2C_f‖y‖²`。
(ii) `S(ν) ≤ ν·f(1)`（`f` 非增），且 `2ν = ω_n − 1` ⟹ `2Σ S(ν(n))y_n² ≤ f(1)(⟨y,Ωy⟩ − ‖y‖²)`。
(iii) 分子 `≤ f(1)⟨y,Ωy⟩ + (2C_f − f(1))‖y‖²`；除以 `⟨y,Ωy⟩`，用 `0 < ‖y‖²/⟨y,Ωy⟩ ≤ 1`（`ω_n ≥ 1`）：
系数 `2C_f − f(1) ≥ 0` 时取 1 得 `2C_f`，`< 0` 时取 0 得 `f(1)`。∎

（`λmin<0` 恒成立：`𝒪_nn = −2S(n)u_n² + f(2n+1)u_n² < 0` 对大 `n`。故 `‖𝒪[f]‖ = max(λ₁, −λmin)`。）

**Einstein 闭式.** `f = ⟦·⟧(ϖ)`：`Σ_{k≥1} ϖ²cos kθ/(k²+ϖ²) = (πϖ/2)cosh(ϖ(π−θ))/sinh(πϖ) − ½`（`θ∈[0,2π]`），
最小值在 `θ=π`：**`2C_{⟦⟧(ϖ)} = 1 − πϖ/sinh(πϖ)`**。

## 2. 引理 g（`analytic`）：`(1 − πϖ/sinh πϖ)/ϖ²` 的交错级数、单调性、上确界

`π/sin πz = Σ_{n∈ℤ}(−1)^n/(z−n)` 取 `z = iϖ`：`πϖ/sinh πϖ = Σ_{n∈ℤ}(−1)^n ϖ²/(ϖ²+n²)`（奇部相消）。故

> **`g(ϖ) := (1 − πϖ/sinh πϖ)/ϖ² = 2 Σ_{n≥1} (−1)^{n+1}/(ϖ²+n²)
>  = 2 Σ_{j≥1} (4j−1) / [ (ϖ²+(2j−1)²)(ϖ²+(2j)²) ]`。**

每个配对项 `>0` 且关于 `ϖ` 严格递减 ⟹ **`g` 严格递减、`g>0`**，且
**`sup_{ϖ>0} g = g(0⁺) = 2η(2) = π²/6 = 1.644934…`**，`g(ϖ) → 1/ϖ²·(1−0) ~ 0` 当 `ϖ→∞`。

即：**`2C_{⟦⟧(ϖ)} = ϖ²·g(ϖ) ≤ (π²/6)·ϖ²`**，且 `⟦1⟧(ϖ) = ϖ²/(1+ϖ²) ≤ ϖ²`。

数值核对（`_lemG_offdiag_GF.py`）：闭式 vs 交错级数（20 万项 + 尾界）六个 ϖ 差 `2.5e-11`；vs FFT 符号最小值九位相符；
2 万点网格上严格递减、最大 1.64493217（网格 `ϖ=1e-3` 处，`π²/6=1.64493407`）。

> ⚠ **float64 的 `g` 在小 ϖ 处灾难性抵消**（team-lead 指出，我独立量化，`_lemG_gf_followup.py`）：
> `1 − πϖ/sinh πϖ ~ (πϖ)²/6`，相对误差 `~1e-16/(πϖ)²`。实测 `ϖ=1e-6` 差 `1.7e-5`、`ϖ=1e-8` 差 **35%**（f64 给 2.2204）。

## 3. 定理 GF-mix：物理核的 `|λmin|` 由 `M2` 一阶矩控制（`analytic`）

设 `f(k) = ∫ ⟦k⟧(ϖ) P(dϖ)`，`P ≥ 0` 有限测度，`∫ϖ²P < ∞`。
（物理：`Λ̃_ij(k) = ∫ 2ωα²F_ij(ω)/(ω²+ω_k²) dω`，`P_ij(dω) = 2α²F_ij(ω)/ω dω`，`ϖ = ω/2πT`，
**`∫ϖ²P_ij = M2_ij/κ`**，`M2_ij := ∫2ωα²F_ij dω`、`κ := (2πT)²`。）

> **定理 GF-mix.**　`−λmin(𝒪[f]) ≤ max( f(1), ∫ϖ²g(ϖ)P(dϖ) ) ≤ (π²/6)·∫ϖ²P = (π²/6)·M2/κ`。

*证*. `f ≥ 0` 非增、`Σ_k f(k) ≤ (π²/6)∫ϖ²P < ∞` ⟹ GF 适用。
`C_f` 是 `f` 的线性泛函族 `{−σ_f(θ)}_θ` 的 sup ⟹ **次可加、正齐次**；Fubini（`Σ_k∫⟦k⟧(ϖ)P = Σ_k f(k) < ∞`）给
`−σ_f(θ) = ∫(−σ_{⟦⟧(ϖ)}(θ))P(dϖ) ≤ ∫C_{⟦⟧(ϖ)}P(dϖ)`，对 `θ` 取 sup：
`2C_f ≤ ∫ 2C_{⟦⟧(ϖ)}P = ∫ϖ²g(ϖ)P ≤ (π²/6)∫ϖ²P`（引理 g）。
又 `f(1) = ∫ϖ²/(1+ϖ²)P ≤ ∫ϖ²P ≤ (π²/6)∫ϖ²P`。代入 GF。∎

配合仓库引理 M（`λ₁(𝒪[f]) ≤ 𝔤(2)·∫ϖ²P`，定理 1(c) 逐字）：

> **推论.**　**`‖𝒪[f]‖ = max(λ₁, −λmin) ≤ max(𝔤(2), π²/6)·M2/κ = (π²/6)·M2/κ`**（因 `π²/6 = 1.6449 > 𝔤(2) = 1.3181`）。
