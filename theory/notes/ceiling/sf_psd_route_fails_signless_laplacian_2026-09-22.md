## 0. 三句话结论

1. **不能。** 精确断点找到了：天花板证明需要的不是「Λ^SF 作为带指标矩阵 PSD」，
   而是一个更强的量——一个「无符号图 Laplacian」（signless Laplacian）型对象必须 PSD，
   而这个对象在**仅有**带空间 PSD（不要求逐元非负）的假设下**普遍不 PSD**：
   随机扫描 20000 组，PSD 输入下下游对象 **46.6% 非 PSD**，最劣归一化本征值 `−2736`（远非边缘案例）。
2. **负对照通过**：把假设换回「逐元非负」（不仅仅 PSD），下游对象 5000/5000 全部 PSD——
   验证脚本本身没写反，链条走不通是真实的数学事实，不是脚本 bug。
3. **这解释了 team-lead 提出的「两个通道方向相反却都有利，很可疑」**：确实都有利（AM–GM 恒等式
   本身没问题），但「都有利」这件事**本身就需要逐元符号信息**才能证明——band-space PSD 是一个
   太弱的量，装不下 AM–GM 用到的 `|x_i||x_j|` 交叉项估计。不是逻辑陷阱，是真实的信息缺口。

## 1. 问题精确化：天花板到底在哪一格消费 Λ^SF 的什么性质

由 `multiband_ceiling_lift_2026-09-18.md` §2 的恒等式 (ML1)(ML2)，天花板证明要求

```
L(k) := diag(R^Z(k)) − Λ̃^Δ(k)  ⪰ 0     （对每个 k）
```

其中（对称化后）`R^Z_i(k) := (Λ̃^Z(k) w)_i / w_i`，`w_i = √N_i`（DOS 权重）。
这就是 (ML3-abs) 证明的对象。现有证明（同一份笔记 §5.0）用的是**逐元 AM–GM**：

```
Σ_ij Λ̃^Δ_ij x_i x_j ≤ Σ_ij |Λ̃^Δ_ij| |x_i||x_j| ≤ Σ_ij Λ̃^Z_ij |x_i||x_j| ≤ Σ_i R^Z_i x_i²
```

第二步 `|Λ̃^Δ_ij| ≤ Λ̃^Z_ij` **逐元**是这条链的唯一非平凡输入。代入 `Λ^Δ=Λ^ph−Λ^sf`、
`Λ^Z=Λ^ph+Λ^sf`，`Λ^ph≥0` 逐元（声子谱函数非负，无争议），这条逐元占优**恰好等价于**
`Λ^sf_ij ≥ 0` 逐元——这正是 Eq.(37) 要交付的东西。

**团队问题的精确形式**：能否只用 `Λ̃^sf` 的**带空间 PSD**（Team B 附录 B.1 已用涨落-耗散定理
建立的、比逐元正弱得多的性质）替代逐元非负，仍然拿到 `L(k) ⪰ 0`？

## 2. 精确拆分：问题可约化为「声子片」与「SF 片」的独立子问题

`L` 对 `Λ^ph`、`Λ^sf` 线性：

```
L = [diag(R^ph) − Λ̃^ph]  +  [diag(R^sf) + Λ̃^sf]
  =:      L^ph（标准图 Laplacian）    +    M（无符号 / signless Laplacian）
```

`L^ph ⪰ 0` **无条件成立**（`Λ^ph≥0` 逐元 ⟹ 标准图 Laplacian，教科书结果，与 SF 无关）。
剩下的问题**完全独立于 `Λ^ph`**：`M := diag(R^sf) + Λ̃^sf ⪰ 0` 是否只需 `Λ̃^sf` PSD？

**这个化简不是可有可无的一步，它钉死了检验范围**：仓库自己的覆盖清单里已经写了
「纯自旋涨落极限（`Λ^ph=0`）」是天花板需要独立覆盖的一个边界情形（CANONICAL §3 普查表）。
在该极限下 `L=M`，`L^ph` 完全帮不上忙 ⟹ **`M⪰0` 必须独立成立**，不能指望 `L^ph` 补一部分松弛。
这确认了下面单独检验 `M` 是对的目标，不是把问题切得比它该有的更难。

`M` 是标准图论里的「无符号拉普拉斯」（signless Laplacian, `Q=D+A`）：对 `A` **逐元非负**时
它和标准 Laplacian 一样无条件 PSD（`D±A` 都是 PSD，`Q=BBᵀ`，`B` 是关联矩阵）；
但对 `A` **只是 PSD（带负非对角元）** 时，这条性质**不是标准结果**——因为标准证明依赖
`A` 的每一项能拆成非负关联矩阵的秩一贡献，带负元时拆不出来。

## 3. 反例（手推 + 数值双确认）

**手推反例**（B=2，`w=(1,1)`）：`Λ̃^sf = [[4, −1.9], [−1.9, 1]]`。

- `Λ̃^sf` 本身 PSD：本征值 `[0.0793, 4.9207]`，`det = 4·1−1.9² = 0.39 > 0`。✓
- `R^sf = Λ̃^sf·w = (4−1.9, −1.9+1) = (2.1, −0.9)`。
- `M = diag(R^sf) + Λ̃^sf = [[6.1, −1.9], [−1.9, 0.1]]`。
- `det(M) = 6.1·0.1 − 1.9² = 0.61 − 3.61 = −3.0 < 0` **⟹ M 非 PSD**（本征值 `[−0.451, 6.651]`）。

**随机扫描**（`_scratch_ir/_chk_sf_psd_route_2026-09-22.py`，`git add -f` 已入库）：
构造 `A = SSᵀ`（`S` 随机，保证 `A` PSD、非对角可正可负）、随机正权重 `w`，`B=2..6`，20000 组：

| | 结果 |
|---|---|
| PSD 输入样本 | 20000/20000（构造保证） |
| `M` 非 PSD 的样本 | **9327（46.6%）** |
| 最劣归一化本征值 | **−2736.06**（`B=6`，非边缘案例，量级远超输入矩阵本身） |

**负对照**（同一脚本，`Λ̃^sf` 换成逐元非负构造，5000 组）：`M` 非 PSD 样本 **0/5000**——
证实标准 signless-Laplacian 结论在逐元非负下确实无条件成立，脚本构造本身正确，
上面 46.6% 的失败率是真实的数学事实，不是脚本方向反了。

## 4. 回答验收门第 4 条（负对照）

任务书要求：构造一个 `Im Λ^SF ⪰ 0` 但有负非对角元的例子，确认链条在其上仍然走得通；
走不通就说明实际上还是在偷用逐元正。

**结果：走不通。** §3 的手推反例就是这样一个例子（`Λ̃^sf` PSD、`Λ̃^sf_12=−1.9<0`），
在它上面 `M` 明确非 PSD——**链条在这个例子上断裂，且断裂不是数值噪声（det=−3.0，非 1e-10 量级）**。
这确认：想要在这一步只用 PSD 而不偷用逐元正是不可能的——`M⪰0` 与「`Λ̃^sf` 逐元非负」
之间没有已知的更弱等价刻画能把 46.6% 的失败率清零。

## 5. 回答验收门第 2 条（两个通道方向相反却都有利——为什么这不是逻辑陷阱）

team-lead 的怀疑：SF 在 Δ 通道减、在 Z 通道加，两者都朝「天花板不变」方向使力，
「两边都顺」通常意味着漏了一个消费点。**现在可以精确回答**：没有漏消费点，
AM–GM 恒等式 `Σ Λ̃^Δ x_ix_j ≤ Σ Λ̃^Z |x_i||x_j|` 本身是对的、且**确实**同时用到了
减号（左边）和加号（右边）——但这个恒等式要成立，中间那步 `|Λ̃^Δ_ij|≤Λ̃^Z_ij`
**需要 `Λ̃^sf` 逐元非负**才能保证，而这正是「消费点」：**消费点不在算子层面的方向，
在 AM–GM 那一步的逐元输入**。「两边都顺」是真的（物理上：自旋涨落既增强质量重整化、
又抑制配对，两者都压低 `T_c`），但「压低多少」这件事——也就是把它严格地写成算子序
`𝕆 ⪯ 𝕆_pair`——要求逐元信息，光有「两边都朝一个方向使力」这个定性事实不够严格化到算子不等式。

## 6. 回答验收门第 1 条（指标空间过渡）

不需要专门分析线性压缩 `P: (k,k') → (i,j)` 这一层——反例在**带指标空间自身**（`M` 的定义域
就是带指标 `i,j`）就已经断裂，压缩映射 `P` 根本没有机会引入或修复这个缺陷。
若 §2 的拆分是对的（`M` 独立于任何费米面细节，只依赖对称化后的带矩阵 `Λ̃^sf(k)`），
指标空间过渡这一层**从未成为瓶颈**，瓶颈在更早、更基本的一步。

## 7. 回答验收门第 3 条（μ\*>0 情形，定理 (Φ-A)）

**未检验，且据 §2–§5 判断不必单独检验**：本篇找到的障碍发生在 (ML3-abs)/`M⪰0` 这一步，
它是 (Z-dom) 判据本身的基础引理，**先于**是否加库仑（`μ*>0` 还是 `μ*=0`）的分支。
定理 (Φ-A) 处理的是库仑通道如何叠加进已经建好的天花板，不改写 (ML3-abs) 这条更底层的引理。

库仑通道的存在会修好一个纯粹发生在 `Λ^sf` 自身的信息缺口，故此处判**大概率同样不通，未做穷举验证**。

## 8. 为什么这和「库仑走 PSD 减法」不矛盾——两种机制不同构

`mustar_psd_multiband_ceiling_2026-09-18.md`（引理 μ-1 + 推论）证的是 `𝕆_μ := 𝕆 − M_coulomb`，
`M_coulomb ⪰ 0 ⟹ 𝕆_μ ⪯ 𝕆` —— **这是纯算子序减法，无条件成立，不需要任何 Laplacian 结构**：
库仑只以一个符号（配对通道排斥）单独出现，`M_coulomb⪰0` 直接给算子序，逻辑上一步到位。

而 Λ^SF **同时**出现在 Z 和 Δ 两个通道、且以相反符号出现在**同一个** `L(k)` 恒等式里——
这不是「算子减法」的形状，是「AM–GM 配平」的形状，后者对逐元符号敏感，前者不敏感。
**这是团队问题真正的答案**：库仑能走 PSD 减法，是因为它只用一次符号；SF 不能，
是因为它同时驱动了 (ML2) Dirichlet 恒等式两侧、且恰好是这个恒等式本身逼出了逐元条件。
两者形式上都叫「PSD」，但消费点的数学结构完全不同，不能类比推广。

## 10. 结论：条件① 不可绕过，明确记账

**FeSe 玻色层判决维持「A（条件×2）」不变**，条件①（Eq.(37) 非对角逐元正，仍是散文支撑）
**没有被本轮关闭**。这条路本身在 (ML3-abs) 这一格——不是「太难还没做完」，是**这一格的
数学结构本身排斥 band-space PSD 这个货币**：AM–GM 恒等式的中间步骤严格需要逐元符号，
46.6% 的失败率（且最劣归一化本征值 −2736，远非临界值附近的边缘反例）说明这不是
可以靠更巧妙的构造修补的缺口，而是真缺口。

**唯一还没排除的入口**：Coulomb 层的 `w=vε⁻¹` 是否也走类似 AM–GM 结构（若走，同样的反例
会击穿它；若走纯算子减法，`mustar_psd_multiband_ceiling` 的机制适用）——已由附录 B.2
（另一队 `coulomb-psd-probe`）查过，结论是 `w` 的 PSD 本身缺文献定理支撑（负面警告），
**这条路本轮不重复查**，与本篇的判定（SF 走不通）相互独立、互不影响。
