# Leavens `c(μ*,r)` 逐 μ* 有理精确下界 —— 头条比较升 rational-exact

> **leavens-cert（team-lead 派活）交付**。承接 `same_information_class_comparison_vs_leavens_2026-09-24.md` §4/§9
> 「μ\*=0.13 一格有 certificate 级族证书、其余 5 格靠 float64 Einstein 根」的级别限制，
> 本篇把 **分母侧** `λ_area`（经由 `c(μ*,r)`）在四个 μ\*（0 / 0.10 / 0.13 / 0.20，r=10）升到
> **rational-exact**（Fraction 精确算术，零浮点，唯一非纯有理输入是 π 的有理上界 `355/113`）。

## 1. 归约（analytic，两步）

**(a) 方向**：`_chk_main_leavens_c_and_phiA_rescale_2026-09-23.py` L265-266 给
`λ_area(c) = (2·300·KB/(c·pref))² = C/c²`，`C>0` 只依赖 `η/M`、与 `c` 无关
⟹ `dλ_area/dc = -2C/c³ < 0` 恒成立（数值差分独立核对）。
⟹ 要 `λ_area` 的**上界**，需要 `c` 的**下界**；`c(μ*,r)=max_w c(w)` 是一个 max
⟹ **任一点 `w` 处的下界即是 max 的下界**，这个方向不需要枚举/覆盖全部分支
（27 齿枚举是为了认证 `c` 的紧致上界，不是这次 `ratio>1` 判决需要的方向——已在 phase 1 报告里确认）。

**(b) N 截断方向**：diagonal 修正项若用**闭式**（不是部分和）：

```
S_n := Σ_{m≥0}[G(|n−m|) − G(n+m+1)] = G(0) + 2·Σ_{j=1}^{n} G(j)   (两条无穷尾恒等相消)
```

本篇 STEP 0 独立重推（不采信 team-lead 的推导原样，自己从定义重新展开求和抵消一次，
并用 Mtail=200000 的直接截断求和数值交叉核对，四点 w、四点 n，差 ~1e−9–1e−12，符合尾差量级）。
用闭式 `S_n` 时，`N×N` 矩阵 `K̂_N` 的**每个矩阵元**（含对角）都与 N 无关地等于无穷维算子
`K̂^∞` 的对应矩阵元 ⟹ `K̂_N` 是 `K̂^∞` 的**真正主子块**；`B_N`（`u_c` 支撑在 `n<N_c`）同理，
只要 `N≥N_c`。⟹ **广义 Rayleigh 商在受限子空间（后 `N` 坐标恒零）上的 sup ≤ 全空间的 sup**
（不需要经典 Cauchy 交错定理，直接是"子集的 sup ≤ 全集的 sup"这条最基本的不等式）：

```
θ_max(K̂_N,B_N) ≤ θ_max(K̂^∞,B^∞)   for N ≥ N_c
```

⟹ **有限 N 的（认证）下界，就是无穷维真值的下界**，不需要额外的 N-尾界引理。
（这推翻了 leavens-cert phase 1 报告里"N 截断方向不利"的结论——那条是用**截断和**版本的
`S_n` 算出来的，指纹是"`S_n` 是部分和"；闭式版本没有这个问题。两段写：旧结论错在用了
截断 S；新结论"闭式 S 下有限 N 是真正下界"独立复核过，见上。）

## 2. 有理精确 Rayleigh 下界（`rational-exact`，本篇唯一的新数值内容）

对固定有理 `w`（无 Coulomb 情形取细网格扫描到的 argmax 附近有理点；有 Coulomb 情形取
锯齿左端 `w=k/r`，`k` 由 float64 粗扫定位），把 `u` 吸进试探向量 `y_n := u_n v_n`
（`v` 是 scipy `eigh` 给出的 float64 广义本征向量，只用来**取**一个好的有理向量——
声音性与它的来历无关，任何有理向量都给合法下界）：

```
分子 = Σ_ij (G(|i−j|)+G(i+j+1)) y_i y_j − Σ_i S_i y_i²
分母 = Σ_i (2i+1) y_i² + 2μ*(Σ_{n<N_c} y_n)²
θ_lower := 分子/分母                     (Fraction 精确算术)
```

变分原理（analytic）：`θ_max(K̂_N,B_N) ≥ <K̂_N y,y>/<B_N y,y>` 对任意实（这里取有理）`y≠0`
⟹ `θ_lower ≤ θ_max(K̂_N,B_N) ≤ θ_max(K̂^∞,B^∞)`（§1(b)）⟹ `θ_lower` 是 `θ_max(w)` 的
**rational-exact 下界**。`c(w) = θ_max(w)/(π w)` ⟹ 用 `π` 的有理上界 `355/113`
（本篇 STEP 0.5 用 mpmath 50 位精度独立核验 `355/113 − π = 2.6676e−7 > 0`）除，
方向仍正确（`θ` 下界 / `π` 上界 / `w`(精确有理) = `c` 的下界）。

## 5. 级别标注（不许越级，CLAUDE.md 硬性要求）

- **`c` 下界这一列：rational-exact**（`N=40` 格 / 每格 162 个有理数，Fraction 精确算术，
  零浮点；唯一非纯有理输入 `355/113 > π` 已独立核验）。
- **`λ_area` 上界**：由 rational-exact 的 `c` 下界与 `C`（float64 物理常数换算）相乘得到，
  **`C` 本身未做区间化**，故 `λ_area` 上界整体只标 **numerical-evidence**——链条被最松的一环
  拖累。若要把 `λ_area` 本身升到 certificate，需要另外区间化 `η/M→C` 的换算（含 `sqrt`），
  这是**未做**的另一件事，不在本轮范围（预算未测，留给下一轮若有需要再派）。
- **`ratio_new`**：只有 **μ\*=0.13 一行**同时具备「分子（既有分支定界下端 3.29，certificate）
  分母（rational-exact 的 c 下界）都非纯 float64」的地位，是本篇唯一可以从 `numerical-evidence`
  升级判词地位的一行。**其余三行（0.00/0.10/0.20）的 `λ_ceil` 参考值是我打的 0.1% 示意折扣，
  不是严格证书**——这三行的 `ratio_new` 仅供数量级参考，不得当作认证排除，与
  `same_information_class_comparison_vs_leavens_2026-09-24.md` §4 的级别限制一致（那 5 格
  本来就没有族级 certificate，本篇没有新增，也没有声称新增）。
