## 1. 多带算子（从零推，未采信任何既有笔记）

标量端用仓库约定（`P4_main_theorems.md` §0 + `P4_uniqueness_strategy.md` §2.A）：
`𝒪[f]_{nm} = u_nu_m[f(|n−m|)1_{n≠m} + f(n+m+1)] − δ_{nm}·2u_n²Σ_{k=1}^n f(k)`，`u_n=(2n+1)^{-1/2}`。
（`|n−m|=0` 的项**不在**，因为 f 只定义在 k≥1；这一点后面是关键。）

从各向异性 Eliashberg 线性化方程出发（Matsubara 轴，`ω_n=πT(2n+1)`，`λ_ij(k)=∫2ωα²F_ij(ω)/(ω²+(2πTk)²)dω`）：

```
Z_i(n)          = 1 + u_n²( R_i(0) + 2 Σ_{k=1}^n R_i(k) ),      R_i(k) := Σ_j λ_ij(k)
Z_i(n)Δ_i(n)    = Σ_{j,m} [ λ_ij(|n−m|) + λ_ij(n+m+1) ] Δ_j(m)/(2m+1)
```

代 `ψ_i(n) = u_n Δ_i(n)` 得本征值-1 判据 `𝕆ψ = ψ`，

```
𝕆_{(n,i),(m,j)} = u_n u_m [ λ_ij(|n−m|)1_{n≠m} + λ_ij(n+m+1) ]
                  + δ_{nm}[ u_n² λ_ij(0) − δ_ij u_n²( R_i(0) + 2Σ_{k=1}^n R_i(k) ) ]
```

**这里就是 team-lead 的结构问题 2 的确切形态**：单带时 `k=0` 的配对项 `u_n²λ(0)` 与 `Z` 里的 `u_n²λ(0)` **精确相消**，所以标量 `𝒪` 的 `L2` 没有对角。多带时配对带的是**矩阵** `λ_ij`、`Z` 带的是**行和** `R_i`，**不相消**。

**对称化**：`λ_ij = N_j V_ij`（细致平衡 `N_i λ_ij = N_j λ_ji`），记 `w_i=√N_i`、`Λ̃_ij = √(N_iN_j)V_ij`（对称、逐元非负）。则 `R_i = (Λ̃w)_i / w_i`。用 `diag(w)` 共轭把配对块对称化而**不动** Z（Z 在带指标上对角）。以下一律用对称形式。

*标级*：`analytic`（初等代数）。**独立验证**：B=1 时逐元复现仓库标量 `𝒪`（maxdiff 5.6e-17，四个 ϖ），并由此得 `𝔤(2)=1.318140212`，落在仓库 CERT-D 的 rational-exact 包围 `[1.318140211762671, 1.318140212373478]` 内——我是从自己的算子从零重算的，不是转引。

## 2. 承重的结构恒等式：Z 与配对之差恰是一个**加权图 Laplacian**

对每个 `k≥0` 记 `Λ̃(k)` 与 `L(k) := diag(R(k)) − Λ̃(k)`。则**恒等式**

> **(ML1)**　`𝕆 = Σ_{k≥1} 𝒪[δ_k] ⊗ Λ̃(k)  −  Σ_{k≥0} 𝒵_k ⊗ L(k)`，
> 　　`𝒵_0 = diag(u_n²)`，`𝒵_k = diag(2u_n² 1_{k≤n})`（k≥1），均 `⪰ 0` 且对角。

记右边第一项为 **`𝕆_pair`**——它就是「把标量 `𝒪` 的核换成矩阵值核」，即 `𝒪` 逐元线性地作用在 `Λ̃(·)` 上；差别只在它的 Z 通道用 `Λ̃` 而不用行和 `diag(R)`。

*标级*：`analytic`（两行：把 (ML1) 展开逐元对照即可）。**数值复核**：maxdiff 2.2e-16，B=2、w 均匀/非均匀、Λ̃ 含负元各 4 组（stage0）。

> **(ML2) Dirichlet 恒等式**　对任意 `x∈ℝ^B`
> 　`⟨x, L(k) x⟩ = ½ Σ_{i,j} Λ̃_ij(k) w_i w_j ( x_i/w_i − x_j/w_j )²`。
>
> *证*：由 `R_i w_i = (Λ̃w)_i` 得 `Σ_i R_i x_i² = Σ_{ij}Λ̃_ij w_j x_i²/w_i`；对 (i,j) 对称化后配方。∎

*标级*：`analytic`。**数值复核**：20000 个随机 **带符号** `Λ̃`、B=2..6，最大相对偏差 1.3e-14——它是**恒等式**（对带符号的 Λ̃ 也成立），逐元非负只是让右边变成非负。

> **推论 (ML3)**　`α²F_ij(ω) ≥ 0` ⟹ `Λ̃(k) ≥ 0` 逐元 ⟹ `L(k) ⪰ 0` ⟹ `𝒵_k⊗L(k) ⪰ 0` ⟹
> 　**`𝕆 ⪯ 𝕆_pair`（算子序）**，故 `λ₁(𝕆) ≤ λ₁(𝕆_pair)`。

*标级*：`analytic`。**不等号方向**：这是 λ₁ 的**上界**，只支持 PASS。

**物理含义**：`w` 恰是 Laplacian 的核向量（`Lw=0`），所以被丢掉的那一项**只惩罚带间不平衡的能隙**（`x_i/w_i ≠ x_j/w_j`），对「所有带按 √DOS 同比例」的能隙**恰好为零**。这就是为什么丢它是干净的：它丢掉的正是多带相对单带的**额外压制**。

## 4. 饱和：多带天花板什么时候锐（`analytic`）

> **(ML4)**　若 `Λ̃ w = ρ w`（即 `w=√DOS` 是 `Λ̃` 的 Perron 向量，等价于 **`R_i = Σ_j λ_ij` 与带无关**），则
> `L w = 0`，于是在 `ψ = v ⊗ w/‖w‖` 上 `𝕆ψ = ρ (𝒪[F]v) ⊗ w/‖w‖`。
> **Perron 扇区精确退化为标量算子、耦合常数为 `ρ = λmax(Λ̃)`**，故 `λ₁(𝕆) = ρ·h(ϖ)`，**上界取等**。

*标级*：`analytic`。**数值复核**：`w` 取 Perron 向量时 6/6 个随机 (B=2,3,4) 构型 ratio = **1.000000000000**（12 位），`R` 的 B 个分量逐位相等；`w` 随机时 ratio 掉到 0.601–0.999（stage3 (iii)）。§6 的全局扫描里最大 ratio `1.00000000000002` 也正落在饱和点（`a=b`、`w=(1,1)`），超出量 1.6e-14 是舍入。

**这就是多带版的「Einstein 极值」**：单带里极值者是 Einstein 谱；多带里**在带指标上的极值者是「每条带的总耦合 `λ_i=Σ_jλ_ij` 都相等」的构型**。偏离越大，天花板越松，且松的量由 Dirichlet 型 (ML2) 显式给出。

**可检验推论**：天花板对多带材料的松弛度由 `λ_i` 的带间离散度控制，而 `λ_i` 是 EPW 输出里直接有的量——不需要任何新计算就能估计自己材料离天花板多远。
