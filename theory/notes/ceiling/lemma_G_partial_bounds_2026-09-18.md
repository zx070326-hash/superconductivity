## 1. 新工具：ℤ-反射 / Dirichlet 型恒等式（`analytic`）

对 `w∈ℓ²(ℕ)` 置 `y_n := u_n w_n (n≥0)`，**关于 `−1/2` 偶延拓** `y_{−1−n}:=y_n`；
在 ℤ 上记 `ω_n:=|2n+1|`、`ν(n):=(ω_n−1)/2`、`S(m):=Σ_{k≤m}f(k)`、`R(m):=Σ_{k>m}f(k)`。则

> **恒等式 (Z).**
> 　`⟨w,𝒪[f]w⟩ / ‖w‖²  =  [ 2⟨R∘ν, y²⟩ − Dir_f(y) ] / ⟨y,Ω y⟩`,
> 　`Dir_f(y) := ½ Σ_{n≠m∈ℤ} f(|n−m|)(y_n−y_m)² = Σ_{k≥1} f(k) Σ_{n∈ℤ}(y_{n+k}−y_n)² ≥ 0`.

推导：`L2+L3` 两项合成 ℤ 上的单个 Toeplitz 型 `Σ_{n,m∈ℤ}f(|n−m|)y_ny_m`
（`L3` 的 `f(n+m+1)` 正是 `|n−(−1−m)|`，负指标就是反射像）；`L1` 变成 `Σ_ℤ S(ν(n))y_n²`；
再用 `Σ_m f(|n−m|)=2‖f‖₁` 把 `Φ:=2S∘ν` 写成 `2‖f‖₁ − 2R∘ν`，`2‖f‖₁·I − T_f` 恰是**带权图 Laplacian**。

于是两端**对偶**：
```
λ₁(𝒪[f])      = sup_{y 偶}  [ 2⟨R,y²⟩ − Dir_f(y) ] / ⟨y,Ωy⟩
|λmin(𝒪[f])|  = sup_{y 偶}  [ Dir_f(y) − 2⟨R,y²⟩ ] / ⟨y,Ωy⟩
```
**(G) ⟺ 这两个 sup 中后者不超过前者。**

*核验*：有限支撑核（`1_{k≤1}`）随机 `w` 两侧差 `1.4e-17 / 9.4e-16`；
长尾核的偏差纯属窗口截断——`N=300/600/1200/2400` 上 `3.27e-4 → 1.63e-4 → 8.16e-5 → 4.08e-5`，
**每加倍严格减半，`O(1/N)`**。另：`K=1..64` 的阶梯核上，恒等式给出的 `−λmin` 与直接对角化**逐位相同**（差 `0.00e+00 ~ 2.2e-16`）。

## 2. 定理 G3：`c = 3`（`analytic`，五行，零计算机辅助）

把 `𝒪[f] = M[f] − L1[f]`，`M:=L2+L3` **逐元 ≥ 0**（因 `f≥0`），`L1` 对角 `≥0`。

> **(a)** 对称有界算子 `A` 与其逐元绝对值 `|A|`（设有界）：`|⟨y,Ay⟩| ≤ ⟨|y|,|A||y|⟩ ≤ λmax(|A|)‖y‖²`。
> 故 **`|λmin(A)| ≤ λmax(|A|)`**。
> **(b)** `|𝒪[f]| ⪯逐元 𝒫[f] := 𝒪[f] + 2L1[f]`（非对角已非负；对角 `|−L1_nn+f(2n+1)u_n²| ≤ L1_nn+f(2n+1)u_n²`），
> 且 `λmax(𝒫) ≤ λ₁(𝒪) + 2λmax(L1)`。
> **(c)** `λmax(L1[f]) = sup_{n≥1} 2S(n)/(2n+1) ≤ sup_n 2n f(1)/(2n+1) < f(1)`（`f` 非增 ⟹ `S(n)≤n f(1)`）。
> **(d)** `λ₁(𝒪[f]) ≥ 𝒪[f]_{00} = f(1)`（`L1_{00}=0`）。

**⟹ `|λmin(𝒪[f])| ≤ λ₁(𝒪[f]) + 2f(1) ≤ 3 λ₁(𝒪[f])`。级别 `analytic`。**

`f∈ℓ¹ ⟹ 𝒪[f]` Hilbert–Schmidt（仓库引理 M 证明里已用），(a) 的绝对求和收敛。

## 3. 定理 GA：`c = 2501567/1174507 = 2.129886838`（`rational-exact`）

把 (c) 的 `<f(1)` 换成 Abel 分解 + 试探向量。设 `f=Σ_K a_K 1_{k≤K}`，`a_K=f(K)−f(K+1) ≥ 0`。

> **关键不等式（逐项，`analytic`）** `2min(n,K)/(2n+1) ≤ θ_K := 2K/(2K+1)`，对**所有** `n,K ≥ 1`。
> （`K≤n` 时 `2K/(2n+1)≤2K/(2K+1)`；`K>n` 时 `2n/(2n+1)≤2K/(2K+1)`，因 `x↦2x/(2x+1)` 递增。）
> 故 `λmax(L1[f]) ≤ Σ_K a_K θ_K`，**对 n 一致**。

> **关键恒等式（`analytic`，本轮发现）** 取 `v_n = u_n t_n`，`t` 有限支撑长 `p`。
> 则 `q_K(v) := ⟨v,𝒪[1_{k≤K}]v⟩/‖v‖²` 满足 **`q_K(v) = q_∞(v)` 对所有 `K ≥ 2p−1`，精确相等**。
> （`⟨v,𝒪[f]v⟩` 只用到 `f` 在 `1..2p−1` 上的值。）`q_∞(v) = 2⟨u,v⟩²/‖v‖² − 1` 由仓库 (S1)。

## 4. 定理 GF：Fourier 路线——对一大类核直接给出 (G)（`analytic`）

由恒等式 (Z) + Parseval。记 `C_f := −inf_θ Σ_{k≥1} f(k)cos kθ ≥ 0`（`f` 非增 ⟹ `θ=π` 处求和 `≤0`）。

`Dir_f(y) = ∫Ψ_f|ŷ|²`，`Ψ_f(θ)=2‖f‖₁−2Σf(k)cos kθ`，于是
```
Dir_f(y) − 2⟨R,y²⟩ = −2∫(Σf(k)cos kθ)|ŷ|² + 2Σ_n S(ν(n))y_n²
                    ≤ 2C_f‖y‖² + f(1)(⟨y,Ωy⟩ − ‖y‖²)          [2S(ν) ≤ 2ν f(1) = f(1)(ω_n−1)]
```
除以 `⟨y,Ωy⟩` 并用 `0 < ‖y‖²/⟨y,Ωy⟩ ≤ 1`（`ω_n ≥ 1`，系数符号决定取端点）：

> **定理 GF（`analytic`）.** `|λmin(𝒪[f])| ≤ max( f(1), 2C_f )`。
> 配合 `λ₁ ≥ f(1)`：**`2C_f ≤ λ₁(𝒪[f])` ⟹ 引理 (G) 对该 `f` 成立（`c=1`）。**

### 4.1 Einstein 核：`2C` 有闭式

`f=⟦k⟧(ϖ)=ϖ²/(k²+ϖ²)` ⟹ `Σ_k f(k)cos kθ = (πϖ/2)cosh(ϖ(π−θ))/sinh(πϖ) − 1/2`，最小值在 `θ=π`：

> **`2C_{⟦⟧(ϖ)} = 1 − πϖ/sinh(πϖ) < 1`，对所有 `ϖ>0`。**（与 FFT 数值 9 位相符：ϖ=0.5/1/7 各一档。）

**推论（`analytic`）：`|λmin(ℌ(ϖ))| < 1` 对所有 `ϖ>0`。**
——数值印证：`ϖ=100` 给 0.999951、`ϖ=1000` 给 1.000000（从下逼近 1），完全吻合。

于是 **(G) 对 Einstein 核成立当且仅当（充分条件）`h(ϖ) ≥ max(ϖ²/(1+ϖ²), 1−πϖ/sinh πϖ)`**：

|---|---|---|---|---|---|---|---|---|
| GF 给的 `ρ` 上界 | 1.2449 | 1.1768 | 1.0170 | **0.9999** | 0.8554 | 0.7309 | 0.5813 | 0.3955 |
| 真 `ρ` | 0.7503 | 0.7370 | 0.7009 | 0.6965 | 0.6549 | 0.6092 | 0.5339 | 0.3907 |

- **`ϖ ≥ 1.0496` ⟹ (G) 成立**（阈值处用了 `h(ϖ)` 的数值 ⟹ 该阈值本身 `numerical-evidence`）。
- **`ϖ ≥ 1.9` ⟹ (G) 成立，全解析**：用仓库推论 (iii) `h(ϖ) ≥ lnϖ+γ+ln4−3/2−1/(12ϖ)−3/(16ϖ²)`，
  在 `ϖ=1.9` 给 `1.0096 > 1 > 2C`。（我核了该下界在 `ϖ∈[1.5,3]` 确实低于 `h`，但**未从零重推**推论 (iii)。）

### 4.3 物理核（消费点的真实输入）

`Λ̃_ij(k) = ∫⟦k⟧(ω/2πT)·P_ij(dω)`，`P_ij(dω)=2α²F_ij(ω)/ω dω`，总质量 `= λ_ij`。
`C_f` 对 `f` **次可加**（sup 的次可加性），故
```
2C_{Λ̃_ij} ≤ ∫(1 − πϖ/sinh πϖ) P_ij(dω) < λ_ij,     f(1) = ∫ϖ²/(1+ϖ²)P_ij < λ_ij
⟹ |λmin(𝒪[Λ̃_ij])| < λ_ij          (analytic，对任意 α²F_ij ≥ 0)
```
且由引理 M（`Λ̃_ij(k) ≥ P_ij([ϖ₀,∞))·⟦k⟧(ϖ₀)`）有 `λ₁(𝒪[Λ̃_ij]) ≥ P_ij([ϖ₀,∞))·h(ϖ₀)`。

> **可检验的逐材料判据（`analytic`）**：若存在 `ϖ₀` 使
> 　`P_ij([ϖ₀,∞)) · h(ϖ₀) ≥ ∫(1 − πϖ/sinh πϖ)P_ij(dω)`，
> 则 (G) 对该块成立，天花板**不付任何代价**。
> 粗口径：`h(ϖ₀)≥1` 需 `ϖ₀ ≳ 1.38`，即 `ω ≳ 8.7 T`；**我没有去查氢化物的 `α²F` 是否满足，不得当已验。**

## 5. No-go：绝对值 / Perron 族封顶（`rational-exact`）

定理 G3 的 (a)(b) 是「把 `𝒪` 换成一个逐元非负的控制者」。这一族的**极限**可以量出来：

**CERT-G2.** 取 `z_n=u_n s_n`，`s=(200,275,89,15,2)`（有理，`u` 的无理性成对抵消）：
```
λmax(|𝒪[1_{k≤1}]|) ≥ ⟨z,|𝒪|z⟩/‖z‖² = 9670047398/6630722595 = 1.458370073
λ₁(𝒪[1_{k≤1}])     ≤ 𝔤(2) ≤ 1.3181615784372800        [引理 M 取 G(k)=1/k²；仓库 CERT-B]
```
> **⟹ 任何形如 `|λmin(𝒪[f])| ≤ λmax(B[f])`（`B ⪰逐元 |𝒪|`）的论证，常数必 `≥ 1.106366`。**
> 特别地 **`c ≤ 1` 不可能由这一族得到**——定理 G3 / GA 的 (a)(b) 两步是**结构性**的损失，不是技术松弛。

数值上这个 barrier 更高：`sup_f λmax(|𝒪[f]|)/λ₁(𝒪[f]) ≥ 1.29636`（在 `f=1_{k≤2}` 取到；
另 400 个随机非负非增核最大 1.2521）。**级别 `numerical-evidence`**（`λ₁(𝒪[1_{k≤2}])` 缺上界）。

**这条 no-go 直接说明：要证 (G)（`c=1`，真值 0.814），必须保留核的振荡/抵消**，
定理 GF 就是第一个做到这点的（它用的是 Fourier 符号 `Σf(k)cos kθ` 的**最小值**，不是绝对值和）。

## 6. 预算：`c` 在消费点买什么

(G′-1) 只有**非对角**块 `N_ij=‖𝒪[Λ̃_ij]‖` 需要 (G)；对角块 `N_ii=λ₁` 是引理 M 白拿。故带 `c` 的加权行和是
```
λmax(N) ≤ (𝔤(2)/κ)·[ λmax(M2) + (c−1)·max_i Σ_{j≠i} M2_ij w_j/w_i ]
```
即**退化系数是 `1+(c−1)·s`，`s` = Perron 加权行和里非对角所占份额，不是 `c`**。
`s→0`（弱带间耦合）时 `c=3` 几乎免费；`s=1`（最坏）时才退化 `×c`、`Tc ×√c`：

| 结果 | `c` | 最坏 `Tc` 上界退化 |
|---|---|---|
| 定理 G3（`analytic`） | 3 | ×1.7321 |
| 定理 GA（`rational-exact`） | 2.129887 | ×1.4594 |
| 定理 GF，`ϖ→0` / Coulomb 型 | 1.247920 | ×1.1171 |
| 定理 GF，`ϖ ≥ 1.9` 或 `γ ≤ 1.28` | **1**（即 (G) 本身） | **×1（无退化）** |

## 7. 走不通的路（记下来免得重走）

1. **丢掉负项的 Dirichlet 松弛**（`Dir_f(y) − 2⟨R,y²⟩ ≤ Dir_f(y)`）：`sup Dir/⟨y,Ωy⟩` 对阶梯核
   **线性发散**，实测 `K=1,2,3,5,8,16,32,64` 给 `2.92 / 7.25 / 11.04 / 18.80 / 30.61 / 62.39 / 126.24 / 254.14`（≈`4K`）。彻底死。
   **负项是承重的**：恒等式里 `(2K+1)‖y‖² − 2⟨R_K,y²⟩ ≤ ⟨y,Ωy⟩` 且在 `|ν(n)|≤K` 上**取等**——这正是 `Ω` 权的来源。
2. **`|D_K|` 松弛**（Dirichlet 核取绝对值）：得 `r_K ≤ 1+γ_K`，`γ_K:=−λmin(Ω^{−1/2}1_{|n−m|≤K}Ω^{−1/2})`。
   `γ_K` 数值上收敛（K=8→1024 给 0.408→0.528，逐加倍增量比 ≈0.85）但 **`1+γ_1 = 1.475 > λ₁(𝒪[1_{k≤1}])=1.184`**，`K=1` 处就已失效。
3. **Fejér 分解** `M_K=(K+1)F_K − K F_{K−1}`（`F` 半正定）：余项 `λmax(Ω^{−1/2}QQ^ᵀΩ^{−1/2})`
   用试探向量 `y_n=ω_n^{−1/2}1_{|n|≤K}` 即得 `≳ K ln K`。死。
4. **加权 Schur / Collatz–Wielandt**，权 `ψ_n=ω_n^α`：`α=1/2` 给 `2‖f‖₁`（相对 `f(1)` 无界）；
   `α=−1/2` 在 `n=0` 处 `~ln K` 发散；`ψ=u` 同样在 `n=0` 发散。
   **根因**：Schur 测的是绝对行和，而真机制是振荡抵消（同 §5 的 no-go）。
5. **望远镜化** `(y_{n+k}−y_n)² ≤ k Σ(y_{j+1}−y_j)²`：常数变成 `Σk²f(k)`，阶梯核 `~K³/3`。死。
6. 派活方列的三条（Perron+`λmax(L1)` 松 2 倍 / 阶梯基 Metzler 为假 / Abel 超可加方向反）**全部复核属实**。
   但第 1 条**不是死路**——把 `λmax(L1) ≤ 2Σf` 改成 `≤ f(1)`（`f` 非增！）它就给出有限常数 3，见 §2。
