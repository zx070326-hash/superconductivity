## 0. 两句话

**[analytic]** 判据 `λ_ii λ_jj ≥ λ_ij λ_ji` 被**可分**电声耦合**恰好取等**（单模，任意 `γ`、任意分块）；
多模可分则严格成立。⟹ **要违反它，必须让 `g^ν_{k,k'}` 对单个模不可分——而动量守恒正是这么干的**
（`g` 只依赖转移 `q = k−k'`，是 Toeplitz 核）。`|g(q)|² ≥ 0` 逐点非负**不蕴含**核 `|g(k−k')|²` 在 `(k,k')` 上半正定
（Bochner 条件管的是实空间变换）。

**[numerical-evidence，输入 L1-文本层]** CaC₆——一个**常规**电声超导体——六带分块上 **11/15 对违反**，最劣 **2.438×**；
三带分块 2/3 对违反，最劣 1.081×。⟹ 判据的失效**不限于**「带间强于带内」的非常规人群。

**约定 [analytic]**：记 `⟨|g|²⟩_{JJ'} := [Σ_{k∈J,k'∈J'} δδ|g|²]/(N_J N_{J'})`，因 `|g_{kk'}|²=|g_{k'k}|²` 而**对称**。
则 `α²F_{JJ'} = (1/N_J)·N_J N_{J'}⟨|g|²⟩ = N_{J'}⟨|g|²⟩` ⟹ **`λ_{JJ'} = N_{J'} V_{JJ'}`，`V` 对称**（DOS 挂**右**指标）。

### ⚠ 一处我与 source-hunt 不同：细致平衡**单独**并不定约定

它写「细致平衡检验证的是 DOS 权重挂在哪个指标」。**不对**——该检验只钉死**组合**：

| 读法 | 约定 | 细致平衡残差 |
|---|---|---|
| A：行 = 第一指标 | `λ_ij = N_j V_ij` | 三带最劣 **1.32%**、六带最劣 **1.80%** |
| B：列 = 第一指标（**表注字面**） | `λ_ij = N_i V_ij` | **逐位相同** |

两者是「同一数组转置 + 约定也转置」，检验**分不开**。
真正钉死约定的**只有 Eq. (11)**（`1/N_J` 挂第一指标）。给定它，细致平衡才反过来钉死**排版为读法 A**
⟹ 表注「The first index runs over the columns」不是让该表自洽的那个读法。
**判据对转置不变**（`λ_ij λ_ji` 与对角元都不变）⟹ 所有判决与此歧义无关，这条歧义不必解决。

## 4. ★ 机制：判据被可分耦合取等，被动量守恒破坏 [analytic]

这是本篇相对 source-hunt 的新内容，也是比「又一个材料失效」更值钱的那部分。

**(S1) 单模可分 ⟹ 恰好取等。** 设 `g_{k,k'} = γ_k \overline{γ_{k'}}`，则 `|g|² = |γ_k|²|γ_{k'}|²`，
记 `A_J := Σ_{k∈J} δ |γ_k|²`：

```
λ_{JJ'} ∝ A_J A_{J'} / N_J
λ_ii λ_jj = (A_i²/N_i)(A_j²/N_j) = (A_iA_j/N_i)(A_jA_i/N_j) = λ_ij λ_ji      ← 恒等
```

对**任意** `γ`、**任意**分块成立。脚本数值复核：`worst rhs/lhs = 1.000000000000`。

**(S2) 多模可分 ⟹ 严格成立。** 若每个模各自可分，`V = Σ_ν (2/ω_ν) a^ν (a^ν)^T`（`a^ν_J := A^ν_J/N_J`）
是**正权秩一之和 ⟹ PSD** ⟹ 判据成立。脚本：5 模随机，`worst = 0.9954 ≤ 1`。

**(S3) ⟹ 违反的**必要**条件是单模 `g^ν_{k,k'}` 不可分——而动量守恒恰恰保证它不可分**：
`g^ν_{k,k'} = ⟨k|δV_ν|k'⟩` 只依赖 `q = k−k'`，是 **Toeplitz 核**，不是乘积。
而 `|g(q)|² ≥ 0`（逐点，在**转移**变量上）**不蕴含**核 `|g(k−k')|²` 在 `(k,k')` 上 PSD——
后者是 **Bochner 条件**，管的是它的**实空间**变换。脚本：6 个 Toeplitz 模，`worst = 1.0061 > 1`，**违反**。

⟹ **这与杀死「声子 `λ_ij` 必 PSD」那条假论证的是同一个 Hadamard-vs-Gram 区分**
（见 [[lambda-ij-criterion-is-not-vacuous-hadamard-vs-gram-2026-09-18]]），
只是这次显现在**动量**结构里而不是能带结构里。
⟹ **CaC₆ 不是病态例，它是「`g` 依赖 `k−k'`」的一般后果。** 判据要成立需要额外的物理输入，不是免费的。

   `2a+2b=0.106` vs `0.104`（+1.9%），`3a+3b=0.256` vs `0.249`（+2.8%）
   ⟹ 同一费米面切两次。**CaC₆ 算一个材料侧数据点，不是两个。**

   本篇只主张「非负性在 `q` 上 ⇏ PSD 在 `(k,k')` 上」，这一条是 analytic（Bochner）。

### 12.5 Eq.(10) 是第 5 种 DOS 约定，而那条比值关系**不定约定**（第三次同形）
