## 1. 先确认对的部分

### 1.1 §1 泡利代数有笔误，但不传播（`analytic`）

`nambu_weight` 第 45 行写 `τ₃Ĝτ₃ = −[iω̃τ₀ − ξτ₃ + φτ₁]/(ξ²+Ẽ²)`。
由 τ₃τ₀τ₃=τ₀、τ₃τ₃τ₃=τ₃、τ₃τ₁τ₃=−τ₁ 直接得到的是

```
τ₃Ĝτ₃ = −[iω̃τ₀ + ξτ₃ − φτ₁]/(ξ²+Ẽ²)
```

τ₃、τ₁ 两个符号都反了。但它第 33 行 Σ 的总体符号约定也反了一次，两处相消，
所以最终的 (Z-eq)/(Δ-eq)（第 63/64 行）与教科书 Carbotte RMP 1990 型方程一致。
ξ 项本来就因 N 偶对称而积掉，唯一有后果的 τ₁ 符号被约定修正。**非承重，不影响结论。**

### 1.2 §1–2 的结构性枢纽成立（`analytic`）

χ(Ẽ_m)=∫dξN(ξ)/(ξ²+Ẽ_m²) 在两个方程里确是**同一函数、同一宗量**，但乘的分子不同
（Z 通道乘 ω̃_m，Δ 通道乘 φ_m）。这是全部差异的根源，`nambu_weight` 抓对了，
也正是 `dos_escape` 的定性论证（「共享同一分母 ⟹ 权重形式相同」）失效的地方。

令 g(E):=χ(E)/χ_flat(E)，χ_flat=πN(0)/E。则

- **Z 通道**：ω̃_m·χ(|ω̃_m|) = g(ω̃_m)·πN(0)·sgn(ω_m) —— 1/|ω̃_m| 被 ω̃_m 精确抵消，
  **不含任何 1/(2m+1) 因子**，只剩 g。
- **Δ 通道**：φ_m·χ(|ω̃_m|) = g(ω̃_m)·πN(0)·φ_m/|ω̃_m|，没有东西去抵消 1/|ω̃_m|。

`g(0)=1` 是一般性质而非假设（E→0 时 χ 与 χ_flat 同受 N(0)/E 主导），只要 N 在 E_F 连续且正。

### 1.3 Δ 通道 = Ansatz A（`analytic`，两稿此处均正确）

φ_m/|ω̃_m| = Z_mΔ_m/(Z_m|ω_m|) = Δ_m/|ω_m| —— **Z_m 精确对消**，
所以 `nambu_weight` 的「近似 6」（Z_m≈1）在这一步根本不需要，只在 g 的宗量里需要。

```
Z_nΔ_n = N(0) Σ_m [λ(n−m)−μ*_c] · g_m Δ_m/(2|m|+1)
```

相似变换 Δ_m=ψ_m/√(w_m)，w_m:=g_m/(2m+1) ⟹ 对称核 √(w_n)λ√(w_m)，即

```
P[g,f] = L2+L3,   u_n² = g(ω̃_n)/(2n+1)        ← Ansatz A，现已由 Nambu 方程导出
```

负 m 分支经 i=−1−m 映回能级，给出 λ(n+i+1)√(w_n w_i)，即 L3，权重同 u。✓

## 2. 错在哪：L1 的索引收缩（承重缺陷）

`nambu_weight` §2 第 80 行写的还是正确的 **`g(ω̃_m)`（挂费米源指标 m）**，
但 §3 第 114 行收缩成求和式时变成了

```
L1[g,f]_n = (2/(2n+1))·Σ_{k=1}^n g(ω̃_k)·f(k)          ← g 挂到了玻色转移指标 k 上
```

——**把 g 的宗量从 m 悄悄换成了 |n−m|**，并且照搬了只在 g≡1 时成立的 telescoping 收缩。
`dos_escape` 的「Ansatz B」与此逐字相同，故同错。

### 2.1 精确形式（`analytic`）

原始 Matsubara 求和：m≥0 时 sgn=+1、能级=m、λ 的宗量 |n−m|；
m≤−1 时令 i=−1−m≥0，则 sgn=−1、能级=i、λ 的宗量 n+1+i。故

```
S_n = Σ_{m≥0} λ(|n−m|)·g_m  −  Σ_{i≥0} λ(n+1+i)·g_i
```

m=n 那格（λ(0)g_n）与 Δ 通道对角项精确相消（这一相消对一般 g 仍成立，
因为两边都带 g_n——正是 KAY 中 L1 从 k=1 起算、L2 带 (1−δ_nm) 的由来）。于是

```
L1[g,f]_n = B_n/(2n+1),
B_n = Σ_{m≥0, m≠n} λ(|n−m|)·g_m  −  Σ_{i≥0} λ(n+1+i)·g_i
```

**这是 g 沿费米源指标与 λ 的卷积，减去一个负频反射项**——既不是 A（整块外部因子 g_n），
也不是 B/C（g 挂转移指标）。g≡1 时 telescoping 给回 `2Σ_{k=1}^n λ(k)`。

另一个被两稿都漏掉的后果：**B_0 对一般 g 不为零**，
B_0 = Σ_{k≥1}λ(k)(g_k − g_{k−1})，A 与 C 都给 0。n=0 那格的泄漏强度因此被改写。

## 3. 下游改判：§5 的方向是反的

`a_n = (B_n − ρ(f)·g_n)/(2n+1)`，ρ(f)=f(0)−f̂(π)。
（引理 1–2 与 u 无关、对任意正权重成立，这一点两稿都对：
`P[g,f] = D_u(T_f+H_f)D_u − f(0)D_u² ⪰ −ρ(f)D_u²`，D_u 任意正对角。）

`nambu_weight` §5 断言：**g 单调不增（van Hove 型）⟹ 引理 4 逐字成立；g 不减（赝能隙型）⟹ 有风险**，
§6 数值给赝能隙台阶 `min a_n = −5.14e−2`（n=5..29 一整段负值，称漏网非秩一）。

用精确 B_n 重算（`_scratch_ir/nambu_lemma4_exact.py` / `nambu_lemma4_stress.py`，
80 组 = 4 个 ϖ × 20 种形状，N=300）：**方向相反**。

- **赝能隙型（g 不减）基本安全**：80 组中仅一个边缘负值（ϖ=0.3、宽 3、深 0.02，−8.3e−4）；
  note 报的 −5.14e−2 那一段**复现不出来**，是其错误 L1 式的产物。
- **van Hove 型（g 不增）才是危险方向**：`vH_step` 宽 3、深 0.02 在 ϖ=1 给 −0.041。
- **随机非单调 g** 破得最狠：−1.37，负 n 达 43 格。

物理上这个方向才自洽：g(0)=1 恒成立，费米面上的 DOS **峰**使 g 从 1 **下降**到背景比值
N_bg/N(0)<1（van Hove）；费米面被**压低**使 g **上升**到 >1（赝能隙）。两稿把 g 的方向认反了。

**方向审计（单边界规则）**：a_n<0 只证明「引理 4 这条充分路线失效」，
**不支持**「定理失效」的判决。下节给的是直接谱量（双侧），不受此规则限制。
