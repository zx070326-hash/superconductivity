## 0. 一句话结论

**有效秩一原理不是无条件普适的**，但它在「核（或算子的非对角部分）以正部为主导」这个宽松条件下**极其稳健**——
覆盖重尾、双峰（多原子谱）、温和振荡的正核，gap/λ₁ 全部 ≥ 0.98（多数 ≥ 0.999）。
**反例确实找到**：当核含有可比量级的**负部**（振荡符号相消、或「墨西哥帽」正核心+负肩），gap/λ₁ **连续坍缩到 0**（本次数值扫到 0.173）。
机制上正对应 Perron–Frobenius／entrywise-positivity 被破坏。库仑 μ*>0 的真实物理模型里，**同一机制真的发生过**：
秩一负的库仑项把 λ₁(M) 压到与 A 的 λ₂ 近交叉（`P4D_coulomb_uniqueness.md` 已记录的失效点，κ=2.05，gap 几乎为零）——
这不是玩具反例，是我们自己理论里已经证实的真实失效实例。

## 3. 为什么谱隙正（Einstein 核的解析机制，非本文新证，摘自 `P4_einstein_extremal.md` §1.F）

**解析恒等式（M1，Lorentz 加法公式）**：ℌ(ϖ) = 2ττᵀ + 𝓡 − 𝒟，其中
- τ_n = p_n·ϖ²/(ϖ²+(n+½)²)（半移 Lorentz 试探向量），B:=‖τ‖²
- 𝓡_{nm} = p_np_m·R(s_n,s_m) ≥ 0 **逐元非负**（R 是两个 Lorentz 因子的加法余项，显式有理式）
- 𝒟 = diag(...) ∈ [0,1] 对角

**关键的不对称增长**：
- ρ=⟨t̂,ℌt̂⟩ ≥ 2B−1 ≈ **ln ϖ + c₀ − 1**（c₀=0.4635101），**随 ϖ 无界增长**（本文 §2.1 数值验证：λ₁ 从 0.05 到 4.6，与 ln ϖ 渐近吻合，误差项 O(1/ϖ) 递减）；
- λ₂(ℌ) ≤ λ₁(𝓡−𝒟) ≤ ‖𝓡‖ ≤ **Θ\* = 0.63492879**（sup 在 s\*=1.5009 处取到的**与 ϖ 无关的通用常数**）。

即：**秩一部分的"势能"随耦合强度（ϖ）无界增长，而"其余全部"的算子范数被一个绝对常数封顶**。
gap ≥ ρ−Θ\* → ∞。这不是巧合，是 Lorentz 核满足加法公式 (M1) 这个**代数特例**的直接推论——
它对一般核**不自动成立**（见下节反例）。

## 4. 推广条件与反例搜索（本文主要新贡献，numerical-evidence）

用与 `P4_concentration_bound.md` §0 相同的算子族公式
(𝒪[φ])_{nm} = u_nu_m[φ(|n−m|)𝟙_{n≠m}+φ(n+m+1)] − δ_nm(2/(2n+1))Σ_{k≤n}φ(k)，
换不同 φ(k)，N=500，测试 gap/λ₁ 是否仍 ≈1。

### 4.1 正核族（entrywise φ≥0）——全部稳健

| 核族 | 参数范围 | gap/λ₁ 范围 |
|---|---|---|
| 基线 Lorentz φ=x/(k²+x) | x∈[1,60] | 0.9993–0.9994 |
| 重尾 φ=x/(k²+x)^0.6（更慢衰减） | x∈[1,60] | 0.9900–0.9930 |
| 幂律尾 φ=1/(1+k)^p（无内禀标度） | p∈[1.05,2.0] | 0.9836–0.9988 |
| 双峰（双原子谱，两个 Lorentz 标度叠加） | x₁,x₂ 相差 3 个量级、权重 10–90% | 0.9926–0.9994 |
| 双峰、峰间距刻意压窄（x接近简并设计） | x₁=3, x₂∈[3.01,10] | 0.9992–0.9993（**未能造出反例**，见 §4.3 讨论） |

**结论**：只要核逐元非负（Perron–Frobenius 型条件），**重尾、幂律、多峰（多原子声子谱）、温和振荡都不破坏有效秩一**，
gap/λ₁ 稳健地留在 [0.98,1.0]。**多峰谱刻意设计成近简并也没能压垮它**（§4.3 展开）。

| 核族 | 参数 | gap/λ₁ |
|---|---|---|

| 墨西哥帽（正核心 − b·倍更宽负肩）φ=a/(1+k²) − b·a/(1+(k/c)²)，c=4 | b=0.3 | 0.786 |

**墨西哥帽族是一条连续可控的反例路径**：随负肩权重 b 从 0.3 升到 0.95，gap/λ₁ 从 0.79 单调坍缩到 0.17——
即**谱隙确实可以被压到任意小**（连续趋于简并/near-crossing），只需核的负部占比连续增大。
振荡核给出另一族独立反例，同样量级（0.76–0.90）。

### 4.3 为什么"设计近简并"没能靠正核造出反例

§4.1 尝试用两个几乎相同标度的正 Lorentz 峰叠加（x₁=3 vs x₂=3.01/3.1/4/10）去凑出"两个同权重的候选主导模式"，
期望 λ₁≈λ₂。结果 gap/λ₁ 仍 ≥0.999，**未能造出**。原因是结构性的：只要 φ≥0，`𝒪[φ]` 的非对角元
处处严格正（entrywise-positive matrix，见 `P4D_coulomb_uniqueness.md` 引理 0 的同一论证），Perron–Frobenius
保证顶本征值单重、顶本征向量不变号；即使两个"候选模式"（试探向量）本身接近简并，正核会把它们**混合成
一个共同的、更集中的 Perron 向量**，而不是维持两个独立的近简并本征值——这正是"正核 ⟹ 秩一主导"机制的
另一面：正性不仅保证顶本征值为正、单重，还**主动压制**了次本征值靠近顶本征值的倾向（除非核本身含负部，
提供了"对抗"顶模式的自由度）。

## 5. 推广条件（结论）

1. **正核（entrywise φ(k)≥0）是有效秩一原理的充分条件**，且经验上相当稳健（不需要核单峰、不需要标度单一、
   容许重尾/幂律/多峰/温和振荡），机制是 Perron–Frobenius：非对角元处处正 ⟹ 顶本征值单重、不变号
   （`P4D_coulomb_uniqueness.md` 引理 0 的一般化）。这是"充分"而非"必要"——温和振荡（§4.1 末行）仍保持正性
   全程为正，谱隙依旧稳健，说明真正起作用的是**核在何种程度上远离改变符号**，而不是核的具体函数形式。
2. **必要性方向的反例已找到（§4.2）**：一旦核含有可比量级的负部（振荡相消 或 墨西哥帽负肩），
   谱隙可以连续坍缩到接近零——有效秩一原理**不是无条件成立**的。
3. **Einstein 核的 Lorentz 加法公式 (M1)** 是比"entrywise 正"更强的代数特例——它不仅给出正性，还给出
   谱隙下界与耦合强度 ϖ 的**显式定量**关系（gap ≳ ln ϖ − Θ\*，无界增长）。一般正核只保证 Perron–Frobenius
   定性单重性，不自动保证谱隙随耦合强度增长（§4.1 里 x 增大时 gap/λ₁ 只是维持稳健、并未观察到系统性地
   趋于 1——这与 Einstein 核不同，Einstein 核在 ϖ→∞ 端 gap/λ₁ 甚至略超过 1 因 λ₂→负）。
4. **库仑 μ*>0 是"正核+负秩一微扰"的真实物理实例**：`P4D_coulomb_uniqueness.md` 记录的近交叉失效点
   （κ=2.05，gap/λ₁≈0.14）与本文墨西哥帽反例同一机制、同一数量级——不是巧合，是同一个"负部/竞争性秩一项
   压垮正核主导"的结构性现象在真实理论里的体现。这也解释了为什么该文件的唯一性定理需要 **κ<1** 这个显式
   假设（μ̃ 不能太大）——κ 本质上就是本文 gap/λ₁ 坍缩程度的一个代理变量。

**对"Tc 普适性"猜想的净评价**：物理声子谱（正的谱函数、有限矩量）天然落在"正核"这一侧，
经验上（§4.1 的重尾/多峰/温和振荡测试）有效秩一相当稳健，这支持"Tc 几乎只由 (λ,⟨ω²⟩,μ*) 决定"这条
经验观察背后确有结构性原因（Perron–Frobenius）。但这**不是**一个可以套到"所有配对机制"上的无条件定理——
凡是配对核可能带负号或强烈振荡的机制（例如某些非声子媒介、符号变化的顶角修正——呼应 `P2_vertex_sign_criterion.md`
里已发现的负号顶角机制！），有效秩一可能失效、Tc 对谱细节的敏感性会重新出现。
