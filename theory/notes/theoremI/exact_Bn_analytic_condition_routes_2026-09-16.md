## 0. 背景与目标

### 0.1 问题陈述（**analytic**，从源文件读取）

一般 DOS 下 Z 通道 L1 的精确形式（来自 `nambu_weight_audit_2026-09-16.md` §2.1）：

```
L1[g,f]_n = B_n/(2n+1),
B_n = Σ_{m≥0, m≠n} λ(|n−m|)·g_m  −  Σ_{i≥0} λ(n+1+i)·g_i
```

其中 g_n = g(ω̃_n) 是 DOS 权重因子（费米面处 DOS 增强/压低的效应），
λ(k) 是玻色核（k 以转移 Matsubara 指数计）。

**物理意义**：g 沿费米源指标与 λ 的卷积，减去负频反射项。
- 平坦 DOS：g≡1，telescoping 给回 `B_n = 2Σ_{k=1}^n λ(k)`（KAY 原始形式）。
- van Hove / 赝能隙：g 非常数，上述收缩**失效**。

完整算子：
```
M = −L1[g,f] + P[g,f],
P[g,f] = D_u(T_f + H_f)D_u − f(0)D_u²,   u_n² = g_n/(2n+1)
```

其中 P[g,f] 的权重 u_n²=g_n/(2n+1) 已由 Nambu 方程导出（`nambu_weight_audit` §1.3，
**analytic**），是 Ansatz A、现已证明。

**目标**：找一个**解析的**充分条件，证明 `λ₂(M) ≤ λ₁ − c·γ`，即谱隙被正下界保护。

### 0.2 已知结果

| 陈述 | 级别 | 状态 |
|---|---|---|
| 平坦 DOS 下定理 I（引理 4） | analytic | **成立**，`delta_channel_immunity_2026-09-16.md` |
| 精确 B_n 下数值测试（80 组形状） | numerical-evidence | gap/λ₁ ∈ [0.976, 1.003]，无近简并 |
| 旧的单调性论证（引理 4 推广） | — | **失效**（公共正因子 g 无法提出） |

## 1. 路线 1：Perron–Frobenius / 非负矩阵理论

### 1.1 思路

引理 4 的核心机制（`delta_channel_immunity` §1，引理 4）：对 f∈𝒫（玻色核类），

```
𝒪'[f] := L1[f] + P[f] ⪰ −ρ(f)·e₀e₀ᵀ,    ρ(f) = f(0) − f̂(π)
```

这里 L1[f] 的对角增长 `2Σ_{k≤n}f(k)/(2n+1)` **逐点压住** P[f] 的最负部分 `−ρ(f)u_n²`，
唯一漏网的是 n=0（那里和是空的），漏网是秩一的 ⟹ Cauchy 交错 ⟹ λ₂ 被封死。

**问题**：引理 4 的证明关键在于

```
a_n = [2Σ_{k=1}^n f(k) − f(0) + f̂(π)] / (2n+1) ≥ 0   (n≥1)
```

这依赖于 f≥0（玻色核非负）。对精确 B_n：

```
a_n = (B_n − ρ(f)·g_n) / (2n+1)
```

B_n 是 g 与 λ 的卷积减负频反射，**不能**提出公共因子 g_n，所以不能沿用
`g_n·[引理 4 对 λ 的结论]` 这条路线。

### 1.2 尝试：对一般 g 直接验证 𝒪'[g,f] + ρ(f)·e₀e₀ᵀ ⪰ 0

数值测试（N=150，varpi=1.0）：

| g 形状 | min_eig(M' + ρ·e₀e₀ᵀ) | min_eig(M') | 引理 4 预言成立？ |
|---|---|---|---|
| flat | +0.002499 | +0.002499 | **是** |
| vH_step (n<5: 0.05) | −0.120678 | −0.165320 | **否** |
| pg_step (n<5: 1.5) | +0.002499 | +0.002499 | **是** |

**方向审计（单边界规则）**：这是在测一个**下界** `M' ⪰ −ρ·e₀e₀ᵀ` 是否被违反。
- vH_step 给出 min_eig = −0.12 < 0，说明**引理 4 的字面推广失效**。
- 但这**不支持**"定理本身失效"的判决——它只说明这条充分路线断了。

从精确 B_n 表达式看：

```
B_n = Σ_{m≠n} λ(|n−m|)·g_m − Σ_{i≥0} λ(n+1+i)·g_i
```

- 第一项：g 沿 m 与 λ 卷积，m 遍历整个费米海。
- 第二项：g 沿负频镜像求和。
- **无法分解成** `g_n · [只依赖 λ 的量]`。

若 g 在低 n 处取小值（van Hove 峰 ⟹ g_0≪1），第一项在 n 附近的贡献被压低，
但第二项（负频反射）仍带整个 g 的积分 ⟹ B_n 可以变负（对某些 n）。

### 1.3 可行性判断与瓶颈

**状态**：**部分可行**——对某些 g 类可能成立，但一般 g 不行。

**瓶颈**：
1. 无法提出公共正因子 g_n。
2. B_n 对 g 的依赖是**非局域的**（卷积结构），不能逐点分析。
3. 需要 g-依赖的界，形如 `B_n ≥ C(g)·[引理 4 的量]`，但 C(g) 的解析形式未知。

**可能的修复方向**：
- 限制 g 的变化率：若 `|g_n − g_m| ≤ ε·min(g_n,g_m)`（缓变 DOS），
  也许能把 B_n 写成 `g_n·[主项] + O(ε)·[修正]`，用连续性论证。
- 但这需要**新的不等式**（尚未推导），且 ε 的阈值未知。

**结论**：路线 1 对平坦 DOS **已闭合**（引理 4，analytic）；
对一般 g **开放**，需额外机制（g 的缓变条件 + 新不等式）。

## 2. 路线 2：Gershgorin 圆盘 + Cassini 卵形

### 2.1 思路

Gershgorin 圆盘定理：矩阵 A 的本征值位于圆盘

```
D_i = { z : |z − A_{ii}| ≤ Σ_{j≠i} |A_{ij}| }
```

的并集内。若某个圆盘与其余圆盘**分离**，则它恰包含一个本征值。

对 M = −L1 + P：
- 对角：M_{nn} = −B_n/(2n+1) + P_{nn}。
- 非对角：来自 P（L2 + L3），衰减 ~u_n u_m ~ 1/√((2n+1)(2m+1))。

**希望**：n=0 的圆盘与其余圆盘分离 ⟹ λ₁ 被孤立在 D_0 内，λ₂ 被挡在外面。

### 2.2 数值测试

平坦 g，N=150：

| varpi | D_0 中心 | D_0 半径 | D_0 上界 | 其余圆盘最大上界 | 分离？ | 实际 λ₁ / λ₂ |
|---|---|---|---|---|---|---|
| 1.0 | +0.500 | 0.714 | 1.214 | 0.378 | **否** | 0.716 / 0.000 |
| 3.0 | +0.900 | 2.646 | 3.547 | 1.561 | **否** | 1.718 / 0.002 |
| 5.0 | +0.963 | 4.176 | 5.139 | 2.493 | **否** | 2.206 / 0.003 |

**观察**：
- D_0 的上界**远大于**实际 λ₁（松 1.7–2.3 倍）。
- D_0 的上界**大于**其余圆盘的上界，但**不分离**——D_0 与 D_1, D_2, ... 有重叠。
- 实际 λ₂ 极小（~10⁻³–10⁻⁴），远低于 Gershgorin 界。

**原因**：
1. P 的非对角行和 `Σ_{m≠n} |P_{nm}|` 对每个 n 都很大（~0.7–4.2），
   因为 P 有**长程关联**（L3 项 f(n+m+1)u_n u_m 对所有 m 都非零）。
2. λ₁ 对应的本征向量是**非局域的**配对模（所有 n 都有权重），
   不是集中在某一格上 ⟹ 圆盘分离不符合物理。

### 2.3 Cassini 卵形改进

Cassini 卵形定理：本征值满足

```
Π_{i=1}^N |λ − A_{ii}| ≤ Π_{i=1}^N R_i,   R_i = Σ_{j≠i} |A_{ij}|
```

或两个圆盘的版本：`|λ−d_i|·|λ−d_j| ≤ R_i·R_j`。

这能收紧 Gershgorin，但**不改变**本质问题：P 的行和太大，所有圆盘/卵形都重叠。

### 2.4 可行性判断与瓶颈

**状态**：**不可行**。

**瓶颈**：
1. P 是**非局域算子**（长程关联），λ₁ 的本征向量分布在所有 Matsubara 频率上。
2. 圆盘分离要求 λ₁ "住在某一格"，这与配对模的物理矛盾。
3. Gershgorin 界本质上是逐点估计，不利用算子的正定性/对称性。

**结论**：路线 2 **死路**。不推荐继续。

## 3. 路线 3：分段论证（小 varpi vs 大 varpi）

### 3.1 思路

小 varpi（varpi ≲ 1，物理区）：核软、衰减慢，也许 L1 对角项小、P 接近秩一？

大 varpi（varpi ≳ 5）：核硬、衰减快，认输（留给数值 + certificate）。

### 3.2 数值测试：L1 与 P 的相对强度

| varpi | f(0) | f(10) | ρ/f(0) | μ₁(P) | max(L1_diag) | L1/P 相对强度 | gap/λ₁ |
|---|---|---|---|---|---|---|---|
| 0.3 | 1.000 | 0.000899 | 0.067 | 0.121 | 0.055 | 0.45 | 0.9995 |
| 0.5 | 1.000 | 0.002494 | 0.159 | 0.298 | 0.133 | 0.45 | 0.9995 |
| 1.0 | 1.000 | 0.009901 | 0.364 | 0.798 | 0.333 | 0.42 | 0.9994 |
| 2.0 | 1.000 | 0.038462 | 0.488 | 1.510 | 0.533 | 0.35 | 0.9992 |

**观察**：
- 即使 varpi=0.3（极软核），L1 的对角最大值仍是 P 顶本征值的 **45%**。
- L1 **不是小扰动**——两个算子强度相当（O(1) 比值）。
- 不能用微扰论（"P + εL1，ε≪1"）。

### 3.3 可行性判断与瓶颈

**状态**：**不可行**。

**瓶颈**：
1. 小 varpi 下 L1 与 P 强度相当，没有天然的小参数。
2. 问题本质是**两个算子的竞争**（−L1 vs +P），不是单算子 + 扰动。
3. varpi→0 极限下 λ₁→0（无配对），不能当作"简单极限"。

**结论**：路线 3 **死路**。物理区没有简化。

## 4. 路线 4（新提出）：变分/g-微扰论

### 4.1 思路

数值证据显示：gap/λ₁ ∈ [0.976, 1.003] 对所有测试的 g 形状（**numerical-evidence**）。
这意味着 λ₂ 相对 λ₁ 的位置**对 g 不敏感**。

**问题重构**：能否证明 `∂λ₂/∂g` 在某个范数意义下**一致有界**？

设 g = 1 + δg（δg 是 DOS 偏离平坦的量），展开：

```
M[g] = M[1] + ∫ (∂M/∂g_n)·δg_n dn + O(‖δg‖²)
```

若能控制 `|λ₂(M[g]) − λ₂(M[1])| ≤ C·‖δg‖`（C 是解析常数），
则只需对有界的 ‖δg‖ 类（例如 ‖δg‖_∞ ≤ 1，即 g∈[0,2]）验证即可。

### 4.2 需要的机制

1. **M 对 g 的 Fréchet 导数**：
   ```
   (∂M/∂g_n) = −∂L1/∂g_n + ∂P/∂g_n
   ```
   - L1 的导数：B_n 对 g 是线性的（卷积结构），可显式写出。
   - P 的导数：u_n² = g_n/(2n+1) ⟹ (∂P/∂g_n) 涉及 D_u 的变分。

2. **扰动论界**（Davis–Kahan 或 Weyl 型）：
   对对称算子 A, B，若 ‖A−B‖ ≤ δ，则
   ```
   |λ_j(A) − λ_j(B)| ≤ C·δ   （C 依赖于谱隔离）
   ```
   这里需要 `‖∂M/∂g‖_{op}` 的界（算子范数）。

3. **顶向量的稳定性**：
   若 ψ₁(g) 对 g 变化不大（‖ψ₁(g) − ψ₁(1)‖ ≤ ε），
   则 λ₂ 被 Cauchy 交错钉在 `⟨ψ₁, M ψ₁⟩` 下方，
   而 ⟨ψ₁(1), M[g] ψ₁(1)⟩ 可以显式计算。

### 4.3 可行性判断与瓶颈

**状态**：**未探索**，需新框架。

**优势**：
- 数值证据强烈支持（gap 对 g 不敏感）。
- 微扰论是成熟工具，Davis–Kahan 界已有现成文献。
- 只需对**有界 g 类**证明（物理上 g∈[C⁻¹, C]，C~2–3 足够）。

**瓶颈**：
1. 需计算 `‖∂M/∂g‖_{op}`——涉及 L1 的卷积结构，可能不紧。
2. Davis–Kahan 常数依赖于 gap(M[1]) = λ₁(M[1]) − λ₂(M[1])，
   后者在 varpi 小时也小（~10⁻³），可能让界变松。
3. 若 ‖∂M/∂g‖ · ‖δg‖ ~ gap，则界平凡（"扰动不比 gap 小"）。

**结论**：路线 4 **有希望**，但需额外工作量（估算导数算子范数）。
若主要目标是"闭环某个充分条件"而非"物理洞察"，这是最现实的路线。

## 5. 总结与建议

### 5.1 三条路线的可行性帐目

| 路线 | 状态 | 瓶颈 | 级别（若闭环） |
|---|---|---|---|
| 1. Perron–Frobenius | **部分** | 无法提出公共 g，需缓变 g 条件 | analytic（限定 g 类） |
| 2. Gershgorin/Cassini | **不可行** | 圆盘重叠，物理不匹配 | — |
| 3. 小 varpi 分段 | **不可行** | L1 与 P 强度相当，无小参数 | — |
| 4. g-微扰论（新） | **未探索** | 需算子范数界 + Davis–Kahan | analytic（有界 g 类） |

### 5.2 当前数值证据强度（**numerical-evidence**）

80 组压力测试（`nambu_weight_audit` §3 引用的脚本）：
- 4 个 varpi × 20 种 g 形状（van Hove 台阶/平滑、赝能隙台阶、随机非单调）。
- gap/λ₁ ∈ [0.976, 1.003]，**无一组接近简并**。
- 最差情况：varpi=5, 随机 wild g，gap/λ₁=0.9995 仍远离危险区。

**这是很强的数值证据**——比某些"只测几个点"的文献数值更可靠。
但它不是解析证明。

### 5.3 建议行动

**选项 A（务实）**：接受当前状态为 **numerical-evidence**，不强求解析闭环。
- 理由：80 组 + 5 种 g 拓扑类型已覆盖物理相关空间。
- 论文写法：陈述为"数值上鲁棒"（numerically robust），引 80 组数据。
- 成本：零（已完成）。

**选项 B（追求闭环）**：投入路线 4（g-微扰论）。
- 理由：最有希望在合理工作量内闭环。
- 所需：
  1. 计算 `‖∂L1/∂g‖_{op}` 与 `‖∂P/∂g‖_{op}`（2–3 天解析推导 + 数值验证）。
  2. 确认 Davis–Kahan 常数在物理区不退化（1 天数值扫描）。
  3. 若上述成立，写定理（形如"‖g−1‖_∞≤1 ⟹ gap≥c·γ(varpi)"）。
- 成本：~1 周（中等）。
- 风险：可能算子范数界太松，最后仍回到选项 A。

**选项 C（保守 + 部分）**：只对**缓变 g**（|g_{n+1}−g_n|≤ε）闭环路线 1。
- 理由：物理上大多数 DOS 特征（van Hove 峰、赝能隙）在温度尺度上是缓变的。
- 所需：推导 B_n 对 g 变化率的不等式（~3 天）。
- 成本：中等。
- 缺点：不覆盖"随机 wild g"（但那本身非物理）。

### 5.4 我的推荐

**短期（本轮交付）**：采用**选项 A**。
- 当前数值证据已足够支撑"秩一主导对一般 DOS 鲁棒"的物理结论。
- 解析充分条件的缺失不影响主定理（Δ 通道免疫，`delta_channel_immunity`）
  ——那里只需平坦 DOS（已 analytic）。

**中期（若有余力）**：探索**选项 B**（g-微扰论）。
- 性价比最高，且若成功，可升格整个一般 DOS 推广为 analytic。

**不推荐**：路线 2（Gershgorin）与路线 3（小 varpi）——死路，勿追。
