# 2-带 toy 模型：多轨道动力学 χ0 构造手推 + PSD/FDT 核验（2026-09-22）

> Team B 续接 Week 2 Day 7 的 Phase 1（2-带 toy 模型验证）。
> Day 7 发现 5-轨道 χ0 在**全部**频率点（含裸 U=0）违反涨落-耗散定理（FDT）的 PSD 要求，
> 且怀疑"两因子 vs 四因子"指标结构选错。本笔记在可逐项手算的 2-带链上，从密度算符
> Wick 收缩重新推导，**定位到一个真实的指标收缩 bug**，修复后 FDT 逐点满足、
> t12→0 退耦极限精确复现单带 Lindhard、四因子对象的正确共轭配对律得到确认。

## 0. 结论先行

- **找到并修复了一个真实 bug**：此前（以及很可能 Week 1/Week 2 沿用）的"两因子"化简
  `χ_ll'(q,ω) = Σ |U_{l,μ}(k)|² |U_{l',ν}(k+q)|² × weight` 是**错的**，只在 `l=l'`
  对角情形碰巧与正确公式重合，`l≠l'` 时给出的是另一个物理上不同的四指标收缩
  `χ_{l,l',l',l}`，不是 `χ_{l,l,l',l'}`（真正的 `n_l·n_l'` 密度-密度关联）。
  正确公式是**交叉项**：`U_{l',μ}(k)U*_{l,μ}(k) · U_{l,ν}(k+q)U*_{l',ν}(k+q)`。
- 修复后：**FDT 在全部 30 个 (q,ω>0) 采样点上以一致符号成立**（`Im χ(q,ω)` 恒为
  Hermitian **负**半定矩阵——符号是傅里叶/Kubo 约定问题，不是物理违反；关键物理内容
  是**符号不翻转、不混合**，30/30 满足）。
- Day 7 报告"PSD 全违反"的诊断**部分成立**（构造确有 bug），但诊断的具体机制
  （"两因子 vs 四因子选错""U=0 裸泡也违反"）与本笔记定位到的具体 bug 一致：
  两因子化简的指标收缩错误在 `l≠l'`（轨道混合）分量上产生系统性符号/幅度错误，
  这类错误在 `U=0`（无 RPA/顶角修正）时同样出现——因为 bug 在裸 χ0 层。
- `t12(k)→0` 退耦极限：修复后 `χ_11,χ_22` 精确（float64 到机器精度）复现独立单带
  Lindhard 函数，`χ_12=χ_21` 精确为零（无轨道混合时不应有交叉关联）。
- 四因子对象 `χ_{l1l2,l3l4}(q,ω)` 的正确共轭关系是
  `χ_{l1l2,l3l4}(q,ω)^* = χ_{l2l1,l4l3}(-q,-ω)`（**指标对 (l1,l2) 与 (l2,l1) 配对，
  不是自共轭**），数值确认（有限 Nk 外推 Nk=1000→8000 残差 1.6e-4→2.0e-9，
  收敛到 0；朴素不换指标的配对给 0.186，不随 Nk 收敛）。
  两因子对象恰是四因子张量的对角块 `χ_ll' ≡ χ_{l,l,l',l'}`（精确重合，diff=0）。

**严格性标级**：Wick 收缩推导本身是 `analytic`；数值核验（PSD/退耦极限/共轭律）
是 `numerical-evidence`（float64，有限 Nk∈[2000,8000]、有限 η=0.03 展宽，非声音区间算术）。

## 1. 模型

1D 二带紧束缚链，实对称哈密顿量：
```
H(k) = [[ε1(k), t12(k)],
        [t12(k), ε2(k)]]
ε1(k) = -2 t1 cos(k) - μ,      t1=1.0
ε2(k) = -2 t2 cos(k) + Δ - μ,  t2=0.6, Δ=0.8
t12(k) = th·sin(k),            th=0.35（k 里奇宇称，退耦时设 th=0 即可测试）
```
对角化：`np.linalg.eigh(H(k))` 数值本征分解，`E(k)=[E_-(k),E_+(k)]` 升序，
`U(k)` 列 = 正交本征矢（band basis 变换矩阵）。

**注**：最初手推了一版基于 `tan(2θ)=t12/((ε1-ε2)/2)` 解析对角化公式，但该公式在
`ε1(k)≤ε2(k)` 恒成立（本模型 `th=0` 时 `ε1-ε2=-0.8(cos k+1)≤0`）且 `t12→0` 的退化点上
给出了**错误的本征矢符号**（把 band0 的本征矢错配到轨道2、band1 错配到轨道1，
全 k 网格系统性调换），这本身就是一个独立的、值得记录的坑：**手推解析对角化公式的
符号约定极易在简并/近简并点附近搞反**，改用 `eigh` 直接数值对角化后此问题消失
（`eigh` 对每个 k 独立返回与真实能量匹配的本征矢，不依赖人工符号约定）。

## 2. Wick 收缩推导

密度算符（轨道对指标，动量 q）：
```
n_{l1 l2}(q) = Σ_k c†_{l1,k+q} c_{l2,k}
```
"两因子"密度-密度关联取 `l1=l2=l`（同一轨道）：`n_l(q) = Σ_k c†_{l,k+q} c_{l,k}`。

```
χ_{l l'}(q,τ) = -⟨T_τ n_l(q,τ) n_l'(-q,0)⟩
```
四个费米算符的连通 Wick 收缩（唯一非零的交叉配对，动量守恒钉死 k'=k+q）给出
标准多轨道泡图公式（与 Graser et al., New J. Phys. 11, 025016 (2009) Eq. (3)-(6)
的指标约定一致）：
```
χ_{l1l2,l3l4}(q,iν_n) = -(T/N) Σ_k Σ_{iω} G_{l4,l1}(k,iω) G_{l2,l3}(k+q,iω+iν_n)
```
在能带基下 `G_{ab}(k,iω) = Σ_μ U_{aμ}(k)U*_{bμ}(k)/(iω-E_μ(k))`，做 Matsubara 求和
（标准“气泡”求和公式）得到解析延拓后的推迟函数：
```
χ_{l1l2,l3l4}(q,ω+i0+) = (1/N) Σ_k Σ_{μν} U*_{l1,μ}(k) U_{l4,μ}(k)
                                            U_{l2,ν}(k+q) U*_{l3,ν}(k+q)
                                            [f(E_μ(k))-f(E_ν(k+q))]
                                            / (ω+iη+E_μ(k)-E_ν(k+q))
```
取 `l1=l2=l, l3=l4=l'`（两因子密度-密度）：
```
χ_{l l'}(q,ω) = (1/N) Σ_k Σ_{μν} U_{l',μ}(k) U*_{l,μ}(k) U_{l,ν}(k+q) U*_{l',ν}(k+q)
                        × [f(E_μ(k))-f(E_ν(k+q))] / (ω+iη+E_μ(k)-E_ν(k+q))
```
**这是交叉项结构**（`U_{l',μ}U*_{l,μ}` 是不同轨道指标的乘积，不是 `|U_{l,μ}|²`）。
把 `l=l'` 代入立即退化为 `|U_{l,μ}(k)|²|U_{l,ν}(k+q)|²`——这正是为什么错误的
"投影平方"公式在对角元上恰好正确、只在离对角元上出错。这个 bug 的隐蔽性
（对角元完全正确掩盖离对角元错误）与仓库 W1 教训中"局部对/整体错"的模式同形，
值得作为独立坑记录。

## 4. 对 Week 2 / 5-轨道重建的含义

1. **Day 7 的诊断方向是对的**：全频率违反 FDT 且 U=0 裸泡也违反，指向裸 χ0
   构造本身的 bug，不是 RPA/f^xc 层。本笔记在可手推的最小模型上坐实了
   **具体是哪个 bug**：两因子化简的指标收缩用了错误的"投影平方"形式而非
   正确的"交叉 U 乘积"形式。
2. **Phase 2（5-轨道重建）行动项**：检查 Week 1/Week 2 现有 5-轨道 χ0 实现里
   两因子化简的具体代码行——如果同样写成
   `Σ|U_{l,μ}(k)|²|U_{l',ν}(k+q)|²` 形式，就是同一个 bug，且预期同样是
   **对角元（轨道内响应）不受影响、离对角元（轨道间响应）系统性出错**。
   这与 Week 1 静态 `Re χ(q,0)` 结果"不撤回"的记录是**相容**的，如果 Week 1
   的判据主要吃对角元、或者 Week 1 用的是本就正确的四因子对角块公式；
   但**任何 Week 1/2 依赖离对角 `χ_ll'(q,ω), l≠l'` 数值的结论都需要用本笔记
   给出的正确公式重新算一遍**，尤其是自旋/轨道混合响应（Q_AFM 处轨道选择性
   响应正是 FeSe 分析的核心对象）。
3. **PSD 检验本身的期望要修正**：不要检验"半正定"，要检验"符号一致不翻转"
   （NSD 或 PSD 二选一，取决于 Kubo/傅里叶符号约定，只需在整条计算链里保持
   一致）。Day 7 若把"违反 PSD"等同于"违反 FDT"而没有先检查是否是全体
   反号（NSD 而非 PSD），可能把一个纯符号约定问题误判为构造错误——
   **这次的 bug 是真的（指标收缩错），但检验脚本设计上也应加一道"先查全体
   本征值是否同号"再判定违反的步骤**，避免未来同类误判。
4. **四因子对象不应被朴素 reshape 成 (l1,l2)×(l3,l4) 矩阵后直接测 PSD**——
   正确的共轭配对是 `(l1,l2)↔(l2,l1)`（同时 `q→-q, ω→-ω`），四因子张量的
   PSD/FDT 陈述如果需要用到，必须先按此配对重新组织成矩阵，不能直接测。
