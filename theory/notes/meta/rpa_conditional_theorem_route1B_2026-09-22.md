## 定理陈述（条件版）

**定理 1B（RPA 对角主导条件保持）**：设 χ₀ 是 N×N 实对称正半定矩阵（静态极限 ω=0），U = diag(u₁,...,u_N) 且 u_α > 0。定义：

- 谱半径：ρ := ρ(χ₀U)
- 对角主导度量：D[M] := min_α (M_{αα} - Σ_{β≠α} |M_{αβ}|)
- 对角元条件数：κ[M] := max_α M_{αα} / min_α M_{αα}

若满足以下条件：
1. ρ < 1（Stoner 稳定性）
2. κ[χ₀] ≤ κ_c（对角元接近）
3. u_max/u_min ≤ κ_U（U 接近均匀）

则 RPA 磁化率 χ^RPA = χ₀(1 - Uχ₀)⁻¹ 保持对角主导：

```
D[χ^RPA] ≥ f(ρ, κ, κ_U) · D[χ₀]
```

对某个 f > 0。

## 证明策略（2×2 → N×N）

### Step 1: 2×2 显式分析

对于 2×2 实对称矩阵：

```
χ₀ = [[c₁₁, c₁₂], [c₁₂, c₂₂]]
U = diag(u₁, u₂)
```

RPA 磁化率：

```
χ^RPA = χ₀(1 - Uχ₀)⁻¹
```

分母：

```
det(1 - Uχ₀) = 1 - u₁c₁₁ - u₂c₂₂ + u₁u₂(c₁₁c₂₂ - c₁₂²)
```

由 ρ < 1，分母 > 0（Stoner 稳定性）。

对角主导度量：

```
D[χ₀] = min(c₁₁ - |c₁₂|, c₂₂ - |c₁₂|)
```

**关键问题**：如何从 χ₀ 的结构（κ, ρ, D[χ₀]）界定 D[χ^RPA]？

### Step 2: 对称情况（κ = 1）

**引理 2.1**（对称情况）：若 c₁₁ = c₂₂ = c（对称），u₁ = u₂ = u（均匀），则：

```
χ^RPA = [[a, b], [b, a]]
```

仍然对称，且：

```
D[χ^RPA] = a - |b| = (c - |c₁₂|) / (1 - uc) = D[χ₀] / (1 - ρ)
```

其中 ρ = u(c + |c₁₂|) < 1。

**证明**：对称性保持显然。计算：

```
a = c(1 - uc) / [(1 - uc)² - u²c₁₂²]
b = c₁₂ / [(1 - uc)² - u²c₁₂²]
```

分母因式分解：

```
(1 - uc)² - u²c₁₂² = (1 - uc - u|c₁₂|)(1 - uc + u|c₁₂|)
```

所以：

```
a - |b| = [c(1 - uc) - |c₁₂|] / [(1 - uc - u|c₁₂|)(1 - uc + u|c₁₂|)]
        = [c - |c₁₂|] / (1 - uc - u|c₁₂|)
        = D[χ₀] / (1 - ρ)
```

因为 ρ = u(c + |c₁₂|)。□

**推论**：对称情况下，对角主导**严格增强**（比值 = 1/(1-ρ) > 1）。

## Step 3: 非对称情况的困难

当 c₁₁ ≠ c₂₂ 时，两行的对角主导增强率**不同**：

```
D[χ^RPA]_行1 = χ^RPA_{11} - |χ^RPA_{12}|
D[χ^RPA]_行2 = χ^RPA_{22} - |χ^RPA_{12}|
```

由于 χ^RPA_{11} 和 χ^RPA_{22} 的增强因子不同，瓶颈会出现在较弱的那一行。

**数值观察**（案例 4）：
- c₁₁ = 1.5, c₂₂ = 0.8 → κ = 1.875
- χ^RPA_{11} = 3.901（增强 2.6×）
- χ^RPA_{22} = 1.265（增强 1.6×）
- 瓶颈在行 2 → D 退化

**机制**：
- RPA 对大对角元增强更多（几何级数求和，首项大）
- 对小对角元增强有限
- min 操作选中弱轨道 → 全局 D 由弱轨道主导

## Step 4: 条件定理的证明思路

**策略**：不直接证明 D[χ^RPA] ≥ D[χ₀]，而是证明：

**引理 4.1**（相对对角主导）：若 κ[χ₀] ≤ κ_c，则：

```
D[χ^RPA] / min_α χ^RPA_{αα} ≥ D[χ₀] / min_α χ₀_{αα}
```

即：对角主导的**相对比例**保持。

**为什么这个更容易**：
- 分子分母同时增强，比值更稳定
- 避免了"绝对增强率不同"的问题

**2×2 验证**（案例 4）：

```
D[χ₀] / min(c₁₁, c₂₂) = 0.600 / 0.8 = 0.75
D[χ^RPA] / min(χ^RPA_{11}, χ^RPA_{22}) = 0.512 / 1.265 = 0.405
```

仍然退化！相对度量也不够强。

### 符号计算

**脚本**：`_rpa_2x2_symbolic_kappa_2026-09-22.py`

完整展开了 D[χ^RPA]_行2 / D[χ₀] 的符号表达式，形式为复杂有理函数：

```
D[χ^RPA]_行2 / D[χ₀] = 
  [c12·(c12²u² - (c22u-1)(c22κu-1)) + (c12²u - c22(c22κu-1))·|det|]
```

其中 det = -c12²u² + (c22u-1)(c22κu-1)。

**关键发现**：
1. 临界条件 D[χ^RPA]_行2 / D[χ₀] = 1 **无法求出 κ 的闭式解**

## Step 8: 技术障碍报告

### 为什么非对称情况困难？

1. **对称性破缺**：κ=1 时的因式分解 (1-uc-u|c12|)(1-uc+u|c12|) 在 κ≠1 时不再成立

2. **非线性耦合**：D[χ^RPA]_行2 包含 κ 和 ρ 的复杂交叉项，无法分离

3. **最小值操作**：两行的增强率不同，min 操作选中瓶颈（弱轨道），放大了非对称效应

4. **符号表达式复杂度**：完整展开后无法求解临界方程的闭式解

### 可能的解析突破路径

**路径 A**：谱分解 + Perron-Frobenius

χ₀ = λ₁v₁v₁^T + λ₂v₂v₂^T，跟踪 RPA 迭代如何改变本征向量在标准基下的混合。技术难点：对角主导不是本征值的直接函数。

**路径 B**：加权度量

定义 D_w[M] := min_α w_α(M_{αα} - Σ|M_{αβ}|)，选择权重 w_α ∝ 1/χ₀_{αα}，可能消除非对称增强率的差异。

**路径 C**：更紧的 ρ 界

当前 ρ = ρ(χ₀U) 是谱半径；若能找到"对角主导保持"的充分条件为某个更小的量 ρ' < ρ，条件定理可能更紧。
