## 定义与陈述

**对角主导度量**（Gershgorin 型）：

```
D[M] := min_α (M_{αα} - Σ_{β≠α} |M_{αβ}|)
```

若 D[M] > 0，则 M 是**严格对角主导**的。

**定理 1A′（对角主导传递）**：设 χ₀ 是 N×N Hermitian 正半定矩阵，U = diag(u₁,...,u_N) 且 u_α > 0。设 ρ := ρ(χ₀U) < 1（Stoner 稳定性）。

若 χ₀ 严格对角主导（D[χ₀] > 0），则 RPA 磁化率 χ^RPA = χ₀(1 - Uχ₀)⁻¹ 也严格对角主导，且：

```
D[χ^RPA] ≥ D[χ₀] / (1 - ρ)
```

**推论**：对角主导性通过 RPA 不仅保持，而且**增强**（因为分母 < 1）。

---

## 证明草图

### Step 1: Neumann 级数

由 ρ < 1，Neumann 级数收敛：

```
χ^RPA = χ₀ Σ_{n=0}^∞ (Uχ₀)^n = Σ_{n=0}^∞ (χ₀U)^n χ₀
```

### Step 2: 逐项对角主导界

**引理 D1**：设 M ⪰ 0 对角主导，A = χ₀U，‖A‖ ≤ ρ。则：

```
D[AM] ≥ σ · D[M]
```

对某个 σ > 0（依赖 A 的结构）。

**证明尝试**：

对任意 α：

```
(AM)_{αα} = Σ_k a_{αk} M_{kα}
```

由于 M Hermitian，M_{kα} = M̄_{αk}，所以：

```
(AM)_{αα} = Σ_k a_{αk} M̄_{αk}
```

若 a_{αk} 和 M_{αk} 都是实的（静态极限），则：

```
(AM)_{αα} = Σ_k a_{αk} M_{αk}
           ≥ a_{αα} M_{αα} - Σ_{k≠α} |a_{αk}| |M_{αk}|
```

**问题**：这个下界涉及 M 的**对角元和非对角元的混合**，不能直接用 D[M]。

---

### Step 3: 换一个角度 —— 用行和范数

**定义**：矩阵 M 的**行和范数**：

```
‖M‖_∞ := max_α Σ_β |M_{αβ}|
```

**引理 D2**：‖AM‖_∞ ≤ ‖A‖_∞ · ‖M‖_∞

这是范数的相容性，**立即成立**。

**引理 D3**：若 M 对角主导，D[M] > 0，则：

```
max_α M_{αα} ≤ ‖M‖_∞ ≤ 2 · max_α M_{αα}
```

**证明**：

```
‖M‖_∞ = max_α (M_{αα} + Σ_{β≠α} |M_{αβ}|)
      ≤ max_α (M_{αα} + (M_{αα} - D[M]))    (对角主导定义)
      = 2·max_α M_{αα} - D[M]
```

而 M_{αα} ≤ ‖M‖_∞（显然），所以：

```
max_α M_{αα} ≤ ‖M‖_∞ ≤ 2·max_α M_{αα}
```

**推论**：行和范数与对角元的最大值**同阶**（在对角主导矩阵上）。

---

### Step 4: 组合得到对角主导界

设 M^(n) := (χ₀U)^n χ₀。

由引理 D2：

```
‖M^(n)‖_∞ ≤ ‖χ₀U‖_∞^n · ‖χ₀‖_∞ ≤ ρ^n · ‖χ₀‖_∞
```

**关键观察**：若 χ₀ 对角主导，则 χ₀U 也"接近对角主导"（U 是对角阵）。

具体地：

```
(χ₀U)_{αβ} = (χ₀)_{αβ} · u_β
```

所以：

```
(χ₀U)_{αα} = χ₀_{αα} · u_α
Σ_{β≠α} |(χ₀U)_{αβ}| = Σ_{β≠α} |χ₀_{αβ}| · u_β
                      ≤ u_max · Σ_{β≠α} |χ₀_{αβ}|
```

其中 u_max := max_β u_β。

**问题**：u_β 不一定相等，所以对角主导度量会因 U 的不均匀性而退化。

---

## 障碍诊断

**核心困难**：U 不是纯量矩阵（u_α 可以不同），所以：

```
D[χ₀U] ≠ D[χ₀] · (某个常数)
```

U 的不均匀性会**破坏对角主导**的量化界。

**物理图像**：
- 若某个轨道 α 的 Coulomb u_α 特别大，它会放大 χ₀_{αβ} 的非对角元
- 即使 χ₀ 对角主导，χ₀U 可能不再对角主导

---

## 可行的修正路径

### 修正 1：条件假设（U 接近均匀）

若 u_max / u_min ≤ κ < ∞（U 的条件数有界），则可以控制退化。

**定理 1A′′（条件版）**：设 χ₀ 对角主导，D[χ₀] > 0。设 U 对角正，u_max/u_min ≤ κ。若 ρ(χ₀U) < 1，则：

```
D[χ^RPA] ≥ D[χ₀] / [(1 + κ(1-ρ)⁻¹)]
```

**优点**：技术上可证（用行和范数 + 条件数控制）
**缺点**：需要 U 均匀性假设（对一般多轨道系统不一定成立）

### 修正 2：改用加权对角主导度量

定义**加权对角主导**：

```
D_U[M] := min_α (M_{αα} - Σ_{β≠α} |M_{αβ}| · (u_β/u_α))
```

这个度量在 U-加权意义下是自然的。

**猜想**：D_U[χ₀U·χ₀] ≥ (某正常数) · D_U[χ₀]

**问题**：这个度量不是标准的 Gershgorin 度量，与 PSD 的关系不清楚。

### 修正 3：退守到静态极限 + 实对称（Route 1B）

若 χ₀, χ 都是实对称（ω=0），则可以用**谱分解**。

实对称矩阵的 Gershgorin 圆盘定理**更强**（所有本征值在圆盘内）。

结合 Perron-Frobenius（非负矩阵的最大本征值与对角主导的关系），可能给出严格界。

**优点**：Essenberger 用的就是静态极限，够用
**缺点**：技术上仍然不平凡（需要控制谱分解的混合）
