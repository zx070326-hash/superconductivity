# RPA 2×2 反例分析：对角主导可以退化

**日期**：2026-09-22 深夜  
**状态**：数值发现（需理论解释）  
**严格性**：numerical-evidence

---

## 关键发现

2×2 显式计算发现一个**反例**：

```
案例: 强非对称 χ₀, 均匀 U
  χ₀ = [[1.5, 0.2], [0.2, 0.8]]
  U = diag(0.4, 0.4)
  
  ρ(χ₀U) = 0.621245 < 1  ✓ Stoner 稳定
  D[χ₀] = 0.600000
  D[χ^RPA] = 0.512048
  比值 D[χ^RPA]/D[χ₀] = 0.853414 < 1  ✗ 对角主导退化
```

即使 ρ < 1（RPA 收敛），**对角主导度量可以下降**。

---

## 为什么会退化？

**机制分析**：

χ^RPA 的对角主导度量是：

```
D[χ^RPA] = min(χ^RPA_{11} - |χ^RPA_{12}|, χ^RPA_{22} - |χ^RPA_{12}|)
```

在反例中：
- χ^RPA_{11} = 3.147590（从 1.5 大幅增强）
- χ^RPA_{22} = 0.512048（从 0.8 轻微减弱）
- |χ^RPA_{12}| = 某个值

问题在于：**两个对角元的增强率不同**。

- 第1行的对角主导增强：3.147590 - |χ^RPA_{12}| >> 1.5 - 0.2
- 第2行的对角主导退化：0.512048 - |χ^RPA_{12}| < 0.8 - 0.2

**瓶颈是较弱的那一行**（min 操作）。

---

## 物理图像

RPA 迭代在**强耦合轨道**和**弱耦合轨道**上的作用不对称：

1. **强耦合轨道**（大对角元）：RPA 使其进一步增强
2. **弱耦合轨道**（小对角元）：RPA 增强有限，可能被非对角元的增长超越

当 χ₀ **对角元差异大**时（1.5 vs 0.8），这种不对称会导致全局对角主导度量下降。

## 对定理的影响

**原计划定理（Route 1A/1B）**：证明 D[χ^RPA] ≥ κ · D[χ₀] 对某 κ > 0

**反例表明**：这个定理在一般情况下**不成立**（即使 ρ < 1）。

---

## 可能的修正方向

### 方向 1：改用**加权**对角主导度量

定义：

```
D_w[M] := Σ_α w_α (M_{αα} - Σ_{β≠α} |M_{αβ}|)
```

其中 w_α 是权重（如 w_α ∝ χ₀_{αα}）。

这样可以避免 min 操作带来的"木桶效应"。

### 方向 2：证明**相对**对角主导

不证 D[χ^RPA] ≥ κ · D[χ₀]，改证：

```
D[χ^RPA] / max_α χ^RPA_{αα} ≥ D[χ₀] / max_α χ₀_{αα}
```

即：对角主导**比例**保持。

### 方向 3：条件定理（χ₀ 对角元接近）

若 χ₀ 的对角元满足 c_{max}/c_{min} ≤ κ（条件数有界），则可以避免上述不对称。

**定理 1A′′′（条件版）**：若 ρ < 1 且 max_α χ₀_{αα} / min_α χ₀_{αα} ≤ κ，则：

```
D[χ^RPA] ≥ f(ρ, κ) · D[χ₀]
```

对某个 f(ρ, κ) > 0。

### 方向 4：改证**行对角主导**的平均

不证 min_α (χ_{αα} - Σ_{β≠α}|χ_{αβ}|)，改证：

```
平均 D[χ^RPA] := (1/N) Σ_α (χ^RPA_{αα} - Σ_{β≠α} |χ^RPA_{αβ}|)
```

平均可能比 min 更稳定。

## 对 Essenberger 应用的影响

**Essenberger Eq.(37) 需要的是什么？**

回顾：Essenberger 声称 Im Λ^SF_{ij} > 0（逐元，含非对角）。

这**不是**对角主导（对角主导允许非对角元为负）。

**我们的定理方向可能跑偏了！**

---

## 重新审视目标

**原始问题**（from 深挖计划）：

验证或证伪 Essenberger Eq.(37) 的 Im Λ^SF_{ij} > 0（**逐元正**，非对角也正）。

**我们试图证明的**：

RPA 保持对角主导（对角主导 ≠ 逐元正）。

**关系**：

- 对角主导 + PSD ⟹ 对角元正，非对角元可以为负
- 逐元正 ⟹ PSD ⟹ 包含对角主导（但逆命题不成立）

**结论**：

**对角主导保持**（即使我们能证明）**不蕴含非对角元为正**。

这是一个**更弱的结论**，不足以支持 Essenberger 的逐元正断言。
