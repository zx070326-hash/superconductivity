## 2. 定理 (D)（analytic）：符号型 `f^xc` 扫描对主导项**零杠杆**

设 `f^xc` 轨道对角且实：`f^xc_{ll′} = f_l δ_{ll′}`；轨道权重
`w_l(i) = |U_{k_i}[l,n_i]|² ≥ 0`（**显然非负**，且 `Σ_l w_l = 1`）。则 `Im Λ^SF_ij` 的
`l = l′` 部分为

```
D_ij = Σ_l  f_l² · w_l(i) · w_l(j) · Im χ^s_ll(q_ij)
```

其中 `f_l² ≥ 0`、`w_l(i)w_l(j) ≥ 0`，**逐项**非负。
⟹ **若 `diag(Im χ^s)` 符号一致（记符号 σ），则 `D_ij` 对每一对 (i,j)、
对每一个实 `f_l` 取值（含每一种符号模式）都有符号 σ。** ∎

**推论（本笔记的承重点）**：一个只翻转轨道对角核**符号**的 `f^xc` 敏感性扫描，
**可证明地**对 `D` 有零杠杆——它只能动 `l ≠ l′` 的余项。

实测余项有多小（同参数，中位数）：

| ω | `|D_ij| / |Λ_ij|` 中位 | `correlation_flip` 下**变号**的对 |
|---|---|---|
| 0.05 | **0.998** | 35/300 = 11.7% |
| 0.2 | **0.959** | 54/300 = 18.0% |

数值验证定理 (D)（四种 `f_l`：全 +1 / correlation_flip / 随机符号 / 随机幅度）：
**`D_ij < 0` 出现 0/300，八种组合全部为 0**，与解析结论一致。

⟹ §3′ 的「结论对两个测试过的 f^xc 分支稳健」**主要测到的是一条代数恒等式**
（`f_l² ≡ 1` 对 `f_l = ±1`），不是物理稳健性。变号的 11.7–18% 全部落在近零对上。
**要让 `f^xc` 扫描有杠杆，必须改变 `|f_l|`（动 `f_l²`）或引入轨道非对角 `f^xc_{ll′}`。**
（后者正是他们自己在「未完成」里标为「这条建模链最粗的一环」的那一项。）

## 3. 置换零假设：90% 与「打散能带信息」不可分辨

**零假设设计**：保留**真实的**权重向量集合 `{w(i)}`、保留**真实的** `q` 集合与真实的
`Im χ^s(q_ij,ω)`，**只打乱**「哪个轨道特征配哪个动量」的对应（对 FS 点做置换 π，
用 `w(π(i))`）。这样两个边缘分布**逐字保留**，被破坏的恰好是费米面能带结构那份信息。
2000 次置换：

| ω | 实测 | 零假设中位 | 零假设 95% 区间 | `P(null ≤ obs)` |
|---|---|---|---|---|
| 0.05 | 271/300 = 90.3% | 268/300 = 89.3% | 259–276 | **0.80** |
| 0.2 | 270/300 = 90.0% | 275/300 = 91.7% | 266–282 | **0.16** |

**两个 ω 的实测值都稳稳落在零假设 95% 区间内。**
⟹ 这 90% **不含任何费米面能带信息**；把 `w` 与 `k` 的真实对应关系整个拆掉，
数字原地不动。⟹ 不可引用为「Eq.(37) 在铁基上成立的证据」。

这与我此前对轨道基扫描（45.8% 对上 49% 无信息基线）的判词**是同一个形状**：
**落在零假设上的观测值，方向再显著也只是在测零假设。**
注意这里更强：45.8% 那次是与**通用**随机基底比；这次是与**材料自身**的置换零假设比。

## 4. 订正：我中途读的「90% 低于零假设 98%」是错的

**第一段：旧陈述错在哪。** 我先跑的零假设（Q2）用**均匀 Dirichlet** 随机概率向量替换真实
`w`，得 98.7% / 97.7%，据此一度读成「实测 90% **低于**结构性基线，若有倾向也是反向」。
这个读法**错了**：均匀 Dirichlet 样本集中在单纯形重心附近（各分量 ≈ 0.2），
比真实轨道权重（通常集中在 1–2 个轨道上）**更"对齐"**，而两个更对齐的非负向量夹一个
PSD 阵更容易得正 ⟹ **Q2 的零假设朝正方向有偏**，不是公平零假设。

**第二段：新陈述凭什么对。** §3 的置换零假设**逐字保留**真实 `w` 的集合（因而保留其
集中度）与真实 `χ` 的集合，只打断配对，**构造上**消除了这一偏倚；它给出 89.3% / 91.7%，
把实测的 90.3% / 90.0% 夹在中间。⟹ 正确判词是**「与零假设不可分辨」**，
**不是**「低于零假设」。本笔记 §0 与 §3 按后者陈述；Q2 的 98% 只作为"零假设设计要匹配
边缘分布"的反面教材保留在脚本里，**不作为结论引用**。

## 5. 机制：符号是从 `diag(Im χ^s)` 的约定继承来的

| ω | `diag(Im χ^s) > 0` | 非对角 `< 0` |
|---|---|---|
| 0.05 | **280/280 = 100%** | 586/1120 = 52.3% |
| 0.2 | **280/280 = 100%** | 560/1120 = 50.0% |

对角**符号一致**（修正符号后全正），非对角是**掷硬币**（50–52%，与
`../misc/dynamic_im_chis_elementwise_sign_scan_2026-09-22.md` 的轨道基结果一致）。
配合定理 (D) 与 `|D|/|Λ| = 0.998`：

> **`Λ^SF` 的逐元正性 = 非负轨道权重 × 符号一致的对角元。**

而那个对角符号，正是该笔记自己标注为
**「Kubo/傅里叶符号约定，非物理内容」**的量，也正是本轮刚刚翻过一次的那个量。
⟹ 头条方向**两次**都由同一个约定决定；这不是巧合，是这个观测量的结构。

**附带结论（限制定理 (S1) §3 的外推）**：定理 (S1) 测到的机制是

## 7. 追加（team-lead 从零复核，2026-09-22 晚）：§6 那项「轨道非对角 f^xc」的预算**尚未算出**

> §6 结尾写「真正有预算的重设计是轨道非对角 `f^xc_{ll′}` …… 派活前仍需先算那一项的预算」。
> 那次预算由 `../_scratch_ir/_chk_offdiag_fxc_budget_for_sign_flip_2026-09-22.py` 执行。
> 我从零重算其**模型**（不是其数值），发现模型本身错位 ⟹ **该预算作废，不是变小、是未算**。
> 复核脚本：`../_scratch_ir/_chk_offdiag_fxc_linear_model_is_misspecified_2026-09-22.py`（`Fraction`，承重行零浮点）。

**第一段：旧陈述错在哪。** 那个脚本的模型是

```
f^xc_ll = 1、f^xc_ll′ = κ  ⟹  Λ_ij(κ) = D_ij + κ·R_ij   （κ 的一次式），  κ* = −D_ij/R_ij
```

但 `Λ^SF = f^xc χ f^xc` 是**夹心**，对 `f^xc` **双线性**。取 `F(κ)=I+κK`（`K` 纯非对角）：

```
F χ F = χ + κ(Kχ + χK) + κ²·KχK
```

即 `Λ_ij(κ) = c₀ + c₁κ + c₂κ²`，且**三个系数没有一个等于脚本所用的量**：
`c₀ = w_i·χ·w_j`（脚本的 `D` 把 `χ` 的非对角丢掉了，所以 `D` 连 `Λ(κ=0)` 都不是）、
`c₁ = w_i·(Kχ+χK)·w_j ≠ R := full1 − D`、`c₂ = w_i·KχK·w_j` 在脚本里**根本不存在**。
根因是把「`χ` 的**轨道指标**非对角」当成了「`f^xc` 的非对角」——这是两个旋钮。
这也正是 §1 定理 (D) 的对偶面：对角 `f^xc` 之所以带 `f_l²`（本篇 L.44），用的就是夹心；
同一个夹心在非对角上必然给出 `κ²`，脚本只在对角侧用了夹心、在非对角侧用了线性。

**第二段：新陈述凭什么对，以及方向。** 显式 3×3 有理例〔rational-exact，1 格 / 约 30 个有理数〕：
`c₀=1/10` 对 `D=23/20`、`c₁=21/10` 对 `R=−21/20`、`c₂=14/5≠0`；
脚本公式报出有限翻转点 `κ*=23/21≈1.095`，而真二次式的两根 `≈−0.699, −0.051` **全为负**
⟹ **真模型下不存在任何正的 κ 使之变号**，脚本却报「1.1 倍非对角强度即可翻」。
4000 组精确有理随机：`(c₀,c₁)≠(D,R)` **4000/4000 = 100%**；两模型对「到底翻不翻得动」
的判断**分歧 1709/4000 = 42.7%**，且**两个方向都出现**（1516 次假「路线开放」、193 次假「路线关闭」）。

⟹ **误差是双边的，因此该脚本的输出既不支持 PASS 也不支持 FAIL**（不是单边界，
不适用「下估只支持 PASS」那条豁免）。判词是 **UNCOMPUTED，不是 ∞ 也不是有限**。

**不受影响的（明确保留）**：§1 定理 (D)（`analytic`）、`|D|/|Λ| = 0.998 / 0.959`、
§3 置换零假设、§4 的订正、§5 机制——它们全部只涉及**对角** `f^xc`，那里 `f_l²` 正是夹心的正确因子。
§6 里「符号型 `f^xc` 扫描预算 = ∞、不要再派」也不变（由定理 (D) 独立给出）。
**只有**§6 最后一句「轨道非对角那一项的预算」这一项失去其数值依据。

**对派活的后果**：按预算优先纪律，**预算未算出之前不派这条线**；
要重算，正确的预算量是二次式 `c₀+c₁κ+c₂κ²` 的最小正根（或「无正根」），
不是 `|D/R|`。本次不派——它的消费点 (K1) 判定目前另有阻断
（定理 (S1)：夹心对非秩一 `f^xc` **永远**给不出逐元正，
`fxc_sandwich_cannot_give_elementwise_positivity_2026-09-22.md`，`analytic`、充要），
⟹ 即便把 κ 预算算对，这条线的终点仍被 (S1) 封死。**先解 (S1) 那一关，再谈 κ。**
