## 定理陈述

**定理 A1**（对称情况的代数退化界）：

设 χ₀ = c·I + c_off·(J-I) 是 N×N 对称矩阵，满足：
1. c > 0, c_off ≥ 0
2. D[χ₀] := c - (N-1)c_off > 0  （对角主导）
3. ρ_max := u(c + (N-1)c_off) < 1  （Stoner 稳定性）

则 RPA 磁化率 χ^RPA = χ₀(I - uχ₀)⁻¹ 满足：

```
D[χ^RPA] / D[χ₀] ≥ C(ρ_min, ρ_max) / N
```

其中：
- ρ_min := u(c - c_off)
- C(ρ_min, ρ_max) > 0 是仅依赖 ρ_min, ρ_max 的常数

---

## 证明

### Step 1: 回顾显式公式

从 Route 1 关键发现，我们已经推导出（数值验证完成）：

```
D[χ^RPA] = [(c-c_off)/(1-ρ_min) - (c+(N-1)c_off)/(1-ρ_max)] · (N-1)/N
```

其中：
- ρ_min = u(c - c_off)
- ρ_max = u(c + (N-1)c_off)

而：
```
D[χ₀] = c - (N-1)c_off
```

### Step 2: 比值的显式形式

```
D[χ^RPA] / D[χ₀] = [(c-c_off)/(1-ρ_min) - (c+(N-1)c_off)/(1-ρ_max)] / [c - (N-1)c_off] · (N-1)/N
```

记：
- a := c - c_off  （非 Perron 本征值）
- b := c + (N-1)c_off  （Perron 本征值）

注意到：
```
c - (N-1)c_off = c - c_off - (N-2)c_off = a - (N-2)c_off
b = a + Nc_off
```

因此：
```
D[χ^RPA] / D[χ₀] = [a/(1-ρ_min) - b/(1-ρ_max)] / [a - (N-2)c_off] · (N-1)/N
```

### Step 3: 分子的下界

**引理 3.1**: 在条件 (1)-(3) 下，分子 S := a/(1-ρ_min) - b/(1-ρ_max) > 0。

**证明**: 

由 ρ_min < ρ_max < 1，我们有：
```
1/(1-ρ_min) > 1/(1-ρ_max) > 1
```

如果 a ≥ b，则显然 S > 0。

如果 a < b（即 c_off > 0），我们需要证明：
```
a/(1-ρ_min) > b/(1-ρ_max)
```

即：
```
a(1-ρ_max) > b(1-ρ_min)
```

展开：
```
a - aρ_max > b - bρ_min
a - ρ_max·a > b - ρ_min·b
a - b > ρ_max·a - ρ_min·b
-(b-a) > a·u(c+(N-1)c_off) - b·u(c-c_off)
-Nc_off > a·u·c + a·u·(N-1)c_off - (a+Nc_off)·u·(c-c_off)
-Nc_off > a·u·c + a·u·(N-1)c_off - a·u·c + a·u·c_off - Nc_off·u·c + Nc_off·u·c_off
-Nc_off > a·u·(N-1)c_off + a·u·c_off - Nc_off·u·c + Nc_off·u·c_off
-Nc_off > a·u·Nc_off - Nc_off·u·c + Nc_off·u·c_off
-1 > a·u - u·c + u·c_off
-1 > u(a - c + c_off)
-1 > u(c - c_off - c + c_off)
-1 > 0
```

**这是矛盾**！我的推导有误。让我重新计算。

实际上，让我直接数值检验这个不等式。

### Step 3': 数值检验分子符号

从 Route 1 的数值结果：

| N | a/(1-ρ_min) | b/(1-ρ_max) | 分子 S |
|---|---|---|---|
| 2 | 0.606 | 3.158 | 需计算 |
| 3 | 1.017 | 3.158 | 需计算 |

等等，这里我需要重新从原始公式计算。

让我改用更直接的方法。

### Step 4: 直接界定（备选方法）

**关键观察**: 从数值结果我们知道比值是正的（虽然 < 1）。

让我们改为界定比值的**下界**，而不是精确形式。

从 Perron-Frobenius 分解：
```
D[χ^RPA] = [非Perron贡献] - [Perron负贡献]
```

非 Perron 贡献来自 N-1 个简并本征值 λ_min = c - c_off：
```
非Perron贡献 ≥ (c-c_off)/(1-ρ_min) · [某个正系数]
```

Perron 负贡献的量级：
```
Perron负贡献 ~ (c+(N-1)c_off)/(1-ρ_max) · 1/N
```

当 N 大时，即使 Perron 增强因子大，1/N 因子使其贡献变小。

但这个论证还不够严格。

### Step 5: 使用约束条件

**关键约束**: c_off < c/(N-1) （由 D[χ₀] > 0）

这意味着：
```
(N-1)c_off < c
c + (N-1)c_off < 2c
```

因此：
```
ρ_max = u(c + (N-1)c_off) < 2uc
```

而：
```
ρ_min = u(c - c_off) > u(c - c/(N-1)) = uc(1 - 1/(N-1)) = uc(N-2)/(N-1)
```

所以 ρ_min 接近 uc（从下方），而 ρ_max < 2uc。

### Step 6: 简化策略

让我采用更实用的方法：**数值拟合下界**。

从已有的 N=2-10 数据，我们观察到比值 r(N) 满足：
```
r(N) ≈ 1.13 · exp(-0.124N)
```

对于大 N，这比 C/N 衰减得更快。所以代数界 C/N 是**松的**。

但我们可以找到一个保守的 C 使得：
```
r(N) ≥ C/N  对所有 N ≥ 2
```

从数据：
- N=2: r=1.21, C=2.42
- N=3: r=0.61, C=1.83
- N=4: r=0.37, C=1.48
- N=5: r=0.25, C=1.25

最小的 C ≈ 1.25，对应 N=5。

但这只是数值观察，不是证明。

## 策略转变

我意识到从显式公式直接证明代数界在技术上有困难，因为：
1. 分子的符号分析需要精细的不等式链
2. 分母与 N 的关系复杂（通过 c_off）

**新策略**: 不证明代数界，而是**证明有界性** D[χ^RPA] > 0（即不会塌缩到零）。

这是一个更弱但更容易的结果。

## 定理 A1'（修正版）

**定理 A1'**（RPA 对角主导有界退化）：

设 χ₀ = c·I + c_off·(J-I) 是 N×N 对称矩阵，满足：
1. D[χ₀] > 0
2. ρ_max < 1

则：
```
D[χ^RPA] > 0
```

即 RPA 保持对角主导的**定性性质**（虽然度量可能减小）。

**证明**:

由 ρ_max < 1，RPA 公式收敛，χ^RPA 良定义。

χ^RPA 仍然是实对称矩阵（保持结构）。

由 Perron-Frobenius 定理，χ^RPA 的所有本征值严格为正（因为 χ₀ ⪰ 0 且 ρ < 1）。

由 Gershgorin 圆盘定理的逆向应用，若所有本征值为正，则存在至少一行满足对角主导。

但这不够强（我们需要所有行）。
