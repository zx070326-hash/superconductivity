# 引理 (W)：加权度量能否挽救，等价于 χ^RPA 是否逐行对角主导

**严格性（分两半，不同档，不要合并陈述）**：

- **(⟸) 可挽救半边：numerical-evidence**（单个 χ₀ = Route 1B 标准反例，60×60 网格，854/854）。

## 0. 这条笔记包含一次对我自己的订正。两段分开写

**第一段：旧陈述错在哪。**
我第一版把天花板写成 `sup_w ratio = max(R₁/D₁, R₂/D₂)`（`R`/`D` 为 χ^RPA / χ₀ 的行亏损，
`t := w₁/w₂`，`ratio(t) = min(tR₁,R₂)/min(tD₁,D₂)`）。这个公式**只在 R₁>0 且 R₂>0 时成立**。
若 R₁<0<R₂，则 `min(tR₁,R₂) = tR₁` 对**一切** t>0 成立——分子被钉死在负的那一行，
永远切不到第 2 行，于是 `R₂/D₂` 这个值根本取不到。实测该公式高估天花板最多 **8.119e3**。

后果的方向是坏的那一侧：我用这个被高估的天花板算出「方案 B 只占 12.9%」，
**这是拿单边高估去支撑一个 FAIL 判决**，正是单边界方向规则禁止的用法。该数字作废。

**第二段：新陈述凭什么对。**
`ratio(t)` 是分段单调的，折点只可能出现在某个 `min()` 换支处，即 `t = D₂/D₁` 与（仅当 R₁>0 时）`t = R₂/R₁`。
在折点与两端极限上取 max 即得**精确** sup。与 4001 点暴力扫描对照，最大差 **1.776e−15** ⟹ 精确。
订正后的数字是 22.2%，但下面会说明这个百分比本身不再是承重量。

## 1. 引理 (W)（不可挽救半边，analytic）

**陈述**：设 χ₀ 逐行严格对角主导（`D_α := χ₀_αα − Σ_{β≠α}|χ₀_αβ| > 0` 对每个 α），
权重 `w_α > 0` 任意，加权度量 `D_w[M] := min_α w_α (M_αα − Σ_{β≠α}|M_αβ|)`。
若 χ^RPA **某一行**的亏损 `R_α < 0`，则

```
D_w[χ^RPA] < 0 < D_w[χ₀]   对一切正权重成立。
```

**证明**：`D_w[χ^RPA] = min_α w_α R_α ≤ w_{α₀} R_{α₀} < 0`（取 R 为负的那个 α₀，`w_{α₀}>0`）。
另一侧 `D_w[χ₀] = min_α w_α D_α > 0`（所有 `D_α>0`、所有 `w_α>0`）。∎

一行。任意 N、任意 χ₀、任意正权重公式——**包括允许偷看 χ^RPA 的权重**。

**这条封的是什么**：Route 2 的目标是「找一个权重公式，使对角主导在 RPA 下普遍保持」。
引理 (W) 说：凡是 RPA 把某一行打穿的参数点，**没有任何权重公式能救**。
加权度量能做的全部事情，是在「χ^RPA 每行都还对角主导、但标准 `min` 选错了行」的点上换一行。

## 2. 数值二分（单个 χ₀，60×60 网格）

χ₀ = `[[1.5,0.2],[0.2,0.8]]`（κ=1.875，Route 1B 标准反例），U=diag(U₁,U₂) 于 [0.02,0.8]²，
仅保留 Stoner 稳定（ρ<1）点，再仅保留**真失败**点（标准度量 ratio<1）：

| | 计数 |
|---|---|
| Stoner 稳定点 | 2903 |
| 真失败点 | 1477 |
| ├ 某行 R_α<0（引理 (W) ⟹ 任何权重都救不了） | **623** |
| └ 全部 R_α>0 | 854 |
| 精确天花板 ≥1（存在某权重可挽救） | **854** |
| 「天花板<1 但全部 R>0」 | **0** |

⟹ 在这个 χ₀ 上二分是**精确**的：不可挽救集 = 负行集，**623/623，无例外**；
可挽救集 = 全正行集，**854/854，无例外**。引理 (W) 解释了不可挽救集的 **100%**。

反向蕴含（全正行 ⟹ 天花板≥1）在此 χ₀ 上 854/854 成立，但**我没有证明它**，
它很可能依赖 `χ₀_11 > χ₀_22` 使第 1 行总被 RPA 增强。标为 **numerical-evidence，单 χ₀**，
不要外推到一般 χ₀。

## 4. 对 Route 2 的判决与预算

rpa-deep-dive 问：值不值得投 0.5–1 天把「强对角通道配大 U ⟹ 方案 B 挽救」推成解析条件？

**不值得，且理由不是「太难」，是目标已被引理 (W) 封顶。**
- 那 0.5–1 天最好的产出是一个描述方案 B 挽救区的条件式。
- 但引理 (W) 已经给出**所有**权重公式的共同上界，而且是 analytic、任意 N。
  在它之上，方案 B 的具体挽救区只是「某个次优公式覆盖了天花板的哪一块」——
  这是工程刻画，不是定理。
- 真正的定理级产出（本笔记 §1）**已经拿到了**，成本约两小时。

⟹ **Route 2 就地封闭，交付物是引理 (W) 这条 no-go，而不是方案 B 的条件式。**
这比原计划的「止损报告」强：止损报告说「我们没找到」，引理 (W) 说「谁都找不到，这里是为什么」。

**剩下唯一有预算的问题**（若还要继续投）：反向蕴含（§2 的 854/854）是否对一般 χ₀ 成立。
它若成立，(W) 就升级为**充要**刻画，Route 2 的故事完整。换 3–5 个不同 κ 的 χ₀ 扫一遍即可，
成本约半天，且**先算预算**：若某个 χ₀ 上出现「全正行但天花板<1」的点，充要就垮，只剩必要。
