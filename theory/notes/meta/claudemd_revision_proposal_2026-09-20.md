## 2. 准入标准（先立标准，再回审）

往 `CLAUDE.md` 加一条规则的**净收益 = 拦下的损失 − 注意力成本 − 误拦的损失**。
后两项在现行文件里从未被记账，这是它膨胀的根因。我提出四道闸，**全过才准入**：

> **A. 动作，不是提醒。** 能写成「落笔前/交付前做 X」，且 **X 执行后留下一个可被他人复核的产物**
> （一个数、一张表、一句标级、一行 `COVERAGE:`）。写不出产物的是「要小心」，归 memory，不进 `CLAUDE.md`。
>
> **B. 复发性有机制。** ≥2 次**独立**同形事故，**或** 1 次事故 + 一个能解释「为什么它会反复发生」的结构性成因。
> 单次事故 + 无机制 = 过拟合，归 memory。
> （理由：条目的价值正比于**未来违反它的概率**；没有机制就没法论证这个概率非零。）
>
> **C. 双向成本已记账。** 凡「不要做 X」型规则，必须写明**误拦的代价**与**推翻它需要什么证据**。
> 只有单向判决的禁令会在研究方向演化时变成盲区——「预算优先」就是现成的例子。
>
> **D. 非冗余。** 若新事故能被已有条目解释，写进**那个条目**（作为实例），不新开条目。
> **条目数的增长必须由机制数驱动，不由事故数驱动。**

三点说明：
- **B 里的「≥2」不是拍脑袋**：文件里最强的四条（W1、单边界、逐箭头、𝒫 封闭）全部是 ≥2 起 + 机制；
  唯一的 1 起条目（记录丢失）机制唯一且执行成本近零，是 B 的「或」分支的合法用法。
- **A 的「留下产物」是本标准里唯一真正咬人的一条**：它把「要小心 X」逼成「打印 X」。
  09-19 门禁的修法正是这个形状——它不是加了检查，是加了 `COVERAGE:` 那一行**计数**。
- **本标准自己不满足 A**（它没有产物）⟹ 它不该进 `CLAUDE.md` 正文，只作为审稿时的口径。我把它写在这里，不写进候选稿。

## 3. 专章：「预算优先」的意义到底在哪里？

### 3.1 正面：三起事故逐条核实（不转引 `CLAUDE.md` 自己的叙述）

原始记录在 `memory/theta-tilde-keeping-D-2026-09-17.md` §「★★ 三次『假预算』」。逐条：

**① `C_R ≤ 1.6` / ② `C_R ≤ 20`**
memory 原文记的 κ 扫描：`C_R = 1.6 / 6 / 20 / 25 / 30 / … / ∞` 给 12 格最劣
`0.2255 / 0.2256 / 0.2257 / 0.2450 / 0.2809 / … / 0.2809`，判据要求 `< 1`
⟹ **`C_R = ∞` 照样过**。
形状**确认同形**：目标常数（1.6、20）是派活方拍的，判据真正要求的只是「有限」。
且 memory 明写机制：`λ₂ ≤ min(P_β, Λ_full(C_R), Θ*, 0.6h)`，**`min` 里各项互相兜底 ⟹ 单项紧度几乎从不决定通不通**。
这个机制是可迁移的，不是单例。

**③ `P_β` 的 `max_{n≤300}V_β` 区间化**
memory 原文：`κ=1→5` 恒 `0.2256`、`κ=8` 给 `0.4397`、`κ≥12` 恒 `0.5751`、**`κ=∞` 仍 `0.5751` PASS**。
方向审计写在 memory 里且**正确**：抬高上界 ⟹ `g=h−界` 变小 ⟹ ratio 变大 ⟹ 判据变难 ⟹ 「κ 处 PASS」蕴含「宽度因子 ≤κ 的包封 PASS」。
形状**确认同形**。

**④ `k_res < 2×` vs 加权 Schur 的固有松** —— **形状不同，`CLAUDE.md` 第 51 行的「同形事故第四起」是误分类。**
（`CLAUDE.md` 那一行把固有松记作 `2.39×`；该数字**出处未定位**，见 §10.4 ⟹ 候选稿里已不引用它，改引可定位的 `1.99–3.24×`。）

我跑了 `theory/notes/_scratch_ir/_chk_ratio_interval_budget.py`（未改一行，`OMP_NUM_THREADS=1`），实测：

```

     1      1 |    1      0.7882 | PASS

     1      5 |    4      0.9689 | PASS
     1     10 |    9         inf | FAIL
```

⟹ `k_res` 的预算**有限且紧**（翻转在 1–2 之间），`k_nrm` 的预算**有限**（翻转在 5–10 之间）。

> **表注（主会话 2026-09-20，见 §3.2(d) 订正块）**：基线 `ratio()` 是 fail-open 的（`nphi/npsi` 下估一个要上界的量）
> ⟹ `computed ratio ≤ true ratio` ⟹ **FAIL 行声音、PASS 行不可信**。
> 本节用到的 `k_res` 翻转（`(2,1)` 起 FAIL）落在**声音的一侧**；
> `(1,2)`、`(1,5)` 那两行 PASS 只支撑较弱的「`k_nrm` 翻转在 5–10 之间」。
> 主会话已从零重跑本表（`OMP_NUM_THREADS=1`），逐行一致。

**两个量都承重，都不是「预算 ∞」。** 第 4 起的失败是：目标常数 `<2×` 定得比**所选估计子的固有松**还低
⟹ 这是**可达性**失败，方向与 ①②③ 的**必要性**失败**相反**：
前三起是「要求太松也能过，别做」，第四起是「要求再紧也做不到，换工具」。
把它们并成一条，会让读者以为「算完预算就够了」，而实际上要算**两个**互相独立的量。
⟹ **建议在候选稿里拆成两条。**

附带一个诚实的限定（memory `lam2-bound-is-the-lemmaC-lever` 与 `nphi-soundness-cost` 对照得出）：
09-17 实测加权 Schur 固有松 `1.55×(φ) / 1.52×(ψ)`，据此判「富余 4.3×、可达、定 `κ≤4`」；

⟹ 「先实测固有松」这条处方本身也有误差，必须在**判据真正消费的那一格 / 最劣格**上测，不能在一个点上测。

**正面小结**：①②③ 确实同形、确实会被这条规则拦住，机制（`min` 兜底）是结构性的而非偶然。
**这条规则的正面价值是真的，不是自我安慰。**它还有两次有据可查的正确使用：
- `memory/offdiag-gf-factor-1p248`：据此**回绝**了「缺口 1（锥）」的派活（只买回 ≤11.7%，MgB₂ 1.2%）；

### 3.2 反面：这条规则本身的成本

**(a) 它阻止过正确的工作——而且是系统性盲区，不是偶然。** ✅ 成立，这是最重的一条。

同一篇 memory 在宣布「`C_R` 预算是假的」之后，紧接着写：

> `C_R≤6` 真正买到的是**绑定项置换**：格 8–12 从 `Θ*` 换成 `Λ_full` ⟹ **把 `Θ*` 踢出链条**
> （`Θ*` 用仓库 M2 pad 族、**我从未从零复核**）。现在 12 格 λ₂ 界只剩 `P_β` + `Λ_full`，两者都是自推的。

⟹ 预算扫描的目标函数是 `∂(判决)/∂(该量)`，**固定链条结构**求偏导。
而 `C_R≤6` 的真实收益是**改变了链条结构**：把一个「继承自仓库、我从未从零复核」的对象从承重位置上摘掉。
**审计面（audit surface）根本不在预算扫描的值域里。** 这不是扫描没扫对，是**目标函数写窄了**。
同类被该规则回绝的活（缺口 1 / 锥）是否也踩了这个盲区——**未知**，因为那次同样只按余量算。我不宣称它错，只标它未被这个角度审过。

**(b) 「预算 = ∞ ⟹ 不承重 ⟹ 不要派活」过强。** ✅ 成立，且反例就在同一页。

`P_β` 判为「κ=∞ 仍 PASS ⟹ 不承重」，但同一篇 memory 同时写：

> **`P_β` 不是关口，它买的是余量：4.43× vs 1.74×。**
> 判定问题（已派 `lam2bound`）：整个 `ratio()` 区间化需要的余量因子 **<1.74×**（则 `P_β` 可直接删）

⟹ 那个「不承重的量」买到的余量，**正是决定下游那件真承重的活（`ratio()` 七个量 + `N=600` 截断尾的区间化）能不能做**的变量。
⟹ **预算不是量的内禀属性，是它「在当前链条状态下」的属性。** 链条一旦收紧，今天的 ∞ 明天可能有限。
这与文件里已有的「换了界就要重解」是同一条道理，只是从未应用到预算自身。

**(c) 「它诱导把力气花在预算上」——❌ 我查证后不采纳。**
`_chk_ratio_interval_budget.py` 是一个 ~85 行的脚本，我实测全扫一次数分钟；

**唯一会贵的情形是「算预算本身需要造新工具」，而那时预算计算已经就是主工作的一部分。**
⟹ 这条反面理由不成立，我不把它写进裁决。

**(d) 我自己发现的第四条反面：预算扫描本身是单边的，而文件从未对它用单边界方向规则。** ⚠ 这条最该进正文。

两个事实，都在 memory 里，但从未被放在一起：
1. `nphi/npsi` 用 `N` 截断本征值当范数，`memory/nphi-soundness-cost-is-two-cells` 原文：
   「两处**低估都让 ratio 偏小** ⟹ 确实 **fail open**」；
2. `P_β` 的 κ 扫描、`C_R` 的 κ 扫描，**都是穿过同一个 `_chk_grid_coarsen.py` 的 `ratio()` 算出来的**
   （`theta-tilde` memory §「真正最弱的一环在 `ratio()` 肚子里」列出那七个量全是 `N=600` 截断 float64、截断尾无误差界）。

⟹ **那些「κ=∞ 仍 PASS」的判决，是在一个 fail-open 的 `ratio()` 上做出的。**
ratio 偏小 ⟹ PASS 更容易 ⟹ **预算被系统性高估**。

> ⚠ **主会话订正（2026-09-20）——本小节原写「只支持『预算**至少**这么宽』」，方向反了。**
> **旧陈述错在哪**：既然 `computed ratio ≤ true ratio`，则 `{κ : computed PASS} ⊇ {κ : true PASS}` ⟹
> `B_computed ≥ B_true`，扫描给的是预算的**上界**：「预算**至多**这么宽」。
> 原文的结论（「不支持『预算是 ∞』」）**是对的**，但它只能从「至多」推出来——
> 若真如原文所写是「至少这么宽」而扫描给 ∞，那反而**证成**了 ∞。条文与它要支撑的结论自相矛盾。
> **新陈述凭什么对**：同一推理给出一个更有用、且不需要实测的推论——
> **在 fail-open 的基线上，预算扫描的 PASS 行不可信，FAIL 行是声音的**
> （`computed FAIL ⟹ true ratio 更大 ⟹ true FAIL`）。
> 这与 `CLAUDE.md` 现行那句「上界的下估只支持 PASS」**看似相反、实则同源**：
> 单边性支持的永远是「使判据**更难**满足的那一侧结论」，而预算扫描的判据是 `ratio < 1`（小才过），
> 故声音的一侧是 **FAIL**。⟹ 候选条文按这个**一般形式**写，不要写死 PASS/FAIL 两个词——
> 现行措辞会在判据不等号反向时被误用，这已是同一条规则的第二次现身。
> **连带：本订正加固了 §3.1 的主结论。** `k_res` 的翻转 `1→2` 落在 **FAIL 侧 = 声音的一侧**
> ⟹「`k_res` 预算有限且紧、第四起不是 ∞ 型」比原文论证的**更稳**；
> 不稳的是 `(1,2)`、`(1,5)` 那几个 PASS 行，它们支撑的只是「`k_nrm` 翻转点在 5–10 之间」这个较弱的说法。

⟹ **预算表必须随「它建立在哪些声音性假设上」一起交付**；
链条声音化之后，凡是据旧预算取消过的活，要重扫一次。

### 3.3 裁决

> **保留，但大改措辞；不降级为建议，不删除。**

理由：正面的机制（`min` 兜底 ⟹ 单项紧度不决定通不通）是**结构性**的，三起事故同形，两次正确使用有案可查，
且它已经被编进一个committed 脚本（`_chk_ratio_interval_budget.py` 的 docstring 里就写着方向审计）
⟹ 满足准入标准 A、B、D。它**唯一不满足的是 C（误拦代价未记账）**，而 C 是可以补的。

**五处具体改动**（全部在候选稿里）：

1. **把 ∞ 分支的结论从「不要派活」改为「不要为余量派活」，并挂上三个非余量理由的检查**：
   （i）它是否把一个**未从零复核的继承对象**踢出链条（审计面 —— `C_R` 的真实收益）；
   （ii）它是否把某一步从 `numerical-evidence` 升到 `certificate`/`analytic`（档位）；
   （iii）它买的余量是否**解锁下游另一个量的预算**（`P_β` 的 4.43× vs 1.74×）。
   三条全否，才是「只买余量」。
2. **预算表须随声音性假设交付**，且**按一般形式**审方向：单边性支持的永远是「使判据**更难**满足的那一侧结论」。
   预算扫描的判据是 `ratio < 1`（小才过）⟹ 在 fail-open 基线上**声音的是 FAIL 行**，
   扫描给的是预算的**上界**（「至多这么宽」）⟹ **它绝不支持「预算是 ∞」**，而那正是禁令的全部依据。（§3.2(d)）
3. **拆分必要性与可达性**：它们方向相反，第 4 起不同形。
4. **预算是链条状态的属性，不是量的属性**；链条收紧后旧预算作废（「换了界就要重解」的实例）。
5. **鼓励「重定向」而非「取消」**：把 `R0` 那次（一般尾界 → 只对一行做）写成正面样板。

**代价**（诚实记账）：改完之后这一节从 14 行涨到约 20 行，且增加了一次判断（「三个非余量理由」需要人来判，不是纯机械）。
我认为值得——被它误拦一次的代价（`Θ*` 一直留在承重位置上，而它是全链条里唯一一个「我从未从零复核」的对象）
比多读六行大得多。

- **第二刀**：浮点灾难性抵消是第三类，处方是「换闭式 / 提 dps」，不是「找差的恒等式」。宜作一句提醒挂在新条文末尾，不单列。

去掉这三例之后，剩下的证据是：**3 次大收益 + 1 条 analytic no-go 定理 + 1 例判别力事故**。
这仍然**远超准入标准 B**——而且它有一条**定理**撑底，是全文唯一一条不靠经验归纳的规则。

### 4.2 `0.05` 阈值：按文件自己的规矩审

`CLAUDE.md` 自己要求「目标常数必须随**消费点**一起交付」且「必须**可达**」。用这两把尺子量 `0.05`：

1. **没有消费点。** `0.05` 不在任何不等式里被用掉——它是一个**分诊阈值**，不是链条里的常数。
   按文件自己那句「**收到一个没有消费点的目标常数，先回问，不要开工**」，这个阈值不该以现在的形式进。
2. **它自己的预算是 ∞（意义上：极宽）。** 现有两个数据点相隔两个量级：
   `D→T` 的 `0.0144` vs `H→D` 的 `0.54`（memory：「相消只到 46%，条件数好 **39 倍**」），
   谐波对照行是 `1.000`。**任何落在 `[0.02, 0.4]` 的阈值给出完全相同的判决。**
   ⟹ 按预算优先，这个常数不承重，**不该定死一个数**。
3. **它会误杀。** 精确预解式 `R` 的正项被抵消 **97%**（比值 `0.03 < 0.05`），而 `R` 是仓库最有价值的工具之一；
   `Θ̃` 在 `s→∞` 两阶同时消，比值 →0。
   ⟹ **相消比小本身不是缺陷**；缺陷是「相消**未被追踪** **且** 输入不确定度大于差值」。
4. **★ 草案的条件结构方向反了（最重要的一条）。**
   草案写：「先找差的闭式/恒等式；**找不到**就必须同时报 `|和|/max|项|`」。
   但 `D→T` **有**闭式——AD/McMillan 是初等闭式，`α = α_ω + α_λ` 还**精确可加、无交叉项**
   （`memory/dt-residual-is-spectral-shape`：`Tc = ω_log·F(λ,μ*)` ⟹ `ln Tc` 可加分离）。
   ⟹ **真正的失效案例会从「找到闭式」这个出口直接漏掉。**
   闭式是**诊断相消的工具**，不是**免检的资格**。事实上正是那个闭式**暴露**了 98.6% 的相消。
5. **还要带上 09-20 的订正**：`memory/dt-residual-is-spectral-shape` 明写

### 4.3 裁决

> **进，但拆成两条、换措辞、去掉 `0.05`、把条件结构倒过来。**

**N1（新小节，放在「一个符号在链条里只许有一个意思」之后）——管放缩次序，是增益侧的规则：**

```
### 相减要留在闭式里（先放缩后相减，必然在相消那一阶失效）

- **凡是要对一个含减法的量做放缩：先分别界两项再相减，在两项相消的那一阶上一定丢光。**
  这不是经验，有定理：预解式上界里把 `‖ρ‖=‖r−Ty‖` 用三角不等式放掉，所得界恒 `≥ E²/g`
  且沿 λ₂ 方向取等——**永不优于 Davis–Kahan，收益全在 `‖ρ‖²` 的交叉项里**。[analytic]
- ⟹ **落笔一个含减法的界之前，先写下「这个差有没有闭式/恒等式」。**
  有就把减法留在闭式里；没有就写下**你在哪一阶丢了信息**，并量一次
  「丢掉相消 vs 保留相消」的比值——这个比值就是该处的收益上限，是下一步该不该做的预算。
  三次实测：把 `𝒟` 留到 Schur 之后 **8.61×**；保留秩一预解式的 j=1 负项 **1.2–58×**；
  反射延拓让 `f(0)` 精确抵消，非对角常数 `3 → 1.248`。
- ⚠ **两个相邻但不同的陷阱，别混**：
  ① **相减会离开原函数类**（`𝒫` 对减法不封闭）⟹ 界**失效**，见上一节；
  ② **浮点相减**（`g(ϖ)` 在 `ϖ≲1e-3` 灾难性抵消，`ϖ=1e-8` 差 35%）⟹ **数字错**，换闭式或提 dps。
  本条管的是第三种：界仍然**成立**，只是**松到失去判决力**。
```

**N2（并入「先数自由度」节的末尾）——管判别力，是事故侧的规则：**

```
- **用一个差值当判别量之前，报两个数：`|和|/max|项|`，以及把输入的不确定度
  （舍入区间、约定跨度、拟合带）传播到差上之后，符号还翻不翻。**
  不设固定阈值——阈值没有消费点，且相消比小本身不是缺陷（精确预解式 R 的正项被抵消 97%，
  它恰恰是最有价值的工具）。真正的失效判据是**第二个数**：差值被输入不确定度淹掉。
  （`D→T`：λ 项 −0.4101 + ω_log 项 +0.4160 = +0.0059，领头项的 1.4%，`Δμ*≈0.05` 吸收全部差异；
  对照 `H→D` 只相消 46%，条件数好 39 倍 ⟹ 判别性只保 `H→D`。）
- **有闭式不等于免检。** `D→T` 的闭式存在且精确可加（`α = α_ω + α_λ`，无交叉项）——
  闭式是**诊断**相消的工具，不是免检的资格；正是那个闭式暴露了 98.6% 的相消。
- **相消比是「行属性」不是「步属性」。** 引用一个条件数之前先问「它是**这一行**算出来的吗」。
  （09-19 把 SSCHA 行的 98.6% 挪去给谐波行的 0.0637 结案；谐波行 λ 冻结 ⟹ 单项、`|和|/max|项| = 1.000`、根本没有相消。）
```

**放置理由**：N1 与「`𝒫` 封闭」是姊妹条（一个讲**对核**做加减、一个讲**对界**做加减），相邻能互相划清边界；
N2 与「自由度」同属「这个判据到底在量什么」，而那一节已经有「看看有多少个印出的量在里面**相消**」这句，天然接得上。

````markdown
## 1. 严格性纪律（承重，最高优先）

> **「承重」的判据**：删掉它 / 把它朝判据变难的方向退化之后，**有哪个已宣布的结论会失去其声称的档位**。

> **§1B 估计与检验纪律**（怎么算一个数）：预算与可达 · 换了界就要重解 · 覆盖率 · 自由度 · 符号唯一 · 相减留闭式 · 精度

### 1A.1 标级与重算

- **四级分类，每条结论必须显式标级**，不许把低一级当高一级陈述：
  - `analytic` — 已证（解析），零计算机辅助
  - `rational-exact` — 解析定理 + **有限次精确有理算术求值**（无浮点、无舍入、可人工复核）。**必须同时标明格数与有理数个数**（例：「12 格 / 约 150 个有理数」），否则不算这一档。介于 analytic 与 certificate 之间，**不得简称为 analytic**。
  - `certificate` — 声音的外向舍入区间算术（iv/mpmath）
  - `numerical-evidence` — float64 点算 / 有限网格
- **承重的数值或引用结论：从零独立重算**。不采信 subagent / teammate / reviewer 的「已完成」——他们的确认是证据线索，不是结论。跑门禁、用自己的代码重建承重恒等式、分类每条断言。
  **复核对象是脚本 / 提交物本身，不是它消息里的转述**——两者可以是不同的陈述。
  发现分歧时**先当转述差异去查源文件**，别当它的错误去写判决（把一处转述错误升级成「两处错误抵消」的叙事，代价是一整节重写）。

### 1A.2 订正是一次交付：W1 的失效热区

- **修好一个缺陷后，重新验证「修正」本身**。修正可能引入**新的**假命题；只确认旧错消失远远不够。
- **经验事实：W1 咬得最狠的时刻，不是写新结论时，而是「我在指出某人算错了」时。**
  注意力全在「旧陈述错在哪」，于是**新陈述被免检放行**——它既没标级、没审方向、也没核前提。
  四起同形（同一轮、同一人、全部由对方或我自己数小时后发现）：
  ① 把 peer 的 `√c_GF=1.11712` 判为「第 6 位起错」——实为**另一份证书的合法下端**；
  ② 写「随机扫打不到零测等号面」——等号面是**原子型**（某量恰为 0），实测 228/20000 与 `0.2^B` 相符；
  ③ 「我的表对、对方的表错」——实为**我的**低 1–2%；
  ④ 把 `ω_c` 读成谱截断，据此把最窄 `τ_max` 从 4.07 改报 2.98——`θ` 的宗量根本是松原频率。
- ⟹ **订正是一次交付，走完整交付流程，不许走捷径。** 落笔前对新陈述逐项过：
  1. **标级**了吗？（订正常常只说「对方错了」，不说自己这条是哪一档）
  2. **方向**审了吗？（订正一个方向缺陷之后，必须**重算**受它影响的每一列——见「换了界就要重解」）
  3. **前提**核了吗？尤其：**重算之前先确认那个符号/截断到底作用在哪个变量上**，
     不要从名字推语义（「cut-off」不算证据，`M2` 的积分区间只能由 α²F 自己的定义式决定）。
  4. 我用的是**对方的证据**还是**我自己从零重建的**？两个数不一致时，
     先问「它们是同一个证书 / 同一个约定下的量吗」，再问「谁错了」。
- **别人的错被证实，不代表我的替代品是对的——这是两个独立命题，各自要证。**
  推论：宣布一次订正时，把「旧陈述错在哪」与「新陈述凭什么对」**分两段写**；
  只有前一段的订正 = 只完成了一半，且是不承重的那一半。

### 1A.3 单边界方向规则

- **一个上界的下估只支持 PASS 判决，永不支持 FAIL。** 对每处代入/截断，先写清不等号往哪边走，再审下游判决。
  单边行只能产出「过」，出「否」即是 bug。**门禁脚本的判决文本要按单边性分支**（`r is None` ⟹ 输出「UNDECIDABLE（单边下估）」而不是「NO」）。
- **也管离散参数的舍入方向。** 给截断指标 / 网格数 / 窗口号分派「这一侧给上界、那一侧给下界」看着像舍入，
  实际是**换了模型**，且所依赖的单调性常常只在别的参数区间成立。
  检验：(1) 若该参数被定义唯一确定（`N_c=⌊rϖ⌋` 且 `rϖ` 区间不跨整数），**两腿必须用同一个值，根本不要夹**；
  (2) 真跨整数时，**逐个候选算、取显式最劣**，不许假设方向；(3) 任何方向假设都要在**工作点**上验证。
  ⚠ 放缩的松可以长期**掩盖**方向错误（实测 Rayleigh 松 0.517 K > 方向误差 0.427 K，证书照样返回合法数，只剩 0.090 K 余量）。
- **也管容差带朝哪边开。** 相对容差写成乘法 `x*(1±tol)` 在 `x<0` 时**端点互换**，从「允许 `tol*|x|` 的 pad」变成「要求区间比 `2tol*|x|` 还宽」——
  对紧证书结构上不可满足（实测要求宽度 ≥1.377e-14 对上 8e-49 的区间 ⟹ 正常与投毒两种模式下**永久 FAIL、零判别信息**，还训练操作者忽略红灯）。
  **一律写加法式 `x ± tol*abs(x)`。** 一般形式：**乘以一个可以变号的量之前，先问不等号往哪边走。**

### 1A.4 记录丢失时不得反向重建

- **被覆盖 / 丢失的正文，不许从索引 hook 或摘要反向重建。** 重建会生成**看起来很像原文的假条目**，
  之后没人能把它和真内容分开，两边还会各自为这条幻影欠债。
  正确动作只有两个：**标记「此处已丢失」**、**向原会话索取**。宁可留空格，不要填格子。
  （2026-09-18：一条「Morel–Anderson 对数宗量 `W/(2ω_c)`」的幻影条目，让两个会话各挂了半天假账。）

### 1B.1 预算优先（派活前必做——已四次踩中，两种机制）

**(i) 必要性预算——这个量值不值得收紧？**

- **派任何「收紧 / 认证某个量」的活之前，先算预算**：把该量朝**判据变难**的方向退化（乘 `κ≥1`、取 `∞`、或直接从链条里删掉），扫出下游判决**在哪里翻转**。
  方向要审：退化必须使判据变难，这样「κ 处 PASS」才蕴含「任何 ≤κ 的包封 PASS」（单边界方向规则的应用）。
  三起事故同形：`C_R ≤ 1.6`、`C_R ≤ 20`、`P_β` 的 `max_{n≤300}V_β` 区间化——目标常数是拍脑袋定的，判据真正要求的只是「有限」。
  机制（可迁移）：界写成 `min(A,B,C,…)` 时**各项互相兜底 ⟹ 单项紧度几乎从不决定通不通**。
- **预算为 ∞（删掉照样过）⟹ 它不为「通过」承重。但「不要派活」之前，必须先否掉三个非余量理由：**
  1. **审计面**——它是否把一个**我从未从零复核的继承对象**从承重位置上摘掉？
     （`C_R≤6` 的预算是 ∞，但它真正买到的是把 `Θ*`（仓库 M2 pad 族，从未从零复核）**踢出链条**。
     预算扫描固定链条结构求偏导，**看不见链条结构的改变**——这是它的系统性盲区，不是偶发。）
  2. **档位**——它是否把某一步从 `numerical-evidence` 升到 `certificate` / `analytic`？
  3. **下游解锁**——它买的余量是否决定**另一个量**的预算？
     （`P_β` 的 κ=∞ 仍 PASS，但它买的 4.43× vs 1.74× 正是「`ratio()` 能不能区间化」的判定变量。）
  三条全否，才是「只买余量」，才可以不做。
- **★ 预算表本身是单边的，也要审方向。** 单边性支持的永远是「使判据**更难**满足的那一侧结论」——
  而预算扫描的判据是 `ratio < 1`（**小才过**），所以声音的一侧是 **FAIL 行，不是 PASS 行**。
  κ 扫描若穿过一个**已知 fail-open** 的量（如用 `N` 截断本征值当范数，两处低估都让 ratio 偏小），
  则 `B_computed ≥ B_true`：扫描给的是预算的**上界**，只支持「**预算至多这么宽**」，
  **绝不支持「预算是 ∞」**——而后者才是那条禁令的全部依据。
  ⟹ **预算表必须随「它建立在哪些声音性假设上」一起交付**；链条声音化之后，据旧预算取消过的活要重扫。
  ⚠ 别把这条与上面那句「上界的下估只支持 PASS」当成两条规则——**是同一条**，只是判据的不等号反了向。
  落笔前先写「这个判据是大才过还是小才过」，再决定哪一侧声音。
- **预算是量在「当前链条状态」下的属性，不是量的内禀属性。** 上游收紧之后旧预算作废（「换了界就要重解」的实例）。
- **最好的预算产出不是取消任务，是把任务缩小。**（Schur 最大行和的 argmax 在 `n=0`、尾包络只需保住 `Ĝ(n₀)<R0`
  ⟹ 尾包络预算实质是 ∞、承重的是 `R0` 这**单独一行**，解析尾部封闭只需对一行做。）

**(ii) 可达性预算——这个目标常数做得到吗？（方向与 (i) 相反，别混）**

- **目标常数必须随「消费点」一起交付**：写明它在哪一格、哪个不等式里被用掉。
  **收到一个没有消费点的目标常数，先回问，不要开工**——派活方与执行方都有这个义务。
- **目标常数还必须可达**：派活前先在 float64 上实测一次所选估计子的**固有松**，确认它低于目标常数。
  估计子自带的松（Schur/Gershgorin 的检验函数 ≡1、三角放缩的 `E²/g`……）**不是执行方能靠努力压掉的**；
  目标常数定在固有松之下 = 派了一件不可能完成的活，且要等执行方撞墙才发现。
  （2026-09-18：目标常数 `k_res<2×` 定在加权 Schur 的固有松之下 ⟹ **不可达**。）
  ⚠ **固有松要在判据真正消费的那一格 / 最劣格上测，不能在一个点上测**：09-17 单点实测 `1.55×/1.52×` 判「可达」，
  09-18 真造出证书实测是 `1.99–3.24×`，**事前低估 2×**。

**(iii) 换工具优先于收紧**

- **算完预算再问一次「有没有换工具的余地」。** 二维 sup 的区间二分常可被闭式塌成一维：`C_R` 从 (s,σ) 分支定界（反复被灾难性抵消与假象角卡死）换成部分分式后，塌成六个显式留数、`sup` 有闭式、对 s 一致、零数值。
- 推论：**先查已有推导链每一步是否「松早了」，再去造新工具。** 8.61× 的那次收益就写在仓库某一行的末尾（把 `𝒟` 留到 Schur 之后），没用上任何新数学。
- 推论：**别给整条链求闭式；先看哪一段已经是精确的。** 有限窗口若已逐位精确（截断到 N 的矩阵元 = 无穷算子的矩阵元），
  就只放缩尾部；把全程放缩（如 `u_m ≤ 1`）换成分段放缩，常常一步从 100× 回到 2×。

### 1B.2 换了界就要重解，别把新界代进旧的最优解

- **一个量被收紧或被订正之后，凡是「为它解过一次优化」的下游，必须用新值重解。**
  把新界代进旧解只量出「旧解在新界下多差」，量不出「新界要花多少」——而后者才是判决。
  （2026-09-18：`nphi/npsi` 换成声音上界后，固定 κ=1 的格划分不评估 ⟹「3 个承重格全部失去 PASS」；
  用同一个贪心**重解**格划分 ⟹ **1 格 → 3 格、零不可行格**。脚本的全部用途本来就是解格划分。）
- **先分清「数字错」还是「证书松」，两者后果相反。** 判据是**收敛性**，不是与证书的比值：
  截断值若在 N 上已收敛到十几位，它在数值上**就是**真值 ⟹ `numerical-evidence` 层结论完好，
  缺的只是「它是上界」的证明（升不到 `certificate`）；只有没收敛时数字本身才是错的。
  ⟹ 看到「认证界 / 点算值 = 2–3×」先测 N 收敛，别直接判结论垮。
  推论：**声音性缺陷该撤回的是方法句，不是数字**——未提交的订正才是最容易丢的那种。
- 推论：**得出「判决翻转」之前，先把翻转的量换算成它本来的成本单位**（这里是格数，不是比值）。
  比值超标可能只意味着分档变密；单位换错会把「多付两格」报成「路线开放」。

### 1B.3 覆盖率优先于检测率（已五次踩中）

> **投毒负对照只证明 `P(报警 | 输入到达检测器)`，证明不了 `P(输入到达检测器)`。**
> 两者都是 1 才叫「检验有效」，而**出事的几乎总是后者**。

- **「0/N 通过」只证明被测的那一步。** 一个证明由若干箭头串成；
  检验脚本往往只跑其中一段（典型是最后那个松弛后的对象），
  **未被测的那个箭头会被相邻步骤的通过率掩盖**。
  宣布「数值支持该定理」之前，**逐条列出证明用到的箭头，标出每条由哪次抽样覆盖**；
  没有覆盖的箭头写「未测」，不许算进通过率。
- **改了链条上任何一个对象的性质（非负→带号、标量系数→k 的函数、单频→双频），
  必须把链条上每个用到该性质的箭头重走一遍，包括不写在当前这一节里的那些。**
  （同款：「物理上自动」要问「对**哪个对象**自动」——已咬三次。）
- **采样要能触发前提的边界。** 每组只用一个频率、只用一个带号，
  会让「符号与 k 无关」「`|f|` 非增」这类隐含前提**恒真**，于是永远测不到。
  设计抽样时先问：**这次抽样里，有多少比例的样本实际违反我要检验的那条前提的否定？**
- **判据是「我的抽样族对退化集给了多少质量」，不是「退化集在环境空间里是否零测」。**
  退化集分两种，**后果相反，必须先分清是哪一种**：
  - **原子型**（某个量被置为**恰好 0**：`diag(M2^ph)=0`、`λ^ph_ij=0`）——
    只要抽样族带**置零掩码 / 稀疏结构**，它就是**正概率事件**，随机扫**会**打到。
    （2026-09-18：`√c_GF` 上界被 20000 组随机取到 **228 次**，不是运气——
    掩码逐元独立置零 20% ⟹ `P(diag 全零) = 0.2^B`，逐 B 与实测相符，总体 z = −1.33、p = 0.18。）
  - **连续型**（两个连续量相等：`M2^ph = M2^sf`、`λ₂ = λ₁`、`g = 𝔤(2)`）——
    **任何独立连续抽样都打不到，加大样本量无效**，必须朝等号面**定向构造**。
    （2026-09-18：`ρ(|M2^Δ|)` 天花板在 0/800 随机后被 `M2^Δ=0` 一击证伪；定向扫 `M2^sf/M2^ph→1` 是 45/45 违反。）
  ⟹ 设计或审阅抽样时，**先写下「使该命题恰好取等的那组参数」，再问抽样族给不给它正质量**；
  给了就报原子概率（可解析算），没给就老实说「未覆盖」，不要用「随机了 N 组」冒充覆盖。
  独立抽取参数**不等于**覆盖了参数的所有组合：频率独立抽了，退化的却是**耦合的某个组合**。
- **门禁同理：看到 PASS 先问「它扫到了几个文件」。**
  任何门禁必须**打印覆盖面计数**并在计数异常偏低时自己 FAIL；不打印覆盖面的 PASS 是不可证伪的。
  **输入结构变化（目录重组、命名规则变化）之后要重新投毒，投毒样本必须用新结构。**
  （2026-09-19：`check_cited_scripts_tracked.sh` 假 PASS 一整天——非递归 glob + 正则不含 `-`，
  实测覆盖 **1/184 篇笔记、28/434 个引用**，而它在那 6.5% 上的检测率是 100%。09-18 的投毒恰好绕开了两处缺陷。）
- 事故形状（五例同形）：`(ML3)` 的 `Λ̃≥0`；「Z 行和为负」的机制猜测；
  `‖𝒪[Λ̃]‖=‖𝒪[|Λ̃|]‖` 默认符号与 k 无关（物理分解下 205/800 为假）；
  `ratio()` 用 N 截断本征值当范数（下估，方向反）；`|M2^Δ|` 当成矩（随机 0/800，定向 45/45）。

### 1B.4 把一组数字当作「N 个独立检验」之前，先数它的自由度（已两次踩中）

- **判据若对某个自由度**不变**，那个自由度就没被测到**——通过率再高也只是恒等式在自证。
  落笔「本例通过/失效」之前先问：**这个判据的值，是这组数的哪几个组合的函数？**
  写成显式形式（能精确有理算就精确算），看看有多少个印出的量在里面**相消**。
- 两起同形：**填充因子是循环量**（`Tc_AD` 就是 AD 公式 ⟹ `filling_factor_f = F(λ,r)` 闭式、零材料信息）；
  **MgB₂ 的四个 `μ*_ij` 只有三个自由度**（`μ*_ij = c·p_ij/N_i` ⟹ 判据余量 `= p11p22/(p12p21)`，
  拟合标度 `c` 与两个 DOS 全部相消，恒 `= 2.23×2.48`）⟹ 「跑过判据的**拟合**库仑矩阵」这一档从未被关掉。
- 推论：**「四个数」不等于「四个独立量」。** 文献常以「第一性原理比值对 × 一个拟合标度」生成整张表；
  要判断某个检验是否触及拟合内容，得找到**生成式**，不能数印出来几个数。
- **用一个差值当判别量之前，报两个数**：`|和|/max|项|`，以及把输入的不确定度（舍入区间、约定跨度、拟合带）
  传播到差上之后**符号还翻不翻**。**不设固定阈值**——相消比小本身不是缺陷（精确预解式 `R` 的正项被抵消 97%，
  而它恰恰是最有价值的工具）；真正的失效判据是第二个数：差值被输入不确定度淹掉。
  （`D→T`：λ 项 −0.4101 + ω_log 项 +0.4160 = +0.0059，领头项的 1.4%，`Δμ*≈0.05` 吸收全部差异；
  对照 `H→D` 只相消 46%、条件数好 39 倍 ⟹ 判别性只保 `H→D`。）
- **有闭式不等于免检。** `D→T` 的闭式存在且精确可加（`α = α_ω + α_λ`，无交叉项）——
  闭式是**诊断**相消的工具，不是免检的资格；正是那个闭式暴露了 98.6% 的相消。
- **相消比是「行属性」不是「步属性」。** 引用一个条件数之前先问「它是**这一行**算出来的吗」。
  （09-19 把 SSCHA 行的 98.6% 挪去给谐波行的 0.0637 结案；谐波行 λ 冻结 ⟹ 单项、`|和|/max|项|=1.000`、根本没有相消。）

### 1B.5 一个符号在链条里只许有一个意思（尤其是「矩」）

- **`M2` 有两个不等价的读法**：`lim k²f(k)`（函数的尾系数）与 `∫ϖ²P`（**正**表示测度的二阶矩）。
  它们**只在 `f ∈ 𝒫`（正 Einstein 混合）上重合**；引理 M / GF-mix 界的永远是后者。
- **对核做加减会离开 𝒫**：`𝒫` 元素的尾**恰好**是 `k⁻²`，从不更快；两个 𝒫 元素相减可以给出 `k⁻⁴` 尾，
  此时「矩之差」不再是任何非负测度的矩，**不界任何东西**。
  ⟹ **凡是在链条里对核做了加、减、取绝对值的地方，先问一句「结果还在 𝒫 里吗」。**
  （同一事实的两次现身：定理 E 的 `γ>2 ∩ 𝒫 = ∅`；天花板的 `M2^Δ` 证伪。）
- **唯一合法次序**：先在**算子层面**用三角不等式消符号（范数不在乎符号），**再**对两个仍在 𝒫 里的片各自取矩。
  在**矩层面**吸收符号（`M2^Δ`、`|M2^Δ|`、`ρ(|M2^Δ|)`）**注定不可修——不是常数没调好，是对象不存在**。

### 1B.6 相减要留在闭式里（先放缩后相减，必然在相消那一阶失效）

- **凡是要对一个含减法的量做放缩：先分别界两项再相减，在两项相消的那一阶上一定丢光。**
  这不是经验，有定理：预解式上界里把 `‖ρ‖=‖r−Ty‖` 用三角不等式放掉，所得界恒 `≥ E²/g`
  且沿 λ₂ 方向**取等**——**永不优于 Davis–Kahan，收益全在 `‖ρ‖²` 的交叉项里**。[analytic]
- ⟹ **落笔一个含减法的界之前，先写下「这个差有没有闭式 / 恒等式」。**
  有就把减法留在闭式里；没有就写下**你在哪一阶丢了信息**，并量一次「丢掉相消 vs 保留相消」的比值——
  这个比值就是该处的收益上限，即下一步该不该做的预算。
  三次实测：把 `𝒟` 留到 Schur 之后 **8.61×**（`λ₁(𝓡−𝒟)` 的两项在连续极限下两阶同时相消）；
  保留秩一精确预解式的 j=1 负项 **1.2–58×**（抵消正项 1–97%）；
  反射延拓让 `f(0)` 在 Parseval 里精确抵消，非对角常数 **3 → 1.248**。
- ⚠ **两个相邻但不同的陷阱，别混**：
  ① **相减离开原函数类**（`𝒫` 对减法不封闭）⟹ 界**失效**，见 §1B.5；
  ② **浮点相减**（`g(ϖ)` 在 `ϖ≲1e-3` 灾难性抵消，`ϖ=1e-8` 差 35%，`[1e-8,1]` 上单调性判错）⟹ **数字错**，换闭式或提 dps。
  本条管的是第三种：界仍然**成立**，只是**松到失去判决力**。

### 1B.7 精度与区间算术

- **多精度一致只测舍入**，不测离散化 / 尾部精度。承重量用**两套独立方案** / 闭式 / 自伴性 / Richardson-in-M 交叉验证。（教训：行和的胖尾 ~a²ϖ²/((1+a²)m³) 让 `nsum([0,∞])` 给垃圾、`nsum([M,∞])` 欠解析；用闭式恒等式或 Richardson 暴力和。）
- **「用了区间算术」≠「每一步都外包」。** bound-producing path 上只许 `+ − × ÷ √` 与整数幂；
  每一个 `mp.<fn>`（而非 `mp.iv.<fn>`）作用在区间上都是**候选缺陷**，且不报错、不加宽。
  **打印实测宽度并与设定精度的预测对照**——永远不要从设置推断精度。
  已知实例（完整九条与实测命中率在 memory `mpmath-iv-atan2-not-outward-rounded`）：
  `iv.atan2` 不外包；一个 pad 必须覆盖它所替身的那份误差；`mp.pi` 惰性（需 `+mp.pi`）；
  `import mpmath as mp` 后 `mp.dps=50` 是**静默 no-op**（全程 53 位）；
  `mp.sqrt` 作用于区间返回点 `mpf`（232/800 不外包）；
  **`float(iv.b)` 就近舍入 ⟹ 任何单边消费的 区间→float64 交接都是洞**（1988/1997 向下动，上界被低估 ⟹ fail-open）。
````
