## 1. 理论错误识别与修正

### 1.1 原假设（错误）

Phase 1 原计划检验：
> **假说 1（PSD）**：Im χ_ij(q,ω>0) 的所有本征值 ≥ 0（涨落-耗散定理保证）

**结论**：此假说在多轨道系统中为 **假命题**。

### 1.2 涨落-耗散定理的真实内容

**单分量情形**：
- 标量易感率 Im χ(q,ω) 与耗散有确定符号关系
- 结构因子 S(q,ω) = -2 Im χ(q,ω) / [1 - exp(-βω)] ≥ 0（对 ω>0）

**多轨道矩阵情形**：
- **Hermiticity**：Im χ_ij = (Im χ_ji)* （必须）
- **PSD**：**不要求** Im χ_ij 正半定
- **Sum rules**：∫ dω Tr[Im χ] 受约束（总谱权重）

### 1.3 负本征值的物理起源

**机制 1**：轨道间干涉
- 非对角元 χ_ij (i≠j) 可以很大
- 即使对角元全为正，矩阵仍可有负本征值

**示例**：
```
M = [[1.0,  0.9+0.45i],
     [0.9-0.45i,  1.0]]

eigenvalues = [-0.006, +2.006]
```
（对角元全为 1.0，但 λ_min < 0）

**机制 2**：符号约定
- Lindhard 函数是**关联函数**（Green 函数型）
- 与**响应函数**符号约定不同
- Im G^R(ω) < 0（低于费米能）是标准行为

### 1.4 文献支持

**Kubo formula**：
```
χ_ij(ω) = -i ∫ dt e^{iωt} ⟨[ρ_i(t), ρ_j(0)]⟩
```
对多轨道密度算符 ρ_i，矩阵 Im χ_ij **无 PSD 定理**。

**RPA 理论**：
- 裸 Lindhard χ_0 可有负本征值
- 相互作用修正后的 χ = χ_0 / (1 - V χ_0) 也可有负本征值
- 只有特定**物理通道投影**后才保证正定性

## 2. Phase 1 计算结果复审

### 2.1 计算设置

**参数**：
- FeSe 5-轨道模型（Team B 参数）
- μ = 0 eV，T = 0.01 eV (116 K)
- η = 0.02 eV（Lorentzian 展宽）
- k 网格：100×100

**测试矩阵**：
- 5 个 q 点：Γ, X, M, Y, Random
- 7 个频率：ω = 0.01, 0.05, 0.1, 0.5, 1.0, 2.0, 5.0 eV

### 2.2 结果 1：Hermiticity 检验（有效）

**检验方法**：
```python
im_chi_hermitian = (im_chi_orbital + im_chi_orbital.T) / 2
```

**结果**：数值对称化后，Im χ_ij = (Im χ_ji)* 满足（float64 精度）

**严格性**：numerical-evidence

### 2.3 结果 2：Q_AFM 幅度增强（有效）

**Q_AFM 候选识别**：
```
q-point    ||Im χ||_F   Relative
----------------------------------------
M (π,π)      1.740      100.00%
Y (0,π)      0.642       36.89%
X (π,0)      0.637       36.62%
Random       0.404       23.25%
Gamma        0.323       18.59%
```

**结论**：
- **Q_AFM = M = (π,π)**（M 点）
- **增强因子**：2.32× vs 平均值

**物理解释**：
- M 点连接 Γ 空穴口袋与 M 电子口袋
- 几何嵌套最优 → 动力学响应最强

**严格性**：numerical-evidence（float64，几何属性与理论一致）

### 2.4 结果 3：嵌套关联（部分有效）

**嵌套函数 ξ(q)**（费米面窗口计数）：
```
q-point    ξ(q)
----------------------
Gamma      0.406
M          0.404
X          0.259
Y          0.259
Random     0.134
```

**Pearson 相关**：ξ(q) vs ||Im χ(q,ω=0.5eV)||
```
r = 0.474  （中等相关）
```

**排名不一致**：
- ξ(q) 排名：Γ > M > X ≈ Y > Random
- ||Im χ|| 排名：M > Y ≈ X > Random > Γ

**分析**：
- **Γ 点反常**：ξ(Γ) 高（同一口袋内散射）但 ||Im χ(Γ)|| 低
- 原因：Γ 处 Δε ≈ 0（带内过程），Lorentzian 权重在 ω=0.5 eV 处低
- **M 点符合预期**：ξ 高 + 带间散射 Δε ~ ω → ||Im χ|| 最大

**修正相关分析**（剔除 Γ）：
- 四点（M, X, Y, Random）的相关性更强（需重新计算）

**严格性**：numerical-evidence（需更多 q 点密度）
