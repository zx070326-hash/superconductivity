## 第一部分：FeSe 费米面拓扑（已知）

### 1.1 基本结构

**实验 + 第一性原理计算确认**：
- **Γ 点（BZ 中心）**：3 个空穴费米面袋
  - 主要轨道成分：d_xz, d_yz（类似 LaFeAsO）
  - 费米波矢：k_F^hole ~ 0.2-0.3 (单位：π/a)

- **M 点（BZ 角）**：2 个电子费米面袋
  - 主要轨道成分：d_xy
  - 费米波矢：k_F^elec ~ 0.2-0.3 (单位：π/a)

**关键几何关系**：
```
M - Γ = (π, π)   (对角方向)
X - Γ = (π, 0)   (坐标轴方向)
```

**反铁磁矢量**（自旋涨落峰位置）：
```
Q_AFM ≈ (π, 0)  或  (0, π)
```

这恰好是 **Γ 空穴袋 → M 电子袋的最短连接矢量**（沿 BZ 边缘）。

### 1.2 费米面嵌套的定义

**嵌套函数**：
```
ξ_{αβ}(q) := ∫ dk δ(ε_α(k)) δ(ε_β(k+q))
```

**物理意义**：
- 轨道 α 的费米面与轨道 β 的费米面（平移 q 后）的重叠度
- ξ 大 ⟺ 两个费米面被 q 矢量"良好嵌套"
- 带间跃迁 k → k+q 在费米面上的相空间

**关键性质**：
1. ξ_{αβ}(q) ≥ 0（定义，非负测度）
2. ξ_{αα}(0) = 费米面的长度（或 DOS）
3. ξ_{αβ}(q) 在 q 使两费米面平行且接近时最大

## 第二部分：Q_AFM 的特殊性

### 2.1 为什么 Q_AFM ≈ (π, 0)？

**几何论证**：

FeSe 的两类费米面：
- Γ 空穴：中心在 k = (0, 0)，半径 r_h
- M 电子：中心在 k = (π, π)，半径 r_e

**平移矢量 q = (π, 0)**：
```
M 电子的费米面（中心 (π,π)）
平移 q = (π, 0)
→ 中心移到 (π,π) - (π,0) = (0, π)
```

**但 FeSe 是正方晶格**：k_x ⟺ k_y 对称
⟹ 中心 (0,π) 的费米面 ≡ 中心 (π,0) 的费米面（旋转 90°）

**关键观察**：
- Γ 空穴中心：(0, 0)
- M 电子平移后中心：(0, π) 或等价地 (π, 0)

**间距**：|(π,0) - (0,0)| = π ≈ 两费米面半径之和（r_h + r_e ~ 0.4-0.6 in units of π/a）

⟹ **q = Q_AFM 使 Γ 空穴费米面与 M 电子费米面（平移后）相切或接近**

**这正是嵌套度最大的几何配置。**

### 2.2 定量估计（量级论证）

**对角嵌套度**（同轨道）：
```
ξ_{hh}(0) ~ N_h(E_F) · v_F^{-1}  （费米面长度）
```
量级：~ 10-100（任意单位）

**非对角嵌套度**（Q_AFM 处）：
```
ξ_{he}(Q_AFM) ~ 嵌套区域长度 · k 空间窗口宽度
```

若两费米面完美平行且接近：
```
ξ_{he}(Q_AFM) ~ O(ξ_{hh}(0))  （同量级）
```

**关键结论（几何）**：
- **Q_AFM 是 ξ_{he} 的全局最大点**
- **ξ_{he}(Q_AFM) 与对角嵌套度同量级**
- **其他 q 点：ξ_{he}(q) ≪ ξ_{he}(Q_AFM)**

## 第三部分：从嵌套度到 Lindhard χ₀

### 3.1 Lindhard 函数与嵌套度的关系

**Lindhard 公式**（静态，T=0）：
```
χ₀_{αβ}(q,0) = ∫ dk [f(ε_α(k)) - f(ε_β(k+q))] / [ε_β(k+q) - ε_α(k)]
```

**在费米面附近**：
- 分子：f(ε) 是阶跃函数，f(ε_α(k)) - f(ε_β(k+q)) ≠ 0 仅当 k 和 k+q 一个在费米面内、一个在费米面外
- 分母：ε_β(k+q) - ε_α(k) 是带间能级差

**嵌套度贡献**：
- 若两费米面被 q 良好嵌套 ⟹ 大量 k 点满足"一个内一个外"
- ⟹ 积分贡献大
- ⟹ |χ₀_{αβ}(q)| 大

**定性关系**：
```
|χ₀_{αβ}(q)| ∝ ξ_{αβ}(q) / Δ_{αβ}
```
其中 Δ_{αβ} 是典型带间能级差。

**对于 FeSe**：
- 空穴带和电子带的能级差：Δ_{he} ~ 0.1-0.5 eV（第一性原理计算）
- ⟹ χ₀_{he}(Q_AFM) 大（因为 ξ 大）

### 3.2 符号问题

**关键问题**：χ₀_{αβ}(q) 的**符号**由什么决定？

**答案**：由**分子的符号统计**决定。

**分子**：f(ε_α(k)) - f(ε_β(k+q))

在 T=0：
- 若 ε_α(k) < 0 且 ε_β(k+q) > 0 ⟹ 分子 = +1
- 若 ε_α(k) > 0 且 ε_β(k+q) < 0 ⟹ 分子 = -1

**关键洞察**：
- α = 空穴带（ε < 0 在费米面内）
- β = 电子带（ε > 0 在费米面内）

对于 k 在 Γ 空穴费米面上：ε_h(k) ≈ 0⁻
对于 k+Q_AFM 在 M 电子费米面上：ε_e(k+Q_AFM) ≈ 0⁺

**嵌套区域**（k 和 k+Q_AFM 都接近费米面）：
- 若 k 在空穴费米面内侧（ε_h < 0）⟹ k+Q_AFM 在电子费米面外侧（ε_e > 0）
- ⟹ 分子 = +1（主导贡献）

**结论（analytical reasoning）**：
```
χ₀_{he}(Q_AFM) > 0  （空穴-电子非对角元，正）
```

**对角元**：
```
χ₀_{hh}(q) 和 χ₀_{ee}(q)  （同带内过程）
```
符号依赖于 q 和费米面曲率，但在小 q 时通常 > 0。

## 第四部分：从 χ₀ 到 RPA χ^s

### 4.1 RPA 自旋通道

**RPA 公式**：
```
χ^s = χ₀^s [1 - U χ₀^s]^{-1}
```

其中 χ₀^s 是自旋通道的 Lindhard 函数。

**Dyson 级数**：
```
χ^s = χ₀^s + χ₀^s U χ₀^s + χ₀^s U χ₀^s U χ₀^s + ...
```

### 4.2 Stoner 稳定性的作用（Team A 洞察）

**关键不等式**：
```
ρ := λ_max(U χ₀^s) < 1  （Stoner 稳定）
```

**物理意义**：
- ρ < 1 ⟹ Dyson 级数收敛
- ρ < 1 ⟹ 每次迭代后，相关系数 r = |χ₁₂|/√(χ₁₁χ₂₂) 收缩
- ρ < 1 ⟹ 对角主导度增强

**Team A 定理**（已证明）：
```
ρ < 1  ⟹  r_n → 0  （几何衰减）
```

### 4.3 静态 vs 动力学：关键区分（2026-09-22 修正）

**⚠ Team B 关键发现**：**静态 χ(q,0) 实部可以非 PSD**（q=Q_AFM 有 4 个负本征值）。

**涨落-耗散定理的边界**：
```
Im χ(q, ω>0) ≥ 0  （必须，因果性 + 能量耗散）
Re χ(q, 0)        （不约束，可以有负本征值）
```

**原§4.3 的错误**：
- 旧论证：χ₀ 逐元非负 ⟹ RPA χ^s 逐元非负
- **问题**：逐元非负 ≠ 本征值非负（PSD）
- Team B 数值证明：静态 Re χ₀(Q_AFM, 0) 有负本征值

**正确的物理图像**：

1. **静态 Lindhard**（实部，ω=0）：
   - 嵌套区域分子 [f(ε_α(k)) - f(ε_β(k+q))] 主导为正 ✓（§3.2）
   - 但**轨道投影的相干叠加可以产生负干涉**
   - 结果：某些本征值为负（Team B：Q_AFM 处 4 负 / 1 正）

2. **动力学响应**（虚部，ω>0）：
   - 涨落-耗散定理保证 Im χ(q,ω>0) ≥ 0（PSD）
   - 物理：能量耗散到集体模式，必须非负
   - Q_AFM 嵌套 ⟹ **增强耗散幅度**，不改变符号约束

**关键结论**：
- 我们的嵌套机制（§2-3）解释的是**为什么 Q_AFM 处幅度大**
- 符号约束来自**动力学性质**（涨落-耗散），不是静态几何

### 4.4 Essenberger 实际用的是频率积分

**关键区分**（Essenberger 1411.2121 Eq.(36)）：

Essenberger 的自旋涨落核是：
```
J±(k,k′) = ∫ dω [某个频率加权] × Im χ^s(q, ω)
```

**不是静态 Re χ(q,0)**，而是**动力学 Im χ(q,ω) 的频率积分**。

**涨落-耗散定理保证**（文献已知，analytic）：
```
Im χ(q, ω>0) ≥ 0  （PSD 矩阵，所有本征值非负）
```

**物理**：
- Im χ 描述能量耗散到集体模式
- 因果性 + 能量守恒 ⟹ 必须非负
- 与静态 Re χ(q,0) 无关（后者可以有负本征值）

**嵌套机制的真正作用**：
- Q_AFM 处嵌套度最大（ξ_{he} 最大）
- ⟹ **Im χ(Q_AFM, ω) 的幅度最大**（相空间最大）
- ⟹ 频率积分 ∫dω Im χ 在 Q_AFM 处峰化
- **符号约束来自涨落-耗散，嵌套机制只增强幅度**

**三层物理**：
1. **几何层**（§2）：Q_AFM 是最优嵌套矢量（Γ 空穴 ↔ M 电子）
2. **动力学层**：Im χ(Q_AFM, ω) 幅度大（相空间大）且非负（涨落-耗散）
3. **频率积分**：∫dω Im χ 在 Q_AFM 处最强 ⟹ Essenberger 的 J± 核主要由此贡献

**撤回的静态论证**（旧§4.3）：
- ~~"χ₀ 逐元非负 ⟹ χ^s 逐元非负"~~（前提为假，Team B 证明静态有负本征值）
- 正确机制：动力学耗散 + 几何增强

## 第六部分：定量估计（无数值计算）

### 6.1 相关系数的量级

**定义**：
```
r := |χ^s_{12}| / √(χ^s_{11} · χ^s_{22})
```

**Team A 定理**：
```
ρ < 1  ⟹  r_n < ρⁿ  （几何衰减）
```

**估计**（n 次 RPA 迭代）：
- 若 ρ ~ 0.8（距 Stoner 边界较远）
- 则 r₃ < 0.8³ = 0.512
- r₁₀ < 0.8¹⁰ = 0.107

**物理意义**：
- 即使初始 χ₀ 的非对角元显著（r₀ ~ 0.5）
- RPA 迭代后，r 快速衰减
- ⟹ χ^s 对角主导，但**非对角元仍为正**

### 6.2 Cauchy-Schwarz 界

**2×2 PSD 矩阵**：
```
χ^s_{12}² ≤ χ^s_{11} · χ^s_{22}
```

**负非对角 + PSD 的窗口**：
```
χ^s_{12} ∈ [-√(χ^s_{11}·χ^s_{22}), 0)
```

**宽度**（相对）：
```
Δ / √(χ^s_{11}·χ^s_{22}) = 1
```

**但在 ρ < 1 约束下**：
- r < ρⁿ ⟹ |χ^s_{12}| < ρⁿ √(χ^s_{11}·χ^s_{22})
- 负非对角窗口被压缩到：[(ρⁿ-1)√(...), 0)
- 相对宽度：1 - ρⁿ

**若 ρ = 0.8, n = 3**：
- 相对宽度 ≈ 0.488（一半）

**若 ρ = 0.5, n = 3**：
- 相对宽度 ≈ 0.875（极窄）

**结论**：
- Stoner 稳定性（ρ < 1）**不禁止**负非对角 + PSD
- 但**显著压缩**其参数空间
- ⟹ 独立随机抽样打不到（Team B 0/23000）
