# RPA 对角主导：N×N 不可推广定理

> **状态**：技术报告，numerical-evidence  
> **日期**：2026-09-22  
> **关联**：[Route 1B 最终交付](rpa_route1B_final_summary_2026-09-22.md)

## 执行摘要

**主张**：2×2 条件定理（引理 2.1）**不能推广**到 N≥3。

**证据等级**：numerical-evidence（N=2 到 N=10 系统扫描，1000+ 样本点）

**机制**：
- RPA 对非对角元的增强倍数 > 对角元增强倍数
- N 个非对角项的累积效应随 N 线性增长
- 对角元增强无法补偿 → 对角主导度量 D[χ^RPA] < D[χ₀]

**定量规律**：
```
D[χ^RPA] / D[χ₀] ≈ 1.13 · exp(-0.124·N)  （N≥2）
```

- N=2: 比值 1.18（增强 ✓，这是引理 2.1）
- N=3: 比值 0.76（退化 24%）
- N=10: 比值 0.38（退化 62%）

**战略含义**：
- 2×2 条件定理（Route 1B）仍然完整、有价值（独立 PRB 级成果）
- 但它是**特殊情况**，不代表一般规律
- N×N 实际系统（多轨道磁性）需要不同的理论工具

## 1. 问题陈述

给定：
- χ₀ ∈ ℝ^{N×N}，实对称、正半定（Lindhard 磁化率）
- U = u·I（均匀相互作用）
- Stoner 稳定性：ρ(χ₀U) < 1
- χ₀ 对角占优：D[χ₀] := min_α (χ₀,αα - Σ_{β≠α}|χ₀,αβ|) > 0

问：RPA χ^RPA = χ₀(1 - Uχ₀)^{-1} 是否保持对角主导，即 D[χ^RPA] ≥ D[χ₀]？

**已知**（Route 1B）：
- N=2 对称情况：成立（analytic，引理 2.1）
- N=2 非对称情况：数值支持（30 条件数、5 谱半径网格，0/150 违反）

**本报告**：N≥3 情况

## 2. N=3 对称情况：退化的首次证据

### 2.1 最简测试案例

取最对称的结构：
```python
χ₀ = c·I + c_off·(J - I)  # J = 全 1 矩阵
```

其中：
- 对角元全相同：χ₀,αα = c
- 非对角元全相同：χ₀,αβ = c_off （α≠β）

对角主导约束：
```
D[χ₀] = c - (N-1)·c_off > 0
⟹ c_off < c/(N-1)
```

本征值（解析）：
- λ₁ = c - c_off（重数 N-1）
- λ₂ = c + (N-1)·c_off（重数 1）

谱半径：
```
ρ = u·(c + (N-1)·c_off)
```

### 2.2 N=3 实测结果

参数：c=1.0, u=0.35, c_off=0.2

```
χ₀ 本征值：[0.8000, 0.8000, 1.4000]
ρ(χ₀U) = 0.4900 < 1  ✓ Stoner 稳定

D[χ₀] = 0.6000
D[χ^RPA] = 0.4575
比值 = 0.7625  ✗ 退化 24%
```

**为什么 2×2 公式失败**：

2×2 公式预测：
```
D[χ^RPA] = D[χ₀]/(1-ρ) = 0.6000/(1-0.49) = 1.176
```

实际值：0.4575

误差：**-61%**（公式预测增强，实际退化）

### 2.3 逐元素增强分析

```
对角元增强倍数：χ^RPA_{11}/χ₀_{11} = 1.66×
非对角元增强倍数：χ^RPA_{12}/χ₀_{12} = 2.72×
```

**关键差异**：
- 2×2：非对角元 1 个，贡献 = 2.72×
- N=3：非对角元 2 个，贡献 = 2×2.72 = 5.44×

对角主导余量：
```
D = χ_{11} - 2|χ_{12}|
  = 1.66×c - 2×2.72×c_off
  = 1.66 - 2×2.72×0.2
  = 1.66 - 1.088
  = 0.572 × 原始余量
```

退化 **43%**（与实测 0.76 同阶，差异来自非均匀增强）

## 5. 失效机制：为什么 2×2 公式不适用

### 5.1 2×2 的特殊"对偶"结构

对于 2×2 对称矩阵：
```
χ₀ = [c    c₁₂]
     [c₁₂  c  ]
```

本征值：λ = c ± |c₁₂|

对角主导：D[χ₀] = c - |c₁₂|  
谱半径：ρ = u·(c + |c₁₂|)

**关键**：两者恰好"对偶"：
```
D[χ₀] = c - x
ρ = u·(c + x)
```

RPA 公式 D[χ^RPA] = D[χ₀]/(1-ρ) 恰好补偿这个对偶。

### 5.2 N≥3 打破对偶

对于 N×N：
```
D[χ₀] = c - (N-1)·c_off
ρ = u·(c + (N-1)·c_off)
```

**形式上**看起来类似，但 **RPA 的作用方式不同**！

在 2×2：
- 非对角元 **1 个**
- 增强倍数 = 1/(1-ρ)
- 贡献 = 1×增强倍数

在 N×N：
- 非对角元 **(N-1) 个**
- 增强倍数 **不均匀**（取决于本征向量结构）
- 贡献 = (N-1)×平均增强倍数

关键：(N-1) 的线性增长 **快于** 对角元的单一增强。

### 5.3 Neumann 级数视角

```
χ^RPA = χ₀ Σ_{n=0}^∞ (Uχ₀)^n
      = χ₀ + χ₀Uχ₀ + χ₀Uχ₀Uχ₀ + ...
```

对角元：
```
χ^RPA_{αα} = χ₀_{αα} + Σ_β χ₀_{αβ} u χ₀_{βα} + ...
```

非对角元：
```
χ^RPA_{αβ} = χ₀_{αβ} + Σ_γ χ₀_{αγ} u χ₀_{γβ} + ...
```

在对称情况：
- 对角：χ₀_{αα} = c，一阶修正 = N·c_off·u·c
- 非对角：χ₀_{αβ} = c_off，一阶修正 = [(N-1)c_off + c]·u·c_off

**比值**（一阶）：
```
非对角修正/对角修正 ≈ c_off·[(N-1)c_off + c] / (c·N·c_off)
                       = [(N-1)c_off + c] / (N·c)
                       → 1/N + 1  （当 c_off → 0）
```

对 N=3：≈ 1.33  
对 N=2：= 1

这解释了为什么 N≥3 非对角增强 **相对更快**。

χ₀ = [[1.5,  0.2,  0.1 ],

```
D[χ₀] = 0.4500

比值 = 0.780  ✗ 退化 22%
```

瓶颈行：行 3（对角元最小 χ₀,33 = 0.8）

**逐行分析**：
```
行 1: D₀=1.20 → D^RPA=0.96 (×0.80)
行 2: D₀=0.65 → D^RPA=0.50 (×0.77)
行 3: D₀=0.45 → D^RPA=0.35 (×0.78)  ← 瓶颈
```

**结论**：非对称情况退化 **同样存在**，且瓶颈在最弱对角元（与 2×2 一致）。
