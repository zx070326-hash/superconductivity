## 1. 主定理（analytic）

四因子轨道基投影写成

```
χ₀(q,ω) = Σ_{m,n} c_mn · (A_m ∘ B_n),
    A_m = conj(U_k[:,m]) · conj(U_k[:,m])^†      （秩一半正定）
    B_n = U_{k+q}[:,n] · U_{k+q}[:,n]^†          （秩一半正定）
    ∘   = Hadamard（逐元）积
    c_mn = (f_m − f_n) / (ε_m − ε_{n} + ω + iη)
```

**第一步（Schur）**：`A_m`、`B_n` 皆秩一半正定 ⟹ 由 **Schur 乘积定理**，`A_m ∘ B_n` 半正定。
数值复核：2000 组随机秩一 Hadamard 积，最小本征值 `−5.213e−14`（舍入）。

**第二步（费米单调性）**，**仅静态 ω=0**：
`Re c_mn = (f_m − f_n)·Δ / (Δ² + η²)`，`Δ := ε_m − ε_n`。
费米函数严格单调减 ⟹ `(f_m − f_n)` 与 `Δ` **恒反号** ⟹ `Re c_mn ≤ 0`。
数值复核：20 万组随机 `(μ, T, ε₁, ε₂)`，`(f_m−f_n)(ε_m−ε_n)` 的**最大值恰为 `0.000e+00`**
——是符号定理，不是「数值上很小」。

**第三步**：χ₀ 的 Hermitian 部分**恰好**是 `Σ Re(c_mn)(A_m ∘ B_n)`（`i·Im(c)` 那部分反 Hermitian）。
非正系数 × 半正定矩阵之和 ⟹

> **静态 `Herm χ₀(q,0)` 负半定，在每个 q、每个材料、任意轨道数上。** ∎

数值复核（完全随机 5 轨道紧束缚，**无 Graser 参数**）：4 个随机模型 × 4 个 q，
正确符号下 **16/16 全是 5 neg / 5**（满秩负定）。

**⟹ 「χ₀ 在 256/256 个 q 点非 PSD」这句话的自由度是 0。它测的是 Schur 乘积定理，不是 BaFe₂As₂。**

## 2. 两条推论：RPA 那一层也是恒等式

**(C2)（analytic，前提 `U` 半正定）**：χ₀ 负定 ⟹ `χ₀⁻¹` 负定 ⟹
`x^†(χ₀⁻¹ − U)x = x^†χ₀⁻¹x − x^†Ux < 0` ⟹ `χ₀⁻¹ − U` 负定 ⟹
`χ^s = χ₀(1−Uχ₀)⁻¹ = (χ₀⁻¹ − U)⁻¹` **负定**。
⟹ `n_neg(χ^s) = n_neg(χ₀) = N`，在每个 q、每个 `U`。
**⟹ 「RPA 改善 0 / 恶化 0，共 256 点」也是恒等式。**
数值：4000 组随机 (N=2..6)，χ^s 最大本征值 `−8.092e−04`，**0/4000 反例**。

**负对照（前提承重性）**：`U` 换成不定对称矩阵，χ^s 出现正本征值 **3225/4000**
⟹ 「`U` 半正定」是承重前提，不是装饰。
`U` 半正定对 Hubbard–Kanamori 形式 `U_αα=U, U_αβ=J` 是 analytic：
`M = (U−J)I + J·𝟙𝟙^T`，本征值 `U−J`（重数 N−1）与 `U+(N−1)J`，`0≤J≤U` 时皆 ≥0。

**(C3)（analytic）**：`eig(Uχ₀) = eig(U^{1/2}χ₀U^{1/2})`（相似），后者半负定 ⟹
`eig(1 − Uχ₀) ≥ 1` ⟹ **RPA 分母永不为零**。
数值：4000 组、`U` 拉到极大，`min Re eig(1−Uχ₀)` 恒为 **`1.000000`**。

> **⟹ Stoner 不稳定在这套符号约定下不可达，任意相互作用强度。**

这条是诊断性的：物理上 Stoner 不稳定**必须**可达。所以约定本身与物理相反。

## 3. 第二个 bug：退化分支与通项分支各在一套相反约定里

代码的 `q=0, m=n` 分支写作 `+f(1−f)/T`。但

```
lim_{n→m} (f_m − f_n)/(ε_m − ε_n) = ∂f/∂ε = −f(1−f)/T     （负）
```

数值（五个 ε 点，中心差分 h=1e−7）：`∂f/∂ε` 与 `−f(1−f)/T` **逐位相符**，与 `+f(1−f)/T` **恰好反号**。

⟹ 退化分支相对通项分支符号错。它**只在 q=0 触发**（唯一有 `ε_k[m]=ε_{k+q}[n]` 精确退化的点），
这解释了为什么报数里 q=0 是唯一的异常点。
随机模型复核：repo 分支在 q=0 给 4 neg / 5（正确符号给 5 neg / 5），**4/4 模型**；
q≠0 两支完全一致（无退化，分支不触发）。

**订正方向（重要，容易改反）**：物理静态 `χ₀(q→0,0) = N(E_F) > 0`（Pauli 顺磁）。
所以**退化分支的正号才是物理号**，错的是通项分支。
⟹ 正确修法是 **negate 通项分支**（整体 `χ₀ = −Σ...`），**不要**去改退化分支。
改完后 q=0 与 q≠0 自洽，且 (C3) 的障碍解除、Stoner 可达。

## 4. 还剩什么：动态通道保有自由度（numerical-evidence）

§1 第二步**只对 ω=0 成立**。ω≠0 时分母是 `ε_m − ε_n + ω`，与 `(f_m − f_n)` 不再恒反号。实测：

| ω | `Re c_mn > 0` 的比例（/200000） | Herm(χ₀) 最大本征值（300 随机模型取 max） |
|---|---|---|
| 0.00 | **0** | −1.5593e−02 |
| 0.05 | 939 | +1.0856e+01 |
| 0.20 | 3578 | +2.8187e+01 |
| 1.00 | 18861 | +1.1468e+01 |

⟹ **ω>0 时本笔记的全部定理失效，那里的符号结构是真信息。**
与此前的预算结论一致：Essenberger Eq.(36) 断的是 `∫dω Im χ^s(q,ω)`，
Eq.(37) 要的是 `Im Λ^SF_{kk'} > 0` 的**逐元**正性；
FDT 只保证 Hermitian 部分非负，**逐元正严格更强、FDT 覆盖不到**。那个缺口是真的。
