**主要发现**：

1. **Stoner 边界洞察**（重大科学发现）：RPA 对角主导保持 ⟺ Stoner 稳定性（ρ<1）。这不是技术限制，而是定理的**自然物理边界**。

2. **2×2 反例**：即使 ρ<1，对角主导度量可以**退化**（D[χ^RPA] < D[χ₀]），当 χ₀ 对角元差异大时。

4. **战略重评**：对角主导 ≠ 逐元正。即使我们能证明对角主导保持，也**不蕴含** Essenberger Eq.(37) 的非对角元逐元正。

## 技术进展

### 已证明（analytic）

1. **Stoner 边界识别**：ρ(χ₀U) < 1 ⟺ RPA 收敛 ⟺ 铁磁稳定性
2. **Neumann 级数框架**：χ^RPA = Σ_{n=0}^∞ (χ₀U)^n χ₀（在 ρ<1 下收敛）
3. **2×2 PSD 条件**：χ₁₂² ≤ χ₁₁·χ₂₂（Cauchy-Schwarz）

### 未完成（技术障碍）

**引理 A**（核心缺口）：证明 r[(χ₀U)χ] ≤ ρ·r[χ] 对任意 χ ⪰ 0

**障碍诊断**：
- Cauchy-Schwarz 只给分子界：|(χ₀Uχ)_{ij}| ≤ √[...] · √[...]
- 分母 (χ₀Uχ)_{ii} 也变了，不能直接和原来的 χ_{ii} 比
- 需要同时控制分子和分母的变化，但相关系数的非线性使得标准工具失效

**尝试的 5 条路径**（全部遇到技术墙）：
1. 矩阵元比值直接界 → Gram 结构不够强
2. Schur 乘积视角 → 不是 Hadamard 乘积
3. 算子单调函数 → 相关系数不是迹形式
4. 静态极限特殊化 → 仍然复杂
5. 加权内积空间算子范数 → 换基后相关系数定义不清楚

### 2×2 反例（numerical-evidence）

**参数**：
```
χ₀ = [[1.5, 0.2], [0.2, 0.8]]
U = diag(0.4, 0.4)
ρ = 0.621 < 1 ✓ Stoner 稳定
```

**结果**：
```
D[χ₀] = 0.600
D[χ^RPA] = 0.512  （下降 14.7%）
```

**机制**：对角元 1.5 vs 0.8 差异大 → RPA 增强不对称（强轨道更强、弱轨道增强有限）→ 瓶颈在弱行 → 全局 D 下降。

## 战略重评

### 原目标 vs 实际需求的差距

| 项目 | 对角主导保持 | Essenberger 需要 |
|---|---|---|
| 定义 | D[χ] := min_α (χ_{αα} - Σ_{β≠α}\|χ_{αβ}\|) > 0 | Im Λ^SF_{ij} > 0（逐元，含非对角） |
| 非对角元 | 可以为负（只要不太大） | **必须全部为正** |
| 关系 | 对角主导 ⊃ PSD ⊃ 对角元正 | 逐元正 ⊃ PSD |
| 蕴含 | **对角主导 ⇏ 逐元正** | |

**结论**：即使我们能证明对角主导传递（技术上已经很难），也**不支持** Essenberger Eq.(37) 的非对角逐元正断言。

| W^RPA ⪰ 0 | RPA 屏蔽势正半定 | Lehmann 表示 + Dyson 级数 | **analytic** |
| χ^RPA Hermitian 部分 PSD | 热平衡稳定性 | 涨落耗散定理 | **analytic** |
| χ^RPA 对角主导 | RPA 迭代增强对角 | 0/23000 扫描 + 机制猜想 | **numerical-evidence**（无定理） |
| **χ^RPA 逐元正（非对角）** | 负非对角 + PSD 不共存？ | **NOT OBTAINED**（无定理） |
