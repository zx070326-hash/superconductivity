## 整合理论框架

### 三层机制

#### 层次 1：Stoner 稳定性 → 符号约束（通用，analytic）

**定理 A′（Team A，条件版）**：
设 χ₀ 对角主导，U > 0 对角，且 ρ(χ₀U) < 1。则：
1. RPA 收敛：χ^RPA = χ₀(1 - Uχ₀)^{-1} 良定义
2. 相关系数收缩：r[χ^RPA] ≤ r[χ₀] · f(ρ)，f(ρ) < 1
3. 对角主导增强：D[χ^RPA] > D[χ₀]

**物理图像**：
```
ρ(χ₀U) < 1  ⟺  Stoner 稳定（顺磁态）
           ⟹  RPA 迭代抑制轨道间相干
           ⟹  相关系数 r_n ∝ ρ^n → 0（几何衰减）
           ⟹  负非对角 + PSD 窗口极窄
```

**关键推论**：
- 所有物理材料必然 ρ < 1（否则铁磁相变）
- Essenberger FeSe 无例外
- ⟹ **Eq.(37) 逐元正是 Stoner 稳定性的必然结果，非 FeSe 特殊性**

#### 层次 2：费米面几何 → Stoner 稳定性（材料特定，待证）

**问题**：为什么铁基超导的费米面几何自然给出 ρ < 1？

**Lindhard 函数**：
```
χ₀_{αβ}(q,0) = Σ_k [f(ε_α(k)) - f(ε_β(k+q))] / [ε_β(k+q) - ε_α(k)]
```

**费米面拓扑的作用**：
1. **对角元**：χ₀_{αα} ~ N_α(E_F)（费米面态密度）
2. **非对角元**：χ₀_{αβ} ~ ξ_{αβ}(q)/Δ_{αβ}（嵌套度 / 带间能隙）
3. **谱半径**：ρ(q) := λ_max(χ₀(q)·U)

**嵌套度的双重作用**（关键洞察）：
- **增强 χ₀ 幅度**：高嵌套 q_nest → χ₀(q_nest) 大
- **但不改变 ρ < 1 约束**：物理稳定性要求 max_q ρ(q) < 1

**待验证假说**：
- Q_AFM ≈ (π,0) 是嵌套度最大点 ⟹ ξ_{αβ}(Q_AFM) 最大
- 同时也是 ρ(q) 最大点 ⟹ ρ(Q_AFM) 接近但 < 1
- 这是铁基超导"接近铁磁不稳定但未跨越"的微观体现

## 数值证据解读

### Team B 的 0/23000 扫描为何未见负非对角？

**PSD 2×2 矩阵的 Cauchy-Schwarz 约束**：
```
χ₁₁ > 0, χ₂₂ > 0, χ₁₁χ₂₂ > χ₁₂²
```

**负非对角 + PSD 需要**：
```
χ₁₂ ∈ [−√(χ₁₁·χ₂₂), 0)
```

**相关系数**：
```
r := |χ₁₂| / √(χ₁₁·χ₂₂)
```

**约束等价于**：r < 1（严格不等号）

**Team A 定理**：ρ < 1 ⟹ r_n → 0（几何衰减）

**参数空间分析**（待数值确认）：
- 若 ρ = 0.9，则 r ~ 0.9^n（n = RPA 迭代轮数）
- 若 n ~ 5，则 r ~ 0.59
- 负非对角窗口：[−0.59√(χ₁₁·χ₂₂), 0)
- 在独立连续抽样下，测度 ~ 0.59/2 ≈ 0.3（粗估）

**⟹ 0/23000 不构成矛盾**，如果：
1. 实际 r 更小（ρ 更小或 n 更大）
2. 抽样分布未均匀覆盖 χ 空间

**需要 Team B 提供**：
- 抽样分布的 ρ 统计（最大值、分位数）

## 费米面嵌套度的真实角色

### 原假说（已修正）
❌ "高嵌套 → 正符号；低嵌套 → 负符号"

### 正确理解
✓ **嵌套度影响幅度，不改变符号结构**

**Essenberger 原文**（1411.2121, Fig.4c 说明）：
> "nesting for the SF pairing leads to an **increased** interband pairing"

关键词：**increased**（增强），不是"positive"（正号）

**物理图像**：
1. 嵌套度 ξ_{αβ}(q) 大 ⟹ χ₀_{αβ}(q) 大（Lindhard 级）
2. χ₀ 大 ⟹ χ^RPA 更大（RPA 增强）
3. **但符号由 Stoner 稳定性控制**：ρ < 1 ⟹ 相关系数小 ⟹ 正号概率高

**嵌套度的作用**：
- **定量**：决定 χ^s 的幅度（配对强度）
- **定性**：不决定符号（符号由 ρ < 1 保证）
