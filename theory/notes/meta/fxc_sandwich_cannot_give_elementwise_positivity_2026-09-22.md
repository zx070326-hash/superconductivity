## 1. 定理 (S1)（analytic）

设 `F = F^T` 实对称。则

```
(F χ F)_ij ≥ 0  对**每一个** PSD 的 χ 成立
   ⟺  F = s·w wᵀ，s ≥ 0，且 w **符号一致**（各分量全 ≥0 或全 ≤0）
```

即：**`rank(F) ≤ 1` 且 `range(F)` 由一个非负向量张成。**

**（⟸）** `F = s w wᵀ ⟹ (FχF)_ij = s²·(wᵀχw)·w_i w_j ≥ 0`，
因为 `wᵀχw ≥ 0`（χ 半正定）且 `w_i w_j ≥ 0`（符号一致）。

**（⟹）** 取 `χ = v vᵀ`（半正定）。则 `(FχF)_ij = (Fv)_i (Fv)_j`，
假设即「**每一个** `Fv` 都符号一致」⟹ `range(F) ⊆` 非负卦限 ∪ 非正卦限。
该并集**不含二维子空间**：若含，则该平面去掉原点后被两个不相交的非空闭锥 `C` 与 `−C` 覆盖，
而二维平面去掉一点是连通的，矛盾。⟹ `rank(F) ≤ 1`，且其 range 由符号一致的 `w` 张成。∎

**推论（本笔记的要点）**：物理的 `f^xc_zz` **不是秩一的**。
⟹ **Eq.(32) 的夹心结构本身，永远不可能保证 Eq.(37)。**
Eq.(37) 不是、也不可能是一条关于「夹心」的定理；它只能是关于**具体的** `f^xc` 与 `χ` 的断言。
这与 `meta/scdft_formalism_essenberger_2026-09-22.md` §8 的文本层结论**独立地相互印证**：
原文里 Eq.(37) 确实只是一句无推导的物理断言，因为**它本来就推不出来**。

## 2. 订正：我第一版写的是 `rank(F) ≤ 1`，漏了符号一致

**第一段：旧陈述错在哪。** 我先写下的充要条件是「`rank(F) ≤ 1`」，
理由是 `(FχF)_ij = s²(wᵀχw) w_i w_j`，`wᵀχw ≥ 0` ⟹ 非负。
**漏了 `w_i w_j`**：`w` 若有混合符号，`w_i w_j` 在 `sign(w_i) ≠ sign(w_j)` 时为负。
数值当场打脸：秩一但 `w` 混合符号 ⟹ **18790/18790 全部违反**。

**第二段：新陈述凭什么对。** 补上「`w` 符号一致」后，(⟸) 的每一个因子都显式非负
（`s² ≥ 0`、`wᵀχw ≥ 0`、`w_i w_j ≥ 0`），逐因子成立，不依赖任何估计；
(⟹) 用 `χ = vvᵀ` 把条件化成对 `range(F)` 的纯几何陈述，再用连通性论证。
数值：`w ≥ 0` 的秩一 F，**0/20000 违反**。
⟹ **符号一致是承重前提，不是装饰**（对照组 18790/18790 即是负对照）。

## 3. 定量：现实的 `f^xc` 能帮多少？机制是什么？

定理说「不保证」，但没说「帮不上」。实测（N=5，各 20000 组随机 PSD χ）：

| `F` 的类型 | 夹心后逐元 ≥0 的比例 |
|---|---|
| 对称，元素**可正可负** | **1.70%** |
| 对称，元素**全 ≥0** | **86.78%** |

差 51×。机制是 **Perron–Frobenius**：`F ≥ 0` 逐元 ⟹ 主特征向量 `w ≥ 0`；
谱隙越大，`F` 越接近 `s wwᵀ`（`w ≥ 0`），即越接近 §1 的**精确**充分条件。
按 Perron 隙分层：

| Perron 隙 `λ₁/max_{k≥2}\|λ_k\|` | `F ≥ 0` 逐元 | **负对照**：同隙，元素允许为负 |
|---|---|---|
| < 2 | **69.0%** | **1.5%** |
| 2–5 | **87.6%** | **3.2%** |
| ≥ 5 | **98.0%** | **2.7%** |

**负对照是这一节的承重部分**：如果驱动因素只是「近秩一」，两列应当相同。
实测右列在任何隙下都趴在 1.5–3.2%，**不随隙上升** ⟹
**驱动因素是 `F` 的逐元非负性，谱隙只做调制。两个成分缺一不可。**

## 4. 判决：未知量搬家了（这是本笔记的交付物）

| | 旧提法 | 新提法 |
|---|---|---|

| 属于 | 材料物理（要算 FeSe 能带 + 磁化率） | **xc 核的性质**（与材料弱相关，泛函一选定就基本定了） |
| 代价 | 高（全套 SCDFT 计算） | **低**（`f^xc` 模型一写下就能直接查） |

⟹ **下一步不是去算 `Λ^SF`，是先看 `f^xc_zz` 是不是逐元非负、Perron 隙多大。**
若逐元非负且隙大 ⟹ Eq.(37) 很可能成立（但仍非定理，98% ≠ 100%）⟹ (K1) 在铁基上站得住。
