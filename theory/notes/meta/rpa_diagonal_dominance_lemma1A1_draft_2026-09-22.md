## 问题陈述

**引理 1A.1**（待证）：设 χ₀ 是 N×N Hermitian 矩阵，满足：
1. 对角主导：D[χ₀] := min_α (χ₀_{αα} - Σ_{β≠α} |χ₀_{αβ}|) > 0
2. 正半定：χ₀ ⪰ 0
3. U = diag(u₁, ..., u_N)，u_α > 0

则一阶 RPA 修正 χ^(1) = χ₀ + χ₀Uχ₀ 满足：

```
D[χ^(1)] ≥ κ₁ · D[χ₀]
```

其中 κ₁ > 0 依赖于 ‖Uχ₀‖ 但在 RPA 收敛域内有正下界。

---

## 证明策略（基于 Worker 1 符号展开的洞察）

### 关键观察 1：Gram 结构

Lindhard 粒子-空穴泡泡具有 **Gram 矩阵**结构：

```
χ₀_{αβ}(q,ω) = ∫ dk ψ_α(k)* ψ_β(k+q) [费米分布因子]
             = ⟨ψ_α, K ψ_β⟩  （某个正核 K）
```

这意味着 χ₀ 可写成 χ₀ = V^T W V，其中 V 是某个"波函数矩阵"，W ⪰ 0 是权重。

**推论**：Cauchy-Schwarz 自动给出

```
|χ₀_{αβ}|² ≤ χ₀_{αα} · χ₀_{ββ}
```

取等 ⟺ ψ_α 与 ψ_β 完全嵌套（费米面几何的特殊配置）。

### 关键观察 2：矩阵乘积的结构

计算 (χ₀Uχ₀)_{αβ}：

```
(χ₀Uχ₀)_{αβ} = Σ_γ χ₀_{αγ} u_γ χ₀_{γβ}
```

**对角项**（α=β）：
```
(χ₀Uχ₀)_{αα} = Σ_γ χ₀_{αγ} u_γ χ₀_{γα}
              = Σ_γ u_γ |χ₀_{αγ}|²    （Hermitian 性质）
              ≥ u_min Σ_γ |χ₀_{αγ}|²
```

**非对角项**（α≠β）：
```
|(χ₀Uχ₀)_{αβ}| ≤ Σ_γ |χ₀_{αγ}| u_γ |χ₀_{γβ}|
                ≤ u_max Σ_γ |χ₀_{αγ}| |χ₀_{γβ}|
```

### 证明草图

**Step 1**：分解 χ^(1) 的对角主导度量

```
D[χ^(1)] = min_α [χ^(1)_{αα} - Σ_{β≠α} |χ^(1)_{αβ}|]
         = min_α [(χ₀_{αα} + (χ₀Uχ₀)_{αα}) - Σ_{β≠α} |χ₀_{αβ} + (χ₀Uχ₀)_{αβ}|]
```

**Step 2**：利用三角不等式（需小心方向）

对非对角项：
```
|χ₀_{αβ} + (χ₀Uχ₀)_{αβ}| ≤ |χ₀_{αβ}| + |(χ₀Uχ₀)_{αβ}|
```

所以：
```
D[χ^(1)] ≥ min_α [χ₀_{αα} + (χ₀Uχ₀)_{αα} - Σ_{β≠α}(|χ₀_{αβ}| + |(χ₀Uχ₀)_{αβ}|)]
         = D[χ₀] + min_α [(χ₀Uχ₀)_{αα} - Σ_{β≠α} |(χ₀Uχ₀)_{αβ}|]
         =: D[χ₀] + Δ
```

**Step 3**：估计 Δ 的下界

需证明 Δ ≥ −(1−κ₁) D[χ₀]，即

```
min_α [(χ₀Uχ₀)_{αα} - Σ_{β≠α} |(χ₀Uχ₀)_{αβ}|] ≥ −(1−κ₁) D[χ₀]
```

这是**关键不等式**。

## 困难点（当前卡住的地方）

### 困难 1：非对角和的控制

从 |(χ₀Uχ₀)_{αβ}| ≤ u_max Σ_γ |χ₀_{αγ}| |χ₀_{γβ}| 到

```
Σ_{β≠α} |(χ₀Uχ₀)_{αβ}| ≤ ???
```

需要一个**全局估计**，而不是逐项估计。

朴素界：
```
Σ_{β≠α} |(χ₀Uχ₀)_{αβ}| ≤ u_max Σ_{β≠α} Σ_γ |χ₀_{αγ}| |χ₀_{γβ}|
```

但这会产生 |χ₀_{αγ}| 的重复计数，导致界太松。

### 困难 2：对角项与非对角项的比值

真正需要的是证明：

```
(χ₀Uχ₀)_{αα} / [Σ_{β≠α} |(χ₀Uχ₀)_{αβ}|] ≥ 某个正常数
```

Worker 1 的符号展开显示：
- 对角项 ~ u |χ₀_{αγ}|²（二次型）
- 非对角项 ~ u |χ₀_{αγ}| |χ₀_{γβ}|（双线性）

但如何从这个"二次 vs 双线性"的结构差异提取出**定量不等式**？

### 困难 3：Cauchy-Schwarz 的使用

对每个 β≠α：
```
|(χ₀Uχ₀)_{αβ}| = |Σ_γ u_γ χ₀_{αγ} χ₀_{γβ}|
                ≤ [Σ_γ u_γ |χ₀_{αγ}|²]^{1/2} · [Σ_γ u_γ |χ₀_{γβ}|²]^{1/2}
                = √[(χ₀Uχ₀)_{αα} · (χ₀Uχ₀)_{ββ}]
```

这给出了**逐项** Cauchy-Schwarz 界，但如何对所有 β≠α 求和？

## 可能的突破方向

### 方向 A：加权 ℓ² 范数

定义加权范数 ‖v‖²_U := Σ_α u_α |v_α|²。

则：
```
(χ₀Uχ₀)_{αα} = ‖χ₀[α,:]‖²_U  （第 α 行的加权 ℓ² 范数）
```

利用 Hölder 不等式或其他泛函分析工具？

### 方向 B：Perron-Frobenius 类比

仓库的引理 M 用了**锥保持**：若 F ≤ G 逐点且都非负非增，则 λ₁(𝒪[F]) ≤ λ₁(𝒪[G])。

RPA 的 χ₀Uχ₀ 是否也有某种"正性结构"可以被传递？

问题：χ₀Uχ₀ 的非对角元**不一定非负**（这正是我们要研究的对象）。

### 方向 C：限制到静态极限（退守路线 1B）

若 ω=0，χ₀ 是实对称矩阵，可能有更简单的代数结构。

物理上：静态磁化率恰是 Essenberger 论文用的量。

**优势**：不涉及频率积分，纯线性代数。  
**劣势**：只覆盖静态情况。
