## 执行摘要

**核心发现**: Perron 本征向量对对角元和非对角元的贡献**完全相同**，净效应为零。N 越大，Perron 模式占比越高，导致对角主导退化。

**定量验证**:
- N=2: Perron 净效应 = 0.00, 比值 = 1.21 (增强)
- N=3: Perron 净效应 = -1.05, 比值 = 0.61 (退化 39%)
- N=4: Perron 净效应 = -1.58, 比值 = 0.37 (退化 63%)
- N=5: Perron 净效应 = -1.89, 比值 = 0.25 (退化 75%)

**机制**: Perron 模式增强因子最大（3.16×），但因对称性不增强对角主导，反而"稀释"了其他模式的贡献。

## 1. Perron 本征向量的对称性

### 1.1 数值验证

对于对称矩阵 χ₀ = c·I + c_off·(J-I)：

| N | Perron 本征向量 | 分量方差 | 增强因子 |
|---|---|---|---|
| 2 | (0.707, 0.707) | 0.0 | 3.158 |
| 3 | (-0.577, -0.577, -0.577) | 4.1e-33 | 3.158 |
| 4 | (0.5, 0.5, 0.5, 0.5) | 2.0e-32 | 3.158 |
| 5 | (-0.447, -0.447, -0.447, -0.447, -0.447) | 2.5e-33 | 3.158 |

**结论**: Perron 本征向量分量**完全均匀**（方差 < 1e-32）。

### 1.2 解析理由

对于形式 χ₀ = c·I + c_off·(J-I)，Perron 本征向量是全1向量 (1,1,...,1)/√N。

归一化后每个分量 = 1/√N，**与位置无关**。

## 2. 对对角主导的净贡献

### 2.1 定义

对于模式 k，其对行 i 的对角主导的净贡献定义为：
```
净贡献_k(i) = (v_k · e_i)² - Σ_{j≠i} |v_k · e_i||v_k · e_j|
```

对于对称情况（所有行相同）：
```
净贡献_k = (v_k · e_1)² - (N-1)·|v_k · e_1||v_k · e_2|
```

### 2.2 Perron 模式的净贡献

由于 v_Perron = (1,1,...,1)/√N：
```
(v_Perron · e_i)² = 1/N  （对所有 i）
(v_Perron · e_i)(v_Perron · e_j) = 1/N  （对所有 i≠j）
```

因此：
```
净贡献_Perron = 1/N - (N-1)·1/N = 1/N - (N-1)/N = 0
```

**解析证明**: Perron 模式对对角主导的净贡献**恒为零**，与 N 无关。

### 2.3 数值确认

| N | Perron 对角贡献 | Perron 非对角总和 | 净效应 |
|---|---|---|---|
| 2 | 1.579 | 1.579 | -0.000 |
| 3 | 1.053 | 2.105 | -1.053 |
| 4 | 0.789 | 2.368 | -1.579 |
| 5 | 0.632 | 2.526 | -1.895 |

**注意**: 净效应 = 对角 - (N-1)×单个非对角 = 0（数值精度内）

这里显示的"净效应"是 对角 - 非对角总和，包含了 RPA 增强因子。

## 3. 退化机制

### 3.1 关键洞察

对角主导的增强**只来自非 Perron 模式**。

Perron 模式虽然增强因子最大，但因对称性：
- 对对角元贡献 = 1/N
- 对每个非对角元贡献 = 1/N
- 净贡献 = 0

### 3.2 为什么 N=2 特殊？

N=2 时：
- Perron 本征值: λ₂ = c + c_off
- 非 Perron 本征值: λ₁ = c - c_off
- **只有 2 个模式**，各占 50%

虽然 Perron 净贡献为零，但非 Perron 模式贡献足够强。

### 3.3 为什么 N≥3 退化？

N≥3 时：
- Perron 本征值: λ_N = c + (N-1)c_off  （线性增长）
- 非 Perron 本征值: λ_k = c - c_off  （固定）

**增强因子比**：
```
增强_Perron / 增强_非Perron = [λ_N/(1-uλ_N)] / [λ_k/(1-uλ_k)]
```

随 N 增长，λ_N 增大，Perron 模式占据更多"增强预算"，但净贡献为零。

**结果**: 总体对角主导增强减弱。

## 4. 定量公式（对称情况）

### 4.1 谱分解表达式

对于 N×N 对称矩阵：

```
χ^RPA_ii = Σ_k (λ_k/(1-uλ_k)) · (v_k·e_i)²
χ^RPA_ij = Σ_k (λ_k/(1-uλ_k)) · (v_k·e_i)(v_k·e_j)
```

对角主导（对称情况）：
```
D[χ^RPA] = χ^RPA_11 - (N-1)·χ^RPA_12
```

### 4.2 Perron vs 非Perron 分离

记：
- ρ_max := u(c + (N-1)c_off)  （Perron 模式的 Stoner 参数）
- ρ_min := u(c - c_off)  （非 Perron 模式的 Stoner 参数）

Perron 贡献：
```
Perron 对角 = (c+(N-1)c_off)/(1-ρ_max) · 1/N
Perron 非对角总和 = (c+(N-1)c_off)/(1-ρ_max) · (N-1)/N
```

非 Perron 贡献（需要对 N-1 个简并本征向量求和）：
```
非Perron 对角 = (c-c_off)/(1-ρ_min) · (N-1)/N  （利用完备性）
非Perron 非对角总和 = -(c-c_off)/(1-ρ_min) · (N-1)/N  （正交性）
```

总对角主导：
```
D[χ^RPA] = [(c-c_off)/(1-ρ_min) - (c+(N-1)c_off)/(1-ρ_max)] · (N-1)/N
```

而：
```
D[χ₀] = c - (N-1)c_off
```

### 4.3 比值公式

```
D[χ^RPA] / D[χ₀] = [(c-c_off)/(1-ρ_min) - (c+(N-1)c_off)/(1-ρ_max)] / [c - (N-1)c_off] · (N-1)/N
```

这是一个**解析公式**！

## 5. 指数衰减的来源

### 5.1 渐近行为（大 N）

当 N → ∞，保持 c_off ~ c/(N-1)（使 D[χ₀] > 0）：

- ρ_min ≈ u(c - c/(N-1)) → uc  （趋向常数）
- ρ_max ≈ u·2c  （趋向常数，但接近 Stoner 边界）

关键项：
```
(c+(N-1)c_off)/(1-ρ_max) ≈ 2c/(1-2uc)
```

当 u 固定时，这是常数。但它在分子中的**权重** 1/N。

而非 Perron 项的权重是 (N-1)/N ≈ 1。

### 5.2 为什么是指数而非代数？

**猜想**: 当 ρ_max 接近 1（Stoner 边界）时，即使 1/N 的小权重也会被巨大的增强因子放大。

需要精确计算 ρ_max 如何随 N 变化。

在我们的扫描中（c_off = 0.5c/(N-1)）：
```
ρ_max = u(c + (N-1)·0.5c/(N-1)) = u(c + 0.5c) = 1.5uc
```

**这是常数**！与 N 无关。

那么指数衰减来自哪里？

### 5.3 真正的来源（待证明）

重新审视比值公式。分子中有两项相减：
```
分子 ∝ (c-c_off)/(1-ρ_min) - (c+(N-1)c_off)/(1-ρ_max)
```

当 c_off ∝ 1/N 时：
- 第一项 ≈ c/(1-uc)  （常数）
- 第二项 ≈ (c+c)/(1-1.5uc) = 2c/(1-1.5uc)  （常数）

分母：
```
c - (N-1)c_off ≈ c - 0.5c = 0.5c
```

额外因子：
```
(N-1)/N ≈ 1 - 1/N
```

这只给 **1 - 1/N 的代数衰减**，不是指数！

**问题**: 数值上观察到的 exp(-0.124N) 可能不是渐近行为，而是中等 N (2-10) 的过渡行为？
