## 动机

从 Route 1 我们发现：
- **Perron 模式对对角主导的净贡献为零**（对角贡献 = 非对角贡献）
- 退化是因为 Perron 模式"占据"了增强预算但不贡献净效应
- 非 Perron 模式真正增强对角主导，但被稀释

**核心思路**: 定义一个**加权**度量，使得 Perron 模式的对称贡献被**权重抵消**，只保留非 Perron 模式的有益部分。

---

## 加权对角主导定义

### 定义 2.1（加权对角主导）

对于 N×N 矩阵 M 和正权重向量 w = (w₁,...,w_N)，定义：

```
D_w[M] := min_α w_α · (M_αα - Σ_{β≠α} |M_αβ|)
```

当 w = (1,1,...,1) 时，退化为标准对角主导 D[M]。

### 目标

寻找权重 w(χ₀) 使得：
```
D_w[χ^RPA] ≥ D_w[χ₀]
```

---

## 权重选择方案

### 方案 A: 逆对角元权重

```
w_α = 1 / χ₀,αα
```

**直觉**: 归一化到对角元，消除"大对角元增强多、小对角元增强少"的不对称效应。

**对称情况**: χ₀,αα = c（所有 α），所以 w_α = 1/c（常数）
→ 退化为标准度量，不提供额外信息。

### 方案 B: Perron 本征向量权重

记 v_P 为 Perron 本征向量（归一化）。

```
w_α = 1 / (v_P · e_α)²
```

**直觉**: Perron 模式对位置 α 的贡献正比于 (v_P · e_α)²。用其倒数作权重，抵消 Perron 贡献。

**对称情况**: v_P = (1,1,...,1)/√N，所以 (v_P · e_α)² = 1/N
→ w_α = N（常数）
→ 仍然是标准度量（乘以常数）。

### 方案 C: 谱权重

基于本征值分布：

```
w_α = Σ_k≠Perron (v_k · e_α)² / (λ_k/(1-uλ_k))
```

**直觉**: 用非 Perron 模式的"预期贡献"作权重。

**问题**: 这个权重依赖于 RPA 后的增强因子，定义循环。

### 方案 D: 比值权重（新想法）

定义：
```
w_α = [Σ_{k≠Perron} (v_k·e_α)²] / [(v_Perron·e_α)²]
```

即：非 Perron 模式在位置 α 的权重 / Perron 模式在位置 α 的权重。

**对称情况**: 
- 分子 = (N-1)/N（由完备性）
- 分母 = 1/N
- w_α = N-1（常数）

仍然退化为标准度量。

---

## 对称情况的根本困难

**引理 2.1**: 对于完全对称矩阵 χ₀ = c·I + c_off·(J-I)，任何**位置无关**的权重 w_α = w（常数）都等价于标准度量（乘以常数因子）。

**证明**: 显然。□

**推论**: 在对称情况下，加权度量方法无法提供超越标准度量的信息。

**含义**: 
- 方案 A、B、D 在对称情况下全部失效
- 加权度量只对**非对称**情况可能有用

## 重新验证 Route 1B 的反例

从 `rpa_2x2_counterexample_analysis_2026-09-22.md`：

```python
χ₀ = [[1.5, 0.2], [0.2, 0.8]]

让我手算 RPA：
```

det = 0.4×0.68 - 0.08² = 0.272 - 0.0064 = 0.2656

χ^RPA = χ₀ × (I - Uχ₀)⁻¹

矩阵乘法：

χ^RPA = [[3.902, 0.753], [0.753, 1.265]]

对，这与文档一致。我之前看错数字了（1.790 应该是 0.753）。

### 继续方案 A

加权对角主导 χ^RPA：
```
D_w[χ^RPA] = min(w₁×3.149, w₂×0.512)
           = min(0.667×3.149, 1.25×0.512)
           = min(2.100, 0.640)
           = 0.640
```

比值：
```
D_w[χ^RPA] / D_w[χ₀] = 0.640 / 0.75 = 0.853
```

而标准度量比值 = 0.512 / 0.600 = 0.853

**完全相同**！

### 引理 2.2

对于权重 w_α = 1/χ₀,αα 且 U = u·I（均匀），有：

```
D_w[χ^RPA] / D_w[χ₀] = D[χ^RPA] / D[χ₀]
```

即方案 A 在均匀 U 下**不改变比值**。

**直觉验证**: 

瓶颈行（设为行 2）：
```
D[χ^RPA] = χ^RPA_{22} - |χ^RPA_{21}|
```

加权版：
```
D_w[χ^RPA] = w₂·(χ^RPA_{22} - |χ^RPA_{21}|) = w₂·D[χ^RPA]_行2
```

同样：
```
D_w[χ₀] = w₂·D[χ₀]_行2
```

所以：
```
D_w[χ^RPA] / D_w[χ₀] = D[χ^RPA]_行2 / D[χ₀]_行2
```

这恰好是标准度量的比值（因为瓶颈都在行 2）。

## 结论

**Route 2 的根本困难**:

1. **对称情况**: 任何位置无关的权重都等价于标准度量
