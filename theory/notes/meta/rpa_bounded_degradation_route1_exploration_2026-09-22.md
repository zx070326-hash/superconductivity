## Step 1: N=3 对称情况的谱分解

### 1.1 矩阵结构

对称均匀非对角：
```
χ₀ = c·I + c_off·(J - I)
```

其中 J = 全1矩阵，对于 N=3：
```
χ₀ = [[c,      c_off,  c_off],
      [c_off,  c,      c_off],
      [c_off,  c_off,  c    ]]
```

### 1.2 本征值（解析）

这个结构的本征值已知：
- λ₁ = c - c_off（重数 N-1 = 2）
- λ_N = c + (N-1)c_off = c + 2c_off（重数 1）

对应本征向量：
- v₁, v₂: 与全1向量 (1,1,1) 正交的任意两个正交向量
- v₃ = (1,1,1)/√3: Perron 本征向量（全正分量）

### 1.3 RPA 的谱分解

RPA 公式：
```
χ^RPA = χ₀(I - Uχ₀)⁻¹ = Σᵢ λᵢ/(1-uλᵢ) vᵢvᵢᵀ
```

对 U = u·I（均匀情况）：
```
χ^RPA = (c-c_off)/(1-u(c-c_off))·(v₁v₁ᵀ + v₂v₂ᵀ)
      + (c+2c_off)/(1-u(c+2c_off))·v₃v₃ᵀ
```

**关键观察**: 
- 小本征值增强因子: 1/(1-u(c-c_off))
- 大本征值增强因子: 1/(1-u(c+2c_off)) 
- 大本征值增强**更强**（分母更小）

## Step 2: 对角主导度量的本征向量表示

### 2.1 问题的困难

对角主导 D[M] = min_α (M_αα - Σ_{β≠α}|M_αβ|) 不是本征值的直接函数。

需要追踪本征向量在标准基 {e₁, e₂, e₃} 下的表示。

### 2.2 对称情况的特殊性

由于完全对称性，所有行相同：
```
D[χ^RPA] = χ^RPA_11 - 2|χ^RPA_12|
         = χ^RPA_11 - 2χ^RPA_12  （因为 χ^RPA_12 > 0）
```

利用谱分解：
```
χ^RPA_11 = Σᵢ (λᵢ/(1-uλᵢ))·(vᵢ·e₁)²
χ^RPA_12 = Σᵢ (λᵢ/(1-uλᵢ))·(vᵢ·e₁)(vᵢ·e₂)
```

### 2.3 Perron 本征向量的贡献

v₃ = (1,1,1)/√3 给出：
- (v₃·e₁)² = 1/3
- (v₃·e₁)(v₃·e₂) = 1/3

所以 v₃ 对对角和非对角的贡献**相同**！

对角主导的增强**只来自** v₁, v₂（正交于 (1,1,1) 的模式）。

## Step 3: 关键引理（待证明）

**引理 P1** (Perron 模式削弱对角主导):

对于对称矩阵 χ₀ = c·I + c_off·(J-I)，定义：
- ρ_min := u(c - c_off)  （小本征值的 Stoner 参数）
- ρ_max := u(c + (N-1)c_off)  （大本征值的 Stoner 参数）

则：
```
D[χ^RPA] / D[χ₀] = g(ρ_min, ρ_max, N)
```

其中 g 随 N 单调递减。

**直觉**: 
- N 越大，Perron 模式（全正向量）的权重越大
- Perron 模式对对角和非对角贡献相同，**不增强对角主导**
- 其他模式（正交于全1）的贡献被稀释

### 3.1 定量计算（N=3）

对于正交于 (1,1,1) 的向量 v，有约束：
```
Σᵢ vᵢ = 0
```

取标准正交基：
```
v₁ = (1, -1, 0)/√2
v₂ = (1, 1, -2)/√6
```

计算：
```
v₁·e₁ = 1/√2,  v₁·e₂ = -1/√2
v₂·e₁ = 1/√6,  v₂·e₂ = 1/√6

(v₁·e₁)² = 1/2,  (v₁·e₁)(v₁·e₂) = -1/2
(v₂·e₁)² = 1/6,  (v₂·e₁)(v₂·e₂) = 1/6
```

所以：
```
χ^RPA_11 = (c-c_off)/(1-u(c-c_off))·(1/2 + 1/6) 
         + (c+2c_off)/(1-u(c+2c_off))·(1/3)
         = (c-c_off)/(1-ρ_min)·(2/3) + (c+2c_off)/(1-ρ_max)·(1/3)

χ^RPA_12 = (c-c_off)/(1-u(c-c_off))·(-1/2 + 1/6)
         + (c+2c_off)/(1-u(c+2c_off))·(1/3)
         = -(c-c_off)/(1-ρ_min)·(1/3) + (c+2c_off)/(1-ρ_max)·(1/3)
```

对角主导：
```
D[χ^RPA] = χ^RPA_11 - 2χ^RPA_12
         = (c-c_off)/(1-ρ_min)·(2/3 + 2/3) + (c+2c_off)/(1-ρ_max)·(1/3 - 2/3)
         = (c-c_off)/(1-ρ_min)·(4/3) - (c+2c_off)/(1-ρ_max)·(1/3)
```

而：
```
D[χ₀] = c - 2c_off
```

## Step 4: 退化机制分析

### 4.1 为什么 N=2 不退化？

N=2 时没有"纯 Perron 模式"的稀释效应。两个本征向量都对对角主导有净贡献。

### 4.2 为什么 N≥3 退化？

关键项：
```
- (c+2c_off)/(1-ρ_max)·(1/3)
```

这是 Perron 模式的**负贡献**（减号）。

N 越大：
1. Perron 本征值 λ_N = c + (N-1)c_off 越大
2. 增强因子 1/(1-ρ_max) 越大
3. 负贡献的绝对值越大
4. 对角主导被削弱

### 4.3 定量预测（待验证）

猜想：
```
D[χ^RPA] / D[χ₀] ∝ [非 Perron 模式权重] / [Perron 模式权重]
                  ∝ (N-1) / N  （粗略估计）
```

但这只给线性衰减 ~1 - 1/N，不是指数 exp(-βN)。

**需要更精细的分析**：考虑增强因子的 N 依赖。
