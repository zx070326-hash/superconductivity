## §0. 问题陈述

### 物理背景

多轨道系统（如铁基超导 FeSe）中，自旋涨落通过 RPA 处理：

```
χ^s = χ₀(1 - U_s χ₀)⁻¹
    = χ₀ + χ₀U_sχ₀ + χ₀U_sχ₀U_sχ₀ + ...
```

其中 χ₀_{αβ}(q,ω) 是 Lindhard 粒子-空穴泡泡（带指标 α,β）。

### 核心问题

Essenberger 1411.2121 Eq.(37) 断言 Im Λ^SF_{ij} > 0（逐元，含非对角），这是 FeSe (Z-dom) 判决的唯一散文支撑环节。三轮调研确认无解析 no-go 定理，仅有 0/23000+ 数值证据。

**我们的目标**：证明更强的结构性质——对角主导性——从而**结构性排除**"负非对角 + PSD 同时成立"。

## §1. 路线 1A：对角主导度量的 RPA 传递（主攻）

### 1.1 核心思路

定义 Gershgorin 型对角主导度量：

```
D[χ] := min_α (χ_{αα} - ∑_{β≠α} |χ_{αβ}|)
```

**目标定理**（暂定陈述）：存在 κ > 0 使得

```
D[χ^RPA] ≥ κ · D[χ₀]
```

**推论**：若 χ₀ 对角主导（D[χ₀] > 0，这对 Lindhard 在费米面附近成立），则 χ^RPA 必然对角主导，且"负非对角 + PSD"结构性不可能。

### 1.2 技术路线

#### Step 1: Lindhard 的对角主导性（已知）

Lindhard 粒子-空穴泡泡在 ω → 0、q → Q_AFM 时：

```
χ₀_{αα}(q,ω) ~ N_α(E_F) · [某个峰函数]
χ₀_{αβ}(q,ω) ~ [费米面嵌套函数] · [同一峰函数]
```

对角元由**单带** DOS 控制，非对角元由**两带间嵌套度**控制。在一般情况下：

```
|χ₀_{αβ}| ≤ √(χ₀_{αα} χ₀_{ββ})  （Cauchy-Schwarz）
```

且等号仅在"完美嵌套"时达到。

**已知结论**（需从文献确认或推导）：
- D[χ₀] ~ N(E_F) > 0

#### Step 2: RPA 一阶项的对角主导传递

考虑 RPA 一阶修正：

```
χ^(1) = χ₀ + χ₀Uχ₀
```

需证明：

```
D[χ^(1)] ≥ c₁ · D[χ₀]
```

**关键引理 1A.1**（待证）：若 χ₀ 对角主导、U ≥ 0 且对角占优，则

```
(χ₀Uχ₀)_{αα} - ∑_{β≠α} |(χ₀Uχ₀)_{αβ}| 
    ≥ [某个正系数] · D[χ₀]
```

**证明策略**：
- 展开 (χ₀Uχ₀)_{αβ} = ∑_γ χ₀_{αγ} U_{γγ} χ₀_{γβ}（U 对角时）
- 对角项：(χ₀Uχ₀)_{αα} = ∑_γ χ₀_{αγ}² U_{γγ}
- 非对角项：|(χ₀Uχ₀)_{αβ}| ≤ ∑_γ |χ₀_{αγ}| U_{γγ} |χ₀_{γβ}|
- 利用 χ₀ 的对角主导性做不等式传播

#### Step 3: 归纳到 RPA 全级数

若能证明每一阶的传递系数 κ_n ≥ κ > 0（一致下界），则对 Dyson 级数求和：

```
D[χ^RPA] = D[∑_{n=0}^∞ (χ₀U)^n χ₀]
          ≥ κ · D[χ₀]  （需证明求和保持不等式）
```

**技术难点**：
- 级数求和可能破坏对角主导性（抵消效应）
- 需证明 (1-Uχ₀)⁻¹ 的 Neumann 级数保持某种单调性

**替代路线**：直接处理 Dyson 方程

```
χ = χ₀ + χ₀Uχ
⟹ χ - χ₀Uχ = χ₀
⟹ (1 - χ₀U)χ = χ₀
```

若能证明 (1-χ₀U)⁻¹ 作为算子"放大"对角主导度量，问题即解决。

### 1.3 与仓库技术栈的连接

仓库 P4 工作大量使用**加权 Schur 定理**和 **Perron-Frobenius 传递**（见 `P4_main_theorems.md` §1 引理 M）：

```
引理 M：F ≤ G 逐点 ⟹ λ₁(𝒪[F]) ≤ λ₁(𝒪[G])
```

**类比启发**：
- P4 的 𝒪[·] 是逐元线性的正算子
- RPA 的 χ₀U 也是某种"正"结构（U>0, χ₀ 的虚部>0）
- 可能存在类似的单调性定理

**直接可用工具**：
- Gershgorin 圆盘定理（对角主导 ⟹ 谱界）
- Perron-Frobenius（非负矩阵的最大本征值）
- 仓库的 `p4_*_interval.py` 区间算术框架（若需数值辅助证明）

## §2. 路线 1B：静态极限的显式界（备选）

### 2.1 简化：ω=0 的静态磁化率

Essenberger 论文用的恰好是**静态** Im χ(q,0)，不是全频率。这给了我们一个简化：

```
χ(q,0) = ∫ dω χ(q,ω)/iω
       = ∑_n (χ₀U)^n χ₀ |_{ω=0}
```

静态极限下：
- χ₀(q,0) 是实矩阵（虚部来自因果性在 ω≠0）
- RPA 迭代变成纯代数：χ = χ₀(1 - Uχ₀)⁻¹

### 2.2 技术路线

**引理 1B.1**（待证）：设 A 是实对称正定矩阵、对角主导度 D[A] > 0，U 是正对角矩阵。若 ‖UA‖ < 1（Stoner 稳定性），则

```
B := A(1 - UA)⁻¹
```

满足 D[B] ≥ c(‖UA‖) · D[A]，其中 c(x) → 1 当 x → 0。

**证明策略**：
- Neumann 级数 (1-UA)⁻¹ = ∑_{n=0}^∞ (UA)^n
- 逐项控制 (UA)^n 的非对角元增长
- 利用 ‖UA‖ < 1 做几何级数求和

**优势**：
- 不涉及频率积分，纯线性代数
- 直接适用于 Essenberger 的 ω=0 场景

**劣势**：
- 只覆盖静态极限
- 可能需要 U 较小（弱耦合）的前提

### 3.2 实施方案

**Phase 1: 符号计算**（派 sonnet worker）
- 输入：一般 2×2 或 3×3 矩阵 χ₀（符号元素）
- 计算：χ^(n) = (χ₀U)^n χ₀ 的显式展开
- 输出：对角元与非对角元的符号表达式

**Phase 2: 不等式反向工程**
- 假设 χ₀ 满足 D[χ₀] ≥ δ > 0
- 数值验证：对随机参数，D[χ^(n)] 与 D[χ₀] 的比值分布
- 识别：最坏情况的参数配置（哪些 χ₀ 使比值最小）

**Phase 3: 归纳证明**
- 若发现模式（如 D[χ^(n)] ≥ κ^n D[χ₀]），用归纳法严格证明
- 或：找到**反例**（负非对角 + PSD 共存的构造）
