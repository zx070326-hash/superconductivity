## 定理陈述（修正版）

**定理 1A (RPA 相关系数收缩)**：设 χ₀ 是 N×N Hermitian 正半定矩阵，U = diag(u₁,...,u_N) 且 u_α > 0。定义：

- 谱半径：ρ := ρ(χ₀U)
- 相关系数：r[χ] := max_{α≠β} |χ_{αβ}| / √(χ_{αα}·χ_{ββ})

若 **ρ < 1**（Stoner 稳定性），则 RPA 磁化率 χ^RPA = χ₀(1 - Uχ₀)⁻¹ 良定义，且

```
r[χ^RPA] ≤ r[χ₀] / (1 - ρ)
```

**推论（对角主导增强）**：若 χ₀ 对角主导（D[χ₀] > 0），则

```
D[χ^RPA] ≥ D[χ₀] · (某个 κ(ρ) > 1)
```

即：对角主导性通过 RPA 被**增强**，不只是保持。

## 解析证明草图

### Step 1: Neumann 级数展开

由 ρ < 1，Neumann 级数收敛：

```
χ^RPA = χ₀(1 - Uχ₀)⁻¹ = χ₀ Σ_{n=0}^∞ (Uχ₀)^n
      = Σ_{n=0}^∞ (χ₀U)^n χ₀
```

### Step 2: 逐项相关系数界

**引理 A**：χ₀ 有 Gram 结构（粒子-空穴泡泡）⟹ 对任意 n ≥ 0：

```
r[(χ₀U)^n χ₀] ≤ r[χ₀] · ρ^n
```

**证明**（归纳法）：
- n=0：显然
- n→n+1：设 χ^(n) = (χ₀U)^n χ₀，需证 r[(χ₀U)χ^(n)] ≤ r[χ^(n)]·ρ

关键不等式：对任意 α≠β，

```
|(χ₀Uχ^(n))_{αβ}| = |Σ_γ χ₀_{αγ} u_γ χ^(n)_{γβ}|
                    ≤ Σ_γ |χ₀_{αγ}| u_γ |χ^(n)_{γβ}|
                    ≤ [Σ_γ |χ₀_{αγ}|² u_γ]^{1/2} · [Σ_γ |χ^(n)_{γβ}|² u_γ]^{1/2}  (Cauchy-Schwarz)
```

而 Σ_γ |χ₀_{αγ}|² u_γ ≤ ‖χ₀U‖ · χ₀_{αα} ≤ ρ · χ₀_{αα}（谱半径定义）

类似地对 β，所以：

```
|(χ₀Uχ^(n))_{αβ}| ≤ √[ρ·χ₀_{αα}] · √[ρ·χ^(n)_{ββ}]
                   = ρ · √[χ₀_{αα}·χ^(n)_{ββ}]
```

**⟸ 这一步需要更精细论证**（当前草稿的弱点）。

真正需要证明：

```
|(χ₀Uχ^(n))_{αβ}| / √[(χ₀Uχ^(n))_{αα} · (χ₀Uχ^(n))_{ββ}]
  ≤ |χ^(n)_{αβ}| / √[χ^(n)_{αα} · χ^(n)_{ββ}]
```

### Step 3: 级数求和

若引理 A 成立，则对 χ^RPA = Σ_{n=0}^∞ (χ₀U)^n χ₀：

```
|χ^RPA_{αβ}| ≤ Σ_{n=0}^∞ |(χ₀U)^n χ₀|_{αβ}
             ≤ Σ_{n=0}^∞ r[χ₀]·ρ^n · √[某对角乘积]
             = r[χ₀]/(1-ρ) · √[某对角乘积]
```

**技术难点**：对角项的几何级数求和与非对角项的求和**不对称**。

需要更精细的界：分别追踪分子（非对角和）与分母（对角乘积平方根）。
