## 1. 定理（反向蕴含，analytic）

**陈述**：设 `χ₀ = [[a,b],[b,c]]` 实对称，`Δ := ac − b² > 0`，逐行严格对角主导
（`D₁ = a−|b| > 0`、`D₂ = c−|b| > 0`）；`U = diag(U₁,U₂)`，`U₁,U₂ ≥ 0`；
`χ := (χ₀⁻¹ − U)⁻¹` 正定（Stoner 稳定）。若 χ 的**两行**亏损皆正
（`R₁, R₂ > 0`），则

```
ceiling := sup_{t>0} min(tR₁, R₂) / min(tD₁, D₂)  ≥  1.
```

**证明**。`χ₀⁻¹ = (1/Δ)[[c,−b],[−b,a]]`。记

```
p := c/Δ − U₁,   q := a/Δ − U₂,   r := b/Δ,
p₀ := c/Δ,       q₀ := a/Δ,       s := pq − r² > 0,   s₀ := p₀q₀ − r² = 1/Δ.
```

则 `χ = (1/s)[[q, r],[r, p]]`（脚本 STEP 1 复核，`max|Δ| = 7e−08`，近奇异处为条件数所限），于是

```
R₁ = (q−|r|)/s,   R₂ = (p−|r|)/s,        D₁ = (q₀−|r|)/s₀,  D₂ = (p₀−|r|)/s₀
```

（后两式是 `U=0` 的特例，自动一致）。`t→0` 与 `t→∞` 给
`ceiling ≥ max(R₁/D₁, R₂/D₂)`，故只需证后者 ≥ 1。令

```
ρ := |r|,   x := q−ρ,  x₀ := q₀−ρ,  y := p−ρ,  y₀ := p₀−ρ      （四者皆 >0，由两条前提）
u := x/x₀ ∈ (0,1],   v := y/y₀ ∈ (0,1]                          （≤1 ⟸ U₁,U₂ ≥ 0）
```

关键恒等式（脚本 STEP 2 复核，`5.8e−13`）：

```
s  = pq − ρ² = xy + ρ(x+y),        s₀ = x₀y₀ + ρ(x₀+y₀),
R₁/D₁ = u · s₀/s,                  R₂/D₂ = v · s₀/s.
```

不妨 `u ≥ v`。则

```
R₁/D₁ ≥ 1
  ⟺ u·[x₀y₀ + ρ(x₀+y₀)] ≥ xy + ρ(x+y)
  ⟺ u·x₀y₀·(1−v) + ρ·y₀·(u−v) ≥ 0,
```

两项**逐项**非负（`v ≤ 1`；`u ≥ v`）。∎
取等当且仅当 `u = v = 1`，即 `U = 0`。

脚本 STEP 3：33586 组随机样本，该表达式最小值 `+8.573e−04 > 0`。
脚本 STEP 4：2715 个全正行样本，`max(R₁/D₁,R₂/D₂) < 1` **0 例**（最小值 1.008511），
暴力 t 扫描（200001 点）的 ceiling **0 例** < 1（同一最小值 ⟹ 极限确实是 sup 的取值处）。

## 3. 「5 个结构相异的 χ₀」里有两个是同一个 χ₀

rpa-deep-dive 报 5 族 + 原族共 3026/3026。我用自己的实现重扫，发现其中两族零自由度：

| 族 | 与原族 `[[1.5,.2],[.2,.8]]` 的关系 | 逐点差 |
|---|---|---|
| **C** `[[1.5,−.2],[−.2,.8]]` | `b → −b`。所有承重量只经 `\|b\|` 与 `Δ = ac−b²` 进入 ⟹ **完全相同** | `max\|ΔR\| = max\|ΔD\| = 0.000e+00`（bit 级） |
| **B** `[[.8,.2],[.2,1.5]]` | `a ↔ c`。配上 `U₁ ↔ U₂` 即行置换；U 网格是**对称方格** ⟹ 扫的是同一个参数多重集 | 行交换后 `max\|ΔR\| = 8.8e−10`（舍入）、`max\|ΔD\| = 0.000e+00` |

⟹ 真正新增的只有 **A、D、E 三族**。「5 族异构」这句话的自由度是 3，不是 5。
**这是自由度相消事故的第 4 起**（前三起：填充因子循环量、MgB₂ 四个 `μ*_ij` 只有三个、
静态 `Re χ₀` 三条头条）。教训重复但形状新：这次相消的不是拟合标度，而是
**判据只经 `|b|` 进入 ⟹ 符号是规范**、以及**判据对指标置换等变 ⟹ 对称网格上置换不产生新点**。
> 派/收「换一组参数再扫一遍」型任务时，先问：**判据是这组参数的哪几个不变量的函数？**
> 这里是 `(a, c, |b|)` 的对称函数，所以 `b` 的符号与 `a,c` 的次序都不是自由度。

**逐族计数我与他们对不上**（我：orig 854 / A 1348 / D 890 / E 594；他们：854 / 744 / 403 / 281；
**唯独原族逐位相符**）。差异来源未定——大概率是「真失败点」筛选条件不同。
**但这一项已不承重**：§1 的证明覆盖全部参数，任何计数口径下反例集都是空集。
不追这条差异，记录在此以免日后有人把两套计数当成互证。

## 4. 判决：Route 2 关闭

二分法现在两侧都是 analytic：

| 半边 | 内容 | 档 |
|---|---|---|
| (⟹) 不可挽救 | 某行 `R_α < 0` ⟹ 任何正权重都救不了 | **analytic**（引理 (W)，任意 N） |
| (⟸) 可挽救 | 全部 `R_α > 0` ⟹ 存在权重使 ratio ≥ 1 | **analytic**（本笔记，N=2、`U ⪰ 0`） |

⟹ 「加权度量能救回什么」这个问题**有了完全的刻画**：
能救的恰好是「χ^RPA 每行仍对角主导、只是标准 `min` 选错了行」的点，一个不多一个不少。
具体权重方案（A/B/C 三案，最好的 B 只占 22.2%）是**工程问题**，不再是理论问题。

**没有关闭的**：N ≥ 3，以及非对角 `U`。§1 的证明用了 2×2 的显式逆，不直接推广。
**预算**：N≥3 的推广**不买通过也不买否决**——(⟹) 半边对任意 N 已经 analytic，
判决「Route 2 不可行」由它单独承担；(⟸) 半边只刻画「剩下那部分有多大」，
删掉它判决不动 ⟹ **预算 ∞，不派活**。想做的话它是纯数学趣味，不是路线需求。
