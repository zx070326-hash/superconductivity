**日期**：2026-09-22  
**发起**：主会话  
**背景**：Essenberger Eq.(37) 非对角逐元正断言（Im Λ^SF_{ij} > 0 for all i,j）是 FeSe 玻色层 (Z-dom) 判决里唯一既承重又仅有散文支撑的一步。三轮调研确认：RPA 层次无解析 no-go 定理，仅有 0/23000+ 数值证据。

## 方向 1：RPA 对角主导的解析证明

### 目标
证明（或给出条件定理）：RPA 近似下，Lindhard χ₀ 的对角主导性通过迭代保持或增强，使得"负非对角 + PSD 同时成立"结构性不可能。

### 三条路线

#### 路线 1A：粒子-空穴对称性传递（最有希望）

**核心想法**：证明对角主导度量 `D := min_α (χ_{αα} - ∑_{β≠α}|χ_{αβ}|)` 通过 RPA 迭代非递减。

**技术步骤**：
1. 定义对角主导度量（Gershgorin 型）
2. 证明：`D[χ^RPA] ≥ κ·D[χ₀]` 对某个 κ>0
3. 利用 Lindhard 在费米面的 `D[χ₀] ~ N(E_F)`

**需要的引理**（可能可证）：
- `(Uχ₀)^n` 的矩阵元如何依赖 n？
- 对角 vs 非对角的传播因子比值
- Gershgorin 圆盘定理的动力学版本

**文献入口**：
- Altland & Simons, *Condensed Matter Field Theory*, Ch. 7
- 仓库加权 Schur 定理（类似结构）
- Perron-Frobenius 定理（非负矩阵迭代）

**交付物**：
- 若成功：定理陈述 + 完整证明（analytic）
- 若受阻：技术障碍报告 + 数值反例搜索

**时间估计**：2-4 周

---

#### 路线 1B：静态极限的显式界

**已知**：静态 χ(q,0) = ∫dω χ(q,ω)/ω 平滑了动力学细节。

**策略**：
1. 在 ω=0 处展开 Dyson 方程：
   ```
   χ(q,0) = χ₀(q)[1 + U·χ₀(q) + (U·χ₀(q))² + ...]
   ```
2. 每一项是矩阵多项式 → 用 Perron-Frobenius / Gershgorin 追踪对角优势度

**优势**：不涉及频率积分，纯线性代数。

**劣势**：只覆盖静态极限（但 Essenberger 用的恰好是静态 Im χ）。

**交付物**：
- 静态 χ(q,0) 的对角主导条件定理
- 适用范围：U < U_c（Stoner 阈值以下）

**时间估计**：1-2 周

---

#### 路线 1C：数值辅助的形式推导

**混合策略**：
1. 用数值逐项验证 RPA 级数前 n=0,1,2,3 项的对角主导传递
2. 从数值中反向工程解析不等式
3. 用符号计算验证推广

**工具**：
- `sympy` 做前几项符号展开
- `mpmath` 高精度数值在边界情况
- 从数值"猜"解析界 → 归纳法证明

**交付物**：
- 半 analytic 结果（数值启发的证明）
- 或：明确的反例（负非对角 + PSD 构造）

**时间估计**：2-3 周

## 方向 2：深挖 Essenberger 非对角逐元正机制

### 目标
验证或证伪 Essenberger Eq.(37) 的 Im Λ^SF_{ij} > 0（逐元，含非对角），并追踪物理机制。

### 三条路线

#### 路线 2I：RPA χ^s 符号结构调查（★★★★★，已校正范围）

**⚠ 任务范围校正（2026-09-22）**：
- **原计划错误**：验证 Essenberger Eq.(37) Im[Λ^SF_{ij}] > 0
- **技术障碍**：Λ^SF ≠ χ^s，需要完整 SCDFT 框架（f^xc + 自洽场，2-3 周）
- **校正后目标**：验证 **RPA 层次的 χ^s_{ij}** 符号结构（1-2 天可行）
- **科学价值**：区分"RPA 结构约束"vs"SCDFT 顶角修正效应"

**已知信息**（from 2026-09-21 笔记）：
- Essenberger 1411.2121 + 1409.7968 全程用 2×2 带结构（Γ 空穴 / M 电子）
- 三通道（声子/自旋涨落/库仑）全是 2×2 矩阵
- 参数组在引用的 Kemper NJP 2010 或 Maier PRB 79, 134520 (2009)

**关键检验点**：

#### 路线 2II：追踪反铁磁矢量 Q 的作用（物理机制）

**物理图像**：
```
铁基超导自旋涨落峰化在 Q_AFM ≈ (π,0)
不同轨道费米面被 Q_AFM "连接"（嵌套）
⟹ χ^s_{αβ}(Q_AFM) 都看到同一个峰
⟹ 可能都是正的（相干增强，无干涉抵消）
```

**技术验证**：
1. 画 χ^s_{αβ}(q) 在布里渊区的符号图（所有轨道对）
2. 识别哪些 q 给负非对角
3. 与费米面嵌套函数比较：
   ```
   ξ_{αβ}(q) = ∫ dk δ(ε_α(k)) δ(ε_β(k+q))
   ```
4. 检验假说：负非对角 ⟺ 嵌套度 ξ_{αβ}(q) 接近 0

**可能的发现**：
- 逐元正 ⟺ 费米面"全局嵌套"（所有轨道对都被 Q_AFM 连接）
- 这是铁基超导的特殊性质，不是 RPA 通用结果
- 在单轨道（铜氧化物）或其他材料上可能不成立

**交付物**：
- 费米面图 + 嵌套度热图
- 符号结构与嵌套度的定量关联
- 物理机制综述（analytic 推理 + numerical-evidence）

**时间估计**：1-2 周（依赖路线 2I 的数值）

#### 路线 2III：从 SCDFT 顶角修正反推（深层机制）

**疑点**：Essenberger 用 SCDFT（超导密度泛函理论），不是裸 RPA。

SCDFT 的 Λ^SF 包含：
```
Λ^SF = 2∬ f_xc · χ · f_xc  （Eq.(32) 夹心形式）
```
其中 `f_xc` 是交换-关联核。

**已知（2026-09-21 调研）**：
- ALDA f_xc 在 r_s~2-3 符号不定（交换负、关联正）
- Eq.(32) 同余推断已撤回

**替代假说**：
- Eq.(32) 是近似表达
- 真正的 SCDFT Λ^SF 来自自洽场迭代
- 迭代过程"筛选掉"负非对角？

**验证方法**：
1. 运行 SCDFT 代码（需要 `libxc` + 超导扩展）
2. 逐步输出 χ 和 Λ^SF
3. 看迭代如何改变符号结构

**交付物**：
- SCDFT 自洽迭代的符号演化
- 顶角修正对非对角元的影响定量分析

**时间估计**：2-3 周（需要 SCDFT 代码环境，技术门槛高）
