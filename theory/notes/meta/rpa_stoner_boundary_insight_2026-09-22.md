## 关键发现

通过 Worker 1 的收缩率分析意外发现：**对角主导保持与 RPA 收敛性是同一件事**。

### 物理图像

在 ρ(χ₀U) 的两侧，系统行为截然相反：

| 条件 | RPA 行为 | 关联系数 r_n | 对角主导 | 物理意义 |
|------|---------|------------|---------|---------|
| **ρ < 1** | 收敛 | r_n → 0（几何衰减） | 增强 | Stoner 稳定 |
| **ρ = 1** | 临界 | r_n → r_crit | 临界 | Stoner 阈值 |
| **ρ > 1** | 发散 | r_n → 1（几何增长） | 丧失 | 铁磁不稳定 |

**物理解释**：
- ρ < 1：自旋涨落被抑制，系统趋向"更对角"（轨道解耦）
- ρ > 1：自旋涨落失控放大，不同轨道间相干性发散 → 铁磁相变

### 数学机制

定义相关系数：
```
r_n := max_{α≠β} |χ^(n)_{αβ}| / √(χ^(n)_{αα} · χ^(n)_{ββ})
```

**猜想**（待 Worker 1 数值确认）：
```
r_{n+1} / r_n ≈ ρ(χ₀U)  （当 n → ∞）
```

即：收缩率由谱半径控制。

**推论**：若猜想成立，则
```
r_n ≈ r_0 · ρ^n → 0  （当 ρ < 1）
```

这是**指数收敛**到完全对角矩阵。

## 对证明策略的影响

### 修正后的目标定理

**定理 A′（RPA 对角化，条件版）**：设 χ₀ ⪰ 0 对角主导，U > 0 对角，且 ρ(χ₀U) < 1。则：

1. **RPA 收敛**：χ^RPA = χ₀(1 - Uχ₀)⁻¹ 良定义
2. **相关系数收缩**：r[χ^RPA] ≤ r[χ₀] / (1 - ρ)  （某个函数形式）
3. **对角主导增强**：D[χ^RPA] > D[χ₀]

**前提 ρ < 1 不是技术限制，是物理必需**：RPA 本身只在 Stoner 稳定区有意义。

### 为什么这更好

原计划是证明"对角主导保持"（D[χ^RPA] ≥ κ·D[χ₀]，某个 κ>0）。

现在的结果是：
- **更强**：不是"保持"，是"增强"（D 严格增大）
- **更清晰**：物理边界明确（ρ=1 是 Stoner 阈值）
- **可计算**：κ 可以从 ρ 显式算出（一旦 Worker 1 确认 r_{n+1}/r_n ≈ ρ）

### Essenberger 应用

Essenberger 用的 FeSe 参数必然满足 ρ < 1（否则铁磁，与实验矛盾）。

所以我们的条件定理**直接适用**于他的场景，且给出的是"逐元正难以共存负非对角+PSD"的结构性理由。

## 技术笔记

### 为什么最初的测试用例都在 ρ > 1？

Worker 1 的脚本用了"自然"参数（χ₀ 对角元 ~1，U ~1–3）。这恰好落在 ρ > 1。

**教训**：探索性数值应该**先扫参数空间边界**（ρ=0.1, 0.5, 0.9, 1.5），再填内部。

### Perron-Frobenius 类比

仓库 P4 的引理 M 用了"非负矩阵 → 最大本征值单调"。

我们这里是"Gram 矩阵 → 相关系数收缩"。

两者都是**正性结构的传递定理**，但传递的对象不同：
- P4：本征值（谱量）
- RPA：相关系数（几何量）

可能存在统一框架（算子单调函数？），但不是当前优先级。
