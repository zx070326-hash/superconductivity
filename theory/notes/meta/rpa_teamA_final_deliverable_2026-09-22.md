## 核心科学发现

### Perron 稀释机制 (analytic)

**定理**: 对于对称矩阵 χ₀ = c·I + c_off·(J-I)，Perron 本征向量对对角主导的净贡献恒为零。

**证明**: 
Perron 本征向量 v_P = (1,1,...,1)/√N，分量完全均匀。

对位置 α 的贡献：
- 对角: (v_P·e_α)² = 1/N
- 每个非对角: (v_P·e_α)(v_P·e_β) = 1/N  (β≠α)

净贡献 = 1/N - (N-1)×1/N = 0  □

**物理图像**:
- RPA 增强因子: λ/(1-uλ)
- Perron 本征值 λ_N = c+(N-1)c_off **线性增长于 N**
- Perron 增强因子最大，但净贡献为零
- 非 Perron 模式(真正增强对角主导) 被稀释

**数值验证** (N=2-5):
- Perron 净贡献 = 对角 - (N-1)×非对角 = 0 (精度 < 1e-15)
- 退化比值: N=2 → 1.21, N=3 → 0.61, N=4 → 0.37, N=5 → 0.25

## 技术路线探索

### Route 1: Perron-Frobenius + 本征向量追踪

**目标**: 从谱分解推导解析界

**成果**:
1. ✓ Perron 机制完全理解 (analytic)
2. ✓ 显式公式推导:
   ```
   D[χ^RPA]/D[χ₀] = [(c-c_off)/(1-ρ_min) - (c+(N-1)c_off)/(1-ρ_max)] 
                     / [c-(N-1)c_off] · (N-1)/N
   ```
3. ✗ 代数界 C/N 的严格证明受阻

**技术障碍**: 
- 分子是两项之差，符号分析需要精细不等式链
- 分母通过 c_off 依赖 N，直接界定困难
- 不等式在多个约束下纠缠

### Route 2: 加权度量

**目标**: 定义 D_w[M] 使 Perron 贡献被权重抵消

**尝试的权重方案**:
- 方案 A: w_α = 1/χ₀,αα (逆对角元)
- 方案 B: w_α = 1/(v_P·e_α)² (Perron 权重)
- 方案 D: w_α = [非Perron权重]/[Perron权重]

**结论**: 
- 对称情况: 所有方案退化为标准度量（常数权重）
- 非对称 + 均匀 U: 方案 A 不改变比值（瓶颈行决定）
- **在 U=u·I 约束下，加权度量无法突破标准度量**
