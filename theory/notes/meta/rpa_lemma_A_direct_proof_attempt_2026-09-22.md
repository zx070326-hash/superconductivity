# 引理 A 直接证明尝试：相关系数单调性

**日期**：2026-09-22 晚  
**状态**：技术推导（探索性）  
**目标**：证明 r[(χ₀U)χ] ≤ ρ·r[χ] 对任意 χ ⪰ 0

---

## 问题诊断

**当前障碍**：Cauchy-Schwarz 只给了分子界：

```
|(χ₀Uχ)_{ij}| ≤ √[某东西涉及 i] · √[某东西涉及 j]
```

但相关系数需要：

```
|(χ₀Uχ)_{ij}| / √[(χ₀Uχ)_{ii} · (χ₀Uχ)_{jj}] ≤ ...
```

分母 (χ₀Uχ)_{ii} 也变了，不能直接和原来的 χ_{ii} 比。

**核心困难**：需要同时控制分子和分母的变化。

---

## 尝试 1：矩阵元比值的直接界

设 A = χ₀U，χ' = Aχ。需要证明对所有 i≠j：

```
|χ'_{ij}| / √[χ'_{ii} · χ'_{jj}] ≤ ρ · |χ_{ij}| / √[χ_{ii} · χ_{jj}]
```

展开：

```
χ'_{ij} = Σ_k a_{ik} χ_{kj}
χ'_{ii} = Σ_k a_{ik} χ_{ki}
```

其中 a_{ik} = (χ₀)_{ik} u_k。

**观察**：a_{ik} 本身有 Gram 结构（Cauchy-Schwarz 自动成立）。

但这还不够——需要更强的性质。

---

## 尝试 2：Schur 乘积视角

Hadamard (逐元) 乘积保持正半定性。但这里不是 Hadamard 乘积，是普通矩阵乘法。

**失败**。

---

## 尝试 3：算子单调函数

考虑函数 f(χ) = max_{i≠j} |χ_{ij}|² / (χ_{ii}·χ_{jj})

需要证明：f(Aχ) ≤ ρ² · f(χ)

这要求 f 在某种意义下关于 A 是收缩的。

**问题**：f 不是算子单调函数（它不是迹形式）。

---

## 尝试 4：静态极限特殊化（Route 1B 退守）

若 χ₀ 和 χ 都是**实对称**矩阵（静态极限，ω=0），且 U 对角正，则：

**引理 B (静态极限版)**：χ₀, χ ⪰ 0 实对称，U 对角正，ρ(χ₀U) < 1。则：

```
r[χ₀Uχ₀] ≤ ρ · r[χ₀]
```

**证明思路**：实对称情况下可以用**谱分解** + Perron-Frobenius 类论证。

χ₀ = Σ_k λ_k v_k v_k^T （正交分解）

则 χ₀Uχ₀ = Σ_{k,ℓ} λ_k λ_ℓ (v_k^T U v_ℓ) v_k v_ℓ^T

**关键观察**：U 是对角正 ⟹ 它在正交基下的作用"更对角"。

但展开后仍然复杂……

---

## 尝试 5：加权内积空间的算子范数

定义加权 ℓ² 范数：

```
‖v‖²_U := Σ_α u_α |v_α|²
```

则 χ₀U 可以写成：χ₀U = U^{1/2} (U^{1/2} χ₀ U^{1/2}) U^{-1/2}

令 B := U^{1/2} χ₀ U^{1/2}，这是**对称**矩阵（若 χ₀ Hermitian）。

则 χ₀U 与 B 相似，‖χ₀U‖ = ‖B‖ = ρ(B) = ρ(χ₀U)。

**引理 C**：对标准正交基 {e_i}（在 ‖·‖_U 意义下），

```
|⟨e_i, B e_j⟩_U| / √[⟨e_i, B e_i⟩_U · ⟨e_j, B e_j⟩_U] ≤ ...？
```

**困难**：{e_i} 在标准基下不是正交的；换基后的相关系数定义不清楚。

---

## 诊断：为什么这么难？

**根本问题**：相关系数 r[χ] 不是**矩阵范数**，也不是**迹多项式**。

它是一个**非线性几何量**（角度的余弦）。

已知的算子不等式（Cauchy-Schwarz、Hölder、矩阵凸性）都是关于**线性泛函**或**迹**的。

相关系数的非线性使得它**不直接继承**这些不等式。

---

## 可能的出路

### 出路 A：条件定理（χ₀ 的特殊结构）

若 χ₀ 本身有某种**对角优势结构**（如 |χ₀_{ij}| ≤ c·√[χ₀_{ii}·χ₀_{jj}] 对某 c < 1），

则可能通过**显式计算**证明乘以 U 后 c 变小。

**问题**：这是循环论证（我们想证的就是这个）。

### 出路 B：静态极限 + 实对称（Route 1B）

限制到 ω=0，所有矩阵实对称。这时可以用**谱分解** + **Perron-Frobenius 方向**。

Essenberger 的 Eq.(37) 用的就是静态极限，所以这个限制**对应用无影响**。

**优点**：技术上更可行
**缺点**：定理范围窄（但够用）

### 出路 C：数值辅助的形式证明（Route 1C）

用 sympy 展开小矩阵（2×2, 3×3）的相关系数比值，找到**显式不等式**。

然后猜测一般 N 的形式，用归纳法证。

**优点**：可能发现隐藏模式
**缺点**：不保证成功

### 出路 D：改证更弱的结论

不证 r[χ₀Uχ₀] ≤ ρ·r[χ₀]，改证：

```
‖χ₀Uχ₀‖_∞ ≤ ρ · ‖χ₀‖_∞
```

其中 ‖·‖_∞ 是**最大行和范数**。这个更容易（直接用三角不等式）。

然后从行和范数反推对角主导（不经过相关系数）。

**问题**：行和范数 → 对角主导 的关系不紧（会损失常数）。

## 下一步建议

**立即行动**：尝试选项 3（对角主导直接界）。

理由：这是**最直接**回答原始问题的路径，且技术上更可行。

**证明草图（选项 3）**：

设 χ ⪰ 0 对角主导，D[χ] > 0。设 A = χ₀U，‖A‖ ≤ ρ < 1。

则对任意 α：

```
(Aχ)_{αα} = Σ_k a_{αk} χ_{kα}
           ≥ a_{αα} χ_{αα} - Σ_{k≠α} |a_{αk}| |χ_{kα}|
```

而：

```
Σ_{β≠α} |(Aχ)_{αβ}| = Σ_{β≠α} |Σ_k a_{αk} χ_{kβ}|
                      ≤ Σ_k |a_{αk}| Σ_{β≠α} |χ_{kβ}|
```

若能证明：

```
对角项增长 > 非对角项增长
```

则 D[Aχ] ≥ (某正常数) · D[χ]。

**这条路看起来可行！** 因为我们有 χ 的对角主导假设 + A 的谱半径界。
