## 关键发现

### 1. 对称情况的解析证明

**引理 2.1**：若 c₁₁ = c₂₂ = c，u₁ = u₂ = u，则：

```
D[χ^RPA] = D[χ₀] / (1 - ρ)
```

其中 ρ = u(c + |c₁₂|)。

**证明要点**：利用因式分解

```
(1 - uc)² - u²c₁₂² = (1 - uc - u|c₁₂|)(1 - uc + u|c₁₂|)
```

得到对角主导严格增强（比值 = 1/(1-ρ) > 1）。

### 2. 临界条件数的精确定位

固定 c22=0.8, c12=0.2，改变 u：

| u | ρ_c | κ_c |
|---|---|---|
| 0.20 | 0.3625 | 2.2162 |
| 0.30 | 0.4751 | 1.9157 |
| 0.40 | 0.5664 | 1.6888 |
| 0.50 | 0.6453 | 1.5114 |
| 0.60 | 0.7176 | 1.3689 |
| 0.70 | 0.7873 | 1.2519 |

### 3. 函数拟合

**最优形式**（有理式）：

```
κ_c(ρ) ≈ 7.23 / (1 - 5.96·ρ)
```

残差平方和（倒数空间）：6.37e-04  
相对误差范围：0.29% – 3.03%

**物理解释**：
- ρ 小（弱耦合）→ κ_c 大（允许更大的非对称）
- ρ 大（强耦合）→ κ_c 小（要求更接近对称）

### 4. 2×2 反例发现

**参数**：χ₀ = [[1.5, 0.2], [0.2, 0.8]], U = diag(0.4, 0.4)  
**结果**：κ = 1.88, ρ = 0.62, D[χ^RPA]/D[χ₀] = 0.85（退化 14.7%）

**失效机制**：
- RPA 对强耦合轨道（c₁₁=1.5）增强更多：χ^RPA_{11} = 3.90（增强 2.6×）
- 对弱耦合轨道（c₂₂=0.8）增强有限：χ^RPA_{22} = 1.27（增强 1.6×）
- min 操作选中弱轨道 → 全局 D 由弱轨道主导 → 退化

## 技术障碍

### 为什么非对称情况困难？

1. **对称性破缺**：κ=1 时的因式分解在 κ≠1 时不再成立

2. **非线性耦合**：D[χ^RPA]_行2 包含 κ 和 ρ 的复杂交叉项，无法分离

3. **最小值操作**：两行增强率不同，min 操作放大非对称效应

4. **符号表达式复杂度**：临界方程无闭式解

### 可能的解析突破路径

**路径 A**：谱分解 + Perron-Frobenius  
χ₀ = λ₁v₁v₁^T + λ₂v₂v₂^T，跟踪本征向量混合。  
**难点**：对角主导不是本征值直接函数。

**路径 B**：加权度量  
定义 D_w[M] := min_α w_α(M_{αα} - Σ|M_{αβ}|)，权重 w_α ∝ 1/χ₀_{αα}。  
**可能性**：消除非对称增强率差异。

**路径 C**：更紧的 ρ 界  
寻找"对角主导保持"的充分条件 ρ' < ρ。
