## 1. FeSe 费米面嵌套的几何必然性

### 1.1 基本拓扑

**FeSe 二维简化模型**（Essenberger 等使用）：
- **Γ 点（BZ 中心）**：空穴费米面袋，主要轨道成分 d_xz, d_yz
- **M 点（BZ 角）**：电子费米面袋，主要轨道成分 d_xy
- **反铁磁矢量**：Q_AFM ≈ (π,0) 或 (0,π)

### 1.2 Q_AFM 的几何特殊性

**关键观察**：Q_AFM 是 Γ 空穴袋与 M 电子袋的**最短连接矢量**。

几何论证：
```
M 电子费米面：中心 (π,π)
平移 Q_AFM = (π,0)
→ 中心移至 (0,π)
```

由正方晶格对称性，(0,π) ≡ (π,0) 的费米面（旋转 90°）。

**结果**：
- Γ 空穴中心：(0,0)
- M 电子平移后中心：(π,0)
- 间距：π ≈ r_h + r_e（两费米面半径之和）

⟹ **Q_AFM 使两费米面接近或相切 → 嵌套度 ξ_{he}(Q_AFM) 最大**。

### 1.3 嵌套函数定义

```
ξ_{αβ}(q) := ∫ dk δ(ε_α(k)) δ(ε_β(k+q))
```

**物理意义**：轨道 α 与 β 的费米面（平移 q 后）的重叠度。

**FeSe 的特点**：
- ξ_{he}(Q_AFM) ~ O(ξ_{hh}(0))（同量级）
- ξ_{he}(q≠Q_AFM) ≪ ξ_{he}(Q_AFM)（全局最大）

## 2. 静态 vs 动力学：Team B 发现的意义

### 2.1 静态极限的失效（Team B 证明）

**Team B 关键发现**：
- 静态 Re χ(q,0) 在**所有 q 点**（256/256）都有负本征值
- RPA 改善率：0/256（从不改善）
- **结论**：裸 RPA 无法产生 PSD 静态磁化率

**对旧机制的否定**：
- ~~"静态 χ₀ 逐元非负 ⟹ RPA χ^s 逐元非负"~~（不成立）
- ~~"静态 χ^s(q,0) 全正"~~（证伪）

### 2.2 动力学框架的必要性

**正确的边界**：

| 量 | 符号性质 | 依据 |
|---|---|---|
| **静态 Re χ(q,0)** | 可以非 PSD | Team B 数值（100% 有负本征值）|
| **动力学 Im χ(q,ω>0)** | 必须 ≥ 0（PSD） | 涨落-耗散定理（analytic）|
| **频率积分 ∫dω Im χ** | Essenberger 声称全正 | 本节机制（§3）|

**涨落-耗散定理**（标准多体理论）：
```
Im χ(q,ω) = (1 - e^{-βω}) ∫dt e^{iωt} ⟨[S(q,t), S†(q,0)]⟩
```

因果性 + 能量守恒 ⟹ Im χ(q,ω>0) ≥ 0（处处成立，PSD）。

**关键区别**：
- 静态 Re χ(q,0) 可以有负本征值（Team B 证明）
- 但动力学 Im χ(q,ω>0) 必须 PSD（涨落-耗散定理）
- Essenberger Eq.(36) 用的是频率积分，不是静态值

## 3. 嵌套机制的真正作用：幅度增强

### 3.1 Lindhard 函数与嵌套度

**Lindhard 公式**（静态，T=0）：
```
χ₀_{αβ}(q,0) = ∫ dk [f(ε_α(k)) - f(ε_β(k+q))] / [ε_β(k+q) - ε_α(k)]
```

**嵌套度贡献**（定性）：
```
|χ₀_{αβ}(q)| ∝ ξ_{αβ}(q) / Δ_{αβ}
```

其中 Δ_{αβ} 是典型带间能级差。

**FeSe 的情况**：
- ξ_{he}(Q_AFM) 最大（几何必然，§1.2）
- ⟹ |χ₀_{he}(Q_AFM)| 最大
- ⟹ |Im χ(Q_AFM, ω)| 最大（RPA 进一步增强）

### 3.2 嵌套机制 ≠ 符号约束

**关键澄清**：

嵌套机制的作用：
- ✓ 解释**幅度**为何在 Q_AFM 处特别大
- ✗ **不能**解释符号为正（那来自涨落-耗散定理）

**机制分解**：
```
Essenberger Eq.(37) Im Λ^SF > 0 的机制
    ↓
符号约束：涨落-耗散定理（analytic，文献已知）
    +
幅度增强：Q_AFM 嵌套（analytical reasoning，本文）
    ↓
频率积分 ∫dω Im χ(Q_AFM, ω) 由 Q_AFM 主导
```

### 3.3 通用性

**机制依赖的物理性质**：
1. 反铁磁嵌套拓扑（Q_AFM 连接空穴与电子费米面）
2. 涨落-耗散定理（因果性）

**推论**：
- 所有铁基超导共享（LaFeAsO, BaFe₂As₂, FeSe 等）
- ⟹ Essenberger Eq.(37) 是铁基超导族的通用性质
- **不是 FeSe 特殊性**
