## 1. 审项 (i) · Layer 1「𝔎_c⪰0 ⟹ μ* 单调降 Tc」

### 1.1 白拿的部分（CONFIRMED）
- 𝔎_c=2|u⟩⟨u| 秩一 PSD 平凡；M(μ̃)=H−μ̃𝔎_c 对 μ̃ 算子序单调 ⟹ λ_k(M) 对每个 k 单调不增（min-max）。Stage B 620 检查 + 我方 N=300、N_c 穷举的 worst-N_c 真隙在 ϖ̄∈{0.6427,1,1.55,3}、μ̃∈{0,…,0.26} 单调不增（`rev_mutilde_cover.py`）。
- 束正定 ⟺ λ₁(M)<1/λ：I−λ𝔎_ph+μ*𝔎_c=I−λM，λ>0，等价严格（λ₁ 取谱上确界，含本质谱 0；λ₁≤0 时恒正定=无 Tc）。
- Z 通道无 μ*（Marsiglio eq.22，researcher A 级）—— 对称化模型内无隐藏非 PSD 通道。

### 1.2 被吞掉的部分：N_c(T) 的阶梯（DOWNGRADE，需定义修正）
证书把 (ϖ̄,N_c) 当独立参数、对 N_c 取 inf，所以证书不受影响（inf 支配物理路径）。但 Layer 1 谈的是 Tc，Tc 沿物理路径 N_c=N_c(T)：`rev_layer1_Tc.py` L1 段，N=200/400：

### 1.3 N_c 取整约定（非承重，措辞）
u_n=𝟙_{n<N_c} 配 |ω_n|<ω_c 应为 N_c=⌊ω_c/2πT+½⌋，文档写 ⌊ω_c/2πT⌋（即 |ω_n|<ω_c+πT）。小窗口差 1（ω_c/ω_E=3、ϖ̄=0.3：0 vs 1），O(1/N_c) 之说在 N_c≈3 时是 30%。证书 N_c 穷举不受影响；Tc 求解器/Stage G 的物理读法须写明用哪个。

## 2. 审项 (ii) · 谱隙路线 + U8 边界 ϖ̄_min

### 2.1 推导链逐条（CONFIRMED）
- α 侧继承 λ_k(M)≤λ_k(H)：K_c⪰0 ⟹ M⪯H，min-max 对任意 k ✓；λ₂(M)≤λ₂(H)≤α，α 无 μ̃、N_c 依赖 ✓。Stage B(iii) 数值 ✓。

- 三 case 穷尽：2×2 块只见 min(N_c,2)∈{0,1,2} ✓。case 0 ⪰ case 2 由算子序，但 case 1 vs 2 之差 2[[0,1/√3],[1/√3,1/3]] 不定，故三 case 都要算 ✓（脚本取 min）。

- k-sign 机制 soundness：v 固定为 M₂_case(a) 顶本征向量，Q(w)=Σk_i⟦i⟧(w)−C（库仑项 w-无关、常数）；k_i≥0 ⟹ Q 增 ⟹ Q(w)≥Q(a)=λ₁(M₂_case(a)) ✓。逻辑缺口：要让 min_case λ_case(a) 成为整个 cell 上对所有 case 的下界，需要每个 case 的 k-sign 都合格（λ_c(w)≥λ_c(a) 用的是 case c 自己的 v），而 `mu2_pencil_cell` 只返回最优 case 的 k-sign。数值上无害：保留 cell 上三个 case 全部合格（min k：0.0154@0.1、0.0168@0.13，`rev_ksign_truegap.py` (A)）；更强，`rev_ksign_counterex.py` 扫 μ̃∈{0.05…1.0}×300 个 a，1781 个"最优 case 合格"的 cell 里没有一个其它 case 失败、零违反 ⟹ 反例不存在。建议改成三 case 都检（或用 §2.3 的无 sign 界，结果全同）。

裁决 (ii)：soundness CONFIRMED（承重，可信）；「k-sign 定 ϖ̄_min」与「ϖ̄_min 是真算子性质」两句 DOWNGRADE。若想把 ϖ̄_min 推向真边界，要改的是 α 侧（小 ϖ̄ 处头块/尾包络），不是 μ₂ 或 k-sign；但真边界只低 0.1，不值得，如实措辞即可。

- 但 (λ,μ*) 与 ϖ̄_c 必须配对看：ω_c=10ω_E、`rev_layer1_Tc.py`：λ=0.7、μ*=0.13 → ϖ̄_c=4.56（Tc/ω_E=0.035），μ̃=0.186、ϖ̄_min≈0.84 ≪ 4.56 ✓；λ=0.7、μ*=0.2 → [0.3,5] 内无根；λ=1、μ*=0.13 → ϖ̄_c=2.20 ✓；λ=2、μ*=0.13 → 0.98 ✓（μ̃=0.065、ϖ̄_min≈0.4）。⟹ λ<1 角落 binding 的是上端 5 与 Tc 是否存在，不是 ϖ̄_min；「ϖ̄≈1–1.6」是 λ≥2 氢化物的数（那里 μ̃≤0.065）。文档把两组参数混在一句里。

裁决 (iv)：CHALLENGED → 免费可闭。修法：(a) 写入 §4.2 覆盖引理（一行算子序）；(b) 加节点 μ̃=0.26（ϖ̄_min=1.1686、inf g 0.0036，本机 <1 min）覆盖 λ≥0.5、μ*≤0.13；(c) 把 U8 的物理区间声明改成按 (λ,μ*)→(μ̃,ϖ̄_c) 配对表述；(d) 若要 λ<1 的 Tc 上界，需把区间上端从 5 外推（OPEN）。
