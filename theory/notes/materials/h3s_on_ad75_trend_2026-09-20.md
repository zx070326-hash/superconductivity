## 2. ω_log 的同位素伸缩关系 [analytic]

谐波均匀质量替换 ω → s·ω（s = √(M_H/M_D) = 1/√2）下：

- **λ 不变**（Hopfield 求和规则，`deficit_budget_h3s_2026-09-17.md` §3 已证）
- **ω̄₂ → s·ω̄₂**（二阶矩线性伸缩）
- **ω_log → s·ω_log**（对数平均 = exp⟨ln ω⟩，在伸缩下同步）

⟹ 从 H3S-200 的 ω_log = 109.995 meV 推导：

```
D3S-200 ω_log = (1/√2) × 109.995 = 77.778 meV
```

**交叉验证**：ω̄₂(D)/ω̄₂(H) = 105.43/149.26 = 0.706351，理论值 1/√2 = 0.707107，
偏离 0.11%（反映 SSCHA 非谐对均匀伸缩的修正，`deficit_budget_h3s_2026-09-17.md` §3 已记录）。

## 3. 约定对齐审计 [analytic]

**关键问题**：AD75 的 ω_log/ω̄₂ 与氢化物文献的 ω_log/ω̄₂ 是否同一定义？

### 3.1 AD75 Eq.(2.10)-(2.12) 定义

```
ω_log = exp[(2/λ) ∫ ln(ω) α²F(ω)/ω dω]
ω̄₂²   = (2/λ) ∫ ω α²F(ω) dω
```

### 3.2 氢化物文献约定

- **hydrides_theory.csv 表头**：明确写 `omega_log_meV` 和 `omega_2_meV`
- **notes 列**（第 2–3 行）：引用 "Allen-Dynes 1975 第二矩"
- **仓库 README.md**（`theory/data/README.md`:31-38）：
  ```
  ω̄₂² = (2/λ)∫α²F(ω)·ω dω（Allen-Dynes 1975 定义）
  ```

⟹ **约定与 AD75 完全一致**，可直接代入回归式，无需换算。

## 9. 与「𝔣 ≈ 0.5 普适」主张的关系

`deficit_factor_f_headline_2026-09-20.md` 的核心发现：

> **「𝔣 ≈ 0.5 普适」被证伪**：AD75 Table I 的 29 行给出 𝔣 ∈ [0.1994, 0.6102]（3.06× 跨度）。
> 但两变量回归 `log 𝔣 = f(log λ, log(ω_log/ω̄₂))` 解释 R² = 0.96，残差散布 7.94%。

本笔记的结果：

- H3S/D3S 的 𝔣 = 0.49/0.50 **不是一个新的「普适常数」**，
  而是它们恰好落在 λ ≈ 1.7–1.8、shape ≈ 0.74 这个参数区域，
  该区域在 AD75 回归式下给出 𝔣_pred ≈ 0.47–0.49。

- **H3S/D3S 与 AD75 隧道材料共享同一条趋势**，
  而不是「氢化物有一套、隧道材料有另一套」。

- 推论：要提高 𝔣（逼近天花板），材料设计需要**同时**：
  1. 增大 λ（朝渐近区走）
  2. 窄化谱（提高 ω_log/ω̄₂，逼近 Einstein 极值谱）
  
  两者缺一不可（两变量回归的 R² = 0.96 vs 单变量 λ 的 R² = 0.91）。

### 11.5 副产物：同位素伸缩的一手证据
