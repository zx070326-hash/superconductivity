## 0. 撤回什么，凭什么

头条回归有**两个模型阶**，它们的 `b` 是**不同的参数**：

| 模型 | 形式 | `b` 的含义 |
|---|---|---|
| 线性 | `log𝔣 = a + b·L + c·Σ` | 样本**平均**斜率 |
| 二次 | `log𝔣 = a + b·L + c·Σ + q·L²` | **λ=1 处**的斜率 |

（`L := logλ`，`Σ := logS`，`S := ω_log/ω̄₂`。）

我先前把**理论的二次 `b` = +1.1745** 与**数据的线性 `b` = +0.9972 ± 0.0405** 相比，报了「4σ 未解释」。
同一份 AD75 29 行数据，两套拟合从零重算（脚本 §0 两道门都断言复现仓库既有数）：

    线性  a = −1.0691   b = +0.9972 ± 0.0405   c = +0.7198 ± 0.1282              R² = 0.9592  s = 0.0794
    二次  a = −1.0003   b = +1.2384 ± 0.0419   c = +0.8034 ± 0.0768   q = −0.5253 ± 0.0749   R² = 0.9863  s = 0.0470

**换模型阶让同一份数据的 `b` 移动 +0.2412 —— 恰是我报的那个「缺口」的量级。**
⟹ 缺口是错配造出来的，不是物理。

## 2. 技术偏置闭式补全：`c` 是逐位免疫的 [analytic]

偏置模型（data = 隧道反演的 AD75，theory = Eliashberg）：

    logλ_D      = L_T + (r₀ + r₁L_T)
    logω̄₂_D    = logω̄₂_T   + (s₀ + s₁L_T)
    logω_log,D  = logω_log,T + (u₀ + u₁L_T)
    logTc_D     = logTc_T                      ← Tc 是技术无关的

⟹ `L_D = (1+r₁)L_T + r₀`，`Σ_D = Σ_T + (u₀−s₀) + (u₁−s₁)L_T`，`y_D = y_T − ½ρ − σ`，于是

| 系数 | 闭式 | 免疫性 |
|---|---|---|
| `q` | `q_D = q_T/(1+r₁)²` | 完全平方 ⟹ **符号**免疫 |
| `c` | **`c_D ≡ c_T`** | **对 r₀,r₁,s₀,s₁,u₀,u₁ 六参数逐位免疫** |
| `b` | `b_D = [b_T − c_T(u₁−s₁) − ½r₁ − s₁]/(1+r₁) − 2q_T·r₀/(1+r₁)²` | 无 |
| `a` | 纯偏移下 `Δa = −(b_T+½)r₀ − c_T(u₀−s₀) − s₀ + q_T r₀²` | 无 |

七组随机参数、无噪声恒等式，三道 `1e-10` 断言全过（脚本 §A）。
**仓库旧式缺 `−c_T(u₁−s₁)/(1+r₁)`**——它在 `u₁=s₁`（`S` 无偏）时消失
⟹ 旧式是**特例不是错，但那个前提此前没写下来**。

> **★ 承重排序由此确定：`c` > `q` > `b` > `a`。**
> `c` 的相合**不能**被「隧道反演有系统误差」解释掉（逐位免疫）；
> `q` 只有符号免疫；`b` 无免疫；`a` 三个偏移全进。

## 3. `a` 缺口：三条候选，都不排他

`a_data < a_theory` 意味着**理论（用氢化物谱）的 𝔣 比 AD75 族高 13.8%**。

**(i) 残余形状自由度——方向对，只买 21%。**
在**同一 (λ, S)** 上把每条氢化物谱与通用形状（双峰 `x ∈ {0.30…0.75}` + 矩形块）对比
（组内 λ/S 命中 ≤6.8e−09）：

    𝔣(氢化物)/𝔣(通用形状)：36/36 格**全部 > 1**，四谱×九 λ 几何均 = 1.0271（+2.7%）
    需要的是 +13.8% ⟹ 覆盖率 0.21×

⟹ 氢化物**确是**高 𝔣 形状（方向可证伪、没被证伪），但量级不足，主因另有其他。
⚠ 「通用形状」是我选的，不是 AD75 那 29 个材料的真实 α²F ⟹ 本测量给的是方向与量级，
不是「氢化物 vs AD75 族」的直接测量。

**(ii) `r₀`（λ 的纯偏移）——能补满，且 `b` 是零自由度的预言，检验通过。**
三个纯偏移里**只有 `r₀` 同时进 `a` 和 `b`**（§2 闭式）。
⟹ 拿 `a` 定 `r₀`（1 自由度），`b` 就是**零自由度预言**（1 检验），且这是一次**可以失败**的检验。
