## 1. ① 旧陈述错在哪

t5 §4.1 印出 13 个 `𝔣/𝔣_E > 1`（最大 NaS2Rh 1.001246），判为「数值伪影」，
理由逐字是「0.01–0.13% 远小于 N=400 截断的预期误差（~0.1–0.5%）」。
**那个「预期误差」是断言的，从未实测**——与 t5 上一轮被订正的缺陷同形。
我去实测它，结果发现被比较的两个对象本身就不成立。三条缺陷各自独立：

### 缺陷 A —— 两侧解的不是同一个方程

`solve_eliashberg_isotropic`（实谱侧）走 **AD75 完整对称矩阵**、判据「最大本征值 = 0」。
`solve_einstein_tc`（参考侧）走的却是 **对角单模**判据 `max_n K_nn = 1`，
且 `K_nn` 写成 `(π/T)·λ_n/(2ω_n)` —— **`T` 在分母**，而松原核里 `T` 在分子（`πT·λ_n/(2ω_n)`）。

### 缺陷 B —— 参考侧的 `Tc_E` 与 Einstein 频率无关（第五起「先数自由度」事故）

把缺陷 A 的分母倒置代进去，判据退化为 `λ_0(T)/(2T²) = 1`，低温解 `T = √(λ/2)` [meV]
⟹ **`ω̄₂` 一个字都没进来**。实测（`_chk_t5_einstein_solver_audit`）：

**判决方向（单边界规则）**：缺陷 C 使 `Tc` 被**低估**（返回 1e−12 而非真值）。
`Tc ≤ 天花板` 是**上界**判据 ⟹ 低估只会让它更容易 PASS。
所以 §4.3 的「0/249 违反」正是仓库规则里**只能产出「过」的那种单边行**，不构成任何确证。
**方向审计的结论是：这些 PASS 不可引用；但它们也不指示任何 FAIL。**

**什么仍然成立**：§4.3 里不经过 `Tc` 的部分完全不受影响——

`m ≡ 2s/λ` 是恒等式。闭式 `0.63173√(λ/s)` 我已从零复现（最大偏差 3.0e−6）。

## 3. 新结果：固定 `N` 的可解 λ 下限 `λ_c(N)`

上面「有的材料任何 N 都解不出、有的一解就收敛」的干净二分，不是巧合。

**机制**：`T→0` 时所有 `λ_l → λ`，AD75 矩阵塌成
`M = 2λ·J + diag(λ − (2n+1) − 2nλ)`。
取秩一试探 `v_n ∝ 1/[(2n+1)(1+λ)]`，过零条件为
`(λ/(1+λ))·2Σ_{m<N} 1/(2m+1) = 1`，配 `Σ_{m<N}1/(2m+1) = ½(ln N + 2ln2 + γ) + O(1/N)`：

> **`λ_c(N) = 1 / (ln N + 2ln2 + γ − 1)`**

物理读法：**固定 `N` 时可取的库珀对数只有 `ln N`，不是 `ln(ω/T)`**——
松原窗口 `[ν_0, ν_N]` 在低温下整体缩小，**永远够不到声子标度**。

**数值确认**（`T→0` 极限下直接二分求 `λ_c`，与上式比）：

| N | λ_c 实测 | λ_c 预言 | 比值 |
|---|---|---|---|
| 50 | 0.205105 | 0.205106 | 1.0000 |
| 100 | 0.179576 | 0.179576 | 1.0000 |
| 200 | 0.159698 | 0.159698 | 1.0000 |
| 400 | 0.143782 | 0.143782 | 1.0000 |
| 800 | 0.130751 | 0.130751 | 1.0000 |
| 1600 | 0.119886 | 0.119886 | 1.0000 |

**与 t5 数据集的独立对照**：batch-q 在 N=400 下，
求解失败的行 **全部** `λ ≤ 0.1380`，成功的行 **全部** `λ ≥ 0.1442`。
`λ_c(400) = 0.143782` **恰落在这个空隙里**。
⟹ 那道「通过/失败」的分界线是**截断**画的，**零材料信息**。

**后果（承重）**：`λ_c` 只随 `ln N` 退，要覆盖 batch-q 的最小 `λ = 0.0202` 需
`N = exp(1/0.0202 + 1 − 2ln2 − γ) ≈ **1.21e21**。
⟹ **松原矩阵对角化在弱耦合端不是「精度不够」，是结构性不可达。**
Cerqueira 6912（λ 中位 0.093）**整体**落在这条线以下，
任何「直接解 Eliashberg 再比天花板」的路线在该数据集上都不可行——
与已记录的「Cerqueira 6912 太弱耦合、天花板检验空洞」结论一致，但这里给出了**定量的理由**，
且理由与原先记的（「Tc 太小、float64 到精度边缘」）**不同**：真正的障碍是截断对数，不是浮点精度。

**严格性**：`λ_c(N)` 闭式的推导用了秩一试探与调和和渐近，**不是定理**；
它在 N ∈ [50,1600] 上与实测相对差 ≤1e−4。
⟹ 标 **numerical-evidence（附解析推导草稿）**，**不得简称 analytic**。
