## 1. Eq.(1a-c) 定义（核对来源）

`arXiv:2307.10728` HTML 全文抓取到的原句（WebFetch 转述，非逐字 PDF，但与 `McMillan.dat`
文件头列出的物理量名称、以及 `theory/data/README.md` 已经记录的定义一致，属交叉验证）：

- λ = 2∫[α²F(ω)/ω]dω
- ln ω_log = (2/λ)∫[α²F(ω)/ω] ln(ω) dω
- ω̄₂² = (2/λ)∫α²F(ω)·ω dω
- **μ\* = 0.10，对全部材料固定**（原句："We took arbitrarily the value of μ∗=0.10 for
  all materials studied"）——这一条对 Step 2/3 的自由度分析是承重前提，见 §2。
- Eliashberg 方程额外用库仑截断 0.5 eV（McMillan/AD 公式不需要这个参数）。

`McMillan.dat` 文件头逐字打印 `lambda`、`wlog[K]`、`wlog[meV]`、`w2av[K]`、`w2av[meV]`，
与上述定义对应，随后是 `mustar - TcMcMillan - TcAllenDynes` 的网格（μ\*=0.000 到某个上限，
步长 0.02，超过某个 μ\* 后配对失效印 `-----`）。本文直接读取 μ\*=0.10 那一行（网格上精确命中，
非插值）。`Eliashberg.dat` 格式相同但只有一列 Tc。

## 2. Step 2：剪枝扫描——先做代数验证，再做数值验证

### 2.1 方向陷阱：本次**不适用**

任务里提醒的陷阱 1（ω_log 顶替 ω̄₂ 只能下估天花板）在本次扫描里**不成立风险**——因为
`McMillan.dat` 直接给出真实 ω̄₂（`w2av[meV]`），不是本文自己拿 ω_log 顶替。249 行全部用
真实 ω̄₂ 参与 FAIL 判定，无需因方向问题剔除任何一行。

### 2.2 自由度陷阱：**代数上证实退化，且比任务简述描述的更极端**

标准 Allen-Dynes 公式（非仅 McMillan 那支简化式）：

```
Tc_AD = f1·f2·(ω_log/1.2)·exp[-1.04(1+λ)/(λ-μ*(1+0.62λ))]
f1 = [1+(λ/Λ1)^1.5]^(1/3),  Λ1 = 2.46(1+3.8μ*)
f2 = 1 + (r-1)λ²/(λ²+Λ2²),  Λ2 = 1.82(1+6.3μ*)·r,   r := ω̄₂/ω_log
```

代入 `Tc_ceiling = C_∞·√λ·ω̄₂·(meV→K) = C_∞·√λ·r·ω_log·(meV→K)`：

```
Tc_AD/Tc_ceiling = [f1·f2·exp(...)/1.2] / [C_∞·√λ·r·(meV→K)]
```

右边**只含 λ、r、μ\***，`ω_log` 精确相消——这是 `analytic`（纯代数恒等式，与任何数据无关）。
**且因为这个数据集 μ\*≡0.10 对全部 6912 材料固定**（§1），比值进一步退化成**纯 (λ,r) 的二元函数**，
不含任何"哪个材料/μ\*取多少"的信息。**这一条比任务简述里"每个条目贡献两个数(λ,r)"更极端**：
不仅 ω_log 被约掉，μ\* 这个变量在**整个数据集里本来就是常数**，不是逐材料变化后被约掉。

### 2.3 数值验证

`cerqueira6912_scans.py`：对 249 行每一行，把 `ω_log` 人为乘以 0.5×/2×/5×（保持 λ, r 不变），
用**上面这条真实 Allen-Dynes 公式自己重算** `Tc_AD`（不是读文件缓存值），检验
`G(λ,r,μ*) := Tc_AD/ω_log` 是否在缩放前后不变：

**最大相对偏差 = 3.157e-16**（249 行 × 3 个缩放因子，全部检查），机器精度量级，
**代数相消数值上确认**。[analytic 恒等式 + numerical-evidence 确认]

### 2.4 FAIL 计数

用 `C_∞=0.1827262477890`、`1 meV=11.6045 K`、真实 `w2av[meV]`、`lambda`、
`Tc_AD`（文件里 μ\*=0.10 那一行的缓存值，不是本文重算的，两者应完全一致——已抽查一致）：

**FAIL（Tc_pred > Tc_ceiling）：0/249。**

## 3. ⚠ 关键警告：`batch-q` 的 λ 分布严重偏斜，本次 FAIL 扫描是弱检验

**249 个材料的 λ 全部落在 `[0.0209, 0.2087]`**（中位数 0.093，均值 0.097），
**没有一个材料 λ>0.21**，`r=ω̄₂/ω_log ∈ [1.054, 2.441]`（均值 1.249，与
`ambient_hydride_candidates.csv` 的 1.83、`hydrides_theory.csv` 均值区间大致同一量级但更窄）。
`Tc_AD`（μ\*=0.10）**249 个里只有 55 个有收敛解**（其余 194 个在 μ\*=0.10 处
`λ-μ*(1+0.62λ)≤0`，Eliashberg 无解——公式判据本身失效，不是数据缺失），
**有解的 55 个全部四舍五入到 0.000 K**（次 mK 量级）。

这意味着：

1. **本次 249 行样本完全不包含论文摘要提到的 "2239/6912 个 Tc>1K" 那部分材料**——
   我们只覆盖了 6912 个材料里 λ 最弱的一条尾巴（`batch-q` 只是因为**体积最小**被选中下载，
   不是按材料属性筛的，见 §0.5——但结果上看它显然不是 λ 的无偏切片）。
2. **FAIL=0/249 是一次弱检验**：λ 越小、Tc 越接近 0，天花板本来就越宽松，
   这批材料从未真正逼近过天花板（可以从数据看出，即便不算比值：Tc_pred≈0 而
   Tc_ceiling=C_∞√λ·ω̄₂·11.6 在 λ~0.1、ω̄₂~200meV 时量级是几十 K，天花板比预测值宽松
   两到三个数量级）。**"0 违反"这个结论对高 λ/高 Tc 候选材料完全没有检验力**——
   要真正压力测试方向 1 的天花板，需要另外几个 batch（尤其是含氢化物/高 λ 材料的那些），
   本文未取。
3. **这不影响 §2 的代数/数值退化结论**（那是纯数学恒等式，任何 λ 值下都成立，
   已在这 249 行的实际参数范围内验证），**只影响"0 FAIL 对 6912 有多大代表性"这一判断**。

## 4. Step 3：人口扫描

沿用 `dir2_population_overlap_2026-09-18.md` 的阈值定义 `Ξ := λ/μ*`；本数据集 μ\*≡0.10
对全部材料固定，故 `Ξ = 10λ`，与 λ 是同一件事的线性重标度（**又一次自由度相消**：
这个数据集上 Ξ<2.6 ⟺ λ<0.26，Ξ<3.1 ⟺ λ<0.31，不需要额外算 μ\* 逐行取值）。

**结果（n=249）**：

| 判据 | 命中数 | 其中 Tc_pred>1K | 其中 Tc_pred>10K | 其中 Tc_pred>77K |
|---|---|---|---|---|
| Ξ<2.6（反转候选） | 249/249 (100%) | 0 | 0 | 0 |
| Ξ<3.1（含灰区+反转） | 249/249 (100%) | 0 | 0 | 0 |

**这正是任务简述预警的"真但空洞"情形的一个实测样本**：由于 `batch-q` 恰好是全弱耦合子集
（§3），"反转候选"这条线在这批材料里覆盖率是 100%，但命中的全部 249 个材料
**没有一个在任何筛选阈值（1K/10K/77K）之上会被任何人关注**——这条判据在本样本上
"重叠"这一说法本身就没有信息量，因为分母（249）和分子（249）恰好因为样本选择方式
（挑了最小的 batch）而重合。

**与 `dir2_population_overlap_2026-09-18.md` 的对照**：那篇笔记用 68 行氢化物候选表
（λ∈[0.61,3.62]）得到 0/68 命中反转区（因为氢化物候选 λ 太大，从不进入反转区）；
本文用这 249 行弱耦合材料得到 249/249 落入反转区但全部 Tc≈0（因为这批材料 λ 太小，
从不产生有意义的 Tc）。**两份样本从两个方向互补地确认了同一件事**：至少在这两个
非随机切片里，"λ 落入反转区"和"Tc 大到会被筛选关注"这两个条件从未同时满足过——
但**这不是对全材料空间的证明**，只是两个非随机子样本（一个是人工挑的高 Tc 候选表，
一个是因体积最小被选中的 batch）都没有撞见反例。
