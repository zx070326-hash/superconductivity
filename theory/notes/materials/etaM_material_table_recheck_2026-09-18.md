## §3 方向审计

- **界 A / 界 B 是上界**：文档在 §4.B 明示方向哨兵（`b > Tc_thy` 等），我的重算复现了同样的不等式方向，且我独立算出的界数值本身满足该不等式。**没有发现任何方向反转**。
- **带 `*` 的行（H3S / YH6 / PdH，用 ω_log 代 ω₂）**：文档规则是「这一行的数字只能证『过』，不能证『否』」。我核对了 §5.3 的裁决表：H3S 与 PdH 两行标「不可判（单边）」，YH6 标「过」——**YH6 为什么允许标『过』而不是『不可判』**？因为 ω_log 代入已经给出 boundA=318.5K > 300K，而**下估超过判据就是合法的『过』**（下估方向对『过』这个方向是正确的，§4.A 已写明这条规则）；这与「不可判」的其余两行（下估未过线）方向一致，判决**无误**。
- **G(λ) 点值 vs 认证包围**：文档在 §5.3(B列) 用的是**认证上包围 F_hi^E**而不是 float64 点值 G，这是正确的方向（点值是下估，不能当上界用）。我在 §2.C′ 核对了 7/7 点值落在认证区间内，**没有发现区间方向反转**（认证上端 ≥ 点值，下端 ≤ 点值）。
- **η_H^ub 是 η_H 的上估**：`η_H^ub = M_H·λ⟨ω²⟩` 假设全部耦合都在 H 上，文档正确标注这是**上估**（因为 `η_H/M_H ≤ Σ_a η_a/M_a`）。这是唯一支持「过」方向使用的地方（§5.3 门槛表用 `eta_H^ub` 反推最低 η_H 需求，方向一致：若假设全在 H 上都够不到门槛，那更保守的真实分配也够不到——不过文档没有做这个反向使用，只用它做量级参照，方向审计不适用）。
- **只支持 PASS 的格子清单**：§5.3 表中 H3S、YH6（若下估未过线时）、PdH 的 A/B 两列——本例中实际是 H3S 与 PdH（因为它们的下估确实低于 300K 门槛），只能判「不可判」不能判「否」；YH6 的下估已过线，按规则允许判「过」。这与文档一致。

## §4 循环量与自由度

- **η/M 与 η_H^ub 不是独立数据**：文档 §4.B 脚注 † 已自我标注「两列都是从 (λ, ω₂) 反推的」。我确认这条自由度陈述成立：`η/M = λω₂²` 与 `η_H^ub = M_H·λω₂²` 是同一 (λ,ω₂) 的两种单位换算，**不构成两个独立检验**。
- **界 A 与界 B 也不是独立检验**：两者都只是同一 (λ, η/M) 经过不同常数（C_∞ vs G(λ)）的重标度，**自由度仍是 (λ, η/M) 两个**，不是表面看到的「界A、界B、A/exp、B/exp」四个独立数字。
- **A/exp、B/exp 列**：这两列进一步引入了 Tc_exp，是第三个自由度，但 Tc_exp 是外部实验值（非本文档反推），故这两列**是**在检验界与实验的关系，不是恒等式自证——**除了 YH6 的 μ*/Tc_thy 中点问题**（见 §5）造成 Tc_thy 本身带有一点人为处理，但 Tc_exp 列不受影响。
- **§2.C 与 §2.C′ 的 G(λ) 数字**：G(λ) 是 λ 的纯函数（不依赖材料），11 行表只有 1 个自由度（λ）；材料数值表里引用它时，等价于把材料的 λ 代入这同一个函数，**不产生新的自由度**——每个材料只贡献 (λ, ω₂) 两个数，而不是 (λ, ω₂, η/M, 界A, 界B) 五个独立数。
- **YH6 循环性提示**：Tc_thy=241.5 与 μ*=0.125 都是从**区间中点**得出，这意味着「界 > Tc_thy」这条判决对 YH6 而言，其比较对象本身带有约 ±5K/±0.025 的人为选点误差——不影响上界成立与否（界=318.5K 远高于区间上端 247K），但**紧度数字**（若要引用 YH6 的 A/exp 或界/Tc_thy 比值）应说明这一点。

### 5.2 两处应披露但目前未披露的问题（不是错误，是文档透明度缺口）

**(a) YH6 的 Tc_thy=241.5 K 与 μ*=0.125 是区间中点，不是原文单点。** `isotope_curated.md` 给的是 `SSCHA: 236–247`（anh Tc）与 `μ*(6Ry)=0.10–0.15`；`p4_eta_over_M.py` 的 `MATERIALS` 表直接沿用了 `p4_tc_sandwich.py` 里早已做过的中点化（该脚本注释里写明「Tc 取 236-247 中点」），但 `P4_eta_over_M.md` 正文和脚注都没有提及这一点，读者会以为 241.5 是原文印出的数字。**旧值不是错**（中点化是合理的展示手段，且不影响上界结论），**新值也没有被独立验证优于原始区间**——即两段都要写：中点选择没有被证明是「代表性」的，只是「区间内的一个点」。建议在文档 §4.A 或表脚注加一句「YH6 的 Tc_thy/μ* 取自区间中点，非原文单点」。

**(b) LaH10@163GPa 的 Tc_exp=250K 与其理论行的压力（163GPa）不匹配。** `isotope_curated.md` 明确给出：实验 250K 对应的是 **150GPa**（H 结构，XRD 确认），而 SSCHA 理论 Tc_thy=242.8K 算的是 **163GPa**（Errea 2020 Ext. Data Table I 的点）。文档 §4.B 主表直接把两者摆在同一行算 `A/exp=1.44`，**没有标注这是跨压力对照**。这不改变界 A > 250K 这件事（因为界本身留有 40%+ 的余量），但「紧度 1.44×」这类精确措辞的物理意义应加一句「Tc_exp 取自邻近压力点，非同压」。这与仓库既有的「H3S 锚点判不掉」系列教训是同一形状的问题（跨压力/跨制备条件对照），值得比照那批笔记的处理方式加一句免责声明。
