## MgB₂（σ/π 两带）

### 阴性结果（重要）：主流做法是**标量** μ*，不是矩阵

Choi, Roundy, Sun, Cohen, Louie, *PRB* 66, 020513(R) (2002)（arXiv:cond-mat/0111225 附近工作）在其全 k 分辨各向异性 Eliashberg 计算里用的是**单一标量** μ*(ω_c)=0.12（ω_c≈5ω_ph^max），并声明结果对该取值不敏感。这是最常被引用的 MgB₂ Eliashberg 计算，其 μ* 是 `μ*·𝟙` 形式，秩一、自动 PSD——但它根本不是矩阵，不构成本任务想要的"矩阵证据"。
来源：多篇二手引述一致（Mazin et al. comment 与 Choi et al. reply 均转述此值），一手 PRB 66,020513 原文未直接取到全文（尝试见下）。

μ_σσ : μ_ππ : μ_σπ : μ_πσ = 3.1 : 2.6 : 1.4 : 1.0
```
**组 2（Moon, Kim, Chang，未发表，ab initio 全介电矩阵，被 Choi et al. Reply 转引）：**

两组均只给**比值**，无绝对数值，且论文明确说这是**裸** μ（bare Coulomb，未做 log 重整化到 μ*）——不是 μ*_ij。若要真正的 μ*_ij 需要额外的重整化步骤，原文未给出该步骤的数字。

### ★ 约定核对（核心发现）

正文（Mazin et al. HTML 抓取）给出定义式：
```
μ_nn' ∝ N_n' ∫|ψ_n(r)|²|ψ_n'(r)|² d³r
```
即 **μ_ij ∝ N_j（目的带的 DOS），重叠积分部分对 i↔j 对称**——这正是任务描述里的 **convention (B)**（非对称，DOS 未吸收）。
交叉验证：两组比值都满足 detailed-balance 式 `N_σ μ_σπ = N_π μ_πσ`：
- 组 2 隐含 N_π/N_σ = μ_σπ/μ_πσ = 1.61（Reply 原文明确指出这一点，并说这比其他电子结构计算给出的 N_π/N_σ=1.37 偏高——两个 DOS 比值互相矛盾，原文自己指出了这个差异，未裁决）。
- 组 1 隐含 N_π/N_σ = 1.4（同一 detailed-balance 逻辑），与组 2 的 1.61 也不一致——**两组比值本身互相矛盾**，不是同一次计算的两种呈现。

正确的对称化不是 team-lead 消息里写的 `sqrt(N_i)*μ*_ij*sqrt(N_j)`（我验证过，直接代入 N_π/N_σ=1.61 后这个公式在组2上给不出对称矩阵，见下）。正确形式应为 **K_ij := μ_ij / N_j**（因为 μ_ij = N_j·K_ij，K_ij=K_ji 是波函数交叠积分本身对称）。用 N_σ=1, N_π=1.61（取自组2自洽值）：
```
K_σσ = 1.75/1    = 1.75
K_ππ = 2.04/1.61 = 1.2671
K_σπ = K_πσ = 1.61/1.61 = 1.00   (或 1.00/1 = 1.00，两式一致，确认对称)
```

### ★★ 团队复核后的裁决：这四个 PASS 无信息量（Gram 构造必 PSD）

团队从零复核确认：我的 `K_ij:=μ_ij/N_j` 对称化正确，团队原公式 `√(N_i)μ*_ij√(N_j)` 有误（已在组2上验证 off-diag 不对称：2.043 vs 1.269）。**但更重要的是**：仓库有引理 μ-2（analytic）——第一性原理 Coulomb 核 `V̂(q)>0` 逐点 ⟹ Bochner ⟹ `V⪰0` ⟹ `μ_ij=⟨V^{1/2}ρ_i,V^{1/2}ρ_j⟩` 是 Gram 矩阵 ⟹ **必 PSD**；以及引理 μ-3（analytic）——Anderson–Morel 标量截断重整化 `μ*=μ/(1+Lμ)` 保 PSD。Mazin 接触势模型与 Moon–Kim–Chang 介电矩阵**都是**"正核+交叠积分"形状，落在引理 μ-2 的保护范围内，**必然 PASS，通不过反而说明算错了**。上面四行 PASS 是对仓库引理的一次一致性检验，**不是关于材料的证据**，不应被下一个读者当材料证据使用。「裸 μ vs μ*」的 caveat 因引理 μ-3 而降级——不再构成障碍，第一性原理 μ 和 AM 重整化后的 μ* 都受 Gram 保护。

真正能检验 PSD 的只有**拟合**得到的 μ*_ij（用实验量反解/调参，不经过正定核构造），因为拟合不受引理 μ-2 保护。

### ★ 找到的拟合矩阵（真正的检验对象）：MgB₂ 比热拟合（Golubov et al. 2002）

Golubov, Kortus, Dolgov, Jepsen, Kong, Andersen, Gibson, Ahn, Kremer, *J. Phys.: Condens. Matter* 14, 1353 (2002) = arXiv:cond-mat/0111262（ar5iv HTML 正文一手取到）：两带 Eliashberg 拟合比热，**μ* 用一个自由参数**（乘以 ratio 2.23:2.48:1:1，来自第一性原理波函数交叠）拟合到实验 Tc=39.4 K：

```
μ*_σσ(ω_c) = 0.210,  μ*_σπ(ω_c) = 0.095
μ*_πσ(ω_c) = 0.069,  μ*_ππ(ω_c) = 0.172
N_σ(0) = 0.300 states/cell·eV,  N_π(0) = 0.410 states/cell·eV
```
（一手取到原文语句："μσσ*(ωc)=0.210, μσπ*(ωc)=0.095, μπσ*(ωc)=0.069, μππ*(ωc)=0.172"；一带模型对照 "μ*=0.1 yields Tc=40 K" 是纯标量。）

**约定核实**：detailed balance `N_i μ*_ij = N_j μ*_ji` 数值验证：N_σ·μ*_σπ=0.30×0.095=0.0285，N_π·μ*_πσ=0.41×0.069=0.02829——两者一致（3位有效数字舍入内），确认与 Ummarino 碳掺杂论文（cond-mat/0408702，同一 2.23/2.48/1 前提比值，一手 HTML 核实）**同一约定**：`μ*_ij = μ(ω_c)·N_tot(E_F)·K_ij/N_i`，K 对称。

对称化：`S_ij := √(N_i/N_j)·μ*_ij`（等价于相似变换 `D^{1/2}μ*D^{-1/2}`，D=diag(N)，保证特征值严格不变，非仅号不变）：
```
S_σσ = 0.210,  S_ππ = 0.172,  S_σπ = S_πσ ≈ 0.0810  (0.08127 与 0.08067 平均，两条独立路径互差 0.7%——舍入)
```
判据：det = 0.210×0.172 − 0.081² = 0.03612 − 0.00656 = **0.02956 > 0**；本征值 ≈ {0.274, 0.108}，**均 > 0 ⟹ PASS**。

**但此结果同样落在引理 μ-2/μ-3 保护范围**——比值 2.23:2.48:1:1 本身是第一性原理波函数交叠计算给出的，唯一被拟合的是标量前因子 μ(ω_c)，不影响 PSD（正标量缩放不改变符号）。所以这也**不是**能检验 PSD 是否会失败的独立数据点，只是把之前的比值证据坐实成了绝对值+确认了同一约定在两篇独立论文（Golubov 2002、Ummarino 2004）间自洽。

### 阴性结果：Fe 基多带 Eliashberg 里 μ*_ij 常年被直接设为零

arXiv:1304.3638（Ummarino, Galasso, Sanna, "A phenomenological multiband Eliashberg model for LiFeAs", *JPCM* 25, 205701 (2013)，ar5iv HTML 一手取到）——4×4 Coulomb 赝势矩阵**形式上存在**但显式设为零：
```
μ*_ii(ω_c) = μ*_ij(ω_c) = 0   (全矩阵)
```
理由：文中称电子声子耦合与库仑赝势"in first [approximation] compensate each other"，于是真正被拟合的是自旋涨落耦合矩阵 λ_ij（本文 Table 2 给出 λ_11=0.90, λ_13=1.15, λ_23=0.80, λ_14=0.45, λ_24=0.30，**全部为正**，无负带间项）。零矩阵是秩零 PSD 平凡满足，同样不构成 PSD 可能失败的检验对象。

同一作者早期两带模型论文 Ummarino, *J. Supercond. Nov. Magn.* 22, 603 (2009)（LaFeAsO₁₋ₓFₓ，"negative interband coupling"）标题里的"负带间耦合"经查证**指向电子-声子/自旋涨落耦合矩阵 λ_ij 里的有效带间项，不是 μ*_ij**——该文被付费墙挡住，一手未核实到 μ*_ij 具体数字，暂不采信为库仑矩阵反例，标记为待查（Springer DOI: 10.1007/s10948-009-0459-8）。

### ★ 阶段性结论（可交付的正面结论，回应团队"标量是否主流"的问题）

1. **绝大多数已发表多带 Eliashberg 计算，库仑项要么是标量 μ*（Choi et al. PRB 66,020513R 2002：μ*=0.12），要么矩阵形式来自第一性原理正定核构造（Golubov 2002 / Ummarino 2004 的 2.23:2.48:1:1 比值），要么整体设零（LiFeAs, arXiv:1304.3638）**。三种情形全部落在引理 μ-2/μ-3 的保护伞下（标量=秩一 Gram 平凡 PSD；正定核构造=Gram 矩阵；零矩阵=平凡 PSD）。
2. **迄今未找到一例"纯拟合、不经过正定核假设"的 μ*_ij 矩阵**——这正是团队要的独立检验对象，但文献里似乎不存在这类对象：作者要么用第一性原理算 Coulomb 矩阵比值（受 Gram 保护），要么干脆放弃拟合库仑矩阵、把负带间效应全部推给声子/自旋涨落耦合 λ_ij（这是另一个物理量，不受本判据约束）。
3. **可交付的正面结论**：目前抽样的全部三类 MgB₂/Fe 基多带 Eliashberg 文献里的 μ*_ij，天花板判据都无条件适用——但这是**结构性的**（Gram 保护 + 零矩阵平凡），不是"材料证据"意义上对判据的非平凡检验。若判据的价值主张是"能筛出违反 PSD 的坏材料"，目前文献抽样样本内**没有找到这样的候选**。

## 头条结论（团队确认，正面交付）

已发表的多带 Eliashberg 处理只有三种形态——**标量 μ\***（Choi–Louie）、**由正屏蔽核/波函数交叠构造的矩阵**（Golubov、Moon–Kim–Chang、Mazin）、**整体设零**（Ummarino LiFeAs 的 μ\*）。三者全部落在引理 μ-2/μ-3 的 Gram 保护伞下 ⟹ 全部 PSD ⟹ **天花板 `Tc ≤ C_∞√ρ(M2)` 对当前文献中的多带 μ\* 处理无条件适用，μ\* 通道不构成例外**。Golubov(2002) 绝对值 + 与 Ummarino(2004) 同约定交叉验证已留档在上文。

## ★★ 新目标核实结果：Ummarino λ_ij（拟合值，不受引理 μ-2 保护）——结构性 PSD 违反

### 矩阵结构（模型假设，非拟合）

原文给出 4×4 矩阵（带指标 1–4）：
```
λ = [[λ11,    0,     λ13,   λ14  ],
     [0,      0,     λ23,   λ24  ],
     [λ31,    λ32,   0,     0    ],
     [λ41,    λ42,   0,     0    ]]
```
其中 `λ31=λ13·ν13, λ32=λ23·ν23, λ41=λ14·ν14, λ42=λ24·ν24`，`ν_ij := N_i(0)/N_j(0)`（原文逐字定义式）。
**λ22=λ33=λ44=0、λ12=λ21=0、λ34=λ43=0 是模型假设（"λ^sf_ii=0, SF produce only interband coupling"，band 1 除外因"only band 1 has a low Fermi energy"），不是拟合结果——是作者手动设零的。**

### 约定核实

`λ_ji = λ_ij·ν_ij = λ_ij·N_i/N_j` ⟹ `N_j λ_ji = N_i λ_ij`，与之前 MgB₂ 遇到的同一类 convention (B)：定义 `K_ij:=N_i λ_ij` 可验证对称（`K_ji=N_j λ_ji=N_i λ_ij=K_ij`）。等价地 `λ_ij = K_ij/N_i`（行指标归一化，与 Golubov MgB₂ 的 `μ*_ij=K_ij/N_i` 同构）。

由此可证（附代数）：`λ_iiλ_jj − λ_ijλ_ji` 与 `K_iiK_jj − K_ijK_ji` **同号**（比例常数 `1/(N_iN_j)>0`），所以团队引理 μ-4 的乘积判据形式 **`λ_ii λ_jj ≥ λ_ij·λ_ji`** 可以直接代入原始（未对称化）的 λ 数值，不需要先转换。

### ★★ 结构性 PSD 违反（不依赖具体拟合数值，仅依赖 λ_ii=0 这一模型假设）

对任一行（λ11,λ13,λ23,λ14,λ24 取具体值），凡涉及 i∈{2,3,4} 的 2×2 主子式，因 `λ_ii=0`（i=2,3,4 结构性设零）而 `λ_ij`（i∈{2,3,4} 与其余带耦合）非零，行列式 `λ_iiλ_jj − λ_ijλ_ji = 0 − λ_ijλ_ji < 0`（只要 λ_ij,λ_ji 均非零）——**违反 PSD 与拟合的具体数值无关，只要模型的"结构零"和非零带间耦合同时存在就必然违反**。以 "sf,ph(2)" 行（Tc=20.1K，最接近实验 Δ 的一组）为例，逐个 2×2 主子式：

```
(1,3): λ11λ33 − λ13λ31 = 0.90×0 − 1.15×(1.15×0.9019) = 0 − 1.1927 = −1.1927  < 0  ⟹ 违反
(2,3): λ22λ33 − λ23λ32 = 0×0 − 0.80×(0.80×1.0483) = 0 − 0.6709 = −0.6709  < 0  ⟹ 违反
(1,4): λ11λ44 − λ14λ41 = 0.90×0 − 0.45×(0.45×1.5010) = 0 − 0.3040 = −0.3040  < 0  ⟹ 违反
