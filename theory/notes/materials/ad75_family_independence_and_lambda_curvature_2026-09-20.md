## 3. 订正一（新陈述凭什么对）

### 3.1 按元素集合分组：14 个，不是 1 个

把每行材料名解析成元素集合（剥 `a-`/`b-` 前缀后匹配九种元素），得 **14 个互不相同的集合**：

| 元素集合 | n | 𝔣 范围 | λ 范围 |
|---|---|---|---|
| {In,Tl} | 8 | [0.2074, 0.3029] | [0.83, 1.09] |
| {Bi,Pb} | 5 | [0.5065, 0.6102] | [1.66, 2.59] |
| {Pb,Tl} | 3 | [0.3786, 0.4932] | [1.15, 1.53] |
| {Ga} | 2 | [0.2541, 0.3644] | [0.97, 1.62] |
| {Bi,Tl} | 2 | [0.2299, 0.4650] | [0.78, 1.63] |
| {Pb} {In} {Sn} {Hg} {Tl} {Ta} | 各 1 | 0.4869 / 0.2330 / 0.1999 / 0.3700 / 0.2263 / 0.1994 | 0.69–1.60 |
| {Bi,Pb,Tl} {Bi,In} {Sb,Tl} | 各 1 | 0.5092 / 0.3866 / 0.4103 | 1.40–1.81 |

**𝔣 的两个极值化学上不相交** —— `Ta`（单质，𝔣=0.1994，λ=0.69）与
`Pb₀.₆₅Bi₀.₃₅`（𝔣=0.6102，λ=2.13），元素集 `{Ta}` ∩ `{Pb,Bi}` = ∅。
⟹ **3.06× 的展布不可能是族内伪影**（这是一条集合层面的 `analytic` 事实，不依赖回归）。

### 3.2 留一元素出：先修我自己的尺子

删掉**含某元素的全部行**后重拟合 `log 𝔣 = a + b·log λ + c·log(ω_log/ω̄₂)`。
八个元素给 |Δb| < 1.8σ，**但删 Bi 给 4.27σ**（`b: 0.9972 → 1.1700`）。

> **我自己的两段式订正。** 我最初就用这个 4.27σ 判「有元素驱动趋势」——**尺子选错了**。
> 4.27σ 用的是**全样本**的 `σ_b`，而子样本与全样本**嵌套**（高度相关），
> 且含 Bi 的 9 行**独占 λ > 1.62 的整个高端** ⟹ 删掉它们把杠杆臂截短 1.60×，
> 指数本来就该动。
>
> 换成正确的尺子并做匹配对照：
>
> | 量法 | 位移 |
> |---|---|
> | 全样本 σ_b（**错**） | 4.27σ |
> | 子样本自己的 σ，合并 | 2.60σ |
> | **把非 Bi 行也截到 λ≤1.62 后比较** | **0.16σ** |
>
> 即：位移**几乎全部**是杠杆臂。佐证两条——
> Bi 行在全样本拟合下的残差与其余行**无系统偏移**（Welch `t = −0.99`）；
> 最大残差行 `a-Pb₀.₄₅Bi₀.₅₅`（−2.68s）删掉后曲率仍在（§5.2）。
>
> **新陈述凭什么对**（与上一段分开）：`0.16σ` 是在**同一 λ 区间**上比较两个拟合，
> 杠杆臂被显式控制掉，剩下的才是「Bi 这一族是否偏离」。它接近零。

### 3.3 最强去相关检验：只留 8 个单质行

`Pb, In, Sn, Hg, Tl, Ta, a-Ga, b-Ga` —— **7 种元素，零合金，两两化学不相交**（Ga 的两个同素异形体除外）：

```
n = 8      𝔣 ∈ [0.1994, 0.4869]（2.44×）     λ ∈ [0.69, 1.62]
b = +1.0601 ± 0.0535   (全样本 +0.9972 ± 0.0405)   Δ = 0.94σ_合并
c = +0.6867 ± 0.1109   (全样本 +0.7198 ± 0.1282)   Δ = 0.20σ_合并
R² = 0.9895            s = 0.0401   （全样本 0.0794）
```

⟹ **趋势在一个化学上完全去相关的子样本上独立复现，且拟合更紧。**

### 3.4 结论与它的边界

- **「独立材料家族数 = 1」推翻。** 常规超导体层面是 **14 个元素集合 / 7 种不相交单质**。
- **仍然成立的窄陈述**：**高 Tc / 氢化物区**的独立家族数**仍然是 1**（H3S/D3S 同一家族）。
  头条笔记真正想外推的正是这个区间 ⟹ 它的**担忧保留，覆盖范围缩小**。
- **本轮判不了的**：29 行全部出自**同一种测量技术**（隧道电导反演 McMillan–Rowell）、
  同一时期、重叠的实验组。**化学独立不蕴含系统误差独立。**
  这一条必须随结论同行；要关掉它，需要一个**非隧道**来源的 `(λ, ω̄₂, Tc)` 三元组
  （这就是 `f-sample-expansion` 那条线的真正价值，见 §6）。

## 8. MgB₂ 能不能进 𝔣 的趋势回归？——不能，且理由是定理

> 缘起：§6 给 `f-sample-expansion` 放行了 MgB₂/CaC₆ 的 `𝔣_up`。但**天花板检验合法 ≠ 可进回归**，
> 这两件事我当时没分开。补上。
> 脚本：`../_scratch_ir/_chk_main_mgb2_multiband_vs_scalar_f_2026-09-20.py`、
> `../_scratch_ir/_chk_main_M2avg_le_rho_theorem_2026-09-20.py`。

### 8.1 三种写法是同一个量 [analytic]

```
λ = 2∫(α²F/ω)dω ,  ⟨ω²⟩ := (2/λ)∫ω α²F dω
⟹ λ⟨ω²⟩ = 2∫ω α²F dω = ∫2ω α²F dω = M2        —— 恒等，按定义
⟹ 𝔣 = Tc/(C_∞√λ·ω̄₂) = Tc/(C_∞√(λ⟨ω²⟩)) = Tc/(C_∞√M2)
```

三个形状迥异的试验谱（窄 Einstein / 宽 Lorentz / 双峰）相对差 ≤ `2e−16`。
**实用后果**：取 `𝔣` 只需**一次积分** `M2 = ∫2ωα²F dω`，不必走 λ → ⟨ω²⟩ → 开方三步。

### 8.2 多带天花板在纯声子材料上**不**退回标量 [analytic]

规范笔记 [`../ceiling/multiband_ceiling_CANONICAL_2026-09-18.md`](../ceiling/multiband_ceiling_CANONICAL_2026-09-18.md) §1：
`M2^sf ≡ 0`（纯声子）⟹ `M2″_Z = diag(M2^ph) + c_GF·offdiag(M2^ph)` —— **仍是矩阵**。
天花板吃 `ρ(M2″_Z)`，不是总 α²F 的标量 `M2`。只有单带 `B=1` 时 offdiag 为空、两者才重合。

### 8.3 ★ 新：`M2_avg ≤ ρ(M2) ≤ ρ(M2″_Z)` 是定理 [analytic]

设 `D = diag(N)`，**细致平衡** `N_i M2_ij = N_j M2_ji` ⟺ `D·M2` 对称。
令 `S := D^{1/2} M2 D^{-1/2}`，则 `S_ij = √(N_i/N_j)M2_ij = S_ji` ⟹ **S 对称**，`ρ(M2) = λ_max(S)`。
取单位向量 `v := (√N_1,…,√N_B)/√(ΣN)`：

```
vᵀSv = Σ_ij √(N_i/ΣN)·√(N_i/N_j)·M2_ij·√(N_j/ΣN) = Σ_ij N_i M2_ij / ΣN = M2_avg
⟹ M2_avg = vᵀSv ≤ λ_max(S) = ρ(M2)                        (Rayleigh)
⟹ ρ(M2) ≤ ρ(M2″_Z)          (Horn–Johnson 8.1.18 逐元单调 + c_GF ≥ 1)
```

即 **DOS 加权各向同性平均恰是对称化矩阵的一个 Rayleigh 商**。取等 ⟺ `M2` 的 Perron 向量 `∝ N`（含单带）。

| 检验 | 结果 |
|---|---|
| 随机细致平衡阵（B=2…5，4000 组）违反 `avg ≤ ρ ≤ ρ″` | **0 / 4000**；Rayleigh 恒等式 0/4000 失败 |
| **负对照**：去掉细致平衡 | **2038 / 4000（51%）直接违反**，最劣 3.46×；定向构造可任意大 |

⟹ **细致平衡是承重前提，不是装饰。** 且该退化集是**原子型/正测度**（随机扫就能打到 51%），
不属于「必须定向构造」那一类——按仓库抽样纪律，这里报随机扫的比例是**合法覆盖**。

### 8.4 后果：天花板检验放行，趋势回归拦下

```
𝔣_scalar := Tc/(C_∞√M2_avg)  ≥  𝔣_multi := Tc/(C_∞√ρ(M2″_Z))
```

- **天花板检验**：`𝔣_scalar ≤ 1` **蕴含** `𝔣_multi ≤ 1` ⟹ 标量版是**保守**的 ⟹ §6 的 `𝔣_up ≈ 0.33` **合法**，方向已审。
- **趋势回归**：`𝔣_scalar` 被系统性抬高 `√(ρ″/M2_avg)`，且**该因子逐材料不同**
  ⟹ 与 AD75 的单带 `𝔣` **不是同一个量** ⟹ **MgB₂ 不得进回归**。
  （用规范笔记 §5 那组「原文未读」的 `λ_ij` 得 1.2703；**该数值不承重**——
  「>1 且逐材料不同」是定理结论，与转引值无关。顺带：细致平衡反解出 `N_π/N_σ = 2.103`，
  落在文献 1.3–2.1 区间内 ⟹ 转引的 `λ_ij` 至少**自洽**。）

⟹ **CaC₆ 的价值高于 MgB₂**：CaC₆ 单带、两处都能进；而 item 2 当前的阻断在**回归侧**。

## 13. ★ 技术系统误差对曲率的作用：`q_D = q_T/(1+r₁)²` [analytic]

> 本节是**派活前预算**（`CLAUDE.md`「预算优先」）：`f-sample-expansion` 提议数字化
> Savrasov Fig.2 取 Pb/Ta 的 DFT `ω̄₂`。先问它买到什么——答案改变了派活内容。
> 脚本（主会话从零写，已 `git add -f`）：

> [`../_scratch_ir/_chk_main_pbta_affine_bias_q_rescale_2026-09-20.py`](../_scratch_ir/_chk_main_pbta_affine_bias_q_rescale_2026-09-20.py)。

### 13.1 恒等式

设技术偏置 `λ_D = ρ·λ_T`、`ω̄₂_D = σ·ω̄₂_T`（`Tc` 两技术**相同**——它是同一个实验测量值，
不经反演）。记 `L := logλ`。由 `𝔣 = Tc/(C_∞√λ·ω̄₂)`：

    log𝔣_D = log𝔣_T − ½logρ − logσ        ← 只在**响应**上加项
    L_D     = L_T + logρ                    ← 动**自变量轴**

设偏置本身仿射：`logρ = r₀ + r₁L`、`logσ = s₀ + s₁L`。则 `L_D = (1+r₁)L_T + r₀` 是 `L` 轴的
**仿射重标度**，而响应侧减掉的是 `L_T` 的仿射函数。代回 `log𝔣 = a + bL + cS + qL²`：

    ★ **q_D = q_T / (1+r₁)²**          b_D、a_D 另有表达式（不承重，略）

数值确认（无噪声、4000 点、五组 `(r₁,s₁)`）：拟合值与预言逐行吻合到 **1e−15**。

### 13.2 三条推论（每条都改变派活）

1. **`σ`（`ω̄₂` 侧偏置）完全不进 `q`** [analytic]。它只在响应上加仿射项，不动 `L` 轴
   ⟹ `s₁` 根本不出现在上式里。数值确认：`s₁ = −0.0535` 与 `s₁ = 0` 给出**逐位相同**的
   `q = −0.766882`。⟹ **数字化 Fig.2 对头条曲率的预算 = ∞**，它只买 `b` 和 `𝔣` 的绝对值。
2. **曲率的存在性对技术偏置结构免疫** [analytic]。`q_T = 0 ⟹ q_D = 0`（实测 `+3.3e−16`）：
   仿射偏置**无中不能生有**。⟹ 头条的**定性**内容（「`𝔣` 随 λ 上升但朝解析天花板 `𝔣≤1` 弯曲」）
   **不需要非隧道样本来保**。这是一条比任何扩样都强的解析护栏，此前未写下来。
3. **但 `q` 的数值不免疫，且已被咬穿** [numerical-evidence，输入未核验]。
   用 `f-sample-expansion` 转述的 Savrasov 值：`ρ_Pb = 1.68/1.55 = 1.0839`、
   `ρ_Ta = 0.86/0.69 = 1.2464` ⟹ `r₁ = log(1.0839/1.2464)/log(1.55/0.69) = −0.1726`
   ⟹ `1/(1+r₁)² = 1.4608` ⟹ `q: −0.525 → −0.767`（**+46%**），
   **直接跨出**现报区间 `[−0.63, −0.40]`（§4′ 第 2 条对应项）。

### 13.3 修正后的派活

**要保 `q`，需要的只是 `λ` 的两技术比值——两边都已印在表里，零数字化。**
真正该扩的是**材料数**而非单材料精度：`r₁` 现由 **2 点**定，误差不可估，而重标度因子
`(1+r₁)⁻²` 对 `r₁` 极敏感。⟹ 已改派：找第三、第四个同时有隧道 `λ` 与 DFT `λ` 的材料

(a) Ta 的 `λ_tun` 出现两个值（Savrasov 引 0.78 vs AD75 印 0.69，差 13%）——这是**两个隧道值**
