## 1. 先讲一次真实翻车：Cauchy 交错方向搞反了

**第一次尝试的（错误）路线**：Feshbach/Schur 补型自能。设 H'=ℌ₊ 限制在 n≥1 上（删去第 0 行/列），
b_n=(ℌ₊)_{n0}（n≥1）。标准恒等式：

```
c₁² = 1/(1+Σ'(μ₁)),   Σ(z)=b^T(H'-z)^{-1}b,   Σ'(z)=b^T(H'-z)^{-2}b
```

**错误推理**：以为 Cauchy 交错给出 μ₁(H') ≤ μ₂(ℌ₊)，从而 μ₁-λ_j(H') ≥ μ₁-μ₂=:γ 对所有 j，
于是 Σ'(μ₁) ≤ ‖b‖²/γ²，得到 c₁² ≥ γ²/(γ²+‖b‖²)。

**这是反的**。对由 (n+1)×(n+1) 矩阵删去一行一列得到的 n×n 主子阵，正确的 Cauchy 交错是

```
λ₁(H) ≥ λ₁(H') ≥ λ₂(H) ≥ λ₂(H') ≥ …
```

即 **μ₁(H') ≥ μ₂(ℌ₊)**（下界，不是上界！）。μ₁(H') 完全可能非常接近 μ₁ 本身（直觉上：只删掉一个坐标，
剩下的算子的顶本征值不会掉太多，除非 c₁ 本身就很大——而这恰恰是我们想证明的东西，整条路线是**循环论证**）。

**怎么发现的**：用这条（错误）公式在 ϖ=30, N=500 跑出 c₁²_lower=0.473，而 `delta_channel_immunity` 表里
该点的 numerical-evidence 值是 c₁²=0.397。**下界 > 真值**，矛盾——这是本任务里"独立重算+方向审计"抓到的
一个真实 bug，不是假警报。按规矩记录在此，不用这条路线的任何数字。

**教训**：Schur 补型的"能隙"必须是**去掉那个坐标之后剩余算子自身的谱隙**，不能偷懒地代入全算子的 γ；
这两者之间的大小关系不是免费的，需要独立证明（而独立证明它，其难度基本等于原问题本身）。

## 2. 修正路线：Davis–Kahan 型 sinΘ 界（本会话独立推导，不引用外部常数）

放弃 Schur 补/自能，改用**特征向量扰动**，把"整个尾�access巴"当作对**已知截断矩阵**的一个有界扰动 E，
用初等的（自证的，不是套用某个教科书常数版本的）sinΘ 不等式控制角度。

### 2.1 分解

固定截断 N，令 A := H_N ⊕ 0（把 (N+1)×(N+1) 截断矩阵 H_N 嵌入 ℓ²(ℕ₀)，其余坐标补零），E := ℌ₊ - A。
E 的分块结构：

```
E = [[0, C], [Cᵀ, H^BB]]
```

C = 头(0..N)–尾(N+1..∞) 耦合块，H^BB = 尾块本身。

### 2.2 尾算子范数的解析（非截断）上界

用 `delta_channel_immunity` 引理 1/2 的**同一 Poisson 求和技巧**（对偶方向：取 max 而非 min）：

```
fhat(0) = πϖ coth(πϖ) = Σ_{k∈ℤ} f(k)      （T_f+H_f 的算子范数上界）
fhat(π) = πϖ / sinh(πϖ)                    （下界，已在原笔记证明 >0）
0 ⪯ T_f+H_f ⪯ fhat(0)·I                    （压缩（principal submatrix）不改变谱界，对任意子空间同样成立）
```

由此（S := Σ_{k≥1}f(k) = (fhat(0)-1)/2，u_n=(2n+1)^{-1/2}）：

```
‖H^BB‖ ≤ (fhat(0)-1)/(2N+3) + u_{N+1}²(fhat(0)+1)      [L1 尾 + (L2+L3) 尾]
‖C‖    ≤ u_{N+1} · (fhat(0)-fhat(π))/2                   [头尾耦合块，标准自伴算子块范数事实]
```

（块范数事实：自伴 M 谱在 [-κ,κ] 内 ⟹ ‖M_AB‖≤κ；对 T_f+H_f 平移 (fhat(0)+fhat(π))/2 使谱对称后套用，
本笔记 §2.2 附初等证明，4 行 Cauchy-Schwarz，不引用外部定理。）

方向：两个都是**上界**，且都不依赖任何截断/离散化假设——f, u_n, fhat(0), fhat(π) 全部闭式，
mpmath.iv 计算，误差只来自浮点舍入（外向）。

### 2.3 sinΘ 不等式（自证，不套用 Davis–Kahan 的现成常数）

设 φ = A 的（精确）顶本征向量，特征值 la=λ₁(H_N)。设 ψ = ℌ₊ 的真顶本征向量，特征值 μ₁。
分解 ψ=cosθ·φ+sinθ·φ_perp（φ_perp⊥φ 单位向量）。取与 φ_perp 的内积：

```
φ_perp^T ℌ₊ ψ = μ₁ sinθ
             = cosθ·φ_perp^T(A+E)φ + sinθ·φ_perp^T(A+E)φ_perp
             = cosθ·φ_perp^T E φ + sinθ·φ_perp^T A φ_perp + sinθ·φ_perp^T E φ_perp
                （φ_perp^TAφ=0，因 φ_perp⊥φ 且 Aφ=la·φ）
             ≤ cosθ‖E‖ + sinθ·λ₂(A) + sinθ‖E‖
```

（φ_perp^TAφ_perp ≤ λ₂(A) 是 Rayleigh–Ritz；两个 |φ_perp^T(·)φ...| ≤ ‖E‖ 是 Cauchy–Schwarz。）
整理，并用 μ₁ ≥ la（compression：λ₁(H)≥λ₁(H_N) 对任意截断恒成立，无需尾控制）：

```
sinθ · (μ₁-λ₂(A)-‖E‖) ≤ cosθ‖E‖ ≤ ‖E‖
⟹  sinθ ≤ ‖E‖ / (δ-‖E‖) ,     δ := la - λ₂(A) = λ₁(H_N) - max(λ₂(H_N),0)   （用 μ₁≥la 放大分母）
```

δ 是**截断矩阵自己的谱隙**（不是原来翻车路线里的、方向错误的"H' 的隙"）——这正是修正的关键：
只用 A=H_N⊕0 自身的、可直接算的谱结构，不再牵扯"删去一行"的那个算子。

### 2.4 φ vs 浮点近似 v₁

φ 是 A 的**精确**顶本征向量，实践中只有 numpy `eigh` 给出的浮点近似 v₁。用同一套 sinΘ 论证（φ_perp 换成
v₁_perp，"A" 换成 H_N 本身，"E" 换成残差 r := ‖H_N v₁ - la·v₁‖，用 iv 精确算出）得到第二层小角度：

```
sinθ₁ ≤ r/(gap₁-r),   gap₁ := λ₁(H_N)-λ₂(H_N)  （certificate，同一台 inertia 计数器给出）
```

数值上 r ~ 1e-16（双精度 eigh 的机器精度残差），gap₁ ~ O(1)，故 sinθ₁ ~ 1e-16，完全可忽略，
但**仍然是被证明的**，不是"多精度一致"式的假设。三角不等式合并：sinθ_total ≤ sinθ₁+sinθ₂。

### 2.5 落到 c₁²

```
c₁ = |ψ[0]| = |cosθ·v₁[0] + sinθ·(...)[0]| ≥ cosθ|v₁[0]| - sinθ   （单位向量任一分量 ≤1）
c₁² ≥ max(0, cosθ|v₁[0]| - sinθ)²
```

## 3. λ₁(H_N)、λ₂(H_N) 的 certificate：区间 LDLᵀ + Sylvester 惯性律

- λ₁(H_N) 下界：Rayleigh 商 v₁ᵀH_Nv₁/‖v₁‖²（v₁ 任意向量，含浮点近似），iv 精确求和，**无条件**成立
  （压缩/Rayleigh–Ritz，不需要尾控制）。
- λ₂(H_N) 上界：对候选 c，把 (H_N-cI) 做**区间 LDLᵀ**（无主元交换的对称高斯消元），数负主元个数；
  若个数 ≥ dim-1，则由 Sylvester 惯性律证明「H_N 至多 1 个特征值 ≥c」，即 λ₂(H_N)≤c。
  若某主元区间跨零则该 c 不可判（返回 inconclusive，脚本自动放大 margin 重试）。
  代码：`inertia_count_below()` / `find_lambda2_upper()`。

三个区间算术坑核查：本次未用 `atan2`；`mp.pi` 用 `+iv.pi` 触发；pad（margin 自动放大直到 LDLT 全部主元
不跨零）覆盖的正是它所代替的浮点误差。`iv.coth/iv.sinh/iv.cosh` 在本机 mpmath 1.3.0 的区间上下文里是坏的
（内部调用不存在的 `ctx.tanh`），改用 `sinh=(e^x-e^{-x})/2` 等手工展开绕开。

## 5. 界为什么这么松，以及 ϖ 大时为什么几乎失效

**松的根源定位**：‖C‖ 的解析上界 ~ u_{N+1}·(fhat(0)-fhat(π))/2，只用了 (T_f+H_f) 的**全局算子范数**
夹逼（引理 2 对偶方向），完全没有利用 f(k)=ϖ²/(ϖ²+k²) 本身在 k→∞ 时 ~1/k² 的**逐点衰减**——那个信息在
夹逼到"整体算子范数"这一步就被冲掉了。所以 ‖C‖ 只随 u_{N+1}~N^{-1/2} 衰减，是很慢的多项式衰减，
不是尾巴该有的速度。

**代价量化**：要把 ‖C‖ 压到比如 <0.5（对 ϖ=30，δ≈3.94，需要 ‖E‖ 明显小于 δ 才有意义），需要
u_{N+1}·47 < 0.5，即 N ≳ 4400；LDLᵀ 是 O(N³) 的区间算术循环，N=4400 在本会话时间预算内不可行
（N=500 耗时 ~112s，N=1000 耗时 858s，按 N³ 标度 N=4400 需要 ~小时级到十小时级，未尝试）。
这就是 ϖ=30 处 N=500 给出**0**（界完全失效，`sinΘ_total`>1 的边界情形）、N=1000 才勉强给出 0.027
的原因——不是公式错，是**尾算子范数上界的衰减速度本身不够快**，撞的是和 `9300dab`（秩一预解式 v
上界廓线路线）类似性质的"结构性代价"墙，只是发生在不同的下游用途上。

**逃逸方向（未在本次做，诚实标注为 open）**：如果能证明一个**逐点衰减**的耦合块范数界（例如用
加权 Schur 检验，把 f(k)~ϖ²/k² 的具体衰减率而不是整体 sup 范数代入），‖C‖ 的衰减率理论上可以从
N^{-1/2} 提到 N^{-3/2} 或更快，届时同样的 N=500~1000 就足以让 ϖ=30 甚至 ϖ=100 给出接近真值的界。
这是本方向如果继续投入、性价比最高的下一步（不是加大 N，是**换一个衰减更快的耦合块估计**）。
本会话未来得及推导/验证这条更细的 Schur 检验，如实标为"下一步，未验证"。
