# ξ(q) argmax 排除半径 bug 类：两个变种，方法论笔记

日期：2026-09-22。作者：`fese-extension`（team-lead 指派的高优先级复核）。

## 0. 一句话

嵌套函数 `ξ(q)` 扫描里，「排除 `q=0` 平凡自重叠峰再取 argmax」这个操作有**两种独立的失效方式**，
后果不同、检出方法也不同，必须分开记账：

- **变种 A（旧，2026-09-22 早，`iron_based_tight_binding_params_2026-09-22.md` 已记录）**：
  **忘记排除** `q=0`——argmax 直接落在自重叠峰上，输出 `Q_AFM=(0,0)`，**一眼假**，肉眼可查。
- **变种 B（新，本笔记，`bafe2as2_graser_finegrid_nesting_2026-09-22.md` 首次发现）**：
  **排除了，但排除半径太小**——argmax 落在自重叠峰**平滑衰减尾部**的某个格点上，
  输出一个看起来合理、非零、非对称点的 `Q_AFM`，**肉眼查不出**，只能靠排除半径扫描（单调退相关）检出。

team-lead 原话："这个变种更毒，因为它给出的输出看起来是合理的。"——本笔记就是把这句话钉成一个可复用的诊断。

## 1. 变种 B 的诊断方法（唯一可靠的检出手段）

**不能**靠画图看峰形状（`ξ(q)` 在粗网格上本来就应该有结构，"看起来合理"不是"是真的"的证据）。

**诊断**：把排除盘的半径从小往大扫（单位取**格点数**，不是 `π` 的弧度单位——见下方 §3 的教训），
每个半径下重新取 argmax，记录位置与数值：

- **argmax 位置随半径单调外移、数值单调下降，直到某个半径后突然稳定不变**
  ⟹ **命中变种 B**：之前所有更小半径的报告都只是同一条自重叠峰尾巴的不同切片，不是真峰。
  稳定后的位置/数值才是真峰。
- **argmax 从最小半径起就已经稳定不变**（或数值/位置在扫描范围内从未随半径变化）
  ⟹ **本诊断未检出**问题。**不得**写成「已确认无污染」——真峰可能恰好离 Γ 很近，
  这是单边界方向问题（CLAUDE.md「单边界方向规则」的应用）：本诊断只能**证有**（单调退相关⟹污染），
  不能**证无**（不退相关 ⇏ 干净）。

## 2. 两个已核验实例（对照）

### 2.1 BaFe₂As₂ Graser 真参数精细网格（命中，变种 B）

脚本 `_graser1003_nesting_scan_2026-09-22.py`（`q_grid=128`，网格步长 ≈0.0156π），
原排除半径 = 3 个格点（≈0.047π）。`_chk_nesting_localmax_scan_2026-09-22.py` 的半径扫描：

| 排除半径（格点） | argmax ξ 值 |
|---|---|
| 1 | 68337.23 |
| 2 | 57609.37 |
| 3（原报告用这个） | 48935.60 |
| 5 | 36698.00 |
| ≥8（≈0.125π） | **33224.86（稳定，往后不再变）** |

**单调退相关**，命中。真峰在 `q≈(±0.516π,±0.516π)`（对角方向），不是原报告的 `q≈(−0.0625π,0)`。
已处理：`bafe2as2_graser_finegrid_nesting_2026-09-22.md` 取代 Plan B 笔记里 BaFe₂As₂ 那一行，
INDEX.md 标 `superseded for BaFe2As2 by ...`。

### 2.2 五材料简化 2-轨道 Plan B 扫描（本笔记新查，**未检出**）

脚本 `_iron_based_nesting_survey_2026-09-22.py`（`q_grid=15`，网格步长 ≈0.224π——**比**变种 B
用到的排除半径 0.15π **还粗**），5 材料共用同一段 `scan_nesting_bz()` 代码（同一遮蔽逻辑，见 §3）。

用 `_chk_iron_based_masking_radius_scan_2026-09-22.py` 对 5 材料分别做格点单位半径扫描
（`r=0..7`，覆盖到约半个布里渊区）：

| 材料 | 旧报告 Q_AFM | 半径扫描 r=0..7 argmax 位置变化次数 | 稳定值（r=7） | 判定 |
|---|---|---|---|---|
| LaFeAsO | (0,0.857π) | 0 | (0,0.857π), ξ=0.0022 | 未检出 |
| BaFe2As2（Plan B 简化模型，非 §2.1 的真参数版本） | (0,0.857π) | 0 | (0,0.857π), ξ=0.0016 | 未检出 |
| LiFeAs | (0,1.000π) | 0 | (0,1.000π), ξ=0.0032 | 未检出 |
| FeSe | (0,1.000π) | 0 | (0,1.000π), ξ=0.0040 | 未检出 |
| FeTeSe | (0,1.000π) | 0 | (0,1.000π), ξ=0.0032 | 未检出 |

**5/5 未检出**——argmax 从 `r=0`（只排除 `q=(0,0)` 单点）起就已稳定，直到 `r=7`（≈半个 BZ）都不变。

**补充机制性证据（比裸半径扫描更强）**：沿 `(0,q_y)` 轴打印完整 `ξ` 剖面，5 材料在**第一个**相邻格点
（`q_y/π≈0.071`）就已从自重叠峰值（0.0188–0.0312）**骤降**到噪声地板（0.0002–0.0034，约 10–15×），
随后才在靠近区边界 `q_y/π≈0.86–1.0` 处**真实回升**。这是一个**非单调**的「陡降→谷底→真实回升」结构，
与变种 B 的「平滑单调衰减尾」在形状上相反 ⟹ 有一个**结构性理由**支持「此处不太可能命中变种 B」：
本脚本的网格（步长 ≈0.224π）比 Γ 自重叠峰的宽度更粗，单点排除足以跳出峰体，
而 §2.1 的精细网格（步长 ≈0.0156π）比峰宽细得多，需要多个格点才能跳出。

**但按 §1 的规则，仍只能写「未检出 + 有机制性支持」，不写「已确认干净」**——
这 5 行 Q_AFM 的严格性维持 `numerical-evidence（简化模型）`，不升级。

## 3. 与变种 A 的区别 + 一个容易踩的混淆点

变种 A（`q=0` 完全不排除）与变种 B（排除但半径不够）**是两个独立 bug**，
`iron_based_tight_binding_params_2026-09-22.md` 已经修过变种 A（加了 `0.15π` 排除盘），
**这次复核确认变种 A 的修复本身没有引入变种 B**（§2.2 表格）——但这是**运气**（网格太粗，
排除半径天然够用），不是这次修复本身的设计保证；换成更细的网格（如 §2.1 的 `q_grid=128`）
**必须**重新做本笔记 §1 的诊断，不能因为"当初 q_grid=15 时测过没事"就免检。

容易踩的混淆点：`0.15π`（变种 A 修复用的排除半径，弧度单位）看起来比
§2.1 变种 B 稳定所需的 `0.125π` 更大，容易误以为"半径已经够大，肯定没有变种 B"。
**这个比较是无意义的**——排除半径要不要够大，取决于它相对**网格间距**的大小，不是相对 `π` 的绝对值：
`q_grid=15` 时 `0.15π` 小于**一个**网格间距（`0.224π`），只排除了单点；
`q_grid=128` 时 `0.15π` 会覆盖约 `10` 个格点，是完全不同的遮蔽强度。
⟹ **报告排除半径时必须同时报网格间距，或直接换算成格点数**，否则"半径 = 0.15π"这句话本身没有信息量。
