## 1. σ² 具体是什么物理量？（先答第一问）

**σ² 不是晶格位置无序（不是合金化/空位/非晶那种结构无序），而是声子谱形状偏离
"单一 Einstein 频率"的展宽参数**——精确定义见 `lambda_stability_tc_joint_ceiling_2026-09-18.md` §3
与 `P4_rigorous_tc_bound.md`：

- 定义测度 `P(dω) := 2α²F(ω)/(λω) dω`（这是 KAY 算子框架与 Semenok λ_* 文献共享的同一个
  概率测度，"记号同构"已被该笔记核过）。
- 写 `ω = ⟨ω⟩_P (1+ξ)`，则 `σ² := ⟨ξ²⟩_P` 就是这个测度下频率的（归一化）**方差**。
- `σ=0` ⟺ `P` 是 δ 函数 ⟺ 单一 Einstein 频率的声子谱（α²F 只在一个 ω 处有质量）。
- `σ>0` ⟺ 声子谱**有宽度**——物理上这可以由很多机制驱动：多支声子色散、
  多种元素质量导致的声子带展宽、合金化/化学无序引起的谱展宽、非谐效应等，
  **σ² 本身只对"谱的形状"敏感，不区分展宽的微观成因**。

⟹ team-lead 原始措辞"晶格无序方差"是一个**可能引起误解的转译**：它不是要求"某种材料在不同
无序度下的晶格结构数据"，而是要求"某种材料序列，其**声子谱形状**（尤其是偏离单频/窄谱的程度）
可控地变化，同时看 Tc 的响应"。这类数据不需要专门的"无序"材料——**任何一批已有 DFT 声子谱
（α²F(ω)）的材料库都自带这个信息**，因为不同材料的声子谱天然有不同的宽度。这是本笔记选择的路径
（见 §2），而不是去找专门的"合金无序度扫描"实验数据。

**可操作的无量纲代理**：真实材料的 α²F 谱只有两个已被广泛报道的矩——
`ω_log`（几何平均）与 `⟨ω²⟩^{1/2}`（即 Cerqueira 数据集里的 `w2av`）。定义
```
r := w2av / wlog   (≥1，恒成立，由 Jensen 不等式；r=1 ⟺ P 是 δ 函数)
```
`r` 是 σ 的**单调代理**（σ 越大 r 越大），但**不是 σ 本身**——两者只在 σ 较小时可用矩展开
互相换算，本笔记未做这个换算（真实材料的 r 可达 2.15，未必在"小 σ"微扰区，见 §4 的严格性声明）。

## 3. 独立对照计算

脚本 `real_material_lambda_star_width_check_2026-09-18.py`：

1. 对每个材料的 `a2F.dos1`，数值积分重算 `λ = 2∫(α²F/ω)dω`，与文件自报的 `lambda=` 行对照
   **验证解析/积分流程正确性**：229/250 材料可解析，**λ 重算 vs 自报中位数相对误差 0.0004%**
   （最大 10.3%，个别材料 DOS 网格稀疏导致，未剔除进主结果但不影响中位数结论）。
2. 同一份谱上再算 `w2av=√(2/λ ∫α²F·ω dω)`、`wlog=exp(2/λ∫(α²F/ω)ln ω dω)`、`r=w2av/wlog`。
3. **直接对该材料的完整谱数值求解 Semenok 稳定阈值**
   `λ_*[P] = 1/max_{u=2πT} (2/λ)∫(α²F/ω)·g(ω/u) dω`，
   `g(x)=6x²+12x³Im ψ'(ix)+6x⁴Re ψ''(ix)`（与 P3 逐字核对过的核，一次性用 mpmath dps=25
   在对数网格上建 1400 点查找表 + 三次样条插值，供后续数值积分/一维最大化重复调用，
   避免对 200+ 材料各自重复做 mpmath 高精度复函数求值）。
4. 跨材料统计 `r` 与 `λ_*[P]` 的相关性——这是对 toy model 里 `κ_S>0`（谱展宽提升稳定阈值）
   这一机制在**真实第一性原理谱**上的独立方向检验，不依赖任何两点谱假设。

## 4. 结果

宽松筛选（`0.02<λ<3`、`λ_*` 有限、`0.999<r<5`）：**n=215/229**。

```
Pearson(r, λ_*)  = 0.9201   (p = 1.2e-88)
Spearman(r, λ_*) = 0.9432   (p = 6.2e-104)
```

更严格筛选（`0.15<λ<3`、`0.98<r<3`，剔除极弱耦合导致 wlog/λ_* 噪声偏大的材料，n=34）：

```
Pearson(r, λ_*)       = 0.9329  (p = 9.6e-16)
Spearman(r, λ_*)      = 0.9034  (p = 2.6e-13)
Pearson(r, λ_*/λ_actual) = 0.8601  (p = 7.1e-11)   # "稳定性余量"随谱展宽同向增大
Pearson(r, λ_actual)     = 0.2059  (p = 0.24，不显著)  # 对照：谱宽度与实际耦合强度本身基本无关
```

粗分箱（按 r 排序对半分）：低-r 半 `r̄=1.095, λ̄_*=4.60`；高-r 半 `r̄=1.507, λ̄_*=7.55`——
方向一致、幅度可观（λ_* 涨约 64%，同期 r 只涨约 38%）。

**方向判断：与 toy model 的 κ_S>0（谱展宽提升 Semenok 稳定阈值）在真实第一性原理 α²F 谱上
方向一致，且相关性很强（|Pearson|>0.9，n 达 215，p 值远超统计显著性阈值）。**
"对照"相关（r 与 λ_actual 本身基本不相关，p=0.24）说明这不是"更强耦合材料恰好谱更宽"这种
混杂变量的假象——λ_* 是纯粹由谱**形状**决定的量，与材料实际的耦合强度 λ 是两个独立自由度，
这与 §1 对 σ² 的定义（σ² 是形状参数，不是耦合强度）自洽。

## 5. 这个检验**没有**证明什么（诚实边界）

1. **只测了机制的一半**：toy model 的 +1.88 结论来自把 `λ_*[P]` 的展宽敏感度（κ_S=5.60）
   与 `Tc(λ,P)` 在固定 λ 下的展宽敏感度（κ₁≈−0.12）**合并**、并令 λ 沿稳定性边界
   `λ=λ_*[P]` 变化，二者相抵后净效应为正。本笔记只独立核验了**前一半**（λ_* 随 r 增大而增大），
   没有对"固定 λ 时 Tc 随谱形状变化"这一半在真实材料上重复检验（这一半其实是文献里更成熟的
   "Einstein 谱在固定 λ,⟨ω²⟩ 时 Tc 最大"结果，本仓库多处已有 certificate 级基础，未在本笔记
   重复）。
2. **样本材料远离稳定性边界**：本批 215 个材料算出的 `headroom=λ_*/λ_actual` 普遍在 20–70
   量级——也就是说，这批常规金属间化合物的实际耦合强度远小于 Semenok 阈值，**它们根本不在
   toy model 假设的"卡在稳定性边界上"的联合天花板场景里**。要真正检验"σ² 提升联合 Tc 天花板"
   这个更强的陈述，需要 λ 接近 λ_*（例如强耦合氢化物候选材料），而 batch-q 250 个材料里没有
   这样的极端材料（本笔记未搜索完整 6912 材料库或专门找强耦合材料子集，是明确的下一步）。
3. **r 只是 σ 的单调代理，不是 σ 本身**：κ_S=5.6035 是在"小 σ 微扰"下用两点谱推出的系数；
   真实材料 r 最高到 2.15（相当程度的展宽），不能假定还在微扰适用区，本笔记**没有**尝试把
   r 换算回 σ² 再和 κ_S 定量比对，只做了方向性（单调性）检验。
4. **λ_*[P] 数值解本身是 numerical-evidence 级**：mpmath dps=25 建表+三次样条插值+400点对数网格
   一维最大化，非区间算术外包，未做收敛性/网格加密复核（仅用自报 λ 做了一次独立正确性核验，
   核验的是"积分流程"而不是"λ_* 求解流程"本身）。
5. **α²F 数据本身是 DFT 计算值，非实验测量**——"真实材料"在这里指"真实第一性原理谱"，
   不是"实验测得的 Tc 随某个可调无序参数变化的序列"。team-lead 原始任务问的后者
   （"无序增大时 Tc 实测是升是降"）**本笔记没有找到、也没有构造出**这样的实验序列数据。

## 6. 严格性标级（逐条）

| 结论 | 标级 | 说明 |
|---|---|---|
| σ² 是 P(dω)-测度下频率的归一化方差（谱形状参数），不是晶格位置无序 | analytic（定义性澄清，继承自已有笔记的定义式，非新证明） | 见 §1 |
| λ 重算与 a2F.dos1 自报值一致（中位误差 0.0004%，n=229） | numerical-evidence（用于验证脚本积分流程正确性，非承重结论本身） | 见 §3.1 |
| r 与 λ_*[P] 在 215/229 个真实材料上强正相关（Pearson 0.92, p~1e-88） | **numerical-evidence**（float64/mpmath 点算，非区间外包；样本为 DFT 计算谱，非实测） | 见 §4；方向与 toy model κ_S>0 一致 |
| "净效应 dlnTc_joint/dσ²=+1.88" 在真实材料上成立 | **未检验，不作此陈述** | 见 §5.1——只测了机制一半，且样本材料远离稳定性边界 |
