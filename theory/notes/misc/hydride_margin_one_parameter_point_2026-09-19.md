## 4. 结果 B [analytic] — 光靠改谱形，永远关不上这个 margin

> **命题 1**　设 `g_max := sup_{x>0} g(x)`。则对**一切**概率测度 `P`，
> $$\lambda_*[P] \;\ge\; \frac{1}{g_{\max}} \;=\; \lambda_*[\text{Einstein}]$$
> 且等号当且仅当 `P` 是单点质量（Einstein 谱）。

**证明**（一行，零计算机辅助）：对每个 `u>0`，因 `P` 是**概率**测度，
`∫g(ω/u)P(dω) ≤ sup_x g(x) = g_max`。对 `u` 取上确界仍有 `max_u ∫g(ω/u)P(dω) ≤ g_max`。
两边为正，取倒数反向，即得。取等需 `P` 把全部质量放在 `g(·/u)` 的极大点上，
即 `P = δ_{ω₀}`、`u = ω₀/x*`。∎

**这条不等式的方向正是需要的方向**：它是 `λ_*` 的**下界**，而 `m_joint = 1` 要求
`λ ≥ λ_*[P]`，所以下界直接给出「所需 λ」的下界——单边界方向审过，产出的是
**"关不上"**（一个必要条件被违反），不是 "PASS"。

**推论**：在固定 `λ` 下对**一切可想象的谱形**取最优，headroom 的最小可能值是
`(1/g_max)/λ`：

| 材料 | λ | 对全体谱形最优化后的 headroom 下界 |

| H3S-200GPa-har | 2.2929 | **1.6100** |
| H3S-200GPa-anh | 1.7210 | **2.1450** |
| D3S-200GPa-har | 2.2938 | **1.6094** |
| D3S-200GPa-anh | 1.7838 | **2.0695** |
| H3S-160GPa-anh | 1.8760 | **1.9678** |
| D3S-160GPa-anh | 1.9412 | **1.9017** |

⟹ **谱形变形（展宽、变窄、多峰、任意重排）在这 6 个材料的实际 λ 上一律无法把
margin 关到 1；λ 本身至少还得涨 1.61×。** 这回答了派活问题 4 要的"analytic 关系"：

## 5. 结果 C [analytic] — N=1 的饱和比有硬顶 1，但**方向必须审**

> **命题 2**　对一切 `λ>1` 与一切二阶矩有限的 `P`，N=1 KAY 临界方程的解满足
> $$u_{T_c} \le \sqrt{\lambda\langle\omega^2\rangle}
> \qquad\text{即}\qquad \mathfrak s^{(1)}(\lambda,P)\le 1 .$$

**证明**：`h₁(x) = x²/(x²+1) ≤ x²` 逐点（分母 ≥1）。代入临界方程，
`1 = λ∫h₁(ω/u_Tc)P ≤ λ∫(ω/u_Tc)²P = λ⟨ω²⟩/u_Tc²`，两边乘 `u_Tc²>0` 即得。∎
（顺带：`h₁<1` 逐点 ⟹ `∫h₁P < 1` ⟹ **`λ≤1` 时 N=1 截断根本无解**，这是
`λ=1` 那一列 `nan` 的来源，不是数值故障。）

> **命题 3**　固定 `P`（`⟨ω²⟩<∞`），`λ→∞` 时 `𝔰⁽¹⁾(λ,P) → 1`。

**证明**：令 `t=1/u`。`∫h₁(ωt)P = 1/λ → 0` 迫使 `t→0`。而
`h₁(y)/y² = 1/(y²+1)` 随 `y↓0` **单调上升**到 1，故由单调收敛
`∫h₁(ωt)P / t² → ⟨ω²⟩`。于是 `t²λ⟨ω²⟩ → 1`，而 `𝔰⁽¹⁾ = 1/(t√(λ⟨ω²⟩))` → 1。∎

**合起来**：`m_1L = √𝔤(2)/𝔰⁽¹⁾ ≥ √𝔤(2) = 1.148102875`，下确界可达但**任何有限 λ 都取不到**。

数值确认（400 点 log 网格，λ∈(1, 1e10]）：6/6 单调下降，
`m_1L(1e10) = 1.148102875` 逐位等于 `√𝔤(2)` 的 CERT-D 两端点（二者在 9 位上重合）；
`𝔰⁽¹⁾ ≤ 1` 在 60/60 组 (材料,λ) 上成立，观测上确界 0.9999999930。

### ⚠ 5.1 方向审计 — 这里差一点就越级（CLAUDE.md 单边界方向规则）

KAY 的 `𝔨⁽¹⁾ ≤ 𝔨` 意味着 **`Tc⁽¹⁾ ≤ Tc_true`**。于是

$$m_{1L}^{\rm true}=\frac{C_\infty\sqrt{\lambda\langle\omega^2\rangle}}{T_c^{\rm true}}
\;\le\; \frac{C_\infty\sqrt{\lambda\langle\omega^2\rangle}}{T_c^{(1)}} = m_{1L}^{(1)} .$$

即 **`m_1L⁽¹⁾` 是真 margin 的上估**。因此：

- **不许写**：「真 margin ≥ 1.1481，所以 margin=1 物理上不可达」。
  命题 2 约束的是**框架自己的下界** `Tc⁽¹⁾`，它只说明
  **N=1 这把尺子永远量不到天花板**，对真 Tc 能否贴上去**一言未发**。
  这是一条单边行产出 "FAIL"，按规则即是 bug。
- **可以写**：`m_true ≤ m⁽¹⁾`。方向反过来用，反而给出**有用**的结论——
  它说天花板**离真值不远**，而不是远。
- 真 margin 唯一声音的**下界**是一行公式定理本身：`m_true ≥ 1`。

## 7. 结果 E — 「1.345 是普适常数」是我自己的一个假设，已被自己的压力测试推翻

第一版看到 6 个真实谱 + Einstein 全部落在 `m⁽¹⁾(λ_*) ∈ [1.3446, 1.3465]`（散布 0.06%），
我差点写下"稳定性边界上的 margin 是一个普适常数 ≈1.345"。

按 CLAUDE.md「采样要能触发前提的边界」做定向构造后，**该假设为假**：
一个 **90/10 双峰谱**（90% 权重在 20 meV、10% 在 300 meV）给出
`𝔰⁽¹⁾(λ_*) = 0.3613`、`m⁽¹⁾(λ_*) = 3.178`。

**机制**（可解析看出，非拟合）：`⟨ω²⟩` 被少数高频权重主导，而 `Tc` 由多数低频权重钉住。

⟹ **一行公式对"带轻高频尾巴的谱"天生松**，这是二阶矩作代理的固有缺陷，与 λ 无关。

500 组随机多峰形（1–3 个高斯峰，宽度 0.8–80 meV，幅度跨 50×）的正式搜索：

- `m⁽¹⁾(λ_*)`：min **1.34458**、median 1.34499、max **2.06499**

- 手工构造的 90/10 双峰达到 3.178 ⟹ **上方无界**

⟹ **修正后的陈述**：`m⁽¹⁾(λ_*[P],P)` **不是**普适常数；Einstein 谱似乎是它的
**最小化子**（`1.34458`），而它可以任意大。§6 那张 `[1, 1.346]` 的表

**标级**：「Einstein 最小化 `m⁽¹⁾(λ_*)`」= **numerical-evidence**（0/500 + 定向构造），

## 8. 结果 F — `λ⟨ω²⟩` 在非谐重整化下不变：真实 DFT 数据上的直接确认

一行公式的**唯一**谱输入是 `λ⟨ω²⟩ = 2∫ω α²F(ω)dω = η/M`。
`oneliner_zero_parameter_2026-09-18.md` §5 断言"靠声子软化拿高 Tc 是假问题：
软化抬高 λ，但 `λ⟨ω²⟩` 不变，天花板不动"（定理 2）。这在同一材料同一压强的
**谐波 / 非谐**配对上是一个可直接证伪的预言：

| 配对 | `λ⟨ω²⟩` 谐波 | `λ⟨ω²⟩` 非谐 | 相对差 | Tc_1L 谐波 (K) | Tc_1L 非谐 (K) |
|---|---|---|---|---|---|
| H3S 200GPa har→anh | 38341.9997 | 38341.9507 | **1.3e−6** | 415.208 | 415.207 |
| D3S 200GPa har→anh | 19827.4176 | 19827.4097 | **4.0e−7** | 298.580 | 298.580 |

作为对照，**同一对里** `λ` 移动 2.2929→1.7210（**−25%**）、`ω̄₂` 移动 129.3→149.3（**+15%**），
两者几乎精确抵消。⟹ **非谐修正把 λ 砍掉四分之一、把谱拉宽 15%，却把天花板挪动了不到 1e−6。**

**⚠ 两条必须跟着这个数走的限定（否则会被读成比实际更强的结论）**：

1. **1.3e−6 这个精度只由两套二阶求积支撑**（trapezoid 与非均匀 Simpson，二者互相吻合到 3e−10，
   远小于 har/anh 之差 4.9e−2 绝对值）。**第三条独立路径**（§1 的 Stieltjes 重建，一阶精度）
   只能把不变性确认到 **2.7e−4 / 2.1e−4**，因为它自己的离散误差在绝对矩上就有 0.34%。
   ⟹ 可以安全陈述的是「不变到至少 3e−4，两套二阶求积给 1.3e−6」，
   **不要**单独引用 1.3e−6 而不说它依赖哪一套求积。
2. **这很可能不是一次独立的经验检验，而是"工作流满足了定理的前提"。**
   若 Mishra 的 SSCHA/EPW 流程在非谐重整化时**保持形变势不变、只重整化声子频率**，
   那么 `∫ωα²F dω` 就是**按构造**精确守恒的——而"形变势与核运动无关"**正是** (A2)
   Born–Oppenheimer 解耦，即定理 2 自己的假设。
   ⟹ 这条数据确认的是**该 DFT 工作流落在定理的适用域内**，
   **不是**"定理的预言被自然界独立验证了"。我**未**核查 Mishra 的流程是否真的这样做
   （需读 arXiv:2510.25902 的方法节或 `epw.in`），故此处只标出这个歧义，不作判定。

**顺带一个不能过度解读的数**：`λ⟨ω²⟩(H3S)/λ⟨ω²⟩(D3S) = 1.93378`（200 GPa，谐波与非谐
**同一个值**）、1.93639（160 GPa）。**不要**把偏离 2 的部分直接读成"η 的同位素漂移"——
H3S 的 `λ⟨ω²⟩ = Σ_a η_a/M_a` 里**硫子晶格那一项在 H→D 下根本不变**，
所以即使 (A2)(A3) 完美成立这个比值也不该是 2。要分离 η 漂移得先做模式分解，本轮**未做**。

## 9. 对 team-lead 设问的正面回答：松，还是物理？

**都不是"理论松"这个简单答案。拆开是三件不同的事：**

1. **`F₁ = √𝔤(2) = 1.1481` 这一份是"尺子"，不是材料，也不是定理。**
   它只出现在拿 N=1 KAY **下界**去量天花板的时候，对一切 λ、一切谱形恒定存在。
   换成完整 KAY 算子它就消失（一行公式在 λ→∞ 的 Einstein 谱上是渐近锐的）。
   **不可据此声称物理上关不上**（§5.1）。

2. **`F₂ ≈ 1.172` 这一份是"稳定性约束的代价"。**
   一行公式只在 `λ→∞` 锐，而 Semenok 把 λ 硬顶在 `λ_*[P] ≲ 5.8`。
   **在允许的最大耦合处，天花板仍高出 17%**——这是物理内容，不是松弛。

3. **`F₃ = 1.25–1.81` 这一份才是"这些材料离极限还有多远"，也是全部材料间差异的来源。**

**"margin=1 的参数点物理上可达吗"——逐个天花板作答：**

| 天花板 | margin=1 要什么 | 可达？ |
|---|---|---|
| 联合（稳定性） | `λ = λ_*[P] ∈ [4.82, 5.81]`，即 λ 涨 2.1–3.4× | **原则上可达**（那就是稳定性边界的定义）；对应 Tc 322–567 K。⚠ 它是否高于"已报道的最大氢化物 λ"**本轮未做普查**，不作此断言 |
| 联合，且允许任意改谱形 | 仍需 `λ ≥ 3.691492`（**命题 1**），即至少涨 1.61× | **谱形变形单独永远不够**[analytic] |
| 一行公式（真 Tc） | `λ→∞` **且** Einstein 谱 | **与稳定性约束直接冲突**：`λ ≤ λ_*[P] < ∞`。在边界上余量 ≤1.346（那 6 个谱形） |
| 一行公式（N=1 下界） | — | **任何 λ、任何谱形都不可能**，硬顶 `√𝔤(2)=1.1481`[analytic]，但这是尺子的性质（§5.1） |

**一句话**：2–3× 的余量**不是**定理松了 2–3 倍。把它拆开，
`√𝔤(2)=1.148` 是 N=1 这把尺子自带的、`1.172` 是"稳定性不让 λ 跑到无穷"这条物理买的、
剩下的 `1.25–1.81` 全是"H3S/D3S 离自己的稳定性极限还差 2.1–3.4 倍 λ"。
**真正的结论是天花板比上一篇看起来的紧得多**：谱形卡在边界上时它只高出 ≤34.6%。
而 margin=1 无法靠改谱形达到——这一条是被**证明**的，不是没搜到。

## 11. 诚实边界（没有证明的部分）

1. **全程 N=1 KAY 截断**。§6 的夹逼上端完全由它给出；换完整算子后上端会**下降**
   （`Tc_true ≥ Tc⁽¹⁾`），夹逼只会更紧，但具体值未知。
2. **全程 μ\*=0**。真实 H3S 的库仑亏损约 30%（见 `../materials/` 亏损预算系列），
   这会把真 Tc 压低、把 margin 推高——§6 的 `[1,1.346]` 是 μ\*=0 的陈述，
   **不能**直接与 §1 的实验比值（1.92–2.26）相减来归因。二者量的不是同一个 Tc。
3. **`λ_*` 的文献地位继承上游**：Semenok–Altshuler–Yuzbashyan 的稳定性阈值，
   本仓对其机制的理解仍停在 WebFetch 摘要级（`lambda_stability_tc_joint_ceiling_2026-09-18.md` §2/§6.5），
   **本笔记未补 PDF 全文核实**。命题 1 是对"给定这个 `λ_*` 定义"的纯数学陈述，
   不依赖该文献主张是否正确；但 §3/§9 里"物理上可达"的解读依赖它。
4. **没有区间算术**。全部数值是 float64/mpmath 点算，最高只到 numerical-evidence 档。
   `√𝔤(2)` 是唯一继承 rational-exact 的量。
5. **只有 H3S/D3S 一个化学体系**（继承上一篇的样本限制）；§7 的随机形状搜索是合成谱，
   不是真实材料。
6. **命题 1 的取等分析**只论证了"需 `P` 集中于 `g(·/u)` 的极大点"，
   **未处理 `g` 的极大点是否唯一**（数值上在 `x*=0.327321` 附近看是唯一的，未证）。
   若非唯一，取等集比"单点质量"大。这不影响不等式本身。
7. **`λ` 与谱形独立可调**是本笔记形变族的假设。真实材料里压强/成分同时改变两者
