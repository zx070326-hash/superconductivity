## 1. 问题

仓库现有两条独立证据链：

- **Tc(λ) 链**（P4，KAY 算子框架）：对任意固定 λ>0、任意谱形测度 P(dω)，
  `Tc ≤ C_∞√(λ⟨ω²⟩)`，Einstein 谱极值定理（certificate 级）保证固定 λ、⟨ω²⟩ 时
  Einstein（单频）谱使 Tc 最大。λ 在这条链里是**自由参数**。
- **λ 上界链**（P3，Semenok–Altshuler–Yuzbashyan，arXiv:2407.12922）：给定声子谱形 P(ω)，
  存在稳定性阈值 `λ_*[P] = 1/max_T ∫g(ω/2πT)P(ω)dω`，超过它电声耦合会破坏体系稳定性；
  这是**独立于** Tc(λ) 链推出的。

派活方原始设问框架担心：λ_* 依赖的是"声子谱在**所有动量点** q 上的行为"（Kohn 反常 / 声子软化，
即动量分辨的 Π(q,ω)），而 Tc(λ) 链早已把动量结构积分掉、只依赖**频率分布** P(ω)——
若果真如此，两条链之间存在"信息不对称"，无法直接拼接成一条自洽联合约束。

本笔记的任务：判断这个担心是否成立，如果不成立、能否给出一个（哪怕只是玩具/局部级别的）
显式联合自洽计算，并诚实标级每条结论。

## 2. 现有 λ 上限推导基础核对

先核对仓库对 λ_* 机制的既有理解是否准确——这一步发现派活设问的前提需要订正。

**订正 1（旧陈述哪里可能误导 / 新陈述凭什么对，分两段写）**：

- 旧设问的隐含前提：λ_* 是由**动量分辨**的声子软化（Kohn 反常，ω²(q)<0 于某些 q）给出的。
- 核查结果（WebFetch 摘要级source，见下方标级说明）：λ_* 机制论文
  Yuzbashyan–Altshuler–Patra, *Instability of metals with respect to strong
  electron-phonon interaction*, PRL 135, 026503 (2025)（arXiv:2409.19562）指出，
  Semenok–Altshuler–Yuzbashyan（arXiv:2407.12922，Adv. Mater. 2025）给出的稳定性阈值来自
  **各向同性 Migdal–Eliashberg 框架内的电子准粒子权重 / 电子比热为负**（`C_el<0`），
  是一个**频率域**（非动量分辨）的不稳定性判据，不是声子频率软化 / Kohn 反常机制。
  换句话说，λ_* 本身就是 P(ω) 的泛函，**不需要**任何动量分辨输入。

标级：此项**文献主张**基于 WebFetch 摘要页（未逐字核对全文 PDF），
证据强度介于"literature claim"与"内部一致性佐证"之间，**不到仓库四档任何一档**（那四档只适用于
仓库自产的数学/数值结论）。下方给出独立于此文献主张的、仓库内部证据（见"记号同构"），
后者才是本笔记结论真正依赖的部分。

**内部佐证（更硬）**：`theory/derivations/P3_tc_max_pressure.md` 记录的"记号同构（金子）"
发现——Semenok 的 `P(ω) := 2α²F(ω)/(λω)` 与 KAY 算子框架里的 `P(dω)`（Tc(λ) 链里出现的同一测度）
**是同一个对象**。P3 整篇 λ_* 推导（λ₀=3.6915 Einstein / 4.7186 Debye，κ=5.6035，c₃=0.8959，
均已复核为该文件既有内容）自始至终只用到 P(ω) 的矩，从未引用任何动量分辨数据。
这是比 WebFetch 摘要更可信的证据：**它是仓库自己已经做过的推导，结构上就是频率域泛函**，
与文献主张（机制是频域电子不稳定性，非动量分辨声子软化）互相印证、独立成立。

⟹ **该项判断：两条链共享同一个测度 P(dω) 作为论域，不存在设问所担心的"动量信息被 Tc 链丢弃"
这一障碍**——至少对仓库实际引用的这个 λ_* 文献是如此（一个真正动量分辨的 DFPT/Kohn 反常
机制会是另一个更难的故事，但那不是仓库现在用的这个界的来源）。

## 3. 耦合点分析

两条链在数学上都是**同一测度 P(dω) 上的 Jensen 型泛函**：

- `λ_*[P] = 1 / max_{T} ∫ g(ω/2πT) P(dω)`，其中 g(x)=6x²+12x³Im ψ'(ix)+6x⁴Re ψ''(ix)
  （P3_tc_max_pressure.md §4，与 arXiv:2407.12922 Eq. S12 逐字核对过）。
- `𝔨^(N)(P,T) = ∫ h_N(ω/2πT) P(dω)`（KAY 算子截断，N=1 时 `h_1(϶)=϶²/(϶²+1)`，
  这是 KAY 定理 4 的显式闭式，是完整算子 𝔨 的一个**下界**：`𝔨^(1) ≤ 𝔨`）；
  Tc 临界条件是 `λ·𝔨(P,Tc)=1`。

两者都已在仓库里独立做过**围绕 Einstein 点的矩展开**：

- P3（`P4derivations/P3_tc_max_pressure.md`）：`λ_*(σ,γ₃)/λ₀ = 1+½κ_Sσ²+c₃γ₃σ³+O(σ⁴)`，
  `κ_S=5.6035`，`c₃=0.8959`（ω=⟨ω⟩(1+ξ)，σ²=⟨ξ²⟩，γ₃=⟨ξ³⟩/σ³）。这是仓库已有、本笔记未重新
  推导的既存结论，标级维持其原有标注（`misc/P3_lambda_star_onepager_2026-09-09.md` 现标
  `numerical-evidence`，2026-09-18 team-lead 已裁定降级——早于四档制、未标格数/有理数个数）。
- P4-A（`theory/derivations/P4_rigorous_tc_bound.md`）：`𝔨^(N)(P,T)=h_N(϶̄)[1+½κ_N(϶̄)σ²+c_{3,N}(϶̄)γ₃σ³+O(σ⁴)]`，
  N=1 闭式 `κ₁(϶̄)=(2−6϶̄²)/(϶̄²+1)²`（analytic，hand-derived + sympy 核验，本笔记独立复核见下）。
  **关键差异**：κ_N(϶̄) 是 ϖ̄ 的函数（不是像 κ_S 那样的纯数），因为这个展开不是"在核自身极大点上做的"
  （没有 envelope theorem 抵消 σ³ 阶的鞍点位移）。

P4-A 自己在 2026-09-09 已标记待办 T3："若把 KAY 侧也在 T 上取极大……϶̄ 被自洽钉住……是 §4 待办"——
即仓库早已识别但从未执行本笔记要做的这个联合自洽计算。

## 4. 自洽草图（玩具级实现 + 双重独立复核）

**设定**：N=1 KAY 截断（已知的、最松的 KAY 近似）+ 精确 Semenok 核 g(x)，
对称两点谱 `P = ½δ_{1−s} + ½δ_{1+s}`（⟨ω⟩=1 固定，σ=s，因对称 γ₃=0）。

**自洽方程组**：
```
λ_*(s) = 1 / max_{u=2πT>0} [g((1−s)/u)+g((1+s)/u)]/2
u_Tc(s) 解:  λ_*(s)·[h₁((1−s)/u)+h₁((1+s)/u)]/2 = 1
```
数值实现：mpmath dps=30，黄金分割搜索求 λ_*(s) 的 max_T，二分法解 Tc 自洽方程。
脚本：`_scratch_ir/lambda_stability_tc_joint_toy_2026-09-18.py`。

**s→0 基线复核**：`λ_*(s→0)=3.691492…`，与 Semenok Einstein 值 3.6915 一致（5 位）。

**结果（联合天花板随谱展宽 s 的变化）**：Tc(s)/Tc(0) 在 s=0.30 处为 1.1647，
**单调随 s 增大**——即：一旦把稳定性约束 λ≤λ_*[P] 折进来，"联合 Tc 天花板"
**不再必然在 Einstein 谱（s=0）取最大**，与不受约束的 Einstein 极值定理（P4 主线定理）的
直觉相反。这是本笔记的核心发现。

**领头阶（σ²）系数，双路独立验证**：

1. 直接数值路径：对 s∈{0.002,…,0.1} 做 `d ln Tc/ds²`，s→0 收敛到 **1.8795–1.8797**
   （`_chk_lambda_tc_convergence_2026-09-18.py`，同时确认 λ_*(s) 单独分支
   `Δλ/λ0/s² → 2.802 = ½κ_S`，与 P3 的 κ_S=5.6035 精确一致——排除了这是有限 s 假象的可能）。
2. 隐函数定理闭式组合：设 `G(u,σ):=λ(σ)·⟨h₁⟩(1/u,σ)−1=0`，
   `λ(σ)=λ₀(1+½κ_Sσ²)`，`⟨h₁⟩(϶̄,σ)=h(϶̄)(1+½κ₁(϶̄)σ²+O(σ³))`：
   ```
   ∂G/∂σ²|₀ = ½(κ_S+κ₁(϶̄₀)) = ½(5.6035−0.12187) = 2.740815
   ∂G/∂u|₀  = −λ₀ h'(϶̄₀) ϖ̄₀² = −3.691492×0.648047×0.371541 = −0.888797
   du/dσ²   = −(∂G/∂σ²)/(∂G/∂u) = 3.0838
   d ln u/dσ²|₀ = 3.0838/1.640577 = 1.8797
   ```
   （϶̄₀=0.609542，u₀=1.640577 是 s→0 基线的自洽解。）

两条独立路径在 4 位有效数字上一致（1.8795 vs 1.8797），**互相独立复核通过**。

（订正记录，按 W1 纪律分两段写：本笔记草稿阶段第一次手推 `du/dσ²` 时把隐函数定理的链式法则用错，
得到 `dlnTc/dσ²=1.1457`——**旧陈述错在哪**：把 ϖ̄ 当自变量直接对 σ² 求导、漏了 ϖ̄=1/u 的雅可比因子；
**新陈述凭什么对**：κ_S 单独分支（=5.6035，与 P3 精确一致）和 κ₁(϶̄₀) 单独分支
（`_chk_kappa1_direct_2026-09-18.py`：固定 u=u₀ 只变谱形，`rel_dev/s²→−0.060933`，
与解析预测 `κ₁(϶̄₀)/2=−0.0609334` 5+ 位吻合）两个零件都独立验证无误后，
才重做了一次完整链式法则推导，其结果与直接数值解（1.8795–1.8797）4 位一致，两条独立路径互证，
不是仅凭"旧的错了"就采信新数。1.1457 已废弃，不作为本笔记任何结论使用。）

**直觉解释**：λ_* 对展宽的敏感度（κ_S=5.60）比 N=1 KAY 核对展宽的敏感度（|κ₁(϶̄₀)|≈0.12）
大约 46 倍。也就是说：把谱从 Einstein 展宽一点点，"允许的 λ 上限"涨得比"给定 λ 时 Tc 质量因
偏离 Einstein 而损失的量"快得多——净效果是联合天花板反而升高。

## 6. 未解决点

1. **偏度 (γ₃) 项未独立核验**。真实声子谱（尤其声学支软尾）常有 γ₃<0；若 KAY 侧的
   c_{3,1}(϶̄₀) 与 P3 的 c₃=0.8959 组合后系数够大且反号，有可能在 γ₃ 显著偏离 0 时
   翻转 §4 的净效应符号。本笔记**未**对此做数值核验（只有 §4 对称两点谱，γ₃≡0 时的结果）。
2. **N=1 是最松的 KAY 截断**。κ₁(϶̄)、结果的具体数值都依赖这个截断；N→∞ 完整算子的
   κ(϶̄) 未推导，也未评估结论是否对 N 稳健（仓库已有的"interchange uniformity"机制原则上
   可以把 N=1 换成完整算子，但需要额外工作，非本笔记范围）。
3. **只是局部（σ→0）微扰结果，非全局变分定理**。真正的"联合 Tc 天花板"应是
   `sup_{P, λ≤λ_*[P]} Tc(λ,P)`，本笔记只验证了在 Einstein 点附近这个 sup 沿"展宽"方向
   是增函数，未证明全局最大值在哪、是否仍有界、是否 Einstein 谱仍是某种约束下的极值点。
4. **μ*=0 全程**（仓库系统性限制之一，未在本笔记内尝试放开）。
5. **Semenok 机制文献主张**（§2）仅 WebFetch 摘要级，未过 PDF 全文——若后续要把"两条链
   共享测度"这件事作为承重结论使用，应补一次全文 PDF 复核。
