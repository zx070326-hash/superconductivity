### 1.2 关键发现：SCDFT vs RPA
**Essenberger 用的不是裸 RPA，而是 SCDFT (superconducting density functional theory)**

- Eq.(32): **Λ^SF = 2∬ f_xc χ f_xc**（sandwich form）
  - `f_xc` = 交换关联核（exchange-correlation kernel）
  - `χ` = 玻色子传播子
  - 这不是 `χ^s = χ₀(1 - U χ₀)^{-1}` 的 RPA 形式

- **memory 已有记录**: "Eq.(32) 同余推断已撤回（f_xc 符号不定）"
  - 即使 sandwich 结构也不保证 PSD

### 2.2 Phase 1: 5-轨道微观实现（三处数值缺陷）

#### 缺陷 1: k-space 归一化缺失 1/(2π)² 因子
**症状**: DOS ~ 161 而非 ~ 4（每轨道应 ~0.8）

**根因**: 
```python
dk = (2*np.pi / k_grid)**2  # 错误：未除 BZ 面积
```

**修复**:
```python
dk = (2*np.pi / k_grid)**2
BZ_area = (2*np.pi)**2
dk_normalized = dk / BZ_area  # 正确
```

**验证**: 修复后 DOS = 4.09，每轨道 ~0.82 ✓

#### 缺陷 2: Lindhard 公式符号约定
**问题**: 分母 `ε_k - ε_{k+q}` 还是 `ε_{k+q} - ε_k`？

**最终形式**（与文献一致）:
```python
chi0_band = (f_k[m] - f_kq[n]) / (eig_k[m] - eig_kq[n] + 1j*eta)
```

**q=0 特殊处理**（L'Hospital）:
```python
if abs(qx) < 1e-10 and abs(qy) < 1e-10 and m == n:
    chi0_band = f_k[m] * (1 - f_k[m]) / T  # -∂f/∂ε
```

#### 缺陷 3: 轨道投影公式
**带基 → 轨道基**正确公式:
```python
chi0_orbital[i,j] += conj(U_k[i,m]) * chi0_band_mn * U_kq[j,n] * dk
```

**注意**: 不是 `|U|²`（那是密度投影），而是**相干叠加**

## 4. 物理解释：为什么裸 RPA 可以有负本征值？

### 4.1 波动-耗散定理的约束
**定理**: Im χ(q, ω>0) ≥ 0（因果性 + 能量耗散）

**不约束**: Re χ(q, 0)（静态实部）

### 4.2 多轨道投影的相干效应
- 带基 Lindhard 对角元: f(1-f)/T **总是正**
- 轨道投影: 
  ```
  χ₀^orb = Σ_{mn} U*_m χ₀^band_mn U_n
  ```
  - **相干叠加**可以产生负干涉
  - 类似量子力学中的"负概率幅"

### 4.3 RPA 的反馈机制
χ^s = χ₀ (I - U χ₀)^{-1}

- 如果 χ₀ 某个本征值 λ₀ < 0
- RPA 后: λ_s = λ₀ / (1 - U λ₀)
  - 分母 (1 - U λ₀) > 1（因为 U > 0, λ₀ < 0）
  - **λ_s 更负**（绝对值放大）

**结论**: RPA 会**放大**负本征值，不是消除

## 5. 物理解释与边界条件

### 5.1 静态 χ(q,0) 非 PSD 是否违反物理定律？

## 6. 与 Essenberger 的关系

### 6.1 Essenberger 的 Λ^SF 构造
**Eq.(32)**: Λ^SF = 2∬ d³r d³r′ **f_xc(r,r′)** χ(r,r′) **f_xc(r′,r″)**

- 如果 χ 是 Hermitian，sandwich 可以改变符号结构

### 6.2 为什么 sandwich 可能产生 PSD？
**理论可能性**: 如果 f_xc 的谱分解恰好"翻转"负本征空间

但 **memory 已撤回**: "f_xc 符号不定" ⟹ sandwich 不保证 PSD

### 6.3 本次扫描的发现
**不是"部分 q 有负本征值"，而是**:

**这意味着**:
1. 裸 RPA 不是"接近但不够" — 而是**结构上不可能**（在静态极限）
2. Essenberger 的 f_xc kernel 必须有**极强的符号翻转能力**，或
3. Eq.(37) 成立因为他们用**动力学 Im χ(q,ω)**（频率积分后）

### 6.4 结论
**Eq.(37) Im Λ^SF > 0 若在 Essenberger 的 SCDFT 中成立，其来源只能是**:
1. **动力学效应**：ω>0 时 Im χ ≥ 0（涨落耗散定理）→ 积分后 PSD
2. SCDFT 的 f_xc kernel 顶角修正
3. 自洽循环产生的反馈效应

**裸静态 RPA 不能重现该结果，但这不是矛盾**：
- 静态 Re χ(q,0) 非 PSD ← **Team B 证明**
- 动力学 ∫dω Im χ(q,ω)/ω PSD ← **memory 0/23000 扫描**
- 两者兼容（Kramers-Kronig 关系）
