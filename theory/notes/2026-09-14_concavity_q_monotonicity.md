# 凹性的等价重述：H″ = −q′(x)/x（主会话探针，2026-09-14）

**状态**：数值上确立的**恒等式 + 等价性**，尚未解析证明。这是把引理 C
（凹性定理）从证书级推向解析级的候选主线。

## 1. 两个恒等式

记 f(k;x) = x/(k²+x)，H(x) = λ₁(𝒪[f(·;x)])，v = v_x 为顶向量（归一）。

**(Q1) 核层面的线性恒等式（精确，误差 ≤ 2.2e-16）**

    ∂f/∂x = k²/(k²+x)² = ( f − f² ) / x        ⟹    𝒪[∂_x f] = ( 𝒪[f] − 𝒪[f²] ) / x

因 𝒪[·] 对核逐元线性。这一条是纯代数的，无需任何谱信息。

**(Q2) 由 (Q1) + Feynman–Hellmann（包络定理）**

    x H′(x) = H(x) − q(x),        q(x) := ⟨v_x, 𝒪[f(·;x)²] v_x⟩

数值验证：|xH′ − (H−q)| ≤ 1.6e-9（x∈[0.05, 51.2]，有限差分精度限制）。

对 x 再求导，H′ 项消去：

    **H″(x) = − q′(x) / x**

数值验证：−q′/x 与直接二阶差分 H″ 逐位相同（11 个 x 值，全部 5 位小数一致）。

**⟹ 引理 C（H 在 (0,∞) 严格凹） ⟺ q 在 (0,∞) 严格递增。**

这个重述把「二阶导为负」换成「一阶导为正」，且 q 是一个**二次型**而非本征值，
所以可用的工具从谱扰动换成了核层面的单调性 —— 与引理 M / 定理 2 同一族工具。

要证凹性，够用的是两条**解析**陈述：

- **(A) E(x) > 0**：g > 0 逐点，但 𝒪[·] 含 −L1 对角项，故正核**不**自动给正二次型
  （实测 λ_min(𝒪[g]) < 0，见探针）。要的是「在 v 上」为正，或找一个更弱的够用形式。
  注意 g = 2x k²/(k²+x)³ 与 (Q1) 同族：g = 2(f² − f³)/x，故
  𝒪[g] = 2(𝒪[f²] − 𝒪[f³])/x —— 又是纯代数关系，可能让 E 归约到 q 与三次矩。
- **(B) |C| < E**：C 是顶向量运动项，标准形式为
  C = 2 Σ_{j>1} ⟨v,𝒪[f²]w_j⟩⟨w_j,𝒪[∂_x f]v⟩/(h−λ_j)。用 (Q1) 把右因子写成
  −⟨w_j,𝒪[f²]v⟩/x（因 ⟨w_j, 𝒪[f]v⟩ = 0 对 j>1），得

      **C = −(2/x) Σ_{j>1} ⟨v,𝒪[f²]w_j⟩² / (h−λ_j)  ≤ 0  自动。**

  于是 |C| ≤ (2/x)‖(I−P₁)𝒪[f²]v‖²/g_gap，只需一个**隙下界**与一个残差范数上界。
  C ≤ 0 是自动的这一点已由上表逐行确认（C 全负），不需要额外假设。

## 5. 追加（同日，主会话第二轮探针）

### 5.1 (A) 的代数归约成立，精确

    g = d(f^2)/dx = 2(f^2 - f^3)/x   ==>   O[g] = 2(O[f^2] - O[f^3])/x
    **E(x) = 2( q(x) - <v, O[f^3] v> ) / x**

数值：|E - E_alg| <= 2.8e-16（varpi in [0.2,20]，10 个点）。故

    **(A) <==> <v, O[f^3] v> < <v, O[f^2] v>**

即「顶向量上，三次核的二次型小于二次核的」。逐点有 0 < f < 1 ==> f^3 < f^2，
但 O 含 -L1 负对角，对核不保序（实测 lam_min(O[g]) < 0），所以要的是**顶向量上的
弱保序**，不是算子序。这是引理 M 那一族工具的自然适用场景。

### 5.3 试探向量的诊断（Neumann 迭代不行）

(M1) 的久期方向 (h+D-R)^{-1}tau 与真顶向量重叠恰为 1.0000（确认 (M1) 提取正确），
但可解析控制的近似都不行：tau 本身 0.15-0.61；(h+D)^{-1}tau 为 0.14-0.52；

故「找一个重叠 >= 0.95 的显式试探向量」这条路暂时封闭，交换子路线取代它。

### 5.4 修订后的瓶颈

不再是「v 的解析控制」，而是这两条：
- **(A)**：<v,O[f^3]v> < <v,O[f^2]v> —— 核层面比较，疑似可用引理 M 族工具。
- **(B)**：||[A,B]v|| 的解析上界（**作用在 v 上**，不是算子范数）。交换子的核层面
  表达式值得先算出来：[O[f],O[f^2]] 是否有闭式或可控的核表示。小 varpi 时它极小
  （varpi=0.2 时 3e-5），提示交换子对 varpi 有高阶零点，这个阶数若能定出，小 varpi
  段自动闭合。
