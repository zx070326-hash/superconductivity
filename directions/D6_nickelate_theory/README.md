# D6 · 镍酸盐超导理论（La3Ni2O7 及相关体系）

层级：非常规（热点）　状态：调研中（2026-09-07）

## 范围

- 实验基线：高压 La3Ni2O7（2023，Tc ~80 K）、La4Ni3O10、常压薄膜 (La,Pr)3Ni2O7（2024–2025）、2025–2026 最新（样品质量、体积分数、压力相图）
- 理论模型：双层两轨道（d_x²-y² + d_z²）、层间 d_z² 强耦合 → s±、d 波竞争、Hund 物理、双层 t-J 的 DMRG
- DFT+DMFT 电子结构（γ 口袋是否存在）与 ARPES 对比
- 无限层 NdNiO2 比较："镍酸盐是不是铜氧化物类比"之争
- 电声耦合是否被排除
- 哪些理论预测已被/可被 2025–2026 实验证伪

## 核心问题

配对机制有没有共识？理论社区的主要分歧线在哪？**什么样的第一性原理计算现在最能区分不同理论？**
