# D5 · 非常规超导配对的第一性原理与数值多体方法

层级：非常规　状态：调研中（2026-09-07）

## 范围

- 2D Hubbard 基态之争：Qin et al. PRX 2020（t'=0, U=8 无超导，条纹胜出）→ t' 效应（Jiang–Devereaux 2019 起）→ Xu et al. Science 2024（超导与部分填充条纹共存）→ 2025–2026
- 团簇 DMFT（DCA/CDMFT）d 波；DΓA、dual fermion、TRILEX、fRG 现状
- 铁基 DFT + RPA 自旋涨落（s± vs d）
- 铜氧化物 ab initio 下折（cRPA）+ mVMC/DMRG（Imada 组）及争议
- 神经网络量子态、张量网络、AFQMC 的最新结果
- Hubbard–Holstein：电声与自旋涨落的协同/竞争
- 冷原子/量子模拟的实际贡献
