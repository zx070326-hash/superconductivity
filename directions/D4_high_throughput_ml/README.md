# D4 · 常规超导体的高通量计算与机器学习

层级：L1 及其可靠性　状态：调研中（2026-09-07）

## 范围

- 高通量 DFPT + Allen-Dynes 数据库：Choudhary & Garrity 2022（JARVIS，~10³）、Cerqueira/Sanna/Marques 2023–2024（数千）、2024–2026 其他组；方法层级与已知系统误差
- ML 预测 λ、ω_log、α²F 或直接预测 Tc（BEE-NET 及 2024–2026 GNN/Transformer）
- 廉价描述符与筛选漏斗，每层假阴性/假阳性率
- 通用 MLIP（MACE/CHGNet/M3GNet）+ 电声耦合
- 常压/低压氢化物与三元氢化物设计（Mg2IrH6 等）；常压常规超导 Tc 理论上限
- 生成模型逆向设计
- 数据集（SuperCon、3DSC、JARVIS-SC）与 ML-Tc 预测器的陷阱

## 核心问题

- 高通量的哪一层（谐波 DFPT / ML 代理 / 描述符）误差主导？
- 高通量结果作为**排序变量**（而非绝对预测）的可靠性如何验证？
- 有没有工作把非谐、各向异性、ab initio 库仑纳入高通量？
- 筛出来的候选有多少被实验验证过？

## 现状摘要

高通量成三级漏斗，多数仍用固定μ*+各向同性ME（Cerqueira 2024, 2307.10728）。BEE-NET打通预测-合成闭环，2/741获实验证实（Gibson 2026, 2503.20005）。ω_log-λ权衡使常压室温常规超导极不可能（Gao 2025, 2502.18281）。guided diffusion证明高通量Tc预测偏高（Prakash 2026, 2509.25186）。各向异性/非谐/库仑均未接入高通量流水线（Mori 2024, 2404.11528）。

## 可切入的具体问题

1. 层状/准二维常规超导体的ab initio μ*修正对已有高通量库排名的系统性重排 | 候选材料清单已公开，方法已发表，不需要超算集群 | 候选材料数目有限（几十个），结论普适性可能受限；需确认该组代码是否公开可用
2. 用guided diffusion论文已公开的"预测vs实测"配对数据，定量拟合一个"高估因子"或校准模型 | 数据已发表，无需新计算，主要是统计建模工作 | 合成验证候选样本量可能偏小，统计功效有限；需综合多个预测-实测配对数据源（BEE-NET、Mg2IrH6等）才有说服力
3. 用现有开源MLIP替代部分DFT弛豫+声子步骤，评估对已知超导体库Tc预测的精度损失 | MLIP权重公开可下载，单机可跑，不需要新的DFT训练数据 | 此类benchmark竞争激烈（已有声子谱层面类似工作），需找准差异化角度（聚焦Tc而非声子谱本身）避免重复
4. Mg₂IrH₆类"预测-合成落差"案例的系统性复盘，定量刻画哪些亚稳相在动力学上大概率无法合成 | 所需形成能计算是标准DFT，不需要大规模算力，凸包数据部分已发表 | 可合成性判据本身是开放难题，单篇论文难给普适规则，需控制范围（聚焦一个体系族）确保可交付
5.（备选，风险较高）针对"常压常规超导Tc理论上限"的ω_log-λ trade-off，探索是否存在被现有高通量库系统性遗漏的化学家族 | 偏理论/概念性工作而非计算密集型 | 该论文已扫描2万个金属，遗漏空间可能不大或难以证伪
